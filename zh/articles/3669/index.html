[OpenAI] 前沿部署工程师 - 首尔 招聘公告

摘要

OpenAI 在韩国招聘网站 Wanted 上发布首尔前沿部署工程师（FDE）职位。该团队负责将前沿模型落地为生产系统，工程师需全程负责从需求探索、技术方案、系统设计到上线部署，并深度嵌入客户团队。职位要求五年以上工程或技术部署经验，具备面向客户的工作经历，能用 Python 或 JavaScript 编写前后端生产级代码，且有构建或部署基于大语言模型系统的经验。工程师还需将实战经验沉淀为工具与手册，并向研究和产品团队反馈模型在真实场景中的表现。

要点

  • OpenAI 通过 Wanted 招聘首尔前沿部署工程师
  • FDE 负责从原型到生产上线的端到端交付
  • 要求五年以上工程经验及客户-facing 经历
  • 需掌握 Python 或 JavaScript 前后端开发
  • 有部署大语言模型系统的经验者优先

全文

职位详情

OpenAI 的前沿部署工程团队与客户合作，将研究突破转化为生产系统。我们在客户交付与核心平台开发的交汇处开展工作。前沿部署工程师（FDE）与我们最重要的战略客户一起，主导前沿模型在生产环境中的复杂端到端部署。你将负责需求探索、技术范围界定、系统设计、构建和生产上线，并与客户工程团队和领域团队直接协作。

主要职责

• 负责多个部署项目从首个原型到稳定生产的技术交付。


• 构建能够为客户创造价值并提升我们学习能力的全栈系统。


• 与客户团队紧密协作，理解他们的需求，并引导他们采用你构建的成果。


• 界定工作范围、安排交付顺序，并尽早清除障碍。


• 在范围、速度和质量之间做出权衡；调整计划以保障交付。


• 当进展或清晰度取决于代码时，直接参与编码。


• 将有效的工作模式沉淀为他人可用的工具、操作手册或构建模块。


• 分享一线反馈，帮助研究团队和产品团队了解模型在哪些方面表现出色、在哪些方面可以改进。


• 通过清晰的沟通和持续跟进，推动团队不断前进。

任职资格

• 拥有 5 年以上工程或技术部署经验，并包含面向客户的工作。


• 曾在快速变化或模糊的环境中界定并交付复杂系统。


• 使用 Python、JavaScript 或类似技术栈编写和评审覆盖前端与后端的生产级代码。


• 曾构建或部署由 LLM 或生成式模型驱动的系统，并理解模型行为如何影响产品体验。


• 能够化繁为简，并在压力下快速做出合理决策。


• 与工程师、产品团队和客户利益相关方进行清晰沟通。


• 尽早发现风险并做出调整，同时不拖慢进度。


• 在高风险情境下展现冷静与判断力。
