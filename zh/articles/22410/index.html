纽约市前沿部署工程师职位 — Exa

原标题：Forward Deployed Engineer Job in New York City — Exa

Talentify · 2026-08-24 · 约 4 分钟读完

摘要

Exa 在纽约招聘前沿部署工程师，全职岗位。Exa 是一家为 AI 构建搜索引擎的公司，刚完成由 a16z 领投的 2.5 亿美元 C 轮融资，估值 22 亿美元。该岗位负责客户签约后的技术落地：推动集成上线、提升使用量与留存、参与售前支持，并覆盖美国东部客户。要求有多年编程经验，熟悉生产系统，最好涉及搜索、检索、LLM 或数据管道。岗位为纽约现场办公，可为国际候选人办理签证担保。

要点

  • Exa 完成 2.5 亿美元 C 轮融资，估值 22 亿美元。
  • 岗位负责客户从签约到生产上线的全流程技术落地。
  • 考核指标为采用率、使用量、留存与扩展收入。
  • 要求多年编程经验，最好有搜索或 LLM 相关背景。

全文

关于 Exa

我们完成了 2.5 亿美元的 C 轮融资，致力于为 AI 打造搜索引擎。本轮融资由 a16z 领投，现有投资者 Benchmark、Lightspeed 和 YC 追加投资，使 Exa 的估值达到 22 亿美元。

Exa 正在打造面向 AI 时代的搜索引擎。我们的 Search API 目前为 AI Agent、财富 500 强企业和 AI 实验室提供支持，正在变革一个自 90 年代以来从未被颠覆的行业。我们是一支约 100 人的团队，主要驻扎在旧金山，成员来自哈佛、MIT、Meta、Google Research，也有前创始人和辍学者。我们正在快速构建史上最智能的搜索引擎。我们高度主动、低调务实，并因一个共同的信念而凝聚在一起：这是少数几个值得做对的重要问题之一。

关于该职位

前沿部署工程师是实施和技术专家。客户签约后，你将成为他们的工程合作伙伴：帮助他们快速上线，让 Exa 成为其技术栈中不可或缺的组成部分，并在此基础上扩大客户规模。你处于产品、工程和客户成功的交汇点，考核指标包括采用率、使用量、留存率和扩展情况。

你将直接嵌入客户的工程团队，用 Exa 的 API 解决实际问题。出了问题，你来修复。缺少功能，你来构建。使用量下滑时，你在客户告知之前就已知道原因。你也是我们的专家储备：当售前交易需要比解决方案架构师更深入的专业知识时，你会被调去助力赢单。这不是支持岗位。你是一名对客户结果负责的工程师。你将从我们的纽约办公室负责东部地区的客户。

在这个职位上，你将：

  • 为新客户上手提供支持，帮助他们从签约走向生产环境集成，负责技术方案、里程碑和价值实现时间
  • 推动使用量和采用率，在每个客户内部发掘新的用例、团队和工作负载，并帮助客户将其落地
  • 让 Exa 不可或缺，通过设计深度嵌入客户产品、AI Agent 和流水线的集成方案
  • 预判流失和缩减风险，通过监控使用数据、质量信号和客户互动，在问题升级之前采取行动
  • 识别并推动业务扩展，与客户经理合作，从使用量增长到新产品和承诺额度升级
  • 调试并解决技术问题，覆盖全栈，从 API 行为和检索质量到客户的应用代码
  • 与支持团队协作，确保客户问题得到快速分诊、升级和解决，在问题升级时担任技术联系人，并与客户形成闭环
  • 在售前环节担任技术专家，当解决方案架构师在复杂评测、定制架构或战略客户方面需要更深入的专业知识时提供支持
  • 将客户反馈转化为产品改进，跨客户发现共性模式，并尽可能亲自交付修复
  • 主持技术评审，与客户 CTO、工程负责人和产品经理就路线图、性能及后续规划达成一致

任职要求

  • 数年编程经验。你能够从零构建并部署一个生产环境服务器
  • 有在真实代码库和生产系统中工作的经验，最好涉及搜索、检索、大语言模型或数据管道
  • 在高强度环境中有出色表现的记录，无论是顶尖计算机科学项目、竞技体育、创业公司还是其他领域
  • 能够长期负责客户关系，并在高风险技术对话中从容应对
  • 具备分析型思维：能够阅读使用数据、发现趋势，并将其转化为行动计划
  • 对频繁切换上下文、模糊性和持续高强度工作有很高的耐受度
  • 愿意根据客户合作需要出差

如果你具备以下条件，可能会脱颖而出……

  • 端到端地构建并发布过面向用户的产品
  • 曾担任软件工程师、前沿部署工程师、解决方案工程师或客户工程师，或担任过拥有实际主导权的技术客户管理岗位
  • 曾在上一家公司推动过客户留存、业务扩展或使用量增长
  • 能在早期阶段环境中如鱼得水，即使你的工作职责每月都在变化
  • 当客户想到 Exa 时就会想到你，这一想法让你充满干劲
  • 深切关注如何整理世界知识并使其可被机器访问这一问题

这是一个位于纽约市的现场办公职位。我们乐于为国际候选人提供签证担保（例如 STEM OPT、OPT、H1B、O1、E3）。除了高端医疗福利（医疗、牙科、视力）外，我们还为所有员工提供生育福利和每月健康津贴。

Exa 是一家机会均等的雇主。所有符合条件的申请人都将获得平等的录用考虑，不因种族、信仰、肤色、宗教、性别、性取向、性别认同或表达、国籍、残疾、年龄、退伍军人身份、婚姻状况、怀孕或相关状况、符合适用法律的犯罪记录，或任何其他受适用法律保护的特征而受到歧视。
