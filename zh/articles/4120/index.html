面向前沿部署工程师的智能体工作空间

原标题：The agentic workspace for forward-deployed engineers

Tandem · 2026-07-14 · 约 2 分钟读完

摘要

Tandem 面向前沿部署工程师推出 agentic 工作区产品，为每个客户部署维护一个自动更新的共享知识库，整合通话、Slack、工单、代码提交等来源，自动生成简报、风险提示和文档草稿，并支持通过 MCP 与 Claude 等工具读写。

要点

  • 为每个部署自动维护一个无需人工更新的共享知识库。
  • 每天生成带来源的简报，指出进展、阻塞和上线风险。
  • 对照 SOW 检测范围蔓延和客户异常，标记风险或扩展机会。
  • 通过 MCP 与 Claude、Claude Code 等双向读写部署上下文。
  • 所有 AI 编辑需经工程师批准，并带可见标记。

全文

连接一切

电话、Slack、邮件、工单、CRM 和文件。还包括代码提交、产品事件、Claude Code 会话以及客户自己的电子表格。也可以通过 Claude 一行记录一个事实。

为前沿部署工程师打造的 Tandem

每个部署项目一个大脑，由你的电话、Slack、代码会话和客户的工具构建而成。无需任何人手动更新。复盘、风险标记和下一步行动，都为你自动起草。

投资方

创始人来自

每通电话、每个会话、每张工单、每次代码提交和每个 Claude Code 会话，汇聚成每个部署项目的一个大脑。说过什么、决定了什么、承诺了什么、交付了什么，一目了然。它会自动保持最新。

“Acme 还能赶上九月的上线吗？”每次都能得到同样的答案，每个事实都附有来源。这是整个小组的上下文，而不只是你个人的。

任务、复盘、状态报告、SOW 更新、交接文档。由大脑起草，写回你的工具。你逐一或批量审批。

简报

有什么进展、什么被阻塞、什么威胁上线。按部署项目划分、附有来源，每天早上在应用或 Slack 中推送。无需调优提示词，无需重读会议记录。

风险

将每个部署项目与既定范围、沟通内容和实际交付进行核对。范围偏离 SOW、无人提及的仓库变更、客户突然沉默。附上凭证标记为风险或扩展机会。由你来定夺。

无界面 / MCP

通过 MCP 读写大脑，可从 Claude、Claude Code 或任何 AI 界面操作。将客户的上下文拉入编码会话，完成后同步回去。整个小组共用一个大脑。

双向交付

客户在他们的 Excel 或 Jira 中跟踪。你在 Tandem 中跟踪。双方都保持最新，无需复制粘贴。每个 Agent 编辑都带有可见标记。未经你的批准，任何内容都不会发布。

在其之上构建

MCP、API、webhooks。将部署上下文接入你自己的仪表盘和工作流。你持续构建，底层的大脑始终保持真实。运行在你的环境中，而非客户的环境。
