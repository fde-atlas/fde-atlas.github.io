摘要

这篇文章整理 AWS 前沿部署工程师面试中 MLOps 与机器学习工程环节的常见问题，涵盖模型 CI/CD、漂移检测与重训练、Kubernetes 推理、特征存储及上线流程等主题，并附高级工程师水平的参考答案。文章指出 AWS 已正式设立前沿部署工程组织，2026 年 9 月公告提及与 Hoxton Wealth 合作落地生产级 agentic AI，纠正了此前 AWS 不使用该职位的说法。AWS 未公布专门的 FDE 面试流程，建议候选人准备领导力原则行为题、基于 AWS 服务的 agentic 系统设计及客户交付讨论，并向招聘人员确认所属赛道。

要点

  • AWS 已正式设立前沿部署工程组织，旧说法过时
  • 2026 年 9 月公告提及与 Hoxton Wealth 合作 agentic AI 项目
  • 面试重点：模型 CI/CD、漂移检测、K8s 推理、特征存储
  • AWS 未公布 FDE 专属面试流程，需向招聘人员确认赛道

AWS 的前沿部署工程师面试环节会涉及 mlops 与 ml 工程类问题，例如“ML 模型的 CI/CD 与传统 DevOps 的 CI/CD 有何不同？”、“作为 MLOps 工程师，你的日常工作职责是什么？”、“MLflow 是做什么的，它有哪四个组件？”。模型 CI/CD、漂移检测与再训练、Kubernetes 推理、特征存储、从预发布到生产的晋升以及流水线测试：这些正是 AWS、Databricks 以及所有 ML 平台面试环节反复考察的内容。完整题集按由易到难排序并附专家答案，见下文。

按顺序练习本页的 mlops 与 ml 工程问题，学习下方链接的底层概念，然后查阅 AWS 的完整面试流程，了解这一轮在整个面试环节中的位置。就 AWS 而言，面试官看重的是：以客户为中心的系统交付。

是的。AWS 设有明确的前沿部署工程组织，其 2026 年 9 月 3 日的公告描述了该团队与 Hoxton Wealth 合作开展生产级 agentic AI 项目。此前关于 AWS 不使用这一职位的说法已过时。

AWS 尚未公布 FDE 专属的面试流程。其 2026 年 9 月的公告描述了工程师嵌入客户团队，将 agentic 系统推向生产环境，并让客户能够自行运营。因此请准备领导力原则类行为面试题、基于 AWS 服务的 agentic 系统设计，以及客户交付讨论。请向招聘人员确认适用的是 FDE、ProServe 还是解决方案架构师方向，以及使用哪些测评。
