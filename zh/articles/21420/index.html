前沿部署策略师 | Clicks | 加州旧金山

原标题：Forward Deployed Strategist | Clicks | San Francisco, CA

Zero G Talent · 2026-10-12 · 约 4 分钟读完

摘要

Clicks 在旧金山招聘前沿部署策略师，面向医疗收入周期管理领域。该职位约八成时间用于为客户部署 AI Agent 工作流，包括梳理流程、编写指令、运行试点、调试故障并汇报自动化率与成本；其余时间将部署经验转化为可复用产品。公司强调部署是通往产品工作的路径，不要求写生产代码，但需具备 LLM 直觉与结构化思维。招聘对象为毕业两年内的量化背景人才，面试含部署案例题与现场试用日。

要点

  • Clicks 招聘前沿部署策略师，专注医疗收入周期管理。
  • 约八成工作为客户部署 AI Agent 工作流并调试故障。
  • 客户实现 90% 以上自动化，五周内上线，保证 50% 以上成本节省。
  • 不写生产代码，但需 LLM 知识与结构化思维。
  • 面向毕业两年内新人，面试含案例题与现场试用日。

任职要求

  • 计算机、数学、物理或工程学学士学位
  • 0-2 年经验；欢迎应届毕业生
  • 面向客户的经验：咨询、销售、教学、创业
  • 深厚的 LLM 知识：提示词、工具使用、评测
  • 出色的结构化思维；能将混乱的流程转化为逻辑

工作内容

  • 部署 AI Agent 工作流：梳理 RCM 流程，编写 Agent 指令
  • 运行有监督的试点，在历史案例上评估 Agent
  • 调试生产环境故障：指令、规则、门户的怪异行为、模型局限
  • 跟踪自动化率、准确率、成本；向管理层汇报
  • 将部署模式转化为可复用的产品模板、工具和评测

我们正在招聘一位前沿部署策略师，让我们的 AI Agent 在医疗机构中投入使用。你的大部分时间将用于与客户一起设计和部署 AI Agent 工作流，其余时间则用于将所学转化为产品。你拥有计算机或类似的量化背景，以系统思维思考，了解 LLM 的实际行为，并热爱与客户合作。

关于 Clicks 我们的使命是加速世界向自主化运营的转型。我们从医疗收入周期管理（RCM）入手。我们构建的 AI Agent 可以完成从预授权到拒赔管理和付款过账的各项工作，在计费团队今天使用的相同 EHR、支付方门户和电话系统中工作。客户可获得 90% 以上的工作全自动化，5 周内上线，并保证节省 50% 以上的成本。

为什么是现在：支付方正在使用 AI 拒绝理赔，不使用 AI 反击的医疗机构将落后于人。计费团队也因工作重复而流失严重。我们的 Agent 替他们承担这些工作。

  • 投资方： Y Combinator、20VC、Fly Ventures、Yellow。已融资 $4.5M。
  • 团队： 小而精、技术驱动、创始人主导。你将直接与创始人共事。

职位介绍 你将端到端负责部署：了解客户团队目前如何完成工作，将其转化为我们的 Agent 能可靠执行的逻辑，证明其有效，并推动上线。

直说了：这主要是一份部署工作。如果你主要想负责产品路线图，这个职位不适合你。如果你想通过与客户一起实际操作来学习该构建什么，那就是它。在一家 AI Agent 公司，知道该构建什么的人正是那些亲手部署过的人。在这里，部署是通往产品工作的路径，而不是进入产品岗位前需要缴纳的过路费。

你不需要编写生产代码。但你需要在逻辑上异常敏锐，能够推理 LLM 在哪里会成功或失败，并能在第一次会面中赢得收入周期总监的信任。

工作内容

部署 AI Agent 工作流（约 80%）

  • 主持客户启动会，梳理授权预审、资格核验、拒付管理和付款过账等工作流，细化到每一步和每一种异常情况。
  • 将 SOP 转化为 AI Agent 指令、决策逻辑和升级规则。
  • 在历史案例上评测 Agent，与客户团队一起运行有监督的试点，然后逐步推广。
  • 调试生产环境故障：判断是指令问题、缺少规则、门户的特殊行为还是模型能力限制，然后自行修复或推动工程团队解决。
  • 跟踪每个工作流的自动化率、准确率和成本，并向客户管理层汇报成果以推动业务扩展。

参与产品打磨（约 20%）

  • 发现各次部署中重复出现的问题，把一次性的修复转化为可复用的产品：模板、工具、评测。
  • 与工程团队并肩工作，缩短每个工作流的上线时间和投入精力。
  • 把客户的真实情况带入每一个产品决策。

你是谁

必备条件

  • 计算机科学、数学、物理、工程或其他量化领域的学位。
  • 应届毕业生至 2 年工作经验。这个职位专为职业早期的人打造。
  • 你真心喜欢与客户打交道，包括那些不光鲜的部分。你曾为了拿到结果做过繁琐的工作，而且并不觉得困扰。
  • 任何形式的面向客户的经验：咨询或客户方实习、创办过项目、销售、教学。
  • 你对 LLM 的理解超越炒作层面：上下文、提示词、工具使用、评测，以及模型会在哪里失效。
  • 出色的结构化思维。你能把混乱的流程转化为清晰的逻辑。
  • 能轻松阅读代码、日志和 JSON，尽管你不需要编写生产代码。

加分项

  • 你用 LLM 构建过东西：副业项目、Agent、提示词流水线、评测。
  • 接触过医疗、收入周期或其他运营密集型行业。

面试流程

  • 与我们的 CEO Dominik 进行初识电话（15 分钟）。我们互相了解，聊聊是什么吸引你申请这个职位。
  • 部署案例（带回家的任务，约 1 小时，外加 30 分钟通话）。我们会发给你一个真实的 RCM 工作流，比如一份附带几张门户截图的授权预审 SOP。你需要写出我们的 Agent 应遵循的指令，并指出你预计它会在哪里失败。可以使用任何你喜欢的 AI 工具，只需告诉我们你是如何使用的。在通话中，你向我们讲解你的工作，我们会抛出几个新的边界情况。无需编程。我们看重的是你的逻辑、你对 LLM 的直觉，以及你如何阐述自己的思路。
  • 与我们的部署负责人通话（45 分钟）。深入探讨我们如何开展部署工作、这个职位上的卓越表现是什么样的，以及你关于日常工作的疑问。
  • 在我们旧金山办公室进行现场试用日。你将与团队一起完成一个真实的部署任务，亲身体验这份工作的真实面貌。
