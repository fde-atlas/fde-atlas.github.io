FDE 作品集：能帮你拿到 Offer 的项目

原标题：FDE Portfolio: Projects That Get Hired

How to Become an FDE — Interview Kickstart · 2026 · 约 2 分钟读完

摘要

这篇来自 Interview Kickstart 的文章面向想成为 FDE 的读者，列出 20 个可写进作品集的项目创意。项目按类型分为 Agent、RAG、评测、Pipeline、MCP、微调等，每个附简要说明，如线索评分、知识库问答、LLM 评测流水线、发票查重、合同条款抽取等，强调贴近真实企业场景。

要点

  • 列出 20 个面向 FDE 求职的作品集项目创意。
  • 项目类型涵盖 Agent、RAG、评测、Pipeline、MCP 与微调。
  • 示例包括线索评分 Agent、知识库问答、发票查重、合同条款抽取。
  • 主张项目应模拟真实企业问题，展示端到端交付能力。

全文

01 线索资格评估 Agent Agent

摄取网络研讨会/演示报名数据和会议记录，基于 ICP 评分标准运行 LLM 诊断，并将评分后的 JSON 数据输出到 CRM。

02 内部知识库 RAG RAG

对 wiki、运维手册和 Confluence 文档建立索引，提供聊天界面，让工程师和运维人员可以带引用地查询机构知识。

03 LLM-as-Judge 评测流水线 Eval

自动化测试框架，将生产环境的提示词对照评分标准运行，从多个维度（准确性、语气、合规性）对输出打分，并发现性能回退。

04 销售通话洞察提取 Pipeline

通过结构化提取链处理通话记录，挖掘客户异议、竞争对手提及、后续步骤和错失销售机会的信号。

05 支持工单路由 Agent

使用 LLM 按产品领域和紧急程度对传入工单进行分类，路由到正确的队列，并为接手工单的客服人员起草首次回复。

06 竞争对手 RFP 情报 Agent Agent

抓取并解析公开的 RFP 和竞争对手申报文件，提取定价和功能信号，生成结构化的竞争简报。

07 重复发票检测 Pipeline

对应付账款发票运行嵌入相似度和结构化字段匹配，在付款审批前标记可能的重复发票。

08 根因分析助手 Agent

收到事故告警后，该 Agent 查询日志和指标，通过 RAG 检索相关运维手册，并起草一份包含建议缓解措施的排序 RCA。

09 文档解析 Pipeline Pipeline

使用多模态 LLM 从海量 PDF 中提取结构化数据（表格、条款、关键字段），并加载到数据仓库。

10 求职者匹配系统 RAG

对简历和职位描述进行嵌入，运行语义相似度排序，并为每个职位展示前 N 名候选人及 LLM 生成的匹配理由。

11 智能体报告生成器 Agent

给定数据源和报告模板，Agent 查询数据、执行分析、填充模板，并导出格式化的 PDF。

12 内部工具 MCP Server MCP

将内部 API（工单、人力资源、分析）封装为兼容 MCP 的工具端点，让组织内任何 LLM 客户端都能安全调用。

13 提示词回归测试套件 Eval

对提示词进行版本控制，每次变更都运行评测，跟踪模型升级过程中的指标漂移，并根据评测阈值控制部署。

14 客户评论情报 Pipeline Pipeline

从多个来源摄取评论，使用 LLM 提取结构化主题和情感，并将汇总的信号推送到 BI 仪表板。

15 入职文档问答机器人 RAG

基于 HR 和入职文档的 RAG 系统，新员工可以用自然语言查询，当置信度较低时自动升级转人工处理。

16 合同条款提取 Pipeline

解析供应商和客户合同，提取关键条款（终止、责任、SLA），标记非标准条款，并加载到结构化存储中。

17 未到场客户重新触达自动化流水线

根据活动行为对未转化线索进行评分，用 LLM 生成个性化触达文案，并批量推送到邮件或 CRM 序列。

18 微调领域分类器微调

从内部数据收集标注样本，针对分类任务（工单类型、线索细分、文档类别）微调基础模型，并通过 API 提供服务。

19 多智能体研究工作流 Agent

编排规划者 + 研究者 + 撰写者的 Agent 循环，按需将内部和外部来源综合成结构化交付成果。

20 LLM 输出护栏层评测

构建一个中间件层，在每条 LLM 响应到达最终用户之前，对其进行策略、幻觉和 PII 检查。
