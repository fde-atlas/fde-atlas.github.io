摘要

本文是 FDE中国 的工具档案，介绍 LangChain 官方的评测与观测平台 LangSmith。其核心优势是与 LangGraph 同源：节点、状态和工具调用在 tracing 中原生可见，调试成本低于外挂方案。作者提醒不要把平台绑定当默认选择——LangSmith 是 SaaS 优先的商业平台，客户对数据出境敏感或要求私有化时，应重新评估 Langfuse、Arize Phoenix 等开源自托管选项。文章提出「先看编排框架、再选观测层」的选型思路，并指出字节 FDE JD 点名 LangGraph 是国内信号，建议在 LangGraph 项目关键节点挂评测断言，跑通端到端回归链路。

要点

  • 同源优势：LangGraph 节点、状态、工具调用在 tracing 中原生可见，调试成本低。
  • LangSmith 是 SaaS 优先商业平台，数据敏感或私有化场景需改用 Langfuse、Arize Phoenix。
  • 选型思路：先确认客户编排框架，再选观测层，而非反向。
  • 行动建议：在 LangGraph 关键节点挂评测断言，跑通端到端回归链路。
