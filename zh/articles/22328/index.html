洛杉矶，加州前沿部署工程师职位

原标题：Forward Deployed Engineer Job in Los Angeles, CA

Talentify · 2026-08-24 · 约 7 分钟读完

摘要

Hadrian Automation 在洛杉矶（Torrance）或旧金山湾区招聘前沿部署工程师，年薪 223,000 至 359,000 美元。该公司在完成 13.7 亿美元 D 轮融资、估值 78.7 亿美元后扩张，为航空航天与国防客户构建自主工厂。该岗位需嵌入客户项目，配置其 Opus 软件与机器人平台并开发新软件，要求全栈能力、AI 原生工作方式及直接面向客户的经验，且因 ITAR 规定须具备美国公民或永久居民等身份。

要点

  • Hadrian 完成 13.7 亿美元 D 轮融资，估值 78.7 亿美元。
  • 岗位年薪范围为 223,000 至 359,000 美元。
  • 前沿部署工程师需配置 Opus 平台并开发新软件。
  • 要求全栈能力、AI 原生工作方式与客户沟通能力。
  • 因 ITAR 规定须为美国公民或永久居民等身份。

全文

Hadrian —— 制造未来

Hadrian 正在打造自主化工厂，以推动美国的再工业化。通过结合 AI、先进软件、机器人技术和全栈制造，我们帮助航空航天与国防企业以最高 10 倍的速度、显著更低的成本建造火箭、卫星、飞机、舰船及其他任务关键系统。

在完成 13.7 亿美元 D 轮融资、估值达 78.7 亿美元之后，Hadrian 正迅速扩展我们的制造布局，推出焊接、铸造、锻造、电子、增材制造等全新能力，同时扩展我们的“工厂即服务”平台，变革关键产品的制造方式。

我们获得 JPMorgan Chase、Valor Equity Partners、Andreessen Horowitz、Founders Fund、137 Ventures、Lux Capital、T. Rowe Price 和 Morgan Stanley 等顶级投资者的支持，正在打造美国制造业的未来——并寻找杰出的人才与我们共同实现这一目标。

如果你准备好迎接职业生涯中最具挑战性也最有回报的工作，同时为子孙后代创造美国的制造业就业机会，那你正是我们在寻找的人。

职位介绍

前沿部署工程师深入企业客户项目一线，竭尽所能确保项目成功。

有时这意味着提供连接纽带：根据项目的具体需求配置和集成 Opus——Hadrian 的软件与机器人平台。同样常见的是，这意味着在最前沿构建新产品，包括客户自己都没想到要提出的产品。你将驱动从需求发现到部署落地的完整闭环，你与客户之间没有任何中间层级。

你构建的最优秀成果不会停留在定制层面。你在最前沿打造的产品往往会成为 Opus 的一部分，这使它成为 Hadrian 新产品发现最敏锐的来源之一。

这不是客户成功或部署支持岗位——你大部分时间都在构建。团队尚处于早期，现在加入的人将定义它的未来。

你的职责

  • 端到端负责整个项目——从最初模糊的沟通，到需求发现、构建、部署和迭代。你会全程跟进，从混乱的起步阶段一直到生产环境稳定运行。
  • 与全方位利益相关者沟通——客户高层、项目经理，以及客户团队和 Hadrian 团队的操作员与工程师——将技术约束转化为非技术利益相关者可以据此行动的决策。
  • 与构建 Opus 的团队紧密合作，在项目需要之处深入钻研——设计集成方案、数据模型和配置，让平台能够在客户的真实系统和实际生产环境中运行。
  • 构建全新软件，助力项目成功 —— 包括独立应用、定制工作流以及解决 Opus 尚未覆盖问题的集成方案。有些工作会专属于某个项目；有些则会成为平台的一部分。
  • 快速交付，持续迭代。 尽早让可用的产品交到用户手中，而不是在封闭环境中追求完美。
  • 将一线经验转化为平台方向。 把具体需求反馈给 Opus 团队，并帮助判断一次性解决方案何时应升级为平台功能。

我们在寻找什么样的人

  • 具备高度主人翁意识的优秀构建者 —— 能够从容地从 0 到 1，并在没人给你规格说明的模糊环境中完成交付。
  • AI 原生，并对此坚定不移。 我们在寻找节奏极快、主动性极强的工程师，他们利用 AI 压缩一切环节 —— 探索、原型设计、执行。你能具体展示 AI 已经如何让你效率成倍提升，并且渴望更进一步。
  • 驾驭全栈 —— 从 UI/UX 工作到后端系统设计，始终选择最适合问题的技术，而不是默认使用自己熟悉的工具。
  • 出色的产品直觉。 你不仅思考如何构建，更思考该构建什么。
  • 有直接与客户或终端用户合作的经验，能够将模糊的需求转化为具体落地的解决方案。
  • 沟通跨度广。 你可以在同一周内与工厂车间的操作人员和项目高级利益相关者顺畅交流，并将复杂的技术约束转化为能推动非技术决策的语言。
  • 被使命和节奏所驱动。 你会因自己对所参与项目产生的影响而充满干劲，并深切关注以客户所需的速度交付成果。

什么会让你脱颖而出

  • 创始人或初创工程师经验 —— 你曾将新产品从 0 做到 1。
  • 有前沿部署、解决方案工程或技术咨询经验 —— 你曾直接面对复杂混乱的客户现实进行构建。
  • 具备航空航天、国防或制造领域的背景 —— 或任何软硬件必须结合的领域。
  • 有可见的作品积累 —— 活跃的 GitHub 主页，或一系列你在工作之外交付的项目作品集。

工作地点

此职位基于我们位于洛杉矶（托伦斯）或旧金山湾区的办公室。你需要定期出差，到客户和操作人员现场工作 —— 足以亲身体会他们的实际环境 —— 但这不是一个需要频繁出差或长期驻外的职位。

Hadrian 的所有工程、产品和设计岗位入职者均以技术团队成员（MTS）身份加入。MTS 需要将一个模糊的问题推进到生产落地，全力拓展 AI Agent 的能力边界，以驯服一年前还难以解决的制造业难题。你的工作单位是“被解决的问题”，而不是工单或 Pull Request。你设定目标意图，构建验证闭环，然后让 Agent 释放到过去需要一个团队才能完成的工作上。你端到端地对 Agent 的产出负责。你能够解释它们做了什么、为什么是正确的，以及下一代 Agent 将如何修复这一代暴露出的问题。

薪酬

该职位的目标薪资范围为 $223,000 - $359,000（实际范围可能因经验而异）。

这是我们在发布本招聘信息时，基于合理和善意判断为该职位支付的最低至最高薪资。我们最终支付的金额可能高于或低于所发布的范围，且该范围未来可能被调整。员工在薪资范围内的具体位置将取决于多项因素，包括但不限于相关教育背景、资质、认证、经验、技能、地理位置、绩效以及业务或组织需求。

全职员工福利

  • 面向员工的医疗、牙科、视力及人寿保险计划，401k 退休金计划
  • 视业务需要，某些情况可能提供搬迁支持。
  • 弹性休假政策
  • 股权

ITAR 要求

为符合美国政府出口法规，包括《国际武器贸易条例》（ITAR），你必须是美国公民或国民、合法永久居民、8 U.S.C. 1324b(a)(3) 所定义的受保护个人，或有资格获得美国国务院所需的授权。在此了解更多关于 ITAR 的信息。

招聘中对 AI 的使用

Hadrian 在招聘和录用流程中使用 AI 辅助工具，以帮助团队更高效地工作。这可能包括帮助整理和分析招聘数据的工具，以及一款 AI 驱动的会议记录工具，它可以录制并转录面试内容、协助协调反馈。这些工具是为团队提供支持的，并不用于做出录用决定。所有候选人评估和录用决定均由人工完成。如果面试将被录制，我们会提前通知你，你可以随时选择退出，且不会影响你的候选资格。通过这些工具处理的候选人数据受我们隐私政策中所述的同等保护。

犯罪记录的考量

Hadrian 将以符合所有适用法律要求的方式，考虑雇用有犯罪记录的合格申请人。我们在申请表中不询问犯罪记录，并且在发出有条件录用通知之前也不会考虑犯罪记录。

Hadrian 是一家机会均等雇主

Hadrian 不会基于种族、肤色、宗教、性别、国籍/族裔、退伍军人身份、残障状况、年龄、性取向、婚姻状况、精神状况、身体残障或任何其他受法律保护的身份进行非法歧视。必要时，公司还会为残障候选人及员工提供合理的便利安排，包括因怀孕、分娩或相关医疗状况而致残的候选人或员工。
