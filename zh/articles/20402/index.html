前沿部署工程师（FDE）| Raindrop

原标题：Forward Deployed Engineer (FDE) | Raindrop

Zero G Talent · 2026-06-30 · 约 2 分钟读完

摘要

Raindrop 是一个 AI Agent 监控平台，正在旧金山招聘前沿部署工程师。该职位需驻场客户、端到端排查问题，并将一线反馈转化为产品路线图。公司由 Lightspeed 等投资，客户包括 Vercel、Speak、Clay 等。

要点

  • Raindrop 为 AI Agent 提供静默失败告警与根因追踪。
  • 传统评测难以覆盖真实生产环境中 Agent 的复杂行为。
  • 平台为每家公司训练私有小模型，处理数亿事件。
  • FDE 需驻场客户、亲手调试并反馈产品改进。
  • 职位要求常驻旧金山，投资人含 Lightspeed 与多位知名创始人。

关于该职位

Raindrop 是面向 AI Agent 的监控平台。财富 100 强和最快的 AI 公司（包括 Vercel、Speak、Clay）的工程团队都在使用 Raindrop 来获取 AI Agent 静默失败的警报。当 AI Agent 出现异常行为时，Raindrop 会发送警报，让 AI 工程师能够深入查看对话或追踪记录，理解根本原因并快速修复。

为什么重要

AI Agent 经常以既滑稽又可怕的方式失败。普通软件会抛出异常，但 AI Agent 会静默失败，让工程师几乎无法了解他们的 Agent 实际表现如何。

目前的现状是筛选数百万条日志，并试图调试那些与真实世界结果不匹配的不稳定评测。评测就像单元测试，它们只能确认你的模型在特定测试用例上表现正确。但在真实世界中，Agent 会调用数千个工具，运行数小时，并遇到数百万个不可预测的操作。

这就是 Raindrop 的用武之地。它会学习每个 AI Agent 问题的独特形态。从“懒惰”、“遗忘”或“任务失败”等预设开始，自动针对每个 Agent 进行调整，并发现未知的未知问题。

只需一键点击，AI 工程师就可以在 100% 的生产数据中追踪问题或主题。他们可以看到随时间变化的频率、受影响的用户数量、相关属性等。

为了处理数亿个事件，我们会逐步训练小型定制模型，这些模型对每家公司都是私有的，能够独特地理解其产品的使用方式。

作为早期团队的一员，你将在塑造公司方面发挥基础性作用——从制定战略和产品决策，到帮助团队扩展规模，再到塑造 AI Agent 的未来。

我们的投资者

我们获得了优秀投资者的支持，包括 Lightspeed 以及领先的 AI 公司，包括 Figma Ventures、Vercel Ventures、Replit 创始人（Amjad Masad 和 Michele Castata）、Cognition（Walden Yan）、Framer（Koen Bok 和 Jorn van Dijk）、Speak（Andrew Hsu）、Notion（Akshay Kothari）等。

你的职责

  • 深入客户现场，帮助他们上手并运行 Raindrop
  • 端到端地负责客户问题，在他们的 Agent 和我们的平台之间进行调试
  • 将你在一线学到的东西转化为产品反馈，塑造我们的路线图

理想候选人

  • 顶尖的沟通者（前 0.1%），宁愿面对客户也不愿整天埋头苦干
  • 优秀的工程师，能够阅读代码库、调试生产系统，并亲自动手修复客户 bug
  • 对 AI 产品和工具有兴趣（最好有构建这些产品的经验，或者是忠实用户）
  • 成长型思维
  • 愿意不惜一切代价解决问题
  • 期待与领导层紧密合作，从第一天起就负责高影响力的工作。
  • 必须在旧金山现场办公（或愿意搬迁）

关于 Raindrop

以正确的方式监控你的 AI Agent。AI 工程师使用 Raindrop 来获取 AI Agent 中静默失败的警报。当你的 AI 出现异常行为时，Raindrop 会向你发送警报，并直接链接到相关事件，让你可以深入查看对话或追踪记录，理解根本原因并快速修复。
