前沿部署工程经理，金融… | OpenAI

原标题：Forward Deployed Engineering Manager, Financial Se… | OpenAI

Zero G Talent · 2026-11-05 · 约 5 分钟读完

摘要

OpenAI 在纽约招聘金融服务方向的前沿部署工程经理。该职位要求 10 年以上工程或技术交付经验、2 年以上管理面向客户工程师的经历，需能编写 JavaScript 或 Python 生产级代码，并有受监管环境（尤其金融行业）的工作背景。职责包括带领 FDE 团队为银行、资管、保险等机构交付生产级 AI 系统，端到端负责交付成果，将现场经验沉淀为工具、手册和路线图输入，并与产品、研究、销售及市场推广团队协作。工作模式为每周 3 天到岗的混合办公，差旅最多 25%，提供搬迁协助。

要点

  • OpenAI 在纽约招聘金融服务前沿部署工程经理。
  • 要求 10 年以上技术交付经验，2 年以上管理经验。
  • 需掌握 JavaScript 或 Python 生产级代码能力。
  • 职责是带领 FDE 团队端到端交付金融 AI 系统。
  • 混合办公每周 3 天到岗，差旅最多 25%。

任职要求

  • 10 年以上工程或技术交付经验
  • 2 年以上管理面向客户的高绩效工程师的经验
  • 使用 Javascript 或 Python 编写生产级代码
  • 曾带领高压技术项目从原型走向生产
  • 具有金融服务或受监管环境的经验

工作内容

  • 带领并发展一支交付生产系统的 FDE 团队
  • 对金融服务部署的端到端交付成果负责
  • 将经验总结沉淀为工具、操作手册和路线图输入
  • 与产品、研究、销售和市场推广团队紧密合作
  • 为 FDE 的绩效和团队成长设定高标准

关于团队

OpenAI 的前沿部署工程团队与银行、资产管理公司、保险公司和私募资本机构合作，在高风险的金融环境中部署生产级 AI 系统。我们的工作处于客户交付与核心平台开发的交汇点，深度融入客户，将前沿模型能力转化为可靠、可审计并能创造可衡量业务影响的系统。我们的工作将早期部署转化为可复用的解决方案模式、运营标准和评测实践，并在受监管的金融机构中规模化推广。

关于职位 作为一名奠基性的 FDE 经理，你将带领 FDE 完成高风险、充满不确定性的金融服务部署，并对技术和业务价值成果进行端到端负责。你将打造一支能够在压力下运作的团队，并帮助 OpenAI 从一线实践中学习。你将服务的客户是投资银行、交易、风险、合规、承保、研究、运营或投资决策领域的专家，你需要将复杂的工作流程、数据约束和监管要求转化为生产系统。

你将与产品、研究、销售和市场推广团队紧密合作，确保一线工作为路线图优先级提供依据、推动新的探索，并支持大规模的安全部署。你的决策将影响 OpenAI 在与我们部署工作最贴近的客户中的信任度。你的成功将以团队交付的稳定性、向研究和产品团队传递信号的清晰度，以及团队和交付模式的持久性来衡量。

该职位位于纽约市。我们采用每周 3 天到岗的混合办公模式，并为新员工提供搬迁协助。该职位还需要出差，出差时间最多占 25%。

在这个职位上，你将：

  • 带领并发展一支使用前沿模型交付生产系统的 FDE 团队
  • 通过清晰的沟通、快速的行动、紧密的协调和过硬的技术质量，对端到端交付成果负责
  • 将行之有效的经验沉淀为工具、操作手册和路线图输入，为 OpenAI 及更广泛的开发者社区创造杠杆效应
  • 及早发现各种信号并紧急上报，无论是产品行为、客户环境还是交付实践中的问题
  • 运用判断力区分哪些需要采取行动，哪些不需要
  • 为 FDE 的表现设定高标准，并通过直接、可执行的反馈支持每个人的成长
  • 定义我们如何组建和支持能够规模化扩展而不增加复杂性的现场团队

如果你具备以下条件，你可能非常适合这个职位：

  • 拥有 10 年以上工程或技术交付经验，其中包括 2 年以上管理高绩效 FDE 或面向客户的工程师团队的经验。
  • 曾主导从原型到生产的高压技术项目。
  • 使用 Javascript 或 Python 编写并评审生产级的前端和后端代码。
  • 能够化繁为简，并在压力下快速做出合理决策。
  • 通过清晰的沟通而非流程来提升团队表现。
  • 在模糊或不断变化的环境中以紧迫感开展工作。
  • 将一线经验转化为针对产品与研究团队的精准、可执行的反馈。
  • 在最关键的时刻以身作则，展现冷静、专注和判断力，与团队建立深厚的信任。
