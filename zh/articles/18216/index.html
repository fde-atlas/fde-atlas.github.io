摘要

这是 AI Codex 术语表中的 AI Agent 词条。文章界定 AI Agent 为能自主执行多步骤行动以完成目标的 AI 系统，与只回答问题的聊天机器人形成对比：Agent 可搜索网页、读写文档、编写代码、调用其他系统，并持续工作直到任务完成。文中以 Claude 为例说明实践方式：用户只需给出目标（如监控收件箱并起草紧急邮件回复），Agent 会自行执行、检查结果并推进。词条还汇总了 37 篇相关文章，覆盖 Agent 运维、评测、成本控制、多 Agent 协作，以及 Anthropic 的 Claude Code、Managed Agents、Claude Tag 等产品动态，并提及前沿部署工程师等新兴岗位的薪酬与招聘趋势。

全文

又称：自主智能体

一种被设置为执行一系列行动以完成目标的 AI 系统——而不仅仅是回答单个问题。智能体不只是回复你的消息，它还可以搜索网页、阅读文档、编写代码、向其他系统发送请求，并持续执行多个步骤直到完成任务。在配备合适工具的情况下，Claude 可以充当智能体。与普通聊天机器人的关键区别在于：智能体会行动，而不只是说说而已。

实践应用

与其问 Claude“我接下来该做什么？”然后自己根据它的回答采取行动，AI Agent 会直接替你行动。你给它一个目标——“监控这个收件箱，并为所有标记为紧急的邮件起草回复”——它就会运行、采取行动、检查结果，并持续工作直到任务完成。
