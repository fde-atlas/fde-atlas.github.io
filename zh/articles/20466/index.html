摘要

SpruceID 招聘高级前沿部署工程师，远程办公（限美国）。该公司主打隐私保护、基于标准的数字身份与凭证方案，客户以州政府等公共部门为主。该职位需兼具工程与客户交付能力：直接与州政府合作，将需求转化为技术架构并落地部署，参与 Rust 后端及全栈 Web 与移动端开发，同时担任公共部门的技术顾问，推动标准落地。要求 5 年以上静态类型语言后端经验，熟悉云基础设施与 DevOps，具备直接面向客户的沟通能力；有数字身份、密码学或公共部门项目经验者优先。

要点

  • SpruceID 招聘高级前沿部署工程师，美国全远程。
  • 工作对象为州政府等公共部门，聚焦数字身份方案落地。
  • 需参与 Rust 后端及全栈 Web、移动端开发。
  • 要求 5 年以上静态类型语言后端经验及云基础设施能力。
  • 有数字身份、密码学或公共部门经验者优先。

职位要求

SpruceID 构建注重隐私、基于标准的数字身份与凭证解决方案，让个人掌控自己的信息，同时帮助政府和企业提供安全、可互操作的服务。我们与公共部门组织合作，推动身份的签发、验证和使用方式的现代化。

作为一名资深前沿部署工程师，你将处于工程与客户交付的交汇点。你将直接与州政府及其他公共部门合作伙伴合作，设计、构建和部署解决现实世界身份挑战的方案。该职位将动手软件开发与咨询及客户成功相结合。你将作为 SpruceID 的现场代表与合作伙伴共事，确保我们的技术得到有效部署并产生持久影响。

该职位为美国境内全远程办公。

工作内容

  • 主导为州政府和企业客户设计和开发产品与解决方案
  • 与客户交付负责人、工程师和 UX 设计师紧密协作，确保项目成功交付和部署
  • 将客户需求转化为技术架构和可运行的实现
  • 作为公共部门合作伙伴信赖的技术顾问，指导他们采用标准和最佳实践
  • 构建符合公共部门安全、隐私和无障碍标准的后端软件以及全栈 Web 和移动应用
  • 为运行在后端服务、移动设备和浏览器中的新及现有 Rust 代码库做出贡献
  • 管理客户部署并支持运维

任职资格

  • 5 年以上使用静态类型语言（如 C#、Rust、Go 或 Java）交付后端软件的经验。
  • 有交付符合无障碍和安全标准的现代 Web 前端的经验
  • 具备领导跨职能工程工作并交付生产系统的能力
  • 拥有云基础设施（AWS、GCP 或 Azure）和 DevOps 实践的动手经验
  • 出色的沟通能力，并有直接与客户合作的经验，最好是在咨询或交付岗位上
  • 常驻美国，并乐于直接与州政府合作伙伴合作

加分项

  • 在数字身份、密码学、数据隐私或区块链方面有扎实的基础
  • 有参与公共部门软件项目的经验

在 SpruceID，我们重视多元的视角和背景。我们致力于提供平等就业机会，不因种族、肤色、血统、宗教、性别、国籍、性取向、年龄、公民身份、婚姻状况、残障、性别认同或退伍军人身份而有所歧视。
