前沿部署工程师 | Anthropic | 德国慕尼黑

原标题：Forward Deployed Engineer | Anthropic | Munich, Germany

Zero G Talent · 2026-08-17 · 约 5 分钟读完

摘要

Anthropic 在德国慕尼黑招聘前沿部署工程师，作为创始批次 FDE 参与构建企业级 AI 部署体系。该岗位需深入客户系统，用 Claude 模型开发生产级应用，交付 MCP 服务器、子 Agent 等技术产物，并将可复用的部署模式反馈给产品与工程团队。要求八年以上技术类客户导向经验，德语母语且英语流利，具备 LLM 生产经验与 Python 能力，差旅比例约 25% 至 50%。公司提供签证支持，采用混合办公政策。

要点

  • Anthropic 在慕尼黑招聘创始批次前沿部署工程师。
  • 职责包括用 Claude 构建生产应用并交付 MCP 服务器等产物。
  • 要求八年以上技术客户经验，德语母语、英语流利。
  • 需具备 LLM 生产经验、Python 能力，差旅 25% 至 50%。
  • 公司提供签证赞助与至少 25% 到岗的混合办公安排。

任职要求

关于 Anthropic

Anthropic 的使命是打造可靠、可解释、可操控的 AI 系统。我们希望 AI 对用户乃至整个社会都是安全且有益的。我们的团队是一支快速成长的队伍，由充满热忱的研究人员、工程师、政策专家和业务领导者组成，共同构建有益的 AI 系统。

你将与我们的售后、产品和工程团队紧密合作，结合工程专业知识、对前沿 AI 应用的理解以及面向客户的技能，深入了解客户的工作流程，开发创新解决方案，应对复杂的业务挑战，同时保持我们对安全性和可靠性的高标准。

你将站在企业级 AI 部署的最前沿，作为我们的创始 FDE 之一，帮助塑造我们的前沿部署模式。我们期望 FDE 能够自主运作，在不确定性中蓬勃发展，并在客户环境中以最高水准代表 Anthropic。这是一项重大责任：你将在企业领域发挥关键作用，倡导我们的使命。

工作职责

  • 在客户系统内使用 Claude 模型构建生产级应用，确保这些产品满足客户需求。
  • 为客户交付 MCP 服务器、子 Agent 和 Agent 技能等技术成果，用于生产工作流程。
  • 为 Anthropic 产品在企业环境中提供全方位的部署支持。
  • 识别并沉淀可复用的部署模式，并将洞察反馈给我们的产品和工程团队。
  • 持续掌握 LLM 能力、实现模式和 AI 产品开发技术栈的最新进展。
  • 与客户建立长期关系，并在合作的整个生命周期中主动发掘 AI 部署的新机会。
  • 频繁出差（25%-50%）前往客户现场，与客户面对面协作开发。
  • 在一线成为 Anthropic 使命的倡导者。

如果你具备以下条件，可能非常适合这个职位

  • 拥有 8 年以上技术类面向客户岗位的经验，例如前沿部署工程师，或具备咨询经验的软件工程师。也欢迎曾创业的技术创始人申请。
  • 德语母语，英语流利
  • 拥有 LLM 生产实践经验，包括高级提示词工程、Agent 开发、评测框架以及大规模部署。
  • 具备扎实的编程能力，精通 Python（最好还掌握 TypeScript、Java 等一门或多门其他语言），并有交付生产级应用的经验
  • 具有高度的主观能动性，能够在复杂组织中的不确定性中从容应对。
  • 具有高度的合作意识，善于跨组织协作，在相互冲突的优先事项之间以诚信为本进行权衡。
  • 热衷于通过创造性的技术应用推动安全、有益的 AI 系统的发展。
  • 具备出色的沟通能力，能够进行客户需求挖掘，并向不同的利益相关者传达技术概念，同时保持谦逊和协作的态度。
  • 拥有金融服务、医疗健康/生命科学或其他企业级垂直行业的背景者优先。
  • 具有企业 IT 系统和/或 AI 部署模式方面的经验者优先。

其他事项

最低学历要求：学士学位，或同等的教育、培训和/或工作经验组合

要求的专业领域：与该职位相关的领域，可通过课程学习、培训或专业经验证明

最低工作年限要求：所需工作年限将与该职位的内部职级要求相对应

基于办公地点的混合办公政策：目前，我们期望所有员工每月至少有 25% 的时间在我们的办公室工作。不过，某些职位可能需要更多的到岗时间。

签证担保：我们确实提供签证担保！但是，我们无法为每个职位和每位候选人都成功办理签证担保。如果我们向你发出录用通知，我们将尽一切合理努力为你办理签证，并聘请了移民律师来协助此事。

即使你认为自己不完全符合所有条件，我们也鼓励你申请。并非所有优秀的候选人都能完全符合所列的全部条件。研究表明，来自弱势群体的人更容易产生“冒名顶替综合征”，怀疑自己的竞争力，因此我们恳请你不要过早地自我否定，如果你对这份工作感兴趣，请提交申请。我们认为，像我们正在构建的这类 AI 系统具有重大的社会和伦理影响。我们认为这使得团队中的多元代表性更加重要，因此我们努力在团队中纳入各种不同的视角。你的安全对我们至关重要。为保护你免受潜在的诈骗，请记住，Anthropic 的招聘人员只会通过 @anthropic.com 邮箱地址与你联系。在某些情况下，我们可能会与经过审核的招聘机构合作，他们会表明自己是代表 Anthropic 开展工作的。请警惕来自其他域名的邮件。正规的 Anthropic 招聘人员绝不会在你的入职首日之前索要金钱、费用或银行信息。如果你对某条沟通信息存有疑虑，请不要点击任何链接——请直接访问 anthropic.com/careers 查看确认的职位空缺。

我们的不同之处

我们相信最具影响力的 AI 研究将是“大科学”。在 Anthropic，我们作为一个紧密协作的团队，只专注于少数几个大规模研究项目。我们重视影响力——推进实现可控、可信赖 AI 的长期目标——而不是研究更小、更具体的问题。我们将 AI 研究视为一门实证科学，它与物理学和生物学的共同之处不亚于与传统计算机科学工作的共同之处。我们是一个高度协作的团队，经常举办研究讨论，以确保在任何时候都在追求最具影响力的工作。因此，我们非常重视沟通能力。

了解我们研究方向的最简单方法是阅读我们近期的研究成果。这些研究延续了我们团队在 Anthropic 成立之前所从事的许多方向，包括：GPT-3、基于电路的可解释性、多模态神经元、缩放定律、AI 与算力、AI 安全中的具体问题，以及从人类偏好中学习。

Anthropic 是一家总部位于旧金山的公益公司。我们提供有竞争力的薪酬和福利、可选的股权捐赠配比、丰厚的假期和育儿假、灵活的工作时间，以及一个可以与同事协作的舒适办公空间。关于候选人使用 AI 的指引：了解我们在申请流程中使用 AI 的政策。
