FDE 面试术语表

原标题：FDE interview glossary

FDE Interview Prep · 2026 · 约 6 分钟读完

摘要

本文是一份 FDE 面试术语表，按字母顺序收录约 60 个面试官与课程常用的术语，每条用一句话定义，并注明对应的课程来源。内容覆盖工程实践（幂等键、金丝雀发布、延迟预算）、数据与 SQL（数据血缘、窗口函数、缓慢变化维）、AI 与评测（LLM-as-judge、提示注入、检索增强生成）、合规（GDPR、HIPAA、FedRAMP、SOC 2）及职位与薪酬（部署策略师、售前工程师、OTE）。还包含面试叙事类词汇，如桥接故事、所有权审计和 tripwire。

要点

  • 按字母排序的 FDE 面试术语表，每条一句话定义并标注来源课程。
  • 涵盖工程、数据、AI 评测、合规认证与薪酬职位等多类术语。
  • 职位词条区分 Palantir 的 FDSE（内部称 Delta）等不同公司用法。
  • 面试叙事词汇包括桥接故事、所有权语言与 tripwire 等。

面试官和课程中使用的词汇，每个词用一句话定义，并附上讲解它的课程。

A

  • Agent（AI Agent）
  • 一种系统，其中模型在设计设定的限制范围内，选择步骤和工具调用来完成任务。

B

  • Backfill（回填）
  • 通过管道重新处理历史数据，理想情况下使用与日常运行相同的幂等代码。
  • Backpressure（背压）
  • 来自慢速消费者的信号，使生产者减速，而不是让内存或队列溢出。
  • Bridge story（衔接故事）
  • 一段简短的叙述，通过点明客户、你为他们构建了什么以及带来了什么改变，将你过去的工作与 FDE 工作联系起来。

C

  • Calibrated commitment（校准过的承诺）
  • 一种仅限于自己可控范围的承诺，包含负责人和日期，并对其他一切说明前提条件。
  • Canary release（金丝雀发布）
  • 先将变更发送给一小部分流量，观察约定的指标，然后再推广给所有人。
  • Circuit breaker（熔断器）
  • 一种模式：在一段时间内停止调用出现故障的依赖项，然后再进行探测，从而避免故障级联扩散。

D

  • Data lineage（数据血缘）
  • 一份记录，说明每条数据的来源及其经过的转换，使任何数字都能追溯到其源数据行。
  • Data residency（数据驻留）
  • 一项要求：数据（包括日志和备份）必须在特定区域内存储和处理。
  • Dead-letter queue（死信队列）
  • 一个存放多次处理失败的消息的地方，保留用于检查和重放。
  • Decomposition round（问题拆解轮）
  • 一种开放式面试：你从模糊问题出发边想边说，该问题有多种可能的解决方案，最终得出一个具体方案和第一个可运行版本。
  • Deployment strategist（部署策略师）
  • 一种面向客户的角色，与 FDE 一起梳理客户的问题和范围；在某些雇主那里，该头衔指的是产品经理或背负销售指标的职位。

E

  • Embedding（嵌入向量）
  • 文本或其他数据的向量表示，用于衡量语义上的相似度。
  • Exponential backoff with jitter（带抖动的指数退避）
  • 以不断增长且随机化的延迟进行重试，使从同一故障中恢复的客户端不会同步重试。

F

  • FedRAMP
  • 美国政府的项目，在联邦机构将数据放入云服务之前，按影响等级对其进行评估和认证。
  • Forward deployed engineer（前沿部署工程师）
  • 一种软件工程师，在客户的问题和环境内部构建并交付生产系统，对客户的成果负责。
  • Forward deployed software engineer（前沿部署软件工程师）
  • Palantir 对其 FDE 职位的称呼，内部称为 Delta；OpenAI 和 EY 也发布 FDSE 职位，各自职责不同。

G

  • Gaps and islands（间隙与孤岛）
  • 一种 SQL 模式，用于在有序数据（如机器状态）中查找连续区段及其间的断点。
  • GDPR
  • 欧盟关于个人数据处理与传输的法规。
  • 黄金集
  • 一组经过精心整理并标注的示例，抽样覆盖重要场景，用于长期以相同方式评估系统。
  • 护栏指标
  • 与成功指标一同监控的指标，用于发现危害或钻空子行为，例如目标是平均值时按地区监控等待时间。

H

  • H-1B 劳动条件申请
  • 美国的一项申报文件，说明雇主将以何种薪资（费率或区间）支付被担保职位的员工；其中不记录奖金或股权。
  • HIPAA
  • 美国的一部法律，其隐私与安全规则规范受保护的健康信息以及处理这些信息的供应商。
  • 混合检索
  • 结合关键词检索与向量检索并合并两者的排序结果，例如使用倒数排名融合。

I

  • 幂等键
  • 由客户端提供的标识符，使服务器对重复请求只应用一次，从而让重试变得安全。
  • 评分者间一致性
  • 两名评审者，或一名评审者与一个模型评判者，对相同条目标注的一致程度，并校正了偶然一致的因素。

L

  • 延迟预算
  • 请求可占用的总时间，分配到其经过的各个步骤，既在中位数处也在慢尾处进行测量。
  • 上线标准
  • 在构建之前与客户商定的阈值，用于决定系统是否上线。
  • LLM 作为评判者
  • 使用带有评分标准的语言模型对输出进行评分；评判者本身必须对照人工标注进行检验。

M

  • Model Context Protocol
  • 一种开放协议，通过服务器向模型暴露工具和数据，使 AI Agent 能以标准方式调用客户的系统。

O

  • OAuth
  • 一种标准，允许应用程序代表用户获得对资源的有限且可撤销的访问权限，而无需共享密码。
  • 目标总薪酬
  • 基本工资加上达成目标后的浮动薪酬；以 OTE 形式标注薪酬的招聘信息将激励薪酬计入该数字。
  • 本体
  • 对客户业务对象及其关系的共享模型，映射到底层数据上，使人员和应用程序使用相同的术语。
  • OpenID Connect
  • 构建在 OAuth 之上的身份层，让应用程序能够验证用户身份并获取基本资料声明。
  • 归属审计
  • 重写故事，使每个决策都有明确的归属者：你决定并做了什么，以及他人做了什么，并给予他们应有的功劳。
  • 归属语言
  • 一种表述方式，明确指出谁在行动、他们将做什么以及何时完成，承担自己的责任，而不指责他人或宣称自己并不具备的控制权。

P

  • 个人数据
  • 能够识别某人或可与某人关联的信息，受隐私法和客户政策的限制。
  • 问题形态
  • 一种反复出现的客户问题结构，例如整合碎片化的数据源，在不同行业中表现相似。
  • 利润分成单位
  • 一种授予形式，支付公司未来利润分配的一部分而非股票，且不享有股东投票权。
  • 提示注入
  • 试图覆盖模型指令的输入，可以是直接的，也可以隐藏在检索到的文档、电子邮件或工具结果中。

Q

  • 查询计划
  • 数据库为执行查询而选择的步骤，通过 EXPLAIN 读取以发现扫描、连接和缺失的索引。

R

  • 重构轮
  • 一种面试形式，要求你在限时且边思考边说出的情况下，学习、调试或扩展从未见过的代码或库。
  • 回归测试套件
  • 在每次提示、模型或代码变更时重新运行的用例，用于捕捉以前正常、现在失效的行为。
  • 重排序
  • 在检索结果进入提示之前，用更慢但更准确的模型对少量结果重新评分。
  • 检索增强生成
  • 使用模型进行回答，并将从文档集合中检索到的段落作为上下文提供给模型。

S

  • 售前工程师
  • 销售团队内部或旁边的技术岗位，通过演示和概念验证帮助赢得交易；美国劳工统计局表示，雇主通常以工资加佣金或奖金的形式支付该职位。
  • SAML
  • 一种基于 XML 的标准，用于在身份提供方和应用程序之间交换认证断言。
  • SCIM
  • 一种标准协议，用于从身份提供方向应用程序配置和取消配置用户和用户组。
  • 范围蔓延
  • 需求通过未经审查的小幅增加而不断增长，而时间、人力或预算却没有相应变化。
  • 服务级别目标
  • 针对所测量的服务级别（如可用性或延迟）设定的目标；它所允许的故障就是错误预算。
  • 单点登录
  • 通过中央身份提供方登录一次，并在多个应用程序中使用该会话。
  • 缓慢变化维度
  • 属性随时间变化的维度表，以及记录变化的技巧，例如为每个版本新增一行并带有生效起止日期。
  • SOC 2
  • 审计师依据 AICPA 信任服务标准，对服务组织控制措施出具的鉴证报告。
  • 解决方案架构师
  • 面向客户的技术岗位，负责设计、提供建议并常常构建概念验证；招聘信息显示该岗位可能位于售前、售后，或两者兼有。

T

  • 令牌桶
  • 一种限流算法，以固定速率补充令牌，并允许不超过容量的突发流量。
  • 绊线
  • 一种特定案例的失败模式，优秀的候选人会在其破坏计划之前发现它，例如每个利益相关者对某个指标的定义各不相同。
  • 信任边界
  • 系统中数据或调用在不同信任级别的部分之间传递的边界，也是身份验证和校验应当所在的位置。

V

  • 虚拟私有云
  • 云服务商内部的一种隔离网络，客户可在其中控制地址分配、路由、出站流量以及指向其他账户的私有连接。

W

  • 行走骨架
  • 系统最精简的端到端版本，能在主要组件之间完成一个小的真实功能，先构建出来再逐步扩展。
  • 窗口函数
  • 一种 SQL 函数，基于与当前行相关的行进行计算（例如累计总和），而不会将这些行合并。
