摘要

Brickanta 是一家获 Y Combinator 支持、融资超 800 万美元的建筑行业 AI Agent 平台，正在荷兰招聘前沿部署工程师。该职位要求候选人兼具荷兰建筑行业经验（熟悉 UAV 2012、RAW、STABU 等法规与规范）和编程能力（Python 或 TypeScript），深入客户现场部署 AI Agent，并将实际项目中的判断转化为可衡量的评测。职位初期为兼职、远程办公，入职培训在斯德哥尔摩，计划 2027 年上半年开始，未来可发展为带领荷兰前沿部署团队。

要点

  • Brickanta 为建筑 AI 平台，融资超 800 万美元。
  • 招聘荷兰前沿部署工程师，需建筑与编程双重背景。
  • 核心工作是在客户现场部署 Agent 并构建评测。
  • 需熟悉 UAV 2012、RAW、STABU 等荷兰建筑规范。
  • 初期兼职远程，2027 年上半年入职，可成长为团队负责人。

关于 Brickanta

Brickanta 是面向建筑行业的 AI 原生智能体平台。数百个 AI Agent 承担投标、采购、合规和质量保证中的繁重行政工作，让建筑商按时按预算完成项目。

我们由 Y Combinator 支持，已从 Northzone、Anton Osika 和 Mario Götze 处融资超过 800 万美元，并已与行业内一些最大的承包商和开发商合作。我们是一支早期团队，发展迅速，像一支精英运动队一样运作：最大程度的自由与最大程度的责任并存。你对自己的工作负责，记录重要事项，与团队同甘共苦。

在与北欧的建筑商共同打造平台之后，我们正将其推向全欧洲。荷兰及更广泛的比荷卢地区是我们的首批市场之一，而这是我们在当地的首批职位之一。

职位介绍

大多数企业级 AI 都死在概念验证阶段。前沿部署工程正是我们避免这种情况的方式：你深入客户的工作流程——在施工现场、在投标室、在采购流程中——持续构建，直到工作真正以不同的方式完成。

在新市场，这也意味着教会我们的 AI Agent 建筑行业在这里是如何运作的。一个答案可能看起来合理，但在真实项目中却以关键的方式出错：UAV 2012 或 UAV-GC 条款被错误解读，工程量与 RAW 或 STABU 规范不符，Bbl 或 Wkb 中的某项要求被遗漏。你的工作就是发现这些问题，并将这种判断转化为我们的系统可以衡量的评测。

这不是咨询工作，也不是演示角色。你交付的是产品：找到真实承包商的真实瓶颈，构建消除瓶颈的 Agent 工作流程，用数字证明成果，并将所学带回核心平台。

你将负责的内容

部署

在荷兰端到端地负责指定客户：理解其工作流程，针对客户的真实文档和数据配置并扩展我们的 AI Agent，并推动它们进入日常使用。提前定义成功标准，并用数字加以证明：节省的工时、赢得的投标、发现的风险。

评测与基准真值

让我们的 AI Agent 应对真实的荷兰工作流程，并依据正确性、完整性和实际实用性来评判输出，而不是看它们听起来是否令人信服。将边缘案例和生产故障转化为可复用的评测：参考输出、评分标准、故障分类体系和专家审核的数据集。

在一线构建

编写代码。集成、数据管道、提示词、评测框架、自动评分器，偶尔还要开发全新功能：只要能让该客户的工作流程运转起来，什么都做。弄清哪些环节需要人工判断，然后把其余部分通过工程手段消除掉。

反哺产品

把你在一线学到的东西转化为数据集和可复用的构建模块，让每一次部署都能让下一次更快，无论在荷兰还是整个比荷卢地区。

我们在寻找什么样的人

建筑行业经验、技术深度，以及对客户的热情，三者兼备其一或兼而有之。独特的经历背景比完美的简历更重要。

背景

  • 在荷兰建筑行业有真实接触经验：现场管理（uitvoerder）、施工准备（werkvoorbereider）、造价估算（calculator）、项目管理、投标、采购或质量管理。
  • 熟悉荷兰的框架体系：《2012 年招标法》（Aanbestedingswet 2012）和 ARW 2016、UAV 2012 和 UAV-GC 2005 合同、RAW 和 STABU 规范、BPKV 评标标准以及 TenderNed，以及《环境法》（Omgevingswet）、Bbl 和 Wkb 下的建筑法规。
  • 有构建和交付软件的经验（Python 和/或 TypeScript、API、数据管道、SQL），或者具备相关基础并有快速达成的动力。
  • 较强的分析能力，并对现代 AI 系统有浓厚兴趣。我们是一家以 AI 为先的公司。
  • 有直接与客户合作的经验，或对此有明确的意愿。
  • 英语流利（这是我们的工作语言），荷兰语达到母语或接近母语水平。会德语或法语是加分项。无需会瑞典语。

心态

  • 你会亲赴工作发生的地方——现场勘察、投标会议室、采购会议——而不是坐在待办事项后面凭空猜测。
  • 注重细节且责任心强：在大量案例中始终坚守质量标准，发现问题、构建修复方案，并跟进到生产环境。
  • 你写作清晰。在 Brickanta，写作带来清晰，所有重要事项都会形成文档——当团队身处另一个国家时，这一点尤为重要。
  • 能够从容应对模糊性，并适应作为房间里唯一的工程师。

成长路径

这一职位旨在随着荷兰市场及更广泛的比荷卢地区共同成长。你将首先亲自执行首批部署，然后在荷兰组建并领导一支前沿部署团队，并随着时间推移，与我们的本地商务负责人一起，负责 Brickanta 在荷兰及整个比荷卢地区的技术布局。你的职责范围、薪酬和股权将随市场一起增长。如果你更愿意深耕而非广拓，这条路径也可以向内延伸至核心 AI、评测和平台工程。

职位概览

  • 地点： 荷兰远程办公，需定期到客户现场工作。你将先与团队一起在斯德哥尔摩总部完成入职培训，之后定期返回。差旅和住宿费用由公司承担。
  • 入职时间： 2027 年上半年。初期为兼职（或类似的灵活安排），目标是随市场增长转为全职。
  • 级别： 中级至高级。相比工作年限，我们更看重你在现场或代码中实际构建过什么。
  • 薪酬： 有竞争力的薪资和股权——你加入得足够早，股权会有实际意义。

关于 Brickanta

Brickanta 是面向建筑行业的 AI 原生 Agent 平台。数百个 AI Agent 接管招投标、采购、合规和质量保障中繁重的行政工作，让建筑公司按时、按预算交付项目。

我们获得 Y Combinator 的支持，从 Northzone、Anton Osika 和 Mario Götze 处融资超过 800 万美元，并已与业内一些最大的建筑公司和房地产开发商展开合作。我们是一个快速成长的年轻团队，以顶尖运动队的方式工作：最大程度的自由，配以最大程度的责任。你是自己工作的所有者，记录下重要的事项，我们作为一个团队共同赢、共同输。

在与北欧建筑公司共同打造该平台之后，我们现在正将其推向欧洲其他地区。荷兰及更广泛的比荷卢地区是我们的首批市场之一，而这是我们在当地的首批职位之一。

职位描述

企业中的大多数 AI 项目都止步于概念验证。前沿部署工程正是我们避免这种情况的方式：你深入客户的工作流程之中——在建筑工地、在成本核算部门、在采购流程中——持续构建，直到工作方式真正发生改变。

在一个新市场，这也意味着你要教会我们的 agents 在这里是如何开展工作的。一个回答可能看起来合理，却在真实项目中真正关键的点上出错：误读了 UAV 2012 或 UAV-GC 条款，工程量与 RAW 或 STABU 工程量清单不符，忽略了 Bbl 或 Wkb 中的某项要求。你的任务就是发现这些问题，并把你的判断转化为我们的系统可以衡量的评测（evals）。

这不是咨询工作，也不是演示岗位。你交付的是产品：你为一家真实的建筑公司解决一个真实的痛点，构建消除该痛点的 agent 工作流，用数据证明结果，并把学到的经验带回平台。

你的职责

实施落地

你将对荷兰的固定客户负责到底：理解他们的工作流，基于他们真实的文档和数据配置并扩展我们的 agents，并确保它们被日常使用。你要事先定义什么是成功，并用数据证明：节省的工时、赢得的投标、及时识别的风险。

评测与基准真值

你要在真实的荷兰工作流上测试我们的 agents，并依据正确性、完整性和实用价值来评判结果，而不是看它们听起来多有说服力。你要把边界情况和生产环境中的错误转化为可复现的评测：参考答案、评分标准、错误分类体系以及经专家审核的数据集。

在一线构建

你要写代码。集成、数据管道、提示词、评测环境、自动化评审器，偶尔还要开发一个全新的功能：一切让该客户的工作流运转起来所需的东西。你要弄清楚哪些环节需要人工判断，并将其余部分自动化。

把知识带回产品

你在一线学到的东西，要转化为数据集和可复用的构建模块，让每一次实施都能加速下一次——在荷兰，以及在整个比荷卢地区。

我们在寻找什么样的人

建筑专业知识、技术深度以及与客户合作的热情的结合。一个不寻常的履历比完美的简历更有价值。

背景

  • 在荷兰建筑行业的真实经验：作为施工执行人员、施工准备人员、造价估算师或项目经理，或在招投标、采购或质量领域工作过。
  • 熟悉荷兰的法规框架：《2012 年招标法》（Aanbestedingswet 2012）和 ARW 2016、UAV 2012 和 UAV-GC 2005 合同、RAW 和 STABU 工程量清单、BPKV 授标和 TenderNed，以及《环境法》（Omgevingswet）、Bbl 和 Wkb 下的建筑法规。
  • 有构建软件并投入生产环境的经验（Python 和/或 TypeScript、API、数据管道、SQL），或者具备基础并有快速达到这一水平的动力。
  • 较强的分析能力，并对现代 AI 系统有浓厚的兴趣。我们是一家 AI-first 的公司。
  • 有直接与客户打交道的经验，或对此有明确的热情。
  • 英语流利，因为这是我们的工作语言；荷兰语需达到母语或同等水平。德语或法语是加分项。无需瑞典语。

心态

  • 你会走到工作实际发生的地方——建筑工地、预算核算部门、采购会议——而不是坐在待办事项后面凭空猜测。
  • 注重细节，具有高度的主人翁意识：你在众多案例中保持高标准，发现问题、构建解决方案，并一路跟进到生产环境。
  • 你写作清晰。在 Brickanta，写作带来清晰度，所有重要内容都会被记录下来——当团队身处另一个国家时，这一点更加重要。
  • 你能从容应对不确定性，也能接受成为现场唯一一名工程师。

成长路径

这个职位旨在与荷兰市场乃至整个比荷卢地区共同成长。起初你亲自完成首批实施，随后在荷兰组建并领导一个前沿部署团队，随着时间推移，你将与我们当地的商务负责人一起，负责 Brickanta 在荷兰和比荷卢地区的技术影响力。你的角色、薪酬和股权都会随市场一起增长。如果你更愿意深耕而非拓宽，这条路径也可以通向产品核心：核心 AI、评测和平台工程。
