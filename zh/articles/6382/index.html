原标题：Prerequisites

AIelsen FDE Academy · 2026 · 约 1 分钟读完

摘要

AIelsen FDE Academy 的先修要求说明，面向前沿部署工程师从业者。课程强调文档不能替代代码：学员需具备 Python 或 TypeScript、SQL、HTTP/JSON、Git 与基础测试能力，能独立运行、修改并解释适配器与业务工具。不同背景决定准备重点而非最终标准：软件工程师需强化发现、指标、干系人协作与归因；业务背景者需补齐编程基础，先走商业路径再完成入门检查，可参与面试与评审，但工程路径仍需代码、测试与交付证据。

要点

  • 课程面向 FDE 从业者，背景只影响准备重点，不降低最终标准。
  • 技术基线：Python 或 TypeScript、SQL、HTTP/JSON、Git 与基础测试。
  • 要求能读 CSV 查空值重复、写 SQL 解释分母与空结果、调用函数处理错误。
  • 文档不能替代代码，需独立运行并解释适配器与业务工具。
  • 业务背景者先走商业路径补编程，工程路径仍需代码与交付证据。

全文

背景与准备

软件工程

加强需求探索、指标、干系人协作与归因分析。

准备证明

将一次业务事故转化为对象、定义、责任归属与验收标准。

从实地工作到持久的业务能力。前沿部署工程

前置条件 / FDE 从业者

这是一门面向 FDE 从业者的工程与交付课程。你的背景会改变准备的优先级，但不会改变最终标准。

运行并修改本地程序，理解数据表和 API，在 Git 中跟踪变更并编写基本测试。建议掌握 Python 或 TypeScript、SQL 以及 HTTP/JSON。

  • 读取 CSV 文件；检查空值和重复项。
  • 编写 SQL；解释分母、窗口函数和空结果。
  • 调用函数，校验参数并处理错误。
  • 运行测试并在 Git 中解释一次变更。

加强行动状态、集成、运维与范围管理。

演示重放、未知结果、拒绝与恢复。

加强 Python、SQL、API、Git、测试与模型工具使用能力；文档不能替代代码。

独立运行、修改并解释一个适配器和业务工具。

如果编程对你来说是新领域，请先从 Academy 业务路径开始，然后打好编程基础并完成入门检查。业务专家可以参与面试和评审；但工程路径仍然要求代码、测试和交付证明。
