全文

FDE · Forward Deployed Engineer

业务现场的 AI Agent 全链路落地专家

FDE = Forward Deployed Engineer，国内常译为前线部署工程师或驻场 AI 落地工程师。不是后端、不是算法研究员、不是售前，而是直接扎进业务现场，把模糊的业务需求变成可交付、可验证、可沉淀价值的 Agent 工作流。

POSITIONING

传统研发在公司内部写通用产品；FDE 直接派驻业务/客户现场，解决模糊业务需求，从零搭建定制化 Agent 工作流。

01 在公司内部打磨平台化通用产品，离一线业务细节较远。

02 扎进业务/客户现场，理解真实流程、处理模糊需求。

03 把业务 Know-how 封装为可运行、可迭代、可沉淀价值的 AI Agent。

CORE WORK

从需求到交付，FDE 覆盖 AI Agent 落地的完整链路

Planning 层：把业务模糊大目标用 HTN 分层拆解，梳理可用 Skills、工具权限、执行约束。

Profile / Memory / Tools / Action：封装业务 Skill、接入向量记忆、对接数据库/API 工具、编写执行逻辑。

Orchestration：实现 Agent 循环、异常熔断、重规划、安全护栏，让 Agent 在业务里稳着跑。

04 工程扩展层：搭建指标监控、自动化评测，验证 Agent 业务价值，再把通用能力沉淀回公司产品线。

DIFFERENCE

按标准流程交付已成熟的产品模块，不动底层逻辑，也不处理一线业务的非标需求。

在公司内部搭建平台、写通用功能，重点在架构与性能，通常不深入一线业务细节。

现场定制 Agent、端到端交付业务结果，并把验证过的通用能力反向输出给团队与产品。

NOTE

部分自媒体把底层 Agent 基建开发工程师也简称为 FDE，本质同赛道，但侧重 Agent 框架底层开发。

我们坚持 FDE 的“前线部署”原意：人要派驻现场，结果要能交付，能力要能沉淀回企业。

不是把产品说明书念给客户听，而是帮助客户把真实业务场景里的痛点变成可运行的 Agent 工作流。

FDE 即 Forward Deployed Engineer（前线/驻场 AI 落地工程师）模式。宁波有道网络把 AI Agent 直接派驻到货代、律师等业务现场，把模糊的业务需求拆解、搭建为可交付、可运行、可沉淀价值的智能体工作流，而不是只卖通用工具。

目前围绕流程化程度高、痛点明确的垂直行业落地，已推出货代 AI 平台、律师 AI 工作平台等方案；制造、外贸、零售、教育等行业也可结合实际业务场景按需定制专属 Agent。

通过货代 AI 平台把报价、跟单、单证、客户服务全流程打通：运价统一管理一键报价、订舱拖车报关等节点自动跟踪提醒、提单装箱单自动生成并校验、多语客服 7×24 应答，减少人工差错与响应时间。
