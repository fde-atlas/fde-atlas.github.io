计算机使用 Agent 的现状 | Anthropic、Browser Use 与 KERNEL

原标题：The State of Computer Use Agents | Anthropic, Browser Use & KERNEL

Forward Deployed · 2026-09-02 · 约 1 分钟读完

摘要

本文是关于计算机使用 Agent 现状的对谈实录。互联网机器人流量已超过人类流量，比预测提前两年。作者邀请三位从业者讨论：Anthropic 计算机使用团队的 Lucas Gonzalez Pagliere、开源项目 Browser Use 创始工程师 Reagan Hsu（约 10 万 GitHub star）、以及浏览器基础设施公司 KERNEL 的创始客户工程师 Eric Feng。对话涵盖模型真实能力与基准测试的差距、跑完真实任务的成本，以及 Agent 与反爬虫系统之间的攻防，最后探讨网络会围绕 Agent 重组还是对其设防，三人观点存在分歧。

全文

互联网上的机器人流量刚刚超过人类流量，比预测提前了两年。其中大部分是 Agent 在为人类设计的网站上点击浏览。

所以我把三位构建这些 Agent 的人请到了一起：Lucas Gonzalez Pagliere，他在 Anthropic 从事计算机使用方面的工作，该团队在 2024 年推出了首个计算机使用模型。Reagan Hsu，Browser Use 的创始工程师，其开源库在 GitHub 上已有约 10 万颗星。还有 Eric Feng，KERNEL 的创始客户工程师，KERNEL 为许多这类 Agent 提供底层浏览器基础设施——他还曾是 Sentry 的第一位市场推广人员。

我们聊到了模型今天的真实水平与基准测试所显示的水平之间的差距、让一个 Agent 运行足够长时间以完成实际工作的成本，以及 Agent 与试图将它们拒之门外的反机器人系统之间的军备竞赛。然后是这一切背后更难的问题：互联网是会围绕 Agent 重新组织自身，还是会对其严防死守。他们在很多问题上都有分歧。

如果你想知道 Agent 今天在真实网站上究竟能做到什么——以及还有什么会让它们彻底卡壳——这一期值得你花时间看看！
