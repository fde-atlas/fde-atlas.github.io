面向 FDE 的小型模型 Agentic AI（2025）详解

原标题：Small Models for Agentic AI (2025) Explained for FDEs

FDE Interviews · 2026-10-26 · 约 3 分钟读完

摘要

这篇立场论文认为，Agent 中大量调用只是分类、字段抽取或工具选择等窄任务，未必需要大型通用模型。作者提出为高频重复任务专门化小型模型，复杂环节仍保留大模型，并给出数据收集、任务聚类、模型选型与迭代的转换流程。文章强调这不是基准测试结论：能否省钱取决于质量底线、回退策略与工程成本，错误的回退可能让坏答案永远得不到重试。对 FDE 而言，应按用途和调用量对工作流分组，在真实上下文中评估单个调用环节，而非凭平均基准成绩替换。

要点

  • Agent 中许多调用是窄任务，不需要大模型能力
  • 建议为重复任务专门化小模型，复杂处保留大模型
  • 论文是立场文章，非受控基准，经济性需本地验证
  • 回退策略可能接受错误答案，需评估路由与结果

一分钟读懂这篇论文

Agent 中的许多调用执行的都是狭窄的操作：对请求进行分类、提取字段，或在一小组工具中进行选择。这篇立场论文认为，此类调用往往不需要大型通用语言模型的广泛能力。它提出为重复性工作专门化较小的模型，并在较大模型的额外能力确实有用时保留较大模型。

该论点将运营层面的考量与现有模型研究的实例相结合。它并非一个受控基准，不能证明小模型可以取代每一次 agent 调用。它对“小”的定义是实用性的：即一个能装进常见消费级设备、并以可用延迟服务用户 agent 请求的模型。该定义取决于任务和部署条件。

作者概述了一个转换流程：收集合适的使用数据、加以整理、识别任务聚类、挑选候选模型、进行适配并迭代。有价值的工程问题是：哪一类调用可以在不损害整体工作流的前提下被替换。

经济性论断需要本地证据。先尝试便宜的模型、失败后再用昂贵的模型重试，其成本可能高于直接使用更强的模型。更糟的是，如果回退策略接受了一个错误答案，它可能永远得不到第二次机会。要同时评估路由决策及其交付的结果。

Agent 可能会把重复性的、狭窄的操作发送给通用模型，而这些操作并不需要该模型的广泛能力。

识别重复出现的任务类别，评估专门化的小模型，并在需要更广泛能力时保留较大的模型。

这是一篇立场论文和迁移提案。专门化是否能省钱，取决于质量、回退行为、利用率和工程成本。

为什么这对 FDE 很重要

客户的 agent 账单往往反映的是重复操作，而非单个困难的请求。追踪工作流，并按用途、调用量、输入长度和错误成本对调用进行分组。这可能会揭示出一个高流量的提取步骤，值得用较小的模型进行测试，即使整个 agent 仍然需要一个强大的规划器。

边界很重要。一个看似简单的工具选择步骤可能蕴含着策略知识或模糊的用户意图。仅凭平均基准表现来替换它，可能会把整个工作流引向错误的分支。要在其实际上下文中评估该调用，并检查下游后果。

使用企业级模型选择来确定需求，然后在相同的质量底线之下比较各个备选方案。当操作具有稳定规则时，将确定性代码也纳入候选。模型大小的决策应基于关于任务的证据，而不是变成一种到处套用的架构偏好。
