OpenAI 推出 OpenAI Frontier，帮助企业部署 AI 员工

原标题：OpenAI Launches OpenAI Frontier To Help Companies Deploy AI Employees

OfficeChai · 2026-02-05 · 约 2 分钟读完

摘要

OpenAI 发布企业级平台 OpenAI Frontier，用于构建和管理可执行实际工作的 AI Agent。平台通过统一企业数据形成语义层，让 Agent 共享上下文、权限与评测机制，并配备前沿部署工程师协助企业落地。HP、Uber 等公司已试用。

要点

  • OpenAI Frontier 面向企业，用于构建、部署和管理 AI Agent。
  • 平台整合数据仓库、CRM 等数据源，构建企业语义层供 Agent 共享。
  • Agent 拥有独立身份、权限与护栏，并内置评测与优化能力。
  • OpenAI 派驻前沿部署工程师与企业协作并反馈给研究团队。
  • HP、Intuit、Oracle、Uber 等已是早期用户。

全文

OpenAI 最广为人知的是其面向消费者的 ChatGPT 产品，但它也开始在企业领域有所动作。

该公司宣布推出 OpenAI Frontier，这是一个新平台，旨在帮助企业构建、部署和管理能够在整个组织内执行实际工作的 AI Agent。该平台解决了 OpenAI 所认为的企业 AI 落地中的一个关键缺口：AI 模型理论上能实现的目标与企业实际能部署的能力之间的脱节。

据 OpenAI 称，75% 的企业员工表示，AI 使他们能够完成以前无法完成的任务。然而，该公司认为，孤立零散的 AI 部署正在造成碎片化，而非提升效率。每个新的 AI Agent 都在孤岛中运行，缺乏在复杂业务环境中有效运作所需的更广泛上下文。

Frontier 采取了不同的方法，将 AI Agent 视为同事，它们需要与人类成功所需相同的基础：共享上下文、入职培训、带反馈的实践学习，以及明确的权限和边界。该平台连接分散的数据源——从数据仓库到 CRM 系统再到内部应用——创建了 OpenAI 所称的“企业语义层”，供所有 AI Agent 引用。

该平台赋予 AI Agent 在开放执行环境中对数据进行推理、处理文件、运行代码以及使用各种工具的能力。至关重要的是，它包含内置的评测和优化功能，使 AI Agent 能够从经验中学习并随时间推移提升性能。每个 AI Agent 都以自己的身份、明确的权限和防护机制运行，旨在满足企业的安全和治理要求。

早期采用者包括 HP、Intuit、Oracle、State Farm、Thermo Fisher 和 Uber，而 BBVA、Cisco 和 T-Mobile 等现有客户已经在试点该平台。OpenAI 引用了未具名客户的影响力案例：一家制造商将生产优化工作从六周缩短到一天，而一家全球投资公司让销售人员与客户相处的时间释放出超过 90% 的增幅。

Frontier 基于开放标准构建，旨在与公司已有的系统协同工作，而无需他们更换平台。这使得 AI Agent 能够集成到现有工作流中，并出现在多个界面中——无论是通过 ChatGPT、OpenAI 的 Atlas 工作流工具，还是现有的业务应用。

除了技术之外，OpenAI 还为该平台配备了前沿部署工程师（FDE），他们直接与企业团队合作，制定在生产环境中构建和运行 AI Agent 的最佳实践。这些工程师还建立了通向 OpenAI 研究团队的反馈闭环，帮助公司了解其模型需要如何演进以适应企业用例。

该公司还通过 Frontier Partners 计划向第三方开发者开放平台，与 Abridge、Clay、Ambience、Decagon、Harvey 和 Sierra 等 AI 原生公司合作，构建能够利用 Frontier 共享业务上下文的应用程序。

OpenAI Frontier 的发布正值 AI Agent 成为主流之际。OpenClaw（此前名为 ClawdBot 和 Moltbot）让人们能够部署自己的个人 AI Agent 并让它们完成现实世界的任务，Anthropic 也推出了 Cowork，帮助知识工作者自动化部分工作。此外，正如 METR 基准测试所显示的那样，AI Agent 能够自主工作的时间越来越长。OpenAI Frontier 最终会被企业如何广泛采用仍有待观察，但打造能够补充——甚至可能取代——许多人类员工的“AI 员工”无疑已成为一种趋势。
