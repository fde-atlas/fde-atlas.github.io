Hebbia RAG 与 Agent 系统设计轮背后的概念

这些题目所假设的术语和思维模型。基础内容可免费学习；更深入的、决定面试成败的理念属于高级内容。

基础检索增强生成（RAG）RAG 通过在查询时检索相关段落并将其放入提示词中，使语言模型基于你自己的数据作答，从而让模型依据真实来源而非记忆回答问题。这是几乎所有企业级 FDE 部署的默认模式，因此几乎每个面试流程都会考察它。

基础向量数据库向量数据库将嵌入向量与元数据一起存储，并使用近似索引快速回答最近邻查询。真正的面试问题不是它们如何工作，而是你何时真正需要一个向量数据库，而不是一个库或带 pgvector 的普通 Postgres。

基础AI Agent 与工具使用Agent 是被包裹在循环中的语言模型，这个循环让它可以选择工具、执行操作、观察结果，并决定下一步做什么。面试官考察的技能是判断力：知道这个循环何时值得它的不可预测性，何时固定流水线更便宜、更快、更安全。

Hebbia 的前沿部署工程师面试循环包含诸如“设计一个让持怀疑态度的律师真正信任的 AI 合同审查工作流（条款提取、风险标记、引用）”、“在 10,000 份 PowerPoint 演示文稿上构建多模态 RAG，能够回答图表查询并引用确切的幻灯片”、“文档提取在试点样本上得分 95%，但在生产环境的第一周只有 60%。发生了什么，你首先修复什么？”之类的 rag & agent 系统设计问题。检索流水线、分块、重排序、使用工具的 Agent、防护栏、多租户和评测框架：这是 OpenAI、Anthropic、Sierra、Glean 和 Scale 的典型 FDE 设计轮。完整的题集按从易到难排序并附有专家答案，见下方。

是的。Hebbia 发布了一个前沿部署工程师职位，该职位大部分时间驻扎在战略客户现场，在 Matrix 平台之上构建定制集成和领域特定解决方案。该职位要求在纽约或旧金山办公室办公。

该职位要求具备生产工程能力，并将金融、法律或咨询领域的经验视为加分项。LLM、RAG 系统或应用 AI 的经验被列为加分项而非硬性要求，因此强大的通用工程能力加上面向客户的判断力才是核心。
