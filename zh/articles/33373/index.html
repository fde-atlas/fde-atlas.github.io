OpenAI 的部署公司同意收购 Northslope

原标题：OpenAI’s Deployment Company agrees to buy Northslope

Kernavique · 2026-07-08 · 约 2 分钟读完

摘要

据 The Next Web 2026 年 7 月 8 日报道，OpenAI 旗下的 Deployment Company 同意收购应用 AI 公司 Northslope，据称可为其增加数百名前沿部署工程师。交易尚未完成，需监管批准，金额未披露。这是该公司自 5 月以来的第二次收购（此前为 Tomoro）。Kernavique 指出，该消息仅基于单一报道，且各方对其是否由 OpenAI 控股说法不一：The Pragmatic Engineer 称 OpenAI 并非投资方，而 The Next Web 与 Forrester 则称 OpenAI 持多数股权并控制该公司。

2026年7月8日，The Next Web 报道称 OpenAI Deployment Company 已同意收购应用 AI 公司 Northslope。The Next Web 写道，Northslope 带来数百名前沿部署工程师，这是该媒体的表述，而非公司声明。该交易尚未完成，需获得监管批准，财务条款未披露。

发生时间：。由 Kernavique 于 撰写。来源：The Next Web（报道）。

事件经过

The Next Web 称，这是该公司自5月收购 Tomoro 以来的第二次收购。文章称 Deployment Company 于5月成立，由 OpenAI 多数持股并控制，并援引40亿美元的资金规模。

该文章将消息归因于 OpenAI 向 Axios 的独家披露，未引用任何高管的话。我们无法打开 Axios 的原文，OpenAI 自己的页面也未能打开，因此本条目仅基于单一报道。

各来源对股权关系的说法不一。The Pragmatic Engineer 在2026年5月24日写道，OpenAI “并非” Deployment Company 的“投资者”。而 The Next Web 以及 Forrester 在2026年7月30日均称其由 OpenAI 多数持股并控制。

我们的解读

这意味着什么

以上事实来自来源。以下是 Kernavique 对这些事实的解读。

如果你是前沿部署工程师

该报道没有提及职位、薪酬或交易完成后 Northslope 工程师的去向。它只告诉工程师们：这类公司可能被整体收购，前提是获得监管批准。

如果你在招聘他们

一家模型公司的部署部门正在通过整体收购公司来获得前沿部署工程师，据本报道，自5月以来已有两次。这表明对某些买家而言，收购是一次性招聘一名工程师之外的另一种选择。
