Northern Trust 借助 AI Agent 简化客户入驻流程

原标题：Northern Trust streamlines client onboarding with AI agent

CIO · 2026-11-09 · 约 3 分钟读完

摘要

Northern Trust 与 Microsoft Frontier Company 合作开发 AI Agent，用于机构客户入驻 Front Office Solutions 平台时的数据准备。该 Agent 将多年交易历史转化为标准化格式，数据准备时间从两周半缩短至三天，降幅达 83%，首次通过质量 F1 分数超过 96%。项目全程仅使用匿名数据，以满足金融业严格的数据治理要求。系统基于 Azure 与 Microsoft Foundry 构建，并集成 Excel 和 SharePoint。这是 Microsoft 7 月成立的 25 亿美元 Frontier Company 最早的客户合作之一，双方强调领域知识与 AI 工程能力缺一不可。

要点

  • AI Agent 将机构客户入驻的数据准备时间从两周半缩短到三天，降幅 83%。
  • 首次通过质量 F1 分数超过 96%，输出仍由人工复核不确定部分。
  • 开发全程只用匿名数据，满足金融业数据治理要求。
  • 系统基于 Azure 与 Microsoft Foundry 构建，集成 Excel 和 SharePoint。
  • 这是 Microsoft 25 亿美元 Frontier Company 最早的客户合作之一。

这款新 AI Agent 是与 Microsoft Frontier Company 合作的成果。Frontier Company 是这家软件巨头新成立的部门，旨在帮助客户大规模部署智能体 AI。

总部位于芝加哥的老牌银行机构 Northern Trust 今日发布了一款全新的 AI 驱动客户入驻 Agent，以简化将机构客户接入 Northern Trust Asset Servicing 的 Front Office Solutions 平台的流程。

该 Agent 可将多年的数据和交易历史转换为标准化格式，以便直接用于银行的报告环境，是与 Microsoft 扩大合作的成果。

该 Agent 由 Northern Trust 与 Microsoft Frontier Company 的前沿部署工程（FDE）团队联合开发，将数据准备时间缩短了 83%，从两周半降至仅三天。

Northern Trust 首席运营官 Pete Cherecwich 表示：“为大型机构客户办理入驻可能涉及海量数据，尤其是在另类投资领域。你可能拥有跨越多项投资、长达数年的交易历史和现金流，而且数据可能以各种不同的格式送达我们手中。”

Pete Cherecwich，Northern Trust

Northern Trust

在此之前，Northern Trust 必须手动对这些数据进行映射和转换，然后才能将数据加载到其环境中。

Cherecwich 补充道：“这似乎是一个非常适合用 AI 解决的问题，因为数据中存在大量复杂性和变异性，但同时也存在这项技术可以学习的模式。这个 Agent 完成了大量繁重的工作，然后我们的员工会审查输出结果，并处理存在不确定性的部分。这正是我们的最佳平衡点：让技术做它擅长的事，让我们的员工在关键之处发挥他们的专业能力。”

智能体技能

Cherecwich 指出，该 Agent 从多个来源整合大量投资和交易数据以重建业绩历史，其 F1 首次通过质量得分超过 96%，这是一项用于衡量其生成的映射的正确性和完整性的 AI 评测指标。

该 Agent 还仅使用匿名化数据进行了评测，以确保客户数据在整个过程中得到安全治理。双方表示，这种“无需人工查看”的方式使他们能够在满足受严格监管的金融服务业严苛的数据管理要求的同时，实现生产级性能。

Cherecwich 说：“谈到投资回报率，我不会只看一个数字。它关乎收入实现速度、客户体验，以及将一个非常手动化的流程变得更高效。它让我们的员工可以把更少的时间花在搬运数据上，把更多的时间用于与客户合作。”

从零开始

合作伙伴在 Microsoft Azure 上构建了该 AI Agent。它使用 Microsoft Foundry 提供企业级 AI，并与 Microsoft Excel 和 SharePoint 等 Microsoft 365 工具集成。Azure 提供了一个受治理的智能层，用于保存经过批准的入职知识，以支持入职流程的持续改进。

该 AI Agent 是 Microsoft Frontier Company 最早一批客户合作项目的成果之一。Microsoft 于 7 月推出了这项 25 亿美元的风险投资计划，为客户提供 FDE 的支持，帮助他们克服从 AI 试点迈向大规模部署前沿 AI 的难关。

“我们觉得需要以不同的方式组织自己，才能以客户期望的速度和规模为他们提供服务，”Microsoft 全球金融服务部门企业副总裁 Bill Borden 表示。“我们在思考什么才能让一家公司成为‘前沿’公司、站在最前沿以充分发挥 AI 的能力，并据此组建了 Frontier Company。”

Bill Borden，Microsoft 全球金融服务部门

Microsoft

这一过程的一部分是研究 Microsoft 内部的 AI 转型。这些经验促使 Microsoft Frontier Company 不仅组建了动手实践的工程团队，还汇聚了能源与电力、制造、汽车和政府等领域的行业专家。具备变革管理和流程优化专长的团队成员也是其中的关键组成部分。

“我们现在拥有一个非常强大的组织，能够与客户坐在一起，了解他们的业务流程和挑战，并理解我们如何真正利用这些技术，”Borden 说。

Cherecwich 认同正是这些能力使得 Northern Trust 与 Microsoft Frontier Company 之间的合作结出了硕果。

“我们了解资产服务、我们的客户，也了解资本催缴或估值是什么样的，即使数据以奇怪的格式传入也是如此，”他说。“Microsoft 懂 AI 和底层技术。你确实需要两者兼备。我认为任何一方都无法独自构建出如此优秀的解决方案。而让 Microsoft 的工程师与我们的团队和我们的专业知识深度融合，使我们能够快得多地推进工作。”
