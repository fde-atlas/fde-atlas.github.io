前沿部署工程师 | FirstWork | 远程，美国

原标题：Forward Deployed Engineer | FirstWork | Remote, US

Zero G Talent · 2026-11-12 · 约 4 分钟读完

摘要

FirstWork 招聘一名远程（美国）前沿部署工程师，负责企业客户从需求调研到上线的完整实施。该公司是一家用 AI Agent 自动化招聘、入职与合规流程的应用 AI 公司，客户覆盖人力派遣、物流、医疗和零售行业，已完成 1500 万美元 A 轮融资（Earlybird 领投），累计融资 2000 万美元。岗位要求 2–6 年软件工程或实施经验，精通 Python、SQL、REST API 与 webhook，需搭建与 ATS、VMS、薪酬及 HR 系统的集成，配置 AI 文件核验流程，并为无 API 的系统编写 RPA 自动化脚本，同时直接对接客户并反馈产品团队。

要点

  • FirstWork 招聘远程前沿部署工程师，面向美国地区。
  • 公司用 AI Agent 自动化招聘、入职与合规流程。
  • 已完成 1500 万美元 A 轮，累计融资 2000 万美元。
  • 要求 2–6 年经验，精通 Python、SQL 与 API 集成。
  • 职责含系统集成、AI 文件核验、RPA 与客户沟通。

关于 FirstWork

FirstWork 是一家应用 AI 公司，致力于打造新一代劳动力运营技术。

我们服务于管理大规模一线员工队伍的员工派遣、物流、医疗和零售行业企业。这些企业需要处理涉及招聘、入职、文档验证、合规、培训以及持续劳动力管理的复杂且高度依赖人工的流程。

我们正在利用 AI Agent 来自动化这些工作流程，与人类团队协同工作，并与企业现有系统进行集成。

我们已完成由 Earlybird Venture Capital 领投的 A 轮融资，融资 1500 万美元，总融资额达到 2000 万美元，正迈入激动人心的增长阶段。凭借成熟的企业客户和不断扩展的产品版图，我们正在超越招聘和入职领域，打造一个全面的 AI 驱动劳动力运营平台。

关于该职位

我们正在寻找一位前沿部署工程师（FDE），在产品工程、客户实施和应用 AI 的交汇点上开展工作。

在这个职位上，你将直接与企业客户合作，深入了解他们的招聘、入职和合规工作流程，并使用 FirstWork 将这些需求转化为可运行的解决方案。

你将端到端地负责客户实施项目，从需求调研和方案设计，到系统集成、自动化、部署以及持续支持。你将构建与外部系统的集成、配置 AI 驱动的文档验证工作流程、开发自动化方案，并与我们的产品和工程团队紧密合作，解决客户特有的挑战。

这是一个注重动手实践的工程职位，你将编写代码、解决真实世界的技术问题、直接与客户互动，并在实际企业环境中看到自己工作带来的影响。

这个机会为何令人兴奋？

  • 在 AI 与工程的交汇点工作： 使用 AI Agent、自动化、API 和集成构建实用的解决方案。
  • 端到端负责实施项目： 承担将复杂的客户需求转化为可运行产品体验的责任。
  • 解决真实世界的技术挑战： 与多样化的企业系统、复杂的工作流程以及合规要求打交道。
  • 直接与客户合作： 与从招聘人员和合规团队到高管层的各类利益相关者协作。
  • 塑造产品： 将客户经验反馈给工程团队，帮助把反复出现的实施挑战转化为可复用的平台能力。

工作职责

  • 负责企业客户实施项目，从需求调研到上线，将业务流程转化为 FirstWork 中可运行的招聘和入职工作流程。
  • 使用 REST API、webhook 和基于文件的数据同步，构建并维护与 ATS、VMS、薪资和 HR 系统的集成。
  • 设计和配置 AI 驱动的文档验证流水线，用于身份证件、执照、认证以及各国特定的合规要求。
  • 为缺乏 API 的系统构建 RPA 自动化，包括工时录入和凭证上传等工作流程。
  • 编写用于数据映射、迁移、调试和报告的脚本。
  • 调查生产环境问题，找出根本原因，并与产品和工程团队协作实施修复。
  • 主持客户会议、产品演示和实施进度更新，与技术和非技术利益相关者进行有效沟通。
  • 与客户密切合作，了解他们的运营挑战，并推荐切实可行的技术解决方案。
  • 与产品团队分享客户反馈和实施经验，帮助构建可复用的功能并改进平台。

我们期待的人才

  • 2–6 年软件工程、解决方案工程、实施或技术咨询经验。
  • 扎实的 Python 和 SQL 技能，能够阅读、理解并调试现有代码。
  • 具备 REST API、JSON、webhook 和第三方系统集成的实际操作经验。
  • 能够理解复杂或定义模糊的业务流程，并将其转化为清晰的技术解决方案。
  • 出色的问题解决和调试能力。
  • 优秀的英语书面和口头表达能力，能够向非技术利益相关者解释技术概念。
  • 具备强烈的责任意识，能够推动实施项目直至成功上线。
  • 能够适应跨时区与美国和欧洲客户协作。

加分项

  • 具有 HR 科技、人力派遣、ATS 或 HRIS 平台（如 Workday、SAP SuccessFactors 或 Salesforce）的经验。
  • 接触过劳动力合规工作流程，包括 I-9、W-4、工作许可检查、背景调查或资质认证。
  • 具有 RPA 工具、n8n 或工作流程自动化平台的使用经验。
  • 具有使用 LLM 进行文档提取、验证或 AI 驱动自动化的经验。
  • 有初创公司或面向客户的技术岗位工作经验。

为什么加入 FirstWork？

  • 构建真实世界的 AI 解决方案： 参与开发能够自动化复杂企业工作流程的实用 AI 应用。
  • 将工程与客户价值相结合： 亲眼见证你构建的系统如何直接改善业务运营。
  • 承担主导责任： 从最初的调研到生产部署，全程推动项目落地。
  • 跨技术与产品领域工作： 与工程、产品团队及企业客户紧密协作。
  • 与 FirstWork 共同成长： 加入一家快速发展的应用 AI 公司，参与塑造企业级 AI 解决方案的构建与部署方式。

FirstWork 是一家机会均等的雇主。我们在评估应聘者时，不因种族、肤色、宗教、性别、国籍、年龄、残障或任何其他受保护身份而有所区别。
