前沿部署工程师，Agentic 平台（欧洲……）| Cohere

原标题：Forward Deployed Engineer, Agentic Platform (Europ… | Cohere

Zero G Talent · 2026-05-12 · 约 5 分钟读完

摘要

Cohere 正在为欧洲招聘 Agentic Platform 方向的 FDE。该职位围绕其企业 AI 工作台产品 North，要求候选人将模糊的企业业务需求转化为基于 LLM 的 Agent 工作流，从原型推进到生产级系统，覆盖金融、医疗、电信等敏感行业。岗位强调 Python、RAG、ReAct 等多步执行模式、评测框架的实战经验，需直接对接客户并承担端到端交付，出差比例约 20%–40%。文中还列出薪酬福利、办公地点及防诈骗提示。

要点

  • Cohere 招聘欧洲区 Agentic Platform FDE，围绕 North 平台工作。
  • 核心职责：把企业模糊需求转化为可评测的 LLM Agent 工作流。
  • 要求 Python、RAG、多步 Agent 模式及评测框架的实战经验。
  • 需端到端负责用例，出差比例 20%–40%，面向金融等敏感行业。
  • 文末附福利待遇、办公地点与招聘防诈骗说明。

任职要求

我们是谁？

Cohere 是领先的安全优先企业级 AI 公司。我们构建尖端的基础 AI 模型和端到端产品，旨在解决现实世界的业务问题。

我们正在为构建 AI 系统的企业训练和部署前沿模型。我们相信，我们的工作对 AI 的广泛采用至关重要，我们正在寻找希望参与其中的伙伴。

我们对自己构建的产品精益求精。我们每个人都负责为提升模型能力以及模型为客户创造的价值做出贡献。Cohere 是一个由研究人员、工程师、设计师等组成的团队，所有人都对自己的专业充满热情。

我们是一家总部位于多伦多的全球科技公司，在伦敦、纽约、旧金山、蒙特利尔、巴黎、柏林和首尔设有重要办公室。加入我们吧！

关于 North：

North 是 Cohere 的尖端 AI 工作区平台，旨在彻底改变企业使用 AI 的方式。它提供一个安全且可定制的环境，让企业在部署 AI 的同时保持对敏感数据的控制。North 与现有工作流程无缝集成，提供一个可信赖的平台，将 AI Agent 与工作场所的工具和应用程序连接起来。

为什么选择这个职位？

这个职位提供了一个独特的机会，让您能够塑造企业在实际应用中驾驭 AI 能力的方式。作为 North 核心产品与客户工程团队之间的桥梁，您将站在解决复杂问题的最前沿，并将 AI 安全地集成到金融、医疗和电信等关键领域。

我们正在寻找具有应用 AI 经验的软件工程师，能够负责基于大语言模型（LLM）的 Agentic 工作流的设计、构建和部署，从早期原型到生产级 AI Agent，在企业工作流程中交付切实的业务价值。

您将与客户紧密合作，解决现实世界的业务问题，通常需要构建首创性的 Agent 工作流，将 LLM 与工具、API 和数据源集成。虽然我们的节奏如初创公司般快速，但标准却达到企业级水准：Agent 从第一天起就必须可靠、可观测、安全且可审计。

在这个职位上，您将：

  • 与我们的企业客户紧密合作，将高价值、模糊的业务问题转化为框架清晰的 Agentic 工作流，并制定明确的成功标准和评估方法
  • 主导基于 LLM 的 Agent 的设计、构建和交付，这些 Agent 能够跨工具、API 和敏感企业数据源进行推理、规划和执行，并具备企业级的可靠性和性能
  • 为我们的 AI 工作区平台 North 构建并交付功能，涵盖从概念化到生产的完整产品生命周期
  • 端到端地负责用例的范围界定与设计，根据问题需要灵活深入任何技术领域（包括前端），以推动最有效的解决方案
  • 参与构建共享框架与模式，助力在客户和团队之间实现一致、高质量的交付
  • 在模糊不清的情况下理清思路、达成共识，并提升整个组织的工程质量
  • 出差比例最高可达 20–40%，与客户和合作伙伴现场协作

如果你符合以下条件，你可能是合适的人选：

  • 你有使用 Python 构建和部署生产级软件的实战经验；你编写整洁、可测试、可观测、可扩展的代码
  • 你构建并部署过高性能的 RAG 和 AI Agent 应用，包括使用 ReAct 或 Plan-and-Execute 等模式来规划和执行多步任务的 Agent
  • 你对 LLM 技术栈非常熟悉：前沿模型、向量数据库和编排框架
  • 你有能力构建稳健的评测框架，远超反复试错的方式，以衡量 Agent 的准确性、安全性和延迟
  • 你有直接与客户合作的丰富经验，能够与企业级利益相关者主导技术讨论，将模糊的业务需求转化为具体的技术规格
  • 你有端到端负责完整用例的经验
  • 你能在快节奏、充满不确定性的环境中蓬勃发展，即使优先级不断变化也能高效执行

如果你还具备以下条件，将是加分项：

  • 有为分布式团队的 AI 和 Agent 系统制定架构标准的经验
  • 有在问题需要时灵活进入陌生技术领域（如前端）的经验
  • 接触过受监管或敏感的行业环境（金融、医疗、电信）
  • 有处理 AI 系统的企业级安全、合规或可审计性要求的经验

Cohere 的全职员工可享受以下福利：

  • 每周 75 美元/75 英镑或等值当地货币的午餐补贴。
  • 全面的医疗和牙科保险，包括单独的心理健康预算。
  • RRSP 匹配、401K、养老金计划。
  • 长达 6 个月的育儿假 100% 薪资补足，父母双方均可享受。
  • 年度丰富福利：艺术与文化、健身/健康、亲子时光，以及工作环境改善补贴。用于会议、课程和辅导的教育学习津贴。
  • 6 周带薪休假（30 个工作日！）
  • 远程办公者可享有前往其他办公室的差旅预算，外加每年一次的公司团建。

我们的工作方式与地点：

  • Cohere 支持远程办公，但我们在多伦多、伦敦、纽约、旧金山、蒙特利尔、巴黎、柏林和首尔设有办公室，更多办公室即将开放。
  • 对于在办公室工作的员工：提供每日午餐计划、丰富的零食，以及定期的社区和社交活动。
  • 对于不在办公室附近的同事：我们提供联合办公福利，让你可以在所在城市与他人一起工作。
  • 每位员工均可获得 500 美元的家庭办公补贴，用于妥善布置你的工作空间。

如果以上要求与你的经验不完全吻合，我们仍然鼓励你申请。

我们致力于为所有人营造包容的工作环境；欢迎来自各种背景的申请者，并致力于提供平等的机会。如果你在招聘过程中需要任何便利安排，请提交便利安排申请表，我们将与你共同努力满足你的需求。

我们可能会使用 AI 工具根据该职位的标准对申请者进行筛选和评估。这有助于我们的招聘人员识别潜在符合条件的候选人，但不会限制招聘人员可以审阅或考虑的申请范围。

谨防诈骗：Cohere 在招聘过程中绝不会要求付款或使用第三方服务（例如简历撰写）。所有正式职位仅在 Cohere 招聘页面和 LinkedIn 上发布，Cohere 员工的所有沟通均来自 @cohere.com 或 @cw.cohere 邮箱。如果你在其他网站上看到相关职位，请通过我们的官方招聘页面进行核实。
