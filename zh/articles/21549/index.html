摘要

这是日本咨询公司Alphakt在OpenWork发布的招聘页面，岗位为Forward Deployed Engineer（FDE）／AI×BPR实施工程师。该公司以AI与业务流程改革（BPR）为核心，服务制造、通信、能源、金融等大型企业，目标是2030年达到300亿日元营收、1000人规模并上市。岗位要求从需求定义到实现全程负责生成AI、LLM、RAG、AI Agent等系统的开发，不要求AI实务经验，但需3年以上Web或业务系统开发经验，会Python或TypeScript，有云平台经验。年薪600万至1000万日元，含45小时固定加班费，绩效联动奖金，最快一年可晋升。工作地点为东京涩谷、赤坂、大阪或客户现场，可混合远程办公，年休日120天以上。

要点

  • Alphakt是主打AI×BPR的咨询公司，目标2030年营收300亿日元。
  • 岗位负责生成AI、RAG、AI Agent系统的需求定义到实现。
  • 不要求AI经验，需3年以上开发经验及Python或TypeScript能力。
  • 年薪600万至1000万日元，绩效最快一年晋升。
  • 工作地含涩谷、赤坂、大阪及客户现场，支持混合远程。

全文

  • 关于 Alphakt
  • Alphakt（阿尔法克特）是一家以 AI×BPR 为核心优势的新一代咨询企业，致力于通过 AI×BPR 支持业务变革。我们陪伴支撑日本核心产业的大型企业——涵盖制造、通信、能源、金融等领域——共同推进变革，提供从战略制定到落地实施的一站式支持。 ◼︎业务领域 以 AI×BPR（业务流程改革）为起点，业务范围广泛覆盖从上游的战略制定到中游的业务与基础架构变革，包括 AI Agent 开发、数据平台建设（DWH・ETL・BI）、云基础设施设计支持等。此外，我们还通过 AI 人才培养培训、网络安全培训等提供人才培养支持，并提供自主研发的 AI 产品。 ◼︎Alphakt 期望的人才形象 我们希望培养和造就的是“AI Agent 应用型顾问”。这是超越传统顾问、销售、工程师等职位框架，横向兼备咨询问题解决能力、客户管理能力、AI 应用能力和解决方案设计能力的“价值创造型人才”。其特点在于不仅仅是顾问，而是亲自熟练运用 AI，彻底致力于客户的成果。 ◼︎业务展望 我们以 2030 年实现销售额 300 亿日元、组织规模 1,000 人为目标，并将 IPO 定位为加速增长的杠杆。我们将在咨询中积累的见解转化为自有产品和新业务，未来着眼于进化为以“数字制造业”身份孵化多个全球业务的企业集团。
  • MISSION・VISION・VALUE
  • ■MISSION 实现最尖端技术，为世界经济的进化做出贡献 Alphakt 将始终保持为无论在何种环境下都能持续增长、持续执行投资的组织。我们将技术从战略到需求定义、设计开发、运营全流程落地为“被实际使用的机制”，通过连接决策与一线的实施，解决客户的经营课题，创造切实的成果。 我们始终以客户为出发点思考，彻底坚持到底直至成功。支撑这一执行的根基，是自我变革、利他即利己、行动量这三大价值观。 通过践行这三大价值观，客户的成功将催生公司自身的持续增长，并连锁带动每一位伙伴实现自己的职业发展。 我们将通过这种良性循环，创造更美好的未来。 ■VISION 成为作为“数字制造业”持续孵化为世界经济进化做出贡献的业务群的组织 我们以制造业为中心，在通信、能源、金融、运输等核心产业中，以 AI 应用和 PM 支持为起点推进变革。 我们更进一步的目标，是进化为作为“数字制造业”自主开展多个全球业务的企业集团。 作为持续创造世界通用的产品和业务模式的组织， 我们将在全球市场确立自己的存在感。 我们将借助技术的力量支持产业结构变革，通过持续的价值创造为世界的发展做出贡献。 ■VALUE 我们以目标 8 倍法则推进事业。 我们对所有人保持体谅之心。 我们以利他即利己的方式行动。 我们以即时回复、即时执行的方式行动。 我们致力于打造被实际使用的机制。 我们以倒推方式思考目标达成计划并付诸行动。
  • Alphakt 的自有产品／服务
  • 将在客户支持中发现的通用性课题产品化，同时也作为员工自身的武器加以运用。Alphakt 在咨询一线与客户交流的过程中，将发现的通用性课题开发为自有产品和服务。这些产品不仅面向客户提供，也是员工在日常业务中实际使用的实践性工具。 ◼︎Skillba 这是一个以项目为单位，将企业数字领域的课题与拥有高度专业技能的人才进行匹配的平台。Alphakt 构建了独有的专业人才网络，根据企业的经营课题实现最优的人员配置。我们还提供 AI 人才培养培训、网络安全培训、基础设施人才培养培训、评估等人才培养服务。 ◼︎PERKS AI 这是一套在所有业务流程中运用 AI，实现自动化和效率化的系统。从调研、资料制作、报告等咨询业务，到商谈管理、会议纪要自动生成、各类工具联动，具备多种多样的功能。在公司内部，顾问通过使用 PERKS AI，实现了能够同时推进多个高难度项目的环境。 今后我们将持续投资，把通过解决客户课题获得的见解，开发并拓展为产品和服务。
  • 职业发展与考核制度
  • 奖励成果的考核制度与加速成长的环境◼︎考核制度 每半年一次，从“VALUE 践行度”“行动・技能发挥度”“成果”三个维度进行考核。由于设计上在职业初期更侧重思维方式与行动特征，而在较高职级则更侧重成果，因此你始终能明确自己当前应当提升什么。此外还建立了面向全职种、与业绩挂钩的激励制度，成果将直接反映在薪酬中。 ◼︎快速晋升 在通常在一个职级停留 2～3 年的情况较多的大环境下，Alphakt 根据绩效表现，最短 1 年即可晋升。晋升时基本工资会上调至上一职级薪酬区间的下限，因此晋升越早，加薪幅度也越大，是“早晋升、大幅涨薪”的设计。 ◼︎教育・培养 以 OJT 为核心，与领导和经理一同参与项目，在实践中掌握实务。除业务技能的学习外，还设置了直接接受经营层和上级就基于 VALUE 的工作方式与思考方式进行反馈的机会，通过“授权 → 反馈 → 责任”的循环来提升成长速度。 ◼︎工作环境・假期 潜心工作、充分休息的文化已深入人心。每年休息日 120 天以上，完全周休二日制（周六周日）、年末年初假期、带薪年假、特别休假制度一应俱全。是可以按自己的节奏有计划地放松身心的体制。
  • 福利待遇
  • 从助力技能提升的学习支持制度，到支撑日常舒适工作的环境建设，建立了可以安心挑战的体制◼︎成长支持 ・高管教练制度 ・课程・讲座听课支持制度 ・共享读书制度 ◼︎工作环境 ・PC 出借 ・心理咨询制度 ・远程办公制度 ・远程办公环境建设支持 ◼︎沟通・其他 ・活动支持制度 ・各部门聚餐补贴 ・饮品畅饮＆午餐抽奖 ・薪酬／报酬统一制度
  • 职位名称
  • 前沿部署工程师（FDE）／AI×BPR 落地工程师
  • 职位描述
  • 【欢迎以下背景的候选人】 ・以 Web 应用或业务系统开发经验为基础，希望在客户现场承担从问题梳理到实现落地的工程师 ・不要求有生成式 AI 的实务经验，但希望将融入 AI 的系统推进到现场实际可用的状态 ・希望从决定“做什么”的阶段就开始参与 ・希望在核心产业项目中积累 AI 落地实绩 ・除面向客户的开发外，对工时管理、人才管理、1on1、日报等内部基础系统开发也感兴趣的人 【角色与职责】 独立完成代码实现，并推动在现场的落地与运维改进 自主推进所负责功能或模块的设计，留下可维护性高的代码和设计文档。熟练运用标准技术栈（语言、框架、数据库、云平台），在理解现有系统结构的基础上提出合理的扩展与改造方案。从设计到可上线运行的代码实现均由自己完成。 期望的角色与未来职业发展 对于积累了一定经验者，我们期待其角色扩展到子系统架构设计、基于性能・可用性・安全性等非功能需求的技术选型，以及作为评审人保障团队整体质量。 【主要工作内容】 ◆ 基于生成式 AI・大语言模型的业务系统、AI Agent、知识检索功能的设计与实现 ◆ 检索增强生成（RAG）平台的设计与搭建、精度评估与改进 ◆ 对客户现场业务和用户问题的调研、需求梳理、技术实现方案的探讨 ◆ 在云环境（AWS／Azure／Google Cloud）下进行 API 设计、应用开发与运维改进 ◆ 在尚无既有机制的领域从零启动新项目（从业务数据的获取方式，到评估的自动化测量、版本管理的设计） ◆ 自有产品「GISHO（技承）」「PERKS」的功能开发与改进 ◆ 支撑工时管理、人才管理、1on1、日报等内部运营体系的系统开发与自动化 ◆ 与顾问・商务岗位协作进行规格调整、发布后的改进与质量提升 【关于 AI】 ※ 不要求具备生成式 AI 或 AI・机器学习本身的实务经验。我们看重的是以工程师的开发能力为基础，将生成式 AI 实际融入业务并使其持续被使用的能力。我们以入职后由您担任使用生成式 AI 项目的主负责人为前提，所需知识可通过公司内部的 AI 基础设施与实际工作中掌握。 【这份工作能获得的经验与成长】 ◆ 将生成式 AI・检索增强生成（RAG）・AI Agent 实际融入业务系统，并负责到运维改进的经验 ◆ 在核心产业项目中积累 AI 工程师实绩的经验 ◆ 在尚无既有机制的领域从零开始设计的经验 ◆ 与客户及内部用户直接对话，梳理问题并落实到产品与机制中的经验 ◆ 将内部验证过的机制推广到面向客户的功能或自有产品的开发经验 ◆ 不仅掌握 AI 或特定技术的使用方法，还承担问题发现・需求设计・质量判断的工程经验
  • 期望的经验与技能
  • 【必备条件】具备以下任一经验者※参考标准：3 年以上实务经验 ・Web 应用、业务系统、API 任一方面的开发实务经验 ・使用 Python 或 TypeScript 的开发经验（有其他语言的 Web 应用・业务系统开发经验、并有意愿在入职后学习者亦可） ・参与过从基本设计・详细设计・实现・测试到运维改进等完整开发流程的经验 ・在云环境（AWS／Azure／Google Cloud 任一）下的开发或运维经验 ・使用 Git 进行团队开发的经验 【加分条件】 ・使用生成式 AI・大语言模型 API 的开发经验 ・检索增强生成（RAG）、AI Agent、提示词设计、评估设计的经验 ・数据库设计、数据处理、业务数据应用的经验 ・需求定义、客户沟通、用户调研、业务改善提案的经验 ・项目负责人、Scrum Master、质量管理、培养后辈的经验 ・内部工具、管理系统、业务自动化的规划与开发经验 ・与客户、内部用户或商务岗位沟通并梳理需求与规格的经验，或今后希望承担此类职责的意愿
