前沿部署工程师 | Anthropic | 法国巴黎

原标题：Forward Deployed Engineer | Anthropic | Paris, France

Zero G Talent · 2026-08-17 · 约 7 分钟读完

摘要

Anthropic 在巴黎招聘前沿部署工程师（FDE），属于 Applied AI 团队。该职位需直接驻扎在战略客户现场，用 Claude 模型构建生产级应用，交付 MCP 服务器、子 Agent 等技术产物，并支持企业环境部署。要求 8 年以上面向客户的技术经验、LLM 生产实践经验及 Python 能力，需母语法语并流利英语，出差比例 25% 至 50%。FDE 还需总结可复用的部署模式反馈给产品与工程团队，并在客户现场代表 Anthropic 的使命。

要点

  • Anthropic 巴黎招聘创始批次前沿部署工程师，隶属 Applied AI 团队。
  • 核心工作是在客户系统内用 Claude 构建生产应用并交付 MCP 服务器、子 Agent 等产物。
  • 要求 8 年以上客户导向技术经验，具备 LLM 生产与 Python 开发能力。
  • 必须母语法语、英语流利，出差占 25% 至 50%。
  • FDE 需沉淀可复用部署模式并反馈产品与工程团队。

你需要具备的条件

关于 Anthropic

Anthropic 的使命是创造可靠、可解释、可引导的 AI 系统。我们希望 AI 对用户乃至整个社会都是安全且有益的。我们的团队是一支快速成长的队伍，由充满热忱的研究人员、工程师、政策专家和业务领导者组成，共同构建有益的 AI 系统。

通过与我们的售后、产品和工程团队紧密协作，你将结合工程专业知识、对前沿 AI 应用的理解以及面向客户的沟通能力，深入理解客户的工作流程，并开发出既能应对复杂商业挑战、又符合我们高安全性和可靠性标准的创新解决方案。

你将站在企业级 AI 部署的最前沿，成为塑造我们前沿部署事业的创始 FDE 之一。我们期望 FDE 能够独立自主地工作，在模糊环境中游刃有余，并在客户环境中以最高水准代表 Anthropic。这是一项重要的责任：你将在企业内部为我们的使命发挥关键的倡导作用。

职责

  • 深入客户系统内部，使用 Claude 模型开发生产级应用，确保这些产品满足客户的需求。
  • 为客户提供技术产物，例如 MCP 服务器、子 Agent 和 Agent 技能，这些产物将被用于生产工作流程中。
  • 为 Anthropic 产品在企业环境中的部署提供支持。
  • 识别并整理可复用的部署模式，并向我们的产品和工程团队提供洞察。
  • 持续深入了解 LLM 能力、实施模式以及 AI 产品开发技术栈的最新进展。
  • 与客户建立长期关系，并在合作的整个生命周期中主动识别新的 AI 部署机会。
  • 频繁出差（25% 至 50%）前往客户现场，与客户建立个人层面的关系。
  • 在一线成为 Anthropic 使命的倡导者。

理想候选人画像：

  • 你在面向客户的技术岗位上拥有 8 年以上经验，例如担任过前沿部署工程师，或具备咨询经验软件工程师。技术联合创始人背景的候选人也非常欢迎投递简历。
  • 您拥有 LLM 生产环境经验，包括高级提示词工程、Agent 开发、评测框架以及大规模部署。
  • 您具备扎实的编程能力，精通 Python（最好还掌握 TypeScript、Java 等一种或多种其他语言），并有交付生产级应用的经验。

• 具备高度的协作精神，能够进行跨组织合作，在诚信的前提下平衡相互竞争的优先事项。

• 热衷于通过创造性的技术应用推动安全且有益的 AI 系统的发展。

• 具备出色的沟通能力，能够与客户开展探索性讨论，并向各类利益相关者传达技术概念，同时保持谦逊协作的态度。

• 拥有金融服务、医疗健康/生命科学或其他行业领域的经验者优先。

• 拥有企业 IT 系统和/或 AI 部署模式方面的经验者优先。

作为 Anthropic 应用 AI 团队的一员，您将担任前沿部署工程师（FDE），直接深入我们最具战略意义的客户，推动变革性的 AI 落地。您将与客户团队紧密合作，交付解决现实业务问题的高级 AI 应用。我们的前沿部署工程师与客户协作，加速现有产品的采用，并基于我们的模型构建新的应用。

您将与我们的售后、产品和工程团队紧密合作，结合工程专长、对前沿 AI 应用的理解以及面向客户的技能，深入了解客户的工作流程，开发应对复杂业务挑战的创新解决方案，同时保持我们在安全性和可靠性方面的高标准。

您将站在企业 AI 部署的最前沿，作为我们的创始前沿部署工程师之一，帮助塑造我们的前沿部署工程模式。我们期望前沿部署工程师能够自主运作，在不确定环境中茁壮成长，并在客户环境中以最高水准代表 Anthropic。这是一项重大责任：您将在企业领域捍卫我们的使命中发挥关键作用。

职责

  • 在客户系统内使用 Claude 模型构建生产级应用，确保这些产品满足客户需求。
  • 为客户交付 MCP 服务器、子 Agent 和 Agent 技能等技术产物，用于生产工作流程。
  • 为 Anthropic 产品在企业环境中的部署提供全方位贴心支持。
  • 识别并沉淀可复用的部署模式，并将洞察反馈给我们的产品和工程团队。
  • 持续深入了解 LLM 能力、实现模式以及 AI 产品开发技术栈的最新进展。
  • 与客户建立长期关系，并在合作的整个生命周期中主动识别 AI 部署的新机会。
  • 频繁出差（25%-50%）前往客户现场，与客户面对面协作开发。
  • 在一线成为 Anthropic 使命的倡导者。

如果你具备以下条件，你可能非常适合这个职位

  • 拥有 8 年以上技术类、面向客户岗位的经验，例如前沿部署工程师，或具备咨询经验的软件工程师。也欢迎曾担任技术创始人的候选人申请。
  • 法语为母语，且英语流利
  • 拥有 LLM 生产环境实践经验，包括高级提示词工程、AI Agent 开发、评测框架以及大规模部署。
  • 具备扎实的编程能力，精通 Python（最好还掌握 TypeScript、Java 等一种或多种其他语言），并有上线生产应用的经验
  • 具有高度的主观能动性，能够应对复杂组织中的不确定性。
  • 具备高度的合作心态，善于跨组织协作，在相互冲突的优先事项之间以诚信为原则进行权衡。
  • 热衷于通过创造性的技术应用推动安全、有益的 AI 系统的发展。
  • 具备出色的沟通能力，能够进行客户需求挖掘，并向不同背景的利益相关者传达技术概念，同时保持谦逊和协作的态度。
  • 拥有金融服务、医疗健康/生命科学或其他企业级垂直行业的背景者优先。
  • 拥有企业 IT 系统和/或 AI 部署模式方面的经验者优先。

其他事项

最低学历要求：学士学位，或同等的教育、培训和/或工作经验组合

要求的专业领域：通过课程学习、培训或专业经验证明与该职位相关的领域

最低工作年限要求：所需工作年限将与该职位的内部职级要求相对应

基于办公地点的混合办公政策：目前，我们期望所有员工至少有 25% 的时间在我们的办公室工作。不过，某些职位可能需要更多在办公室的时间。

签证担保：我们确实提供签证担保！但是，我们无法为每个职位和每位候选人都成功办理签证担保。不过，如果我们向你发出录用通知，我们将尽一切合理努力为你办理签证，并且我们聘请了移民律师来协助此事。

即使您认为自己不完全符合所有任职条件，我们也鼓励您申请。 并非所有优秀的候选人都符合所列出的每一项条件。研究表明，来自弱势群体的人更容易产生“冒名顶替综合征”，怀疑自己的竞争力，因此我们恳请您不要过早地否定自己，如果您对这份工作感兴趣，请提交申请。我们认为，像我们正在构建的这类 AI 系统具有巨大的社会和伦理影响。我们认为这使得多元代表性更加重要，我们致力于在团队中纳入多样化的视角。您的安全对我们至关重要。 为保护您免受潜在诈骗，请记住 Anthropic 的招聘人员只会通过 @anthropic.com 邮箱与您联系。在某些情况下，我们可能会与经过审核的招聘机构合作，他们会表明自己是代表 Anthropic 工作的。请警惕来自其他域名的邮件。正规的 Anthropic 招聘人员绝不会在您入职第一天之前索要金钱、费用或银行信息。如果您对某条通讯存疑，请不要点击任何链接——请直接访问 anthropic.com/careers 查看确认的职位空缺。

我们的不同之处

我们认为，最具影响力的 AI 研究将是“大科学”。在 Anthropic，我们作为一个紧密协作的团队，只专注于少数几个大规模研究项目。我们重视影响力——推进实现可控、可信赖 AI 的长期目标——而不是研究更小、更具体的问题。我们将 AI 研究视为一门实证科学，它与物理学和生物学的共同之处不亚于与计算机科学传统研究的共同之处。我们是一个高度协作的团队，经常举办研究讨论，以确保我们在任何时刻都在从事最具影响力的工作。因此，我们非常重视沟通能力。

了解我们研究方向的最简单方法是阅读我们近期的研究成果。这些研究延续了我们团队在 Anthropic 成立之前所从事的许多方向，包括：GPT-3、基于电路的可解释性、多模态神经元、缩放定律、AI 与算力、AI 安全的具体问题，以及从人类偏好中学习。
