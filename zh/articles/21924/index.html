摘要

开源可观测性平台 SigNoz 招聘远程前沿部署工程师（印度时区）。该职位需直接与客户工程团队合作，设计 OpenTelemetry 埋点方案、定制仪表盘、编写技术文档并参与客户代码库的实际开发。SigNoz 是 DataDog 的开源自托管替代方案，获 YC 支持，上线不到一年已获 22000+ GitHub 星标，用户遍布 30 多个国家。候选人需有 2-6 年 DevOps、SRE 或解决方案工程经验，熟悉 Kubernetes、云平台及多语言编程。

要点

  • SigNoz 招聘远程前沿部署工程师，限印度时区。
  • 职责包括设计 OpenTelemetry 埋点策略与定制仪表盘。
  • 要求 2-6 年 DevOps、SRE 或解决方案工程经验。
  • 需直接参与客户代码库并编写技术文档。
  • SigNoz 为开源可观测性平台，获 YC 支持。

任职要求

关于该职位 SigNoz 是一个全球开源项目，用户遍布 30 多个国家。我们正在构建一个开源可观测性平台，帮助开发者监控应用并快速排查问题。上线不到一年，我们已获得 22000+ Github stars，Slack 社区拥有 6000+ 成员，以及 150+ 贡献者。为什么选择我们？

  • 有机会参与全球开发者基础设施产品的工作
  • 获得 YC 以及湾区多家知名风投机构的支持
  • 我们完全远程办公，没有办公室
  • 直接与高增长公司的工程团队合作

我们正在寻找这样的人：

  • 具备足够的技术能力来架构可观测性解决方案 - 你将直接与工程团队合作，设计他们的 OpenTelemetry 埋点策略，定制仪表盘，并针对其特定用例进行优化。
  • 擅长技术文档写作 - 你将编写定制集成指南、故障排查文档以及工程团队真正愿意遵循的最佳实践文档。
  • 能够动手实施 - 你将直接参与客户代码库的贡献，帮助调试埋点问题，确保部署成功，而不仅仅是提供指导。
  • 具备产品思维 - 你将从客户部署中发现共性模式，并与我们的产品团队合作构建更好的默认配置、模板和工具。

什么样的人适合这个职位

  • 2-6 年技术岗位经验 - DevOps、SRE、平台工程或解决方案工程背景
  • DevOps/平台工程背景 - 容器化、Kubernetes、基础设施即代码、云平台（AWS/GCP/Azure）
  • 扎实的编程能力 - 能够熟练使用多种语言（Go、Python、Node.js、Java）为客户代码库做贡献
  • 出色的技术写作能力 - 能够编写工程师真正会使用的清晰、可操作的文档
  • 系统思维 - 能够理解复杂的分布式架构，并设计可扩展的监控策略
  • 较强的学习能力 - 能够快速理解新的客户环境并相应调整解决方案

什么样的人可能不适合

  • 喜欢独立工作而不愿直接与客户打交道的人
  • 在技术写作或文档编写方面有困难的人
  • 回避动手编码或技术实施工作的候选人
  • 倾向于遵循既有流程而非创造新解决方案的人
