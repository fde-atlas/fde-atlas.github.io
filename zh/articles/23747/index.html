前沿部署工程师 | Cozmo AI | 纽约州纽约市

原标题：Forward Deployed Engineer | Cozmo AI | New York, NY

Zero G Talent · 2026-08-08 · 约 3 分钟读完

摘要

Cozmo AI 在纽约招聘前沿部署工程师，为公司面向财产理赔行业的 AI Agent 平台工作。候选人需深入客户理赔运营现场，构建生产级 Agent 系统，对接 Xactimate 等遗留软件，并在上线与飓风季高峰期间现场交付。职位要求扎实的计算机基础与 LLM 工程经验，接受 0 至 4 年经验的新毕业生。公司明确要求每周近六天到岗工作，薪酬为竞争性薪资加创始人级别股权。申请需提交技术作品、一段视频问答和最早到岗日期。

要点

  • Cozmo AI 为财产理赔行业构建 AI 操作系统，客户包括大型修复特许经营商。
  • FDE 需驻场客户运营，端到端构建生产级 Agent 系统并逆向工程遗留理赔软件。
  • 要求 0 至 4 年经验，需具备 LLM Agent 与评测的实战能力。
  • 工作强度高：纽约到岗，每周近六天，上线周不休。
  • 申请需提交可检验的技术作品、60 秒视频问答与最早到岗日期。

你需要什么

关于 Cozmo

Cozmo 是财产理赔领域的 AI 操作系统。当凌晨两点有人家中水管爆裂时，我们的 AI Agent 接听电话、记录损失、将理赔录入 Xactimate 和 Cotality、按 SLA 派遣合适的承包商、在违约前催收确认函，并根据现场照片起草可直接提交给保险公司的估价单。我们同时运营理赔业务的两端：客户接触的一切，以及幕后发生的一切。

我们的客户是修复连锁品牌、TPA 和理算公司，它们的董事会要求它们转型为 AI 原生企业，而它们自己却无从下手。我们的锚定客户是美国最大的修复连锁品牌之一。

职位介绍

理赔是一个充满敌意的工程环境。数据散落在 Xactimate 文件、保险公司门户、Zendesk 队列、语音留言和潮湿石膏板的照片中。工作流程是二十年前设计的，并靠加盟协议来强制执行。SLA 以分钟计算，违约意味着真金白银的损失。你的任务是走进这个环境，从第一性原理出发思考系统应该是什么样子，然后构建在生产环境中运行它的 AI Agent。

你将把一部分时间花在客户运营现场，另一部分时间编写成为平台一部分的代码。从“我看到调度员在这件事上浪费了一小时”到“现在由一个 AI Agent 来完成”，这段距离应该以天计，而整段距离由你负责。

你将向 CTO 汇报，并与两位创始人直接合作。

你的工作内容

  • 深入企业理赔运营现场，端到端地对技术成果负责
  • 构建生产级 AI Agent 系统：提示词架构、工具调用、路由、评测、降级方案，以及 LLM 与那些从未打算开放 API 的系统之间的粘合层
  • 逆向工程遗留理赔软件，使其可编程
  • 随着推进设计数据层。我们接触的每一份理赔都会产生数百个结构化数据点，你构建的管道将成为护城河
  • 在有硬性截止日期、高管紧盯的现场上线期间交付，包括业务量一夜之间翻三倍的飓风季高峰
  • 将现场解决方案转化为平台原语，让每次部署都比上一次更快

我们的招聘标准

  • 出色的计算机科学基础，来自顶尖院校，或有可证明的自学同等水平。我们看重你思维的深度，并会直接进行考察
  • 0 到 4 年经验。欢迎应届毕业生，只要你的作品比简历更有说服力
  • 你构建得又快又深：精通 Python 或 TypeScript，能胜任全栈开发，能独自从空仓库做到生产系统
  • 实战型 LLM 工程：你构建过 Agent 系统、编写过评测，并且了解模型在哪些地方会失效，而不仅仅是在 notebook 里调用 API
  • 第一性原理思维。当标准流程有问题时你能察觉，并且能够向已经运行该流程二十年的负责人论证重新设计的合理性
  • 可查验的进取心证明：研究、创业、开源、竞赛成绩，或某个已上线且有人使用的产品
  • 你愿意与客户打交道。最优秀的 FDE 把部署本身视为最有意思的部分

加分项

  • 语音 AI、电话系统或实时系统
  • 保险、理赔或现场服务领域经验
  • 竞赛编程、奥赛或研究方面的获奖记录

我们的工作方式

我们每周工作近六天，在纽约线下办公，上线周连第七天也要投入。我们坦率地说明这一点，因为高强度是我们对抗员工规模百倍于我们的老牌公司的结构性优势，也因为我们想要的工程师读到这一段会感到轻松。在这样的环境里，没有人会让你放慢脚步。

薪酬

有竞争力的薪资加上创始级别的股权，股权占比较高，因为我们想要的是公司的主人；如需要，还提供搬迁至纽约的支持。

如何申请

无需求职信。请向我发送以下三样东西：

  • 你构建过的最具挑战性的技术作品，附上可供查验的代码或成果
  • 用一段不超过 60 秒的 loom/Vimeo 视频，以第一性原理回答：一个 Agent 需要根据通话记录和 40 张照片，将水损估价录入 Xact。最先出问题的是什么？你如何围绕它进行设计？
  • 你最早能入职的日期

我们会在 48 小时内回复每一份真实申请。无论简历如何，问题 2 的出色回答都能获得面试机会。
