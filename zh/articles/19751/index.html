前沿部署软件工程师 - SF | OpenAI

原标题：Forward Deployed Software Engineer - SF | OpenAI

Zero G Talent · 2026-03-11 · 约 4 分钟读完

摘要

OpenAI 在旧金山招聘前沿部署软件工程师（FDSWE），要求 7 年以上全栈经验，需与客户及内部 FDE、销售、解决方案团队协作，用 OpenAI API 构建定制化生产系统，出差比例可达 50%，采用每周 3 天到岗的混合办公模式。

要点

  • 岗位为旧金山前沿部署软件工程师，混合办公每周 3 天到岗。
  • 要求 7 年以上全栈工程经验，客户-facing 经验优先。
  • 职责包括嵌入客户现场、设计抽象并交付可扩展方案。
  • 需与销售、解决方案工程师、架构师及研究团队协作。
  • 出差比例最高可达 50%，提供搬迁协助。

职位要求

关于团队

OpenAI 的前沿部署工程团队与客户合作，将研究突破转化为生产系统。我们的工作处于客户交付与核心平台开发的交汇点。

关于该职位

我们正在寻找以客户为中心的软件工程师，构建利用 OpenAI API 解决客户实际问题的有效定制软件。作为前沿部署软件工程师（FDSWE），你将与我们的客户以及 OpenAI 前沿部署工程师合作，设计并实现可扩展的解决方案，解决他们最棘手的问题。你将设计用于解决客户问题的抽象层，并利用它们提升我们在所有前沿部署项目中的交付速度和质量。

你将与负责同一客户的销售、解决方案工程、解决方案架构师以及客户成功经理紧密协作。你还将与我们的研究团队以及应用产品与工程团队合作，提供有价值的客户反馈。

该职位位于旧金山。我们采用每周 3 天到岗的混合办公模式。我们提供搬迁协助。该职位需要出差，出差比例最高可达 50%。

在这个职位上，你将：

  • 深度融入战略客户，详细了解他们的业务挑战和技术需求。
  • 采用以实验为驱动、迭代式的方法，设计、架构并开发全栈解决方案。
  • 为概念验证原型和完整的生产部署准备详细的工作范围和项目计划。
  • 以技术专家和值得信赖的顾问身份，与客户的技术团队并肩编码，在他们的基础设施上推动项目完成。
  • 与产品、研究和应用团队协作，确保无缝的客户体验、项目成功以及可落地的产品反馈
  • 为内部知识库做贡献，将最佳实践固化下来，并分享从客户项目中获得的经验，以扩展前沿部署工程职能。

如果你具备以下条件，你将在这个职位上如鱼得水：

  • 在科技和产品驱动型公司的相关岗位拥有 7 年以上专业全栈工程经验（不含实习）——有面向客户的经验者优先
  • 曾是创始人，或在初创公司担任早期工程师并从零构建过产品者加分
  • 具有使用 Postgres/MySQL 等关系型数据库的经验
  • 偏好快速行动，并愿意与客户迭代合作，交付能真正解决其问题的正确方案。
