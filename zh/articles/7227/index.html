Microsoft 借助 CSP 合作伙伴分发免费 Copilot 试用

原标题：Microsoft taps CSP partners to distribute free Copilot trials

Channel Dive · 2026-07-22 · 约 3 分钟读完

摘要

微软自8月1日起通过云解决方案提供商渠道向中小企业提供最多25名用户的30天免费Copilot试用，试用结束后转为付费。这是其“前沿转型”战略的一部分：新成立的Microsoft Frontier Company投入25亿美元，将6000名技术人员嵌入Accenture、Capgemini、EY、KPMG和PwC等大型系统集成商，并推出前沿部署工程师模式的认证与合作伙伴专项资质。微软还将30%的合作营销资金导向Copilot增长，并扩展云市场至欧洲、澳大利亚、日本和南非等30多个地区，以追赶AWS和Google Cloud。

要点

  • 8月1日起通过CSP渠道提供30天免费Copilot试用，最多25名用户
  • Microsoft Frontier Company投入25亿美元，派驻6000名技术人员协助客户采用AI
  • 前沿部署工程师将嵌入Accenture、EY、KPMP等大型系统集成商
  • 30%合作营销资金将投向Copilot增长，并推出新的工程师认证
  • 云市场新增30多个地区，追赶AWS和Google Cloud的市场能力

全文

反馈。

简报要点：

  • 微软将依托其云解决方案提供商网络，从8月1日起向客户提供最多25名用户的免费30天Copilot试用。这款入门级365 SKU于6月通过直接授权首次面向员工少于300人的企业开放，并于本月早些时候通过合作伙伴以“Copilot in 30”形式推出。
  • “这是面向分销商及其合作的经销商的工具，用于服务中小企业客户，让他们获得所需的Copilot体验，并在30天试用结束后转化为付费购买，”微软首席合作伙伴官兼全球渠道合作伙伴销售企业副总裁Nicole Dezen在接受Channel Dive采访时表示。
  • 这款中小企业套餐是微软以渠道为中心的推动举措的一部分，其中包括对Microsoft AI云合作伙伴计划成员在技能培训、认证和联合销售资源方面的额外投入。“这实际上关乎我们如何让客户通过Microsoft AI平台与Microsoft合作伙伴生态系统的结合，安全地在整个企业中落地应用AI，”Dezen说。

深度洞察：

Copilot是微软推动AI在Azure云服务和365办公生产力套件中普及的先锋——该公司将这一努力称为“前沿转型”。

本月早些时候，微软承诺向一个新业务部门投入25亿美元，该部门将派出6,000名技术人员帮助客户采用AI。微软在7月2日（即其当前财年开始后一天）的公告中表示，Microsoft Frontier Company初期将向前沿部署工程师嵌入大型全球系统集成商合作伙伴，包括埃森哲、凯捷、安永、毕马威和普华永道。

“我们2027财年的战略聚焦于前沿转型，”Dezen说。

微软寄望于Copilot的采用来解锁更大的商机——今年早些时候，一些合作伙伴曾反映Copilot在中小企业中的采用较为缓慢。

“Copilot是大多数客户进入AI世界的重要入口，”Dezen说。“我们把它称为AI的用户界面。”

Copilot也在重塑微软向分销商和经销商分配联合营销资金的方式。今后，公司将把30%的联合投入定向给专注于Copilot增长的合作伙伴。

除了向客户推销Copilot之外，微软还希望合作伙伴扩充其FDE队伍。周三，该公司推出了一项面向AI部署架构师的Frontier Transformation Engineer认证，其模式参照微软内部的FDE；同时还推出了一项面向在多个AI和安全领域具备专长的合作伙伴的Frontier Partner专项认证。

“这一切都建立在Microsoft Frontier Company正在使用的同一套人才画像和技能培训方法论之上，”Dezen说。“这实际上关乎微软如何将FDE能力规模化地带给每个细分市场、每个行业、全球每个地区的客户。”

Omdia（Channel Dive 的姊妹公司）高级首席分析师 Lisa Lawson 表示，合作基金（Co-op）援助是帮助合作伙伴产生需求的关键。

Lawson 说：“在现代客户旅程中，买家拥有更多掌控权，并更加依赖其可信顾问、合作伙伴和专家网络，这使合作伙伴在售前获取客户方面至关重要。然而 Omdia 的研究显示，62% 的合作伙伴在需求挖掘上的投入仅为 10% 或更少。这就是为什么供应商必须帮助合作伙伴在高影响力的需求挖掘活动上投入更多，以便在客户决策过程的每个环节精准触达他们。”

随着 Microsoft 加大其在 AI 领域的投入，该公司正在扩展其基于云的市场，在欧洲、澳大利亚、日本和南非新增了 30 多个区域。Omdia 首席分析师 Alistair Edwards 告诉 Channel Dive，此次扩张为经销商提供了更多与独立软件供应商共同构建多方解决方案的机会，并使 Microsoft Marketplace 与竞争对手处于同一水平。

Edwards 表示，在今年之前，多方私有报价（Multiparty Private Offers）仅在 3 个国家可用——美国、英国和加拿大。他补充道：“AWS 以及在一定程度上 Google Cloud 在让合作伙伴通过其市场进行全球交易方面领先更多。如果没有这种 MPO 机制，客户如果想通过 Microsoft Marketplace 采购，基本上只能直接向第三方供应商购买。”

Marketplace 的这些举措也表明 Microsoft 有意扩展其渠道业务。

Edwards 说：“随着 Microsoft 现在在 Marketplace 上大力倚重协同销售（co-sell），渠道合作伙伴将能够借助 Microsoft 销售团队的力量来推动业务势头。Microsoft 的销售人员现在有很强的激励去推动市场计费收入，因此可以预期他们会优先与合作伙伴开展销售。”
