工具档案：promptfoo——CLI 优先的 prompt 测试与红队工具

摘要

本文是 FDE中国 的工具档案，介绍开源命令行工具 promptfoo。它定位为 prompt 与 AI Agent 的测试和红队工具，而非评测平台，优势是轻量、可编排、易接入 CI，短板是缺少看板与协作功能。作者强调它与评测平台是先后关系：用例规模变大后应迁移到平台。对 FDE 而言，其开源可离线的特性适合内网与私有化交付，数据不出客户机房。建议把 prompt 改动纳入回归测试，实现评测左移。

要点

  • promptfoo 是 CLI 优先的开源 prompt 与 Agent 测试工具，内置红队能力。
  • 定位是测试工具而非平台，强在快与 CI 集成，弱在看板与协作。
  • 用例超过几百条、需业务方参与时，应迁移到评测平台，两者是先后关系。
  • 开源可离线，适合内网与私有化交付，数据不出客户机房。
  • 建议在 CI 中加入 promptfoo 回归任务，把 prompt 改坏事故变成第一条用例。

这张卡回答「轻量级评测用什么」。promptfoo 的定位是测试工具而非平台：强在快、可编排、能直接进 CI，弱在看板与团队协作。最常见的误用是拿它当长期评测中台——一旦评测用例超过几百条、需要业务方一起看结果，就应该迁移到带数据集管理与可视化的平台，两者是先后关系而非二选一。

相比站内评测方法论文章，这张卡的增量在于把「评测左移」落成具体动作：prompt 改动像代码一样过回归。国内语境的加分项是开源可离线，适配内网与私有化交付环境，数据不出客户机房。行动建议：在一个进行中的项目里给 CI 加一条 promptfoo 回归任务，把上次改坏 prompt 的事故变成第一条用例。
