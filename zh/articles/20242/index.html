圣何塞前沿部署工程师职位 — Adobe

原标题：Forward Deployed Engineer Job in San Jose — Adobe

Talentify · 2026-09-24 · 约 7 分钟读完

摘要

Adobe 在圣何塞招聘移动方向前沿部署工程师（FDE），全职岗位。该职位要求直接服务大型企业客户，将 Adobe Mobile SDK 集成到复杂的 iOS 和 Android 应用中，编写生产级代码并排查线上问题，同时把客户反馈转化为产品改进。要求 6–12 年软件开发经验，精通 Swift/Objective-C 或 Kotlin/Java，需 20%–40% 时间出差。加州薪资区间为 148,500 至 214,950 美元。岗位还强调 AI 能力，包括用 LLM 构建移动体验原型，并明确禁止在面试中未经许可使用 AI 工具。

要点

  • Adobe 在圣何塞招聘移动方向前沿部署工程师，全职。
  • 职责包括 SDK 集成、生产级代码与线上问题排查。
  • 要求 6–12 年经验，精通 iOS 或 Android 开发。
  • 出差占 20%–40%，加州薪资为 14.85 万–21.495 万美元。
  • 重视 LLM 与 AI 移动体验经验，面试禁用 AI 工具。

职位机会

移动端体验往往是全球品牌与客户之间最重要的接触点。Adobe 的移动 SDK 为一些全球最大的移动应用中的个性化体验、客户互动、分析、消息传递、实验以及 AI 驱动的交互提供支持。

我们正在寻找经验丰富的移动端前沿部署工程师，他们能够在软件工程、客户架构和技术咨询的交汇处蓬勃发展。

作为一名 FDE，您将直接与 Adobe 最大的企业客户合作，将 Adobe 的移动技术集成到复杂的 iOS 和 Android 应用中。您将帮助客户解决棘手的实施难题，设计可扩展的移动架构，排查生产环境问题，并通过直接的客户反馈影响 Adobe 移动平台的未来发展。

这不是传统的咨询岗位。

您将编写生产级代码、构建参考实现、制作 AI 驱动的移动体验原型，并与客户工程团队并肩工作，以加速成功部署。

您的职责

  • 直接与企业移动工程团队合作，了解应用架构、技术限制和业务目标。
  • 使用 Adobe Mobile SDK、API 和云服务设计并实现可扩展的集成。
  • 开发生产级 iOS 和 Android 代码、示例应用、可复用的 SDK 集成以及参考实现。
  • 排查移动应用、后端 API、身份验证、网络和 SDK 行为等方面的复杂生产环境问题。
  • 与客户工程团队共同主持架构研讨会、实施评审和技术深度探讨。
  • 与产品管理和工程团队紧密协作，将客户反馈转化为产品改进。
  • 使用 LLM、端侧智能和 Adobe AI 能力制作新型 AI 驱动移动体验的原型。
  • 帮助客户采用现代移动工程实践，包括 CI/CD、可观测性、测试、发布管理和性能优化。
  • 差旅至客户所在地的时间约占 20%–40%。

成功的标准

我们招聘的工程师兼具深厚的技术功底与出色的客户同理心。

成功的候选人应展现出：

移动工程卓越能力

你曾构建并发布过服务大规模用户的生产级 iOS 或 Android 应用。

客户合作

你乐于与工程团队直接协作，深入理解客户问题，并成为值得信赖的技术顾问。

系统思维

你理解移动应用如何与 API、身份系统、身份验证、后端服务及云基础设施交互。

软件开发

你编写整洁、可维护的生产级代码——而不仅仅是原型或概念验证。

技术领导力

你既能主导架构讨论，也能亲自动手参与工程工作。

沟通能力

你能清晰地向工程师、架构师、产品负责人及高管利益相关者解释复杂的技术概念。

AI 素养

你积极使用 Copilot 等或类似的 AI 辅助开发工具，并理解 LLM 如何提升现代移动体验。

行动导向

你能快速诊断问题、构建解决方案，并持续改善客户成果。

我们在寻找什么样的人

相比头衔，我们更看重实际展现的影响力。

优秀的候选人通常具备：

必备条件

  • 6–12 年专业软件工程经验。
  • 在 iOS（Swift/Objective-C）或 Android（Kotlin/Java）开发方面拥有深厚专长。
  • 有将复杂移动 SDK 集成到生产应用中的经验。
  • 有构建和使用 RESTful API 及后端服务的经验。
  • 对移动架构、应用生命周期、网络、安全及性能优化有深入理解。
  • 有企业级移动应用的开发经验。

优先条件

我们尤其看重具备以下一项或多项经验的候选人：

  • 企业级 B2B SaaS 平台
  • API 集成平台
  • 身份与身份验证（OAuth、OpenID Connect、SSO）
  • 客户实施或专业服务工程
  • 解决方案架构
  • 技术咨询
  • 开发者关系
  • 移动 DevOps 与 CI/CD
  • AWS、Google Cloud 或 Microsoft Azure
  • 移动分析平台
  • 推送通知与消息平台
  • AI 驱动的移动应用
  • 将 LLM 集成到移动体验中
  • 检索增强生成（RAG）
  • 端侧 AI 或 GenAI 框架

理想背景

我们寻找的是既构建过软件、又与客户合作过的工程师。

常见背景包括：

  • 高级 iOS 工程师
  • 高级 Android 工程师
  • 移动解决方案工程师
  • 移动 SDK 工程师
  • 移动解决方案架构师
  • 客户工程师
  • 移动平台工程师
  • 开发者关系工程师
  • 技术顾问（移动方向）
  • 专业服务工程师
  • 资深移动工程师

为什么选择 Adobe

你将参与塑造全球数亿人使用的移动体验。

你将直接与财富 500 强的工程团队合作，解决行业内最具挑战性的移动集成问题，影响 Adobe 的产品路线图，并帮助定义下一代 AI 驱动的移动体验。

如果你喜欢构建软件、解决客户问题，并乐于在工程与产品创新的交汇处工作，我们期待与你交流。

Adobe 通过释放创造力、提升生产力并打造个性化客户体验的创新平台和工具，赋能每一个人进行创作。Adobe 行业领先的产品，包括 Adobe Acrobat Studio、Adobe Express、Adobe Firefly、Creative Cloud、Adobe Experience Platform、Adobe Experience Manager 和 GenStudio，以 AI 为动力、以人类智慧为驱动，帮助个人和企业将创意转化为影响力。

我们在全球拥有 30,000 多名员工，正在创造未来、不断超越，推动下一个十年的增长。我们的使命是招募最优秀的人才，并致力于打造一种让所有员工都能发挥影响力的企业文化。在 Adobe，我们相信伟大的创意可以来自组织的任何角落。下一个伟大的创意，也许就来自你。

预期薪资范围：

我们的薪酬反映了美国多个地理市场的劳动力成本，并根据这些确定的市场支付不同的薪酬。该职位在美国的薪资范围为年薪 $114,100 - $214,950。此范围内的薪酬因工作地点而异，也可能取决于与工作相关的知识、技能和经验。招聘人员可以在招聘过程中向您介绍该工作地点的具体薪资范围。在加利福尼亚州，该职位的薪资范围为 $148,500 - $214,950。

在 Adobe，销售类职位的起薪以总目标薪酬（TTC = 基本工资 + 佣金）表示，短期激励以销售佣金计划的形式提供。非销售类职位的起薪以基本工资表示，短期激励以年度激励计划（AIP）的形式提供。

此外，某些职位可能有资格获得以新员工股权奖励形式提供的长期激励。
