前沿部署工程师 | Middesk | 加州旧金山

原标题：Forward Deployed Engineer | Middesk | San Francisco, CA

摘要

Middesk 在旧金山招聘前沿部署工程师，要求 6 年以上生产软件开发经验，精通 Python 及 TypeScript 或 Go，负责客户集成架构、LLM 与 AI Agent 系统运维及评测框架建设。Middesk 服务超过 700 家银行与金融科技公司，2025 年验证逾 700 万家企业，由 Sequoia Capital、Accel 等投资。

要点

  • Middesk 招聘前沿部署工程师，常驻旧金山。
  • 要求 6 年以上生产软件经验及 Python 加另一语言。
  • 职责包括端到端拥有客户集成与 AI Agent 系统部署。
  • 需设计评测框架衡量 LLM 输出质量与可靠性。
  • 公司服务 700 多家银行与金融科技公司。

关于 Middesk：

Middesk 正在构建数据与智能基础设施，帮助企业之间放心地开展合作。我们从打造一个全面了解企业的平台起步，整合权威数据与专有数据，帮助客户验证企业身份、更快地完成客户入驻，并在整个客户生命周期中管理风险。

如今，超过 700 家银行和金融科技公司使用 Middesk，2025 年我们验证了超过 700 万家企业。我们还将业务拓展到企业验证之外，帮助企业设立、注册、管理和维护其业务，已支持超过 50,000 家企业开设超过 100,000 个账户，用于招聘员工、发放工资并保持合规。

Middesk 源自 Y Combinator，并获得红杉资本、Accel、Insight Partners 和 Canapi 的投资。我们很荣幸入选《福布斯》金融科技 50 强和最佳初创企业雇主榜单。

关于该职位：

我们正在招聘一名前沿部署工程师（FDE）：一位技术功底深厚的建设者和技术领导者，能够在工程、产品和真实客户问题的交汇处大展身手。

你将与客户以及内部产品和工程团队并肩工作，设计、交付并迭代在生产环境中运行的关键任务集成和 AI 驱动系统。你将编写真实的代码，端到端地负责复杂的部署，并帮助塑造 Middesk 整体系统的构建方式。前沿部署工程师弥合产品意图与实际使用之间的差距——充当紧密的反馈闭环，同时影响我们产品的使用方式及其未来的发展方向。

你将担任技术领导者，帮助确定方向、影响架构，并为我们如何在真实世界中部署和运营系统建立最佳实践。

这一职位非常适合曾经创业的创始人、怀念直接为客户创造价值的前核心工程师，或者热衷于承担责任、希望构建反馈即时可见的真实系统的人。

工作内容

负责部署的技术方向

  • 负责面向客户的复杂系统与集成的架构设计和技术设计。
  • 在速度、可靠性和可扩展性之间做出并清晰传达明确的权衡。
  • 识别系统性风险，推动跨部署的改进，而不仅仅是一次性的解决方案。
  • 建立其他工程师可以借鉴的模式和标准——帮助定义 Middesk 前沿部署工程的“卓越”标准。

构建并部署真实系统

  • 与战略客户深度合作，了解他们的架构、工作流程和约束条件。
  • 使用 Middesk 的 API、数据管道和 AI 工作流设计、构建并部署生产级集成。
  • 端到端地负责部署：从架构和实现到上线、监控和迭代。部署质量至关重要——我们处于客户系统的关键路径上。
  • 解决那些尚无既定方案、模糊且影响重大的问题。

AI、Agent 与评测

  • 在真实的客户工作流中构建和运营基于 LLM 和 Agent 的系统。
  • 设计并维护评测框架（评测），以衡量 LLM 输出和 Agent 行为的质量、可靠性和正确性。
  • 创建测试工具、指标和反馈循环，持续改进 AI 驱动的系统。
  • 能够熟练地并行运行多个编码 Agent 或自动化工作流，调试故障，并对系统行为进行推理分析。

影响产品与工程方向

  • 将部署中的经验转化为可复用的抽象、内部工具和产品改进。
  • 通过发现反复出现的模式、技术差距和可发挥杠杆作用的机会，影响路线图优先级。
  • 参与架构讨论，并为全组织的技术决策做出贡献。
  • 我们相信，只有交付客户价值，工程速度才有意义——你的职责就是确保这一点。

领导并提升标准

  • 通过影响力而非职权进行领导——在高自主权、高信任的环境中，为工程质量和务实精神树立高标准。
  • 通过设计评审、代码评审和动手协作指导工程师。
  • 享受真正的自主权、对产品方向的直接影响，以及具有现实世界影响的深度技术问题。
  • 与一个重视深思熟虑的工程而非形式化流程的团队共事。

我们在寻找的人才：

核心要求

  • 6 年以上在生产环境中构建和交付软件的经验。
  • 有作为团队或主要系统的技术负责人或领域负责人的经验。
  • 精通 Python 以及至少一门其他语言（TypeScript、Go 等）。
  • 有设计和运营分布式系统、API 以及云原生基础设施的经验。
  • 能从容应对全栈工作：后端系统、集成、基础设施和工具。
  • 强烈的调试直觉和主人翁意识——你不仅关注正常流程，更深入关注故障模式。
  • 出色的沟通能力——能够向工程师、产品团队和非技术利益相关者清晰地阐述权衡取舍。

AI / LLM 经验（强加分项）

  • 具有构建或部署基于 LLM 或 AI Agent 系统的实践经验。
  • 熟悉 LLM 评测技术和性能度量方法。
  • 具有编排由 AI 驱动的自动化工作流、AI Agent 或开发者工具的经验。
  • 对应用 AI 系统中的故障模式和权衡取舍有清晰的理解。

客户与行业经验

  • 有在高不确定性、快速迭代的初创环境中工作的经验。
  • 具有金融科技、合规或对正确性和数据质量要求较高的受监管系统方面的背景。
  • 能够直接与客户合作解决复杂的技术问题。

加分项：

  • 曾是创始人或初创公司早期工程师。
  • 具有身份系统、风险/反欺诈或工作流自动化方面的经验。
  • 熟悉可观测性、可靠性工程或系统安全实践。
