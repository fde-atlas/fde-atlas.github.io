前沿部署工程师（中级/高级）| Hippocratic AI

原标题：Forward Deployed Engineer (Mid/Senior) | Hippocratic AI

Zero G Talent · 2026-06-11 · 约 5 分钟读完

摘要

Hippocratic AI 在加州 Menlo Park 招聘中高级前沿部署工程师，要求驻办公室办公。该职位负责端到端交付医疗机构的对话式 AI Agent：搭建基于客户临床数据的 RAG 管线、通过 MCP 和工具调用对接 Epic、Cerner 等 EHR 系统，并承担生产监控与事故响应。入职 90 天内需独立完成首个部署，一年内部署多个 Agent 并沉淀可复用框架。任职要求包括 3 年以上软件工程经验、扎实的 Python 能力及 LangChain 等框架实战经验，有医疗 IT（FHIR、HL7）背景者优先。公司专注医疗安全 LLM，刚完成 1.26 亿美元 C 轮融资，估值 35 亿美元，累计融资超 4 亿美元。

要点

  • Hippocratic AI 招聘中高级前沿部署工程师，常驻 Menlo Park 办公室。
  • 职责涵盖 RAG 管线、MCP 集成、EHR 对接及生产监控全流程。
  • 要求 3 年以上经验，精通 Python 与 LangChain 等 LLM 框架。
  • 医疗 IT 经验如 FHIR、HL7、Epic 集成为加分项。
  • 公司 C 轮融资 1.26 亿美元，估值 35 亿美元。

关于该职位

职位使命

作为 HAI 的前沿部署工程师，你将成为 AI 部署的技术负责人，直接改变医疗系统的运作方式。你将深入客户现场，构建、上线并运营生产级对话式 AI Agent——设计能够处理真实临床工作流程、影响数千次患者交互的系统。设立这一职位的原因是：医疗机构已准备好大规模部署突破性 AI，他们需要一位世界级的 AI 工程师，能够在现场构建可靠且创新的系统。

你将取得的成就

主导你的首个重大成果：在 90 天内，你将完成对首个 AI 部署的端到端负责：基于客户数据设计并实现 RAG 流水线，构建将我们的 Agent 连接到客户系统（电子病历、数据仓库、运营工具）的工具调用和 MCP 集成，以零意外的方式完成生产上线，并建立能在客户察觉之前捕获异常的监控体系。

创造持久影响：在 12 个月内，你将在所负责的医疗系统中部署多个 Agent，构建可复用的 AI 模式和框架以加速未来部署，成为客户信赖的技术合作伙伴，帮助他们解决最棘手的 AI 问题，并提供可衡量的证据证明我们的 Agent 提升了运营可靠性和临床结果——在生产级医疗环境中验证我们的技术。

团队情况

你将与部署策略师、工程师和临床专家并肩工作——深入客户现场，同时与我们核心 AI 团队紧密相连。你将在现场以高度的技术主导权和自主性开展工作，并直接接触我们的产品、机器学习研究和工程领导团队。这是一种交付真实系统、为结果负责、在问题演变成危机之前将其解决的文化。

你的工作内容

  • 设计并实现 RAG 流水线，使对话式 AI 的回答基于客户的临床数据，确保准确性、安全性以及与医疗工作流程的相关性，同时管理检索延迟和数据治理
  • 构建工具调用和模型上下文协议（MCP）架构，使 AI Agent 能够安全地与客户系统交互——电子病历系统（Epic、Cerner、Athena）、数据仓库和运营工具——优雅地处理错误并执行安全约束
  • 使用 LangChain、LangSmith 和现代 AI 框架开发生产级 Python 代码，实现先进的 LLM 技术（RAG、提示词工程、LLM 即裁判、思维链推理），解决新颖的医疗 AI 问题
  • 执行端到端部署，包括基础设施搭建、集成测试、生产监控配置、切换规划和上线执行——确保部署按计划进行，不出意外
  • 监控并负责生产系统，为已部署的 AI Agent 建立监控，快速响应事故，与客户协作排查问题，并实施修复措施，确保系统持续可靠运行
  • 以技术专家身份与客户合作，讲解 AI 系统架构，帮助团队理解系统的能力与局限，并通过主动沟通和解决问题建立客户对解决方案的信心

工作地点要求

我们相信最好的想法诞生于协作之中。为了支持快速协作和强大的团队文化，除非另有说明，该职位要求每周五天在我们位于加州门洛帕克的办公室工作。

基本任职资格

  • 计算机科学、软件工程或相关技术领域的学士学位
  • 3 年以上专业软件工程经验，具备扎实的 Python 基础和生产级软件开发经验
  • 具备 LLM 框架（LangChain、LangSmith 或类似框架）的实践经验，并深入理解现代 LLM 开发模式和最佳实践
  • 在 LLM 技术方面拥有深厚专长，包括检索增强生成（RAG）、提示词工程、工具调用、LLM-as-judge 及相关高级模式
  • 具备构建 API、数据库或企业系统集成的实际经验；熟悉异步模式、错误处理和可靠性工程

优先任职资格

  • 具有使用 Model Context Protocol（MCP）或类似框架进行工具集成和多系统编排的经验
  • 具有医疗 IT 经验，包括 EHR 集成（Epic、Cerner、Athena）、FHIR、HL7 或医疗数据标准
  • 具有生产环境 DevOps 或基础设施经验，包括搭建监控、告警、日志和事故响应系统
  • 有在生产环境中部署 AI 系统或使用 LLM 的业绩记录，能够管理延迟、可靠性和运维复杂性
  • 具有关键任务或安全敏感系统的经验，在这些系统中可靠性和错误处理不容妥协
  • 具有初创公司或高速增长科技公司的背景，尤其是担任技术领导或负责角色的经历

我们全面的薪酬方案旨在回报您的专业能力，包括有竞争力的基本工资和有价值的股票期权。个人录用待遇将根据多种因素确定，包括您的专业经验、核心能力和地理位置。

为什么加入 Hippocratic AI

用安全至上的 AI 重塑医疗健康。 我们正在打造全球首个专注于医疗领域、以安全为核心的 LLM——一个旨在全球范围内改善患者治疗效果的突破性平台。这是品类的开创。

获得全球顶尖医疗与 AI 投资者的支持。 我们最近完成了 1.26 亿美元的 C 轮融资，估值达 35 亿美元，由 Avenir Growth 领投，融资总额达 4.04 亿美元，参投方包括 CapitalG、General Catalyst、a16z、Kleiner Perkins、Premji Invest、UHS、辛辛那提儿童医院、WellSpan Health、John Doerr、Rick Klausner 等。

与医疗和 AI 领域最优秀的人并肩前行。 加入那些毕生致力于改善医疗、推动科学进步、打造改变世界的技术专家团队——确保我们的平台强大、可信、真正具有变革性。
