AWS 投入 10 亿美元成立新 AI 部门，将工程师嵌入客户团队，加入日益壮大的浪潮

全文

Amazon Web Services 周二宣布，将投资 10 亿美元组建一个新的前沿部署工程部门，帮助客户构建和部署人工智能系统。

前沿部署工程师（FDE）是指直接派驻到另一家企业内部、致力于加速技术转型的员工。国防承包商 Palantir 十多年前创造了这一术语，但如今它在软件供应商中重新兴起——这些供应商希望直接把人才派驻到客户现场，以提升产品采用率。

包括 OpenAI 和 Anthropic 在内的领先模型开发商今年早些时候宣布成立各自的 FDE 公司，与银行、私募股权和咨询公司展开合作。现在，AWS 也希望在这一市场中分得一杯羹。

“多年来我们一直具备相关能力，但从结构上讲，这就像是把所有人聚集到一个业务部门中，遵循统一的部署准则，”AWS 前沿 AI 工程与服务副总裁 Francessca Vasquez 在一次采访中表示。“这是我们第一次以这种方式来做。”

按收入计算，Amazon 是最大的云服务提供商，也是首家宣布此类举措的超大规模云厂商。

Vasquez 表示，AWS 的新部门将配备“数千名”FDE。一个由大约五六名工程师组成的初始小组将同时派驻到一家 AWS 客户内部，这些员工还将与 AI Agent 协同工作——AI Agent 是能够代表用户独立完成任务的工具。

AWS 在一篇博客文章中表示，其 FDE 派驻人员将与客户的业务、工程和安全团队紧密合作，力求在数周内留下具备新解决方案和能力的自给自足团队。

“客户现在最看重的就是速度，”Vasquez 说。“我们确实认为，对于那些希望更快为其利益相关方、客户和管理层创造价值的客户来说，FDE 是一个理想选择。”

今年 5 月，Anthropic 宣布与 Blackstone、Hellman & Friedman 和 Goldman Sachs 共同成立了一家新的“AI 服务公司”，帮助中型企业部署其 Claude AI 模型。

几天后，Anthropic 的主要竞争对手 OpenAI 宣布与 TPG、Advent International、Bain Capital、Brookfield Asset Management 等公司共同成立 OpenAI Deployment Co.。该公司表示，新组织将扩展 OpenAI 将 FDE 派驻到那些在“严苛环境中解决复杂问题”的企业中的能力。

Amazon 已向 Anthropic 和 OpenAI 投入数十亿美元，但 Amazon 高管们毫不掩饰在部分领域与这些实验室直接竞争的雄心。AWS 的一位发言人表示，公司期待有机会与 OpenAI 和 Anthropic 的 FDE 公司合作，并将在近期分享更多关于其合作伙伴计划的细节。

据该公司介绍，包括艾伦研究所、美国职业篮球联赛（NBA）、理光和美国职业橄榄球大联盟（NFL）在内的机构已经在与 AWS 的前沿部署工程师合作。Vasquez 表示，拥有多样化数据集、受严格监管行业的公司将成为下一批采用者。

“这是为那些真正在寻找方法来演进其工作流程的客户准备的，”Vasquez 说。
