大语言模型与生成式 AI 基础

基础Tokenization 与 Tokens大语言模型读取的不是字符或单词，而是 token：由分词器产生的子词片段，每个 token 被映射为一个模型嵌入的整数。Token 是上下文窗口和计费的单位，而文本如何切分成 token 也解释了大量模型怪癖，这就是为什么几乎每个循环都从这里开始。

基础上下文窗口上下文窗口是大语言模型一次能够关注的固定 token 数量，输入和输出共享同一预算。理解它，正是能够合理规划提示词规模、控制成本与延迟、并判断何时需要使用 RAG 的工程师，与那些只是把所有内容一股脑粘贴进去然后祈祷的工程师之间的分水岭。

基础Embeddings 与向量表示嵌入将一段文本转换为一组数字，并使其在空间中的位置反映语义相似性，从而让你可以按含义而非关键词进行搜索。嵌入是 RAG、语义搜索、聚类和去重背后的引擎，因此 FDE 循环会要求你解释余弦相似度，以及那些会悄悄破坏向量索引的陷阱。

检索与 Agent

基础检索增强生成（RAG）RAG 通过在查询时检索相关段落并将其放入提示词中，将大语言模型建立在你自己的数据之上，使模型基于真实来源而非记忆作答。它是几乎所有企业级 FDE 部署的默认模式，这也是为什么几乎每个循环都会考察它。

基础向量数据库向量数据库将嵌入与元数据一起存储，并使用近似索引快速回答最近邻查询。真正的面试问题不是它们如何工作，而是你何时才真正需要一个向量数据库，而不是一个库或带 pgvector 的普通 Postgres。

AI 生产环境系统设计

基础内容从概念验证到生产环境在演示中正确回答了一个问题的 Notebook 并不是可交付成果。生产环境是那些不起眼的工作，它把一次性的成功转变为客户可以在没有你在场的情况下运行、信任和运维的系统。弥合这一差距是 FDE 工作的大部分内容。

基础内容重试、指数退避与抖动当调用因瞬时错误而失败时，立即重试是最糟糕的做法：它会把负载堆积到一个本已不堪重负的服务上，并使所有客户端同步形成踩踏。指数退避将重试间隔拉开，而抖动则让客户端去同步，使它们不再齐步到达。

面向客户的技艺

基础内容需求挖掘需求挖掘是找出隐藏在客户明确提出的要求背后的真实问题的工作。客户交给你的请求（“给我们做一个聊天机器人”）几乎从来不是真正的需求；能够挖掘出谁在使用它、成功是什么样子、实际存在哪些数据以及为什么截止日期是截止日期的 FDE，才是能交付出人们真正会使用的东西的人。

基础界定模糊问题界定一个开放式提示（“某城市想缩短 911 响应时间”）是一种结构化操作，而非灵光一现：澄清输入和约束，大声说出你的假设，划分出最小可用的 MVP，明确你正在选择的准确性/成本/延迟权衡，并规划失败时的应对方案。直接跳到模型或架构是候选人在模拟轮中被淘汰的最常见原因。

基础向非工程师解释权衡高管并不关心你选择了 RAG 还是微调；他们关心成本、交付时间以及可能出错的地方。翻译技术权衡意味着将准确性、成本和延迟转化为业务实际正在做的决策，用他们的语言将每个选项框定为带有后果的选择，并回答他们最终都会问的问题：为什么 AI 每次给出的答案都不同，为什么这不是一个 bug。

在哪里申请，以及 BCG X 官方资源

直接来自 BCG X：公开职位和公司自己的招聘指南。在这里准备，然后在那里申请。

指向 BCG X 自身页面的外部链接。职位和流程会变化；请务必在官方网站上确认。

是的。BCG X 在其自己的招聘网站上发布多个级别的前沿部署 AI 工程师职位，包括一个位于孟买的 Lead Forward Deployed AI Engineer 职位。它是少数直接使用该头衔的大型咨询公司之一。

你是被部署到一个客户项目上，而不是自己的产品。客户关系是商业性的且有明确时限，利益相关者是高管层，工作的一部分是留下可传承的能力。预期面试会考察你与客户合作的方式，而不仅仅是你能构建什么。

我们没有关于前沿部署环节具体流程的公开确认信息。BCG X 在其咨询招聘渠道之外同时招聘技术职位，因此请同时准备实用的 AI 工程能力和商业框架下的结构化问题解决。请将其视为有依据的准备，而非已公布的流程。

BCG X 未公布该职位的薪酬区间。咨询薪酬是基本工资加奖金，对应明确的职级体系而非股权，且以印度为基准的职位是参照印度市场而非美国薪酬区间来定价的。
