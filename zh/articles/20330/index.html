摘要

这是一则面向日本的 FDE（前沿部署工程师）招聘信息。正文描述 SpaceXSI（xAI 相关团队）的岗位：工程师需驻场客户团队，负责发现业务瓶颈、设计并上线基于 Grok 模型的生产级 AI Agent 与编码工作流，承担评测、监控、成本权衡，并以收入、成本、节省工时等指标衡量成效。要求 5 年以上软件、机器学习或数据科学经验，有生产级 AI Agent 经验，日语和英语流利。页面标题虽为 Cursor，正文实为 SpaceXSI 岗位描述。

要点

  • SpaceXSI 在日本招聘前沿部署工程师，要求驻场客户团队交付系统。
  • 职责包括发现瓶颈、上线生产级 AI Agent 与编码工作流。
  • 需负责评测、追踪、调试及延迟与成本权衡。
  • 要求 5 年以上相关经验，日语英语双语流利。
  • 成效以收入、成本、节省工时等业务指标衡量。

任职要求

  • 5 年以上软件工程、机器学习工程或数据科学经验
  • 负责过客户成果并交付过生产系统
  • 用 Python 或 TypeScript 在生产环境中构建过 AI 原生工作流或 AI Agent

工作内容

  • 主导客户调研，找出瓶颈并定义成功指标
  • 设计并交付生产级 AI Agent 和编码 Agent 工作流
  • 负责生产质量，包括追踪、评测、调试和成本权衡
  • 构建模型系统并将其集成到客户的认证和数据系统中
  • 衡量收入、成本、节省工时和错误率等成果

SpaceX 的创立基于这样一个信念：人类探索星辰的未来，从根本上比止步不前的未来更令人振奋。如今，SpaceX 正在积极开发实现这一目标所需的技术，最终目标是让生命成为多行星物种，并将意识拓展至星辰。SpaceXSI 正在构建超级智能，以帮助人类理解宇宙。我们的团队正在打造完整的超级智能技术栈：从我们的 Colossus 超级计算机，到 Grok 模型，再到我们的应用套件，包括 Grok Bot、Grok Build、Grok Imagine、Grok Voice 和 X。我们正在打造一个强大的飞轮：更多的算力训练出更好的模型，更好的模型驱动更有用的产品，而我们从用户使用这些产品中获得的洞察，又将塑造我们下一步的构建方向。

前沿部署工程师 - 日本

你将直接嵌入客户团队，作为驻场工程师：负责一项业务成果，交付一套在你离开后仍能持续运行的生产级 SpaceXSI 系统，并成为从一线反馈到产品工程团队的关键技术闭环。工作本身就是项目本身。某一周，你可能需要接手一个混乱的业务流程，并在其上部署一个生产级 Agent：选定用例、搭建架构、接入客户的认证、数据和工具，然后通过评测不断加固，直到团队真正开始使用它。另一周，你可能需要深入客户的代码仓库和交付系统，为迁移、PR 审查闭环或从故障到修复的流程交付一条由 Agent 驱动的路径，并且是在测试、审查和灰度发布的保障下进行，而不是在聊天侧边栏里草草了事。

职责：

  • 主导客户调研：熟悉客户的代码库和工作流，找出真正的瓶颈和值得构建的用例，并定义清晰的成功指标
  • 基于 Grok 和我们的模型，在真实业务流程和客户工程组织内部，设计并交付生产级 Agent、AI 应用和编码 Agent 工作流
  • 在数天内让首个版本上线，然后在数周内通过灰度发布、监控和基于真实使用的迭代不断加固
  • 负责生产质量：追踪、评测、调试模型或交付故障，以及延迟和成本权衡
  • 围绕模型构建系统（工具、MCP 服务器、检索、规则、技能、CI 门禁和评测），并将其集成到客户的认证、数据、工作流和交付系统中；判断何时提示词、架构、数据、流程或模型变更才是正确的抓手
  • 衡量真正重要的结果（收入、成本、节省的时间、错误率、周期时间、漏出缺陷），而不是席位采用率
  • 直接与 Staff+ 级别工程师、平台和领域负责人合作，深入研究他们的系统，同时清晰地沟通权衡与成果
  • 让客户团队能够独立运行你构建的系统，并将所学转化为可复用的模式以及对 SpaceXSI 产品的改进

基本任职资格：

  • 你拥有 5 年以上软件工程、机器学习工程或数据科学经验
  • 你曾对客户或运营结果负责，而不仅仅是做出一页幻灯片或一个原型，并且能够将模糊的问题转化为范围明确、已交付的系统
  • 你曾在生产环境中构建并负责 AI 原生工作流或 AI Agent（使用 Python、JavaScript/TypeScript），并排查过真实的生产故障（模型、工具、数据、流水线或交付路径）
  • 必须精通日语和英语

优先技能和经验：

  • 2 年以上面向客户的岗位经验，主导需求探索对话，并为外部利益相关者的结果负责
  • 在以下多个领域具备实战深度：AI Agent 与工具调用、评测框架、检索与上下文系统、CI/CD 或开发者平台，以及真实代码库中的 AI 原生编码工作流
  • 拥有前沿部署工程师、解决方案工程师或平台工程师并深度嵌入客户的经验，或作为创始工程师端到端负责过 AI 产品
