LLM Zoomcamp 免费 RAG 课程：评测与监控

FDE Times · 2026-10-08 · 约 4 分钟读完

摘要

文章介绍 DataTalks.Club 的免费课程 LLM Zoomcamp，重点是其评测与监控两个模块。课程完全免费，仅需 1–5 美元 OpenAI 额度，无需 GPU。文章以银行内部制度助手为例，演示如何用 20 个问题的离线评测集区分检索失败与模型理解错误，并强调延迟和成本也应纳入质量度量，帮助 FDE 用数据回答客户的质疑。

要点

  • 课程免费，只需 Python 基础和 1–5 美元 OpenAI 额度。
  • 第 4 模块讲评测，第 5 模块讲监控，面向 Demo 之后的工作。
  • 离线评测可区分检索失败与模型理解错误两类问题。
  • 监控覆盖用户反馈、延迟、成本与实时仪表盘。
  • 跟班学习每年 6 月开课，可获证书；自学可做作品集项目。

DataTalks.Club 的 LLM Zoomcamp 用两个完整模块讲 Demo 之后的评测与监控，只需 1–5 美元 OpenAI 额度。

要点速览

  • DataTalks.Club 的 LLM Zoomcamp 完全免费，视频、资料和作业都不收费。只需熟练掌握 Python，任意一台笔记本即可，不需要 GPU。
  • 最值得学的是第 4 模块（评测）和第 5 模块（监控），这正是 FDE 在 Demo 之后要负责的工作。
  • 想拿证书必须参加每年一期的跟班学习，通常 6 月开课。自学没有证书，但同样可以做出作品集项目。

让 RAG 聊天机器人答上几个问题，只完成了一半工作。另一半通常在第三周到来，客户会问：“它给的答案到底对不对？你怎么知道？”DataTalks.Club 的免费课程 LLM Zoomcamp 值得关注，正是因为它直面这个问题。

除了 LLM 和 RAG 基础，课程专门用一个模块讲评测，另一个模块讲监控。对想成为前线部署工程师（FDE）的人来说，这两部分最有价值，因为 FDE 的工作恰恰从 Demo 结束的地方开始。

谁在办这门课？要花多少钱？

DataTalks.Club 是 Zoomcamp 系列课程背后的社区，创始人 Alexey Grigorev 是讲师之一。视频、资料和作业全部免费；如果自己跑代码，可能的开销只有 1–5 美元的 OpenAI 额度。

入门门槛很低：Python 用得熟练，有一台笔记本就行，不需要 GPU。对做过几年后端的开发者来说，技术上几乎没有障碍。难的是后两个模块要求养成的度量习惯。

两个模块，应对第三周

第 4 模块（评测）讲如何离线和在线度量检索质量与回答质量，覆盖搜索、RAG 和 Agent。第 5 模块（监控）转向已经部署的系统：用户反馈、系统健康状况、实时仪表盘、每次 LLM 调用的指标、延迟和成本。

列成清单读起来很枯燥，只有放进具体事故里才有意义。

假设你为一家银行部署了一个查询内部制度的助手。第一周大家都很满意。到了第三周，一位部门负责人抱怨答案“听着像回事，其实是错的”。

常见的第一反应是改 Prompt。但“错”至少有两个来源：检索器取错了文档；或者取对了，模型却理解错了。改 Prompt 只能解决后一种。

用 20 个问题拆开两类失败

这正是第 4 模块要培养的能力，而且现在就可以练。写 20 个部门负责人可能会问的问题，给每个问题标注包含正确答案的制度段落。这就是你的第一个离线评测集。

第一步只跑检索器，不调用模型。逐个检查正确段落是否出现在检索结果里。假设 14 个命中、6 个未命中：这 6 个是检索失败，任何 Prompt 都救不回来，因为模型根本没看到正确的文档。

第二步只看检索器答对的 14 个问题。把对应的上下文原样交给模型，再给回答打分。仍然答错的就是理解错误，这时候改 Prompt、调整上下文的呈现方式或者换模型才有意义。

两步做完，“听着像回事，其实是错的”这句抱怨就变成了两个独立的数字，各自指向需要修的那一层。你带回给部门负责人的是诊断，而不是承诺。

手写的测试集会过时

自己写的 20 个问题，永远不会和真实用户输入的内容完全一致。所以第 4 模块还讲在线评测，第 5 模块则把用户反馈接入仪表盘。今天评分低的问题，下周就该加进测试集。

监控还能回答测试集回答不了的问题：失败发生得有多频繁，每个回答要花多少钱。对企业客户来说，一个回答正确、却让用户等太久或者 API 调用开销太大的助手，同样是问题。

把延迟和成本当作质量的一部分，与准确率同等对待。

跟班学习还是自学？

课程每年开一期，通常 6 月开始。所谓“live cohort”并不是直播课：所有课程都是预先录好的，跟班只是多了截止日期和作业评分。自学没有证书，但可以自由地做作品集项目。

如果你需要截止日期推着走，就等下一期。如果自律，现在就从 GitHub 仓库开始。无论哪种方式，都不要直接跳到第 4 模块：快速过一遍基础，在一个你非常熟悉的数据集上搭好管道，再把时间投入评测和监控。

把课程变成简历上的证据

在 FDE 面试中，证明你度量过真实系统，比课程名称更有说服力。看岗位描述时，留意“evaluation”“production monitoring”“LLM observability”这类字眼，这正是第 4、5 模块的内容。

简历上不要只写“完成 LLM Zoomcamp”。要写你搭建的 RAG 系统、区分检索与回答的评测集，以及跟踪延迟、成本和用户反馈的仪表盘，并附上仓库链接。面试时，讲一个测试集帮你定位到失败出在哪一层的经历。

这门课不会让你成为 FDE。但它教你用数字回答“你怎么知道？”，而对 FDE 来说，这就是工作的大部分。
