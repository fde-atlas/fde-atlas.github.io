书中内容

六个部分，按面试流程考察的顺序排列。详细的章节拆解仍在编辑中，所以这里呈现的是整体框架，而非目录。

这个角色，以及客户合作流程

前沿部署工程师到底是什么，这个头衔在不同公司间如何碎片化，以及一次客户合作如何从首次通话走到交接。这是后面每一轮都默认你已经掌握的背景知识。

拆解轮

Palantir 的招牌面试轮及其效仿者：把一个模糊的业务目标转化为组件、接口和一份你能为之辩护的方案。这是大多数候选人折戟的一轮，也是最难独自练习的一轮。

编码与实操构建

FDE 面试流程真正考察的编码，是在时间压力下做集成工作和多部分构建，而不是竞赛式谜题。还包括当面试官期望你使用 AI 工具时会有什么变化。

应用 LLM、RAG 与 Agent

能在客户真实文档中站得住脚的检索，上线前的评测，经得起考验的护栏，以及判断 Agent 何时是错误答案的判断力。这是五年前还不存在的工作内容。

生产环境调试与部署

在测试环境正常，一到生产环境就出问题。漂移、偏差、静默退化，以及把一个让某人印象深刻的试点，变成在你不掌控的环境中满足真实 SLA 的系统。

客户轮

向非技术人员解释权衡取舍，在演示出故障时稳住场面，对客户说不，以及那些决定录用结果比任何人承认的都多的行为面试轮。

适合谁读

  • 从后端、数据或 ML 转向前沿部署工作的工程师，他们能构建东西，但从未在客户面前被评判过。
  • 解决方案工程师和技术顾问转向另一个方向，转向一个要求编写生产代码的角色。
  • 任何在我们追踪的 111 家公司之一安排了面试流程、并有三周时间充分准备的人。
