摘要

Avallon AI 在纽约招聘前沿部署工程师。该公司来自 YC，为保险理赔流程构建 AI Agent，覆盖从报案到结算的全流程，一年内实现七位数 ARR，目前季度环比增长 3 倍。该职位要求兼具技术深度与客户沟通能力：约 30-50% 时间做编码、集成与 AI 调优，其余负责客户实施、项目管理与产品反馈。要求 2-5 年经验，掌握 Python 或 TypeScript、REST API 与系统集成，熟悉 LLM、语音 AI（如 Twilio、Vapi）或保险领域经验者优先。面试包括创始人初谈、一小时技术面和最终轮。

要点

  • 岗位 30-50% 时间做技术工作，其余面向客户。
  • 要求 2-5 年经验，会 Python 或 TypeScript 及 API 集成。

关于我们

保险是全球最大的行业之一，却仍然依赖没人愿意做的手工操作。理赔就是最典型的例子：高重复性的工作流程通过电话、电子邮件和长达 200 页的 PDF 文件处理，其中大部分仍运行在 2000 年代初构建的系统上。几十年来，软件一直围绕这个问题打转，却始终无法触及核心，因为没有任何技术能够完成通话或阅读文档。而 AI 终于可以做到。Avallon 构建的 AI Agent 能够运行从报案受理到结案的完整理赔生命周期，让团队更快地推进工作、消除繁琐事务，并提高准确性。

我们从 YC 孵化，在十二个月内实现了从零到七位数的年度经常性收入（ARR），目前正以每季度 3 倍的速度增长，并与全球一些最大的保险公司合作。Avallon 获得顶级投资者的支持，我们的创始团队包括来自 MIT、哈佛和康奈尔的优秀建设者。我们的目标是成为整个保险行业的自动化层，并以一支人才密集的团队实现这一目标，让每个人都能在这里完成职业生涯中最出色的工作。

职位介绍

我们正在寻找兼具技术深度与客户热情的前沿部署工程师。你将直接与客户合作，部署我们的 AI Agent，构建定制化解决方案，并确保客户从我们的平台中获得最大价值。

这一职位处于工程与客户成功的交汇点。你将编写代码、设计集成方案、调优 AI 系统——同时与使用你所构建产品的用户保持直接联系。预计你将把 30%-50% 的时间用于动手技术工作，其余时间用于客户沟通、项目管理和实施策略。

你的工作内容

  • 客户实施： 从首次演示到生产部署，全程负责技术关系。理解每个客户的工作流程，并配置我们的 AI Agent 以满足其运营需求。
  • 解决方案工程： 构建定制集成、API 和工作流，将我们的语音 AI 和文档 Agent 连接到客户系统（理赔管理平台、CRM）。
  • AI 调优与优化： 基于真实客户使用模式和反馈，进行提示词工程、语音定制和 Agent 行为优化。
  • 调研与产品反馈： 你将亲眼看到哪些方案有效、哪些无效。将这些洞察反馈给我们的产品和工程团队，以塑造我们的产品路线图。
  • 技术咨询： 指导客户就 AI Agent 设计、工作流自动化和系统集成等复杂决策提供咨询。

你需要具备的条件

  • 以客户为中心且具备技术功底： 你既能与 CTO 进行技术对话，也能向理赔经理解释 AI 的能力。你真正关心的是客户成果，而不仅仅是技术上的优雅。
  • 构建者心态： 拥有 2-5 年构建或实施技术解决方案的经验。你具备 Python 或 TypeScript 的基础编程能力——足以构建集成、调试问题并理解系统架构。
  • 沟通能力： 你能清晰地向非技术利益相关者解释复杂的技术概念。你写作出色、演讲自信，并知道何时简化表达、何时深入技术细节。
  • 极强的主动性： 你能在模糊环境中如鱼得水。遇到阻碍时，你会主动寻找解决方案。你不会等待完美的需求——而是收集背景信息、做出明智决策并快速推进。
  • API 与集成能力： 具备使用 REST API、webhook 和第三方集成的经验。你曾将不同系统连接起来，并理解跨平台的数据流。
  • 项目管理： 你能同时管理多个客户实施项目，果断排定优先级，并在紧迫的期限内交付高质量成果。

加分项

  • AI/ML/数据科学经验： 有 LLM、提示词工程、RAG 系统或 Agent 框架的实践经验。你了解 AI 哪些能可靠做到、哪些不能。
  • 顶级咨询公司背景，并拥有理工科学士学位
  • 全栈能力： 能熟练驾驭整个技术栈——React、Node.js、PostgreSQL、云基础设施。
  • 低代码工具使用经验（Zapier、Make、Retool）
  • 语音 AI 系统： 了解电话平台（Twilio、Vapi、LiveKit）和实时通信系统。
  • 领域专长： 具有保险、理赔运营或传统行业其他复杂运营工作流的背景。

如果这让你心动，我们期待你的加入。
