摘要

本文介绍 Reflection AI 的机器学习工程师面试流程。该公司由前 DeepMind 研究员创立，定位为开放前沿实验室，主打自主编程 Agent 与 agentic 强化学习，并不设经典的前沿部署工程师岗位。流程包括招聘官电话、技术电面、4-6 轮现场面试和创始人收尾谈话，分研究、研究基础设施、产品工程三条赛道。文章还给出印度市场参考薪资及备考资源。

要点

  • Reflection AI 不设经典前沿部署工程师项目，专注编程 Agent 研究。
  • 面试分研究、研究基础设施、产品工程三条赛道。
  • 流程：招聘官电话、技术电面、4-6 轮现场、收尾谈话。
  • 研究轮重点考察强化学习、奖励设计与 credit assignment。
  • 印度远程雇佣参考薪资：初级 ₹35-55 LPA，资深可达 ₹1.5 Cr。

部分公开数据

关于 Reflection AI 机器学习工程师面试体验的公开指导信息，包括面试轮次形式和准备重点。最后审阅于 2026 年 7 月 31 日。

  • 1招聘人员电话沟通背景、动机以及适合哪条轨道：研究、研究基础设施或产品工程。
  • 2技术电话面试由工程师或研究人员主持；考察编程和与岗位相关的深度知识。
  • 3现场面试（4–6 轮）取决于所选择的轨道。研究轨道侧重于强化学习、奖励、信用分配和评估，而非死记硬背的架构；研究基础设施轨道考察分布式训练以及保持大型 GPU 集群稳定运行；产品工程轨道涵盖 Asimov 背后的 Agent 框架和代码理解流水线。
  • 4结束面谈与创始人或团队负责人讨论匹配度和方向。
  • Reflection 的公开押注是面向编程的 Agent 强化学习，因此研究轮次更多围绕奖励、信用分配和评估展开，而不是架构方面的琐碎知识
  • 一家小型前沿实验室，在三条不同的轨道上招聘专业人才；你所选轨道的深度比广度更重要
  • 系统成熟度：在极大的 token 预算下训练前沿模型，同时保持集群稳定运行

由针对这家特定实验室的公开面试指南汇编而成（我们排除了将 Reflection AI 与无关公司混为一谈的第三方总结）；轨道和轮次可能有所不同，请与你的招聘人员确认。

由我们的研究和公开可得信息（候选人报告和公司面试指南）汇编而成。面试环节会变化并被持续迭代，且因团队、级别和地区而异。请将其视为方向性的准备参考，而非官方规范，并向你的招聘人员或招聘联系人确认确切的轮次。

LLM 与生成式 AI 基础

基础Tokenization 与 Tokens语言模型并不读取字符或单词，而是读取 tokens：由分词器生成的子词片段，每个 token 被映射为模型嵌入的一个整数。Tokens 是上下文窗口和计费的单位，文本如何切分成 tokens 解释了大量模型怪癖，这也是为什么几乎每个面试流程都从这里开始。

基础上下文窗口上下文窗口是语言模型一次能够关注的固定 token 数量，输入和输出共享同一预算。理解它，正是那些能够合理设计提示词、控制成本和延迟、并知道何时使用 RAG 的工程师，与那些只是把所有内容粘贴进去然后祈祷的工程师之间的分水岭。

基础Embeddings 与向量表示Embedding 将一段文本转换为一组数字，其位置使得含义相近的内容在空间中彼此靠近，从而让你可以按语义而非关键词进行搜索。Embeddings 是 RAG、语义搜索、聚类和去重背后的引擎，因此 FDE 面试流程期望你能解释余弦相似度，以及那些会悄悄破坏向量索引的陷阱。

检索与智能体

基础检索增强生成（RAG）RAG 通过在查询时检索相关段落并将其放入提示词中，使语言模型立足于你自己的数据，从而让模型基于真实来源而非记忆作答。它几乎是所有企业级 FDE 部署的默认模式，因此几乎每个循环都会测试它。

基础向量数据库向量数据库将嵌入与元数据一同存储，并使用近似索引快速回答最近邻查询。真正的面试问题不是它们如何工作，而是你何时真正需要一个向量数据库，而不是一个库或带 pgvector 的普通 Postgres。

机器学习基础设施与服务

编程与工程技艺

基础解析混乱的真实世界数据客户文件往往很脏：引号不一致、表头缺失、垃圾行、具有误导性的编码。这项工作的要点是进行防御性解析，跳过并记录坏行而不是中止整个批次，并保持解析逻辑纯净且与业务逻辑分离，从而使其保持可测试性和确定性。这正是早期 FDE 数据接入工作的大部分内容。

基础真正重要的大 O 分析在实际部署中，大 O 并不是白板上的谜题；它是唯一能告诉你客户的数据是否适合你所选方案的计算。这项技能在于找出在客户规模下占主导地位的项，知道暴力法何时失效、何时需要索引或 ANN，并识别常数因子和内存何时比指数更能决定结果。
