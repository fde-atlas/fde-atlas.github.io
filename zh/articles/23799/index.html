创始前沿部署工程师 | Cair Health

原标题：Founding Forward Deployed Engineer | Cair Health

Zero G Talent · 2026-07-09 · 约 2 分钟读完

摘要

Cair Health 是一家获 Y Combinator 等投资的医疗收入周期管理（RCM）初创公司，年经常性收入超 100 万美元且已盈利，去年增长 21 倍。该公司招聘首位前沿部署工程师，深入大客户现场，负责 EHR 集成、配置和调优 AI Agent、现场排障，并决定哪些定制工作应沉淀为核心产品。要求 3 年以上面向客户的技术岗位经验，掌握 Python、SQL、React、REST API、AWS/GCP、Docker，并有构建或使用 AI Agent 的经验。

要点

  • Cair Health 招聘首位前沿部署工程师，驻场服务大客户。
  • 公司为医疗 RCM 平台，ARR 超 100 万美元且已盈利。
  • 职责包括 EHR 集成、部署调优 AI Agent 与现场排障。
  • 需判断定制构建何时泛化进核心产品并移交平台团队。
  • 要求 3 年以上客户-facing 技术经验，熟悉 Python、React、AWS 等。

你需要具备的条件

关于 Cair Health

Cair Health 获得了 Y Combinator、Foundation Capital、Soma Capital 等优秀投资机构的支持，已融资超过 300 万美元，致力于打造由 AI Agent 运营的医疗行业收入周期管理平台。我们已实现 100 万美元以上的年度经常性收入（ARR），处于盈利状态，去年增长了 21 倍。我们的客户包括诊所、MSO、数字健康公司、EHR 厂商、FQHC、计费公司等。

日常工作中，我们会与运营负责人、RCM 主管、计费人员，有时还有工程师打交道。但产品本身技术含量很高，每个客户最终都需要有人能够配置系统、排查集成问题，或直接与客户的工程团队就我们的 API 及其数据流进行协作。

关于该职位

我们正在招聘第一位前沿部署工程师，深入我们最重要的客户账户，构建尚不存在的东西。你负责界定构建范围、交付上线、让它在生产环境中正常运行，然后转向下一个项目。有些日子，你需要针对客户的 EHR 编写集成代码；另一些日子，你需要部署并调优 AI Agent 以适配特定的工作流程。你就是那个能快速将客户混乱的现状转化为可用系统的人。

作为这一职能的首位员工，你将建立后续每一位 FDE 都会继承的模式和工具体系。

你的职责

  • 深入客户账户，界定需要构建的内容，交付上线，然后转向下一个构建任务
  • 构建 EHR 集成，将客户彼此割裂的内部系统、电子表格及其他一切接入 Cair，使其都能通过我们的 AI Agent 自动运行
  • 为每个客户特定的收入周期配置部署、配置和调优 AI Agent
  • 实时调试问题，通常要在时间压力下完成
  • 判断哪些内容应泛化进核心产品、哪些应保留为一次性构建，并移交给我们的平台团队
  • 构建内部工具、脚本和 AI Agent，让下一次构建比上一次更快
  • 将你在一线学到的东西以清晰、有优先级的输入形式反馈给产品与工程团队

必备条件

你需要拥有计算机科学学位或同等的实践经验，并在技术型、面向客户的岗位（解决方案工程、前沿部署工程、实施或技术客户成功）中有 3 年以上经验。

  • 扎实的软件工程基础，能够独立负责从设计到生产上线的完整过程
  • 具备编写 Python（或类似语言）、SQL 以及前端 React 的经验
  • 熟悉 REST API
  • 有 AWS 和 GCP 的使用经验
  • 熟练使用 Docker，包括本地运行和部署
  • 有构建或使用 AI Agent 的实际经验
  • 习惯在日常工作中使用 AI 编程 Agent（Cursor、Claude Code、OpenCode 或类似工具），因为你善于使用这些工具，所以交付速度更快
  • 能够从容应对模糊性，可以在编写代码和参加客户实时通话之间灵活切换

加分项

  • 有 EHR 集成、理赔/计费系统或医疗保健 API 的经验
  • 有早期创业公司身兼多职的经验
  • 有医疗保健或 RCM 背景
  • 曾担任前沿部署工程师、解决方案工程师或类似的嵌入式工程职位
