摘要

Veritus 在旧金山招聘前沿部署工程师，加入其面向消费信贷与催收的 AI 语音 Agent 平台。该岗位直接对接客户，将需求与合规约束转化为可上线的 Agent，编写后端集成，并基于 OpenAI、ElevenLabs、Deepgram 等平台优化延迟与语音质量。要求 TypeScript 或 Python 经验、API 开发能力及 LLM 相关背景，金融或医疗等强合规行业经验与西班牙语能力为加分项。

要点

  • Veritus 是 YC 孵化的 AI 语音 Agent 平台，专注贷款服务与催收。
  • 岗位需将客户需求与合规约束转化为生产级 AI Agent。
  • 日常工作包括后端集成、A/B 测试与延迟、语音质量调优。
  • 要求 TypeScript 或 Python、API 经验及 LLM 相关背景。
  • 金融、医疗合规经验与西班牙语为加分项。

关于 Veritus

Veritus Agent 正在打造首个完全 AI 原生的语音 Agent 平台，面向消费信贷与催收领域。我们是一支由 YC 支持的团队，领导层来自 Best Egg、PayPal、Divvy 和 Lending Club——我们的使命是用实时 AI Agent 改造传统呼叫中心，实现更高转化率、更低成本和更好的借款人结果。这个机会

我们正在招聘一名前沿部署工程师，帮助我们在从产品市场契合迈向快速增长的过程中扩展 AI 语音 Agent。这是一个动手实践、面向客户的工程岗位，负责将真实世界需求转化为生产级 AI Agent。你将与客户、销售和工程团队紧密合作，完成以下工作：

  • 将客户特定需求和合规约束转化为稳健、可测试的逻辑
  • 编写工具和后端集成，使 Agent 能够与外部系统（API、CRM、支付平台等）对接
  • 使用 OpenAI、ElevenLabs 和 Deepgram 等平台调优延迟、响应速度和语音质量
  • 设计 A/B 测试，以优化业务成果和合规性

如果你符合以下条件，你将在这个岗位上如鱼得水：

  • 拥有使用 TypeScript 或 Python 构建软件的可靠业绩记录
  • 具有构建和使用 API 的经验
  • 有使用 AI 系统、编排框架或 LLM 评测工具的经验
  • 对构建低延迟、可打断的实时语音系统的独特挑战充满热情
  • 受到在金融或医疗等受监管、高信任领域交付可衡量影响的驱动
  • 乐于贴近客户工作，并根据实时数据和反馈快速迭代
  • 希望加入一个高自主性、以执行为导向的团队，解决有意义的问题

加分项

  • 熟悉语音设计、话轮转换和对话系统
  • 有金融服务、医疗保健或其他强合规环境的经验
  • 能流利使用西班牙语
