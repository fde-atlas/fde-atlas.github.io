阶段 1，构建工程化构建智能 AI 系统第 1–4 周

第 01–08 课

第 01 周，第 01–02 课模型与 Agent 运行框架

  • S01：模型、推理、上下文与网关工程快速模型与审慎模型、结构化输出、上下文预算与压缩、缓存、模型路由、成本与提供商抽象。
  • S02：Agent 运行框架、技能与工程效率Pi、AGENTS.md、SKILL.md、插件、渐进式披露、Superpowers、SDD/TDD、独立评审与沙箱执行。

第 02 周，第 03–04 课检索与知识工程

  • S03：高级检索策略文档 AI、多模态解析、词法、向量与混合搜索、重排序、分层与无向量检索、来源追溯、引用与拒答。
  • S04：知识库、知识图谱与 GraphRAG实体、关系、本体、小规模图谱构建、多跳推理、时序事实与图谱辅助检索。

第 03 周，第 05–06 课循环与图谱工程

  • S05：循环工程ReAct、计划-执行-验证、有界目标循环、心跳、定时与事件触发、工具权限边界、预算限制、卡死检测、重试、转向、升级与终止。
  • S06：图谱工程与自适应 Agent 拓扑LangGraph 状态、确定性节点与校验节点、条件边、检查点、人工中断、并行委派、静态与自适应图谱以及 A2A 概念。

第 04 周，第 07–08 课记忆、评测与优化

  • S07：记忆与长上下文工程工作记忆、情景记忆、语义记忆与程序性记忆、整合、压缩、矛盾处理、修订、过期、删除与投毒防御。
  • S08：Agent 评测与神经符号验证任务与轨迹评测、校准的评判模型、工具操作正确性、属性测试、确定性不变量、Z3 约束以及评测驱动的优化（GEPA）。

第 2 阶段：连接集成企业数据与系统第 5–8 周

第 09–16 课

第 05 周，第 09–10 课企业上下文与受治理的数据访问

  • S09：企业数据发现与 Agent 就绪的数据访问数据资产、元数据发现、所有权、血缘、权限、目录、API、数据库、数仓访问与合成数据环境。
  • S10：企业上下文、语义与本体工程规范实体、跨系统身份映射、业务词汇表、语义指标、实体关系、数据源优先级与知识来源追溯，并简要介绍 Apache Ossie 与元数据感知 AI。

第 06 周，第 11–12 课AI 原生数据工程与存储

  • S11：智能多模态摄取与数据契约基于 LLM 的提取、分类与富化、确定性转换、模式校验、AI 数据契约、异常处理、血缘、新鲜度与删除传播。
  • S12：AI 存储架构与知识生命周期关系型、向量与图存储、湖仓与数仓集成、索引策略、租户感知过滤、增量更新、重新嵌入、版本管理、保留策略与安全迁移。

第 07 周，第 13–14 课企业级 SQL Agent 与 AI 分析

  • S13：基于语义层的 SQL Agent元数据引导的 Schema 发现、业务指标定义、文本转 SQL、查询分解、SQL AST 校验、Schema 与列级授权、只读执行、查询预算以及执行准确率评估。
  • S14：跨结构化与非结构化数据的分析智能多步骤分析规划、沙箱化 Python 计算、数据仓库与湖仓访问、图、SQL 与向量推理、来源归因、数值对账以及分析评估。

第 08 周，第 15–16 课企业能力集成与主动式 AI 工作流

  • S15：面向 Agent 的企业 API、MCP 与连接器将现有 API 转化为安全的 Agent 能力、OpenAPI 到 MCP 的适配、技能与插件、类型化工具契约、范围化权限、需审批的操作、幂等性与连接器治理，并简要介绍浏览器与计算机操作的回退方案。
  • S16：事件驱动、主动式与可恢复的 Agent 工作流Webhook、调度、CDC、事件触发的循环、异步执行、知识新鲜度、重复事件、重试、死信处理与恢复。

第 3 阶段：交付安全部署、运营并展示价值第 9–12 周

第 17–24 课

第 09 周，第 17–18 课AI 运营、受控试点与安全发布

  • S17：可观测性、持续质量与 AI FinOpsOpenTelemetry 与 OpenObserve、模型、Agent 与工具追踪、任务质量、漂移、每次成功任务的成本、租户与功能归因、预算、SLO 以及符合 FOCUS 的成本报告。
  • S18：渐进式自主、模型迁移与安全发布影子执行、人工审批与范围化自主执行、OpenFeature 与 flagd、基于评测的金丝雀发布、提示词、模型与技能版本管理、回滚、发布清单、技术 UAT 与事故恢复。

第 10 周，第 19–20 课身份、可信执行与安全

  • S19：企业身份与 Agent 授权OIDC、SAML 与 SCIM、authentik、范围化与委托凭证、用户到工具的归因、MCP 授权、企业管理的授权、RBAC 与 ReBAC，以及网关策略控制。
  • S20：Agentic 安全与 AI 供应链OWASP LLM、Agentic 与 MCP 风险、恶意技能与插件、记忆投毒、工具提权、沙箱边界、PII、模型来源、已批准的能力以及 AI 材料清单。

第 11 周，第 21–22 课模型服务与运营应用

  • S21：模型选择、优化与服务托管模型与自托管模型、主权模型与印度语言模型选项、提示词优化、RAG 与微调、量化、KV 缓存、批处理、vLLM 与推理经济学。
  • S22：可部署的 AI 应用与 Agent 到用户的界面生产服务拓扑、持久化执行、容器、AG-UI、MCP Apps、流式进度、人工审批、异常处理以及托管与自托管运行时。

第 12 周，第 23–24 讲分布式 AI 系统与扩展

  • S23：扩展与隔离 Agent 工作负载无状态服务与持久化状态、工作节点、Kubernetes Pod、队列、KEDA、安全的代码执行、沙箱隔离、资源限制与故障恢复。
  • S24：分布式推理与容量工程模型感知路由、KV 缓存复用与卸载、分离式推理、SGLang、llm-d、Dynamo、驻留、可用性与成本-容量架构。

除周末课程外，还将在预先告知的工作日安排行业领袖讲座和答疑解惑环节。

课程内容和时间表可能会有所改进。随着课程的丰富，部分模块、主题或其顺序可能会发生变化，但核心学习目标保持不变。
