Razorpay FDE（前沿部署工程师）：职位、技能与准备

原标题：Razorpay FDE (Forward Deployed Engineer): Role, Skills & Prep

FDE India · 2026-10-30 · 约 6 分钟读完

摘要

本文介绍 Razorpay 在班加罗尔招聘前沿部署工程师（FDE）的岗位详情。Razorpay 于 2026 年 3 月在 FTX'26 发布 Agent Studio，一个基于 Anthropic Claude Agent SDK 构建的支付与银行 AI Agent 市场。FDE 需嵌入商户工程团队，负责从售前技术评估、集成架构、Agent 构建（含评测与人工审批流程）到上线后 15–30 天 hypercare 的全流程。岗位要求 3–10 年实际工程经验，明确这不是售前、支持或解决方案架构角色。文章还给出备考建议：构建支付类 Agent、展示跨系统调试能力、掌握 MCP 与 LangChain 等框架。FDE 薪资未公开，可参考其他岗位薪资区间。

要点

  • Razorpay 为 Agent Studio 招聘前沿部署工程师，工作地点班加罗尔。
  • 岗位要求 3–10 年实际工程经验，明确不是售前或解决方案架构。
  • FDE 负责售前评估、集成、Agent 构建与上线后 15–30 天 hypercare。
  • 技能要求：Python 或 Node.js、API、webhook，及 LangChain、MCP 等框架。
  • FDE 薪资未公开，文章建议参考其他岗位薪资作方向性参考。

通往 FDE 的 6 个月路线图。

  • Razorpay 的前沿部署工程师驻扎在班加罗尔的商户工程团队中，将在其 Agent Studio 上构建的 AI Agent 从探索阶段推进到正式上线。
  • 该职位要求 3–10 年动手工程经验，并明确表示这不是售前、支持或解决方案架构岗位。
  • 技能要求：扎实的 Python 或 Node.js 能力，熟悉 API、webhook、认证、数据管道，以及 LangChain、LangGraph、AutoGen 或 MCP。
  • 每次上线后的 15–30 天强化保障期内，FDE 是第一响应人。

班加罗尔支付公司 Razorpay 正在招聘前沿部署工程师，将 AI Agent 落地到商户的业务中。它是少数几家使用 FDE 职位名称的印度产品公司之一，且该职位贴近最初的模式：你与客户的工程师并肩工作，端到端负责集成，并持续跟进直到其在生产环境中正常运行。

为什么 Razorpay 需要 FDE

在 2026 年 3 月的 FTX'26 大会上，Razorpay 发布了 Agent Studio，这是一个面向支付和银行业务的 AI Agent 市场（Razorpay 官方博客将无代码 Agent 构建器列为测试版），据 The Paypers 报道。发布的 Agent 包括通过语音或消息实现的弃购挽回、争议响应、订阅挽回（与 ElevenLabs 合作构建）和现金流预测，并集成了 Shopify、WhatsApp、Shiprocket、Slack 和 QuickBooks。新闻稿称 Agent Studio 基于 Anthropic 的 Claude Agent SDK 构建。

对于大型商户而言，现成的 Agent 作用有限。FDE 就是让这些 Agent 适配特定商户系统的工程师。

FDE 负责什么

Razorpay 的班加罗尔职位列表描述了完整的闭环：

  • 售前探索。 评估集成复杂度以及某个工作流是否适合用 Agent 实现，然后在方案中共同撰写部署计划。
  • 集成生命周期。 与商户工程团队合作，从架构设计到正式上线。
  • Agent 构建。 在 Agent Studio 上进行工具绑定、MCP 集成、编排管道、评测以及人工审批流程。
  • 跨系统调试。 涵盖 Razorpay 系统、商户系统、外部工具以及模型行为。
  • 重点关怀期（Hypercare）。 每次上线后的 15–30 天内担任第一响应人。
  • 让工作可复用。 为共享知识库制定季度部署蓝图，并向产品经理提供结构化反馈。

职位描述明确指出这是嵌入式工程岗位，不是售前、支持或解决方案架构。如果你是解决方案工程师，这一点很重要：你需要证明自己能编写和调试生产代码，而不仅仅是设计。

经验、技能与薪酬

Razorpay 的要求职位描述中的细节
经验3–10 年动手软件工程经验，包括在真实客户环境中发布和调试代码
编程语言精通 Python 或 Node.js；能快速读懂陌生代码并编写胶水代码
系统知识API、webhook、认证、数据管道、日志、生产系统
AI有使用 LLM 或 Agent 框架的实战经验，如 LangChain、LangGraph、AutoGen 或 MCP
客户工作有与外部客户或商户技术团队直接合作的经验

FDE 职位的薪酬未公开。作为参考，FACE Prep 引用聚合网站的估算数据，称 Razorpay 的 ML Engineer 职位年薪约为 ₹25–45 LPA，SDE-1 约为 ₹14–20 LPA，并说明这些仅供参考。这些是不同的职位，因此只能用来大致了解 Razorpay 的薪酬水平。对于印度产品公司 3–6 年经验的 FDE 薪酬，可参考 FDE 薪酬估算器。

如何准备

  • 做一个支付场景的 Agent。 例如，一个 Agent 读取支付失败的 webhook，通过 API 查询订单数据，并发送 WhatsApp 挽回消息，且在任何退款操作前需要人工审批。
  • 展示跨系统边界的调试能力。 准备一个故事：bug 出在别人的系统里，而你通过日志、重试或 webhook 签名不匹配找到了它。
  • 认真学习 MCP 和一个 Agent 框架。 职位描述中提到了 MCP、LangChain、LangGraph 和 AutoGen。要构建工具绑定和评测集，而不只是聊天演示。
  • 练习需求探索。 面对一个商户问题，你能否在 10 分钟内判断它是否适合用 Agent 解决、需要集成哪些系统、可能出什么问题？这就是这份工作中售前的部分。
  • 带上重点关怀期思维。 谈谈监控、回滚，以及你构建的东西上线后的前两周你做了什么。

如果你正从后端工程转型，我们关于产品公司中 FDE 角色如何运作的指南会解释日常工作有何不同。

常见问题

前沿部署工程师在 Razorpay 做什么？

他们与商户的工程团队合作，在 Razorpay 的 Agent Studio 上规划、构建和上线 AI Agent：包括技术调研、集成架构、带工具绑定和评测的 Agent 工作流、跨系统调试，以及上线后 15–30 天的支持。

Razorpay 对 FDE 职位要求多少年经验？

班加罗尔的 FDE 职位要求 3–10 年的软件工程实战经验，包括在真实客户环境中发布和调试生产代码。

应届生能以前沿部署工程师的身份加入 Razorpay 吗？

在我们找到的 FDE 职位中不行。据 FACE Prep 介绍，应届生通常以 SDE-1 或实习生的身份进入 Razorpay，在积累生产经验后可以转向面向客户的工程岗位。

什么是 Razorpay Agent Studio？

一个面向支付和商业银行领域的 AI Agent 市场，于 2026 年 3 月在 FTX'26 上发布，目前提供测试版的零代码 Agent 构建器。Agent 包括弃购挽回、争议响应、订阅挽回和现金流预测，新闻稿称其基于 Anthropic 的 Claude Agent SDK 构建。
