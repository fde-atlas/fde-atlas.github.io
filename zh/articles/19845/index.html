前沿部署工程师 | Sphere | 加州旧金山

原标题：Forward Deployed Engineer | Sphere | San Francisco, CA

Zero G Talent · 2026-04-15 · 约 4 分钟读完

摘要

Sphere 在旧金山招聘前沿部署工程师，负责嵌入战略客户现场，解决跨境税务与合规问题。公司主打 AI 系统 TRAM，用于解读 190 多个司法管辖区的贸易法规并自动完成合规流程，已获 a16z 与 YC 支持，完成 2100 万美元 A 轮融资，客户包括 ElevenLabs、Replit、Deel 等。该职位要求端到端交付定制功能、撰写技术 PRD，并与财务和税务负责人沟通，需熟悉 Python、Django 和 React，须在办公室工作。

要点

  • Sphere 招聘旧金山前沿部署工程师，需驻办公室办公。
  • 核心产品 TRAM 用 AI 处理 190 多个司法管辖区的贸易合规。
  • 公司获 a16z 与 YC 支持，A 轮融资 2100 万美元。
  • 职责涵盖客户接入、需求调研、撰写 PRD 与定制开发。
  • 技术栈为 Python、Django 与 React，重视细节与沟通。

你需要什么

关于 SPHERE

贸易基础设施的每一次突破都遵循同样的模式：降低一项交易成本，扩大市场。集装箱化之于货物，SWIFT 之于货币，Stripe 之于支付。合规是最后也是最大的领域之一——而且是最难的，因为贸易规则不是可以查询的数据。它们是一个复杂的适应系统，涉及 190 多个主权司法管辖区，语言各异，不断变化，并相互影响。

Sphere 构建了解决这一问题的系统。我们的 AI（TRAM）摄取全球贸易法律，对其进行解读，解决跨司法管辖区的冲突，并产出比人类专家更可靠的合规判定。我们以毫秒级延迟和零停机时间处理整个生命周期——计算、登记、申报、汇款。

  • 由 a16z 和 YC 投资。 A 轮融资 $21M，月增长率超过 30%，客户包括 ElevenLabs、Replit、Deel、Runway 和 Lovable。
  • 小团队，全球影响力。每个人负责的领域，在更大的公司里都相当于一个完整的团队。位于旧金山，需到办公室办公。
  • 问题不断叠加。扩展至进项税、预扣税、电子发票、关税——每一项都使复杂性成倍增加。如今是数千万笔交易，未来将是数十亿笔。

职位描述

作为 Sphere 的前沿部署工程师，你将直接深入 Sphere 最具战略意义的客户，了解他们的跨境业务流程，识别影响最大的合规挑战，并设计和交付定制解决方案，使 Sphere 无缝融入他们的运营。

你不只是执行一套既定方案，而是在推进过程中亲自定义它。你将与我们的创始人、工程团队和市场推广团队直接合作，定义 Sphere 在客户环境中的呈现方式，并塑造我们在规模化过程中前沿部署工作的模式。这是一个难得的机会，可以对产品和客户体验都产生巨大影响。

这一职位非常适合那些热衷于端到端负责问题（从发现到部署）、并乐于迎接将复杂的、特定司法管辖区的监管要求转化为优雅的生产级软件这一挑战的工程师。我们寻找的人既能自如地与客户交谈，也能自如地深入代码库，并且在构建内部流程时与解决客户问题时同样严谨。

你的工作内容

赋能

  • 在签约前完成客户入驻，让客户账户在 Sphere 中正常运行
  • 处理客户计费系统的集成
  • 提取并解读税务责任报告，帮助客户了解其风险敞口
  • 引导客户理解并管理其全球税务责任的复杂性
  • 指导客户完成 VAT ID 收集、地址信息清理以及各地区合规工作

商业化变现

  • 在客户需求与工程路线图之间架起桥梁
  • 通过确保 Sphere 成为客户所有收入合规需求中不可或缺的一环，与客户建立深度绑定
  • 端到端地研究新的合规要求（电子发票、进项税等）
  • 识别客户中的共性模式——哪些定制需求被反复提出
  • 规划并撰写严谨、精炼的技术 PRD/提案，可直接交付给核心工程团队
  • 在 Sphere 平台之上为重要客户构建定制功能与集成
  • 识别可规模化并作为新功能或新产品部署到所有客户的定制开发

任职要求

  • 具备 FDE 或面向客户的工程岗位经验。
  • 具备端到端执行并交付定制客户功能的经验。
  • 主人翁精神。无需他人告知方法，就能把模糊的问题推进到上线交付，全程紧盯客户成果，且不遗漏任何线索。
  • 永葆好奇心。你不会坐等别人指出答案——你会主动去寻找，并且知道何时该请教比你更懂的人。
  • 出色的沟通能力。我们的工作节奏极快，因此清晰、简洁的沟通至关重要。
  • 客户至上。你将与财务领域的许多人打交道（财务总监、财务负责人、税务负责人）。你需要喜欢他们，并为他们倾注心力。
  • 对细节的极致把控。与数字打交道时，这一点不容妥协——99% 的正确率是不够的。

加分项

  • 有处理海量交易数据的经验。你会与它打得非常交道！
  • 熟悉 Python 和 Django。我们的核心应用后端和数据管道服务均使用 Python 和 Django 构建
  • 熟悉 React。我们的整个前端均使用 React 构建。

你是怎样的人

如果你符合以下特质，你将在这里如鱼得水：

  • 你是一条“斗犬”。 你曾被低估，经历过挣扎，却从未停止奔跑。你心怀不甘，动力十足。当你看到 Stripe、Deel 和 Flexport 都在合规领域放弃时，你会想：很好，这意味着机会属于我们。饥饿感胜过出身。
  • 早期创业精神刻在你的骨子里。 你曾在没有现成 playbook、没人给你答案的情况下打造产品。你主动定义问题，而不是等待指令。
  • 你端到端地全权负责。 给你一个目标，你就能自己找到路径。小团队，全球化的业务覆盖面——每个人都负责一个在更大公司里需要整个团队来承担的领域。没人会告诉你该怎么做。
  • 我们相信速度和准确性可以兼得。 我们正在打造一款复杂的产品，需要强大的稳定性和 100% 的在线率，而且我们必须以客户的节奏进行开发。快速行动，但不要破坏东西。两者兼顾。
  • 身处现场是一种特性，而不是成本。 常驻旧金山不是一项政策，而是工作得以完成的方式。我们所需要的协作速度和密度无法通过视频实现。

如果你符合以下情况，这份工作可能不适合你：

  • 你需要别人给你现成的结构，或者模糊性让你感到疲惫而非振奋
  • 你更想管理他人而不是攻克难题（我们是一个扁平化的资深团队——每个人都在动手构建）
  • 你习惯于“差不多就行”的交付方式（在这里，微小的错误会产生巨大的影响）
