摘要

HappyRobot（Y Combinator S23 孵化，累计融资超 2 亿美元）正在巴西招聘前沿部署工程师。该职位要求全栈开发能力与客户沟通能力并重，负责客户接入、实施与持续支持，同时参与产品开发。候选人需熟练使用 React、TypeScript、Node.js 和 Python，具备构建 AI/ML 应用的经验，包括 LLM 提示词设计与语音、转写模型调优，并能管理 API 与第三方系统集成。公司强调无层级文化、极端责任感和快速迭代，提供有竞争力的薪酬、股权及医疗等福利。

要点

  • HappyRobot 在巴西招聘前沿部署工程师，要求技术与沟通能力兼备。
  • 职责涵盖客户接入、实施、支持及功能与 MVP 开发。
  • 技术栈要求 React、TypeScript、Node.js、Python 及 AI/ML 经验。
  • 公司为 YC S23 孵化，融资超 2 亿美元，投资方含 a16z。
  • 文化强调无层级、极端责任感和快速专注执行。

你需要具备的条件

关于 HappyRobot

HappyRobot 是企业构建和编排 AI 劳动力的基础设施。我们的 AI 员工不仅通过语音和电子邮件进行沟通——它们还能自主决策、采取行动，并在整个企业系统中运营业务。我们诞生于 Y Combinator（S23），获得 a16z、Base10、Prysm Capital 和 Eurazeo 的投资，融资总额超过 2 亿美元，为全球企业的关键业务运营提供支持。

我们的平台在最严苛的环境中经受住了考验，在这些环境中，AI 会产生真实的业务影响。我们从物流行业起步，从零开始构建了自己的语音技术栈、模型和编排层，现在正将这一基础设施带给每一个运营实体经济的企业。欲了解更多我们的愿景，请阅读我们的宣言。

职位概述

我们正在寻找一位常驻巴西、多才多艺且技术精湛的前沿部署工程师加入我们的团队。在这一职位中，你将把出色的技术能力与卓越的沟通技巧相结合，直接与客户合作，确保他们充分发挥 HappyRobot AI 平台的价值。你将参与客户入职、实施和持续支持工作，同时也将为产品开发和创新做出贡献。

在 HappyRobot，没有职级或层级之分——我们是一个由建设者组成的团队。我们执行、我们构建、我们负责，并且我们深切关注客户及其成功。

你的工作内容

  • 面向客户的工程工作——从客户入职到持续使用，与客户紧密合作，帮助他们集成和优化我们的 AI 解决方案。
  • 技术开发——构建新功能、MVP 和可扩展的解决方案，直接影响客户成果。
  • 全栈开发——使用 React、TypeScript、Node.js 和 Python 开发强大的应用程序和工具。
  • AI/ML 应用——设计、实现和迭代 AI/ML 解决方案，包括 LLM 提示词工程、语音和转录器的调优，以优化使用场景。
  • 集成与 API——管理 API 以及与第三方系统的集成，确保客户获得无缝的功能体验。
  • 跨职能协作——与产品、工程和客户成功团队合作，交付定制化解决方案。
  • 迭代式问题解决——根据客户反馈和不断变化的需求，持续迭代和改进 AI 解决方案。
  • 项目管理——在紧迫的期限内优先安排并管理多个项目，同时保持高质量的成果。

必备条件

  • 扎实的全栈开发经验：React、TypeScript、Node.js。
  • 熟练掌握 Python 的实际应用。
  • 具备构建 AI/ML 应用的经验，包括 LLM 提示词工程和调优。
  • 能够管理 API 并与第三方系统进行集成。
  • 出色的沟通能力，能够向非技术背景的利益相关者讲解技术概念。
  • 具备在紧迫期限内对多个项目进行优先级排序和管理的成熟能力。
  • 创始人心态：高度独立，勇于担当，在快节奏的环境中如鱼得水。

为什么加入我们？

  • 加入一支世界级的工程师和建设者团队。
  • 获得顶级投资者支持，包括 a16z、Y Combinator、Base10、Prysm Capital 和 Eurazeo。
  • 对项目拥有所有权和自主权，并鼓励快速交付。
  • 全面的福利待遇，包括医疗、牙科和视力保险。
  • 有竞争力的薪资 + 高增长初创公司的股权。

我们的运营原则

极致担当

我们对工作、成果和团队的成功承担全部责任。不找借口，不推卸责任——如果有什么需要改进，我们就主动承担并把它做得更好。这意味着即使不是“你的分内事”，也要挺身而出。如果有人掉了球，我们就把它捡起来。如果客户不满意，我们就去解决。如果流程出了问题，我们就重新设计。我们不会坐等别人来解决——我们以担当引领，并期望身边的人同样如此。

匠心精神

对每一项任务都倾注用心与专注，追求卓越，对工作的质量和成果深度负责。匠心精神意味着绝不满足于“还行”。我们注重细节，因为细节会不断累积。无论是产品功能、内部文档还是销售电话——我们都将其视为自身标准的体现。我们致力于通过保持好奇、一丝不苟，并为我们所构建的东西感到自豪——即使无人注视——来交付令人惊叹的客户体验。

我们是“majo”与同事友好相处，享受共事的乐趣。始终保持真诚坦率，同时心怀善意。“Majo”是我们表达“做一个好人”的方式。平易近人、乐于助人、温暖待人。我们正在打造一项雄心勃勃的事业，如果大家一路同乐，过程会更轻松（也更有趣）。我们带着善意给予反馈，带着尊重相互挑战，毫无自我地共同庆祝胜利。

专注的紧迫感在最短的时间内创造最大的影响。快速行动，但方向要正确。我们以速度运作，因为时间是我们最稀缺的资源。但没有专注的速度就是混乱。我们果断排定优先级，坚决行动，并保持步调一致。我们追求高杠杆：用最简单、最聪明的行动取得最大的成果。我们跑的是一场高速马拉松——而不是毫无策略的冲刺。

人才密度与精英制只招聘能提升团队平均水平的人；“卓越表现只是及格线。”能力胜过资历。我们相信最好的团队建立在人才密度之上——每一次招聘都应提高标准。我们奖励的是贡献，而非头衔或工龄。我们把所有权交给那些赢得它的人，并且我们彼此都以高标准互相要求。顶尖人才希望与其他顶尖人才共事——这就是我们取胜的方式。

第一性原理思维将问题剥离至物理层面的基本事实，无视行业教条，从零开始重建解决方案。我们不复制粘贴现成的方案。我们回归本源，追问事物为何如此，必要时从零重建。这种思维方式推动我们创新、挑战陈旧的假设，并比现有企业行动得更快。这就是我们打造他人认为不可能之物的方法。
