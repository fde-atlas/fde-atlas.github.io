摘要

Luminai 在加州 San Mateo 招聘前沿部署工程师，要求嵌入客户现场，理解医疗机构的业务流程，设计并部署 AI 驱动的解决方案，并将一线洞察反馈给产品团队。职位要求 3-10 年以上软件工程经验，精通 Python，熟悉云基础设施，有 LLM、向量数据库或 Agent 框架经验者优先。团队每周四天到办公室（周三可远程），工作地点为旧金山或纽约。

要点

  • Luminai 招聘前沿部署工程师，聚焦医疗行业客户交付。
  • 职责涵盖端到端部署：需求梳理、方案设计、生产系统与迭代。
  • 要求 3-10 年经验，精通 Python，熟悉 AWS、GCP 或 Azure。
  • 有 LLM、向量数据库、提示工程或 Agent 框架经验者优先。
  • 每周四天到岗，地点为旧金山或纽约，周三可远程。

职位要求

作为一名前沿部署工程师，你将处于工程、产品和客户交付的交汇点。你将直接深入客户现场，深入理解他们的工作流程，设计并部署能够带来即时、真实影响的 AI 解决方案。

这是一个高度自主、亲力亲为的职位，适合在模糊环境中如鱼得水、喜欢直接与客户合作，并希望通过实地所见来塑造产品方向的人。你将与产品团队和工程团队紧密合作，将客户需求转化为可扩展的系统，改善医疗机构的运营方式。

我们的团队每周 4 天在办公室办公（周一至周五，周三可选择远程办公），办公地点位于加利福尼亚州旧金山或纽约州纽约市。

你的工作内容

  • 直接深入客户现场，了解他们的工作流程、限制条件和成功标准
  • 设计、构建并部署针对真实运营问题的 AI 驱动解决方案
  • 构建和维护生产系统，包括 API、集成、监控和反馈循环
  • 将业务需求和客户需求转化为技术架构和具体实现
  • 在可靠性、速度和判断力至关重要的高风险环境中开展工作
  • 识别各客户部署中的共性模式，并将洞察反馈到核心产品和平台的开发中
  • 与产品团队和工程团队紧密合作，影响路线图、抽象设计和长期系统设计
  • 端到端负责部署工作，从最初的范围界定到上线和迭代

我们在寻找什么样的人才

  • 3-10 年以上软件工程经验，最好担任过 FDE 或从事过后端/系统方向的工作。
  • 精通 Python（有 TypeScript / JavaScript 经验者优先）。
  • 有使用云基础设施（AWS、GCP 或 Azure）的经验。
  • 能够将模糊的需求转化为可运行、可用于生产的系统。
  • 出色的沟通能力，能够自如地与技术背景和非技术背景的利益相关者合作。
  • 具有高度的主人翁意识，能够在快速变化的环境中独立开展工作。
  • 有 AI 系统（LLM、向量数据库、提示词工程或 Agent 框架）相关经验者优先。
