高级前沿部署工程师（AI Agent）- 英国 | Cresta

原标题：Senior Forward Deployed Engineer (AI Agent) - UK | Cresta

摘要

Cresta 在英国招聘资深前沿部署工程师（AI Agent 方向）。Cresta 源自 Stanford AI Lab，累计融资超过 2.7 亿美元，投资方包括 a16z、Greylock 和 Sequoia，客户含 United Airlines、Cox Communications、Marriott 等。该岗位负责开发、部署和优化基于 LLM 的 AI Agent，与客户及内部团队协作完成系统集成、性能调优和试点交付，并向产品团队反馈改进路线图。要求 3 年以上软件开发、AI/ML 或 FDE 经验，熟练使用 Python 和 Golang，熟悉 RAG、function calling、云平台和 DevOps。

任职要求

Cresta 释放客户体验的真正潜力，将每一次对话转化为竞争优势。Cresta 的统一 AI 平台结合了对话式 AI Agent、实时人工坐席辅助和全面的对话智能，助力各渠道实现收入与效率的双重提升。包括联合航空、Cox Communications 和万豪在内的全球领先企业，每天都在使用 Cresta 打造世界级的客户体验。

Cresta 源自斯坦福 AI 实验室，已从全球顶级投资者（包括 a16z、Greylock 和红杉资本）处融资超过 2.7 亿美元。Cresta 的领导团队汇聚了当今 AI 领域的顶尖人才。我们的 CEO Ping Wu 在加入 Cresta 之前，曾创立并领导 Google 的 Contact Center AI 和 Vertex AI 平台，如今致力于构建 AI 驱动的客户体验的未来。

在未来几年，AI 将重新定义世界各地的人们每天与企业互动的方式。来 Cresta，一起构建这个未来。

职位介绍：

在 Cresta，AI Agent 团队的使命是打造最先进的 AI Agent，为客户解决实际问题。我们专注于运用大语言模型（LLM）和 AI Agent 系统领域的最新技术，同时确保我们开发的解决方案具备成本效益、安全且可靠。

作为一名 AI Agent 工程师，你将站在部署 AI Agent 以应对现实世界挑战的最前沿。在这一职位上，你将与客户以及我们的软件和机器学习工程师紧密合作，确保高影响力的 AI Agent 部署，并为我们核心 AI 平台的持续改进做出贡献。你将开发智能 AI Agent，将其与外部系统无缝集成，并提供实践性的技术专业知识以确保部署成功。该职位需要出色的工程能力、适应性和客户沟通能力。如果你自我驱动、善于分析，并渴望在实际应用中发挥 AI 的价值，这个职位就是为你准备的。

工作内容：

  • AI Agent 开发： 使用 Cresta 的 AI 平台和工具开发、配置、部署和优化 AI Agent。
  • 系统集成： 构建 AI Agent 与外部系统（API、数据库、CRM 等）的集成，确保工作流程无缝衔接。
  • 性能优化： 优化 AI Agent 性能（例如微调提示词和配置），并在复杂的企业环境中排查问题。
  • 需求收集： 与客户和内部利益相关者协作，收集技术需求，并将业务需求转化为 AI Agent 解决方案。
  • 演示与迭代： 为潜在客户进行互动演示并展示有说服力的概念验证，主动收集反馈，并迭代优化解决方案以达成目标。
  • 项目协调： 定义项目里程碑，制定实施计划，并与内部团队协调执行以确保按时交付。为我们的产品和工程团队提供紧密的反馈闭环——识别差距、构建定制工具，并通过真实部署中的经验影响产品路线图。
  • 跨职能协作： 与产品经理合作定义 AI Agent 目标，根据客户反馈快速迭代，并塑造能最大化客户投资回报的产品能力。
  • 技术指导： 作为客户信赖的技术顾问，指导 AI Agent 落地与使用的最佳实践。就 AI Agent 最佳实践提供技术指导，包括架构设计、安全考量和可扩展性规划。

我们期待的人才：

  • 学历： 计算机科学、工程或相关专业的学士或硕士学位。
  • 经验： 3 年以上软件开发/咨询、AI/ML 工程、系统集成或 FDE 方向的全职工作经验。
  • 编程能力： 熟练掌握 Python 和 Golang，能够编写简洁、高效的代码。
  • AI/ML 知识： 熟悉 AI/ML 概念。有大型语言模型（LLM）和提示词工程技术的实践经验者优先。
  • AI Agent 框架： 深入理解通用 AI Agent 框架、函数调用和检索增强生成（RAG）。有构建此类系统的实践经验者优先。
  • 云与 DevOps： 有云平台（AWS、GCP 或 Azure）和 DevOps 实践（CI/CD、容器化、监控）的经验。
  • 集成专长： 有通过 API、Webhook 和数据管道进行系统集成的实践经验。
  • 沟通能力： 出色的沟通和项目管理能力。
  • 分析思维： 能够运用数据驱动的决策方式（包括 A/B 测试和性能监控）来优化解决方案。
  • 协作型建设者： 你能在跨职能环境中如鱼得水，与产品经理和工程师紧密合作，将真实的客户问题转化为可扩展的 AI 解决方案。

该职位的薪酬包括基本工资、股权以及多种福利。实际基本工资将根据候选人的个人因素确定，包括经验、技能和工作地点，并遵循当地适用的最低工资要求。
