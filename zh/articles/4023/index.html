前沿部署 AI 工程师

原标题：Forward Deployed AI Engineer

IFS Loops Enterprise Agentic AI Platform · 2025-07-22 · 约 2 分钟读完

摘要

TheLoops（IFS 旗下公司）招聘前沿部署 AI 工程师，负责为企业客户设计、部署生产级 AI Agent 解决方案。该岗位要求 2-5 年软件工程或 ML 部署经验，熟悉 Python、LLM 应用、RAG 及企业系统集成，并与产品、工程团队协作反馈客户洞察。

要点

  • TheLoops 是 IFS 旗下企业级 AI Agent 平台公司。
  • 岗位需 2-5 年软件工程、解决方案工程或 ML 部署经验。
  • 职责覆盖从需求发现、原型到配置、测试与上线的全流程。
  • 要求掌握 Python 及 OpenAI、LangChain 等 AI 框架。
  • 需将客户洞察反馈给产品路线图并完成稳定交付。

全文

关于 TheLoops

TheLoops 是 IFS 旗下公司，是首个专为企业级关键任务应用和行业打造的企业级 AI Agent 平台。我们的 AI Agent 如同数字同事，受到治理、安全可靠、持续学习，全天候 24/7 运转，以推动可衡量的业务成果。

随着我们的发展，我们正在寻找有干劲、乐于协作、雄心勃勃的人才，与我们共同开创 AI 驱动运营的未来

关于该职位

作为前沿部署 AI 工程师，你将直接与企业客户合作，交付定制化、可投入生产的 AI 解决方案，解决现实世界中的问题。你将主导智能 Agent 在客户工作流中的设计与部署——从需求探索、原型设计，到配置、测试和上线，全程负责。

这是一个快节奏、注重实操的职位，融合了工程、客户协作和应用 AI。你将成为我们的产品与客户需求之间的关键纽带——确保快速交付价值，并为长期成功奠定基础。

你的职责

  • 与企业客户合作，在复杂工作流中规划并落地 AI Agent 用例
  • 将 TheLoops 平台与客户系统集成
  • 调优 Agent 的行为与逻辑，以交付可衡量的成果（例如降低成本、提升效率、减少错误）
  • 排查部署问题并快速迭代，确保性能、准确性和用户采纳度
  • 与产品、工程和客户成功团队紧密协作，将客户洞察反馈到产品路线图中
  • 记录技术决策，并将稳定的部署移交给客户工程或支持团队

我们期待的条件

  • 2–5 年软件工程、解决方案工程或 ML 部署相关经验
  • 精通 Python，并具备 AI/ML 框架的工作知识（例如 OpenAI、Hugging Face、LangChain、Pinecone、Weaviate 等）
  • 熟悉构建 LLM 应用、RAG 系统或对话式 AI 工作流
  • 具备通过 API 或中间件与企业系统集成（例如 Salesforce、ServiceNow、SAP、Oracle）的经验
  • 能够将业务问题转化为技术解决方案——并快速交付
  • 出色的人际沟通能力；无论与客户在白板前讨论，还是埋头写代码，你都能游刃有余
  • 在动态环境中倾向于行动导向、主人翁意识和持续学习

加分项

  • 具备 SaaS、客户体验、支持运营或制造系统方面的背景
  • 有在关键任务环境中部署 AI 的经验
  • 曾参与企业级 AI 平台或多 Agent 编排的相关工作

为什么加入我们

  • 参与具有真实业务影响力的前沿 AI 解决方案的开发
  • 成为快速成长的团队的一员，共同塑造企业大规模部署 AI 的方式
  • 高度自主权、高曝光度，以及主导变革性项目的机会
  • 有竞争力的薪酬、灵活的工作方式，以及全球企业 IFS 的支持
