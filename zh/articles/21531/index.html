前沿部署工程师（FDE），网络安全 - 纽约 | OpenAI

原标题：Forward Deployed Engineer (FDE), Cyber - NYC | OpenAI

Zero G Talent · 2026-11-06 · 约 6 分钟读完

摘要

OpenAI 在纽约招聘网络安全方向的 FDE。该岗位与客户安全团队（从 CISO 到一线分析师）合作，将前沿 AI 部署到防御系统中，例如跨数十万代码仓库部署补丁、分析 PB 级日志以检测恶意 Agent 和协同攻击。职责包括界定项目范围与成功标准、主导技术设计与实现、构建基于防御决策的评测、指导生产上线，并将成功经验沉淀为可复用工具。要求 5 年以上软件工程经验，具备安全工程、SRE、DevOps 或产品工程背景，有构建和评测 AI Agent 的经验，熟悉 CI/CD。工作模式为每周 3 天到岗，出差比例可达 50%，提供搬迁协助。

要点

  • OpenAI 纽约招聘网络安全方向 FDE，协助防御方大规模部署 AI 系统。
  • 典型场景：跨数十万仓库部署补丁、分析 PB 级日志检测恶意 Agent。
  • 要求 5 年以上工程经验，熟悉安全工程、SRE、DevOps 及 AI Agent 评测。
  • 需构建评测体系、指导生产上线，并将经验转化为可复用工具。
  • 每周 3 天到岗，出差最多 50%，提供搬迁协助。

关于团队

OpenAI 的前沿部署工程团队与客户共同构建，将前沿 AI 带入生产环境。我们的网络安全 FDE 与保卫全球关键系统的安全和工程团队合作，涵盖从企业软件到其运行的核心基础设施。网络安全 FDE 与我们的产品、研究和市场推广团队紧密合作，根据客户保卫系统的需求调整我们的产品和模型。

关于职位

你将构建让防御者在极大规模下获得优势的系统，这种规模很少有工程团队会遇到。你可能需要帮助一家企业在数十万个代码仓库中识别、测试和部署补丁，或者帮助安全团队分析 PB 级日志以寻找恶意 Agent 或协同攻击的迹象。在这些部署中，你将构建客户工程师可以信赖的工具，以支持重大的安全决策。

你将直接与客户安全团队合作，从 CISO 到一线分析师。随着 AI 改变攻击者的运作方式，你将帮助这些团队确定防御体系需要在哪些方面演进、确定构建内容的优先级，并与将运维这些解决方案的工程师一起验证方案。你将与 OpenAI 的客户团队合作，将安全优先事项转化为帮助防御者覆盖更多领域的已部署系统。

你还将帮助塑造 OpenAI 的下一步构建方向。当你发现防御者的需求与当今模型或产品能力之间的差距时，你将与研究和产品团队合作，定义、构建和测试解决该差距的能力。

该职位位于纽约。我们采用每周 3 天到岗的混合办公模式。我们提供搬迁协助。需要出差，出差比例最高可达 50%。

在这个职位上，你将：

  • 与客户安全负责人及 OpenAI 的市场推广团队合作，确定合作范围、明确职责分工，并制定可衡量的成功标准。
  • 与客户工程师共同主导技术设计与实现。将 AI Agent 集成到安全工作流中，设定访问边界，并确定哪些操作需要人工审核。
  • 构建以防御者实际决策为基础的评测。对于补丁 Agent，测试修复方案能否阻止已知漏洞利用，同时保持应用的预期行为。对于检测系统，将历史攻击与正常流量一起回放，以衡量检测速度和误报率。
  • 与将负责运营该系统的工程师一起指导生产环境上线。为他们提供所需的可观测性和控制手段，使其能够理解系统行为、在必要时进行干预，并充满信心地扩大应用范围。
  • 将各次部署中验证成功的方法转化为可复用的工具和工程实践，供其他防御者采用。

如果你具备以下条件，你可能非常适合这个职位：

  • 5 年以上软件工程经验，包括构建和发布生产级软件。
  • 具有通过安全工程、基础设施、SRE、DevOps 或产品工程工作保护生产系统的经验。
  • 具有构建和评测面向软件工程工作流的 AI Agent 的经验。
  • 熟悉 CI/CD 流水线及保持代码质量、可靠性和安全性的相关实践。
  • 能够在陌生的代码库中开展工作，并贡献可维护、生产质量的改动。
  • 能够向工程团队和高级安全利益相关方清晰地传达技术概念与权衡取舍。

其他经验

网络安全涵盖众多领域，虽然我们主要寻找优秀的工程通才，但如果您在以下任一领域拥有更深入的经验，我们非常乐意了解：

  • 安全好奇心与实验精神： 你阅读 CVE 分析文章，是因为你想了解系统是如何被攻破的。你可能构建过 Agent 蜜罐来验证某个假设——或证明某个观点——并乐于将安全问题转化为动手实验。
  • 安全社区参与： 你乐于与防御者交流想法，无论是在 Black Hat 上与 CISO 讨论安全策略，还是与一线从业者比较技术方案。
  • 应用安全： 你编写过 CodeQL 查询或 Semgrep 规则，构建过模糊测试工具，或发现并负责任地披露过漏洞。
  • 自动化修复： CI/CD 是你的快乐源泉。你构建过能在大型代码库中将安全发现转化为经过测试的补丁、依赖升级或配置变更的工具。
  • 检测工程： 你使用 Sigma、YARA、Splunk 或 KQL 编写并部署过检测规则，并针对攻击者行为进行过测试。
  • 云与身份安全： 你曾设计过云 IAM 架构，并调查过工作负载身份、角色层级或跨账户信任的滥用行为。
  • 安全研究： 你曾对恶意软件进行逆向工程、开发漏洞利用复现，或参与过漏洞研究。
  • Agent 安全： 你曾对 AI Agent 进行提示注入、工具滥用或凭据泄露方面的测试，并构建过相应的防御措施。
