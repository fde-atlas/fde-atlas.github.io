前沿部署 AI 工程师，德国 | ICEYE

原标题：Forward Deployed AI Engineer, Germany | ICEYE

Zero G Talent · 2026-10-29 · 约 6 分钟读完

摘要

ICEYE 在德国招聘前沿部署 AI 工程师，隶属前沿部署工程部门，向该部门副总裁汇报。该职位需将 ICEYE 情报平台部署到客户的隔离内网等安全环境，构建融合 SAR 卫星数据与情报文档的 RAG 系统，并用 LangChain、LangGraph 开发 AI Agent。候选人需 3 年以上生产系统经验，精通 Python 及 Go、TypeScript 或 Rust 之一，熟悉 Docker、Kubernetes 与 LLM 应用。职位要求约 50% 时间驻场，需持有德国安全审查（Ü1/Ü2/Ü3）资格并可获得北约许可，且须为驻在国母语人士。ICEYE 总部位于芬兰，拥有全球最大的商业 SAR 卫星星座，员工超 1000 人，服务国防情报、灾害监测等领域。招聘流程包括人才面试、带回家任务、用人经理与团队面试。

要点

  • ICEYE 在德国招聘前沿部署 AI 工程师，约 50% 时间驻客户现场。
  • 核心工作：在隔离内网部署平台，构建融合 SAR 数据的 RAG 系统与 AI Agent。
  • 要求 3 年以上经验，精通 Python 及 Go、TypeScript 或 Rust 之一。
  • 需德国安全审查资格、北约许可，并为驻在国母语人士。
  • ICEYE 总部在芬兰，运营全球最大商业 SAR 卫星星座，员工超 1000 人。

任职要求

  • 3 年以上构建和部署生产级软件系统的经验
  • 精通 Python，并掌握 Go、TypeScript 或 Rust
  • 具备 LLM、提示词工程和 RAG 的实际动手经验
  • 在安全、隔离、物理隔离（air-gapped）环境中进行 Docker 部署
  • 具备 Linux 和基础 Kubernetes 操作经验

工作内容

  • 将 ICEYE 平台部署到客户的安全环境中
  • 构建将 SAR 数据与情报文档相结合的 RAG 系统
  • 使用 LangChain 和 LangGraph 框架开发 AI Agent
  • 创建面向多源情报工作流的数据融合管道
  • 与分析师和军事操作人员嵌入式协作

职位亮点：

  • 职位： 前沿部署 AI 工程师
  • 部门： 前沿部署工程
  • 地点： 德国

  • 必须具备获得相关国家级和 NATO 安全审查的资格与能力
  • 必须常驻部署所在国，并具备该国家语言的母语水平。

前沿部署 AI 工程师的使命

在这一职位上，你将是国防和情报客户所依赖的动手型 AI 构建者。你将把 ICEYE 的情报平台部署到安全（通常是物理隔离）的环境中，并在此基础上快速交付 AI 驱动的工作流——从基于 Docker 的部署到将 SAR 影像与情报报告融合的 RAG 系统。这是一个每天都要交付代码的岗位：将原始卫星数据转化为分析师用于守护国家安全的关键任务工具。

关于我们

ICEYE 是全球太空主权情报领域的领导者。我们提供持续监测能力，用于探测和响应地球上任何地点的变化。

ICEYE 拥有全球最大、最先进的 SAR（合成孔径雷达）卫星星座。我们为客户提供无与伦比的质量、时延和重访周期，全天候、昼夜不间断。对于选择自主运营星座的政府，我们将这一经过验证的能力作为主权系统提供。

ICEYE 构建的星座服务于国防与情报、环境监测、保险和应急管理领域的客户。我们助力快速决策，共创更安全的未来。

ICEYE 创立于并总部位于芬兰，在全球范围内开展业务，拥有 1000 多名员工，遍布欧洲、北美、中东和亚太地区。

日常工作职责：

平台部署与集成

  • 将 ICEYE 的情报平台部署到客户的安全环境中（本地部署、物理隔离网络、涉密数据中心）。
  • 构建和维护容器化应用（Docker），并在客户的 Kubernetes 集群中管理部署。
  • 开发 API 和数据管道，将 ICEYE 系统与客户的 C4ISR 基础设施和情报工具相连接。
  • 在无外部互联网访问的隔离环境中排查部署问题。

AI 解决方案开发与定制

  • 构建检索增强生成（RAG）系统，将 ICEYE SAR 数据与客户情报文档相结合，实现具备上下文感知能力的分析。
  • 使用 LangChain、LangGraph 或类似工具等框架开发 AI Agent 和工作流，以自动化分析任务。
  • 实现提示词工程策略和对话式 AI 界面，使分析师能够使用自然语言查询卫星数据。
  • 创建模型上下文协议（MCP）集成，将 AI 系统与客户数据源连接起来。

数据融合与情报工作流

  • 构建数据融合管道，将 SAR 影像与其他情报来源（AIS、射频信号、光学影像、SIGINT）相结合。
  • 开发自动化工作流，对不同数据模态的信息进行关联和交叉比对。
  • 创建根据客户作战需求定制的轻量级工具、仪表板和告警系统。

客户沟通与快速原型开发

  • 与情报分析师、数据科学家和军事操作人员深度协作，理解关键任务问题。
  • 快速构建 AI 驱动的解决方案原型（先实现功能，后打磨细节），以应对紧迫的作战需求。
  • 就平台能力和 AI 工作流的使用开展实操培训。
  • 收集客户反馈，并将其转化为 ICEYE 产品和工程团队的技术需求。

我们期待的人才

必备技能：

  • 3 年以上软件工程实操经验，构建和部署过生产系统。
  • 精通 Python 编程（必需），并掌握以下至少一门语言：Go、TypeScript 或 Rust。
  • 具备 LLM、提示词工程和 RAG 系统的实操经验。
  • 熟悉 Agent 框架（LangChain、LangGraph、pydantic-ai）和向量数据库。
  • 具备 Docker 经验，以及在安全/隔离/物理隔离（air-gapped）环境中部署的经验。
  • 具备 API、数据管道以及生产环境中系统集成方面的实践经验。
  • 熟悉 Linux 和基本的 Kubernetes 操作。
  • 具备构建者思维：快速交付、根据反馈迭代，优先考虑可用的解决方案而非完美的架构。
  • 沟通能力和客户沟通能力强，能够与情报分析师/军事操作人员深度协作。
  • 英语口语和书面能力强，能够向非技术背景的利益相关者解释技术概念。
  • 愿意因前往区域内客户现场而出差 40%–60% 的时间。

加分技能：

  • 具有国防、情报或政府业务环境的工作经验。
  • 具有本地数据中心部署和/或隔离网络（air-gapped）部署经验。
  • 熟悉地理空间数据、卫星影像或遥感技术。
  • 具有 MCP 集成、多 Agent 系统或 Agentic 工作流的经验。
  • 更深入的 Kubernetes、IaC（Terraform/Ansible）和/或离线 CI/CD 经验。
  • 理解情报分析工作流程以及国防/政府需求。
  • 具有数据融合、多源情报集成或 GIS 工具（ArcGIS、QGIS）的使用经验。
  • 具有解决方案工程、技术咨询或客户成功方面的背景。
  • 具有国防科技领域经验（如 Palantir、Anduril、Scale AI 或类似初创公司）。

在 ICEYE 工作

在 ICEYE，你将加入一个多元化且高度投入的团队，大家怀着共同的抱负：让不可能成为可能。作为一家全球性的规模化成长企业，我们将速度与雄心相结合，并让你从第一天起就能真正承担起责任。你的成长、健康与成功是我们的优先事项，我们提供持续的职业发展、培训机会，以及以协作为制胜之道的文化。

我们的工作方式（我们的价值观）

让不可能成为可能： 我们设定远大目标，并在压力下保持冷静。当事情变得艰难时，我们展现出坚韧、乐观和担当，并不断前行，直到找到出路。

  • 保持好奇： 深入钻研，提出问题，认真倾听，批判性思考。理解决策背后的“为什么”。
  • 放眼全局： 密切关注公司各处的动态，以便做出更好的决策。思考你的工作如何影响他人。
  • 推动高效协作： 营造心理安全感，邀请不同的观点，打造包容的团队。没有糟糕的问题。
  • 像一个团队一样行动： 我们共同获胜。我们将任务匹配给最合适的人，并随着优先级的变化保持敏捷。
  • 享受乐趣： 我们所做的事情意义重大——而且过程应该是愉快的。庆祝进步，为成果感到自豪，分享胜利的喜悦。
