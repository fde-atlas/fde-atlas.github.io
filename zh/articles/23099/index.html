前沿部署工程师 | OpenRouter | 加州旧金山

原标题：Forward Deployed Engineer | OpenRouter | San Francisco, CA

Zero G Talent · 2026-06-01 · 约 5 分钟读完

摘要

OpenRouter 在旧金山招聘前沿部署工程师，隶属售后团队，负责帮助客户完成技术接入、生产落地与用量扩展。该岗位需常驻湾区，深入客户工程团队调试集成、优化模型路由与成本，并将客户反馈转化为产品改进。要求四年以上技术型客户岗位经验，熟悉 LLM 推理与生产级 AI 应用。

要点

  • OpenRouter 提供统一 API 接入数百个 AI 模型，该岗位属售后团队。
  • 职责涵盖技术 onboarding、调试集成、模型与路由策略建议。
  • 需定期到客户办公室工作，岗位强制要求常驻旧金山湾区。
  • 要求四年以上 FDE、解决方案工程师等面向客户的技术经验。
  • 入职 90 天内需独立负责客户技术成功并推动生产用量增长。

职位要求

此职位必须位于旧金山湾区（加州）

关于 OpenRouter

OpenRouter 是 AI 推理的统一接口，让开发者和组织能够通过单一 API 访问数百个模型。我们的平台帮助团队在不同提供商之间选择、路由、评测和扩展模型使用，让构建生产级 AI 应用时更容易为每个用例选择合适的模型。

随着推理成为现代软件公司的核心运营层，OpenRouter 帮助客户更快地推进、降低复杂度，并从快速演进的模型生态系统中获得更多价值。

关于该职位

我们正在寻找一位前沿部署工程师加入我们的售后团队，帮助客户成功实施、采用并扩展 OpenRouter。

该职位处于客户成功、支持、客户工程、产品和开发者关系的交汇点。你将在销售完成后直接与客户合作，帮助他们快速上线、将 OpenRouter 集成到生产系统、改进推理架构，并在团队和应用中扩大使用规模。

你将与开发者深度协作、亲自动手。你将调试集成问题、设计实施方案、就模型和路由策略提供建议、发现提升采用率的机会，并将客户经验转化为产品反馈。理想的候选人需要具备足够的技术能力以赢得工程团队的信任，具备足够的商业敏感度以理解客户成果，并具备足够的主动性以推动客户从初始实施走向规模化生产使用。

该职位要求能够定期前往旧金山湾区各客户的办公室工作，并可能根据需要前往其他地点出差。

你的工作内容

客户实施

  • 在合同签订后主导新客户的技术入职，帮助他们从启动阶段走向生产使用。
  • 与客户成功经理和客户经理合作，制定成功计划、实施里程碑和技术采用目标。
  • 帮助客户将 OpenRouter 集成到他们的应用、工作流、基础设施和开发者环境中。
  • 排查 API、SDK、模型选择、路由、延迟、可靠性和部署方面的问题。
  • 针对常见客户场景创建实施指南、参考架构、代码示例和可复用的操作手册。

推理采用与优化

  • 与客户合作，了解他们的 AI 用例、应用架构、流量模式和推理目标。
  • 根据客户需求推荐模型、供应商、路由、回退、缓存及成本优化策略。
  • 分析使用模式，发现提升采用率、改善可靠性、降低成本或拓展新工作负载的机会。
  • 帮助客户从质量、延迟、成本、可靠性、隐私和规模需求等维度评估模型与供应商。
  • 推动客户从最初的 API 使用走向跨团队、跨应用的更广泛的生产部署。

技术与开发者互动

  • 与客户开发者、工程负责人、AI 团队及平台团队建立稳固的技术关系。
  • 主持技术工作会、集成评审、架构讨论及开发者赋能培训。
  • 为构建 AI 原生产品、AI Agent、内部工具及生产级 LLM 工作流的客户担任可信赖的技术顾问。
  • 将复杂的技术概念转化为面向开发者和业务利益相关方的实用指导。
  • 在公司内部为开发者需求发声，帮助改善客户的实施体验。

跨职能协作

  • 与客户成功团队紧密合作，提升留存率、采用率、客户健康度及业务扩展。
  • 与销售团队协作，把握技术扩展机会，推动战略性客户增长。
  • 与产品及工程团队合作，反馈客户意见、功能需求、集成障碍及产品缺口。
  • 为内部知识库、客户操作手册、上手材料及最佳实践贡献力量。
  • 帮助定义 OpenRouter 优秀的售后技术互动应有的样子。

我们期待的人才

  • 在技术类面向客户的岗位拥有 4 年以上经验，例如前沿部署工程师、解决方案工程师、解决方案架构师、技术客户经理、开发者布道师或客户工程师。
  • 扎实的软件工程基础，能够阅读、编写并调试生产级代码。
  • 具备使用 API、SDK、云基础设施、开发者平台或 AI/ML 基础设施的经验。
  • 熟悉 LLM、推理、模型评测、提示词工程、AI Agent、延迟/成本权衡及生产级 AI 应用模式。
  • 能够直接与开发者及工程负责人合作，诊断问题并设计切实可行的解决方案。
  • 敏锐的客户直觉：懂得如何推动成果、应对不确定性并建立信任。
  • 出色的书面与口头沟通能力，尤其擅长向混合背景的受众讲解技术话题。
  • 高度的主人翁意识、行动导向，并能适应快速发展的创业环境。
  • 能够定期到客户现场工作，并根据需要出差前往客户所在地。

加分项

  • 有使用 OpenAI 兼容 API、模型路由、评测、可观测性或 LLM 应用框架的经验。
  • 在 API、基础设施、开发者工具或 AI 公司拥有客户成功、售后工程或实施岗位的经验。
  • 有构建 AI Agent、聊天产品、Copilot、自动化工作流或生产级 LLM 应用的经验。
  • 熟悉 Python、TypeScript、REST API、流式 API 以及常见的后端应用架构。
  • 有与企业客户、初创公司或技术创始人合作的经验。
  • 能够创建技术内容，例如指南、演示、示例代码库、迁移文档或架构图。

成功的标准是什么

在入职后的前 30 天，你将学习 OpenRouter 的产品、客户群体、实施模式和售后流程。你将旁听客户通话，了解常见的集成路径，并开始支持客户入驻。

在入职后的前 60 天，你将独立主导技术实施工作流，帮助客户解决集成障碍，并为客户入驻和产品采用贡献可复用的技术资产。

在入职后的前 90 天，你将负责一批售后客户的技术成功，推动生产使用量的可衡量增长，识别扩展机会，并在客户、客户成功、产品和工程团队之间建立反馈闭环。

如果你符合以下条件，你将是非常合适的人选

  • 你喜欢贴近客户，解决现实世界中的实施问题。
  • 帮助开发者更快交付、构建更好的 AI 产品会让你充满干劲。
  • 你既能深入技术细节，又能始终聚焦业务成果。
  • 你喜欢在代码、客户沟通、产品反馈和采用策略之间灵活切换。
  • 你能从容应对不确定性，能够把反复出现的客户问题转化为可扩展的系统、操作手册和产品洞察。
  • 你相信推理正在成为软件的基础层，并希望帮助客户成功地采用它。

如果你认为自己不完全满足以下所有条件，但仍然对这份工作感兴趣，请尽管申请。没有人能符合所有要求，我们寻找的是渴望加入团队的人。
