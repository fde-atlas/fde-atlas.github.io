前沿部署软件工程师 | ConductorAI

原标题：Forward Deployed Software Engineer | ConductorAI

Zero G Talent · 2026-06-11 · 约 3 分钟读完

摘要

ConductorAI 在华盛顿特区招聘前沿部署软件工程师，服务于美国政府合同下的涉密项目。该职位要求入职时持有有效的 DoD Top Secret/SCI 安全审查并具备美国公民身份，需两年以上软件工程或前沿部署工程经验，熟练使用 Python 和 TypeScript。工作内容包括驻场配置与支持软件、收集用户反馈并转化为产品需求、编写生产级代码、构建基于 LLM 的平台功能，以及向非技术受众讲解技术方案。国内及海外差旅最多占 40%。年薪范围为 15 万至 22 万美元，持有 TS/SCI 审查者可获更高薪酬，另有与 Series A 阶段相称的股权。公司产品用 AI 帮助大型组织应对流程与合规事务。

要点

  • ConductorAI 招聘前沿部署软件工程师，工作地点为华盛顿特区。
  • 硬性要求：美国公民身份及有效的 DoD TS/SCI 安全审查。
  • 需两年以上经验，掌握 Python 与 TypeScript，熟悉 LLM 应用。
  • 职责涵盖驻场支持、用户反馈转化、生产代码编写与技术演示。
  • 年薪 15 万至 22 万美元，含股权，差旅最多 40%。

你需要具备的条件

简介

我们看重在管理复杂性、独立工作方面拥有丰富经验，并被难题所激励的候选人。

我们提供什么

  • 有机会对关键任务工作流程产生真正的影响
  • 有机会使用最先进的技术与任务合作伙伴一起解决新问题
  • 随着公司成长，有机会通过时间来定义你的角色
  • 有竞争力的薪酬和股权上涨空间，并根据影响力进行年度绩效调薪

职位概述

作为一名前沿部署工程师，你将处于工程与客户合作的交汇点。你将定期驻场于客户现场，建立信任、诊断需求，并将用户反馈直接转化为产品改进。你本质上仍然是一名工程师：你将编写代码、调试系统，并帮助塑造一个旨在利用 LLM 和现代 AI 应用技术的平台架构。但你在客户简报室里和在终端里同样自如。

这一职位适合那些认为掌控完整闭环令人充满干劲的人：理解问题、构建解决方案、部署上线，并实时观察它为用户创造价值。你应该能够从容应对模糊性，倾向于采取行动，并为你所交付成果的质量和可靠性感到自豪。你将在一个小型、紧密协作的团队中工作，并需要向技术熟练程度不一的用户和利益相关者清晰地传达复杂的技术概念。

作为早期团队成员，你还将帮助塑造我们的文化、流程和产品方向。我们期望你以影响力而非工作量来衡量你的工作。

工作地点

华盛顿特区地区。需在国内及美国境外（OCONUS）出差，出差比例最高可达 40%。

主要职责

  • 驻场客户环境，配置、优化和支持 ConductorAI 软件，包括针对特定客户用例定制工作流程以及排查系统问题
  • 在小型工程团队中编写和维护生产级质量的 Python 和 TypeScript 代码
  • 直接与用户合作，收集反馈、了解工作流程，并将洞察转化为可执行的产品需求
  • 根据真实客户使用情况，调试并提升系统的可靠性、性能和易用性
  • 为新客户和现有客户构建并交付技术演示
  • 与产品和工程团队协作开发新功能，从客户需求到交付能力形成直接闭环
  • 发现自动化手动流程的机会，提升客户现场的运营效率
  • 作为核心团队成员，在公司成长过程中参与公司战略、文化建设及职责演进

任职资格

  • 入职时须持有有效的国防部绝密/SCI（TS/SCI）安全许可；此要求源于美国政府合同下涉密工作的性质
  • 根据适用的联邦法律和政府合同义务（ITAR/EAR），须为美国公民；我们无法考虑绿卡持有者，也无法为该职位办理签证担保
  • 2 年以上专业软件工程或前沿部署工程经验
  • 精通 Python 和 TypeScript
  • 具备以技术身份直接与最终用户或客户合作的经验
  • 出色的书面和口头沟通能力，包括能够向非技术受众讲解技术概念
  • 能够在模糊、快节奏的环境中高度自主地开展工作
  • 具备大语言模型（LLM）和现代 AI 应用技术方面的经验
  • 能够接受最高 40% 的国内及海外（OCONUS）出差

优先资格

  • 持有有效的 TS 或 TS/SCI 安全许可
  • 具有国防、情报或国家安全领域的工作经验
  • 具有早期初创公司或快节奏、模糊环境的工作经验
  • 具备系统设计或全栈开发背景
  • 与国防部或民政机构利益相关方已有合作关系

薪酬待遇

该职位的基本薪资范围为 150,000–220,000 美元，并提供与 A 轮融资阶段相匹配的可观股权机会。持有有效 TS 或 TS/SCI 安全许可的候选人可能获得该范围较高水平的薪酬。起薪将根据资历、经验和所在地确定。该范围仅反映基本薪资，不包括股权或其他薪酬组成部分。
