前沿部署工程师实习生 | Netter | 法国巴黎

原标题：Forward Deployed Engineer Intern | Netter | Paris, France

Zero G Talent · 2026-11-18 · 约 2 分钟读完

摘要

Netter 在巴黎招聘前沿部署工程师实习生，面向应届毕业班学生，月薪 3,000 欧元，表现好可转正。实习生将全程负责一个客户项目：从需求定义、数据接入、模型部署到帮助客户独立使用平台，并把客户反馈带回产品团队。要求掌握 Python 和 SQL，能与客户直接沟通并解释取舍；有 Palantir、BCG X 或咨询公司实习经历、API、数据管道或应用机器学习经验者优先。Netter 平台为中型企业集中整理数据，部署分析、工作流和机器学习管道，客户案例包括养老院集团的欠款催收自动化、物流公司的空载路线优化和零售连锁的客户分群营销。

要点

  • Netter 在巴黎招聘前沿部署工程师实习生，月薪 3,000 欧元，可转正。
  • 实习生全程负责客户项目：需求定义、数据准备、模型部署与客户赋能。
  • 要求 Python、SQL 能力和与客户沟通、解释取舍的软技能。
  • 有 Palantir、BCG X 或咨询实习及 API、数据管道经验者优先。
  • Netter 为中型企业整合数据，部署分析、工作流与机器学习管道。

你需要具备

  • 工程、分析或数据科学专业的应届毕业年级学生
  • 使用 Python 和 SQL 探索不熟悉的数据
  • 与客户沟通并解释权衡取舍
  • 有 API、数据管道或应用机器学习方面的经验
  • 以解决问题的方式构建更优方案

你将要做的事

  • 负责一个客户项目，从需求发现到上线落地
  • 在 Netter 上准备数据并部署首批模型
  • 帮助用户在平台上实现自主使用
  • 与产品团队分享客户洞察

数据与 AI 部署 | 巴黎 仅限应届毕业年级实习 | 之后有机会转为全职

你的职责

  • 在 Netter 工程师的支持下，负责一个客户项目，从需求发现到上线落地。直接与业务团队合作，明确问题所在以及成功的标准。
  • 在 Netter 上准备并接入客户数据，构建并部署首批模型，帮助用户在平台上实现自主使用。
  • 将从客户那里学到的经验带回产品团队，以改进平台。

必备条件

  • 你喜欢在技术与商业的交汇处工作。工程、分析背景，或就读过 X-HEC Data Science for Business 之类的项目，都非常契合。
  • 你能使用 Python 和 SQL 探索不熟悉的数据并验证想法。
  • 你乐于弄清楚问题为何无法解决，并构建更好的解决方案。
  • 你能自如地主导与客户的对话，解释权衡取舍并商定后续步骤。

加分项

  • 曾在 Palantir、BCG X 或咨询公司实习，并直接与客户合作开展数据或技术项目。
  • 曾为他人构建过工具，无论是在初创公司、学生项目还是个人独立完成。
  • 有 API、数据管道或应用机器学习方面的经验。

不适合的情况

  • 你更倾向于几乎没有客户接触的纯内部岗位。

薪酬

  • 每月 3,000 欧元。

关于 Netter

Netter 将传统中型市场的数据进行集中和结构化处理，以部署分析、工作流和机器学习管道。- 一家养老院集团此前在多个互不连通的工具中手动追讨未付发票。Netter 集中化了催收工作流，自动发送提醒，实现实时可视化和任务分派。- 一家物流运营商的卡车经常空驶。Netter 连接了他们的 TMS、ERP 和车队数据，并自动化了路线和装载优化。油耗更低，利润率更高。- 一家零售连锁店多年来积累了大量闲置的会员卡数据。Netter 将其与公开人口统计数据交叉比对，构建了精准的客户细分，并向合适的人群推送合适的促销活动。
