Hamza Farooq 在 Maven 上开设的前沿部署工程训练营

原标题：Forward Deployed Engineering Bootcamp by Hamza Farooq on Maven

Maven Learning, Inc · 2026-11-14 · 约 4 分钟读完

摘要

Hamza Farooq 在 Maven 开设的前沿部署工程训练营，面向 AI 工程师、软件工程师和产品经理，讲授端到端构建与部署 Agentic RAG 及多 Agent 系统。课程含 7 次直播、10 次答疑、4 个项目和演示日，学费 2,750 美元，学员可获 Claude Certified Architect 认证考试资格及免费的实时语音 Agent 专题工作坊。

要点

  • 定位 FDE 为 AI 时代的新护城河，强调全栈自主可控以降低延迟与成本。
  • 课程覆盖 ReAct Agent、多 Agent 拓扑、MCP/A2A、评测与安全防护。
  • 技术细节包括 GPTQ、QLoRA、KV 缓存、推测解码等推理优化手段。
  • 要求 Python、GitHub 与 Claude Code 订阅，熟悉 MERN 栈者优先。
  • 学费 2,750 美元，11 月 14 日至 12 月 19 日开课，提供 Maven 保障。

掌握构建、优化和部署端到端智能体 RAG 系统与多智能体工作流的高级技术

  • 工程化构建具备结构化追踪、决策审计、记忆和终止控制的 ReAct 智能体。
  • 实现感知-思考-行动循环、规划智能体、反思机制和工具使用架构。
  • 构建生产级 Agent Harness，并剖析 Claude Code 在模型之外强大能力的来源。
  • 以可预测的延迟、更低的成本和经得起推敲的基准测试来服务生产级 LLM。
  • 精通 GPTQ、GGUF、QLoRA、AWQ、prefill、decode、KV 缓存和投机解码。
  • 衡量 TTFT、词间延迟、吞吐量以及每种部署选择的经济效益。
  • 构建真正具备推理能力的检索系统，而不是简单地把单次向量查询拼接到提示词上。
  • 添加语义缓存和知识图谱，实现既快速又有据可依的混合记忆。
  • 将你的流水线扩展到 potentially 数百万份文档而不崩溃。
  • 设计具备清晰拓扑结构、通信协议和运维判断力的多智能体系统。
  • 为真实用例实现编排者-工作者、层级式、辩论式和交接式工作流。
  • 使用 MCP 和 A2A 连接智能体，并评估何时单智能体系统是更优选择。
  • 交付具备可衡量质量、分层安全和生产级评测循环的智能体系统。
  • 实现 Llama Guard、NeMo Guardrails、数据校验和提示词注入防御。
  • 使用黄金任务、部分得分评分和 LLM 评审打分来构建基于轨迹的评测。
  • 将你的产品拆分为独立的服务（应用、推理、检索、工作进程），各自独立扩展。
  • 将 React 前端、Node.js 后端和 AI 后端整合为一个无缝的产品。
  • 把一个项目从空仓库带到上线部署、能处理真实流量的产品，而不是一个演示。
