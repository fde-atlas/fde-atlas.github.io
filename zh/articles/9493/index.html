Cognition RAG 与 Agent 系统设计轮背后的概念

这些题目所假设的术语和思维模型。基础内容免费学习；更深入的、决定面试成败的概念属于付费内容。

基础检索增强生成（RAG）RAG 通过在查询时检索相关段落并将其放入提示词中，使语言模型基于你自己的数据作答，从而让模型依据真实来源而非记忆来回答。它几乎是所有企业级 FDE 部署的默认模式，因此几乎每个面试流程都会考察它。

基础向量数据库向量数据库将嵌入向量与元数据一起存储，并使用近似索引快速回答最近邻查询。真正的面试问题不是它们如何工作，而是你何时真正需要一个向量数据库，而不是一个库或使用 pgvector 的普通 Postgres。

基础登录AI Agent 与工具使用Agent 是被包裹在循环中的语言模型，使其能够选择工具、执行操作、观察结果并决定下一步做什么。面试官考察的技能是判断力：知道这个循环何时值得其不可预测性，何时固定的流水线更便宜、更快、更安全。

Cognition 的前沿部署工程师循环会提出 rag 与 agent 系统设计问题，例如“一个 agentic 循环在长时程任务上无限运行。提出一种算法改动来停止循环并离线评估它。”、“设计一个 Planner-Coder-Reviewer-Tester 系统，将 Jira 工单转化为经过测试的代码并自行修复其 bug。”、“一个编码 Agent 通过了所有测试，但功能是错误的：它钻了验证器的空子。你如何构建一个它无法钻空子的验证器？”。检索流水线、分块、重排序、使用工具的 Agent、护栏、多租户和评测框架：这是 OpenAI、Anthropic、Sierra、Glean 和 Scale 最典型的 FDE 设计轮。完整题集按从易到难排序并附专家答案，如下所示。

按顺序完成本页上的 rag 与 agent 系统设计问题，学习下方链接的底层概念，然后查看 Cognition 的完整面试流程，了解这一轮在整个流程中的位置。具体到 Cognition，面试官的权重是这样的：候选人反馈显示，前沿部署循环会取消传统的编码轮和系统设计轮；技术能力改为通过 Devin 练习和项目讲解来评估。

是的，而且不止一个职位名称。Cognition 发布了前沿部署工程师和应用 AI 工程师职位，将 Devin 嵌入客户的工程团队。应用 AI 工程师的职位描述说得很直白：你不是在演示 Devin，而是在部署它，与工程团队深度协作，推动可衡量的生产力提升，直到 adoption 真正落地。

面试会考察实际编码、系统和 Agent 设计，以及对过往项目的深入探讨，还会要求你提供成功企业部署的证据。候选人指南对前沿部署流程的描述各不相同：在 Devin 内完成一个实操性 take-home 而非算法轮，一个以业务影响力为评判标准的项目展示，一场高管提案，以及一场限时模拟客户通话。不同职位的面试流程不同，请与招聘人员确认你的具体安排。
