前沿部署安全工程师 | OpenAI | 华盛顿特区

原标题：Forward Deployed Security Engineer | OpenAI | Washington, DC

Zero G Talent · 2026-05-21 · 约 4 分钟读完

摘要

OpenAI 在华盛顿特区招聘前沿部署安全工程师（FDSecE），负责为公共部门等战略客户部署 OpenAI 技术时提供安全保障。该职位要求候选人深入嵌入客户现场，从设计、生产到持续运维全程参与安全工作，包括访问控制、加密、网络安全等防护措施的实施与监控。任职要求包括有效的美国安全审查许可、5 年以上安全工程经验，熟悉 Azure、AWS、Kubernetes、Terraform 等部署技术，掌握 Python 或 Golang 等编程语言，并具备红队测试、威胁监测等安全运营经验。职位采用每周 3 天到岗的混合办公模式，需经常出差至客户现场，也考虑远程安排并提供搬迁协助。

要点

  • OpenAI 招聘前沿部署安全工程师，首选华盛顿特区。
  • 职责是保障公共部门客户部署的安全，全程嵌入。
  • 要求持有美国安全审查许可及 5 年以上安全工程经验。
  • 需熟悉云平台、Kubernetes、Terraform 及 Python 或 Golang。
  • 混合办公每周 3 天到岗，需前往客户现场工作。

职位要求

关于团队

安全是 OpenAI 使命的基石，即确保人工通用智能造福全人类。安全团队负责保护 OpenAI 的技术、人员和产品。我们在所构建的东西上是技术型的，但在工作方式上是运营型的，并致力于支持 OpenAI 的所有产品和研究。我们安全团队的原则包括：以影响力为优先、赋能研究人员、为未来的变革性技术做好准备，以及建设健全的安全文化。

关于职位

我们的技术支持着世界上一些最重要、最具影响力的工作，包括公共部门中具有战略意义的高影响力客户。作为前沿部署安全工程师（FDSecE），你将负责保障 OpenAI 技术在这些新型应用场景中的安全。我们正在寻找积极进取、坚韧不拔且充满好奇心的人才，与工程团队紧密合作，确保我们的基础设施部署在面对对手时具备高度安全性。

作为一名 FDSecE，你将深入嵌入整个生命周期，在现场工作并亲力亲为，确保这些部署从设计到生产以及持续运营过程中的整体安全。

该职位优先考虑常驻华盛顿特区，但也可考虑远程工作。我们采用每周 3 天到岗的混合办公模式，并为新员工提供搬迁协助。该职位需要前往客户现场出差并在客户现场工作。

在这个职位上，你将：

  • 深度嵌入我们最具战略意义的公共部门客户，实施并维护健全的安全控制措施。
  • 作为设计和技术方面的思想伙伴，运用安全专业知识提供保护性控制，包括访问控制、身份验证、加密、网络安全和系统安全。
  • 与团队成员、跨职能团队、客户和服务提供商紧密协作，实现安全与合规目标。
  • 通过例行安全评估、威胁监控和安全验证演练，确保关键安全与监控控制措施的连续性。

如果你具备以下条件，你可能非常适合这个职位：

  • 持有有效的美国安全审查许可。
  • 5 年以上安全工程经验，侧重于基础设施安全、应用安全、网络安全、数据中心安全和系统工程。
  • 熟悉部署模型，包括云平台（Azure、AWS）部署及底层基础设施原语（Kubernetes、Terraform）
  • 熟练掌握 Python、Golang 或类似编程语言。
  • 拥有开发高质量、可扩展且安全的基础设施的成熟经验。
  • 具备安全运营经验，包括内部威胁监控、网络/终端检测与响应，或红队与渗透测试运营。
  • 全面掌握现代对手的战术、技术和程序。
  • 能够在跨职能团队环境中高效协作。
  • 能在动态环境中茁壮成长，从容应对不确定性。

关于 OpenAI

OpenAI 是一家致力于确保通用人工智能造福全人类的 AI 研究与部署公司。我们不断突破 AI 系统能力的边界，并通过我们的产品将其安全地部署到世界。AI 是一种极其强大的工具，必须以安全和人类需求为核心来构建；为实现我们的使命，我们必须包容并重视构成人类全貌的多元视角、声音和经历。
