关于 Hyperspell

Hyperspell 是面向 AI Agent 的记忆与上下文层。

AI agent are clueless geniuses.

AI Agent 在任何标准化测试中都能碾压人类，但在真实工作中却撑不过一天。当今这些超级智能的 Agent 所缺失的，是它们所处真实世界的上下文——一种由人类从数十次互动和众多渠道中的数百个数据点拼接而成的上下文。一种随任务不断增长的上下文。

Hyperspell 通过连接 AI Agent 用户的工作区数据，构建个性化的记忆与上下文层，为 AI Agent 提供这种上下文。

我们的价值观

我们相信，未来是由拥有最大胆想法的人塑造的。我们的使命是成为所有组织的默认上下文层，让它们的 AI Agent 都能连接。我们做这件事不是因为容易，而是因为它值得。

我们深切关怀。我们关心客户及其成功，关心 AI 的未来及其对社会的贡献，最重要的是，关心彼此。我们站在 AI 的前沿，事实上是人类历史上技术最先进的公司之一——正因如此，而非尽管如此，我们也希望成为最有人情味的公司。一个我们可以一起享受塑造未来的地方。

我们的投资者

我们获得了众多出色投资者的支持，包括 Y Combinator、Afore Capital、Scribble Ventures 和 Pioneer Fund。我们的天使投资人包括来自 OpenAI、Anthropic、xAI 和 DeepMind 的技术团队成员，以及硅谷一些最受尊敬的创始人，包括 Siqi Chen（Runway）和 Julian Weisser（On Deck）。

我们的创始人

Hyperspell 由 Conor Brennan-Burke 和 Manu Ebert 于 2024 年创立。Conor 曾在 Checkr 负责增长，管理其价值 3000 万美元的 API 产品组合，并普遍被称为“YC 最乐于助人的创始人”。

Manu 在机器学习和 AI 领域拥有超过 15 年的经验，曾出售过两家公司，在 Airbnb 领导过高增长工程团队，并于 2014 年买下了他的第一个 .ai 域名（为此他不得不向安圭拉的域名管理机构发送传真（！））。

关于该职位

作为我们的创始前沿部署工程师，你的使命是帮助客户取得成功，并推动

AI Agent 能力的边界。你将在 AI 系统如何理解、记忆和推理信息的前沿领域工作。

你将应对诸如以下的挑战：

  • 打造世界首个自我集成 SDK：改进开发者将应用连接到 Hyperspell 的方式，让集成体验如同魔法一般
  • 负责客户关系：你将成为公司在许多客户面前的形象代表。你需要回应他们的功能需求和缺陷报告，并在很多问题进入工单系统之前就亲自解决。
  • 深入了解客户：深入客户现场，理解他们的业务、数据和用户，然后发掘机会，解决他们自己都未曾意识到的问题
  • 全栈功能负责：端到端地构建新的集成、API 端点、仪表盘功能和分析工具。
  • 塑造产品：将客户痛点转化为产品方向。你从一线获得的洞察将直接影响我们的产品路线图
  • 技术赋能：帮助客户设计实施方案、调试棘手问题，并充分发挥我们平台的价值

你的工作内容

  • 在最初的 30 天内，你将接手新客户，负责客户的 Hyperspell 入驻流程，并构建和交付他们请求的较小功能。
  • 在 60 天内，你将交付内部工具和仪表盘，帮助我们管理工作流程。你将部署自定义 AI Agent 与你协同工作，帮助我们的客户取得成功。
  • 在 90 天内，你将负责涉及我们技术栈各个部分、影响现有和未来客户的更大项目。

任职要求

  • 3 年以上产品工程经验
  • 精通 Python 和 TypeScript
  • 思路清晰，沟通能力出色
  • 真心乐于帮助其他工程师取得成功
  • 能够在旧金山现场办公

薪酬待遇

  • 基本工资 15 万至 22 万美元
  • 0.5%–1.5% 股权
  • 10,000 美元用于打造你理想的工作环境
  • 医疗、牙科和视力保险以及丰厚的健康福利
