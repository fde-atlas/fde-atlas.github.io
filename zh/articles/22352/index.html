西雅图（华盛顿州）前沿部署工程师职位

摘要

JeffreyM Consulting 于 2026 年 9 月 25 日在西雅图发布全职前沿部署工程师招聘，年薪 15 万至 22.5 万美元加股权，需到客户现场出差。该职位为客户部署一套面向制造与采购场景的 AI 采购平台，涉及 ERP、PLM、MES 等系统集成、数据迁移、API 排障及生产代码编写。要求四年以上相关经验，熟悉 TypeScript、React、GraphQL、PostgreSQL 与 SQL。因涉及 ITAR 管控数据，候选人须具备美国公民或永久居民等“美国人”资格。

  • 薪资 15 万至 22.5 万美元加股权，需按需出差到客户现场。
  • 职责涵盖采购平台部署、ERP/PLM/MES 集成、数据迁移与 API 排障。
  • 要求 4 年以上经验，熟悉 TypeScript、React、GraphQL、PostgreSQL。
  • 涉及 ITAR 管控数据，候选人须符合“美国人”资格要求。

关于该机会

我们的客户是一家快速发展的科技公司，正在为复杂的制造和采购环境构建 AI 驱动的软件，现诚聘前沿部署工程师加入其团队。

该职位将软件工程与直接客户互动相结合。您将与航空航天、国防、太空、能源和机器人等行业的客户密切合作，将一个复杂的采购平台部署并集成到他们现有的技术环境中。

您将负责从实施到上线的全部技术部署工作，直接与客户利益相关方合作，同时编写生产代码、构建集成、排查 API 和数据流问题，并与产品和工程团队紧密协作。

这一机会非常适合喜欢解决模糊的现实世界问题、直接与客户合作，并希望看到自己的技术成果部署到复杂运营环境中的工程师。

您的职责

  • 负责客户技术部署的全流程，从项目启动和需求调研，到数据迁移、配置、集成和上线。
  • 构建并维护平台与客户 ERP、PLM、MES 及其他企业系统之间的集成。
  • 编写生产级代码，并针对客户特定需求开发技术解决方案。
  • 梳理并验证跨系统数据流，排查同步、身份验证、API 和数据负载问题。
  • 编写 SQL 和 GraphQL 查询，以验证迁移、调查差异并开发运营分析。
  • 配置并支持与采购、供应商入驻、审批、询价（RFQ）和采购订单生命周期相关的工作流。
  • 直接与采购、工程、财务和 IT 领域的客户利益相关方合作。
  • 在整个客户生命周期中担任技术合作伙伴，识别并解决可能影响实施或采用的阻碍因素。
  • 将客户的重复性需求转化为产品和工程需求，并在适当情况下直接参与产品开发。
  • 协助构建可复用的部署流程、技术文档、实施模板和入职指南。

要求

我们期待的人才

  • 4 年以上软件工程、前沿部署工程、解决方案工程、客户工程或技术实施相关经验。
  • 扎实的工程基础，最好拥有计算机科学、软件工程、数学、物理、数据科学或相关技术学科的背景。
  • 出色的软件开发能力，并有交付生产级代码的实际经验。
  • 熟悉现代 Web 应用技术。有 TypeScript、React、Next.js、GraphQL 和 PostgreSQL 经验者优先。
  • 具备 API 工作知识，包括阅读 API 文档、使用 Postman 等工具测试端点，以及排查身份验证和负载问题。
  • 能够从容处理复杂且不完美的真实世界数据。
  • 出色的沟通能力，能够直接与技术团队和客户高层利益相关者协作。
  • 能够独立负责技术问题和客户成果，从最初的需求发现一直到问题解决。
  • 愿意根据需要前往客户现场。

优先条件

  • 出色的 SQL 技能，包括联接、聚合、数据验证和查询排错。
  • 有 GraphQL 经验，或具备快速学习类似技术的能力。
  • 熟悉制造采购流程，如 MRP、寻源、供应商质量、收货或三单匹配。
  • 有实施、配置或集成 ERP、PLM 或 MES 系统的实操经验。
  • 有作为软件工程师构建面向客户的集成或解决方案的经验。
  • 有基于运营数据开发报表或分析的经验。
  • 具有航空航天、国防、太空、能源、机器人或其他受监管制造环境的背景。
  • 曾从事前沿部署工程、解决方案工程、技术咨询或部署策略相关工作。

其他要求

该职位涉及 ITAR 受控数据和 CUI 数据。候选人必须是美国公民、合法永久居民，或符合适用 ITAR 法规下“美国人”的资格。

  • 无限带薪休假
  • 401k 退休计划并提供匹配缴款
  • 其他各类福利，如 OneMedical、Kindbody、TalkSpace 等
  • 与精英创业者和工程师团队共事的机会
  • 通过改善全球供应链来改变世界的机会
