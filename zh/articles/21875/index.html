Cresta 高级 FDE 职位描述：每一行意味着什么

原标题：Cresta Senior FDE Job Posting: What Each Line Means

FDE Times · 2026-10-24 · 约 6 分钟读完

摘要

文章逐行解读 Cresta 高级前沿部署工程师（AI Agent）职位的招聘要求，指出四个动词——开发、配置、部署、优化——对应一次客户交付的完整生命周期。作者强调该职位虽为远程，但每条要求都意味着在客户系统上的实际工作，并建议求职者为每项要求准备小型实证项目，如带超时与人工兜底的 API 工具、双语言服务、CI/CD 流水线和部署计划。

要点

  • 四个动词对应客户交付的完整生命周期。
  • 每条要求都可转化为客户现场的具体任务。
  • Python 与 Golang 并重，不可只学 Python。
  • 建议用小型项目作为每项要求的证据。
  • 简历筛选后是 CoderPad 自主测评。

四个动词——开发、配置、部署和优化——勾勒出一个项目合作的生命周期，而最有力的证明就是为每项任务做一个小型构建。

简要概述

  • Cresta 的资深 FDE（AI Agent）职位描述围绕四个动词展开：开发、配置、部署和优化 AI Agent，此外还要求将 Agent 与客户的 API、数据库和 CRM 进行集成。
  • Python 和 Golang 是核心要求，同时需要云和 DevOps 经验；有 LLM 和提示词工程经验者优先。
  • 简历筛选之后是一份自主安排时间的 CoderPad 测评，因此一个带有真实集成的 Agent 项目比任何技能清单都更有价值。

你打开 Cresta 于 2026 年 10 月 13 日发布、面向澳大利亚远程候选人的资深前沿部署工程师（AI Agent）职位描述，看到一份熟悉的清单：Python、Golang、云、DevOps、LLM、项目管理。

粗略一看，它和其他任何工程职位没什么两样。但仔细阅读后，你会发现每一行都对应着你将在客户系统上执行的具体任务，即使这个职位是远程的。

这里需要学习的技能并非 Cresta 独有。它是如何阅读一份 FDE 职位描述：把每一行翻译成它所隐含的工作，然后为每项任务构建一小份证据。这样做的候选人更容易通过简历筛选，并且在进入技术测评时，已经自己完成过类似的工作。

职位描述中的动词比名词更能说明问题

职责部分的开头句包含四个动词：在 Cresta 的平台和工具上开发、配置、部署和优化 AI Agent。这个顺序就是一个项目合作的生命周期。你不是从零开始构建产品；你是在现有平台的基础上，让它为某一个特定客户服务。

要理解“让它工作”意味着什么，就要看看这个产品。Cresta 将自己描述为一个面向企业级规模的、同时服务人工客服和 AI Agent 的统一平台。

eesel AI 在 2026 年 5 月更新的一份分析指出，Cresta 的 AI Agent 支持语音、聊天和短信，并通过基于 API 的函数调用以及 MCP 支持与其他系统连接。

一个更早的细节更为重要。早在 2021 年，Cresta 的博客就写道，该产品的设计初衷是与客户已在使用的呼叫中心软件集成并协同运行。因此，这里的前沿部署工程师几乎总是在别人的系统内工作，面对他们无法掌控的数据、限制和流程。

每项要求都是客户现场的一项任务

下表将职位描述中的主要条目翻译成实际工作，并展示你在申请之前如何证明每一项。

职位描述中的条目客户现场的实际工作需要准备的证据
将 Agent 与 API、数据库、CRM 集成Agent 必须能在对话过程中查询发票、订单和客户记录一个调用 API 的工具，带超时和回退机制
Python 和 Golang编写 Agent 逻辑，编写可靠运行的中间件服务用两种语言编写同一个服务
云（AWS、GCP 或 Azure）和 DevOps容器化，通过 CI/CD 发布，上线后进行监控一个包含 Dockerfile、CI 流水线和仪表盘的代码仓库
LLM 和提示词工程（强烈优先）当 Agent 在真实数据上回答错误时调整提示词一套测试问题集，包含修复前后的结果对比
设定里程碑、规划、内部协调在多个团队参与时按时交付一份包含里程碑和风险的部署计划

该职位要求在软件开发、咨询或 AI/ML 工程领域至少有 3 年全职经验。这三条路径同等重要，因此从未做过 AI 的后端工程师仍有机会，前提是他们能证明自己符合 Python 和 Golang 这一条以及云和 DevOps 这一条。

示例：在客户来电期间查询发票的 Agent

想象一家电信运营商，希望用一个 AI Agent 在语音渠道回答“我这个月的账单是多少？”。数据存放在运营商的计费系统中，而不是在 Cresta 里。你的任务是编写一个 Agent 可以通过函数调用（function calling）调用的工具。

import requests

BILLING_URL = "https://billing.example-telco.internal"

TOOL_SPEC = {
    "name": "get_open_invoice",
    "description": "Fetch the unpaid invoice for a customer whose phone number has been verified",
    "parameters": {
        "type": "object",
        "properties": {"phone": {"type": "string"}},
        "required": ["phone"],
    },
}

def get_open_invoice(phone: str) -> dict:
    try:
        r = requests.get(
            f"{BILLING_URL}/invoices",
            params={"phone": phone, "status": "open"},
            timeout=2.5,  # on a call, a long silence is a failure
        )
        r.raise_for_status()
    except requests.RequestException:
        # the customer's system failed: don't guess, hand off to a human
        return {"ok": False, "action": "handoff_to_human"}

    items = r.json().get("items", [])
    if not items:
        return {"ok": True, "invoice": None}
    inv = items[0]
    return {"ok": True, "amount": inv["amount"], "due": inv["due_date"]}

API 调用本身只需要几行代码。价值在于围绕它的三个决策，而这些正是面试官希望听你解释的内容。

第一个决策是超时。在聊天中，等待五秒是可以接受的；但在通话中，五秒的沉默会让客户以为线路已断开。这里的 2.5 秒数字只是用于说明的假设；在真实项目中，你需要在选择之前先测量客户 API 的延迟。

第二个决策是返回

handoff_to_human

而不是让模型自行发挥。一个无法获取数据却照样回答的 Agent，就是在凭空编造账单金额。由于该平台同时服务人工客服和 AI Agent，将通话转接给人工是自然的回退方案。

第三个决策是区分“没有发票”和“出错”。这两种情况会导致给客户完全不同的答复，提示词必须教会 Agent 在每种情况下说出正确的答复。

从示例到应用：按此顺序操作

从上面这个工具开始，针对你自己编写的模拟 API 运行它，并添加十个测试问题，包括不存在的号码和一个会挂起的 API。记录你在调整提示词前后 Agent 答对的数量。这就是 LLM 和提示词工程这一条的证明材料，而职位描述明确将其标注为强烈优先。

接下来，用 Go 重写这个模拟计费服务。招聘启事要求同时掌握 Python 和 Golang，因此一个用两种语言实现同一服务的仓库可以直接回应这一条。将其容器化，添加一个运行测试的 CI 流水线，并附上延迟指标：这三件事完整覆盖了云与 DevOps 这一条要求。

最后，为运营人员撰写一页纸的假设性部署计划：包括里程碑、客户的哪些团队需要授予 API 访问权限，以及哪些风险可能导致延误。招聘启事要求 FDE 自行设定里程碑、规划部署并与内部团队协调以按时交付，因此这份计划就是针对这一条的直接证明。

CoderPad 轮次与常见错误

根据招聘启事，通过简历筛选的候选人将在 CoderPad 上参加一项自定进度的技术测评。简历是第一道门槛，因此它应该描述你做过的工作，而不是罗列技术。

一个简单的模板：“通过 API Y 将 Agent 与客户系统 X 集成，降低了 Z”，其中 Z 是你实际测量出的数字。

第一个错误是在技能栏列出“LLM、RAG、Agent”却没有配套的测试套件。第二个错误是假设 FDE 会取代客户的系统，而 Cresta 自己都说该产品是为与现有呼叫中心软件并行运行而构建的。第三个错误是跳过 Go，认为 AI 只需要 Python。

Cresta 的另一份招聘启事展示了这条路径的下一步：前沿部署工程经理职位，于 2026 年 1 月发布，面向美国的远程候选人，要求至少 2 年管理、指导和发展工程团队的经验，并愿意在 10-25% 的时间里出差与客户会面并参加活动。

你今天练习的规划与协调，正是迈向那一步的基础。

善于阅读招聘启事的人不会去数自己匹配了多少关键词。他们会问自己是否已经为任何人做过这类工作，如果没有，就在这个周末构建一个小型版本。
