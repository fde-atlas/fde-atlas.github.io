FDE 股权详解：限制性股票单位（RSU）与期权，以及该问什么

原标题：FDE equity explained: RSUs vs options, and what to ask

摘要

这篇文章解释 FDE offer 中股权条款的读法：RSU、期权、现金替代与 PPU 的区别，以及 vesting、cliff、行权成本和私司估值对实际价值的影响，并列出应书面确认的问题清单。

要点

  • RSU 无需付费即可获得股票，期权须股价高于行权价才有价值。
  • 同一名义金额的股权，工具、归属表、定价与流动性可能完全不同。
  • Google FDE 报价显示 38/32/20/10 的前置归属，两年后比均匀归属多 40%。
  • 私司股权需确认估值依据、双重触发条款与回购等流动性渠道。
  • 所有关键条款应以书面形式确认，口头回答不具约束力。

你手上有一份 offer，而股权那一行是你无法定价的数字。一位 Blind 用户在 2026 年 5 月详细列出了 Google FDE offer 的内容，其 RSU 按 38/32/20/10 归属：第一年归属 38%，最后一年归属 10%。来源 1Google (FDE) vs NVIDIA (AI Infra) – Offer comparison发布者Blind (teamblind.com)来源类型Blind 上的候选人报告。关于公布的薪资区间，请参阅我们的前沿部署工程师薪资指南。

关于 RSU 与期权的简短回答：限制性股票单位（RSU）在归属时转换为股票，无需你付出任何成本，因此只要股票有价值，它就有价值。股票期权是以固定行权价购买股票的权利，因此只有股价高于该价格时才有价值，而且行权需要付费。在相同的名义价值下，RSU 是更稳妥的选择；只有当股价涨到高于授予时定价所依据的价格时，期权才能带来更多收益，若股价等于或低于行权价则一文不值。以现金代替股权就是现金。在比较两份股权授予之前，请务必以书面形式确认工具类型、归属时间表、数量背后的定价以及出售规则。

为什么股权那一行难以解读

一份股权授予是把好几个数字写在一行里。在名义数字背后，隐藏着：

  • 工具类型。 单位、期权、以现金代替两者，或某种你从未听说过的东西。
  • 数量与价格。 一个美元价值等于单位数量乘以某人选定的价格。是哪个价格？何时选定的？
  • 时间表。 每一部分何时归你所有，如果你提前离开会损失什么。
  • 流动性。 你能否出售已归属的部分，以及何时能卖。
  • 税务。 你何时需要缴税，以及按什么价值缴税。

两份名义价值相同的股权授予可能在每一项上都不同，所以在每一项都弄清楚之前，“这份股权好不好”是没有答案的。

RSU、期权与现金代替

RSU

RSU 是一项承诺：在归属时给你一股股票，或其现金价值。你无需付费即可获得。在上市公司，已归属的 RSU 会变成你可以持有或出售的股票。在美国，归属时的价值按普通收入征税，雇主可能会扣留部分股票以缴纳税款。

私营公司可能授予双重触发RSU。第一个触发条件是时间：即你的归属时间表。第二个是计划中定义的流动性事件，例如 IPO 或被收购。在第二个触发条件发生之前，已满足时间条件的单位尚未结算，因此你不持有任何股票，也没有东西可卖。请询问什么算作第二个触发条件，以及如果它始终没有发生，这些单位是否会过期失效。

股票期权

期权是以固定行权价（即授予期权时设定的行权价）购买股票的权利。今天行权所能获得的收益，是股票价值与行权价之间的差额乘以期权数量。如果股票价值低于行权价，期权就处于“价外”状态：今天行权毫无收益，只有价格在期权到期前涨到行权价之上，行权才有回报。

期权有三点是 RSU 所没有的：

  • 行权需要付费。 购买股票的成本是行权价乘以数量，再加上行权可能触发的任何税费。
  • 行权窗口期。 当你离职时，计划会给你一段固定的时间来行权已归属的期权；窗口关闭后，期权就作废了。在私营公司，这可能意味着要为暂时无法出售的股票支付真金白银。
  • 在美国有两种税务处理方式。 激励性股票期权（ISO）和非法定股票期权（NSO）的征税方式不同。对于 NSO，行权时股票价值与行权价之间的差额按收入征税；对于 ISO，通常不征税，但可能触发替代性最低税（参见 IRS 股票期权指南）。离职超过 3 个月后才行权的 ISO，会按 美国税法中的 ISO 规则 作为 NSO 征税。请询问你持有的是哪一种，并在行权前咨询税务顾问。

现金替代

有些 offer 用现金代替股权：没有上涨空间，也没有流动性问题。请询问支付时间、提前离职是否需要退还部分款项，以及它是否取代了同岗位其他人获得的股权授予。

归属计算：把一笔授予额换算成年度数字

授予额是跨越数年的总额。要把它与薪资并列比较，就要按照你自己 offer 信中的时间表，把它换算成你每年实际获得的数额。下面是一个虚构的授予额，分别按平均时间表和某位 Blind 发帖人报告其 Google offer 所采用的前置加权时间表计算。Source 1Google (FDE) vs NVIDIA (AI Infra) – Offer comparisonPublisherBlind (teamblind.com)Source typecandidate report on Blind

# Illustrative: a made-up grant
grant = 200_000   # value at grant

def by_year(pcts):
    return [round(grant * p / 100) for p in pcts]

even  = by_year([25, 25, 25, 25])
front = by_year([38, 32, 20, 10])
print("even ", even)
print("front", front)
print("after 2 yrs", sum(front[:2]), sum(even[:2]))
# even  [50000, 50000, 50000, 50000]
# front [76000, 64000, 40000, 20000]
# after 2 yrs 140000 100000

总额相同，形状不同。前置加权时间表在第二年之后离职时支付更多，且在第一年之后逐年递减，所以如果你打算长期留下，要问是否有追加授予（refresher），以及由什么决定。

悬崖期（cliff）是另一个数字。Levels.fyi 根据用户提交的信息称，Anthropic 的股权分 4 年归属：第一年 25%，之后第二至四年按月归属。Source 14Anthropic Software Engineer SalaryPublisherLevels.fyiSource typeself-reported pay on Levels.fyi 时间表可能会把第一年的份额放在悬崖期之后：在悬崖日之前没有任何归属。以下是在虚构输入条件下，一年悬崖期加按月归属意味着什么：

# Illustrative: 1-year cliff, then monthly
def vested_pct(months, cliff=12, total=48):
    if months < cliff:
        return 0.0
    return min(months, total) / total * 100

for m in (11, 12, 18, 30):
    print(m, "months:", vested_pct(m), "%")
# 11 months: 0.0 %
# 12 months: 25.0 %
# 18 months: 37.5 %
# 30 months: 62.5 %

在悬崖期前一个月离职，你将一无所获。签字之前先弄清你的悬崖日期。对于双重触发单位，通过悬崖期只满足时间条件。

RSU 与期权，正面对比

现在来看标题掩盖的比较。取同一家公司的两笔虚构授予额，按 offer 所依据的股价计算价值相等（

sized_at

，高于行权价），然后看看随着股价变动各自的价值：

# Illustrative: same company, two made-up grants
sized_at = 20.0  # share price the offer used
rsus = 1_000
options, strike = 4_000, 15.0
for price in (10, 15, 20, 30):
    r = rsus * price
    o = options * max(price - strike, 0.0)
    print(price, "RSUs:", r, "options:", o)
print("equal at", sized_at,
      rsus * sized_at == options * (sized_at - strike))
print("cost to exercise:", options * strike)
# 10 RSUs: 10000 options: 0.0
# 15 RSUs: 15000 options: 0.0
# 20 RSUs: 20000 options: 20000.0
# 30 RSUs: 30000 options: 60000.0
# equal at 20.0 True
# cost to exercise: 60000.0

在授予额定价所依据的股价下，两者相等。高于该价时，期权迅速领先，因为每份期权都获得全部涨幅。在行权价或以下时，期权一文不值，而 RSU 仍保留大部分价值。而且期权行权还要花钱。当招聘人员把期权报成一个美元价值时，要问它假设的股价和行权价是多少。

私募公司股权：估值、流动性与要约收购

在私营公司，数字背后的价格是首先要弄清的事情。2026 年 5 月，一位参与 Anthropic 面试流程的人在 Blind 上发帖询问，Anthropic 的 RSU 授予是基于什么估值。Source 11Anthropic offer - advice + RSU info?PublisherBlindSource typecandidate report on BlindSource 12RSU Valuation for current Anthropic offers?PublisherBlindSource typecandidate report on BlindSource 13Anthropic options exercise windowPublisherBlindSource typecandidate report on Blind 对于任何私营公司的授予，这都是应该提出的问题，而且答案应当落在书面上。

在信任一个私营公司估值之前，需要理解三件事：

  • 头条估值不是你的价格。 融资轮中的投资者购买的是优先股，享有员工普通股所没有的权利，例如在出售时优先获得偿付，因此融资轮的价格并不等于普通股的价值。
  • 期权使用的是另一个数字。 在美国，私营公司期权的行权价不得低于普通股的公允市场价值（对于 ISO，税法有此要求；行权价由 409A 条款估值确定），这可能远低于最新一轮融资的价格。基于融资轮优先股价格计算的金额，会比基于普通股价值计算的金额显得更大。
  • 不能出售的授予，其价值低于可以出售的授予。

私营公司的流动性来自 IPO、收购或要约收购（tender offer），即公司或其投资者以设定价格从员工手中购买股份。2026 年 3 月，Decagon 的博客宣布了公司的首次员工要约收购。Source 15Decagon closes employee tender at $4.5 billion valuationPublisherDecagon blogSource typecompany blog 请询问你的雇主是否开展过此类要约收购、谁可以出售、能出售多少，以及尚未归属的双触发 RSU 是否可以参与。

我们评估私营公司授予的方法是写下它的三个版本：招聘人员给出的数字、一个由你为时间和风险自行选择折扣后的数字，以及零。如果这份 offer 只在第一个版本下才成立，你就知道自己赌的是什么了。

PPU：它们是什么，以及该问什么

利润参与单位（profit participation unit）是一种合同性权利，赋予持有者分享公司未来利润分配的份额，用以替代股票授予。它不带有股东投票权，且只有在利润被分配或单位被回购或出售时才会产生收益。

  • 我们在 Blind 上找到的帖子提到的是期权和 RSU，从未提到 PPU。来源 11Anthropic offer - advice + RSU info?发布者Blind来源类型Blind 上的候选人报告来源 12RSU Valuation for current Anthropic offers?发布者Blind来源类型Blind 上的候选人报告来源 13Anthropic options exercise window发布者Blind来源类型Blind 上的候选人报告

如果录用通知中确实提到了 PPU，或任何你不熟悉的工具，请询问它的收益依据是什么、何时发放、收益是否有上限、单位多久可以出售一次，以及如何征税。

需要以书面形式得到解答的问题

口头回答只是一个起点；真正具有约束力的是录用信和计划文件。

需要以书面形式确认的股权条款

  • 工具类型：RSU、双触发 RSU、期权（ISO 或 NSO）、现金替代，还是其他
  • 单位或期权的数量，以及用于将美元金额换算成该数量的每股价格
  • 对于期权：行权价，以及你离职后的行权窗口期
  • 归属时间表：悬崖期（cliff）截止日期，以及每年归属的比例
  • 对于双触发单位：什么构成第二触发条件，以及单位是否会过期
  • 追加授予：是否会有追加授予，以及由什么决定
  • 流动性：过去的要约收购（tender offer）、谁可以出售，以及以什么条款出售
  • 如果公司被收购，未归属的股权会怎样
  • 对于现金替代或签约奖金：何时支付，以及你在什么情况下需要偿还

当录用通知到达后，以下是通话时可以使用的措辞：

你：“谢谢，我对这个机会很感兴趣。在我进行比较之前，能否以书面形式发送股权条款：工具类型、单位数量、你们使用的每股价格以及归属时间表？”

招聘人员：“这是我们的标准方案。”

你：“明白了。我仍然希望将其写入录用信或计划摘要中，这样我才能进行对等比较。如果我离职，已归属的股权会怎样？如果公司被收购，未归属的股权又会怎样？”

对于私营公司的股权授予或期权，请补充以下问题：

你：“这个美元金额是基于最新的优先股价格还是普通股价值？另外，对于已归属的期权，我离职后的行权窗口期有多长？”

招聘人员：“我们使用的是最近一轮融资的价格。”

你：“谢谢。能否将股份数量和行权价写入录用信，这样我就可以自己计算了？”

保持好奇的语气：你是在询问这笔授予是什么，而不是在争论它的数额。如果招聘人员说数额本身是固定的，我们针对最终股权数额的示范回答涵盖了接下来该问什么。如果条款附带很短的期限，为期一周的录用截止期限提供了争取时间的措辞。

FDE 股权的常见错误

  • 比较不同工具的表面数字。 相同美元金额的期权和 RSU 是不同的赌注。先把两者都换算成年化价值。
  • 将前置发放的股权平均分配。 要为后续年份做好规划，或询问有关刷新（refresher）授予的事宜。
  • 把私募估值当作成交价。 在老股回购、IPO 或被收购之前，它只是纸面上的数字。
  • 忘记行权成本。 离职后，期权可能需要花钱才能保留。
  • 相信口头薪酬承诺而非录用信。 只有录用信和股权计划文件具有约束力。

把股权放到整个 offer 中一起看

当每笔授予都变成一个年度数字、且风险写在旁边时，你就可以比较完整的 offer 了。如何比较两个 FDE offer 详细讲解了这一过程。如何谈判 FDE offer 介绍了当股权固定时可以争取什么，例如职级、签字费或入职日期。如果你正在查阅 H-1B 备案文件来核实基本薪资，公开薪资区间和备案文件能说明什么 解释了为什么备案文件从不包含股权信息。

人们常问的问题

在 FDE offer 中，RSU 和股票期权有什么区别？

RSU 是一种股份承诺，随着归属（vest）逐步归你所有，因此只要股份还有价值，它就保有一定价值。股票期权是以固定行权价购买股份的权利，因此只有当股份价值高于该行权价时才有价值，而且行权需要你付费。

什么是利润参与单位（PPU）？

利润参与单位是一种合同权利，可获得公司未来利润分配的一部分，作为股票的替代形式发放，且没有股东投票权。只有当利润实际分配、或单位被回购或出售时才会产生收益，因此在将其与 RSU 比较之前，请询问有关上限、支付时间以及出售规则的问题。

如何比较两个 FDE offer 之间的股权？

使用录用信中自带的归属时间表，将每笔授予折算为年度价值，并对私企股权按“多年内可能无法出售”的可能性进行折价。然后将年度股权价值与基本薪资和目标奖金并列，并在每个数字旁边标注相应风险。
