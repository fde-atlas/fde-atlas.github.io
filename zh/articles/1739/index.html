前沿部署式销售 — 一个 Claude Skill

全文

一个 Claude Skill

现在就用它来销售。

Forward Deployed Selling 是一个 Claude skill,在销售的每个阶段为你提供建议——从首次回复到成交——其方法源自 AWS 企业级 AI 销售的实战锤炼。

01 / 它做什么

01为你参与的每一笔交易配备一位顾问。

02基于你现有的技术栈构建销售 Agent。

03更快实现首批收入。

04接入任何 Agent 工作流。

05无需学习方法论即可销售。

06把所有销售工作都留在 Claude 内完成。

02 / 适用人群

03 / 工作原理

它构建每笔销售所需的三样东西。

→你的理想客户画像(ICP)。

→你的市场推广策略(GTM)。

→能让两者落地的信息传达。

3x3 只是界面,底层的方法才是真正干活的。

04 / 方法

每笔交易都依赖全部六项——三条面向销售者的原则,三件 AI 现在能做的事。

三条原则

→让"答应"变得容易。降低买家每一步的成本——而不是把要求最大化。

→让他们看见未来。用他们自己的数字展示购买后的世界——而不是一份泛泛的案例研究。

→展示,而非讲述。用真实的工作成果来证明结果,而不是一份幻灯片。

AI 带来的可能

→了解更多。仅凭公开数据,就能对目标客户进行五层深度的研究。

→个性化每一次触达。每份交付物都是独一无二的,贴合具体情境,并附有来源依据。

→带着论点而来。带着一个让买家做出反应的观点到场。探索变成了验证。

05 / Skill 内部

先做目标定位。之后每个任务都针对已验证的目标运行,每份输出在交付前都会经过检查。

ICP 验证市场 × 人群 × 渠道,在其他任何环节运行之前先锁定。

GTM 策略销售动作、渠道、信息和验证标准,均由 ICP 推导而来。

阶段诊断仅凭公开数据,将任何客户定位在认知 → 熟悉 → 价值路径上。

论点生成一页纸的客户观点,附来源并标注,供你审阅。

利益相关者画像五层背景信息,外加谁在使用、谁购买、谁支持、谁能扫清障碍。

价值框架不行动的成本与行动的价值,两者均有来源,都用买家的数字呈现。

交易评分阶段、风险和速度综合成一个层级,并且不会让你跳过任何阶段。

实时交易辅导发现阻碍交易的因素,并给出恢复计划。

资格不符处理诚实地指出不合适的客户,并告诉买家什么才更适合他们。

演示交付物构建那些你原本要亲手撰写的工作成果。

每份输出都要通过三道检查:伦理、方法和诚实。每个数字都注明来源。如果你想跳过某个步骤,它会先发出警告。

06 / 安装

可在 Claude Code、Cowork 和 Claude 聊天中使用。Claude 会根据问题自动加载所需内容。你无需管理任何文件。

Claude Code

$mkdir -p ~/.claude/skills

$git clone https://github.com/vonarmen-wq/forward-deployed-selling ~/.claude/skills/forward-deployed-selling

Cowork 与 Claude 聊天

  • 下载下方的 zip 文件。
  • 在 Claude 中：设置 → 能力 → 技能 → 添加。
  • 上传 zip 文件——无需解压。

安装完成后，试试

  • “为我的产品制定一套市场推广策略。”
  • “制定一份打入（目标客户）的销售计划。”
  • “帮我打磨产品的价值主张。”

09 / 标准

该技能免费。其上有两条付费路径：认证，面向希望学习该框架的个人或团队；以及 Powered by FDS 标识，面向基于该方法构建的产品与交付。

认证

面向希望学习如何应用完整 Forward Deployed Selling 框架的个人或团队。采用小班制课程，最后需在真实或模拟交易中进行最终演示。

Powered by FDS 标识

面向交付或产品基于该方法的咨询公司和软件供应商。提交申请、完成审核，并授权使用该标识用于包装、文档和营销。
