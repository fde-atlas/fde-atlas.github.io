摘要

Michael Couch 的个人站点汇集了他关于前沿部署工程（FDE）与企业 AI 落地的系列文章。核心主张是：模型本身不再是竞争优势，围绕模型的“缰绳”——接口、权限、评测、工作流与运维层——才是。他提出最小四人前沿小组（Frontier Lead、Creative Technical Lead、Applied Builder、Domain Champion），强调 FDE 团队的使命是让企业逐步摆脱对它的依赖，而非制造永久绑定；同时把 FDE 方法延伸到硬件与工厂场景，讨论技能文件夹标准、评测体系、断电开关与开放权重模型的便携性。

要点

  • 竞争优势在模型外围的“缰绳”，而非模型本身。
  • 最小前沿小组由四种角色组成，避免臃肿 AI 团队。
  • FDE 的目标是让客户独立，而非永久依赖。
  • 技能文件夹已成开放基础设施，评测与断电开关不可或缺。
  • 同一套 FDE 方法适用于硬件、工厂与气隙环境。

  • 2026年11月《AI 应当扩展人们能做的事》降低成本是合理的结果，却是不完整的战略。用一份扩展台账记录变革真正带来的能力、体验与机会。
  • 2026年11月《网络只有创造出东西才算集体》联系人清单只是潜力。集体必须把它转化为工作：一个使命、一位可问责的负责人、一支精心组建的团队，以及公平的交换。
  • 2026年11月《变革平台不是一款应用》第一个平台是一种可复用的方法，用于从重要问题走向可观察的改进。软件可以随后跟上，但它无法替代这套方法。
  • 2026年11月《X 比客户更宽》客户体验、员工体验、创始人的摩擦与公共服务，往往是从不同座位看到的同一个缺陷。围绕 CX 划定的边界正是它长期不可见的原因。
  • 2026年11月《判断力才是稀缺资产》能否获得工具已不再是区分严肃组织的标准。真正区分它们的是判断力：哪些负担重要、什么证据算数、何时该停止。
  • 2026年11月《要么公平交换，要么不会重来》当报酬、人情、所有权和隐私始终含糊不清时，独立的协作就会消亡。在开工之前把交换条件讲清楚，否则就不会有第二次。
  • 2026年11月《方法可复用时，软件才配得上它的位置》先让同样的决策被手工反复做出足够多次，确认它们其实是同一个决策，再去构建登记系统和流程工具。而不是在此之前。
  • 2026年11月《首次合作应当小到可以完成》一个摩擦点、一条基线、身处其中的员工、一个可运行的验证、一位明确的负责人，以及采纳、迭代或停止的决策。几周时间。而不是一场转型工程。
  • 2026年11月留存的能力：终结企业依赖的高管指南如何招聘、签约和治理前沿部署团队，以实现机构独立性而非永久依赖。直面怀疑者、招聘官的诊断转变，以及为什么目标绝不是把银行变成软件公司。
  • 2026年11月前沿信条：停止扩大中间层前沿部署工程团队的目的不是让自己不可或缺，而是让企业日益独立于它。团队不是产品；它留下的能力才是。拆解“代理税”，并通过90天依赖度削减测试。
  • 2026年11月运营节奏：决策优先于形式化流程高速运转的企业前沿工程如何在没有敏捷仪式或指导委员会表演的情况下日常运作。共享专业能力、四层视野运营节奏、NIST AI RMF 治理，以及六项记分卡。
  • 2026年11月前沿工程的真实经济学企业 AI 转型的财务现实。顶级前沿部署工程的实际成本、为什么50万英镑买不来完整能力、数学如何在10个领域非线性扩展，以及2倍收益成本门槛。原型不是收益，释放的工时也不是现金。
  • 2026年11月三条车道与交接陷阱为什么不是每个问题都需要四个人、为什么应用型构建者是现代工程中最危险的招聘，以及如何解决企业生产交接危机。小组拥有实验，直到它能说出谁拥有结果。
  • 2026年11月分层能力：扩展小组而不膨胀如何在企业内扩展前沿部署工程而不制造一支咨询顾问大军。区分部署小组与永久能力、三层架构，以及保护组合经济性的缺失的第五职能。
  • 2026年11月四种智能，一套驾驭机制企业前沿小组的解剖：角色、运营比例，以及防止 AI 转型退化为昂贵混乱的缺失的第五职能。为什么最危险的招聘是无法调试的构建者。
  • 2026年11月重建企业的四种人如何组建最小的企业团队，将新兴技术转化为可衡量的组织优势。停止招聘单体式 AI 团队。最小可行前沿单元：前沿负责人、创意技术负责人、应用构建者、领域倡导者。
  • 2026年11月打造他们能留下的东西传统咨询模式是为永久依赖而设计的：解决眼前的危机，让客户离开你就无法运营，然后出售续约。下一代合作伙伴关系以能力转移为契约、衡量和奖励标准。
  • 2026年11月我们都是客户客户支付发票，但他们并不是工作的最终评判者。在指导委员会和 KPI 仪表盘之外，有一个努力度过每一天的真实的人。客户不是流程末端的一个指标，而是流程存在的理由。
  • 2026年11月AI 让距离变得难以承受在构建缓慢的时代，代理商与客户之间的距离是一种可以接受的税。随着 AI 原生的构建循环和前沿部署工程的出现，执行能力已不再稀缺。稀缺的是上下文、判断力和信任。当构建成本下降时，误解的成本就会上升。
  • 2026年11月拥有网络之长，而不付网络之税跨类别的灵感、全球专业深度和规模经济，确实是代理商网络的真正优势。但客户不应为碎片化的人员配置、重复的交接或控股公司的政治斗争买单。广泛共享专业知识；在本地保留问责。
  • 2026年11月成为组织肌理专职人员、共享系统、持续的上下文和嵌入式专业知识，如何取代外部供应商与内部客户团队之间的旧有割裂。受雇于外部，绝不意味着理解也在外部。
  • 2026年11月客户不是一个客户账号服务客户的组织，绝不能变得比被服务的客户更重要。为什么下一代代理商必须成为运营肌理的一部分，而不是围绕工作的又一层官僚机构。
  • 2026年10月由陌生人构建的软件的终结不理解业务的人，仍在为其他人挑选必须使用的软件。代理税就是这种距离的代价。领域专家应当塑造系统，而技术专家应站在他们身旁：必须可靠的东西集中管理，应当富有想象力的东西分布开来。
  • 2026年10月入学考试已经消失。工具不仅让现有的玩家更快，还让从未进入过这个行业的人得以进入市场。工程能力不再总是拥有产品的前提。市场正在取代机构，成为新的入学考试。
  • 2026年10月匿名化让人安心，但它并非匿名化。重新排列 ID，让欧洲数据集看起来抽象，并不是匿名化。GDPR 仍然将其视为个人数据。这种安心仪式让曾经负责担忧的人退场，却把一份个人履历交给了模型。把许可权交给工具。
  • 2026年10月工单队列是一种配给制度分析师的仪式（工单、数据管理员、数据仓库、仪表盘、幻灯片）配给了一个查询成本高昂的世界。AI 原生的工作是与整个数据资产在几秒钟内的对话。真正的约束是：如何给他们这种自由，同时不对人撒谎。
  • 2026年10月共享分类体系，否则免谈同一个“人”有十四种定义，Agent 就不可能是 AI 原生的。共享分类体系就是契约：实体、粒度、所有者、保留策略、司法辖区，像技能一样加载。跳过它，每个工具都会变成一种私有方言。
  • 2026年10月图与向量是工具，不是宗教向量找到“感觉相似”的东西。图知道“谁是同一个人”，以及哪个连接是允许的。通过 MCP 在同一套分类体系和同一个终止开关下同时暴露两者。存储选型之争是个错误的论题。
  • 2026年10月官僚体系即将走向自主我们正在教机器执行那些没人记得是谁做出的决策。AI 或许不会消灭官僚体系，而是可能将其工业化。决策债、来源追溯和受控遗忘才是应对之道。
  • 2026年10月为实验室立章程：何时注资、何时关停、法务签什么实验室只有作为铸造厂才有价值。当你能说出四名操作者、一小时级的见证、一个被允许的数据切片，以及一个可以公开日落解散的董事会时，才值得注资。否则别搞玻璃房，直接在业务里运行 FDE。
  • 2026年10月建立实验室：现在就去寻找变革者并给他们工具从想法到执行的鸿沟已经崩塌。实验室不是创新表演，它是 FDE 背后的赋能系统：找到那些已经在主动推进的操作者，本月就把工具套件交到他们手中，把不可替代的人才转化为能够毕业的循环。
  • 2026年10月FDE 前沿：设计能够复利增长的前沿部署团队企业照搬了前沿部署工程师的头衔，却错过了背后的操作系统。FDE 不是特警队、人力外包或 CoE 表演，它是边缘地带的三位一体：操作者、构建者、平台。设计有退出条件的驻留机制，交付工具套件而非幻灯片，并度量循环。
  • 2026年10月技能离开了厂商：当文件夹成为基础设施10月22日，Anthropic 将 Agent Skills 捐赠给 AAIF，70+ 运行时，上百万已发布的技能。一封信仍然可以杀死一个模型，却难以杀死一个行业约定加载的文件夹。建立规范目录树，运行时双源部署，寻找作者而非厂商。
  • 2026年10月数字主线是工具套件，不是口号厂商在卖数字主线。大多数只是 PLM、MES 和一个没人信任的数字孪生之间的幻灯片。把它构建为带所有者、评测、身份和终止开关的技能图谱：主线之上建大教堂，允许旁支消亡。软件 FDE 和硬件 FDE 是同一个操作系统。
  • 2026年10月你的硬件人才一直是瓶颈CAD、固件和测试中的实现工作正在被压缩。硬件组织仍在配给一个“祭司阶层”。稀缺资产是工作台上的 IC：领域知识、品味、认证记忆。找到他们，给他们技能和底线，筛选出那种能从失败循环中写出技能的心态。
  • 2026年9月气隙、开放权重与无法调用 API 的工厂OT、ITAR 和气隙场所无法依赖前沿 API。董事会仍在为这些产线购买 Cloud Copilot。在围栏内运行可移植技能与本地推理，以安全案例开拓 B 市场。磁盘上的工作流所有权才是对冲。
  • 2026年9月大教堂机器与切线夹具Agent 以提示词的速度生成 CAD、HMI 和数字孪生。硬件文化把每个界面都当作资本。两种速度：认证产品和受监管的 HMI 是大教堂；夹具、工装和周二的孪生视图是切线。出生即标注，指派品味，公开退役。
  • 2026年9月产线旁的实验室工业创新实验室通常只是个参观景点。真正赋能的实验室紧挨着工位：寻找非官方的脚本编写者，当月就把一整套角色技能包交到他们手中，每轮循环都执行毕业 / 入库 / 退役，并保留一个技术员一定会按下的停止按钮。
  • 2026年8月部署在产线上的前沿部署工程师工业 AI 正在把 FDE 招入工厂、CAD 和机器人领域。企业会把这一头衔以 SWAT 的形式复制到 OT 中。围绕良率和周期时间设计驻场：流程负责人 + FDE + 平台。交付技术员能留住的技能和评测。这是 FDE OS 的引力版本。
  • 2026年8月世界会崩坏时的评测90% 的通过率在软件里是模型卡，如果那 10% 是一道焊缝，就是一次召回。为从模型到仿真、台架再到产线的阶梯打分。大声失败，引用材料，把急停开关放进路径。没有评测的技能只是一份风格指南。
  • 2026年7月技能成为基础设施Agent Skills 是一个开放文件夹标准，每个严肃的运行时都会加载。渐进式披露、评测优先的编写方式、自然生长的市场、角色技能包、可移植路径，以及一个物理优先的技能库，证明同一个对象能从台架存活下来。别再在 Notion 里收集提示词了。
  • 2026年7月最后一英里从来都是原子软件界刚学会一个模型可能在周五消失。硬件界从未相信过别的。最后一英里从来都是几何、引脚定义、刀具路径，和那台还在发传真的机器。套用同一套 OS——技能、评测、FDE、实验室——而不是一个 Physical AI 卓越中心。引力出现了。
  • 2026年6月急停开关之后：战壕里留下了什么Fable 下线两周后，问题不再是公平与否，而是磁盘上还剩下什么。评测、路由器、开放权重分支、技能文件夹——而不是那封道歉信。租马，但拥有缰绳。无法从笔记本上拷走的能力从来都不属于你。
  • 2026年6月快时尚界面：当每个界面都是临时的，如何指派品味大多数企业 UI 正在变得切线化——为某个用户和某个请求而生，随后被替换。大教堂仍然重要；品味的仲裁者必须治理那些能复利累积的东西。代码编辑器的逻辑遇上组织设计：克隆、反转、混搭、退役。
  • 2026年6月被削弱的前沿模型与开放权重：一线实战者究竟在用什么前沿 API 受政策管控且不连续，欧洲将继续购买被削弱的版本，而董事会还在沉睡。认真的构建者会 fork 开放权重，用自己的数据微调，并在一线共享测试框架。当政策喧嚣四起时，可移植性才是赢家。
  • 2026年6月Fable 指令：当模型战争走向地缘政治在美国出口管制指令下达后，Anthropic 在全球范围内召回了 Fable 5 和 Mythos 5，起因是一类狭窄的越狱漏洞——该实验室称此类漏洞在其他地方已广泛可得。前沿部署如今已成为地缘政治：终止开关、面向盟友市场的削弱版访问，以及实验室逐渐成为美国经济基础设施的核心组成部分。
  • 2026年6月测试框架正变得比模型本身更重要基础模型已经强大到足以支撑严肃的运营用途，但大多数团队仍以模型选择来衡量进展，而不是看智能在与生产环境的接触中能否存活。持久的优势正在转向测试框架：界面、记忆、权限、工作流、护栏，以及让模型每天都能发挥作用的运维层。
  • 2026年6月企业无力循环权力最大的人往往对实际发生的事情了解最少，不是因为他们不在乎，而是因为领导层消费的是业务的摘要，而非亲身体验业务。疏离导致糟糕的决策、更多的汇报，以及与实际工作更远的距离。解决办法是贴近一线，而不是再来一场转型计划。
  • 2026年6月我搭建了一个 Reddit 市场推广引擎，因为产品发布太耗时每次发布都需要同样重复的工作：调研、参考案例、素材、文案、变体。Creative Patterns 发现制胜模式；We Go-To-Market 将其转化为可直接发布的素材。人类担任创意总监；系统负责生产。大多数 AI 产品生成的是输出，而我更感兴趣的是生成整套市场推广系统。
  • 2026年6月Paperclip 与组织级 AI 的兴起大多数 AI 工具都是围绕单一用户设计的。而公司是由职责、审批、交接和预算构成的网络。Paperclip 映射组织结构——组织架构图、目标、心跳、治理——并在这一结构中编排 AI Agent。这是数字组织设计的早期一瞥，而不是又一篇 Agent 框架评测。
  • 2026年5月应对 AGI：从奇点回溯到今天这是一次从奇点回溯到今天的逆向推演，逐层对应马斯洛需求层次。哪些职业会消解，哪些会复利增长，模型构建者欠我们什么，以及认真的人在未来两年应该做什么。这是 dealingwithagi.com 沉浸式作品的文字版配套读物。
  • 2026年5月内部卓越 vs 代理机构燃料：为什么品牌加速两者都需要品牌团队内部的构建能力是真实存在的。正确的解读不是“代理机构已死”，而是内部卓越是成熟度的标志，它将值得保留的代理机构与建立在人力套利之上的代理机构区分开来。新的契约是：品牌团队拥有生产闭环；代理机构提供变革、规模化品味、现实检验和集中式问题解决。
  • 2026年5月快时尚软件：一次性工具，复利式品味未来十年，运营者交付的大多数软件都应是一次性的。快时尚软件是 IC 时代的自然运作模式。复利的部分是底层的技能、知识、品味、品牌，而不是产物本身。
  • 2026年5月技能库：每个 AI 原生团队应优先交付的 20 项可组合能力如果技能是可复用的单元，而 AI Agent 是编排者，那么下一个问题就是先编写哪些技能。二十项命名的、可测试的能力，涵盖写作、视觉、研究、视频和工程，这是能够复利的 IC 级运作层。
  • 2026年5月热工作与深工作：AI 原生运营者的两种模式大多数团队假装工作只有一种模式。其实有两种。热工作带来力量；深工作赢得力量。那些能够命名这两种模式、在两者之间建立节奏、并拒绝将它们悄然混合的团队，将产出未来十年持久且难以被复制的工作成果。
  • 2026年5月思维模式的较量：当人人都有 Claude Code 时，什么来筛选人才？当工具人手一份时，筛选标准就向上移动到思维模式：构建框架的速度、廉价的证伪能力、丰裕环境下的品味，以及对闭环的掌控。2026 年的招聘流程在三年后将变得面目全非，而正确的游戏化评测/训练平台仍是一片广阔的空白。
  • 2026年5月以你思考的速度：弥合构想与执行之间的差距在计算历史的大部分时间里，瓶颈都是将思想转化为语法。键盘在输出过程中总会丢失一些东西。取而代之的是一个能推断你话语中缺失部分的系统，而那些早已知道自己想做什么的运营者，即将看起来如同超人。
  • 2026年5月个人贡献者时代：当工程能力不再是瓶颈二十年来，软件最昂贵的资源是工程师。AI 将工程能力压缩至近乎为零，瓶颈转移到了知道什么值得构建的人身上。IC 时代是结构性的，而非战术性的，它将重塑其底层的组织架构。
  • 2026年5月更多变体很便宜。创意学习才是瓶颈。广告平台生成的内容比以往任何时候都多，但大多数团队都淹没在导出文件中。Creative Patterns 背后的赌注是：付费广告的未来在于自有创意智能和可迁移的记忆，而不是更多噪音，这与 DESIGN.md 和 Stitch 中的机器可读设计理念相一致。

  • 2026年4月当生产免费时，品味、记忆与循环的复利赢家不是拥有最多 AI 变体的团队，而是拥有最紧密创意反馈循环的团队。提取、可审计性，以及与高风险设计系统相同的可防御性工作，应用于你真正拥有的付费投放经验。
  • 2026年4月公开的 /writing：所有权、声誉与论点的机器可读之家为什么在开放网络上建立一个权威的写作界面，胜过把笔记散落在各个信息流中。叙事的所有权、信任的复利，以及一份人类和系统都能阅读的规范——绑定于 agentic 基础设施，而不是别人的算法。
  • 2026年4月发布笔记：当文章是产品而非表演在这里发布内容究竟为构建带来了什么：案例研究、犀利观点和运营纪律——以文字呈现 Strategy、Architect、Build，并有证据支撑网站的其他部分。
