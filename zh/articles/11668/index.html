原标题：Sharpening Tax (2026) Explained for FDEs

FDE Interviews · 2026-10-26 · 约 3 分钟读完

摘要

这篇论文研究后训练如何改变 AI Agent 的成功分布：微调后的模型首次尝试成功率更高，但在多次独立采样下可能反而覆盖更少的任务。作者在 14 组模型对、三个交互式基准上比较基础模型与后训练模型，发现单次准确率与多次尝试后的覆盖率之间常有权衡，并提出“锐化税”指标来概括测试时扩展性的变化。论文还提出 PTGS 方法，在 RL 训练中按题目难度调整采样温度：难题增加探索、易题更集中，受控实验显示准确率与覆盖率均优于固定温度基线。作者提醒：正的税既可能来自丢失可恢复任务，也可能来自成功更快、重试收益减少，需结合绝对成功率、一致性与成本解读。对前沿部署工程师而言，一次性助手与可多次尝试的离线系统需要不同的成功画像，且重试并非免费，涉及 token、延迟与不可逆操作的风险。

要点

  • 后训练可提升首次成功率，但可能降低多次采样后的任务覆盖率。
  • 研究覆盖 14 组模型对与三个交互式基准，发现常见覆盖权衡。
  • 提出 PTGS：按题目难度自适应调整 RL 训练采样温度。
  • 正的锐化税可能源于任务丢失，也可能源于成功更快，需谨慎解读。
  • FDE 应按部署场景定义预算与成功标准，重试有真实成本。

一分钟读懂这篇论文

Sharpening Tax 研究后训练如何改变 agent 的成功分布。一个经过调优的模型可能在首次尝试时解决更多任务，却反复无法解决某个子集，而一个不那么集中的基础策略偶尔能解决这些任务。当系统能够生成多个候选并可靠地识别出成功结果时，这一区别就很重要。

作者在交互式 benchmarks 上比较基础模型与后训练模型配对。基础模型使用一个轻量级 harness 来帮助它们使用所需的接口。该研究报告了单次尝试准确率与多次独立 rollout 后成功率之间频繁出现的权衡，然后引入了一个统计量来概括测试时可扩展性的变化。

论文还提出了后验温度调节组采样（posterior-tempered group sampling，PTGS）。在 RL 训练期间，它估计 prompt 的难度并调整采样 temperature：较难的 prompt 获得更多探索，较容易的 prompt 则采用更集中的采样。报告的受控实验显示，相对于固定温度的基线，准确率和覆盖率都有所提升。

该指标需要谨慎解读。正的 tax 可能是因为策略丢失了可恢复的任务，但也可能是因为它更快地取得成功，因此从重试中获益更少。请将 tax 与绝对成功率、一致性和成本结合起来阅读。official project 和 code 提供了该研究的实现和实验背景。

为什么这对 FDE 很重要

一次性支持助手和离线代码搜索系统需要不同的成功特征。助手可能看重强有力的首个回答和可预测的行为。代码系统则可以承受多次独立尝试，前提是测试能够识别出有用的结果。单一的排行榜分数无法同时代表这两种需求。

这篇论文为这一决策提供了术语，但反复尝试并非没有代价。它们会消耗 token、latency 和评估器容量。对于会改变状态的 AI Agent，重试可能还需要干净的环境或显式的恢复语义；盲目重复一个不可逆的操作并不等同于独立采样。

使用 推理时计算 来定义真实预算，用 轨迹评估 来定义成功。如果系统无法区分好的候选与坏的候选，那么 oracle pass@k 覆盖率就会夸大用户实际获得的结果。
