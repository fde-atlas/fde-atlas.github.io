摘要

FDEInterviews.com 发布的 74 页评测指南，面向前沿部署工程师，讲解如何为 LLM、RAG 和 Agent 构建可信评测。全书分六部分，从定义验收标准、构建数据集，到验证 LLM 评审器、测量重复运行可靠性，再到发布门禁与生产监控。核心观点是：高一致率不等于能抓住关键失败，例如评审器 94% 的一致率下仍有四成真实失败漏检，必须查看混淆矩阵。指南附 Python/SQLite 本地练习包（44 项测试、8 项变异检查）、8 份工作表和十个决策演练，并以虚构的客服退款流程贯穿全书。

  • AI 评测
  • 一套可重复的程序，用于在给定条件下评判一个明确的 AI 系统，使用指定的输入、证据、评分和决策规则。
  • LLM-as-a-judge
  • 一种用于将书面评测标准应用于所提供证据的模型。其错误率和决策覆盖率必须对照经过审查的标签进行验证。
  • Agent 评测
  • 对 Agent 的结果、行动历史和运行约束的评估，包括权威状态和尝试过的行为。
  • pass@k 和 pass^k
  • 分别指 k 次尝试中至少一次成功和全部运行成功。它们回答的是不同的可靠性问题，并需要明确的采样假设。
  • 评测发布门禁
  • 一种预先声明的决策规则，在变更到达用户之前，综合证据有效性、硬性约束、质量比较和运行限制进行判断。
