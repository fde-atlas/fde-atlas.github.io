前沿部署工程师究竟做什么

前沿部署工程师处于平台与部署该平台的客户之间。这是一份真正的工程工作——生产级代码、系统集成、数据建模——但它发生在客户的问题场景中，而非产品路线图之内。Palantir 让这一职位广为人知；随着前沿模型从演示走向生产系统，AI 实验室和企业平台也纷纷采用了这一职位。

这一职位的本质特征是贴近客户。FDE 深度嵌入客户团队：在他们的系统上工作，参加他们的会议，对齐他们的截止日期。这带来了比产品工程短得多的反馈循环，以及对模糊性高得多的容忍度，因为需求规格通常是在工作中逐步发现的，而非直接交付到手。

这不是支持岗位，也不是售前岗位，尽管它与两者都有交集。大多数 FDE 职位要求编写生产级代码，且不背负销售指标——这是判断一个职位名称是否模糊时最明确的检验标准。

日常工作

  • 针对客户现有技术栈构建集成和数据管道
  • 与客户团队一起对工作流程进行原型设计，然后对验证可行的部分进行加固
  • 将模糊的业务问题转化为平台能够实现的功能
  • 将客户反复出现的需求作为真实需求反馈给产品团队
  • 嵌入式或现场办公工作，出差频率因雇主而异

招聘团队的筛选标准

  • Python
  • TypeScript 或其他应用开发语言
  • SQL 与数据建模
  • API 与集成设计
  • 分布式系统基础
  • 云平台（AWS、GCP、Azure）
  • LLM 应用模式（需求日益增长）
  • 直接与客户利益相关方合作

常见问题

  • 前沿部署工程师是一份真正的工程工作吗？
  • 对于大多数职位来说，是的——他们期望的是生产代码，而不是配置。不过这个头衔确实存在被滥用的情况，因此本榜单会根据每个职位的编码强度和面向客户的时间进行评分，而不是只相信头衔。
  • FDE 职位需要多少出差？
  • 从完全不出差到几乎每周出差都有，头衔本身说明不了什么。每个职位的出差要求都会被提取并归入一个区间，你可以按自己能接受的范围进行筛选。
  • FDE 和解决方案架构师有什么区别？
  • FDE 负责构建；解决方案架构师负责设计和评审。在实践中两者高度重叠，有些雇主甚至混用这两个头衔——因此每个职位的评分比其头衔更可靠。
  • FDE 职位的薪酬和产品工程职位一样吗？
  • 在大多数雇主那里，FDE 的薪酬对标同等级别的产品工程岗位，有些还会增加浮动部分。如果职位公布了薪资范围，会在该职位的页面上显示。
