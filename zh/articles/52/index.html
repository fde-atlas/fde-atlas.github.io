AWS 投资 10 亿美元，将 AI 前沿部署工程师嵌入客户团队

原标题：AWS invests $1 billion to embed AI forward deployed engineers with customers

About Amazon · 2026-06-30 · 约 4 分钟读完

摘要

AWS 宣布投入 10 亿美元组建专门的前沿部署工程师（FDE）组织，将工程师与专用 AI Agent 直接嵌入客户团队，把部署周期从数月压缩到数天。该模式以 Agent 为核心，围绕业务成果而非计费小时展开，并在项目中部署语义层与知识图谱，使客户在合作结束后能独立运营。NFL、NBA、Ricoh、Southwest Airlines 等客户已参与，NFL 借此在数周内上线 NFL Fantasy AI 等产品。

要点

  • AWS 投资 10 亿美元组建专门的前沿部署工程师组织
  • 工程师与 AI Agent 嵌入客户团队，部署周期从数月缩至数天
  • 项目按业务成果而非计费小时计价，强调客户自给自足
  • 语义层与知识图谱让专业知识留在客户系统内
  • NFL、NBA、Ricoh 等客户已合作，NFL 数周内上线新产品

核心要点

  • 该组织使用 agentic AI 构建智能体解决方案，将部署周期从数月压缩至数天。
  • AWS FDE 专注于业务成果，并让客户在 AI 方面实现自主自足。
  • 全球客户，例如 Allen Institute、Cox Automotive、NBA、NFL、Ricoh 和 Southwest Airlines，已经在与 AWS FDE 团队合作。

客户已经不再停留在探索 AI 能做什么的阶段；他们希望将 AI 变成自身运营的核心。他们希望用内置 agentic AI 重建业务流程，从而提升生产力并交付 AI 驱动的产品。我也清楚地听到，许多客户需要专业的 AI 工程师直接与他们的团队合作，帮助他们构建并成为 AI 原生组织。

今天，我很高兴地宣布，我们将通过创建一个专门的 AWS 前沿部署工程（FDE）组织来满足这一需求。在 10 亿美元投资的支持下，AWS FDE 模式在三个关键方面与众不同：它以智能体为先，它将时间线从数月压缩至数天，并且它的设计目标是让客户在部署结束后实现自主自足。

AWS FDE 将 AWS 前沿团队——与专门构建的智能体协同工作——直接嵌入客户团队内部。这些经验丰富的工程师，其中许多人构建了我们的 AWS AI 服务，与客户的业务、工程和安全团队合作，使用客户的数据、治理和流程来构建并部署生产级 AI 系统。

与传统的咨询不同——传统咨询进行评估、提出建议，并将每次部署视为独立项目——AWS FDE 着眼于长期构建。客户在 AWS FDE 部署结束后，不仅获得新的解决方案，还获得新的工程能力。除了在他们自己的 AWS 环境中运行的智能体系统之外，他们还获得持久的 AI 技能、工作流和模式，可以用来独立创新。部署围绕共同目标和业务成果来组织，而不是按计费小时计算。客户成功，我们才成功。

AWS 新的工程组织压缩时间线

AWS FDE 使用智能体部署技术和 AI 驱动的开发生命周期——一种新的软件开发方法，强调由 AI 驱动的执行、人工监督和动态团队协作。每个客户项目都会为其下一个项目积累智能。这不是在现有工作流之上叠加的 AI 工具。智能体加速生命周期的每个阶段，而人类工程师负责验证和引导。

一如既往，AWS 合作伙伴将在这里发挥重要作用，贡献模型专业知识、行业知识和互补技能，确保客户获得合适的工程师。我们正在投资合作伙伴培训、工具和资源，以加速 AWS FDE 合作项目。

自信的自主自足

AWS FDE 合作模式在设计上就致力于让客户实现自主。随着项目的推进，客户工程师会从观察者转变为共同建设者，最终成为能够自主运营的运营者。

客户将获得已部署的系统、知识图谱、操作手册、架构文档，以及经过培训、能够独立运营的内部骨干。每一次合作都会沉淀出可编码的专业知识，并在合作结束后长期持续增长。

其核心是一个由 FDE 团队部署到客户自己的 AWS 账户中的语义层。它连接企业数据源，丰富元数据，并利用 AI 发布一个受治理、有版本管理的知识图谱。AI Agent 基于该知识图谱进行推理，因此领域专业知识存在于客户的代码中，而不是存在于可能随人员流动而流失的机构知识中。我们通过客户的 Agent 和系统来交付成果，而不仅仅依赖可能离开的人员，因此收益能够长期持续。

安全性从一开始就内建于其中：基于硬件的隔离、端到端加密，以及永不离开客户治理框架的客户数据。

AWS 如何与 NFL 共同构建

AWS 前沿部署工程师已经深入嵌入 Allen Institute、Cox Automotive、NBA、Ricoh、西南航空和 NFL 等客户并与其开展合作。

“NFL 拥有数百万球迷，他们希望全年都能消费橄榄球内容，包括休赛期。我们以满足球迷高期望所需的速度和规模进行创新，”美国国家橄榄球联盟首席信息官 Gary Brantley 表示。“为了给球迷创造新的数字体验，NFL 与 AWS FDE 合作，让工程师与我们的团队并肩构建，并在短短几周内上线生产环境。我们共同打造了 NFL Fantasy AI 和 NFL IQ 等全新的面向球迷的产品，让球迷能够以前所未有的方式与 NFL 数据互动。球迷和转播商的参与度从第一天起就可以衡量，这一切都得益于 AWS 的交付模式。”

AWS 工程师：您团队内部的专家

自创立以来，AWS 一直与各行业的客户并肩合作，帮助他们构建生产系统，提供经过时间检验的框架、成熟可靠的模式和经验总结。自 2017 年起，我们一直在为客户构建 AI 解决方案——在过去三年中，AWS 生成式 AI 创新中心的工程师已经完成了数千个客户解决方案。他们与 BMW 合作，降低了 2300 万辆联网车辆的服务中断；帮助 Jabil 为工厂车间构建了制造助手；并与 Lyft 合作，将司机支持问题的解决速度提升了 87%。

现在，随着客户要求我们与他们更深入地合作、超越单个用例并帮助他们提升 AI 能力，我们正在扩大对这一方法的投入。AWS 前沿部署工程师（FDE）拥有相关经验和深厚的产品开发专业知识，能够以建设者的身份与客户团队协作。他们带来了 AWS 数十年来在数百万客户用例中积累的经验。

开始使用 AWS 前沿部署工程

AWS FDE 专为那些已经度过试验阶段、需要运行真实业务流程的生产级 AI 系统的组织而打造——尤其是在受监管行业、金融服务和政府领域，在这些领域中，安全性、治理和生产上线速度是不容妥协的。

客户可以联系其 AWS 客户团队，了解 AWS FDE 如何帮助他们实现 AI 目标。
