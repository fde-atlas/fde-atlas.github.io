在客户入驻中平衡人性化关怀与技术

原标题：Balancing the human touch and tech in customer onboarding

Rocketlane · 2021-10-12 · 约 7 分钟读完

摘要

本文整理 Rocketlane 深度对话内容，WeGift 客户成功副总裁 Renata Kashiwaya Pinheiro 分享如何在客户上线流程中平衡自动化与人工服务。WeGift 的上线涵盖 API 集成、商户审批、财务配置与培训，目标 21 天完成，实际常需 3 至 60 天。她建议将欢迎邮件、平台导览等环节自动化，而用例理解、咨询与安抚客户等环节保留人工；即使是技术触达客户，也由 CSM 主持启动会以对齐期望。文中还讨论了反馈收集方法（如 CSAT 优于 NPS）、闭环跟进、常见失败原因及 CSM 所需技能。

要点

  • WeGift 上线目标 21 天，实际常需 3 至 60 天。
  • 欢迎邮件、导览等可自动化，咨询与安抚需人工。
  • 技术触达客户也由 CSM 主持启动会对齐期望。
  • WeGift 认为 CSAT 比NPS更适合其场景。
  • CSM 需具备化解冲突、提问与项目管理能力。

总结博客内容

在第三期 Deep Dives 系列活动中，WeGift 客户成功副总裁 Renata Kashiwaya Pinheiro 与 Rocketlane 的 Srikrishnan Ganesan 一起探讨了客户成功团队如何在客户引导流程中在技术手段与人性化服务之间找到恰当的平衡。

WeGift 是一个数字化支付平台，帮助来自 30 多个国家的企业通过数字奖励、激励和支付推动业务发展。Renata 的 CSM 团队负责客户的整个引导旅程，涵盖 API 集成、商户审批、入驻、财务设置和培训。

在本次活动中，Renata 重点分享了：

  • WeGift 如何在客户引导流程中结合技术触达与人性化服务
  • 为什么客户引导仍然需要人的参与
  • 如何充分利用客户反馈
  • 团队要出色完成客户引导中高接触环节所需的技能

以下是我们从本次活动中总结的关键要点。

WeGift 的客户引导流程主要聚焦于：

  • API 集成：由客户方完成，WeGift 的解决方案工程师提供支持
  • 商户审批 + 入驻：将客户偏好的商户接入平台
  • 财务设置：处理内部审批、开票、转账等事宜
  • 平台培训
  • 引导的目标是让客户在 21 天内上线运行。不过，根据客户的具体需求，实际往往需要 3 到 60 天不等。

凡是不需要人工交互就能创造价值的环节都应自动化，而不是用人力去填补产品空白。以下是 Renata 推荐的方法：

  • 可以自动化的环节：欢迎邮件、平台引导导览、调查问卷发布、基于触发条件的操作手册、团队介绍（视频形式）
  • 需要人性化服务的环节：了解使用场景、根据客户目标灵活调整、提供咨询、解答疑虑，并让客户确信他们的处境和需求已被充分理解。
  • 在 WeGift，即使是技术触达型客户，启动会也由 CSM 主持，借此机会对齐预期、为客户指引相关资源，并解答疑问或消除顾虑。
  • 对于企业级客户，CSM 会定期与客户会面，有时每周多达两次，以确保客户在整个引导过程中得到支持，并保证上线按预先商定的时间表推进。
Rocketlane 如何做客户引导：人员、流程、工具
  • 任何引导项目都需要清楚了解客户的期望以及他们衡量成功的标准。最佳时机是启动会议，在会上应讨论并就所有预期达成一致，包括时间表、人员管理、干系人管理等各方面。
  • WeGift 客户成功团队利用启动会议向客户介绍他们上手过程中将接触到的关键团队成员，说明各自的职责，并在各个接触点上对齐双方的期望。

然后，他们会在两个阶段评估客户期望的达成情况：

  • 客户首次能够使用其产品时
  • 客户在有意义的活动场景中独立使用产品时

这项评估包括了解：

  • API 是否按预期运行，以及实施起来的难易程度
  • WeGift 客户成功团队是否能够高效地管理沟通
  • 客户的疑问是否得到了充分的解答与支持
  • 客户使用其平台的难易程度

这为他们提供了必要的洞察，以弥补客户上手流程中的不足，并帮助他们持续改进上手体验。

如何成功举办客户上手项目的启动会议

帮助 WeGift 改进客户上手流程的两大关键变革是：

  • 尽可能实现自动化：包括视频演示、旅程各阶段可随时发送的模板消息、在在线客服中提供知识库文章等。
  • 在启动会议等阶段增加人力资源：将每个项目都强制要求由 CSM 主持启动会议，而不是直接按默认任务清单开始项目
  • 确保每一个反馈收集点/阶段之后都有相应的闭环行动。例如，高 CSAT 分数可以通过感谢邮件或案例研究邀请来跟进，而低分数或负面反馈则可用于发起复盘电话，以挽回局面或规划重新上线。
  • 让客户知道他们的反馈已被重视的一个好方法是：将基于反馈所做的任何变更通过邮件、新闻通讯或会议告知客户。
如何就客户上手体验收集可执行的反馈
  • 确保反馈收集问卷的措辞和时机都恰当（例如，仅在客户与平台/解决方案充分互动之后再进行）
  • 针对不同的客户群体使用合适的反馈收集方法。WeGift 团队发现在他们的场景中，CSAT 比 NPS 更有用。
  • 通过提问来评估人性化服务的有效性。例如：客服团队是否理解了您的问题？您是否感受到了共情与关怀？
  • 在上手旅程中标记“顿悟”时刻，并在这些时刻前后分别使用问卷
  • Renata 推荐 Attest 博客，其中提供了设计高效问卷的技巧和资源。
  • WeGift 团队使用客户成功平台 Planhat 来进行问卷/反馈收集。他们确保：(a) 问卷问题会根据回答触发后续追问；(b) 低分数会触发警报，提醒 CSM 进行跟进
  • 期望设定不当：这是项目开始时没有讨论、量化和对齐期望的直接结果
  • 沟通断层：入职团队在两次更新之间等待过久，或只在里程碑时才分享进展，而不是在需要时随时分享阶段性更新
  • 缺乏固定的沟通节奏：这可能导致因客户组织内部变动而引起的范围变更被遗漏。
客户实施中你可能犯的十个错误

优秀 CSM 需要的三项技能：

  • 处理并化解紧张局面的能力
  • 提前提问的能力
  • 基本的项目管理能力，尤其对于高接触的复杂客户入职
  • CSM 招聘：WeGift 的招聘流程包含一项任务，用于评估候选人是否适合该职位。任务会给候选人一个客户入职场景，并要求他们制作一份从签约到上线的演示文稿。

评估内容包括互动模式、干系人管理、双方的上报机制、时间线等。

  • 持续迭代，确保即使是自动化或技术触达的元素，也能根据人工反馈进行调整。
  • 充分发挥人工触达的作用：(a) 庆祝成功（例如，在上线时分享礼品或关怀礼包），(b) 解决问题（例如，在收到负面反馈或调查回复后立即跟进）

前沿部署工程师（FDE）会深入客户环境，负责实施、定制并落地运营复杂产品。他们打通集成障碍、修复数据问题、调整工作流程并弥合工程差距——大幅加速客户上线、产品采用和价值实现，远超传统售后角色的作用。

70–85% 的资源利用率。G2 评分 94%。

一个平台即可完成上表试图拆分到多个工具中的全部工作。

企业实施失败的原因在于客户不遵循流程，或未能按时提供干净的数据。大多数延误纯粹是“客户侧”的问题。

实施失败是因为复杂环境需要实时的技术问题解决能力。FDE 能够打通传统上线团队无法独立解决的工作流程、集成和未知限制。

获取更强大的一体化 PSA

与传统售后模式相比，将工程师直接派驻到客户处的公司能显著提升企业客户留存率——因为驻场工程师能发现工单队列中永远不会浮现的“未知问题”。
