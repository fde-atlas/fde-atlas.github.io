摘要

Crack ML Interview 整理的前沿部署工程师（FDE）面试备考资料：介绍 FDE 与产品工程师、售前工程师等角色的区别，归纳五轮面试流程（问题拆解、实战编码、部署系统设计、AI/LLM 应用、行为与客户场景），并提供 79 道练习题、13 家公司信息及 504 个在招岗位。公开可查的 FDE 面经很少，仅 17 道题和 3 篇经验帖来自真实 FDE 面试，其余为编辑推断。

要点

  • FDE 驻客户现场，交付生产代码与集成，考核客户成果。
  • 面试五轮：拆解、实战编码、部署设计、AI 应用、行为客户。
  • 仅 17 道题来自真实 FDE 面试，含 OpenAI、Anthropic、Palantir。
  • 提供 79 道练习题、13 家公司资料和 504 个在招岗位。
  • AI 公司看重模型 API、检索、Agent 与评测，而非训练理论。

前沿部署工程师与客户一起、在客户的系统内部构建软件。他们的面试直接考察这一点：界定模糊的业务问题、针对真实数据和 API 进行实战编码、为客户环境进行设计，以及应对客户。本节汇总了我们从面试反馈中了解到的信息、针对每一轮的指导建议，以及 79 道经过审核的练习题。

前沿部署工程师做什么

FDE 是被分配到客户而非某个产品领域的软件工程师。其工作是让产品为某一个客户产生真实成果：理解他们的问题和数据，把产品接入他们的系统，编写缺失的代码和工作流，将其投入生产，并把重复出现的模式反馈给产品团队。这一角色常见于其产品是需要为每个客户进行适配的平台的公司，如今包括大多数向企业销售 AI 系统的公司。

我们的推断（编辑观点）

大多数面试流程的常见形态

  • 招聘官初筛：背景、从事 FDE 工作的动机、出差意愿。
  • 技术初筛：实践性编程，通常涉及 API 或数据文件。
  • 现场或线上现场面试，通常包含以下四到五项：问题拆解、实操编程、部署系统设计、AI / LLM 应用、行为与客户沟通。
  • 有些公司还会增加带回家的作业或对过往项目的演示。

根据岗位职责以及同公司软件和 AI 工程面试流程中报告的轮次推断得出。请将其作为规划参考，而非任何公司的官方流程。

常见问题

  • 前沿部署工程师是做什么的？
  • 前沿部署工程师（FDE）是一种直接与客户合作的软件工程师，其职责是让产品在客户的环境中真正产生效果：界定问题、与客户的系统集成、编写生产代码和工作流，并将所学反馈给产品团队。
  • FDE 与 FDSE 或“部署策略师”是一回事吗？
  • 职位名称因公司而异。前沿部署软件工程师（FDSE）和前沿部署工程师通常指的是同一个工程岗位。有些公司会将其与一个技术性较低、负责客户关系的部署或策略岗位搭配；请阅读职位描述，了解该岗位需要编写多少代码。
  • FDE 面试与软件工程师面试有何不同？
  • 纯算法题会更少，而更侧重实际工作：拆解模糊的客户问题、针对杂乱的数据和 API 编码、在客户的约束条件下设计系统，以及客户角色扮演。对代码质量和沟通能力的要求都很高。
  • 前沿部署工程师需要机器学习知识吗？
  • 在 AI 公司，应用层面的知识很重要：基于模型 API 构建、检索、AI Agent 和评测。深度模型训练理论很少是考察重点。我们的 AI 应用轮次指南涵盖了通常需要掌握的内容。
  • 我应该如何在两周内做好准备？
  • 阅读五个轮次指南，然后把大部分时间花在实践上：做两三道涉及 API 和数据的实用编程题、两道部署设计题、一次口头拆解案例演练，并为行为面试轮准备一套故事素材库。使用 AI 面试官进行限时模拟面试。
