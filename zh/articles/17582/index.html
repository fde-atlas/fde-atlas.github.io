Hugging Face AI Agents 课程：FDE 学习指南

原标题：Hugging Face AI Agents Course: An FDE's Study Guide

FDE Times · 2026-10-08 · 约 4 分钟读完

摘要

文章评析 Hugging Face 2025 年发布的免费 AI Agents 课程（Apache-2.0 许可），面向想转型 FDE 的开发者。作者指出课程最有启发性的对比：Unit 1 测验需 80% 及格，而结业认证只要求自建 Agent 在基准测试中超过 30%，说明让 Agent 真正解决问题远比掌握理论困难。课程涵盖 smolagents、LlamaIndex、LangGraph 三个框架，每章约需 3-4 小时。作者建议不必按顺序学习：先快速通过 Unit 1 拿基础证书，Unit 2 深入一个框架即可，Unit 3 当作客户需求分析练习，并在 Unit 4 之前先学可观测性与评测的附加单元。求职简历上应写明基准分数及提升过程，而非仅写“完成课程”。

要点

  • Unit 1 测验要求 80%，结业认证只要求基准超 30%。
  • 课程免费、无截止日期，证书也免费，采用 Apache-2.0 许可。
  • 三个框架中深入一个即可，概念比库更重要。
  • 应在 Unit 4 之前先学可观测性与评测附加单元。
  • 简历应写明基准分数和提升方法，并附 Hub 链接。

对于想成为 FDE 的人来说，这门课真正的启示是：让一个可用的 Agent 达标所需的门槛很低，而且各单元不必按固定顺序学习。

简要概述

  • 该课程由 Hugging Face 于 2025 年以 Apache-2.0 许可证发布，完全免费，包括内容和证书在内，且没有截止日期
  • 单元 1 的证书要求测验达到至少 80%；结业证书只要求你的 Agent 在基准测试中得分超过 30%。这个差距正是 FDE 工作的本质
  • 在学习单元 4 之前先学关于可观测性与评测的附加单元：如果你无法度量，就无法提高分数

要获得 Hugging Face AI Agents 课程的单元 1 证书，你需要期末测验达到至少 80%。要获得整个课程的结业证书，你构建的 Agent 只需在期末作业的基准测试中得分超过 30%。这两个数字几乎说明了这门课程的一切，也说明了 FDE 工作的一切。

正确回答理论问题很容易。而基准测试的门槛低得多，这表明让一个 Agent 真正解决问题要难得多。对于前沿部署工程师来说，重要的问题不是你对工具调用了解多少，而是你的 Agent 能否在真实数据上运行。

如果你是拥有 2–8 年经验、希望转型 FDE 岗位的开发者，这门课程值得花几周时间学习。但你不必按照它编排的顺序来学。

四个单元，两个证书级别

这门课程的正式名称是“Welcome to the 🤗 AI Agents Course”。它于 2025 年在 huggingface.co/learn/agents-course 上线，由 Ben Burtenshaw 和 Sergio Paniego 维护，由 Joffrey Thomas 和 Thomas Simonini 编写和开发。整个代码库以 Apache-2.0 许可证开源。

Hugging Face 将课程目标描述为使用三个框架——smolagents、LlamaIndex 和 LangGraph——从“理论、设计和实践”三个层面学习 AI Agent。先修要求是基础 Python 和对 LLM 的基本理解。每个章节设计为一周学习时间，大约 3–4 小时。

入门之后是四个单元：单元 1 讲基础，单元 2 讲框架，单元 3 讲用例，单元 4 是期末作业，按基准测试评分。附加单元涵盖函数调用的微调、可观测性与评测，以及一个玩宝可梦的 Agent。学员还可以在 Hub 上分享自己的 Agent 并相互竞争。

证书完全免费，且没有截止日期。基础级证书在完成单元 1 后颁发；结业级证书还需要完成一个用例作业和期末挑战。

如果你的目标是成为 FDE，应该按什么顺序学习？

建议不要给每个单元同等的权重。如果你已经调用过 LLM API，就可以快速过一遍第 1 单元：这个阶段的目标是拿到基础证书，然后尽快进入实操。

第 2 单元教授三个框架。选一个深入钻研；另外两个略读即可，了解它们的差异。真正值得带走的能力，是识别同一个 Agent 概念用三种不同方式写出来的样子，而不是死记三个 API。

第 3 单元讲用例，在这里你应该开始不看示例直接写代码。把它当作一次客户调研练习：像阅读客户需求一样阅读任务简报，然后问自己输入数据长什么样、Agent 允许调用哪些工具，以及什么才算“完成”。

接下来是最重要的部分，也是需要调整顺序的地方：在第 4 单元之前，而不是之后，学习关于可观测性与评测的附加单元。如果你看不出 Agent 在哪一步出错、哪些工具调用是多余的、哪里过早停止，你就无法提升基准测试分数。这种“运行、测量、修复、再运行”的循环，是一个值得现在就养成的习惯。

如果你已经多次见过你的 Agent 以错误的格式调用工具，那么关于函数调用微调的附加单元值得一学。Pokemon 那个单元留到空闲的周末再玩。

30% 这个数字教会了我们什么？

这也是为什么值得注意，课程把 smolagents、LangGraph 和 LlamaIndex 放在同一个单元里。这种安排暗示：概念才是持久的资产，而库随时可以替换。

从这个角度看，30% 的及格线不应被解读为宽松。它可以理解为一种信号：Agent 在真实问题上还远不完美，而你的价值在于一步一步、有意识地推动那个数字上升。

这也正是写简历的方法。不要止步于“完成了 Hugging Face 的 AI Agents 课程”。要写明你的 Agent 在第 4 单元基准测试中得了多少分、你做了哪些改动让它从一个水平提升到下一个水平，并附上 Hub 的链接，让面试官可以自己运行它。

阅读 FDE 职位描述时，留意 evaluation、observability、tool calling 这类词。如果它们出现了，你就已经有可以谈论的项目了。

印着你名字的证书是免费的。基准测试上的那个数字，以及你如何把它推上去的故事，才是 FDE 招聘经理想听到的。
