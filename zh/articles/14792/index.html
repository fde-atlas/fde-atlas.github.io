Decagon 的前沿部署工程师：职位、薪资与面试（2026）

原标题：Forward Deployed Engineer at Decagon: Role, Salary, and Interview (2026)

fde.directory · 2026-10-30 · 约 4 分钟读完

摘要

本文介绍 Decagon 的前沿部署工程师岗位。Decagon 按对话或解决量收费，只有 Agent 真正在客户工单系统里跑通才有收入，因此部署能力是核心。岗位隶属售后运营下的 Agent Builder 团队，工作以配置 Agent 规范（AOP）、搭建评测与回归测试框架为主，而非现场写软件。要求 5 年以上客户侧技术经验，AI 经验非必需。SF/NYC 基本工资 17.5 万至 23 万美元加股权。文章还梳理了约 3 至 4 周的面试流程及适用人群。

要点

  • Decagon 按对话或解决量收费，部署质量直接决定收入。
  • FDE 岗位属交付团队，核心是编写 AOP 与评测框架。
  • 要求 5 年以上实施或解决方案工程经验，AI 经验可选。
  • SF/NYC 基本工资 17.5 万至 23 万美元，低于前沿实验室总包。
  • 面试约 3 至 4 周，含编码、LLM 系统设计与项目深挖。

Decagon 以一种按效果计费的定价模式销售客服 AI Agent，这使得其前沿部署工程师成为公司里最重要的人。根据其 2024 年 12 月的定价文章，Decagon 按对话收费，或按更高的单价按成功解决收费（如果 AI Agent 转人工则不收费）。只有当 AI Agent 真正能在客户混乱的工单系统里正常运转时，收入才会产生。这是一个部署问题，而 Decagon 招聘 FDE 正是为了解决这个问题。

这家公司的发展速度足以值得关注。据 The Information 报道，Decagon 截至 2024 年底的年化收入约为 1000 万美元；2026 年 8 月，公司告诉 Newcomer，其收入已突破 1 亿美元。这是公司自行披露的数据，并非经审计的数字。在 2026 年 3 月的员工股份回购时，其员工人数超过 300 人。

这个职位背后的公司

Decagon 由 Jesse Zhang（CEO）和 Ashwin Sreenivas（CTO）于 2023 年 8 月创立，已完成五轮定价融资，共筹集约 4.81 亿美元。最近一轮是 2026 年 1 月的 2.5 亿美元 D 轮融资，估值 45 亿美元，由 Coatue 和 Index Ventures 领投，约为 2025 年 6 月 15 亿美元估值的三倍。据报道，其客户包括 Avis Budget、Hertz、Block、Affirm、Chime、Varo、Deutsche Telekom 和 Grubhub。该公司声称平均拦截率超过 80%。

这份工作到底是什么

我们能读到的招聘启事是 Forward Deployed Engineer, Agent Builder，工作地点在旧金山或纽约，隶属于 Decagon 称为 Agent Builder Org 的团队——售后运营（Post Sales Operations）下属的一个“技术交付团队”。注意它的归属：既不在工程部门，也不在销售部门，而是一个交付职能。

根据招聘启事，工作内容包括：

  • 负责企业级 AI Agent 构建项目，从需求界定到上线和迭代
  • 编写并维护定义 AI Agent 行为的文档（Decagon 称之为 AOP，即 Agent Operating Procedures，Agent 操作规程），然后针对质量和可靠性进行调优
  • 配置并验证防护栏
  • 搭建并测试集成（工单系统、内部工具），并构建所需的各类工具
  • 与客户的高级技术利益相关方商定成功标准
  • 将客户洞察反馈给工程部门

澳大利亚的一份姊妹招聘启事，职位名为 Agent Deployment Engineer，补充了值得细读的细节：通过根因分析调试“概率性和技术性故障”，以及构建评测和回归测试框架。两份招聘启事均未提及出差。

有两点值得注意。首先，这份工作更接近于配置与评测类工作，而不是 Palantir 那种在现场编写软件的模式。核心产物是 Agent 规范及其配套的测试框架。其次，入职门槛看重的是资历，而非 AI 经验：要求在面向客户的技术岗位（解决方案、前沿部署或实施工程）拥有 5 年以上经验，而 LLM 或 Agent 经验只是“加分项”。如果你是来自 Salesforce 或 Zendesk 生态的优秀实施工程师，这就是一扇门。可与 Sierra 对比，后者采用类似的 Agent 部署模式。

职位名称不断变化

如果你搜索这个职位，会发现它有多个名称。Decagon 自己的招聘页面上显示的是“Forward Deployed Engineer, Agent Builder”和“Agent Deployment Engineer”，而第三方职位聚合网站则将明显等同的岗位列为“Customer Engineer, Agent Builder”，其中还包括一个法语版本。我们可以在原始招聘信息中确认前两个，但无法打开第三个的原始来源，因此请将其视为未经证实。这个规律对你的求职仍然很重要：如果你只按“Forward Deployed Engineer”筛选，会漏掉一部分招聘渠道。

薪酬

职位地点公布薪资
FDE, Agent Builder旧金山 / 纽约$175K–$230K 基本工资 + 股权
Agent Deployment Engineer澳大利亚A$200K–A$270K（标题显示 A$213K–A$266K），含股权

$175K–$230K 是基本工资，这是你应该锚定的数字。它远低于前沿实验室公布的 $350K–$550K 总薪酬区间，也低于 Ramp 公布的区间，我们在我们的 Ramp 分析中介绍过。作为交换，你获得的是一家估值 45 亿美元、据报道年化收入达 1 亿美元的公司的股权。在与实验室 offer 比较之前，请先询问行权价、最新的 409A 估值以及股权刷新政策。澳大利亚那份招聘信息在标题和正文之间不一致，这提醒你要与招聘人员确认薪资区间。

面试流程

Decagon 尚未公布针对 FDE 的具体面试流程，我们找到的第三方指南也明确没有涵盖这一内容。以下是根据候选人反馈和一份第三方指南（techinterview.org，2026 年 10 月更新）整理的工程面试流程；预计你的面试轨道会有重叠，但请与招聘人员核实。

阶段形式反馈内容
招聘人员 / 沟通电话短背景、动机
编程60 分钟实际构建任务；一位候选人反馈是带撤销和重做功能的购物车
系统设计60 分钟偏向 LLM；一位候选人被要求为聊天机器人产品设计安全机制
项目深挖60 分钟对你主导的项目进行多层深入探讨，包括被否决的备选方案
行为 / 文化不定一个出了问题的项目；你如何使用 AI

该指南将整个流程周期定为 3–4 周。最有用的准备是设计题：构建一个能端到端解决工单的 AI Agent，涵盖意图识别、工具调用、升级处理、防护栏和模糊请求。同时准备好回答“你如何定义‘已解决’”，因为 Decagon 自身的定价正取决于此。有一位候选人报告在文化面试环节后立即被拒，所以不要把该环节当作走过场。

谁适合申请

如果你有五年以上的实施或解决方案工程师经验，并希望近距离接触一个有可衡量成果的产品，那就申请吧。如果你想要以出差为主、现场构建软件的工作，或前沿实验室级别的薪酬待遇，那就跳过吧。Decagon 自称是一家办公室办公型公司。

在职位看板上浏览当前的前沿部署工程师职位，或订阅每周摘要。
