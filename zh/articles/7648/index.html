摘要

DeepLethe 在 Hugging Face 上公开了 FDE-Gym 基准的三个完整示例场景。该基准测试 AI Agent 能否胜任前沿部署工程师的工作：进入客户运行环境、理解需求、做出决策并交付可上生产的系统。三个场景分别是校园预订助手、B2B 计费 API 的夜间值班响应、仓库移动机械臂部署。每个场景包含任务说明（分 L0 至 L3 四个信息量等级）、模拟客户环境、利益相关者 NPC、评分器等文件，可配合 GitHub 上的 harness 运行。完整基准含 20 个原始场景及 75 个变体任务，后者仅用于排行榜评分。数据集明确禁止用于训练，并附 canary GUID。

要点

  • FDE-Gym 测试 AI Agent 能否完成前沿部署工程师的实际工作
  • 公开三个示例：校园预订、计费 API 夜间值班、仓库机械臂部署
  • 任务分 L0 至 L3 四级，信息量递减
  • 完整基准含 20 个场景加 75 个保留变体任务
  • 数据禁止用于训练，附 canary GUID

FDE-Gym 示例

来自 FDE-Gym 的三个完整场景，无需申请即可阅读。FDE-Gym 测试 AI Agent 能否胜任前沿部署工程师的工作：进入客户正在运行的环境中，弄清楚其中什么最重要，做出这份工作所需的决策，并交付一个能在生产环境中稳定运行的系统。论文与排行榜：https://fde-gym.com/paper

场景背景
campus_booking校园应用：基于借阅系统和场馆平台的预订助手
oncall_incidentB2B 开票 API：AI 夜间响应员
robot_cell_rollout仓库：五个工位上的移动操作机器人

每个条目都是其场景的原始任务，与完整集合中的内容完全一致：

cases/<scenario>/
  engagement.json    title, what the scenario runs (model gateway, simulated services)
  briefs/L0..L3.md   the task instruction the agent receives, at four levels (L0 says most, L3 least)
  world/             the customer's environment: documents, data, the system as found
  npcs.json          the customer's stakeholders: what each knows, and the contact cost of asking
  build_world.py     builds the agent's workspace
  gen.py, ...        generators for the data and for the held-out production traffic
  services/          simulated customer services, where a scenario has them
  grader.py          replays production on the delivered system and scores it
  truth.json         reference facts used in scoring
  variants.json      scoring anchors (the system as found, the reference solution)

运行案例

这些案例在 FDE-Gym 测试框架上运行：https://github.com/deeplethe/fde-gym（这些文件已使用标签

harness-v1.1.0

验证）。将

cases/

放在

harness/

旁边，或将

FDEGYM_ENGAGEMENTS

指向它。

python3 harness/run.py new   --engagement oncall_incident --level L3 --name oncall-L3-1
python3 harness/run.py serve --name oncall-L3-1
python3 harness/run.py grade --name oncall-L3-1

这 20 个场景的原始任务可在 DeepLethe/FDE-Gym 获取（按需提供）。该基准测试的其余 75 个任务是这 20 个任务的变体，其中客户世界的具体事实有所不同；这些变体任务被保留，仅在排行榜上进行评分。
