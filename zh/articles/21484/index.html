摘要

日本食谱平台クラシル招聘高级前沿部署工程师（FDE），年薪1200万至1800万日元，工作地点为东京都港区。该职位隶属AI业务，围绕面向食品厂商、批发与零售的AI Agent平台Kurashiru AI OS展开。公司认为Coding Agent的进化使软件实现不再是瓶颈，工程师的价值转向深入客户现场、从需求定义到方案落地。职责涵盖问题识别、PoC验证、系统设计（AI-OCR、非结构化数据管道）、全栈开发及上线后的持续改进。要求5年以上Web开发经验、LLM应用开发经验及使用Claude Code等AI驱动开发的经验，并需日语沟通能力。

要点

全文

  • 关于 Kurashiru
  • 以《Kurashiru》《ReshiChalle》为龙头，致力于创造能够照亮人们与社会的业务的Kurashiru株式会社，秉持愿景“BE THE SUN”、使命“持续创造照亮世界的发明”，从食谱视频服务“Kurashiru”到省钱应用“ReshiChalle”，再到“Kurashiru AI OS”，接连不断打造出事业的支柱。 ■ 累计下载量4,400万、日本最大规模的食谱视频服务“Kurashiru” ■ 累计下载量1,500万的省钱应用“ReshiChalle” ■ 面向制造商、批发商、零售商的AI Agent平台“Kurashiru AI OS” 我们一直以来通过“Kurashiru”和“ReshiChalle”，以食谱和实惠购物支撑着消费者的每日餐桌。 而这些餐桌，是由生产、运输、配送食品的制造商、批发商和零售商的现场所支撑的。 然而，这些现场正面临日益严重的劳动力短缺，由此导致的倒闭也接连不断。 守护并拓展日本餐桌理所当然享有的丰富。 为此，我们充分发挥在toC服务中积累的用户基础和海量数据， 用AI直面食品流通中遗留的巨大低效问题，支撑产业现场，持续将高品质的日本食品送到消费者手中。 “用AI重新发明产业形态，将幸福传递给80亿人” 今后我们也将不局限于现有业务的延伸，持续非连续地创造全新的业务。
  • 关于 Kurashiru 的业务
  • ◆Kurashiru 应用下载量突破4,000万，是日本No.1的食谱视频平台。 以“将每天3次的幸福传递给80亿人”为服务使命，致力于打造每天好用、能传递人情温度的服务。 ◆Kurashiru Reward 一款“让日常购物体验更实惠”的购物辅助应用。为购物而前往商店（移动）、查看传单、购买商品、领取收据——这些日常购物行为都会转化为积分，积分可以用来兑换各种特惠。 ◆TRILL TRILL是日本No.1的生活方式平台。不仅提供当下想了解、立刻能派上用场的时尚信息，也呈现涉及恋爱、结婚、金钱、未来等较为认真严肃的内容。 ◆LIVEwith 以“让更多人能活出自我”为理念，为直播主提供支持的直播经纪事务所。目前直播代理人数已突破约1,000名，是日本最大规模的机构之一。
  • 关于文化
  • Kurashiru的VALUE是全体成员共同拥有的价值观！它是成员为实现愿景与使命而自主推进业务的判断基准，也是共同实现愿景与使命的团队全体成员应持有的共同价值观。 ■Ownership 这一项Value体现了在Kurashiru工作时全体成员都应具备的主人翁意识和创业家精神的重要性。我们认为，平时主动成为起点、保持主人翁意识，能够培养出众多经营人才以及在无数关键时刻被委以重任的“修罗场人才”，从而强化组织。 ​ ■Trade on “Trade on”是体现为实现长期可持续增长而进行决策的基准的Value。它表达的理念是：在追求商业成功的过程中，不应以牺牲某人的幸福为代价（Trade-off），而应做出维护所有利益相关者幸福的Trade-on决策。 ■Heart to Heart “Heart to Heart”是实现Kurashiru理想团队形态的Value，体现了源自深厚人际关系的真诚沟通的重要性。我们认为，要跨越创业公司所挑战的高难度山峰，信任关系至关重要。 ■GRIT “GRIT”是表达克服困难与挫折、朝着目标持续努力之力量的词语。这一Value由4个要素构成，我们以它为指针，坚持坚韧不拔的挑战，致力于打造能够产生重大发明的组织。 “Guts（胆识）” 拥有直面困难局面的勇气。 “Resilience（韧性）” 即使身处困境也拥有重新站起的复原力。 “Initiative（主动性）” 拥有发现自身目标并积极投入的自发性。 “Tenacity（执着）” 拥有为实现目标坚持努力到最后的执念。​​
  • 工作环境与制度
  • 以“好好学习、好好工作、好好玩耍”为信条的高自由度环境。Kurashiru以通过薪酬回报为基本前提，并完善了支持有工作意愿者的各项制度。 ◆家庭远程制度 在家人生病等需要照顾家人的日子，可以选择远程办公。 此外，我们还设有“家庭弹性制度”，在工作时间内完成育儿或护理等事务后，可再次打卡并以远程方式继续工作。 ＜＜工程师的工作方式＞＞ 我们还为工程师准备了相应的制度。 ◆完全远程OK 每位员工可自行选择到办公室上班或完全远程办公。 ◆外设购买制度 入职时可购买上限5万日元的外围设备。 所购设备也可在家中自行使用。
  • 各职位的魅力
  • 活跃成员眼中的“在 Kurashiru 工作的魅力”■销售（Kurashiru）：向出 前职：食品制造商销售 能够把我在方案策划阶段通过倾听了解到的内容，“在 Kurashiru 提供支持的基础上对外发布”，这一点非常有魅力，也让我觉得很有乐趣。 当用户，甚至朋友和家人对我说“看起来特别好吃”“我照着做了”时，我就会觉得做这件事太值了，并感到由衷的喜悦。 另外，我当初就是抱着“想用营销视角来做销售”的目标寻找企业，最终决定加入 Kurashiru 的。 从这个意义上说，能够以更宏观的视野带动众多的人、促成态度转变，这与前职有很大不同，也是让我觉得非常快乐的地方。 ■策划：菱田 前职：广告代理店投放顾问 能接触到各种制造商营销课题的机会其实并不多见，而能够认真面对并解决这些课题，正是美食媒体独有的价值。 正是因为“Kurashiru”拥有如此大的规模，才能遇到各种各样的客户。这让我学到很多。 方案的规模也很大，相应地可以追踪到用户的反应和效果，能够亲眼看到营销课题被逐步解决的过程，这一点非常了不起。 ■导演：千代原 前职：媒体广告制作 由于制作的对象都是大家熟知的品牌厂商的东西，责任也很重大，当自己亲手创作的东西走向社会，看到它被电视专题报道、出现在广告里、或通过某种渠道传播时，会有一种“看着自己的孩子成长”的感觉……我想这也是一种工作的意义所在。 ■工程师：yochio 前职：创业公司工程师 “可以做各种各样的事情”正是这份工作的有趣之处。 最近我参与了 CGM 功能的开发，比如实现了短视频界面功能，以及食谱卡片（可通过图片滑动查看的食谱）等功能。 Kurashiru 的开发周期很快，三个月后可能就在做完全不同的事情了。工作内容不断变化，让我个人重新燃起干劲，非常开心。 专注开发容易积累技术债务，但公司也会给你时间去改善这些问题，所以请放心。
  • 职位名称
  • [AI 事业/开发] Senior Forward Deployed Engineer（FDE）
  • 工作内容
  • 随着 Coding Agent 的进化，软件实现本身已不再是瓶颈。对工程师所要求的附加价值，已转变为深入理解客户的本质性课题，并从需求定义落实到具体的解决方案设计与实现。在本职位中，你不仅要作为具备全栈开发能力的 Builder 实现产品，还需要主动深入客户现场，深入理解其业务与课题。从课题识别、原型制作、生产环境实现，到导入后的落地与改善，你将端到端地承担这一系列流程。・识别客户现场课题 通过对客户的访谈和对现场的理解，对复杂的业务流程进行结构化梳理，在识别出本质性课题的基础上，提出具体的解决方案。・解决方案设计 基于 PoC 中获得的验证结果，结合 AI-OCR、非结构化数据管道等技术，设计面向实际运营的系统。・全栈开发 最大限度地活用 Coding Agent，从前端、后端到 AI Agent Harness 的构建，端到端地实现所需功能。・运营、落地与持续改善 通过设计护栏（Guardrail）和微调等手段，运转实际运营中获得的反馈闭环，最大化为客户提供的价值。
  • 期望的经验与技能
  • ・Web 应用开发经验（5 年以上）・使用 REST API 及数据库（RDB）进行后端设计与实现的经验・利用 LLM（OpenAI API、Claude API 等）开发应用的经验・使用 Claude Code/Codex 等进行 AI 驱动开发的实践经验（个人或工作均可）・能够用日语顺畅地进行业务沟通的能力
  • 招聘要项
  • 工作地点 东京都港区 薪资 年薪 1200 万～1800 万日元 工作时间 00:00～00:00 ■弹性时段：5 点～10 点、16 点～22 点 休息休假 完全周休二日制 结婚假／陪产假／庆吊假／生理假／（每月最多 1 天）／产前产后假／育儿假／护理假 待遇与福利 ■社会保险完备、各类休假、育儿与托育支持制度、健康与心理健康支持制度、可兼职（许可制）、面向工程师／设计师的周边设备购买补贴（上限 5 万日元）、表彰制度、社团活动 等
