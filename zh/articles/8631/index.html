基础从概念验证到生产在演示中正确回答了一个问题的 notebook 并不是交付物。生产化是那些不起眼的工作，它把一次性的成功变成客户可以在没有你在场的情况下运行、信任和运维的系统。弥合这一差距是 FDE 工作的大部分内容。

基础重试、指数退避与抖动当调用因瞬时错误而失败时，立即重试是最糟糕的做法：它会给本已不堪重负的服务增加负载，并让所有客户端同步形成踩踏。指数退避可以拉开重试的间隔，而抖动则让客户端去同步化，使它们不再齐步到达。

Decagon 的前沿部署工程师面试环节会考察系统设计与生产工程类问题，例如：“你的 Agent 在 8% 的情况下选择弃答，而每一次弃答都变成人工的负担。请设计升级处理系统。”、“你的客服 Agent 下个月就要上线。请定义其 SLO、错误预算，以及预算耗尽时会发生什么。”、“至少一次投递与恰好一次投递有什么区别，为什么 FDE 需要关心这一点？”。Palantir 式的问题拆解、POC 的生产化、客户事故调试、可观测性、VPC/物理隔离部署：演示如何变成真正的部署。完整题集按从易到难排序并附专家答案，见下方。
