Sierra RAG 与 Agent 系统设计轮背后的概念

这些题目所假设的术语和思维模型。基础内容免费；更深层的、决定面试成败的理念属于付费内容。

基础检索增强生成（RAG）RAG 通过在查询时检索相关段落并将其放入提示词中，使语言模型基于你自己的数据作答，从而让模型依据真实来源而非记忆来回答问题。这是几乎所有企业级 FDE 部署的默认模式，因此几乎每个招聘流程都会考察它。

基础向量数据库向量数据库将嵌入向量与元数据一起存储，并使用近似索引快速回答最近邻查询。真正的面试问题不是它们如何工作，而是你什么时候真正需要一个向量数据库，而不是一个库或使用 pgvector 的普通 Postgres。

基础AI Agent 与工具使用Agent 是被包裹在循环中的语言模型，这个循环让它选择工具、执行操作、观察结果并决定下一步做什么。面试官考察的技能是判断力：知道这个循环何时值得它的不可预测性，何时固定流水线更便宜、更快、更安全。

Sierra 的前沿部署工程师面试循环包含诸如“什么时候 Agent 是错误的答案？请论证为什么不该构建一个。”、“设计一个带订单状态和退货工具的客户支持 Agent。你如何保证它安全且有用？”、“某品牌想要一个从不提供财务建议、始终保持品牌语气、且从不提及竞争对手的 Agent。请设计相应的防护机制。”等 RAG 与 Agent 系统设计题。检索流水线、分块、重排序、使用工具的 Agent、防护机制、多租户和评测框架：这是 OpenAI、Anthropic、Sierra、Glean 和 Scale 最典型的 FDE 设计轮。完整题集按由易到难排序并附专家答案，见下方。
