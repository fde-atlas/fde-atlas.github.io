摘要

DeployedJobs 统计目前有 413 个应用 AI 工程师职位，是平台上增长最快的职位类别。该职位多见于前沿实验室和平台公司，核心是围绕他人训练的模型做系统工程：检索、评测、Agent 设计与工具调用，并常直接面向客户。文章区分了应用 AI 工程师与 FDE 的侧重差异，并指出微调在实际工作中并不常见。

要点

  • DeployedJobs 收录 413 个应用 AI 工程师职位，为增长最快的类别。
  • 工作重心是检索、评测、Agent 设计等模型侧系统工程，而非研究。
  • 多数职位面向客户，分类依据职位描述文本而非头衔。
  • 与 FDE 的区别在于：前者偏模型侧工作，后者偏嵌入式客户关系。
  • 微调出现频率低于求职者预期，评测能力更受重视。

应用 AI 工程师实际做什么

应用 AI 工程师构建产品或部署中面向模型的部分：检索、评测、Agent 设计、工具使用，以及将一个能力强大的模型变成足够可靠、可以交付给用户使用的脚手架。

这一职位随着前沿模型从演示走向生产而出现，通常指的是应用工作而非研究工作。一些职位描述中会出现训练和微调，但重心是围绕他人训练的模型进行系统工程——以及日益重要的评测工作，它能告诉你系统是否真正有效。

这些职位中有许多是面向客户的，这也是它们出现在本看板上的原因。如果某个职位纯粹是内部产品工作、没有客户接触，那就是顶着类似头衔的另一份工作，分类会如实反映这一点。

日常工作

  • 针对真实客户数据设计检索和上下文策略
  • 构建评测框架，并用它们来判断已上线功能是否有效
  • 提示词和 Agent 设计，包括工具使用和多步骤工作流
  • 将模型接入现有产品界面和数据管道
  • 直接与客户团队合作，确定系统需要实现什么

招聘团队考察什么

  • Python
  • LLM 应用模式——RAG、Agent、工具使用、结构化输出
  • 评测设计与错误分析
  • 向量搜索与嵌入
  • API 集成与后端工程
  • 数据管道
  • 云部署
  • 对模型哪些可信、哪些不可信的判断力

常见问题

  • 我需要机器学习研究背景吗？
  • 通常不需要。大多数应用 AI 工程师的招聘要求扎实的软件工程能力，加上对模型行为的真实判断力，而不是论文发表。研究方向的职位通常称为研究工程师或研究科学家。
  • 这与前沿部署工程师有什么不同？
  • 两者有重叠且正在趋同。保留下来的区别在于侧重点：应用 AI 工程师以面向模型的工作为核心，而 FDE 以深入客户内部的合作关系为核心。很多职位实际上两者兼具，因此在这里同时标注了两个标签。
  • 微调是这份工作的一部分吗？
  • 有时是，但比候选人预期的要少。在大多数生产系统中，检索、评测以及提示词或 AI Agent 设计承担了更多的工作量。
