Agent 开发简介：Decagon 如何重新定义前沿部署

原标题：Introducing Agent Development: How Decagon is redefining forward deployment

Decagon · 2026-10-30 · 约 5 分钟读完

摘要

Decagon 的 Agent PM 撰文回顾公司从约 20 人扩张到近 500 人的过程中，前沿部署团队角色的演变。作者认为，仅靠“英雄式”嵌入客户现场的做法无法规模化，成功的 FDE 需要成为系统思考者，把交付流程当作系统来设计。为此 Decagon 成立了 Agent Development 团队，专注从零到一将 AI Agent 上线并让流程可复用。通过梳理不必要的定制工作并转为自助化路线图，单个 Agent 的定制工程量减少 80%，原本需要一个冲刺的促销政策改造现在一下午即可完成，Agent Development Manager 接手了大部分原本需要工程师的构建工作。作者认为交付能力正成为产品护城河，并以此招聘。

要点

  • 前沿部署团队已成为 AI 公司标配，但“英雄式”打法难以规模化。
  • 成功的 FDE 应是系统思考者，让交付随每次上线不断改进。
  • Decagon 成立 Agent Development 团队，专注 Agent 从零到一上线。
  • 自助化改造使每个 Agent 的定制工程量减少 80%。
  • 作者认为交付能力正成为新的产品护城河。

文章

前沿部署团队已迅速成为现代 AI 公司的标配。几乎每家公司都有一支这样的团队，充当客户需求与产品之间的桥梁。

传统上，这些团队招聘时看重的是干劲、技术能力和客户同理心。典型的形象是那种深入客户现场、奋力拼搏、为客户不惜一切的“英雄”。这一点至今仍然成立，但随着这些团队规模的扩大，另一种重要特质开始显现：系统思考者。

我近距离见证了这一转变。我在 Decagon 大约 20 人的时候加入，担任创始 Agent 产品经理。如今，我们已有近 500 名员工，前沿部署团队也在不断壮大。以下是我关于如何在这个岗位上取得成功的经验总结。

前沿部署作为瓶颈

大多数前沿部署团队的起步方式与 Decagon 相同。在我入职的头几个月里，对这个角色最简单的描述就是“协调者”：我坐在工程、产品和客户之间，把客户的需求转化为工程任务，或者向客户解释产品的局限。

很早我就发现，这种模式无法规模化。每个客户都会产生源源不断的需求，全部涌向工程团队，而客户自己无法获取所需的东西。这些工作几乎完全是定制的：接线、工作流、边缘情况，一次只能服务一个客户。

只有十个客户时，这几乎不成问题；你可以用蛮力搞定每一次上线。但在 Decagon 这样高速增长的公司，一波需求正在积聚：这是每家公司都渴望的需求，也是会压垮蛮力型团队的需求。下一阶段的增长不会来自更多的人，而是来自更好的系统。

前沿部署作为系统设计

在软件领域，系统设计意味着对应用进行架构设计，使其在负载增长时依然稳固。最优秀的前沿部署团队也以同样的方式看待自己的工作。交付流程应当被设计成能够承接日益复杂的客户，并在每一次上线中不断改进。

系统思考从客户的 Agent 开始。AI 给了你近乎无限的构建空间；同一个结果你可以用十几种方式配置出来，而且大多数都能达标。稀缺的能力是克制与远见：看到二阶效应，选择能够长久的设计，而不是看起来最复杂或最精巧的方案。这种失败模式如今随处可见：Agent 构建逐渐退化成一个由提示词和补丁堆砌而成的黑箱，没人敢碰。系统设计师构建的 Agent，要让客户在一年之后仍然能够理解并掌控它。

同样的直觉还能进一步延伸。系统设计师会把前沿部署团队打造成一台机器：每个人都使用同一套行动手册并不断为其添砖加瓦，让一个人的经验成为所有人的财富。他们还设计整个运作如何与公司其他部分衔接：如何与工程部门协作、如何为产品路线图提供输入、如何为销售策略提供建议。

我们的构建方式：Agent Development

大约六个多月前，我们正是为此组建了 Agent Development 团队：一个专注于将 AI Agent 从零推向生产的“从零到一”过程、并让这一过程不断复利放大的团队。

我们最早的项目之一，与其说是为了某个客户，不如说是为了所有客户。我们梳理了每一处不必要定制化的工作、那些迫使每次构建都需要定制工程的边缘情况和缺口，然后与产品和工程团队合作，将这一分析转化为自助服务路线图。

这使每个 AI Agent 所需的定制工程工作减少了 80%。过去，调整客户的促销政策需要一名工程师花整整一个冲刺周期编写定制代码；现在，一名 ADM 用一个下午就能用自然语言完成设计、调试和测试。Agent Development 经理如今承担了几乎所有曾经需要工程师完成的构建工作，客户也切实感受到了变化：上线更快、更满意，并且对自己正在构建的东西有了更清晰的可见性。

在传统产品护城河几天内就会被复制的世界里，曾经是我们瓶颈的交付工作正在成为新的护城河。

来和我们一起构建

这个职位如今归结为两件事：

  • 做好从零到一： 构建客户喜爱的 AI Agent，成为客户愿意合作的团队，对结果负责，直到 AI Agent 上线，并解决真实的业务问题。
  • 放大从零到一： 让流程每次都更简单，把你曾经手动做过的每一步，变成下一个客户永远无需重复的事情。

能在这个职位上脱颖而出的人，都是具备出色商业直觉的优秀问题解决者。他们以数据为驱动，并且会本能地追问“然后呢？”，追踪一个决策如何向下游层层传导。最重要的是，他们痴迷于构建能够长久存在的优美系统。我们招聘看重的正是这些特质，无论一个人曾经设计过软件、组织、流程还是 AI Agent，这些特质都会以同样的方式显现。

我们相信，这是当今 AI 公司面临的最重要的问题之一，而我们正在 Decagon 打造世界上最优秀的团队来解决它。
