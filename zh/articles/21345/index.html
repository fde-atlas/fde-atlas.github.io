摘要

这是日本招聘点评网站 OpenWork 上 Treasure Data（Treasure AI）的一则 FDE 职位信息。该岗位隶属专业服务团队，实质是解决方案架构师角色，负责客户数据平台（CDP）的导入咨询、架构设计与技术支持。文中介绍了公司价值观、获奖情况、任职要求及待遇：年薪 1000 万至 1600 万日元，含 30 小时固定加班费，工作地点为东京麻布台 Hills，原则上不可远程。要求 2 年以上 SQL 与 ETL 经验，有数据类项目导入背景者优先。

要点

  • Treasure Data 招聘 FDE，实为解决方案架构师角色。
  • 工作内容是 CDP 导入咨询、架构设计与代码评审。
  • 要求 2 年以上 SQL 与 ETL 实务经验。
  • 年薪 1000 万至 1600 万日元，含固定加班费。
  • 工作地点在东京麻布台 Hills，不可远程。
