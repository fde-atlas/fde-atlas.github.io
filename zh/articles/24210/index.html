摘要

DimeHealth AI 在纽约招聘前沿部署工程师，负责医疗客户上线与部署实施。该岗位横跨工程、产品与客户成功，需配置系统集成与 API，排查生产环境问题，并按客户需求定制工作流。要求掌握至少一门编程语言、熟悉 API 与数据库，具备独立工作与客户沟通能力。医疗系统经验为加分项。

要点

  • DimeHealth AI 招聘前沿部署工程师，常驻纽约。
  • 职责包括客户上线、系统集成与生产环境排障。
  • 需会 Python 或 JavaScript，熟悉 API 与数据库。
  • 医疗或受监管行业经验为加分项。
  • 岗位提供股权与高度自主权。

职位要求

前沿部署工程师

关于 DimeHealth AI

DimeHealth AI 构建帮助医疗机构简化运营、改善患者就医渠道并自动化人工流程的软件。我们的平台可与现有系统集成，帮助团队以更少的管理开销更快地推进工作。

职位概述

我们正在寻找一位前沿部署工程师，帮助新客户接入平台并确保部署成功。

该职位处于工程、产品和客户成功的交汇点。你将与内部团队和外部利益相关者紧密合作，实施解决方案、排查问题，并确保系统在真实环境中平稳运行。

你将负责把项目从初始部署推进到生产上线，直接与客户合作，利用软件和自动化解决运营问题。

工作内容

  • 主导新客户的入驻和实施工作
  • 配置与外部系统、API 和第三方平台的集成
  • 排查生产部署中的技术问题
  • 根据客户需求定制工作流和部署配置
  • 直接与客户利益相关者合作，收集需求并推动执行
  • 与工程和产品团队协作，改进部署基础设施和内部工具
  • 识别运营瓶颈并提出可扩展的技术解决方案
  • 协助编写实施流程和最佳实践文档

我们期待的人才

  • 出色的问题解决能力和对细节的关注
  • 至少掌握一门编程语言（Python、JavaScript 或类似语言）的经验
  • 熟悉 API、数据库和系统集成概念
  • 能够在模糊、快节奏的环境中独立开展工作
  • 出色的沟通能力，乐于直接与客户打交道
  • 如有需要，愿意偶尔出差进行客户部署

加分项

  • 接触过医疗系统或受监管环境
  • 有部署或支持生产软件系统的经验
  • 有端到端负责技术项目的经验
  • 对应用 AI、工作流自动化或运营系统感兴趣
  • 有创业公司经验，或适应高自主权的工作环境

你将获得

  • 负责真实的客户部署和技术实施
  • 参与工程、运营和客户成功之间的跨职能协作
  • 有机会与公司领导层紧密合作，参与高影响力项目
  • 快速学习的环境，承担重大责任并拥有高度自主权
  • 有竞争力的薪酬和股权方案
  • 有机会在一家快速成长的初创公司参与制定部署和实施策略
