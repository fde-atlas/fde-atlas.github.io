前沿部署工程经理 - 慕尼黑 | OpenAI

原标题：Manager, Forward Deployed Engineering - Munich | OpenAI

Zero G Talent · 2026-11-09 · 约 4 分钟读完

摘要

OpenAI 在慕尼黑招聘前沿部署工程团队经理。该职位要求 8 年以上工程或技术交付经验，其中 2 年以上管理面向客户的工程师团队，并能用 JavaScript 或 Python 编写和审查生产级代码。经理将带领 FDE 团队把研究成果转化为生产系统，端到端负责交付成果，把现场经验沉淀为工具、手册和路线图输入，并与产品、研究及市场推广团队紧密协作。工作模式为混合办公，每周到岗 3 天，出差比例最高 25%，提供搬迁支持。

要点

  • OpenAI 在慕尼黑招聘前沿部署工程经理，属早期管理岗位。
  • 要求 8 年以上技术交付经验，含 2 年以上管理经验。
  • 需用 JavaScript 或 Python 编写生产级代码。
  • 职责包括带队交付生产系统并沉淀可复用经验。
  • 混合办公每周 3 天到岗，出差最多 25%。

任职要求

  • 8 年以上工程或技术交付经验
  • 2 年以上管理面向客户的高绩效工程师团队的经验
  • 曾带领高压技术项目从原型走向生产
  • 能够编写和评审 Javascript 或 Python 的生产级代码
  • 能在模糊或不断变化的环境中保持紧迫感地开展工作

工作职责

  • 领导并发展一支交付生产系统的 FDE 团队
  • 以清晰和高效掌控端到端的交付成果
  • 将经验总结为工具、操作手册和路线图输入
  • 为 FDE 的表现设定高标准，并支持团队成长
  • 规划可扩展的现场团队的人员配置与支持

关于团队 OpenAI 的前沿部署工程（FDE）团队与客户合作，将研究突破转化为生产系统。我们与用户深度协作，解决高价值问题，快速从原型推进到部署，并提炼出可复用的模式来塑造我们的平台。我们在现场交付与内部开发的交汇处开展工作，与产品、研究和市场推广（GTM）团队紧密合作。

关于职位 作为一名奠基性的 FDE 经理，你将带领 FDE 团队完成高风险、高不确定性的客户部署，并端到端地掌控技术与业务价值成果。你将打造一支能够在压力下运作的团队，并帮助 OpenAI 从一线实践中学习。

你将与产品、研究、销售和 GTM 团队紧密合作，确保一线工作能够为路线图优先级提供依据、推动新的探索，并支持大规模的安全部署。你的决策将影响与我们部署工作最贴近的客户对 OpenAI 的信任。你的成功将以团队交付的稳定性、向研究和产品团队传递信号的清晰度，以及团队和交付模式的持久性来衡量。

该职位位于慕尼黑。我们采用每周 3 天到岗的混合办公模式，并为新员工提供搬迁协助。该职位还需要出差，出差时间最多占 25%。

在这个职位上你将

  • 领导并发展一支使用前沿模型交付生产系统的 FDE 团队
  • 通过清晰、高效、紧密协调和技术质量，掌控端到端的交付成果
  • 将有效经验总结为工具、操作手册和路线图输入，为 OpenAI 及更广泛的开发者社区创造杠杆效应
  • 及早发现各种早期信号并迅速上报，无论是产品行为、客户环境还是交付实践中的问题
  • 运用判断力区分哪些需要采取行动，哪些不需要
  • 为 FDE 的表现设定高标准，并通过直接、可执行的反馈支持每个人的成长
  • 规划如何为现场团队配置人员并提供支持，使其在不增加复杂性的情况下实现扩展

如果你具备以下条件，你可能非常适合这个职位

  • 拥有 8 年以上工程或技术交付经验，其中包括 2 年以上管理高效能 FDE 或面向客户工程师的经验
  • 曾主导从原型到生产的高压技术项目
  • 使用 Javascript 或 Python 编写并评审生产级的前端和后端代码
  • 化繁为简，并在压力下快速做出合理决策
  • 通过清晰的方向而非流程来提升团队表现
  • 能在模糊或不断变化的环境中保持紧迫感地开展工作
  • 将一线经验转化为对产品与研究团队犀利且可执行的反馈
  • 在关键时刻以身作则，展现冷静、专注与判断力，与团队建立深厚的信任
