前沿部署工程师 | Mem0 | 加州旧金山

原标题：Forward Deployed Engineer | Mem0 | San Francisco, CA

Zero G Talent · 2026-07-16 · 约 3 分钟读完

摘要

Mem0 在旧金山招聘全职前沿部署工程师，直接向 CTO 汇报。Mem0 是 Y Combinator 支持的初创公司，为 AI Agent 提供记忆层，已融资 2400 万美元，开源社区超过 15 万开发者。该职位要求驻场办公，深入战略客户，将记忆 API 集成到客户的 AI Agent 中，并把现场经验反馈给产品与研究团队。

要点

  • Mem0 为 AI Agent 构建长期记忆层，融资 2400 万美元。
  • 岗位驻旧金山，直接向 CTO 汇报。
  • 需 4 年以上生产软件开发经验，熟悉 Python。
  • 职责包括客户集成、生产问题排查与路线图反馈。
  • 有 LLM Agent、RAG、向量数据库经验者优先。

职位要求

关于 Mem0

我们正在为 AI Agent 构建记忆层。想象一下，长期记忆让 AI 能够记住对话、从交互中学习，并随时间积累上下文。我们已经在为企业客户和拥有 150,000+ 开发者的开源社区提供数百万次 AI 交互的支持。我们是一家获得 Y Combinator 支持的公司，已从顶级投资者那里筹集了 $24M 种子轮 + A 轮融资。

这是一个全职、驻场岗位，工作地点位于加州旧金山。你将与一支技术实力雄厚的团队面对面紧密合作，快速协作与高速迭代是我们文化的一部分。

该职位直接向 CTO 汇报，隶属于工程部门，使命是将记忆基础设施直接交付到客户手中，并将该领域最棘手的问题反馈到核心产品中。

职位概述

站在工程与客户的交汇点。你将深入 Mem0 最具战略价值的客户，构建集成和定制解决方案，以验证记忆在生产环境中的价值，并将你在一线的所学转化为产品与研究团队的需求。这是一个高度自主的岗位，适合希望在几天内（而非几个季度）看到自己的代码在真实客户技术栈中运行的工程师。

你的工作内容

  • 在售后深入客户现场，设计、构建并交付将 Mem0 的记忆 API 集成到客户 AI Agent 和产品中的方案。
  • 快速原型化并投入生产定制解决方案，为高价值客户扫清障碍，从检索配置到完整的流水线构建。
  • 负责与战略客户的技术关系：排查生产问题，并作为技术升级的对接点。
  • 将一线经验转化为路线图输入：识别反复出现的集成缺口，并反馈给工程与研究团队。
  • 构建可复用的工具、示例应用和参考实现，缩短下一位客户的见效时间。
  • 与销售和客户成功团队协作，共同推进方案界定、技术攻坚和业务扩展机会。

你需要具备

  • 4 年以上生产软件交付经验，具备将 API/SDK 集成到面向客户系统的实际动手经验。
  • 扎实的 Python 基础；能够跨技术栈工作（API、数据流水线、部分前端），为客户扫清障碍。
  • 具备直接与外部客户合作的技术工作经验：解决方案工程、前沿部署工程、技术咨询或类似岗位。
  • 能够适应模糊性和快速变化的需求范围；在缺乏上下文的情况下被投入新问题时，你依然能游刃有余。
  • 具备出色的沟通能力，能够面向技术与非技术受众进行有效交流。
  • 愿意为现场客户合作偶尔出差。

加分项

  • 有使用基于 LLM 的 Agent、RAG、嵌入（embeddings）或向量数据库的经验。
  • 在基础设施或 API 公司从事解决方案工程、前沿部署工程或专业服务的背景。
  • 有在时间压力下构建演示或 POC 的经验。
  • 熟悉生产系统的可观测性与监控工具。

我们的文化

办公室优先的协作方式

我们是一支位于旧金山的线下办公团队。走廊里的交流、白板讨论和即兴协作，让我们比单纯的远程会议更快地推进工作、打造更好的产品。

速度与匠心并重

我们行动迅速，但不牺牲工程卓越。我们构建的每个系统都应快速、可靠、可扩展，并经过精心设计。

极致的主人翁意识

Mem0 的每个人都是建设者和所有者。如果你发现问题或机会，你有权力去解决它。头衔不如影响力重要。

高标准，高信任

我们招聘卓越的人才，给予他们自主权，并以高工程标准要求自己。我们挑战想法、认真评审代码，并共同庆祝成功。

数据驱动，而非自我驱动

最好的想法无论来自谁都会胜出。我们依靠数据、客户反馈和深思熟虑的实验来指导决策。

福利与待遇

  • 医疗、牙科与视力保险 - 全面的保险计划，为你全额承担（家属可享补贴）
  • 免费午餐与晚餐 - 每天在办公室提供餐饮，因为好的食物成就好的工作
  • 灵活的带薪休假 - 按需休假充电，无需死板的额度累计
  • 早期公司股权 - 对你所构建的事业拥有真正的所有权，而不仅仅是一份薪水
  • 定期的团队聚会与活动 - 融入文化之中，而非事后补充
  • 顶级设备 - 为你提供发挥最佳工作所需的笔记本电脑和配置
