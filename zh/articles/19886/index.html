前沿部署工程师（美国）| AiPrise | 加州圣何塞

原标题：Forward Deployed Engineer (USA) | AiPrise | San Jose, CA

Zero G Talent · 2026-03-24 · 约 3 分钟读完

摘要

AiPrise（YC S22 孵化）在圣何塞招聘前沿部署工程师。该公司提供覆盖 200 多个国家的合规编排平台，整合 80 多家身份与合规供应商，服务金融科技与支付企业。该职位要求直接驻场服务大客户，快速构建定制集成并反馈产品路线图。

要点

  • AiPrise 为 YC S22 孵化的合规编排平台，覆盖 200 多个国家。
  • 平台整合 80 多家身份与合规供应商，聚焦 KYB、AML 与风险评分。
  • 前沿部署工程师需嵌入客户现场，当天定位问题并部署修复。
  • 职责包括定制集成、数据管道及将客户需求转化为平台功能。
  • 要求 3 年以上后端经验，熟悉 AWS、REST API 与微服务。

关于 AiPrise

AiPrise 是一家获 YC 投资（S22）的全球合规编排平台，帮助金融科技公司、交易平台和支付公司在全球范围内验证并接入客户。我们与 80 多家身份与合规供应商集成，提供全面的风险视图。我们正在构建 AI 驱动的合规 AI Agent，以变革 KYB、AML、制裁筛查和风险评分，帮助客户更快地完成客户接入、减少人工审核并防范金融犯罪。

我们的业务覆盖 200 多个国家和地区。

职位介绍

这不是一个典型的工程岗位。作为前沿部署工程师，你将处于工程、产品和客户成功的交汇点。你将直接与 AiPrise 最大、最具战略意义的客户合作，了解他们的合规挑战，构建定制化集成，并交付让平台不可或缺的解决方案。

你不需要等待工单进入你的队列。你会与客户同处一室，界定问题、编写代码并部署修复方案——有时在同一天内完成。

这个职位适合那些从为真实的人解决真实问题中获得动力的工程师，并且希望自己的工作产生看得见、立竿见影的影响。

你的工作内容

面向客户的工程工作。 深入关键客户，了解他们的客户接入、KYB 和合规工作流程。将他们的痛点转化为技术解决方案，无论是定制集成、新的 API 端点，还是工作流程的微调。

快速构建与交付。 设计并部署客户专属配置、与第三方合规和身份供应商的集成，以及定制数据管道。负责从需求界定到生产上线的完整生命周期。

连接产品与工程。 将客户洞察反馈给核心产品团队。识别客户需求中应转化为平台功能的共性模式。根据你在一线观察到的情况帮助塑造产品路线图。

在压力下解决技术问题。 实时调试生产问题。排查跨 80 多家供应商的复杂集成问题。成为客户信赖的、能让一切正常运转的人。

规模化推广有效方案。 将一次性解决方案转化为可复用的模式。编写内部工具、文档和操作手册，让每个人的下一次部署都更快。

我们寻找的人才

  • 3 年以上软件工程经验，构建并交付过生产系统。你编写过真实用户依赖的代码。
  • 扎实的后端基础。 熟练掌握至少一门现代编程语言（Python、Go、Java、Node.js）。有 REST API、微服务和关系型数据库（PostgreSQL、MySQL）方面的经验。
  • 从容面对客户。 你能在与金融科技公司合规副总裁的通话中从容应对。你善于倾听、表达清晰，并懂得如何将业务语言转化为技术需求（反之亦然）。
  • 行动导向。 你不会等待完美的规格说明。你会界定范围、构建并迭代。你能适应模糊性，并在被赋予主导权时如鱼得水。
  • 云计算经验。 有 AWS（优先）、GCP 或 Azure 的实践经验。熟悉 CI/CD、Docker 和现代部署实践。

加分项

  • 有金融科技、监管科技、支付或欺诈/风险检测领域的经验
  • 熟悉合规工作流程（KYC/KYB、AML、制裁名单筛查）
  • 有大规模集成第三方 API 的经验
  • 具备前端技能（React、TypeScript），能够构建内部工具或面向客户的仪表板
  • 有 ML/AI 系统或数据密集型应用的工作背景

为什么选择这个职位

  • 你的工作对客户和收入有直接、可衡量的影响。在你和成果之间没有任何中间层。
  • 你将深入了解合规和金融科技领域，接触多样化的客户环境。
  • 你将加入一个 36 人的快速发展的团队，你的代码在几天内（而非几个月）就能上线生产环境。
  • 有竞争力的薪酬，以及在这家势头强劲的 YC 孵化公司中获得的有意义的股权。
  • 团队位于圣何塞，线下办公，与创始人和核心工程团队并肩工作。

关于 AiPrise

AiPrise 提供合规平台和 API 集成，用于验证多个国家的企业和个人，以降低风险并防止欺诈。该平台包括企业尽职调查（KYB）、客户尽职调查（KYC）以及带有可自定义规则引擎的持续欺诈监控解决方案。AiPrise 还提供 Compliance Co-pilot，这是一个 AI 辅助工具，用于案例审查、文档分析和增强尽职调查报告生成。
