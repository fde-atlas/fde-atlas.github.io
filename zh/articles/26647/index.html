前沿部署工程师，企业客户 | Labelbox

原标题：Forward Deployed Engineer, Enterprise Accounts | Labelbox

Zero G Talent · 2026-11-13 · 约 5 分钟读完

摘要

Labelbox 在旧金山湾区招聘面向大客户的前沿部署工程师。该岗位是技术与商务的前线，需与客户高层共同梳理业务流程、定义可衡量成果，并基于 Labelbox 数据标注平台与 Recursion Managed Agent 构建含 AI Agent 与人工环节的 agentic 工作流。职责包括演示、试点、撰写面向决策层的商业方案，与客户经理协作赢得新客户并推动续约与扩展。任职要求包括相关领域硕士及以上学位、三年以上经验、Python 与数据分析能力、主导过 LLM 或 Agent 项目，以及顾问式销售经验。绩效以企业客户增长、留存与扩展衡量。

要点

  • 岗位驻旧金山湾区，面向企业大客户。
  • 需基于 Labelbox 平台与 Recursion Managed Agent 构建方案。
  • 要求硕士学历、三年以上经验及 LLM 或 Agent 项目经历。
  • 工作兼顾工程与顾问式销售，需说服高管层。
  • 考核指标为新客户增长与存量客户续约扩展。

工作职责

  • 梳理客户业务流程并定义可衡量的成果

  • 交付演示、概念验证和高管层面的商业论证
  • 与客户经理合作，赢得并拓展企业客户
  • 指导客户完成架构与集成设计

塑造 AI 的未来

在 Labelbox，我们正在构建关键基础设施，为领先的研究实验室和企业的突破性 AI 模型提供支持。自 2018 年以来，我们一直率先探索以数据为中心的方法，这些方法是 AI 开发的基础，而随着 AI 能力呈指数级扩展，我们的工作变得更加不可或缺。

关于 Labelbox

我们是唯一一家为前沿 AI 开发提供三种集成解决方案的公司：

  • 企业平台与工具：先进的标注工具、工作流自动化和质量控制系统，帮助团队大规模产出高质量训练数据
  • 前沿数据标注服务：通过 Alignerr 提供专业数据标注，利用领域专家为下一代 AI 模型服务
  • 专家市场：将 AI 团队与高技能标注员和领域专家连接起来，实现灵活扩展

为什么加入我们

  • 高影响力环境：我们的运作方式如同早期初创公司，注重影响力而非流程。你将快速承担更多职责，职业成长与你的贡献直接挂钩。
  • 技术卓越：站在 AI 开发的最前沿，与行业领袖合作，共同塑造人工智能的未来。
  • 快速创新：我们赞赏那些主动担当、快速行动并交付成果的人。我们的环境奖励高自主性和快速执行力。
  • 持续成长：每个角色都需要持续学习和进化。你将身边围绕着一群充满好奇心的人，在 AI 前沿共同解决复杂问题。
  • 清晰的职责归属：你会清楚地知道自己负责什么，并拥有执行的自主权。我们通过明确的职责和指标，赋能员工推动结果达成。

职位介绍

前沿部署工程师是 Labelbox 在我们最大型企业客户内部的技术与商业前线。你将直接与企业业务和技术负责人合作，深入了解他们的业务实际运作方式：即 AI 能够改变结果的流程、用例和工作流。然后，你将使用 Labelbox 数据标注平台和 Recursion Managed Agent 平台来设计和构建解决方案，重点打造将 AI Agent 与人类共同纳入闭环以运行真实业务的 agentic 工作流。

你的成功以业务成果来衡量：新企业客户的增长，以及现有客户的留存与扩展。这一角色融合了工程、产品和销售。你需要足够的技术深度来构建可信的解决方案，也需要销售能力来赢得信任、塑造愿景并拿下订单。发现并解决问题只是工作的一半，说服客户承诺采用解决方案则是另一半。

你的日常工作

  • 与客户并肩工作，识别并梳理他们的业务流程、用例和工作流，并定义他们希望实现的可衡量成果
  • 基于 Labelbox 的产品和服务（尤其是数据标注平台和 Recursion Managed Agent）提出、演示并开发解决方案，设计能够自动化和增强企业核心流程的 agentic 工作流
  • 推销愿景：提出有说服力的解决方案提案，进行技术演示和概念验证，并为高管支持者和采购决策团队构建商业论证
  • 与客户经理合作赢得新的企业业务，识别扩展机会，并准确预测续约
  • 与客户利益相关者和高管支持者建立可信赖的顾问关系，并将每次合作与业务价值和 ROI 挂钩
  • 通过确保客户从已部署的解决方案中获得价值，并发现下一个可着手的工作流，推动客户留存与扩展
  • 指导客户完成跨 SaaS、API、SSO 和安全需求的架构与集成设计
  • 为高技术水平的客户管理入职、实施和持续交付
  • 紧跟不断演进的机器学习和 Agent 开发生命周期，包括 LLM、Agent 架构以及训练与评测数据的作用
  • 与产品、工程、支持和销售团队合作，将客户需求转化为新解决方案，并在公司内部为客户需求和功能请求发声
  • 将成功的部署转化为客户推荐和案例研究，助力进一步的企业业务增长

关于你

  • 拥有计算机科学、工程、数学或 AI 相关领域的硕士或更高学位
  • 在相关领域拥有 3 年以上专业经验
  • 精通 Python 和数据分析
  • 具有主导 LLM 或基于 Agent 的项目经验
  • 强烈的商业直觉：能够从容应对面向客户的顾问式销售，具备说服和影响利益相关者（包括高管）的业绩记录
  • 能够理解客户的业务流程，并将其转化为与业务成果紧密关联的具体技术解决方案
  • 出色的沟通能力，能够清晰地向技术和业务受众解释复杂的技术概念
  • 较强的项目管理和组织能力
  • 对 AI 以及技术、产品和客户需求交汇领域的热情

Labelbox 致力于确保整个组织的薪酬公平，并透明地讨论薪酬。美国候选人的预期年薪基本工资范围如下。该范围不包含任何潜在的股权方案或额外福利。具体薪酬因多种因素而异，包括技能和能力、经验以及地理位置。

Labelbox 的生活

  • 环境：快节奏、高强度，非常适合那些在承担责任和快速决策中茁壮成长的雄心勃勃的人
  • 成长：职业晋升机会与你的影响力直接挂钩
  • 愿景：参与构建人类最具变革性技术的基础

我们的愿景

我们相信，数据在实现通用人工智能的过程中仍将至关重要。随着 AI 模型变得更加复杂，对高质量、专业化训练数据的需求只会不断增长。加入我们，共同开发能够助力下一代 AI 突破的新产品和服务。

Labelbox 获得了包括软银、Andreessen Horowitz、B Capital、Gradient Ventures、Databricks Ventures 和 Kleiner Perkins 在内的领先投资者的支持。我们的客户包括财富 500 强企业和领先的 AI 实验室。
