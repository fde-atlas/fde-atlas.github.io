Notion：前沿部署工程师、市场推广……

原标题：Notion: Forward Deployed Engineer, GTM,...

Index Ventures · 2026-11-15 · 约 5 分钟读完

摘要

Notion 在旧金山和纽约招聘前沿部署工程师（GTM 方向），隶属服务团队。该岗位面向企业客户，负责复杂项目的技术交付：深入客户现场设计并实现生产级方案，包括基于 MCP、Agent API 的自定义 AI Agent 与自动化工作流、数据管道，以及大规模内容与数据迁移。候选人需五年以上客户导向工程经验，熟练掌握 Java、JavaScript、Node.js、SQL 或 Python 中至少一种语言，并具备 API 集成、技术调研与调试能力。岗位还要求把实施中的问题反馈给产品与工程团队，沉淀可复用的工具与方法论。旧金山或纽约的年薪目标总额为 17.5 万至 24 万美元。

要点

  • Notion 招聘前沿部署工程师，常驻旧金山或纽约。
  • 岗位负责企业客户的端到端技术交付与方案设计。
  • 需构建基于 MCP 与 Agent API 的 AI Agent 和自动化流程。
  • 要求五年以上相关经验及至少一门编程语言的熟练掌握。
  • 年薪目标总额为 17.5 万至 24 万美元。

Notion 是一个协作式 AI 工作空间，让团队与 AI Agent 共同思考。我们正在打造一个让您的知识、项目、会议和 AI 工具并存的统一平台，让工作更快速、更清晰、更少碎片化。数以百万计的个人、小型团队和大型企业都在 Notion 上开展工作。

Notion 员工（Notinos）是将这一未来工作方式变为现实的“零号客户”。我们重视匠心，致力于打造经久不衰的产品，并坚信优秀的工作本质上仍然是人的工作。我们的目标不是发布下一个功能。每一位 Notino 所在的团队都在努力为 AI 时代的人类协作方式树立标准。从构建企业的记录系统，到创建和管理 AI Agent，再到自动化处理繁琐事务，我们深切关注为客户腾出更多时间，去完成他们人生中真正重要的工作。

职位介绍

作为 Notion 服务团队的一名前沿部署工程师，您将主导我们最复杂客户项目的一线技术交付。您将设计、构建并部署可用于生产环境的解决方案，帮助企业客户将 Notion 集成为其业务的运营层。

您将深入企业客户，设计并构建将 Notion 深度融入其技术和运营环境的解决方案。这包括编写和维护定制代码，使用 MCP、Agent API 以及 Notion 的自动化与执行基础设施来设计和部署生产级的定制 AI Agent 与 AI 工作流，构建数据管道，并解决围绕规模、权限和治理的复杂挑战。

您将深入企业客户，设计并构建将 Notion 深度融入其技术和运营环境的解决方案。

这是一个面向客户的工程职位，适合那些能够熟练编写代码、调试技术问题、向利益相关者解释权衡取舍，并将模糊的客户问题转化为可扩展技术解决方案的人。您的工作将帮助我们塑造支持复杂客户需求的最佳实践，并确保 Notion 平台为规模化做好准备。

您将取得的成果

  • 负责客户项目的一线技术交付，包括深入的技术调研、需求收集、方案设计以及端到端的实施落地。
  • 担任值得信赖的技术顾问，帮助客户做出明智的架构决策，并发现扩展和深化 Notion 使用的机会。
  • 设计、构建并运营定制 AI Agent、集成、自动化流程和数据管道，将 Notion 与客户的系统和工作流连接起来。
  • 领导大规模内容和数据迁移的设计与执行，包括调研、范围界定、数据建模、转换逻辑、验证以及迁移后优化。
  • 直接与客户的工程、IT、安全和业务利益相关方合作，收集技术需求、识别限制条件、评估可行性，并做出合理的架构决策，使 Notion 在客户更广泛的技术生态中发挥最大价值。
  • 排查复杂的实施问题，涵盖 API、集成、自动化逻辑、数据质量、权限、身份验证、系统限制以及客户特定环境。
  • 与产品、客户体验（CX）和工程团队设计并运营反馈闭环，将真实世界的实施挑战转化为可执行的洞察、技术需求和工具改进，直接影响 Notion 的产品路线图和我们的客户。
  • 构建可复用的技术资产，包括迁移工具、集成模式、参考实现、调研框架、技术标准、脚本以及内部交付工具。
  • 通过改进方法论、范围界定文档、构建模式、技术文档和工程最佳实践，帮助定义服务团队如何规模化交付复杂的技术实施。

你需要具备的技能

  • 5 年以上面向客户或前沿部署工程岗位或类似动手型技术岗位的经验。
  • 熟练掌握至少一种编程语言，如 Java、JavaScript、Node.js、SQL 或 Python，并能在面向客户或内部工程场景中编写生产级代码。
  • 具备 API 和数据集成的实际动手经验。
  • 能够主导与客户的技术调研，评估可行性、识别风险、界定技术工作范围、估算工作量，并将模糊的需求转化为可执行的计划。
  • 出色的调试和问题解决能力，能够在代码、API、权限、集成和客户特定配置中定位根本原因。
  • 出色的书面和口头沟通能力，能够有效地与技术和业务受众交流。
  • 拥有通过将技术挑战转化为解决方案、为客户大规模创造价值的良好业绩记录。

加分项

  • 有专业服务领域的工作经验，最好是在初创公司或高速增长的环境中。
  • 有在复杂编码或业务工作流中自主部署 AI Agent 的经验。
  • 有设计或实施 AI 驱动工作流的经验，包括使用 MCP、API、LLM 应用、提示词工程、检索/RAG 系统或工作流编排。
  • 有从零开始开发技术框架、调研方法论或内部工具的经验。
  • 具备 ETL/ELT 工作流、数据转换、模式映射、验证脚本或大规模内容迁移工具方面的经验。
  • 与产品和工程团队协作的丰富经验，包括能够影响路线图或架构决策。
  • 具备支持售前或早期接触阶段的经验，包括技术调研、迁移范围界定、可行性分析、工作量评估，以及构建原型或定制脚本以验证方案。
  • 在企业客户成功实施方面拥有出色的业绩记录。

Notion 致力于提供极具竞争力的现金薪酬、股权和福利。该职位的薪酬将基于多种因素确定，例如工作地点、职位的范围和复杂程度，以及候选人的经验和专业能力，可能与以下提供的范围有所不同。对于位于旧金山或纽约市的职位，该职位的总目标收入（包括基本工资和目标激励薪酬）的预估范围为每年 175,000 - 240,000 美元。
