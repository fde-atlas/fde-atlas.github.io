前沿部署工程实习生 | Dime | 纽约州纽约市

原标题：Forward Deployed Engineering Intern | Dime | New York, NY

Zero G Talent · 2026-05-04 · 约 1 分钟读完

摘要

Dime（DimeHealth AI）在纽约招聘前沿部署工程师实习生。该公司为医疗机构开发软件，用于简化运营、改善患者就诊流程并自动化人工工作。实习生将负责新客户上线与部署：配置与外部系统的 API 集成、排查部署中的技术问题、按客户需求定制工作流，并与工程和产品团队协作完善部署流程、沉淀最佳实践。要求掌握至少一门编程语言（如 Python 或 JavaScript）、了解 API 与系统集成基础，并具备与非技术背景人员沟通的能力。有医疗系统或受监管环境经验、端到端项目经验者为佳。岗位提供真实部署实践与跨职能锻炼，表现优秀者有机会转正。

要点

  • Dime 在纽约招聘前沿部署工程师实习生。
  • 工作内容是客户上线、API 集成与部署排障。
  • 要求会 Python 或 JavaScript，懂 API 集成。
  • 医疗系统或受监管环境经验为加分项。
  • 表现优秀者有机会获得全职录用。

关于 DimeHealth AI

DimeHealth AI 构建帮助医疗机构简化运营、改善患者就医渠道并自动化手动工作流程的软件。我们的平台可与现有系统集成，帮助团队以更少的管理开销更快地推进工作。

职位概述

我们正在寻找一名前沿部署工程实习生，帮助新客户接入平台并确保部署成功。

该职位处于工程、产品和客户成功的交汇点。你将与内部团队和外部利益相关者密切合作，实施解决方案、排查问题，并确保系统在真实环境中平稳运行。

你的工作内容

  • 支持新客户的接入与实施
  • 配置与外部系统和 API 的集成
  • 排查各部署中的技术问题
  • 协助根据客户需求定制工作流程
  • 与工程和产品团队协作，改进部署流程
  • 协助记录最佳实践和实施模式

我们期待的人选

  • 较强的问题解决能力和对细节的关注
  • 至少掌握一种编程语言的经验（Python、JavaScript 或类似语言）
  • 熟悉 API 和基本的系统集成概念
  • 能够在模糊、快节奏的环境中工作
  • 良好的沟通能力，并愿意与非技术背景的利益相关者合作

加分项

  • 接触过医疗系统或受监管环境
  • 有端到端技术项目经验
  • 对应用 AI 或工作流程自动化感兴趣

你将获得

  • 参与真实部署项目的实践经验
  • 接触工程与运营之间的跨职能工作
  • 有机会在快速成长的创业环境中做出贡献
  • 有机会获得全职录用
