推测解码（2023）——FDE 详解

原标题：Speculative decoding (2023) Explained for FDEs

FDE Interviews · 2026-10-18 · 约 4 分钟读完

摘要

这篇解读面向前沿部署工程师，讲解推测解码论文：用小模型起草、大模型并行验证，在不改变输出分布的前提下加速小批量推理。T5-XXL 配 T5-small 实测提速 2.3-3.4 倍，输出完全一致，无需重训练。

要点

  • 大模型逐 token 生成时受内存带宽限制，算力大量闲置。
  • 小草稿模型猜 γ 个 token，大模型一次并行打分验证。
  • 接受规则保证输出分布与目标模型完全相同，支持各种采样方式。
  • T5-XXL 用 T5-small 起草，单 TPU-v4 提速 2.3-3.4 倍。
  • 草稿约为目标模型百分之一大小效果最佳；高批量下收益会消失。

一分钟读完这篇论文

大语言模型一次生成一个 token，每一步都是一次完整的前向传播。对于小批量的大模型来说，这次传播的大部分时间都花在从内存读取权重和 KV cache 上，算术单元大多处于空闲状态。一次处理五个位置与一次处理一个位置的耗时几乎相同。

Speculative decoding（投机解码）正是利用了这种闲置资源。一个小而快的 draft（草稿）模型（论文称之为近似模型）以自回归方式生成 γ 个猜测。然后大型 target（目标）模型在一次并行传播中对前缀加上全部 γ 个猜测进行评分，得到它自己每个位置的概率。猜测从左到右用 speculative sampling（投机采样）进行检验：以 min(1, p(x)/q(x)) 的概率保留猜测的 token x。在第一次被拒绝时，丢弃剩余的猜测，并从 p − q 的归一化正部中采样一个替代 token。如果所有猜测都通过，目标模型的这次传播还会免费多产出一个 token。

该规则保证输出与目标模型的分布完全一致，无论是贪心解码、temperature、top-k 还是核采样，因为它们都可以表示为从一个调整后的分布中采样。目标模型的每次传播产生 1 到 γ + 1 个 token，因此在目标传播次数上永远不会比标准解码慢。设每个 token 的接受率为 α（即期望重叠度 Σ min(p, q)），则每次传播的期望 token 数为 (1 − α^(γ+1)) / (1 − α)。

在以 T5-small 为草稿模型的 T5-XXL 上，作者在单个 TPU-v4 上测得解码速度提升 2.3-3.4 倍，输出完全相同且无需重新训练。比目标模型小约 100 倍的草稿模型效果最好；即使是 bigram 模型也能达到 α = 0.2。

研究笔记：问题、方法与结果

用 T5-small 草稿模型加速 T5-XXL（11B）解码，输出相同，批量大小为 1，运行在 TPU-v4 上

无论草稿模型、temperature 或采样方法如何，输出分布都等于目标模型的分布

作为 T5-XXL 翻译的草稿模型，即使是 bigram 模型也能达到的接受率，约相当于 1.25 倍加速

大语言模型每次前向传播只生成一个 token，而每次传播主要是在等待从内存读取权重和 KV cache，而不是在等待算术运算。生成 K 个 token 需要 K 次串行传播，因此延迟随输出长度增长，而 GPU 的算力却处于闲置状态。

让一个小得多的草稿模型猜测接下来的 gamma 个 token，然后让目标模型对它们全部进行一次并行处理。以 min(1, p/q) 的概率保留每个猜测，其中 p 和 q 分别是目标模型和草稿模型的概率；在第一次被拒绝时，从 p 超出 q 的归一化盈余部分中采样一个替代 token。这一投机采样规则使输出与目标模型的分布完全一致，且对任何草稿模型都成立。

在 T5-XXL（11B）配合 T5-small（77M）起草的设置下，解码在单个 TPU-v4 上快了 2.3-3.4 倍，且输出完全一致：贪心翻译为 3.4 倍，采样为 2.6 倍。小草稿模型在 T5、LaMDA 和类 GPT 模型上接受了 53-88% 的 token。

这对 FDE 为什么重要

延迟在小批量场景下正是交互式产品的痛点：聊天、编程助手、以及需要等待每次响应的 Agent。投机解码是为数不多能在不改变模型输出的情况下降低延迟的优化之一，因此很容易获得批准：质量不可能倒退。

它需要空闲算力。 收益来自内存受限解码期间闲置的算术运算。在大批量场景下，GPU 已经是算力受限的，验证被拒绝的猜测会损失吞吐量。它首先是一个延迟优化工具。

草稿模型决定收益。 接受率 α 和草稿模型的相对成本 c 决定了加速比。来自同一模型家族、大约小 100 倍的草稿模型是论文的最佳选择；太大的草稿模型接受率更高但成本过高（T5-large 只带来了 1.4-2.2 倍）。

存在免费的草稿。 n-gram 模型，或直接复制上下文中已经出现的文本，运行成本几乎为零。论文针对编辑和改写场景提出了复制思路，因为这类任务的输出会重复输入。
