Xforce by Xero：为您的事务所打造的 AI 工作流

原标题：Xforce by Xero: AI Workflows Built With Your Firm

Xero · 2026 · 约 6 分钟读完

摘要

Xero 推出 Xforce，一支由合作伙伴顾问和前沿部署工程师组成的团队，与会计和簿记事务所共同设计并构建工作流。该服务基于 XeroForce（Xero 的 AI Agent 与工作流构建平台）和 Xero API，目前处于早期测试阶段，首批设计伙伴位于澳大利亚、新西兰和英国，包括 Liston Newton Advisory、Nexia、Azets、Sumer 等。Xero 强调平台本身不足以改变事务所运作，需要团队驻场协作：事务所提供战略方向、负责人和流程知识，Xforce 负责设计与实现。目标是减少重复性工作、实现跨客户的标准化服务。定价尚未公布，注册意向不保证入选。

要点

  • Xforce 是顾问加前沿部署工程师的驻场协作团队。
  • 基于 XeroForce 平台和 Xero API 构建事务所工作流。
  • 首批设计伙伴分布在澳、新、英三国。
  • 事务所需提供负责人与流程知识，共同设计。
  • 目标为减少重复工作并标准化跨客户服务。

注册您对 Xero 旗下 Xforce 的兴趣

告诉我们您事务所的情况，以及您的团队在哪些重复性工作上花费时间。我们的 beta 阶段仅从少数事务所开始，因此注册意向并不代表确认名额。如果看起来合适，我们的团队会与您联系。我们希望听到以下事务所的声音：

  • 以 Xero 作为事务所核心的事务所。
  • 在多个客户之间存在希望改进的重复性工作，无论是否已确定工作流程。
  • 能够指定一位事务所负责人支持这项工作，并让熟悉工作流程的人员参与其中。
  • 愿意与我们共同设计和测试工作流程，并分享反馈。

注册意向

Xero 旗下的 Xforce 目前处于早期体验阶段，仅有少数位于澳大利亚、新西兰和英国的设计合作伙伴参与。注册意向并不代表确认早期体验名额。可用性、范围及其他细节可能会有所变化。Xero 将按照其隐私声明处理您的信息。

我们的首批设计合作伙伴

Xero 旗下的 Xforce 目前处于 beta 阶段，最初与澳大利亚、新西兰和英国的少数设计合作伙伴共同开发，包括澳大利亚的 Liston Newton Advisory、新西兰的 Nexia 和 Shepherd Hensman，以及英国的 Azets 和 Sumer。

Xforce by Xero 凭借深厚的会计专业知识以及对事务所运作方式的深入理解，将帮助我们继续加速 AI 战略。我们期待与 Xforce 团队合作，设计并构建能够规模化、并为客户和事务所带来最大影响的 AI 驱动工作流程。

- Fraser Campbell，Azets 英国会计与商业咨询服务主管

从 AI 实验到为您事务所量身设计的工作流程。

事务所正在尝试使用 AI，但挑战往往不只是再选择一个工具那么简单。关键在于决定要改变哪些工作，打通 Xero 与事务所其他技术栈之间的步骤，并让新的工作流程契合事务所服务客户的方式。

XeroForce 是 Xero 的自定义 AI Agent 和工作流程构建工具。但仅有平台本身，无法重新设计事务所的运作方式。

这正是 Xforce 的用武之地：我们计划让合作伙伴顾问和前沿部署工程师与您的团队并肩工作，重新设计并构建真正重要的工作流程，首先从测试版中的一小批设计合作伙伴开始。

一个与您共同构建的团队，基于 Xero。

Xero 的 Xforce 是一支由合作伙伴顾问和前沿部署工程师组成的团队。他们将帮助会计和簿记事务所使用 XeroForce 和 Xero API 重新设计并构建工作流程，并在合理的情况下连接到贵事务所使用的其他软件。

该团队具备会计师和簿记员所关注工作流程的专业知识，以及如何在 Xero 上进行构建的经验。贵事务所则提供战略、支持和工作流程专业知识。这项工作将由双方共同设计和构建，首先从我们的测试版设计合作伙伴开始。

一个与您共同重新设计工作流程的团队。

Xero 的 Xforce 将派出合作伙伴顾问和前沿部署工程师，与您的团队一起处理真正重要的工作流程。贵事务所需要指派一位负责人来支持这项工作，并安排最熟悉这些工作流程的人员。双方将围绕贵事务所的战略，使用 XeroForce、Xero API 以及适合的现有工具，共同重新设计并构建新的工作方式。

从贵事务所的流程出发，然后跨工具进行构建。

Xero 的 Xforce 将对会计和簿记工作流程的理解与在 Xero 上构建的技术经验相结合。团队将与您的人员一起确定哪些工作流程可以改进，然后帮助设计和构建符合贵事务所运作方式的方案，使用 XeroForce、Xero API 以及其他合适的工具。

Xero 的 Xforce 如何帮助贵事务所

把时间从重复性工作中解放出来。

重新设计财务任务与工具之间的步骤，让您的团队可以把时间投入到审核、咨询和客户关系上。

为每位客户提供始终如一的服务。

围绕贵事务所的标准建立工作流程，并将其应用到您选择的客户中，由您的团队掌控整个过程。

围绕您的战略打造工作流程。

首先明确贵事务所希望如何服务客户，然后围绕贵事务所的流程、优先级和现有工具来设计工作流程。

贵事务所始终掌控全局。

您的团队确定方向、设定防护措施并提供背景信息，Xero 的 Xforce 则在整个设计和构建过程中与您并肩同行。

在 XeroForce 测试版获得积极反馈的基础上，Xero 的 Xforce 将经验丰富的专家派驻到事务所现场，帮助他们嵌入可信、可重复且可扩展的 AI 工作流程，实现更高的一致性和效率，并为他们节省时间，以便重新投入到业务增长中

Diya Jolly，Xero 产品与技术总裁
