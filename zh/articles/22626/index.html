FDE Claude：Anthropic 的 Preferred 合作伙伴

原标题：FDE Claude : partenaire Preferred d'Anthropic

SFEIR · 2026-11-14 · 约 5 分钟读完

摘要

法国咨询公司 SFEIR 介绍其 FDE Claude 服务：作为 Anthropic Claude Partner Network 的 Preferred 合作伙伴（2026 年 10 月 5 日升级），SFEIR 派遣前沿部署工程师进驻客户团队，按诊断、设计、部署、运行四阶段部署 Claude Code、Claude Cowork 及基于 Claude API 的定制 Agent。文章还区分了 Forward Deployed Engineer 职位与 Anthropic 通过 Claude Frontier Academy 颁发的 Frontier Deployed Engineer 徽章。

要点

  • SFEIR 于 2026 年 10 月 5 日成为 Anthropic Preferred 合作伙伴。
  • 超 170 名员工（约五分之一）持有至少一项 Claude 认证。
  • 服务分三条线：AI4IT、AI4Business、API 定制 Agent。
  • 任务周期 3 至 12 个月，四阶段推进，含免费半天工作坊。
  • 文章澄清 FDE 职位与 Frontier Deployed Engineer 徽章的区别。

在 Anthropic，缩写 FDE 指 Forward Deployed Engineer，即派驻客户现场的工程师岗位；也指 Frontier Deployed Engineer，即颁发给其客户与合作伙伴工程师的认证徽章。FDE Claude 服务属于前者：SFEIR 的前沿部署工程师加入您的团队，部署 Claude Code、Claude Cowork 以及基于 Claude API 构建的 Agent，直至投入生产。

FDE Claude 服务遵循 SFEIR 的 FDE IA 服务方案流程：诊断、设计、部署、运行。工具选型上，IT 部门使用 Claude Code，业务部门使用 Claude Cowork，当流程需要定制 Agent 时则使用 Claude API。SFEIR 是 Claude Partner Network 中的 Anthropic Preferred 合作伙伴。

01 合作伙伴关系

自 2026 年 10 月 5 日起成为 Anthropic Preferred 合作伙伴

2026 年 10 月 5 日，SFEIR 宣布从 Select 级别晋升至 Anthropic 的 Claude Partner Network（服务类）Preferred 级别。超过 170 名员工——约占集团五分之一——持有至少一项 Anthropic 认可的 Claude 认证。2026 年 10 月 5 日的公告详细说明了所达到的级别及其承诺；SFEIR Anthropic 合作伙伴页面回顾了自 Select 级别以来的合作历程。

SFEIR 的工程师自 2025 年春季起使用 Claude Code，自 2026 年初起每位 Sfeirian 员工都在使用。Claude Cowork 最初在集团管理层和职能部门部署。FDE Claude 团队在您现场落地的实践，都先在 SFEIR 内部运行过：自 2025 年起内部使用 Claude Code、拥有 Claude Certified Architect 认证的工程师。

02 团队部署的内容

Claude Code、Claude Cowork 以及基于 Claude API 的 Agent

FDE Claude 服务承诺一个明确的范围：IT 部门、业务团队，或需要定制 Agent 的某个流程。每个范围都有对应的专属页面。FDE 会带来我们的公共资产：无论哪个范围，都包括我们的服务在 Claude 上打磨成熟的成果（安全与管理的参考配置、skills、共享的 Agent 和 MCP 服务器、采纳路径）；对 IT 部门而言，还包括 Tooling 部门的 SDLC Framework，即 SFEIR 实践的 AI 驱动研发周期，Claude Code 就部署在其中。

  • FDE AI4IT：在企业中、在您的 SDLC 中部署 Claude Code 团队将 Claude Code 安装到您的开发周期中：Agent、skills、MCP 服务器、质量控制、度量。SFEIR 的 Agent 化 SDLC 包含十一个阶段，代码生成只是其中之一；人类把控三个关键节点：Define、Plan 和 Ship。
  • FDE AI4Business：Claude Cowork 与业务 AI Agent 团队将 Claude Cowork 作为云上落地区进行部署：先配置安全与管理参数，再接入连接您系统的连接器，并在整个组织范围内共享技能。经过培训的内部 AI 倡导者推动采用，以业务单元而非许可证数量来衡量成效。
  • 基于 Claude API 的 Agent：连接您信息系统的定制 Agent 当流程需要超越 Claude Code 或 Cowork 的能力时，团队会使用 Claude API 构建 Agent，通过 MCP 连接到您的系统，并以每个成果的成本来衡量效果。

03 流程安排

分四个阶段的 Claude FDE 项目

  • 01诊断分析工作流、数据、信息系统及各项约束（法规、安全、治理）。与业务人员共同识别对 Claude 而言投资回报率最高的用例。
  • 02设计目标架构：SDLC 中的 Claude Code、面向业务部门的 Claude Cowork、通过 MCP 连接的基于 Claude API 的 Agent、与信息系统的集成、评测计划。
  • 03部署构建与上线：数据管道、Agent、可观测性、安全控制、与现有信息系统的集成。与您的团队共同开发。
  • 04运行与扩展监控、成本/延迟优化、持续治理、提升您团队的技能、将可复用的实践工业化。团队随后完成交接。

04 Anthropic 的徽章

Claude Frontier Academy 与 Frontier Deployed Engineer

Anthropic 开设了 Claude Frontier Academy，这是一个为其客户与合作伙伴的工程师颁发 Claude Frontier Deployed Engineer 徽章的项目。该徽章是由 Anthropic 授予的头衔；而 Forward Deployed Engineer 这一职位——即 Claude FDE 项目中工程师所担任的角色——则另有其名。Frontier Deployed Engineer 页面介绍了该项目、其准入条件，以及 FDE 两种含义之间的区别。

05 问题

常见问题

  • Claude FDE 项目包含哪些内容？这是 SFEIR 专注于 Claude 的 Forward Deployed Engineers 项目：工程师嵌入您的团队，从诊断到运行，部署 Claude Code、Claude Cowork 或基于 Claude API 构建的 Agent。SFEIR 于 2026 年 10 月 5 日成为 Anthropic Claude Partner Network 的 Preferred 合作伙伴，此前以 Select 级别加入。
  • Claude FDE 项目的工程师是 Frontier Deployed Engineers 吗？不是。Frontier Deployed Engineer 是 Anthropic 通过 Claude Frontier Academy 授予其客户与合作伙伴工程师的徽章。Claude FDE 项目的工程师是 SFEIR 的 Forward Deployed Engineers：是职位，而非徽章。SFEIR 已有超过 170 名员工持有至少一项 Anthropic 认可的 Claude 认证。
  • Claude Code、Claude Cowork 还是基于 Claude API 的 AI Agent：如何选择？Claude Code 面向 IT 部门，嵌入开发流程（AI4IT 前沿部署工程师任务）。Claude Cowork 面向业务团队，像云落地区一样部署，并在您的团队中培养 AI 冠军（AI4Business 前沿部署工程师任务）。当某个流程需要更多能力时，团队会用 Claude API 构建定制 AI Agent，并通过 MCP 连接到您的信息系统。诊断作为任务的第一阶段，会做出裁决。
  • Claude FDE 任务持续多久？根据范围从 3 到 12 个月不等，分为四个阶段：诊断、设计、部署、运行。首次接触以免费的半天框架研讨会形式进行，由一名资深 FDE 和一名业务负责人共同主持。
