成为年薪百万美元以上前沿部署工程师的免费 8 周路线图

原标题：The Free 8-Week Roadmap to Become a $1M+ Forward Deployed Engineer

AI Action Letter · 2026-07-05 · 约 10 分钟读完

摘要

作者基于 Palantir、OpenAI 和 Anthropic 的真实职位描述，设计了一份八周、几乎免费的 FDE 备考路线图。文章先教读者识别伪装成 FDE 的销售岗位，再按数据工程、云基础设施、Claude API、生产级 RAG、Agent 与 MCP、评测六大模块安排学习，最后两周聚焦在真实环境中部署项目并准备非 LeetCode 式的面试。文中引用 Palantir 起薪约 13.5 万至 20 万美元、Anthropic 总包最高 120 万美元等数据，并推荐 Claude Certified Architect 作为唯一值得考取的认证。

要点

  • FDE 岗位去年增长超 1000%，需先甄别伪装成 FDE 的销售岗。
  • 前六周依次学习数据工程、云与基础设施、Claude API、生产级 RAG、Agent 与 MCP、评测。
  • Anthropic 的 Claude Certified Architect（99 美元）是唯一推荐的认证，备考课程免费。
  • 第七周要求在真实基础设施上部署一个基于真实数据的 RAG Agent 并撰写咨询式文档。
  • FDE 面试以调试和系统设计为主，而非 LeetCode，求职应靠内推和项目演示。

全文

大家好，

几周前，我详细解析了前沿部署工程师这个职位：它是什么、为什么爆火、薪资如何。那封信反响巨大。几乎每一条回复都在说同样的话：“好吧 Abhijay，但我到底要怎么才能成为其中一员？”

答案就在这里。一份精确的工程学习计划。八周，几乎完全免费。

如果你错过了第一篇，先快速回顾一下。去年 FDE 职位发布量暴涨超过 1,000%。Palantir 起薪约 $135K 到 $200K，而在 Anthropic，总薪酬从 $300K 一直到 $120 万。

有一点我需要先说清楚，因为总有人问我。这不是 AI 产品经理路线。FDE 要在客户混乱的系统里交付生产代码。所以这个计划以工程为先。真实的代码。真实的数据。真实的部署。如果你想走产品路线，那是另一封信的内容。

但在你开始学习任何东西之前，先听一个来自一线的警告。我翻遍了真正的 FDE 们发言的 Reddit 帖子，点赞最高的评论都很直白。有人称之为“多绕了几步的销售”。还有人称它为“被 Palantir 说得很酷的顾问岗位”。所以真相介于两者之间。有些 FDE 工作非常棒。有些则是换了个更好听头衔的销售指标。你的第一项技能就是分辨它们。

然后我做了这件枯燥但有用的事。我从 Palantir、OpenAI 和 Anthropic 拉取了真实的职位描述，并据此反向构建了这个计划。

第一步：过滤假职位

在学习任何东西之前，先学会阅读职位描述。如果职位发布包含以下内容，请跳过：

  • 配额、OTE 或提成结构（那是穿着戏服的销售岗位）
  • 汇报对象是销售或 GTM 而不是工程部门
  • 职责主要是做演示和促成交易

真正的 FDE 是做构建的。他们把公司的产品真正落地到客户混乱的系统里。

这个差距有个名字。即产品开箱即用的功能与客户真正成功所需之间的空间。Palantir 称之为“Delta”。你的全部工作就是弥合 Delta，这需要三顶帽子：一部分是软件工程师，一部分是数据架构师，一部分是顾问。这个计划会训练这三方面。

Palantir、OpenAI 和 Anthropic 的实际要求（我读了职位描述）

  • Palantir FDSE：精通 Python、Java、C++ 或 TypeScript 的“强力程序员”。像创业公司 CTO 一样端到端负责项目。处理大规模数据，构建定制 Web 应用，监控生产环境。1 年以上经验。出差最多 25%。
  • OpenAI FDE：负责需求探索、范围界定、系统设计、构建和生产上线。用 Python 或 JavaScript 编写覆盖前端和后端的生产级代码。通过“评测驱动的反馈”衡量成功。
  • Anthropic FDE（应用 AI）：具备 LLM 生产经验，包括 Agent 开发与评测框架。能交付真实产物，如 MCP 服务器、子 Agent 和 Agent 技能。Python，最好还会 TypeScript。3 年以上经验。

三大主题跃然眼前：深度工程（代码、数据、云）、Agent 与 MCP，以及评测。这份计划正是围绕这三点构建的。坦白说一句：Palantir 接受只有 1 年经验的人，所以它是最容易够到的门。OpenAI 和 Anthropic 通常要求 3 到 5 年以上。从你所在的位置出发去瞄准。

第 1 部分：三顶工程帽（第 1 至 6 周）

第 1 周：数据工程（任务从这里开始）

大多数 AI 学习路线都跳过这一步。别跳。FDE 任务几乎总是从数据审计开始，而不是从模型开始。Palantir 的职位描述里明确写着你要“处理大规模数据”。如果你理不清客户那个有 20 年历史的数据库，你就无法在其之上构建任何东西。

  • 高级 SQL：窗口函数、CTE，以及通过阅读查询计划找出慢在哪里。“Select Star SQL”是一本免费的交互式书籍：

https://selectstarsql.com

  • 面向现实的数据建模：星型模型，以及将客户原始数据转化为可用数据的 Bronze、Silver、Gold“奖牌”分层模式。
  • 现代数据栈：动手使用 dbt（免费的“dbt Fundamentals”课程）和 DuckDB，对客户杂乱的 CSV 文件进行快速本地分析。
  • 核心课程：免费的 Google Cloud Skills Boost“数据工程师”学习路径：

https://www.cloudskillsboost.google

第 2 周：云与基础设施（载体）

FDE 会被空降到复杂的云环境中，并且必须完成部署。这一周将把你和那些只在笔记本环境里构建东西的人区分开来。

  • Docker：把一切都容器化。免费入门指南：https://docs.docker.com/get-started
  • 用 Terraform 实现基础设施即代码：几分钟内搭建起完整环境。HashiCorp 的教程是免费的：https://developer.hashicorp.com/terraform/tutorials
  • Kubernetes 基础（GKE 或 EKS），外加网络、IAM 和密钥管理。免费的 AWS Bedrock 工作坊是很好的云上实操练习。
  • 保持系统存活：浏览免费的 Google SRE Workbook，尤其是监控和事故响应部分。FDE 要负责“第二天”，也就是部署之后的那部分工作。

第 3 周：用 Claude API 构建（真正的 LLM 工程）

不是“写出更好的提示词”，而是真正从生产代码中调用模型、接好工具调用，并获得结构化、可靠的输出。

  • Anthropic Academy 的“Building with the Claude API”课程：免费、有证书、动手实践。

https://anthropic.skilljar.com

  • Anthropic Cookbook（GitHub）：关于工具调用、RAG 和评测的即拷即用笔记本。先拿来用，再把它们改坏。https://github.com/anthropics/anthropic-cookbook
  • 可选但值得一看，如果你想真正理解底层原理：Andrej Karpathy 在 YouTube 上的免费课程“Deep Dive into LLMs like ChatGPT”：

第 4 周：生产级 RAG（处理脏数据的专长）

将模型连接到客户的数据是 FDE 的看家本领。但生产级 RAG 与玩具演示完全是两回事。

  • DeepLearning.AI 的《构建与评估高级 RAG》：分块、检索与质量衡量。免费：https://www.deeplearning.ai/short-courses/building-evaluating-advanced-rag
  • freeCodeCamp 的《从零学习 RAG》：由真正的 LangChain 工程师讲授的两个半小时课程。免费：
  • 深入学习实际工作中最关键的部分：摄取杂乱的企业 PDF、向量数据库（Pinecone、Weaviate 或 pgvector），以及将语义向量与关键词匹配相结合以处理行业术语的混合搜索。Pinecone 的免费学习中心很不错：https://www.pinecone.io/learn

第 5 周：Agent、MCP 与 Agent 技能

这正是让你成为 2026 年 FDE 的关键。Anthropic 的职位描述明确要求你能交付 MCP 服务器、子 Agent 和 Agent 技能。那就动手构建它们吧。

  • Anthropic 的《构建高效 Agent》：什么时候该用 Agent，什么时候简单的工作流反而更好。免费：https://www.anthropic.com/research/building-effective-agents
  • 《MCP：与 Anthropic 一起构建丰富上下文的 AI 应用》（DeepLearning.AI）：学习模型上下文协议并构建一个服务器。免费：https://www.deeplearning.ai/short-courses/mcp-build-rich-context-ai-apps-with-anthropic
  • Hugging Face 的 AI Agent 课程：免费且提供认证。用 smolagents 构建，并记录你遇到的每一种失败模式。https://huggingface.co/learn/agents-course
  • 使用 LangGraph 进行多 Agent 编排（DeepLearning.AI，免费）：https://www.deeplearning.ai/short-courses/ai-agents-in-langgraph

唯一真正值得考取的证书：Claude Certified Architect

我一直在劝大家别花 2,500 美元去买那种“纸面认证”。但这里有一个例外。2026 年 3 月，Anthropic 推出了首个官方认证——Claude Certified Architect。看看它的五个考试领域：Agent 架构、Claude Code、提示词工程、工具设计与 MCP，以及上下文管理。这几乎逐条对应了 FDE 的工作内容。

Skilljar 上的 13 门 Anthropic Academy 备考课程完全免费，即使你从不参加考试也可以学习：

https://anthropic.skilljar.com

考试本身收费 99 美元，如果你的公司加入 Claude Partner Network 则免费。如果在这整个计划中你只考一张证书，那就考这张。

第 6 周：评测与可观测性（证明它有效，并让它持续运行）

对 FDE 来说，评测不是走过场。它是你向持怀疑态度的客户证明你部署的东西确实有效的方式，也是你在离开后及时发现系统开始漂移的手段。

  • DeepLearning.AI 的《评估 AI Agent》（与 Arize 合作）：基于代码的评测、LLM 作为裁判，以及可观测性。免费：https://www.deeplearning.ai/courses/evaluating-ai-agents
  • Anthropic，《揭开 AI Agent 评测的神秘面纱》：评测驱动开发，直接来自实验室。免费：https://www.anthropic.com/engineering/demystifying-evals-for-ai-agents
  • OpenAI Evals 和 promptfoo（均在 GitHub 上开源）：实验室实际使用的框架。https://github.com/openai/evals 和 https://github.com/promptfoo/promptfoo

熟练掌握 RAG 三角：忠实性（答案是否紧扣检索到的上下文）、答案相关性以及上下文相关性。然后通过追踪（tracing）增加生产环境可观测性（LangSmith 有免费套餐），这样你就能准确看到 Agent 的思维链在现场何处断裂。

第 2 部分：缩小 Delta 差距并拿下工作（第 7 和第 8 周）

第 7 周：在混乱的环境中交付项目，然后像顾问一样思考

这才是整个游戏的关键。FDE 要证明的是他们能够集成和部署，而不仅仅是演示。

选择一个真实的问题，而不是玩具项目。可以从 Y Combinator 的“创业公司需求”（Requests for Startups）、一个混乱的 Kaggle 数据集或 data.gov 中挑选一个。写一段简短的范围说明：客户是谁、瓶颈是什么、成功是什么样子。然后基于该数据构建一个 RAG Agent，用 MCP 服务器或小型 Web 应用封装它，并使用 Docker 和 FastAPI 部署到真实基础设施上上线。先交付粗糙的版本，证明核心流程可行。

然后戴上顾问的帽子，因为这是工程师丢掉工作的环节：

  • 先给出答案。高管们想在听到“怎么做”之前先知道“所以呢”。这就是金字塔原理。
  • 不断追问“为什么”，直到触及真正的问题。“我们想要更高的效率”不是需求规格。深挖到它成为规格为止。
  • 像 FDE 一样撰写文档。把你的项目打包成一份现场调研（Site Survey）、一份包含可衡量成功标准的技术范围界定文档（Technical Scoping），以及一份每周高管摘要（Weekly Executive Summary）。从 Awesome-FDE-Roadmap 仓库获取可直接复制的模板：https://github.com/pierpaolo28/Awesome-FDE-Roadmap
  • 如果你的写作笨拙生硬，Google 的免费技术写作课程能快速解决这个问题：https://developers.google.com/tech-writing
  • 了解这份工作的真实运作方式：Palantir 自己的《前沿部署软件工程师的一天》：https://blog.palantir.com

用数字说出你的成果。不要说“我构建了一个 RAG Agent”，而要说“我构建了一个 RAG Agent，将某支持团队的查询时间缩短了 40%”。

第 8 周：FDE 面试（不是 LeetCode），然后聪明地投递

这是让所有人都感到意外的部分。FDE 的面试流程通常不是 LeetCode。

  • Palantir：他们会给你一个带有文档的、有问题的代码库，观察你多快能发现并修复问题。它考察的是对细节的关注，而不是背下来的算法。
  • Google Cloud 和 OpenAI 的 FDE：更接近系统设计和岗位相关知识。

当他们给你一个案例时，不要直接开始写代码。使用一个简单的框架，称之为 C.A.S.E：

  • 澄清（Clarify）：数据量、安全性（是 PII 还是 PHI），以及“完成”到底意味着什么
  • 架构设计：数据流，从客户的源系统到最终用户
  • 解决 Delta：指出产品开箱即用做不到什么，以及你会构建哪些粘合代码
  • 评估：你如何证明 AI 没有产生幻觉，以及你离开后如何持续监控

初级回答全是 Python。高级回答会谈到安全、成本和利益相关者的认可。

还要准备应对非常针对 FDE 的刁钻问题。“客户有 5 PB 的本地数据，需要在 48 小时内迁移到云端。”带宽是瓶颈，所以你会运送一台物理传输设备，并在传输过程中构建 schema。或者“客户的首席工程师讨厌你的产品，不给你访问权限。”这是信任问题，不是技术问题。

在 Exponent 的 YouTube 频道免费练习系统设计：https://www.youtube.com/@tryexponent

然后不用投简历石沉大海，直接敲开大门

网申会石沉大海。内推不会。

  • 走窄路。在 LinkedIn 和 Wellfound 上设置职位提醒，瞄准 OpenAI、Anthropic、Palantir、Databricks、Ramp 和 Sierra 的 20 到 30 个岗位，再加上那些可以直接联系到创始人的早期 AI 创业公司。创业公司是更容易的第一扇门。
  • 给 FDE 和工程经理发简短、具体的邮件。附上一个 2 分钟的 Loom 演示视频，展示你已部署的项目，而不是简历。一个能跑起来的 Agent 永远胜过一份 PDF。
  • 规模化操作。我搭建了一个 n8n 工作流，一旦有新的 FDE 职位发布就立即抓取，找到招聘经理，并起草一封个性化邮件供我审核后发送。n8n 免费且开源（https://n8n.io）

只需记住一件事

这个头衔很火，所以招聘人员把什么都贴上“FDE”的标签。因此要以怀疑的态度阅读每一份职位描述。构建一个真实的项目并部署到真实的基础设施上。为它编写评测。然后走进面试流程时，清楚这是一场调试和系统设计的考验，而不是 LeetCode 刷题。

如果你从我的 AI 行动信中获得了价值，请考虑订阅。这能让我继续前行。
