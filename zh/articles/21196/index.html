Celonis 的 FDE 招聘与社内职位名称 Value Engineer｜东京的招聘职位对比

原标题：CelonisのFDE求人は社内名Value Engineer|東京の募集職種と比較

FDE Talent編集部 · 2026-11-14 · 约 21 分钟读完

摘要

Celonis 于2026年11月在慕尼黑和巴黎发布的两件 FDE 职位，正文均写明内部职名为 Senior Value Engineer，属 Value Engineering 部门，工作重心是价值测算、PoV 和商业案例，技术要求仅为 Python 或 SQL。编辑部比对全部264件招聘发现，慕尼黑同一正文以6个不同职名发布；真正负责客户现场实施到上线的是 Services 部门的 Deployment Engineer，东京正以日语必备招聘该职（6年与12年以上经验两档）。文章提醒求职者应通过正文、部门和动词判断职务，而非依赖 FDE 职名。

要点

  • Celonis 的 FDE 招聘内部职名实为 Senior Value Engineer。
  • 慕尼黑同一正文以6个职名发布，含顾问与售前。
  • FDE 职务偏价值提案，技术要求仅 Python 或 SQL。
  • 东京招聘 Deployment Engineer，需日语，经验6年或12年以上。
  • 建议以正文、部门和动词而非职名判断职务。

  • 02 慕尼黑面向零售・消费品的职位中，除开头职位名称的一句话外正文完全相同的招聘，曾以FDE、Value Engineer、售前等6个职位名称发布（截至2026年11月14日）。
  • 03 Celonis的FDE职位的工作，是通过价值测算、PoV、商业案例来支撑从接单到续约的价值提案职务，技术要求仅限于Python或SQL的知识。
  • 04 在客户现场实施并推进到生产环境上线的是另一部门（Services）的Deployment Engineer，Celonis正在东京招聘要求6年以上和12年以上经验的两个职位，且日语为必备条件。

プロセスマイニングで知られるCelonis(セロニス)が、2026年11月9日にミュンヘン、10日にパリで「Forward Deployed Engineer(FDE)」の求人を公開しました[1][2]。編集部が9月29日から取っている求人スナップショットで、Celonisの求人にFDEの職種名が出たのはこれが初めてです。ところが本文を読むと、どちらにも「社内名はSenior Value Engineer」と書かれています[1][2]。

Celonisは東京でも採用しており、日本の製造業・インフラ業界の大企業を担当する職種を募集しています[10]。FDEの求人を見た人が知りたいのは、「CelonisのFDEは何の仕事で、ほかの会社のFDEや、Celonisが東京で募集している職種とどう違うのか」でしょう。この記事では、Celonisのジョブボードに載っている求人264件をすべて取得して本文を照合し、FDEの職種名が付いた求人の正体と、東京で応募できる職種を比べます。FDEという職種の一般的な説明はFDEとは?をご覧ください。

Celonis的FDE职位是做什么工作的？

CelonisのFDE求人は、社内ではSenior Value Engineerと呼ばれる、顧客企業にCelonisの価値を示して導入と拡大を進める職務です。価値の試算やPoV(価値の実証)、ビジネスケースとデモを作り、価値を探るワークショップを回し、経営層を含む関係者と話しながら、受注から利用の拡大、契約の更新までを受け持つと書かれています[1]。所属はValue Engineering部門です[1]。

同一招聘以6个职位名称发布是怎么回事？

ミュンヘンの小売・消費財(CPG/Retail)向けでは、冒頭の「この職種は〜」という一文の職種名だけが違い、残りの本文が一字一句同じ求人が6件、別々の職種名で公開されています(2026年11月14日時点)[1][3][4][5][6][7]。FDE以外の5件のうち、Value Engineerの名前で出ている1件を除く4件にも、FDEの求人と同じく社内名はSenior Value Engineerと明記されています[4][5][6][7]。

11月12日には、マドリードのイベリア・中南米向けの「Senior Value Engineer」と同じ本文が、Solution Engineer・Value Consultant・Business Transformation Consultantの職種名で公開され、それぞれに社内名はSenior Value Engineerと書かれています[14][15]。新卒向けでも、実装側の「Associate Deployment Engineer」(2月12日公開)と同じ本文の求人が、11月12日に「Associate Technology Consultant」の名前で出ています[12][13]。

挂着 FDE 名字的 Value Engineer 需要具备什么？

求められるのは、データ分析と業務改善で顧客の価値を示してきた経験と、経営層と話す力です。技術の要件は「PythonかSQLの知識」と、RPAやBIツールの導入、ダッシュボードやアプリを作った経験にとどまり、開発経験の年数は書かれていません[1]。理想的な経歴としては、ソフトウェア会社のソリューションコンサルティング、セールスエンジニアリング、ITや経営のコンサルティングが挙がっています[1]。

在客户现场负责实施的是哪个职位？

顧客先で実装を担うのは、Services部門のDeployment Engineerです。Celonisは東京の求人で、Servicesを自社の顧客対応部門(Customer Organization)の「納品のエンジン」と呼び、Deployment Engineerを「Celonisの納品の背骨」と位置づけています[8]。担う範囲は、要件を決めるワークショップから、データの接続、設計、構築、価値の測定、本番稼働と顧客への引き継ぎまでです[8]。

“这不是一切都要手工完成的传统咨询岗位。你是一名借助 AI 增强能力的交付专家：你把需要构建的内容写成规格说明，尽可能让 AI Agent 去执行，验证结果，并与客户一起持续改进。” “This is not a traditional consulting role where you build everything manually. You are an AI-augmented delivery professional: you specify what needs to be built, direct AI agents to execute wherever possible, validate the results, and iterate with the customer.”

Celonis「Senior Deployment Engineer」招聘启事（东京，2026年11月14日获取）

求人票によると、Deployment Engineerは自社のAIエージェント(求人票での名前は「Apollo」)に、データモデル、業務プロセスの分析、KPI、ダッシュボードを作らせ、その出力を業務の要件に照らして検証します[8]。要件にはPQL(Celonis独自のクエリ言語)・SQL・Pythonの熟達と、Claude Code・Codex・CursorなどのAI開発ツールに慣れていることが挙がっています[8]。AIが最初の結果を速く出しても、作った仕組みが堅牢で保守でき、規模を広げられるものになっているかに責任を持つ、とも書かれています[8]。

寻找 FDE 职位的人能从这个案例中学到什么？

学べるのは、FDEという職種名は会社によって指す仕事が大きく違い、同じ会社の中でも職務の名前ではなく呼び名の1つとして使われることがあるということです。Celonisでは、FDEの名前が付いた求人は価値提案の職務で、実装の職務には別の名前が付いていました[1][8]。

  • 本文の冒頭と社内名を読む。 Celonisのように、本文に社内名を書いている会社がある。社内名が分かれば、同じ会社のほかの求人と比べられる[1]
  • 部門を見る。 CelonisのFDE求人はValue Engineering部門、東京の実装職はServices部門に属している[1][8]。ただし、マドリードのValue Engineer系の求人はServices部門に置かれており、部門だけでは決められない[15]
  • 数一数动词。 是以“传达、展示、推动”为主，还是以“构建、验证、上线”为主，由此可以了解工作的重心
  • FDE以外の職種名でも探す。 東京のDeployment Engineerのように、職務がFDEに近くても職種名にFDEを含まない求人がある[8]

职位名称的更换并不只发生在 Celonis。Cognition 在不改变正文的情况下将职位名称统一为 FDE 的例子见 Cognition 的 FDE 职位，职位名称增多会如何使职位数量膨胀则在 FDE 职位一年增长 4.6 倍是真的吗 中有讨论。FDE 与相近职位的一般区别整理在 FDE 与解决方案架构师的区别 中。

这篇文章有哪些不清楚的地方？

从职位说明中能了解到的，仅限于 Celonis 如何描述职务内容、以哪些名称发布。区分使用职位名称的理由、招聘名额数量、薪酬、AI Agent 的内部机制，都无法从职位说明中确认。

  • 区分使用职位名称的理由。 Celonis 没有在职位说明中说明理由。是在按职位名称比较应聘者的聚集方式，还是配合各地区的叫法，不得而知
  • 採用枠の数。 同じ本文の6件が1つの採用枠なのか別々の枠なのかは、求人票からは分からない(求人IDはそれぞれ別)[1][3][4]
  • 報酬。 ミュンヘン・パリ・東京の求人には報酬額が書かれていない[1][2][8][10]
  • AIエージェント「Apollo」の中身。 名前は東京のDeployment Engineerの求人票に出てくるが、編集部はCelonisの公式発表で中身を確かめられなかった[8]
  • 时间点。 内容基于 2026 年 11 月 14 日获取的职位说明。职位信息可能随时变更，恕不另行通知

总结

  • Celonisが11月9日・10日に公開したFDE求人2件は、社内名がSenior Value Engineerで、所属はValue Engineering部門[1][2]
  • ミュンヘンの小売・消費財向けでは、同じ本文がFDE・Value Engineer・プリセールス・3種のコンサルタントの6つの職種名で出ていた[1][3][4][5][6][7]
  • FDEの名前が付いた職務の中心は価値の試算・PoV・ビジネスケースで、技術要件はPythonかSQLの知識にとどまる[1]
  • 顧客先で実装し本番稼働まで持つのはServices部門のDeployment Engineerで、東京でSenior(6年以上)とPrincipal(12年以上)を日本語必須で募集している[8][9]
  • 東京にはほかにValue Engineer(日英併記の求人票)と、マドリードで1年研修してから東京へ移る新卒向けのOrbit Programがある[10][11]
  • FDE 这个职位名称所指的工作因公司而异。阅读职位时不要只看职位名称，而要看正文、部门和动词

常见问题

QCelonis 的 FDE 和 Value Engineer 是同一个职位吗？

截至2026年11月14日的Celonis招聘信息中也是如此。慕尼黑和巴黎的FDE职位在正文中明确标注了内部职称为Senior Value Engineer，慕尼黑面向零售与消费品行业的职位则与以Value Engineer为名的招聘正文相同。所属部门也都是Value Engineering部门。

QCelonis的Value Engineer是做什么工作的？

这是向客户企业展示Celonis的价值并推进导入与扩展的职务。需要制作价值估算、PoV、商业案例和演示，开展探索价值的研讨会，并负责从签约到使用扩展、合同续签的全过程。技术要求包括Python或SQL知识，以及RPA、BI工具的导入经验。

QCelonis的Deployment Engineer是做什么工作的？

这是Services部门中负责在客户现场实施Celonis的职务。负责从需求梳理、数据连接、设计、构建、效果测量到正式上线与交接的全过程。东京的招聘中，职务内容包括让公司的AI Agent创建数据模型和仪表板并进行验证，要求精通PQL、SQL、Python，具有6年以上经验（Principal为12年以上），并要求日语能力。

应聘QCelonis东京的职位需要日语吗？

截至2026年11月14日，东京的Deployment Engineer（Senior和Principal）要求日语流利并具备商务水平的英语。面向应届生的Orbit Program要求同时具备日语和英语。Value Engineer的招聘信息为日语和英语并列，英语属于优先条件。

QCelonis的FDE招聘信息中写有薪酬吗？

没有写。慕尼黑和巴黎的FDE招聘信息以及东京的招聘信息中均未记载薪酬金额，只有关于向全体正式员工授予股权激励（RSU）的记载。
