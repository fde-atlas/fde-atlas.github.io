前沿部署工程师（应届生）| LiteLLM

摘要

LiteLLM 招聘面向应届生的前沿部署工程师。LiteLLM 是流行的开源 AI 网关，客户包括 Adobe、Netflix 和 NASA。该岗位核心是负责支持队列：处理工单、与客户沟通、在客户环境中复现问题、追查根因而非表面修补，必要时提交修复代码的 PR，并把客户的技术反馈传达给工程团队。要求包括顶尖大学计算机学位、扎实技术功底、快速掌握产品、以指标为导向并承受高工单量。公司提供有竞争力的薪酬、医疗保险及匹配 3.5% 的 401k。

要点

  • LiteLLM 招聘应届生前沿部署工程师，核心是处理支持工单。
  • 要求复现客户环境问题并解决根因，可提交 PR 修复。
  • 硬性要求顶尖大学计算机学位与技术功底。
  • 客户包括 Adobe、Netflix、NASA 等知名公司。
  • 福利含医疗保险与匹配 3.5% 的 401k。

LiteLLM 是全球最受欢迎的 AI 网关，深受 Adobe、Netflix 和 NASA 等顶级公司的信赖。我们的平台为开发者提供安全、可靠的 LLM 及相关服务访问，我们正在寻找一位前沿部署工程师（应届毕业生），帮助客户在使用领先的开源 AI 网关时取得成功。

职位介绍

我们正在寻找一位前沿部署工程师（应届毕业生），主要通过客户电话和支持队列中的互动，帮助客户取得成功。由于 LiteLLM 是一款开发者工具，因此这个人必须具备技术能力。你将深入研究客户的问题，深刻理解它们，并帮助客户扫清障碍。

这个角色的核心很简单：处理支持队列、解决工单，让客户在使用产品时取得成功。我们寻找的是执着于找到问题根本原因、而非只做表面修复的人。最优秀的人会在解决问题之前先真正理解问题的深度。

职责

  • 负责支持队列，处理工单，帮助客户取得成功
  • 诊断客户问题，解决根本原因，而不仅仅是症状
  • 在客户的具体环境中复现问题
  • 在需要时提交修复缺陷和改进的 Pull Request
  • 作为客户的技术代言人，向工程团队反馈

我们的要求

  • 顶尖大学的计算机科学学位（必须）
  • 扎实的技术基础，并渴望快速掌握 LiteLLM 的产品功能
  • 执着于客户，帮助他们通过产品取得成功
  • 执着于解决根本原因，而不是掩盖问题
  • 以指标为导向、勤奋努力，能够处理大量工单
  • 强烈倾向于深入理解问题

为什么加入 LiteLLM？

  • 快速发展的环境，拥有深入的技术主导权。
  • 有竞争力的薪资、医疗、牙科和视力保险福利，以及匹配 3.5% 的 401k 计划。
