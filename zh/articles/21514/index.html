摘要

LayerX 的前沿部署工程师（FDE）实践分享：FDE 深入理解客户业务领域，基于 Ai Workforce 平台快速构建 AI Workflow，并承担产品功能开发职责。团队引入 Coding Agent 自动化 Workflow 构建，将原本约两周的人工搭建大幅提速，同时指出评测护栏（harness）设计、局部最优和 token 成本等仍是待解课题。

要点

  • FDE 的使命是理解客户业务与商惯习，设计并实现最大化业务价值的架构。
  • 避免每个客户重复造轮子，优先复用 Ai Workforce 现有功能。
  • FDE 直接参与产品功能开发，开发流程与基础团队一致。
  • 用 Coding Agent 自动构建 Workflow，并持续吸收例外案例改进。
  • 难点在于定义好的 harness，LLM as a Judge 带来成本与时间开销。
