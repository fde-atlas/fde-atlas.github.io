前沿部署工程师 | Applied Intuition | 日本东京

原标题：Forward Deployed Engineer | Applied Intuition | Tokyo, Japan

Zero G Talent · 2026-10-27 · 约 5 分钟读完

摘要

Applied Intuition 在东京招聘 2027 年 3 月毕业的应届前沿部署工程师。该公司成立于 2017 年，估值 150 亿美元，为汽车、国防等行业提供物理 AI 基础设施，全球前 20 大车企中有 18 家是其客户。东京站点位于大手町，有 60 多名员工，这是该公司首次招聘应届生班级。

要点

  • Applied Intuition 在东京招聘 2027 届应届前沿部署工程师。
  • 公司估值 150 亿美元，服务汽车与国防等行业。
  • 工作内容是将产品部署到客户真实环境中并全栈开发。
  • 要求 C++ 或 Python 能力及约两年经验或同等教育背景。
  • 东京办公室 60 余人，首次招收应届生班级。

任职要求

  • 计算机、计算机工程、电子工程或相关专业的本科/硕士学位，2027 年 3 月毕业
  • 精通 C++ 或 Python 编程
  • 约 2 年工作经验，或同等的教育背景组合
  • 出色的沟通能力，并对客户工作有浓厚兴趣
  • 自驱力强，能快速上手新的技术工具

工作内容

  • 将产品部署并集成到客户的真实环境中
  • 跨技术栈开发新产品、新功能和新工具
  • 攻克软件工程、基础设施、机器人和系统方面的挑战
  • 与客户和团队协作解决技术问题
  • 端到端地主导技术和产品决策

Applied Intuition, Inc. 正在推动物理 AI 的未来。这家硅谷公司成立于 2017 年，目前估值达 150 亿美元，正在打造数字基础设施，让地球上每一台移动的机器都拥有智能。Applied Intuition 服务于汽车、国防、卡车运输、建筑、采矿和农业行业，聚焦三大核心领域：工具与基础设施、操作系统以及自动驾驶。全球前 20 大汽车制造商中有 18 家，以及美国军方及其盟友，都信赖该公司的解决方案来实现物理智能。Applied Intuition 总部位于加利福尼亚州森尼韦尔，在华盛顿特区、圣地亚哥、佛罗里达州沃尔顿堡滩、密歇根州安娜堡、伦敦、斯图加特、慕尼黑、斯德哥尔摩、班加罗尔、首尔和东京设有办公室。欲了解更多信息，请访问 applied.co。

我们是一家实行办公室办公的公司，期望全职员工每周主要在 Applied Intuition 办公室工作 5 天。不过，我们也重视灵活性，并信任员工能够合理安排自己的日程。这可能包括偶尔远程办公、在家参加晨会后再前往办公室，或在需要时提前下班以照顾家庭事务。此办公室办公要求不适用于承包商职位。

关于东京

Applied Intuition 于 2019 年进入日本市场。公司发展迅速，并与日本主要汽车 OEM 客户建立了战略合作关系。东京站点位于大手町地区，拥有 60 多名员工，他们此前来自 Woven by Toyota、Mobileye、TIER IV、Google、西门子以及其他知名公司。我们正在招聘首届应届毕业生班级——想了解更多吗？

关于该职位

Applied Intuition 正在重新定义商用和国防领域的车辆智能。作为前沿部署工程师，你将在小团队中工作，端到端地负责高影响力项目的执行。你将成为 Applied Intuition 的技术与客户真实运营环境之间的技术桥梁。

该职位既要求技术深度，也要求卓越的运营能力。你将直接与客户合作，部署和集成 Applied Intuition 的产品，同时应对各种软件工程、基础设施、机器人和系统方面的挑战。你将对技术和产品决策拥有重要的主导权，并与客户和内部团队紧密合作，解决难题并交付有影响力的解决方案。

在 Applied Intuition，你将：

  • 直接与客户合作，将 Applied Intuition 的产品和工具部署并集成到真实环境中
  • 跨越我们的整个技术栈，为客户的自动驾驶开发工作流程开发新产品、功能与工具
  • 应对各种软件工程、基础设施、机器人和系统方面的挑战
  • 获得与各领域专家以及创业元老共事的绝佳机会
  • 随着成长，逐步主导技术和产品决策，并推动项目从开发到部署的全过程。
  • 与客户、工程师和产品团队紧密协作，理解问题并交付有效的解决方案
  • 打造自己的专业领域，并快速熟悉新的技术工具和环境

我们寻找的人应具备：

  • 计算机科学、计算机工程、电气工程或相关专业的学士/硕士学位（已获得或在读），2027 年 3 月毕业
  • 具备自我驱动的良好记录，能够快速熟悉新的技术工具
  • 曾为各类工程挑战设计过高效且有效的解决方案
  • 扎实的编程能力，熟练掌握 C++ 或 Python 等语言
  • 有在快节奏环境中主动担当的经验
  • 出色的沟通能力，并有兴趣直接与客户合作解决技术问题
  • 约 2 年任意领域的工作经验，或同等的教育与经验组合

加分项：

  • 具备前端、API 层、数据库 ORM、容器化或集群编排框架（如 React、GraphQL、SQLAlchemy、Docker 或 Kubernetes）的工作知识
  • 有使用仿真工具、对物理问题建模或使用机器人中间件（如 ROS）的经验
  • 有处理复杂软件系统、基础设施、机器人或硬件的经验
  • 有国防、汽车、机器人或相关行业的经验

未完全满足所有要求？如果你对这个职位充满热情，但过往经历与职位描述中的每项条件并非完全吻合，我们仍鼓励你申请。你或许正是这个职位或其他职位的合适人选。

Applied Intuition 是一家提供平等机会的雇主，也是联邦承包商或分包商。因此，双方同意，在适用的情况下，他们将遵守 41 CFR 60-1.4(a)、41 CFR 60-300.5(a) 和 41 CFR 60-741.5(a) 的要求，且这些法规在此以引用方式纳入。这些法规禁止基于受保护退伍军人或残障人士身份对合格个人进行歧视，并禁止基于种族、肤色、宗教、性别、性取向、性别认同或国籍对所有个人进行歧视。这些法规要求受涵盖的主承包商和分包商采取积极行动，在雇用和晋升方面不因种族、肤色、宗教、性别、性取向、性别认同、国籍、受保护退伍军人身份或残障而区别对待个人。双方还同意，在适用的情况下，他们将遵守第 13496 号行政命令（29 CFR 第 471 部分，A 分部附录 A）中关于联邦劳动法下员工权利通知的要求。
