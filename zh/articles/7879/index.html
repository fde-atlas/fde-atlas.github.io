Palantir 前沿部署架构师 Chad Wahlquist 谈本体论、仪表盘的消亡，以及将 token 成本降低 60% 的 Evolve 工具

原标题：Palantir's forward deployed architect Chad Wahlquist on ontology, the death of dashboards, and the Evolve tool cutting token costs 60%

摘要

Palantir 前沿部署架构师 Chad Wahlquist 在访谈中阐述本体论如何让企业以语义对象建模业务，使运营应用与 AI Agent 共用同一数据基础。他主张淘汰仪表盘，认为指标应是运营应用的副产品。Palantir 推出 Evolve 工具，通过分析生产日志替换更便宜的模型，有客户两天内降低 60% token 成本。公司还推出免费开发者层与 Builders 计划，希望成为初创企业从第一天起就采用的基础设施。

  • 运营应用、KPI 与 AI Agent 可共用同一数据基础。
  • Wahlquist 主张淘汰仪表盘，指标应源于实际决策的运营应用。
  • Evolve 分析生产日志换用更便宜模型，客户两天省 60% token 成本。

要点

摘要

Palantir 的 Chad Wahlquist 谈本体论、仪表盘和 Evolve

Chad Wahlquist 是 Palantir 的一名前沿部署架构师，他的工作就是解决大多数企业软件公司宁愿忽视的问题：企业其实并不真正理解自己是如何赚钱的。Wahlquist 表示，他经常遇到一些财富 500 强公司以及规模较小的公司，它们无法识别自己最赚钱的产品，甚至常常主动把销售推向错误的产品，因为数据在任何人看到底层机制之前就已经被汇总成了 KPI。

用 Palantir 的说法，解决方案就是本体——一个按照业务实际运作方式对其进行建模的语义层，而不是强行将其塞进行和列。Wahlquist 将其与源自 Kimball 1996 年的维度建模进行对比，后者在 2026 年仍是大多数 Tableau 部署的基础。本体可以在一个语义对象中容纳 CAD 文件、图像、计算机视觉模型和表格数据，例如代表一家制造工厂的对象。正是这种多模态结构让 Palantir 能够在同一个基础上运行运营应用、KPI 和 Agent，而无需为每个用例重建数据架构。

“我们开发了一个名为 Evolve 的工具，它会实际分析生产环境中的日志，了解这些模型如何运行、人们用它们做什么、其上的架构，并能够替换来自不同提供商的不同模型。其中一些客户通过重新架构、选择不同的模型并进行提示词调优，在两天内消除了 60% 的 token 成本。”

消灭所有仪表盘

Wahlquist 对仪表盘的态度很直接：他想消灭它们。KPI 和指标应该是运营应用的副产品——决策实际发生的地方——而不是凭空推测构建的独立产物。他认为，如果把构建仪表盘当作目标，你就会得到“梦幻球场”——没有人会来。OODA 循环（观察、判断、决策、行动）只有在应用内以行动结束时，才能真正影响业绩。

Evolve 与 60% 的 token 成本削减

Palantir 最近推出了一款名为 Evolve 的工具，针对 Wahlquist 经常看到的一种模式：团队在最新的前沿模型上构建 AI Agent 工作流，因为这是让东西跑起来最简单的方式，随后却烧穿了 token 预算。Evolve 会分析生产日志——模型表现如何、用户在做什么、架构长什么样——并找出哪些环节可以用更便宜、更旧或更确定性的模型来处理而不损失质量。它还会标记出缓存模型已经足够的情况，或者把某份数据放进本体（ontology）就能完全省掉模型调用的情况。

Palantir 的 McCarthy 在一次公司活动中提到，一位客户通过模型替换、重新架构和提示词调优的组合，在两天内将 token 成本削减了 60%。

你不会读到的企业 AI 优势

真正获得 AI 优势的公司并不会到处宣传。Wahlquist 举了 AIG 作为公开的例子——将复杂的商业保险承保从数月缩短到数小时或数天，带来的信任和速度优势，是缺乏同样工具的竞争对手在竞标中根本无法匹敌的。他说，类似的时刻正在各行各业发生，只是保持低调，直到它们体现在财报和利润率数据中。

面向构建者的 Palantir

Wahlquist 说 Palantir 提供免费的开发者层级和一个 Builders 计划，其中已经包括两人创业公司。目前有一个实时的 Shopify 集成。他描述了一位小企业主——主要通过 YouTube 视频自学——如何在三个月内把 -10% 的利润率扭转为 +9–10% 的利润率。Wahlquist 认为，Palantir 作为企业从第一天起就使用的基础层——像 Stripe Atlas 一样可以注册的东西——正是产品的发展方向，尽管销售模式和叙事还没跟上。
