要写这份工作，我得先做这份工作

原标题：To Write About the Work, I Have to Do the Work

FDE Hub · 2026-11-10 · 约 2 分钟读完

摘要

作者加入 Sycamore 担任前沿部署工程师，分享两周的入职体验。Sycamore 开发企业级 AI Agent 操作系统，其产品方向与作者长期关注的议题一致：Agent 分阶段获得自主权、信任决定部署速度、系统随业务规则变化而失效。作者的工作是双向循环：把研究转化为可复用、可扩展的客户方案，同时把客户真实需求带回产品。他观察到 AI 辅助开发的交付速度远超一年前，正在思考速度如何改变工作中稀缺的部分。FDE Hub 将保持中立，素材将来自一线实践。

两周前，我以前沿部署工程师的身份加入了 Sycamore。

我首先一直是一名 FDE，其次才是 FDE Hub 的创始人和编辑。这份通讯之所以有价值，是因为它是从这份工作的内部写出来的，我需要继续做这份工作，才能凭亲身经验来写作。

为什么选择 Sycamore

Sycamore 正在为企业构建一个 Agent 操作系统：用于构建 AI Agent 的软件，以及在它们运行后对其进行治理的软件。

吸引我的是，这家公司的组织方式正是围绕我在这里写了一年的那些问题。我曾论证过 Agent 是分阶段赢得自主权的，而且信任对部署推进速度的影响远大于能力。我也写过 当业务规则改变而软件毫不知情时，系统会逐渐失效 的问题。

在 Sycamore，这些是工程师和研究员团队每天都在攻克的产品问题。在文章中描述这些问题是一回事，而我想直接参与解决它们。

这份工作是双向的

我在工程团队中，组织结构非常扁平。

我工作的很大一部分从研究开始。我身边有大量的研究，我的职责是消化它们，弄清楚如何应用，并把它们转化为可重复、可扩展、对客户有用的东西。

另一部分则朝相反的方向进行。我与客户坐在一起，弄清他们真正的需求，然后把这些反馈带回产品中。

我之前论证过，这个闭环正是 FDE 团队存在的理由，能站在这个闭环的中间感觉很好。两周内，我已经投入了构建工作，开始与一位客户合作，还见了潜在客户。

节奏

我每天的大量时间都花在指挥各种 Agent 上，产出量与我一年前的工作方式相比难以同日而语。

工程的节奏令我惊叹——我本身就已经写过构建速度变得有多快。这样的速度改变了工作中哪个环节是稀缺的，我还在思考这在实践中意味着什么。

这对 FDE Hub 意味着什么

FDE Hub 将保持厂商中立。我会继续写关于这门手艺的内容，访谈也将继续涵盖来自全行业的从业者。

变化的是素材。我每周都在构建产品、与客户交流，这些经历会融入我的文章。

我还为视频系列录制了五段新的对话，它们将在未来几周陆续发布。

这是很好的两周。
