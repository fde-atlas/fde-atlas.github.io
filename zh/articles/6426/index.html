摘要

Latent Space 采访 Modal CTO Akshat Bubna，探讨 AI 基础设施如何从开发者体验转向 Agent 体验。Modal 刚完成 3.55 亿美元 C 轮融资，其平台为推理、训练、批处理和沙箱等 AI 工作负载重建了底层原语，认为 Kubernetes 不适合突发性计算密集型任务。

要点

  • Modal 完成 3.55 亿美元 C 轮融资，定位为面向 AI 应用的云平台。
  • Kubernetes 为 Web 服务器设计，无法应对突发性 AI 工作负载。
  • SDK 团队已从开发者体验转向 Agent 体验，用装饰器替代 YAML。
  • 强化学习 rollout 可能需要 10 万个沙箱，生产 Agent 需硬性护栏。
  • Modal 跨 17 家云服务商构建容量池，可观测性比读代码更重要。

我们一直在进行一个 Agent Cloud 系列调查，覆盖所有顶级推理/计算/云服务提供商，从 Databricks 到 Daytona 再到 Railway，甚至更早的 E2B，而我们现在很高兴以回归 Modal 来为这个系列收官——Modal 刚刚完成了一笔高达 3.55 亿美元的巨额 C 轮融资。

云是为开发者而建的。但现在 Agent 正在改变这一点。

旧的基础设施栈是为人类设计的——他们可以阅读文档、推敲 YAML、看懂仪表盘，从而在出现故障时弄清楚自己需要什么。虽然这对开发者来说很痛苦，但仍然可行，因为他们可以在脑中补全缺失的上下文。

然而，Agent 没有这种奢侈条件。在这个 Agent 的新时代，一切都必须更加紧密。

Agent 也需要良好的开发者体验 - Modal 博客
