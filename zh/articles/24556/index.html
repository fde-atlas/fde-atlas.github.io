职位要求

HackerRank 正在全球范围内扩展其前沿部署工程（FDE）职能。我们正在招聘一名前沿部署工程经理（全球），为该团队制定战略、标准和执行标准。这是一个亲力亲为的领导岗位。你将领导全球 FDE 职能，直接管理美国的 FDE，并与 EMEA 和 APAC 的区域总经理紧密合作。

你的职责

  • 领导、辅导并培养一支 FDE 团队，他们负责主导客户合作（售前和售后），以定义并交付解决方案。
  • 与销售、产品、工程和客户成功团队合作，打造能解决客户实际问题的解决方案。
  • 与产品和工程团队合作，将客户定制解决方案纳入产品路线图。
  • 在 API、集成和平台能力方面提供亲力亲为的技术领导。
  • 提升我们开展演示、概念验证和现场合作的方式。
  • 构建可复用的操作手册、交付标准和最佳实践，以实现规模化快速推进。

你是什么样的人

  • 一位经验丰富的技术领导者，拥有 8 年以上工程、解决方案工程或技术交付经验，以及 2 年以上带领高绩效技术团队的经验。
  • 热衷于与团队并肩作战、评审设计、挑战假设，并在问题变得模糊或高风险时挺身而出。
  • 在领导面向客户的技术团队方面经验丰富，深知成功取决于信誉、清晰度和执行力，而非话术或交接。
  • 在工程和业务场景中都能游刃有余，既能与工程师讨论架构，也能与销售、产品和客户负责人对齐成果。
  • 出色的演讲者和沟通者，能够针对技术和非技术受众调整表达方式。

如果你具备以下条件更佳

  • 担任过前沿部署工程师、解决方案工程师或技术顾问的经验。
  • 拥有开发者工具、HR 科技或 API 优先的 SaaS 平台背景。
  • 有在全球分布式或矩阵式团队中工作的经验。

如果你符合以下情况，你将在这个岗位上如鱼得水

  • 你喜欢从零开始构建团队、系统和标准。
  • 模糊性能激发你的活力，尤其是在快速变化的环境中。
  • 你对责任感和质量有高标准，倾向于行动和紧迫感。
