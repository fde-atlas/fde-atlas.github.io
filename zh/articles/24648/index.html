高级前沿部署工程师，移动端 | SpruceID

原标题：Senior Forward Deployed Engineer, Mobile | SpruceID

Zero G Talent · 2026-03-24 · 约 2 分钟读完

摘要

SpruceID 正在招聘高级前沿部署工程师（移动方向），负责为政府机构开发数字身份相关的移动应用。该职位要求五年以上 iOS 或 Android 开发经验，熟悉 Swift、Kotlin、Flutter 或 React Native，并具备移动安全、蓝牙或 NFC 等底层协议经验。工作内容涵盖与州政府客户直接对接、将政策需求转化为移动端产品、配合后端集成 API，以及确保应用符合安全、隐私和无障碍标准。职位为美国境内全远程，熟悉 OAuth、OpenID Connect 或 mDL 等身份协议者优先。

要点

  • SpruceID 招聘移动方向高级前沿部署工程师，服务政府数字身份项目。
  • 要求五年以上移动开发经验，掌握 Swift、Kotlin、Flutter 或 React Native。
  • 需直接对接州政府客户，将政策需求转化为移动端实现。
  • 需熟悉移动安全、蓝牙或 NFC，以及无障碍设计标准。
  • 职位为美国全远程，了解 mDL 等身份协议者优先。

你需要具备的条件

SpruceID 构建保护隐私、基于标准的数字身份与凭证解决方案，让个人掌控自己的信息，同时帮助政府和企业提供安全、可互操作的服务。我们与公共部门组织合作，推动身份的签发、验证和使用方式的现代化。

作为前沿部署移动工程师，你将专注于构建和部署移动应用，把 SpruceID 的技术直接交到与政府互动的民众手中。你将与州政府、公共部门合作伙伴以及 SpruceID 各团队紧密协作，设计并交付安全、私密且易于使用的移动体验。该职位将动手开发与面向客户的交付相结合，确保移动应用满足高技术标准和公共部门的实际需求。

该职位在美国境内完全远程办公。

你的工作内容

  • 使用 Swift、Kotlin、Flutter 或 React Native 等框架为 iOS 和 Android 设计、构建和维护移动应用
  • 确保移动应用满足政府在安全性、隐私、无障碍和可靠性方面的要求
  • 与后端工程师协作，将 API 和服务集成到稳健的移动体验中
  • 将客户和政策需求转化为移动优先的产品设计与实现
  • 与 UX 设计师紧密合作，为公共部门受众提供直观且包容的用户体验
  • 与客户交付负责人合作，确保在生产环境中成功部署、测试和运营
  • 通过确保移动端实现符合全球数字身份协议，推动标准的采用
  • 就移动应用的部署、安全和运营为公共部门合作伙伴提供技术指导

任职资格

  • 5 年以上为 iOS 和/或 Android 构建并发布生产级移动应用的经验
  • 精通至少一种移动开发技术栈：Swift、Kotlin、Flutter 或 React Native
  • 具备构建后端服务和 API 以及集成移动应用的经验
  • 深入理解移动安全，包括安全存储、身份验证和加密实践
  • 具备蓝牙或 NFC 等底层协议的使用经验
  • 熟悉移动应用的无障碍标准和包容性设计实践
  • 出色的沟通能力，能够直接与客户合作，最好有咨询或交付场景的经验
  • 常驻美国，并愿意直接与州政府合作伙伴对接

加分项

  • 具有在公共部门或其他高度受监管环境中交付移动解决方案的经验
  • 熟悉身份标准和协议，如 OAuth、OpenID Connect 或 mDL（移动驾照）
  • 具备 CI/CD 流水线、自动化测试和移动应用部署方面的经验

在 SpruceID，我们重视多元的视角和背景。我们致力于提供平等的就业机会，不因种族、肤色、血统、宗教、性别、国籍、性取向、年龄、公民身份、婚姻状况、残障、性别认同或退伍军人身份而有所歧视。
