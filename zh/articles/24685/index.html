摘要

这是一则招聘启事：Cursor（Anysphere）在旧金山招聘前沿部署工程师合作伙伴项目负责人，年薪22.4万至33.6万美元。该职位负责搭建并运营通过系统集成商和咨询公司扩展FDE交付的合作伙伴生态，包括制定技术准入标准、设计认证与赋能体系、共同交付首批合作项目并沉淀为可复用的方法论。候选人需具备软件工程或架构背景、企业级复杂项目交付经验，最好有LLM应用或AI Agent部署经验，并接受出差。文中还混入了SpaceXSI关于Grok模型与超级智能团队的描述。

要点

  • Cursor招聘前沿部署工程师合作伙伴项目负责人，年薪22.4万至33.6万美元。
  • 核心职责是通过系统集成商扩展FDE交付，而非直接招聘更多工程师。
  • 需制定技术准入标准、设计认证体系并共同交付首批合作项目。
  • 要求软件工程背景、企业级交付经验，最好有LLM或AI Agent部署经验。
  • 成功标准是合作伙伴按质量标准交付的FDE项目数量。

SpaceX 的创立基于这样一个信念：人类探索星辰的未来，从根本上比止步不前的未来更令人振奋。如今，SpaceX 正在积极开发实现这一目标所需的技术，其终极目标是让生命成为多行星生命，并将意识拓展至星辰。SpaceXSI 正在构建超级智能，以帮助人类理解宇宙。我们的团队正在打造完整的超级智能技术栈：从我们的 Colossus 超级计算机，到 Grok 模型，再到我们的应用套件，包括 Grok Bot、Grok Build、Grok Imagine、Grok Voice 和 X。我们正在打造一个强大的飞轮：更多的算力训练出更好的模型，更好的模型支撑更有用的产品，而我们从用户使用这些产品中获得的经验，又将塑造我们接下来的构建方向。

前沿部署工程合作伙伴经理

我们的前沿部署工程师（FDE）不会在旁观者位置上提供建议。他们会深入企业客户团队，与他们并肩构建生产级的 AI 编码工作流，并留下在项目结束后仍能持续产生价值的习惯。作为前沿部署工程合作伙伴经理，你将构建并运营一个通过系统集成商（SI）和咨询公司来延伸这项工作的合作伙伴生态系统：招募合适的合作伙伴，为其交付团队提供赋能与认证，并共同交付将 Grok 模型、Grok Bot、Grok API 和 Cloud Agents 落地到企业客户生产环境的前沿部署项目。成功的衡量标准是：因为合作伙伴能够承接工作，有多少更多的 FDE 工作达到了我们的质量标准并得以交付，而不是有多少合作伙伴签约。

职责：

  • 与我们的 FDE 共同交付首批由合作伙伴主导的项目，然后将行之有效的经验转化为蓝图：项目模式、范围界定模板、架构模式、评测标准，以及推广与交接标准。
  • 设定技术标准，确定哪些公司和实践有资格交付项目，拥有验收的“通过/不通过”决策权，并从范围界定、架构评审到生产上线和交接，全程负责合作伙伴主导项目的技术成功，在风险项目中亲自介入。
  • 设计并运营合作伙伴赋能与认证体系，指导合作伙伴团队完成实际项目，直到他们能够独立交付。
  • 与合作伙伴团队合作，引入具备足够技术深度的系统集成商和咨询合作伙伴，共同交付前沿部署工程类项目。
  • 与合作伙伴负责人及销售团队共同建立并运营联合业务管道，并参与制定联合或合作伙伴主导的方案。
  • 将合作伙伴在一线的经验教训和产品缺口转化为可复用的操作手册，并向产品与工程团队提供具体反馈。

基本任职资格：

  • 拥有软件工程师、解决方案工程师、架构师或前沿部署工程师的实战技术背景。
  • 拥有在企业客户现场亲自主导复杂技术项目的经验，从需求探索和范围界定到生产环境落地，并能应对复杂的利益相关方环境。

优先技能与经验：

  • 拥有为部署企业客户部署基于 LLM 的应用、评测或 AI Agent 系统的经验。
  • 拥有通过非直接下属的工程师构建交付能力的经验，例如合作伙伴实践团队、外包交付组织或赋能职能，并在商业压力与之相悖时仍能坚守质量标准。

其他要求：

  • 必须愿意出差拜访客户。
