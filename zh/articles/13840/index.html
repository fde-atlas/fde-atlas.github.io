摘要

这是 Interview Kickstart 的前沿部署工程师（FDE）培训课程介绍页。课程面向希望转型 FDE 的资深工程师，为期 23 周，分四个阶段：AI 工程（Agent 基础、RAG、多智能体、评测与安全、微调）、AI 辅助编程、FDE 实务（客户发现、SoW 与定价、生产化、合规交接）以及六周面试准备，内容对标 Palantir、OpenAI、Anthropic、Glean 的招聘方式。课程包含 8 个实战项目和跨 AWS、GCP、Azure 三套云栈的企业级毕业项目，主讲人为一线 AI 工程师和 FDE。文章认为 FDE 技能栈需要 AI 工程深度与客户交付能力兼备，是应对常规编码被自动化的职业对冲。

要点

  • 23 周课程，覆盖 AI 工程与 FDE 客户交付两大技能栈。
  • 含 8 个实战项目及跨 AWS、GCP、Azure 的企业级毕业项目。
  • 面试准备对标 Palantir、OpenAI、Anthropic、Glean 的招聘流程。
  • 面向解决方案架构师、MLE、数据工程师等转型人群。
  • 主张 FDE 角色是对常规编码被自动化的一种职业对冲。

AI 工程主线

第 1 周：Agentic AI 基础与反射型 Agent

  • Agent 方程式：提示词、工具、记忆与 LLM
  • ReAct 循环与五大核心 Agentic 设计模式
  • Agentic 与自主性的决策权衡及提示词工程

第 2–3 周：RAG 驱动的知识 Agent

  • 使用 LangChain LCEL 的检索 → 增强 → 生成流水线
  • 带历史记录与幻觉防范的多轮 RAG
  • 检索与生成指标：Precision@K、忠实度

第 4 周：多 Agent 系统（规划器–执行器–评审器）

  • 基于角色的设计：编排器、规划器、综合器
  • 任务分解、路由与委派
  • LangGraph 的状态、节点、边与检查点持久化

第 5 周：对话式与多模态 Agent

  • 级联式 STT→LLM→TTS 与实时语音到语音的权衡
  • 用于协调的可复用 LangGraph 子图
  • 人在环中的批准、审阅编辑与中断模式

第 6 周：Agent 通信协议（MCP、A2A、ACP）

  • 通过 MCP 与 FastMCP 服务器实现结构化工具访问
  • 借助有限状态机与经验证的转换实现可靠消息传递
  • 通过 Google ADK 基于 A2A 协议实现网络化 Agent

第 7 周：混合搜索与检索

  • 稀疏向量与稠密向量；k-NN、ANN 与 HNSW
  • 使用 SPLADE 实现学习型词汇匹配
  • 在 Qdrant 中使用倒数排名融合（RRF）的混合搜索

第 8 周：Agent 可观测性、评测与安全

  • LangSmith 追踪以及基于精选追踪记录的评测数据集
  • LLM-as-judge、DeepEval 指标与 Guardrails AI
  • 使用 Presidio 进行 PII 脱敏；通过路由、缓存和批处理控制成本

第 9 周：微调与领域适配

  • 提示词 vs RAG vs 微调的升级决策框架
  • PEFT 全景：LoRA、QLoRA、前缀微调与适配器
  • 4-bit 量化、TRL SFTTrainer 以及部署到 HF Hub

第 10–11 周：毕业项目——企业级多 Agent 系统

  • 从架构到构建，完整负责一个真实企业问题
  • 集成检索、编排、评测、安全与成本监控
  • 像生产系统评审一样论证可靠性、延迟与成本

AI 辅助编程

第 12 周：与 Claude 结对编程

  • AI 时代真实的面试考察意图与问题解决思维
  • 结构化的五阶段 AI 辅助编程框架
  • Claude 生态系统：Skills、Projects、Artifacts 与 Claude Code

FDE 主线

第 13 周：客户探索与需求界定（FDE 毕业项目启动）

  • FDE 角色是什么，以及它与 SWE、SA 和 MLE 的区别
  • 90 分钟客户访谈脚本与“展示一下你今天是怎么做这件事的”
  • 干系人映射、RACI 与决策日志纪律

第 14 周：SoW、定价与解决方案架构

  • 带风险缓冲的 4 里程碑估算框架
  • 撰写以评测为验收标准的 SoW，以及 IP/数据条款
  • 定价模型与可辩护的技术栈选型决策矩阵

第 15 周：构建生产级 Agent（OpenAI Agents SDK + AWS Bedrock AgentCore）

  • Agent、Handoffs、Guardrails、Sessions 与沙箱执行
  • Foundry Agent Service vs. Hosted Agents vs. Container Apps
  • 生产加固、四种多 Agent 失效模式，以及大规模 RAG

实战项目：毕业项目工作：将构建成果加固到生产级 成果：在真实负载下于 AWS Bedrock AgentCore 上运行加固后的生产级 Agent。

第 16 周：API、MCP 服务器与 RBAC

  • 将 API 设计为 Agent 工具（FastAPI、OpenAPI 与幂等性）
  • 构建并加固 MCP 服务器，实现按租户隔离与审计日志
  • 认证模式：OAuth 2.0、Entra 服务主体与托管标识

第 17 周：评测、可观测性与交付（毕业项目收尾）

  • 数据治理、数据驻留、租户隔离与自主性阶梯
  • 合规素养：SOC 2、HIPAA + BAA、FedRAMP、ISO 27001 与 GDPR
  • 将评测套件作为 CI 部署门禁、事故应急演练与干净的交付交接

FDE 面试准备

第 18–21 周：Agentic AI 系统设计实战

  • 研究型 Agent：面试条件下的规划、工具与安全护栏
  • 在大型模式上构建可靠的 text-to-SQL Agent
  • 多智能体协作、共享记忆与自我改进的验证循环

第 22 周：问题拆解与案例研究面试

  • 源自 Palantir 的 FDE 问题拆解 / 案例轮面试
  • 澄清模糊之处、拆解问题、提出为期 4 周的范围，并指出风险最大的假设
  • 一个包含 10+ 场景的题库、AI 辅助结对编程环节，以及架构追问

第 23 周：行为面试与采购–安全面试

  • STAR+ 框架与 16 道 FDE 专属行为面试题
  • 沟通权衡取舍，以及在不损害可信度的前提下传达坏消息
  • 一次采购/安全模拟演练和一份 15 题的安全问题库

附加内容（自学进度）

基础方向：

AI 驱动开发基础、Python 要点、提示词与工具、多智能体系统、LLM 框架（MCP、A2A、ADK），以及从开发到部署（Docker、FastAPI、Kubernetes 基础、可扩展 RAG）。

职业方向：

DSA（排序、递归、树、图、动态规划）、简历与 LinkedIn 大师课、行为面试策略，以及 Offer 谈判工作坊。

与讲师在直播课中共同构建——逐步跟着代码一起动手搭建。

  • 你的第一个由 LLM 驱动的智能体。学习 LLM 如何将函数调用作为其推理引擎、工具（领域查询、CRM 历史、线索评分）如何塑造行为，以及“思考–行动–观察”循环如何驱动真实决策。
  • 一个面向 IT 支持的生产级 RAG 系统，严格基于检索到的工单数据作答。涵盖 OpenAI 嵌入、分块、五种 LlamaIndex 索引方式、LangChain LCEL 管道、防幻觉保障机制、两层评测，以及带记忆的 Agentic RAG 扩展。
  • 一个 Orchestrator → 搜索 → 行程规划器 → 合成器的工作流：由专门的智能体搜索航班和酒店、生成行程并综合推荐。使用 LangGraph、LangChain、Tavily、SerpAPI 构建。
  • 一个基于 LangGraph StateGraph 的有状态语音助手，包含 RAG 产品发现、带 HITL 中断的订单跟踪、并行分发、MemorySaver 检查点，以及 Whisper + OpenAI TTS 管道。
  • 一个买家–卖家系统，智能体通过类型化的 Pydantic 模式进行通信。从一个暴露出十种失败模式的失败版本，逐步演进到具备 FSM 终态、基于 MCP 的工具、LangGraph 路由，以及通过 Google ADK 实现真正 A2A 传输的健壮架构
  • 在 Amazon ESCI 数据集上实现词汇精确性与语义理解的结合。使用 SPLADE 和 BGE-Large 生成双路嵌入，以 HNSW 索引到 Qdrant，并通过倒数排序融合（Reciprocal Rank Fusion）进行合并。
  • 一个 Supervisor + 专家智能体系统，具备完整的生产加固：LangSmith 追踪、DeepEval 指标、Guardrails AI 校验器、Presidio PII 脱敏，以及基于 tiktoken 的单次查询成本仪表盘。
  • 医疗健康问答 Agent：使用 QLoRA 微调 4 位量化的 Qwen2.5-1.5B-Instruct，将 LoRA 适配器部署到 HF Hub，并在 LangSmith 中与基础模型进行并排评测。

常见问题

1 什么是 FDE 岗位？为什么是现在？

前沿部署工程师处于软件工程、面向客户的实施和 AI 部署的交汇点——负责在客户环境中维护生产代码。前沿实验室和超大规模云厂商正在大力投入这一岗位，美国的 FDE 职位发布数量急剧增长，而且 FDE 的薪酬明显高于高级 SWE。

2 这个项目是为谁设计的？

两类人群，各自掌握 FDE 技能栈的一半。面向客户的工程师——客户工程师、解决方案架构师、解决方案工程师——希望获得 AI 工程深度；以及编码或数据工程师——MLE、数据工程师、数据科学家、后端 SWE，以及编码方向的技术负责人、TPM 和 EM——希望掌握客户探索、需求界定和交付的技艺。两者最终都将掌握完整的技能栈。

3 我需要具备 AI 或 ML 经验吗？

不需要。AI 工程主干（第 1–11 周）会先打好基础——Agent、RAG、多 Agent 编排、评测、微调——然后才开始 FDE 专项模块。需要具备软件工程背景和熟练的 Python 能力。

4 这个项目与其他 AI 项目有何不同？

这是首个为美国市场打造的端到端 FDE 项目，由拥有真实客户经验的从业者授课，在一个项目中涵盖 AI 工程主干、FDE 主干以及为期六周的 FDE 专项面试准备。

5 Live Guided Projects 和 Capstone 有什么区别？

引导式项目在直播课程中由讲师带领逐步完成。毕业项目则是一个独立的、由学员主导的企业级实战项目，讲师提供指导和答疑解惑的支持——而非逐步教学。

6 课程是如何交付的？

概念与系统设计的直播互动课程、每周一个引导式直播项目、专门的面试准备模块，以及自主进阶的基础知识与工具学习。

7 我每周需要投入多少时间？

直播课程每周约需 4–6 小时，作业、项目和自主练习每周约需 6–8 小时。

8 我将学习哪些工具和技术？

Python、LangChain、LangGraph、LlamaIndex、Google ADK；OpenAI、Anthropic 和 Gemini API；FAISS、Chroma、Qdrant、pgvector；Whisper 和 OpenAI TTS；LangSmith、DeepEval、Guardrails AI、Presidio；FastMCP 和 A2A；Hugging Face、PEFT、QLoRA；Streamlit、FastAPI；Docker、AWS、GCP、Azure；OpenAI Agents SDK 和 Azure AI Foundry。

9 什么是多技术栈毕业项目覆盖？

毕业项目在一个主技术栈（OpenAI Agents SDK + Azure AI Foundry）和两个备选技术栈（Google ADK + Vertex AI；Claude Agent SDK + Amazon Bedrock AgentCore）上交付，让你毕业时能够在 Azure、GCP 和 AWS 上自如交付项目。

10 我可以选择自己的毕业项目吗？

可以。你可以从预先定义的 FDE 实战项目中选择，或使用 BYOP 选项提出自己的项目，并在导师指导下确定范围。

11 我会学到何时不该使用 Agent 吗？

会。一个核心主题是 Agent 化与确定性方案的决策——何时规则、确定性工作流或传统机器学习优于 Agent，以及如何在设计评审和面试中为这一选择进行论证。

12 我构建的系统有多接近生产级？

这些系统的设计考虑了生产环境的约束——评测、防护栏、成本跟踪、可观测性、部署、RBAC 和交接。它们是学习型系统，但架构映射了真实的企业级部署。

13 这能帮助我转型到 FDE 岗位吗？

能。面试准备模块围绕招聘 FDE 团队的公司的真实面试流程设计——AI 系统设计、问题拆解/案例轮次、AI 辅助结对编程，以及行为面试和采购安全轮次。

14 讲师的资质如何？

所有讲师均为一线公司的在职或前 AI 工程师 / FDE，拥有构建和部署企业级 Agent 系统的实战经验。

15 会有作业或考试吗？

本课程以项目为主，而非考试为主。每周都将引导式直播实战与独立拓展任务相结合，直接关联系统设计和生产环境的权衡取舍。

16 如果我错过了直播课程怎么办？

所有直播课程均有录像，讲师支持加讨论频道可帮助你异步解决问题。
