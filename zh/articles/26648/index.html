前沿部署工程师 AI Gateway EMEA | Kong

原标题：Forward Deployed Engineer AI Gateway EMEA | Kong

Zero G Talent · 2026-11-04 · 约 4 分钟读完

摘要

Kong 正在 EMEA 招聘前沿部署工程师，聚焦 AI Gateway 方向。该岗位要求深入客户企业，端到端负责从技术调研到生产环境落地的全过程，确保客户的战略性 AI 用例在真实流量、身份与策略管控下安全运行，而非停留在演示阶段。候选人需具备 Go、Python 或 TypeScript 的生产级开发经验，熟悉 API 网关、Kubernetes、OAuth/OIDC、mTLS 等基础设施技术，并掌握 LLM 与 Agent 模式，包括 MCP、模型路由、评测及成本与延迟权衡。岗位职责还包括排除试点与生产中的技术障碍，将现场经验沉淀为可复用模式，并定期回到 Kong 内部工程团队协作，把一线需求反馈给产品团队。

要点

  • Kong 在 EMEA 招聘 AI Gateway 方向的前沿部署工程师。
  • 岗位要求端到端负责从试点到付费落地的技术路径。
  • 需具备 Go、Python 或 TypeScript 生产级开发经验。
  • 要求熟悉 MCP、Agent 模式、API 网关与身份安全。
  • 工程师需定期回内部工程团队，反馈一线需求。

任职要求

  • 具备使用 Go、Python 或 TypeScript 构建生产级软件的实际工程经验
  • 拥有前沿部署工程师、解决方案架构师或技术顾问等面向客户的技术经验
  • 在身份认证、网络、安全和可观测性方面具备企业架构直觉
  • 了解 LLM 和 AI Agent 模式，包括 MCP 和模型 API
  • 具有 API 网关、Kubernetes、服务网格、OAuth/OIDC、mTLS 和策略执行方面的经验

工作内容

  • 与客户平台和工程团队共同主导 AI、API 和 AI Agent 相关的技术调研
  • 设计涵盖模型、API、MCP、工具访问、身份认证和策略的运行时架构
  • 构建原型、集成、评测流程和参考实现，以支撑生产流量
  • 消除试点和生产环境中的障碍：认证、网络、可观测性、延迟和成本
  • 负责从试点到付费的技术路径，直至工作负载真正运行起来

关于该职位：

如果您认为自己不完全符合以下所有条件，但仍然对该职位感兴趣，请申请。没有人能完全满足所有要求——我们寻找的是在某些方面特别出色，同时对其他方面也有一定兴趣和能力的候选人。

您将帮助我们的客户在其真实环境中安全地运行他们的首个战略性 AI 用例。不是演示，也不是悄然夭折的概念验证，而是真实的流量、真实的身份认证、真实的策略。

作为 EMEA 地区的前沿部署工程师，您将与该地区一些最重要企业的平台、安全和工程团队并肩工作，负责从首次调研电话到工作负载真正运行的技术路径。您是一名具备企业架构直觉的建设者，能够赢得资深工程师和安全架构师的信任，并能从容应对 API、AI Gateway、Agent、MCP、身份认证和策略等方面的各种不确定性。

这不是仅做演示的售前工程师角色，也不是基于工单的实施咨询工作。您将端到端地负责战略性 AI 机会的技术成功，并将所学带回 Kong 的工程团队，让下一单成交得更快。

工作内容

  • 与客户平台、安全和工程团队共同主导 AI、API 和 AI Agent 相关的技术调研。
  • 设计涵盖模型、API、MCP 和工具访问、身份认证和策略的运行时架构。
  • 构建原型、集成、评测流程和参考实现，证明 Kong 能够治理真实的生产流量。
  • 消除试点和生产环境中的障碍：认证、网络、可观测性、延迟和成本
  • 负责从试点到付费的技术路径，并坚持跟进直到工作负载顺利运行。
  • 将你构建的内容转化为可复用的模式，让下一个 AI Gateway 项目的赢单更快、成本更低。
  • 定期深入 Kong 内部工程团队，与他们在 AI Gateway 和 Agent 路线图工作上结对协作。
  • 在竞争对手定义叙事之前，将一线实践模式和路线图关键需求直接反馈给产品团队。
  • 与销售、解决方案工程和客户成功团队在 EMEA 地区合作处理战略性 AI 机会。

你将带来什么：

  • 扎实的工程实践背景，具有构建和交付生产级软件的经验（Go、Python、TypeScript 或类似语言）。
  • 具有面向客户的技术岗位经验，如前沿部署、解决方案架构、资深或首席工程师，或技术咨询。
  • 企业架构直觉：能够在复杂环境中针对身份、网络、安全和可观测性约束进行设计。
  • 具有 LLM 和 Agent 的生产环境经验，深入理解 Agent 开发框架和 AI 工程原则，包括模型选择与路由、提示词与上下文设计、工具调用、检索、测试与评测，以及成本、延迟和可靠性之间的权衡
  • 具有 API 网关或基础设施经验：Kubernetes、服务网格、OAuth/OIDC、mTLS、策略执行。
  • 在资深工程师和安全架构师中具有可信度。你能够主导一场技术讨论，从白板走向可运行的代码。
  • 你对结果负责，而不是工单。你能从容应对模糊性，并推动工作直至完成。
  • 具有 MCP 的实践经验，包括构建或部署 MCP 服务器，并清晰理解 Agent 如何发现和调用工具、身份如何在调用中传递，以及工具访问如何得到安全保障
  • 优秀的英语书面和口头沟通能力；掌握其他欧洲语言者优先。
  • 愿意根据需要前往 EMEA 地区的客户现场。

加分项

  • 曾在 AI 原生、开发者平台或基础设施公司工作。
  • 具有 Kong Gateway、Konnect 或其他 API 管理平台的使用经验。
  • 有开源贡献，或有发布参考架构或模式的记录。
