摘要

日本新事业共创公司Relic在OpenWork发布解决方案工程师／FDE招聘。该职位要求工程师从客户模糊的需求出发，挖掘其尚未言明的痛点，完成需求定义、前后端实现、云基础设施搭建，并利用AI提升开发效率。公司强调不做单纯按规格交付，而是支持客户内制化并长期陪伴。年薪540万至1125万日元，含45小时固定加班费，采用裁量劳动制，要求每周过半工作日的13点至17点在办公室。任职需3年以上Web开发经验及AI应用实绩。

要点

  • Relic为日本大企业提供新事业共创服务，支持超5000家企业。
  • FDE需从无规格书状态挖掘客户模糊需求并推进项目。
  • 工作涵盖前后端实现、云基础设施及AI活用提案。
  • 年薪540万至1125万日元，含固定加班费45小时。
  • 要求3年以上Web开发经验及与AI结合的具体成果。

  • 工作内容
  • 按照客户提供的规格开发系统。但工作不止于此，还要通过对话挖掘出客户自己也尚未能用语言表达的困扰，并引导至解决。在这个职位上，您将作为这样的工程师发挥作用。 在客户的现场，有很多尚未整理成规格书形式的模糊课题。与客户一起梳理问题所在，提出解决方向，与开发团队一起将其实现，并见证其运营和落地。我们认为编写代码只是手段之一。 您还将把利用AI提高开发和周边业务的效率、并将节省出的时间用于解决客户课题，作为日常工作的一部分。 ▼主要业务内容 ・通过客户访谈，把握和梳理业务课题 ・以咨询为起点的提案与报价 ・从没有规格书的状态进行需求定义，与客户一体推进项目 ・将客户模糊的需求转化为团队可实施的任务，发挥桥梁作用 ・包括AI应用在内的课题解决方案提案 ・包括合同形式（承包/准委任/成果联动型等）在内的提案设计 ・不止于交付，持续支持客户内部化并陪伴同行 ・前端及后端实现，技术的调研、选型与导入 ・使用云和托管服务进行基础设施的设计、构建与运维 ・团队内的知识共享、成员培养（教学也被视为业务的一部分） ＊必要时，可能会前往客户处确认业务情况 【近期的工作案例】 ・面向大型企业的AI基础设施提案：深入到合同结构、非功能需求、AI精度相关方针的提案 ・SaaS提供与内部化支持：不止于交付，陪伴客户转向以成果为核心的合同 ＊详情将在面试中说明 【使用的技术与工具】 ■ 语言 / FW：TypeScript / Next.js, Ruby / Ruby on Rails, PHP / Laravel, Python ■ 基础设施 / 托管：AWS, GCP, Supabase, Vercel, Netlify ■ 开发环境与工具：Docker, GitHub, Claude Code, Cursor, Code Rabbit ■ 沟通工具：Slack, GitHub, Zoom, esa.io, Backlog ＊由于每个项目都会进行技术选型，可能会采用上述以外的技术栈 ＊基于“适材适所”的方针，我们致力于选择适合事业/产品性质的技术
