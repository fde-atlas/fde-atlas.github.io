Claude API 免费课程怎么学：FDE 学习顺序

FDE Times · 2026-10-08 · 约 4 分钟读完

摘要

文章分析 Anthropic 免费课程“Building with the Claude API”对想转型 FDE 的开发者的价值。课程门槛低，只需基础 Python 和 JSON，其 MCP 与 Agent 模块与 Anthropic 2026 年 4 月的 FDE 招聘要求高度重合。作者建议先学提示词评测，再学工具调用、RAG 和 MCP，但指出课程无法教授驻场工作与部署模式提炼，需靠个人项目补足。

要点

  • 课程免费，只需基础 Python 和 JSON，含评测、工具调用、RAG、MCP、Agent 模块。
  • MCP 与 Agent 模块对应 Anthropic FDE 招聘要求交付的成果。
  • 建议学习顺序：先提示词评测，再工具调用，之后 RAG 与 MCP。
  • 课程不教客户现场工作与部署模式提炼，需用个人项目补足。
  • 简历应突出交付物、评测数字和可复用的部署模式。

MCP 与 Agent 模块紧贴 Anthropic 自家 FDE 招聘要求，最该先学的是提示词评估，而不是 RAG。

要点速览

  • 课程免费，只需要基础的 Python 和 JSON，设有评测、工具调用、RAG、MCP 和 Agent 的专门模块。
  • MCP 和 Agent 模块，正好对应 Anthropic FDE 招聘启事要求工程师向客户交付的成果。
  • 课程不教如何在客户现场工作，也不教如何提炼部署模式，这部分只能自己练。

Anthropic 应用 AI 团队于 2026 年 4 月 28 日发布的前线部署工程师（FDE）招聘启事，要求候选人向客户交付非常具体的东西：MCP 服务器、子 Agent、Agent 技能。而 Anthropic 自己的免费课程，恰好设有 MCP 和 Agent 工作流的专门模块。课程大纲和岗位描述有不少重合。

不过，同一份招聘启事还要求 FDE 把 25% 到 50% 的时间花在客户现场，与客户一起构建产品。这部分没有哪个视频能教会。

如果你是正在考虑转向 FDE 的开发者，这门课值得花时间。只是要清楚：它覆盖的是工作的哪一半，哪一半得靠自己学。

这门课适合谁？

“Building with the Claude API”由 Anthropic 制作，托管在 Skilljar 上，属于 Anthropic Academy 的一部分，免费报名。Anthropic Academy 自称是 Anthropic 教育团队发布免费课程和指南的地方。课程页面将其描述为一门视频课程，教开发者通过 Anthropic API 把 Claude 集成进应用。

入门门槛不高：会基础的 Python 和 JSON 即可，不需要 LLM 经验。值得注意的是，目标受众明确包括正在转向 AI 应用开发的软件工程师，这几乎就是想转型 FDE 的人的画像。

课程页面没有注明时长，进度可以自己定，比如每周学一个模块，再配一个小练习。

先学哪些模块？

先学提示词评测（Prompt evaluation）模块，排在 RAG 和 Agent 之前。它教你构建测试数据集，再同时用模型和代码给结果打分。到了客户现场，靠它才能用数字而不是感觉证明系统可用。

设想客户是一家保险公司，想用 Claude 从理赔档案中提取信息。你写 20 份样例档案，用代码检查输出是否为合法 JSON、必填字段是否齐全。

代码判断不了的，交给模型打分，比如摘要里有没有编造细节。如果 20 份中有 17 份两轮都通过，你就有了一个可以带进客户会议的数字，剩下的 3 份则告诉你下一步该修什么。

评测之后学工具调用（Tool use）。这个模块从 schema 讲到多工具的多轮对话，还加入了文本编辑工具和网页搜索工具。时间紧的话，这两个内置工具可以快速带过。

把时间花在编写 schema 和处理多工具多轮对话上，因为你为客户构建的每一个基于工具的系统，都离不开这两项能力。

接下来是 RAG 与智能体搜索（RAG and Agentic Search）：分块、嵌入、BM25 和多索引管道。几乎每个客户手里都有一堆内部文档，想直接对其提问。BM25 与嵌入结合，既能命中精确输入的产品编号，也能应对措辞五花八门的问题。

三个值得记住的思路

第一，评测需要两层打分。能机械衡量的交给代码，其余交给模型。少了任何一层，都是在自欺欺人。

第二，来自 Agent 与工作流（Agents and workflows）模块。该模块讲了并行化、链式调用和路由，还有一节专门比较工作流与 Agent。选择能解决问题的最简单结构。步骤固定的文档审核流程，用链式调用就够了。只有步骤无法预知时，才需要能自主决策的 Agent。

第三是 MCP。该模块涵盖客户端、服务器、工具、资源和提示词，而 MCP 服务器正是 Anthropic 招聘启事中写明 FDE 必须交付给客户的成果之一。所以，要把 MCP 当作打包交付物的方式来学，而不是一个学来只为说“我会”的协议。

课程没教的那一半

The Pragmatic Engineer 的 Gergely Orosz 将 FDE 定义为在客户团队和核心产品团队之间轮换工作的工程师。这一岗位起源于 2010 年代初的 Palantir。Google 的 FDE 招聘启事描述的是一个直接在客户团队内部构建、把前沿 AI 产品与生产环境的现实连接起来的人。

Anthropic 的招聘启事同样要求在客户系统内部工作，并识别、固化反复出现的部署模式。没有哪个模块教你如何在两天内读懂一个陌生代码库，也没有哪个模块教你如何把第三次部署变成产品团队可复用的模板。

这个缺口可以用个人项目补上。挑一个假设场景，比如某连锁零售企业的客服部门。构建一个封装其模拟 API 的 MCP 服务器，写一套评测，再写一页说明，描述下一次部署可以复用的模式。

简历上就写这些：交付物、评测数字和提炼出的模式。阅读岗位描述时，留意“customer systems”或“deployment patterns”这类说法，判断公司需要的是你的哪一半。

课程能帮你写出客户需要的代码。客户会不会再请你回去，取决于工作的另一半。
