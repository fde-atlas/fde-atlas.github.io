前沿部署软件工程师，公共部门 | Scale AI

原标题：Forward Deployed Software Engineer, Public Sector | Scale AI

Zero G Talent · 2026-03-11 · 约 4 分钟读完

摘要

Scale AI 在得州奥斯汀招聘公共部门前沿部署软件工程师。该岗位需嵌入美国陆军、空军、联合司令部及情报界等政府客户现场，端到端负责 AI 应用从原型到生产交付。要求五年以上软件工程经验，精通 Python 与 TypeScript，熟悉云平台与容器技术，并持有或可申请 TS/SCI 安全审查。岗位需约 25% 至最高 50% 差旅，或迁往华盛顿特区、圣路易斯。薪酬含基本工资、股权与福利，被拒者九十天内不可重新申请同一岗位。

要点

  • Scale AI 招聘面向政府客户的前沿部署软件工程师，常驻奥斯汀。
  • 工作内容为嵌入陆军、空军与情报机构，端到端交付 AI 应用。
  • 要求五年以上经验、Python 与 TypeScript 能力及 TS/SCI 安全审查。
  • 差旅约 25%，必要时可达 50%，或需迁往华盛顿特区或圣路易斯。
  • 薪酬包含基本工资、股权及健康、退休等福利。

职位要求

在 Scale，我们为美国一些最重要的决策构建背后的 AI 系统。在公共部门工程团队，你将直接嵌入美国政府客户，包括陆军、空军、联合司令部和情报界，构建并部署支持其最关键任务的 AI 应用。

这是一个混合型的面向客户的工程岗位。你将与你要解决的问题的当事人并肩工作，负责从首个原型到生产环境的完整交付，并交付客户在实际工作中采用和依赖的软件。模型性能至关重要，时间紧迫，模糊性是常态。你的工作将直接塑造 Scale 平台能为公共部门实现的能力。

你的职责

  • 嵌入政府客户，理解其任务使命，界定问题范围，并将其转化为可运行的软件。
  • 端到端负责交付：在客户现场设计、构建、部署和维护解决方案，从原型到稳定的生产环境。
  • 构建健壮的后端系统和数据集成，将客户环境与 Scale 平台双向连接。
  • 与产品和工程团队协作，将一线反馈纳入产品路线图，使你构建一次的模式成为整个团队可复用的能力。
  • 担任客户利益相关方的技术联系人，引导产品采用并最大化任务影响力。

我们期待的人才

必备条件

  • 5 年以上软件工程经验，最好有面向客户、前沿部署或政府领域的背景。
  • 精通 Python 和 TypeScript（或类似现代语言）的生产级编码。
  • 熟悉全栈技术，包括云平台（AWS、Azure 或 GCP）、容器、Linux 和网络基础。
  • 能够在模糊、快节奏的环境中独立工作，并在压力下做出合理的权衡决策。
  • 持有有效的 TS/SCI 安全许可，或具备获得该许可的资格。

加分项

  • 有构建或部署基于 LLM 或生成式模型的系统的经验。
  • 熟悉 Node 和 React、Kubernetes 和 Docker，以及 Terraform。
  • 具备数据工程背景，涵盖 ETL 管道、数据建模和数据治理。

工作地点与差旅

该职位需要大量时间在客户现场工作。预计差旅比例为 25%，必要时最高可达 50%，和/或需迁往华盛顿特区或圣路易斯。

Scale 针对符合条件的职位的薪酬方案包括基本工资、股权和福利。每个职位发布页面上显示的薪资范围反映了该职位新员工薪资的最低和最高目标，可能涵盖 Scale 的多个职级；具体薪资将在面试过程中根据工作地点及其他因素确定，包括与工作相关的技能、经验、资历、面试表现以及相关教育或培训背景。符合条件的 Scale 员工还将获得基于股权的薪酬，但需经董事会批准。招聘人员可以在招聘过程中与您分享您期望工作地点的具体薪资范围，并确认所聘职位是否有资格获得股权授予。您还将享受包括但不限于以下福利：全面的医疗、牙科和视力保险、退休福利、学习与发展补贴以及丰厚的带薪休假。此外，该职位还可能有资格享受通勤补贴等额外福利。

请注意：我们的政策要求在重新考虑同一职位的候选人之前有 90 天的等待期。这使我们能够确保对所有申请者进行公平而全面的评估。
