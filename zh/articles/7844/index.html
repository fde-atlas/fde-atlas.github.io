Linux 磁盘加密技术：FDE、FBE 与 eCryptfs 实现分析

原标题：Linux Disk Encryption Technology: FDE, FBE and eCryptfs Implementation Analysis

BestHub · 2023-06-09 · 约 2 分钟读完

摘要

本文是 Linux 内核安全系列第二篇，系统梳理磁盘加密技术。文章先介绍数据的三种状态（使用中、传输中、静态）及对应加密手段，再对比全盘加密（FDE，含硬件自加密盘与 dm-crypt/LUKS 等软件方案）与基于文件系统的加密（FBE，含 eCryptfs 与原生 fscrypt），最后深入剖析 eCryptfs 的架构、密钥管理与代码流程。

要点

  • 数据安全分三种状态：使用中、传输中、静态，分别对应内存加密、TLS/SSH、磁盘加密。
  • 全盘加密 FDE 包括硬件自加密盘和 dm-crypt/LUKS、BitLocker、FileVault 等软件方案。
  • FBE 分为堆叠式加密文件系统 eCryptfs 和支持 Ext4、F2FS、UBIFS 的原生 fscrypt。
  • eCryptfs 为每个文件生成独立 FEK，并用 FEKEK 加密，密钥由用户口令派生。
  • 文章引用 2005 与 2007 年两篇 eCryptfs 论文，兼顾理论与实现细节。

全文

本文回顾了 Linux 磁盘加密技术，阐述了静态数据安全的概念，对比了全盘加密（硬件和 dm-crypt/LUKS）与基于文件系统的加密（堆叠式 eCryptfs 和原生 fscrypt），并对 eCryptfs 的架构、密钥管理和实现细节进行了深入分析。

OPPO Kernel Craftsman

本文是 Linux 内核安全技术系列的第二篇，聚焦磁盘加密技术及主流实现方案。内容涵盖三大方面：

1. 技术背景 ：介绍不同状态下的数据安全——使用中的数据（如 Intel TME 和 AMD SME 等全内存加密）、传输中的数据（SSL/TLS、SSH）以及静态数据（磁盘加密）。文章讲解了多种加密分类维度，包括加密对象、用户感知和加密算法。

2. 磁盘加密方案 ：详细分析两种实现方式——全盘加密（FDE）和基于文件系统的加密（FBE）。FDE 包括硬件方案（自加密硬盘）和软件方案（dm-crypt/LUKS、BitLocker、FileVault）。FBE 分为堆叠式加密文件系统（eCryptfs、基于 FUSE 的方案）和原生文件系统加密（支持 Ext4、F2FS、UBIFS 的 fscrypt）。文章从灵活性、性能和实现等方面对 FDE 与 FBE 进行了全面对比。

3. eCryptfs 深度剖析 ：对 eCryptfs 进行了大量分析，包括演示透明加密的测试用例、文件加密特性、密钥管理机制（FEK——文件加密密钥，FEKEK——文件加密密钥的加密密钥）、架构设计以及代码流程分析。文章解释了 eCryptfs 如何实现每个文件使用唯一加密密钥，以及从用户口令派生密钥的过程。

文章引用了多篇学术论文，包括《eCryptfs: an enterprise-class cryptographic filesystem for Linux》（2005）和《eCryptfs: a Stacked Cryptographic Filesystem》（2007），为 Linux 磁盘加密技术提供了理论基础和实践实现细节。
