前沿部署策略师 | Cursor

原标题：Forward Deployed Strategist | Cursor

Zero G Talent · 2026-09-23 · 约 4 分钟读完

摘要

Cursor 招聘 Forward Deployed Strategist，负责最重要的客户合作：与高管对接、把模糊业务问题转化为有明确 ROI 的限时项目，并与 FDE 协作交付。该岗位要求 6 年以上解决方案架构或技术咨询经验，熟悉生产环境中的 agentic coding 与 LLM，能动手配置 Cursor 工作流与集成，并具备 C-suite 沟通能力。典型配置为一名策略师搭配 1-2 名 FDE：策略师负责高管关系、范围控制与配置层交付，FDE 负责深度生产构建。岗位还强调推动客户自主采用、沉淀可复用 playbook，并向产品团队反馈缺口。金融、保险、电信等行业经验为加分项。

要点

  • Cursor 招聘 Forward Deployed Strategist，主导战略客户合作全流程。
  • 典型配置：一名策略师搭配 1-2 名 FDE 协作交付。
  • 要求 6 年以上解决方案架构或技术咨询经验。
  • 需熟悉 agentic coding 与 LLM 的生产环境表现。
  • 职责包括高管关系、范围控制、配置层交付与沉淀 playbook。

SpaceX 的创立基于一个信念：人类探索星辰的未来，从根本上比止步不前的未来更令人振奋。如今，SpaceX 正在积极开发实现这一愿景所需的技术，最终目标是让生命成为多行星物种，并将意识拓展至星辰。SpaceXSI 正在构建超级智能，以帮助人类理解宇宙。我们的团队正在打造完整的超级智能技术栈：从 Colossus 超级计算机，到 Grok 模型，再到我们的应用套件，包括 Grok Bot、Grok Build、Grok Imagine、Grok Voice 和 X。我们正在打造一个强大的飞轮：更多的算力训练出更好的模型，更好的模型支撑更有用的产品，而我们从用户使用产品中获得的洞察，又将塑造我们下一步的构建方向。

关于该职位

我们正在寻找一位前沿部署策略师，负责我们最重要的战略客户合作——从首次研讨会到最终交付。你将与高管发起人密切合作，挖掘价值最高的用例，将其转化为范围明确的项目，并与 FDE 协同对最终成果负责。

你通常会在一个由一名策略师和 1-2 名 FDE 组成的小组中工作。你负责高管关系和交付的整体规划；FDE 则嵌入客户团队，负责更深层的生产构建。你将每周保持在配置层的实际操作中，包括工作流、集成和平台工具，并在构建最复杂的环节与 FDE 协作。你将把技术构建转化为业务成果，并负责推动构建方案的落地采用。

这一职位适合那些既具备 Agentic 编程和 LLM 方面的技术公信力，又拥有在董事会赢得信任的高管气场，同时具备精准判断力的人——能够确保项目范围紧凑、交付迅速，并值得客户再次合作。

工作职责

  • Scope
    • 与客户高管发起人合作，界定 FDE 项目范围——将模糊的业务问题转化为具体、限时且有明确 ROI 的可交付成果
    • 主导技术调研与架构评审，揭示集成复杂性和基础设施限制，以验证每个项目在技术上均切实可行
    Deliver
    • 与 FDE 并肩协作完成技术构建——你负责配置层，包括工作流、设置、集成以及无需大量定制代码的平台工具，而 FDE 负责更深层的生产级构建
    • 负责技术赋能与采纳：开展实操培训、构建操作手册和参考工作流，并辅导客户团队直至他们能够独立自主。采纳效果以你不在场时他们的用户实际操作情况来衡量
    • 在整个交付过程中监控技术可行性，当约束条件出现时与发起人一起调整范围，而不是任由项目漂移
    • 在交付过程中发现并界定扩展机会，与客户团队协作推进
    • 将产品缺口、集成摩擦和反复出现的客户痛点以足够的具体度反馈给产品与工程团队，以推动路线图决策
    • 构建可复用的操作手册，让整个 FDE 组织随时间推移不断提升能力
    Own the executive relationship
    • 在你的项目中建立并维护高管关系，从启动到交接担任主要联系人
    • 向需要同时相信成果和交付团队的高管层利益相关者推销愿景和计划
    • 在业务成果与技术实现之间进行双向翻译——既面向发起人，也面向构建团队

如果你符合以下条件，你可能是合适人选

  • 你在解决方案架构、部署策略、技术咨询或客户经理岗位拥有 6 年以上经验，曾在 AI 生产工作流中与技术团队共同负责范围界定和交付
  • 你对 Agentic 编程和 LLM 有足够深入的理解，能与资深工程师平等对话：它们在生产环境中的表现、失败之处，以及弹性工作流的样子（你不需要亲自编写生产代码）
  • 你能熟练上手 Cursor 工作流、集成和平台配置，并能读懂足够的 Python / JS-TS 代码以与 FDE 协作
  • 你已将 AI 原生工作流推进到原型阶段之后，并能区分真正的生产约束与锦上添花的功能
  • 你能走进一个陌生的企业工程组织，快速找到杠杆最高的切入点，并界定出能在数周而非数季度内交付具体价值的项目
  • 你具备掌控高管层关系的高管气场，也拥有赢得客户工程负责人信任的技术公信力
  • 在金融服务（FSI）、保险、电信、高科技、医疗健康/生命科学或半导体领域的深厚行业经验是重要加分项
