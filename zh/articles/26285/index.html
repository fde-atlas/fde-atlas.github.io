前沿部署工程师 | MSPilot | 远程，乌克兰

原标题：Forward Deployed Engineer | MSPilot | Remote, Ukraine

Zero G Talent · 2026-11-20 · 约 5 分钟读完

摘要

Y Combinator 支持的初创公司 MSPilot 正在招聘远程前沿部署工程师（可驻乌克兰），面向 IT 服务行业的 AI 基础设施平台。该职位要求直接通过 Slack 和 Teams 服务客户，端到端交付全栈功能，并构建和调优 AI Agent 与 MCP 连接器。要求三年以上全栈经验、生产环境运维能力、PostgreSQL、云基础设施及 LLM API 经验。招聘流程包含付费试用任务，两周内完成，先签三个月合同后转正式岗位并授予股权。

要点

  • MSPilot 为 IT 服务商提供 AI Agent 部署与治理平台，由 Y Combinator 支持。
  • 前沿部署工程师需直接对接客户，从需求到修复全程负责，无工单队列。
  • 技术要求：3 年以上全栈经验、Python 或 TypeScript、PostgreSQL、云平台、LLM API 与 MCP。
  • 招聘流程含 1 至 2 天付费试用任务，总时长不到两周。
  • 先签三个月全职合同，转正后股权归属期可追溯至入职日。

任职要求

  • 3 年以上全栈工程经验，具备生产环境运维经验
  • 熟练使用 Python 或 TypeScript 进行生产开发，掌握 Web 框架技能
  • 具备关系型数据库设计经验和 PostgreSQL 使用经验
  • 云基础设施经验：AWS、GCP 或 Azure
  • 有 LLM API 以及 AI Agent 或 MCP 集成经验

工作内容

  • 在 Slack 和 Teams 中担任技术联系人
  • 构建并交付全栈功能、集成和修复
  • 构建和调优 AI Agent 及 MCP 连接器
  • 根据客户报告调查并解决生产环境问题
  • 将客户反馈的模式转化为平台功能和文档

关于我们

我们是一家 Y Combinator 支持的初创公司，正在为 IT 服务行业构建 AI 基础设施层：IT 服务商使用我们的平台向其管理的受监管行业交付 AI，并在同一套体系上为客户构建和运行 AI Agent。

创始人此前打造过一个拥有 200 万以上用户的 AI 编程平台。你将在这一品类正面向中小企业成形的关键时刻，以前沿部署工程师的身份加入我们。

工作内容

你将是离客户最近的工程师。你直接与 IT 服务商及其管理的中小企业合作，在共享的 Slack 和 Microsoft Teams 频道中工作，从客户的第一条消息到修复上线生产环境，全程由你负责。你与客户之间没有工单队列，也没有其他团队替你交付工作。

1. 直接与客户合作

  • 在共享的 Slack 和 Teams 频道中担任技术联系人：回答问题、实时调试问题，并清晰地解释当前情况和后续安排
  • 将模糊的需求（“AI Agent 没有达到我们的预期”）转化为精确的问题描述、行动计划和已交付的改动
  • 主持通话并撰写更新说明，让非技术的企业主和资深 IT 管理员都能看懂

2. 端到端交付到生产环境

  • 构建客户所需的功能、集成和修复，覆盖整个技术栈：前端、后端、数据库和部署
  • 在平台的运行时和治理体系之上，为特定客户工作流构建和调优 AI Agent 及 MCP 连接器
  • 从客户报告入手，深入日志、链路追踪和代码调查生产环境问题，然后亲自修复根本原因
  • 对自己交付的内容负责：部署、监控，并与客户确认问题已解决

3. 将一线经验反哺产品

  • 发现客户之间的共性模式，将一次性的解决方案转化为平台功能、模板和文档
  • 直接与创始人和创始工程师合作，基于你每天从客户那里听到的反馈，决定下一步要构建什么

这是一个真正的工程岗位，带有面向客户的职责，而不是带点脚本工作的支持岗位。你每周都会编写生产代码，客户几天内就能看到成果。

我们在寻找什么样的人

你是谁

  • 3 年以上全栈工程经验，并且真正花时间运维过自己构建的系统
  • 出色的英语书面和口语能力。你每天都会通过 Slack、Teams 和电话与客户沟通，主要是美国本土的 IT 服务商。你表达清晰、简洁，能够向非技术人员解释技术问题而不失准确性
  • 天生以客户为导向：你关心的是客户的问题是否得到解决，而不是工单是否关闭。你会主动跟进，坦率地指出问题所在，并在客户感到沮丧时保持冷静
  • 你曾端到端地交付过一个副业项目。一个副业项目、独立产品或自由职业构建，由你亲自从想法推进到生产环境：架构、代码、部署和运维
  • 你曾服务过生产环境中的用户：真实依赖你构建的产品、报告 bug、提出功能需求，并直接从你这里得到答复的人
  • 是 agentic 编程工具（Claude Code、Codex、Cursor 或类似工具）的日常用户。你用它们进行开发，并理解它们在底层如何调用模型和工具
  • 能够独立负责问题。你会把一个客户请求从第一条消息推进到修复上线，而不需要等待别人来界定范围、分配任务或为你扫清障碍

技术要求

  • 扎实的全栈能力：有使用 Web 框架（Django、Next.js、React 或类似框架）进行前端和后端生产开发的实际经验
  • 精通 Python 或 TypeScript，并且能够阅读和修改自己日常不使用的语言编写的代码
  • 系统设计经验：你设计过在生产环境中运行的系统，能够评估不同设计之间的权衡（成本、复杂度、可靠性、上线速度），并向工程师和客户清晰地传达这些权衡
  • 扎实的关系型数据库经验（首选 PostgreSQL）：模式设计、编写和调试查询，以及对在线系统执行迁移
  • 真实的生产环境经验：部署、日志与监控、故障调试和回滚。你曾是那个被呼叫处理故障的人，而不仅仅是合并代码的人
  • 具备云基础设施（AWS、GCP 或 Azure）、容器的工作知识，并理解 HTTP 流量如何从客户端到达你的服务：DNS、TLS、代理和 API
  • 有使用 LLM API（Anthropic、OpenAI）以及构建 Agent 或工具集成的实际经验；有 MCP（Model Context Protocol）经验者优先

加分项

  • 曾有前沿部署、解决方案工程或面向客户的工程经验
  • 创业公司经验：你曾在早期公司工作过（或创办过公司），了解在小团队、真实资源受限条件下交付产品的感受
  • 微软生态经验：Microsoft 365、Entra ID（Azure AD）、Teams、Intune
  • 认证与身份相关经验：OAuth2 / OIDC / SAML
  • 有 IT 服务背景，或熟悉面向 IT 服务商的工具（RMM、PSA、设备管理）
  • 有与业务系统（CRM、工单、会计、文档存储）构建集成的经验

我们提供什么

  • 早期股权：有实际意义的所有权，而非象征性的授予
  • 有竞争力的薪资，首次通话时公开讨论
  • 与创始人及客户直接协作：没有层级、没有遗留代码、没有客户经理夹在中间
  • 一个具体且有收入支撑的问题：有付费客户和经过验证的需求，而不是研究项目
  • 快速反馈：你周二上线的东西，周三客户就在使用，周四就会向你反馈
  • 硬件/联合办公预算以及带薪休假

招聘流程

  • 初识通话（30 分钟）：双向匹配度、产品演示、薪资期望。以英语进行
  • 生产环境深入探讨（60 分钟）：由你选择，向我们介绍一个你构建并上线到生产环境的项目：架构、背后的决策、出了什么问题、你如何对待用户、你会如何重做
  • 带薪试用任务（约 1-2 天，有报酬）：一个真实的客户场景。你会收到一条以 Slack 原始形式到达的请求，需要澄清需求、构建变更、上线部署，并向客户回复更新
  • 录用：前 3 个月为带薪全职合同，之后转为带股权的正式职位。这是一个双向试用：你评估我们的同时，我们也在评估你。转正时，股权归属期将追溯至你的入职日期

整个流程时长：不到两周。
