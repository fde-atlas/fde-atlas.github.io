建立实验室：寻找变革者并立即为他们提供工具

原标题：Establish the Lab: Hunt Change-Makers and Give Them the Tools Now

Michael Couch | couch.cx · 2026-10-26 · 约 13 分钟读完

摘要

作者认为，从想法到落地的周期已从数季度压缩到数天，企业内最稀缺的是懂业务、有判断力的变革者，而非模型本身。多数组织仍通过中央队列配给工具与权限，导致这些人转入影子 IT。文章主张设立“实验室”：一个提供访问、工具链（harness）和快速审批的铸造厂式环境，主动“猎取”已在暗中自动化的员工，当月发放可用工具包，并以九十天为周期将成果分为毕业、入库或淘汰。实验室是 FDE 的平台后盾，衡量标准是可复用的生产路径，而非演示。

要点

  • 想法到落地周期已压缩至数天，稀缺的是懂业务的人才。
  • 变革者不会举手报名，需通过观察实际工作主动猎取。
  • 实验室三大职能：访问权限、工具链、可快速放行的见证人。
  • 工具应本月发放，而非等待 2027 年的赋能路线图。
  • 衡量标准：生产化路径、复用率、影子 IT 下降。

如果公司里没有变革者的立足之地，你就无法运营一支 FDE 团队。这个驻场机制需要一个家——不是 CoE，不是供应商作战室，也不是披萨加周五黑客马拉松。它需要一个实验室：一个让那些已经感受到工作痛点的人能够获得工具、许可和保障，在组织架构注意到之前就把东西交付出来的地方。

这不是创新表演。创新表演是一间玻璃房、一个冠名的项目，以及一场从不触及生产环境的季度展示。在这种新格局下，实验室是一套赋能系统。从想法到执行的周期从未如此之短。公司内部的人才从未如此宝贵。赢家将是那些主动寻找已经能看到下一个循环的人，并现在就给他们技术栈的公司——而不是等转型办公室完成运营模式之后。

SCQA（概览）

现状： 从想法到可运行产出的周期已从数个季度压缩到数天；知道该构建什么的人已经在你的工资单上。冲突： 大多数组织仍然通过中央队列来配给工具、数据和权限，于是变革者要么沉默，要么转入地下。问题： 如何建立一个真正赋能的实验室，而不是又一个椅子更漂亮的 CoE？答案： 寻找那些已经在主动拉取资源的实干者，给他们一条黄金路径和一个终止开关，衡量已交付的循环而非演示，并把实验室视为 FDE 背后的平台，而不是试点的博物馆。

差距已经消失。组织却没有。

在企业历史的大部分时间里，从“我知道我们该做什么”到“它周一就能跑起来”之间的距离，是一份资本申请、一个积压队列和一群技术神职人员。这个距离正是我在 The Individual Contributor Age 和 As Fast As You Can Think 中所写的。实施不再稀缺。稀缺的是清晰度、品味和对领域的忠实还原。

实验室之所以存在，是因为这种压缩如今已是结构性的。一个有清晰图景、一个 agentic IDE 和一条通往真实系统的安全路径的实干者，可以在一周内完成过去需要一整年“数字化”才能完成的循环。如果你不给他们一个地方去做，他们照样会做——在个人的 ChatGPT 上、在私搭的 n8n 上、在外包人员的笔记本电脑上。你将得到没有保障的速度。这正是下一次事故、下一个影子流程，以及下一张仍然说不出一个生产工作流名称的“AI 治理”董事会幻灯片的由来。

所以实验室不是可有可无的企业文化。它是对一种新物理规律的唯一成熟回应：不赋能自己员工的代价，如今已高于让他们交付的代价。

你的人才从未如此宝贵

模型是租来的。领域知识不是。那个知道异常为何存在、客户真正信任谁、CRM 里哪个字段是假的、以及周四下午“完成”意味着什么的人，才是稀缺资产。一年前，他们被工程产能所限制。今天，他们是乘数。给他们一个模型和一套工具链，他们就能跑赢整个项目。把他们留在排队队列里，你就等于为一种你拒绝使用的品味付了钱。

这正是高管们仍然搞反的部分。他们去挑选前沿模型和知名供应商，却低估了那些已经在工资单上、一直在等待许可的人。实验室的首要任务不是“探索 AI”，而是提升你已有人才的转化率——从操作者到交付闭环，从想法到成品，从异常到系统。

把他们当作可互换的“Copilot 用户”，你只会得到平庸的产出。去寻找那些变革者——那些已经建起支撑整个区域运转的电子表格的人，那些已经自动化了自己一周工作的人，那些曾经申请 API 权限却被拒绝的人——你将免费获得下一个运营模式。他们一直都在那里。只是工具终于跟上了他们的速度。

去寻找。不要等着市政厅里的志愿者自告奋勇。

变革者不会在全员大会上举手。他们很忙。他们对各种项目计划略有过敏。他们曾被那些只想收集用例申请表的创新实验室伤过。你要像寻找产品市场契合度那样去寻找他们：看谁已经在主动发力。

  • 谁已经在没有工单的情况下交付成果？ 那个拥有私人 Figma 转演示文稿流程的品牌负责人。那个周日汇报包是一个脚本的分析师。那个把 Slack 接到 CRM 上却从未告知 IT 的客户成功经理。
  • 谁在以有用的方式表达愤怒？ 不是愤世嫉俗者。而是那个能说出哪个环节坏了、哪个字段是假的、哪个审批还困在邮件里的操作者。带着规格说明的愤怒是一份礼物。
  • 其他 IC 已经在向谁请教？ 非正式的技术型操作者。如果三个团队的问题都经由同一个人处理，那个人本身就已经是一个实验室了——只是非官方的，没有评测，也没有备份。
  • 谁在晋升之后仍然贴近一线工作？ 那些仍然会打开记录系统的管理者。他们可以赞助一个驻场计划，而不必成为某个幻灯片的负责人。

你无法通过一份题为“AI 倡导者”的调查问卷找到他们。你要通过走现场、阅读那些影子工具、询问 FDE 三人组他们离不开谁来找到他们。然后，给这些人更大的发挥空间，而不是一个委员会席位。

实验室到底是什么（在这个十年里）

实验室是一个为将成果交付到业务中的人准备的特权环境。它更像一个铸造厂，而不是一个研究小组。它有三项工作，而且只有三项：

  • 访问权限：身份认证、模型路由、被允许使用的数据产品、看起来像生产环境的沙箱、以及不再是 Slack 粘贴的密钥管理。如果变革者仍然要等六周才能拿到一个账号，那你就没有实验室。你只有一本宣传册。
  • Harness，与 harness over horse 相同的直觉。界面、记忆、权限、日志、评测、紧急开关。实验室不会发放一个聊天机器人，而是提供一条可以变成运行中工作流的路径。
  • Witness，一个能在周二说“可以”的人。如果实验室里没有一个具名的负责人能在几小时（而不是几个季度）内打通数据、法务和安全问题，那它就只是一个候诊室。授权是一个延迟数字。

它不是掌控公司 AI 叙事的地方，不是供应商关系办公室，也不是失败的 CoE 项目改名换姓的收容所。如果实验室的主要产出是一个展示项目，那就关掉它，把预算给两个驻留项目。

与 FDE 的关系是明确的。实验室是保持平台属性的中心，FDE 是扎根于业务领域的边缘。业务中的变革者走进实验室，带着一条黄金路径离开，然后要么自己交付，要么拉一个 FDE 三人组来完成最后一公里。如果实验室试图为二十个业务部门做最后一公里，它就会变成我之前警告过的那种巡演乐队。

现在就给他们工具：而不是通往工具的路线图

一个组织不相信这种压缩的迹象是：当一线操作者已经在把客户数据粘贴进消费级聊天工具时，它却发布了一份 2027 年赋能计划。没有获准技术栈的速度不是一场道德剧，而是一个预测。他们会使用任何能闭环的东西。

“现在”意味着一个本月就能交到某人手里的入门套件：

  • 托管机器上的一个 Agentic IDE，Cursor、Claude Code，或任何你真正能支持的工具，使用公司的模型路由，而不是个人 API 密钥。
  • 一个他们可以扩展的技能库，可通过文件系统寻址、有版本管理、朴实无华。与 the skill library 和 skills over agent armies 的论点相同。一个品牌检查。一次 CRM 查询。一个评测 harness。不要等平台完善。
  • 一个被允许使用的数据产品，一片有已知分类的现实切片，而不是“等数据湖治理好了再来”。从操作者已经身处其中的数据集开始。
  • 一条丑陋但真实的上生产路径，身份认证、日志、人工覆盖。在实验室做原型，然后毕业进入 FDE 驻留项目或操作者自己的记录系统。
  • 一笔 token 和时间的预算，如果他们不得不偷用 GPU 时数和熬夜，你就等于告诉他们这只是个爱好。如此宝贵的人才不会留在爱好里。

偏好可以等待，不可妥协的事项不能：不得在离开租户的提示词中包含机密，不得进行无日志的生产写入，不得使用无法在审计中指名道姓的模型。把这些放进路径里。其余一切都由变革者决定。这与 FDE 所承载而非等待的治理是同一种划分。

授权是许可加上一条底线，而不是一场演讲

人们不会因为一张关于实验精神的价值观海报而被赋能。只有当尝试的预期成本低于询问的成本时，他们才被赋能。实验室就是设定这条底线的地方。

许可：你可以在这个范围内修改一个已命名的工作流。你可以交付一项技能。只要终止开关有效，你可以公开地让一个循环失败。你不会因为一个未能毕业的原型而受罚，只会因为一个假装自己是生产环境的原型而受罚。

底线：你不会被丢下独自面对一个模型和一句祈祷。这里有黄金路径、有做过这件事的人、有针对明显失败的评测，还有当最后一公里是集成问题时你可以求助的 FDE。没有底线的授权就是初级员工受伤的方式，也是法务在第四个月关掉实验室的方式。

企业无力循环是领导层消费他们不再亲手接触的工作的摘要。实验室是相反的几何结构：想要变革的高管应该像过去巡视一线那样巡视实验室。如果他们只看到演示文稿，他们资助的就是一场戏剧。

把它设计成铸造厂，而不是园区

物理空间是可选的。一些最好的实验室只是一个频道、一个代码仓库，以及业务部门里的一个周二工位。不可选的是密度。变革者需要看到彼此的循环。孤立产生十二片雪花。密度产生一座图书馆。

人员配置刻意保持精简。一个可行的种子配置：

  • 一名实验室负责人，以毕业的循环数量来衡量，而不是以人数或供应商覆盖范围来衡量。他们是一个有品位的平台型人才，而不是项目经理。
  • 一名工具链/平台工程师，负责身份、路由、评测、日志。就是让 FDE 驻场交付变得平淡无奇的那个人（或小组）。
  • 轮换的运营者，四到八名变革者，有明确时间限制的轮岗期，并在他们的实际工作中有一个指定的成果。他们不是“去实验室”。他们是把工作带进来。
  • 一名短绳牵引的法务/安全伙伴，响应延迟以小时计，而不是一个常设委员会。如果他们只参加指导会议，你已经输了。

除非你真的在做研究，否则不要配置研究团队。大多数企业并不是。他们是在尝试把已知模式安装进顽固的工作流。那是铸造厂的工作。据此招聘。微团队是基本单元：小规模、有装备、循环建立即完成。

职业路径在这里也很重要。实验室不能成为产品组织不想要的人的停车场。它也不能成为最优秀运营者的死胡同。序列是：驻场运营者 → 回到业务部门的技术运营者 → FDE 或平台。你培养的是组织真正需要的独立贡献者，就像一条精心设计的 FDE 职业路径一样。

什么毕业。什么消亡。

如果一切都永远留在实验室里，实验室就是临终关怀医院。每个循环都会在某个日期前获得三个标签之一，并以书面形式记录：

  • 毕业，在运营者的工作流中运行，指定了负责人，评测已开启，FDE 或平台团队维护着工具链。这是胜利。庆祝通往生产的路径，而不是演示日。
  • 入库，没有成为工作流，但留下了一项技能、一个连接器、一个评测、一个数据集定义。复用才是重点。杀掉界面；保留骨架。
  • 日落：问题不对、归属不对，或不安全。就在大家看得见的地方删掉它。一个不敢砍项目的实验室只是一个能力中心（CoE）。

像驻留计划一样设定时限：九十天足以看清一切。按比例雇佣的数字员工测试依然适用：当最初的人休假时，你安装的能力是否仍在运转？

如何判断实验室是真的

别再数“实验”了。把赋能当作一个操作系统来衡量：

  • 从想法到第一条生产形态路径的时间，不是幻灯片，不是聊天机器人玩具，而是操作员在真实案例中使用它。
  • 变革者转化率：在你发掘的人当中，有多少人交付了别人也能运行的闭环？如果实验室只产出实验室负责人的工作，那你雇的是一个英雄，而不是一座铸造厂。
  • 拉动，而非推动：业务部门主动找上门，操作员主动申请名额。如果六个月后你还在四处发掘，要么工具不对，要么授权是假的。
  • 复用：后续闭环从库中起步。零复用意味着手工作坊式的表演。
  • 影子 IT 下降：随着合规路径变快，消费级工具和私自自动化应当减少。如果实验室“很忙”而影子 IT 却在上升，说明实验室比一线还慢。这是产品层面的失败。
  • FDE 杠杆：驻留计划从实验室技能起步，而不是从零开始。实验室与 FDE 是同一个系统，请按此打分。

Token 花费是成本，不是 KPI。利用率是扼杀铸造厂的方式。实验室里没有毕业的工时就是库存。库存应当让人难受。

失败模式（你多半也已经有了）

创新表演。 玻璃墙、冠名的实验室、等候名单，却没有通往生产的路径。变革者来一次，发现真正的工作仍需提工单，就再也不来了。

实验室变成 CoE。 实验室掌控叙事、供应商和汇报材料。业务部门只是列席。没有任何业务能长期保有的成果落地。你重建了单体式产品组织，却称之为好奇心。

工具永远是将来时。 访问权限还在路线图上。与此同时，有才华的人都在用个人账号。你教会了他们：公司才是瓶颈。

开门，却不发掘。 “任何人都可以加入。”来的人是有空闲时间的人，而不是有洞察的人。平庸的输入，平庸的闭环。

研究扮演。 论文、评测排行榜、模型对比测试，工作流程却毫无改变。用逛前沿技术代替站在工作现场。

没有熔断开关，然后一禁了之。 有人上线了不安全的东西。法务恐慌，实验室被冻结，变革者重回地下。你本有机会把治理放进路径中，却选择了贴一张海报。

如果你认出了不止一条，不要增加人手。把使命收窄到访问、工具链、见证。发掘四名操作员，毕业两个闭环，然后再谈规模化。

如何在本季度把它建起来

你不需要一个为期两年的目标运营模型。你需要一个按日历运转的铸造厂：

第一周。 任命实验室负责人。指定响应速度以小时计的安全合作方。把不可妥协的事项写在一页纸上。选定第一个获准的数据产品。搭建好模型路由。

第二至三周。 猎寻。坐到两个已经感到痛楚的业务单元中去。通过观察实际工作（而不是发邮件发表格）找出四个变革推动者。用他们的语言向他们提供工具和九十天内可交付的成果：那个包、那个异常、那个活动锁定、那个入职路径。

第三十天。 第一条接近生产形态的路径，哪怕很丑陋。日志已开启。紧急开关已测试。操作员已在使用。如果你做不到这一点，说明你的访问权限故事是谎言，先解决这个问题再去招人。

第九十天。 两个循环，标注为毕业 / 入库 / 淘汰。留下可供后续 FDE 驻场计划接手的技能。一份书面清单，写明平台接下来必须把哪些事情变得平淡无奇。只有到那时才增加人手。

供应商会向你兜售“盒装实验室”。有时候，这个盒子确实能让你更快搞定身份认证和模型。但它无法替代猎寻真人。如果唯一能看到实际工作的人都在公司之外，那你只是租了一个灯光更好的演示。

实验室、FDE、操作员：一个系统

不要把它们当作相互竞争的项目来运营。操作员掌握全局图景。实验室让尝试变得廉价且安全。当尝试还不够时，FDE 负责安装最后一公里。平台在两者背后支撑。这就是这个铁三角的企业版本，拉远了镜头来看。

把实验室当作校园、把 FDE 当作特警队的公司，会得到两场表演。而把两者都视为将不可替代的人才转化为运行中系统之方法的公司，从外面看就像“快速采用了 AI”。其实不然。他们只是停止了对自己的员工实行配给。

从想法到执行的鸿沟已经崩塌。你的变革推动者早已知道该如何利用这一点。建立实验室，让他们能在光天化日之下行动：本月就到位的工具、有底线的授权、一套可以毕业的脚手架、一场对那些早已在主动发力之人的猎寻。人才从未像现在这样宝贵。表现得好像你还有时间等待运营模型，就等于把他们拱手送给街头，或送给一个在第一天就递给他们 Cursor 的竞争对手。
