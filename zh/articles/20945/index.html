您将能够做到什么

在 3 天强化课程结束时，您将掌握前沿部署工程师的技术核心——而不仅仅是理论。

构建生产级 AI Agent

使用 Google ADK 架构 Agent——Agent、Tool、Runner、Session——并通过 LiteLLM 在 Gemini、OpenAI 和 Claude 之间切换，无需重写逻辑。

设计真正有效的检索系统

摄取真实文档，选择分块和嵌入策略，并量化检索质量，而不是凭猜测。

编排多 Agent 系统

使用 Sequential、Parallel 和 Loop 模式协调专业 Agent，并了解何时使用确定性工作流，何时使用 LLM 驱动的路由。

将 Agent 连接到企业系统

使用 MCP 将 Agent 接入数据库、REST API 和内部工具——安全地，通过工具过滤和 OAuth。

像工程师一样评测 Agent，而不是做演示

构建黄金数据集，运行 LLM-as-judge 评测，在客户发现问题之前捕获回归。

带着防护栏和可观测性上线

在任何内容进入生产环境之前，添加提示注入防御、PII 脱敏、成本跟踪和 Langfuse 追踪。

部署真实系统并进行版本管理

将 Agent 容器化并部署到 Cloud Run 和 Vertex AI Agent Engine，配备回滚和监控。

像 FDE 一样为您的架构辩护

向同学和讲师展示完整的多 Agent 毕业项目——接受与面向客户的部署同样的严格审视。

你将使用的技术栈

模型无关、生产级工具

Google ADK 是核心框架。其余工具与前沿部署工程师在实际工作中使用的完全相同。

Google ADK

Agent 框架

Agent、Tool、Runner 和 Session 等基础组件——本课程每个实验所基于的架构。

Gemini

通过 API 调用的模型

Google 的模型，在 ADK 中原生使用，并与 OpenAI 和 Claude 在成本与能力上进行对比评测。

OpenAI

通过 API 调用的模型

通过 LiteLLM 接入，现场对比各提供商的推理能力、延迟和成本。

Claude

通过 API 调用的模型

Anthropic 的模型，适用于推理密集型 Agent，同时也是许多 FDE 用来构建和调试自己代码的助手。

LiteLLM

模型路由

一个统一接口对接所有提供商——无需重写 Agent 逻辑即可切换 Gemini、OpenAI、Claude 或开源权重模型。

MCP

Model Context Protocol

连接 Agent 与数据库、API 和企业工具的开放标准，并具备完善的访问控制。

Langfuse

可观测性与追踪

追踪每一次 Agent 调用，监控每个请求的 token 成本，并在上线前发现质量回退。

Cloud Run 与 Vertex AI

部署

一条命令将你的毕业项目 Agent 部署到生产环境，随后进行版本管理、回滚和监控。

前沿部署工程师课程

一个结构化、实操为主的 3 天课程（可申报 HRDC 培训基金），帮助你构建前沿部署工程师的技术核心。

第 1 天：Agent 基础、工具与检索（RAG）

AI 工程范式转变、Google ADK 架构，以及构建你的第一个生产级 Agent。

核心理论

  • AI 工程范式： AI 工程与传统软件——范式转变、观察-推理-行动循环，以及 Agent 在何处为企业创造价值。
  • Google ADK 与模型无关设计： ADK 架构：Agent、Tool、Runner、Session。通过 LiteLLM 切换 Gemini、OpenAI、Claude 或开源权重模型。现场演示。
  • RAG 架构： 嵌入、分块策略、向量存储（Vertex AI、Chroma、pgvector）。混合搜索、重排序、检索评测。
  • 提示词工程与模型选择： 系统提示词、工具描述、输出格式约束。各 LLM 提供商在成本、延迟和能力上的权衡。

课堂实操示例

实验 1：Hello World Agent

构建一个最小化 Agent，并通过 LiteLLM 在 Gemini、OpenAI 和 Claude 之间切换，直观体验模型无关设计。

实验 2：多工具 Agent

天气、预算和网络搜索工具，并使用 before_model_callback 安全护栏拦截对抗性输入。

实验 3：RAG 增强型 Agent

导入文档语料库、构建嵌入、将检索工具接入 ADK Agent，并测量检索质量。

课前热身 Colab

融合实验 1、2 和 4 的入门笔记本——参与者需在第一天之前完成，以便做好构建准备。

第二天：多 Agent 系统、企业集成与模型定制

编排多 Agent 团队、通过 MCP 连接企业系统，以及理解微调。

核心理论

  • 多 Agent 编排： SequentialAgent、ParallelAgent、LoopAgent。层级结构、任务委派、状态共享以及 Agent 之间的上下文传递。
  • MCP 与企业集成： 模型上下文协议（Model Context Protocol）：将 Agent 连接到数据库、通过 OpenAPI 连接 REST API，以及通过 OAuth + 工具过滤连接企业工具。
  • 模型定制：微调、LoRA 与 MoE： 定制阶梯：提示工程、RAG、LoRA/QLoRA、全量微调。MoE 模型以及何时不该微调的决策树。
  • Agent 即工具与动态路由： 将专家 Agent 转换为可调用的 AgentTool。LLM 驱动的路由与确定性工作流的对比——何时使用哪种方式。

课堂实操示例

实验 4：多 Agent 编排

电影提案团队：研究员、编剧、评论家。先构建 Sequential 流程，然后添加 Parallel 评论家和 LoopAgent 修订循环。

实验 4a：SequentialAgent 流水线

将研究员、编剧和文件写入 Agent 串联成电影提案流水线，使用 adk web 运行。

实验 4b：基于图的工作流（ADK 2.0）

节点与边构成的工作流：LLM 分类器对工单进行路由，包含并行汇合、人在回路和动态节点。

实验 5：动态 Agent 路由

将专家 Agent 转换为 AgentTool。根 Agent 动态路由查询。对比工作流路由与 LLM 驱动的路由。

实验 6：MCP 与企业集成

连接 MCP 服务器，实现工具过滤以确保安全访问，使用真实数据查询外部数据库。

实验 6a：MCP 与 ADK Mermaid 图表

通过 HTTPS 连接远程 MCP 服务器，在 Authorization 头中传递令牌，并渲染和保存图表。

微调概念课

30 分钟纯概念课程：LoRA、QLoRA、MoE 架构，以及何时不该微调的决策框架。无需 GPU。

第三天：生产化——评测、可观测性、安全与部署

通过评测、追踪、防护栏和 Cloud Run 部署，让 Agent 达到生产就绪状态。

核心理论

  • Agent 评测与测试： ADK 评测框架、LLM 作为评判者的模式、黄金数据集、轨迹与响应质量的对比，以及回归测试。
  • 可观测性、追踪与成本管理： OpenTelemetry 和 Cloud Trace。集成 Langfuse 进行追踪。按请求跟踪令牌用量和成本。延迟预算与质量告警。
  • 安全、防护栏与负责任的 AI： 提示注入防御、PII 检测/脱敏、工具调用授权、审计日志，以及 GDPR/EU AI Act 合规。
  • 生产部署： 将 ADK Agent 容器化。一键部署到 Cloud Run 和 Vertex AI Agent Engine。涵盖版本管理、回滚和监控。

课堂实操示例

实验 7：评测、可观测性与防护栏

LLM-as-judge 评测套件、Langfuse 追踪、Token 成本仪表盘，以及提示词注入和 PII 防护栏回调。

实验 7a：使用 LangSmith 进行 Agent 评估

在另一套技术栈上评估实验 7 的 Agent：LangSmith 追踪、数据集、启发式和 LLM-as-judge 评估器。

实验 8：毕业项目构建与部署

完整的多 Agent 系统，包含工具、RAG、MCP、评估、防护栏和追踪——部署到 Cloud Run。

毕业项目展示

各团队演示其系统。同伴评审与评分：最佳架构奖、最佳评估奖、最具生产就绪奖。

认证与资源

结业证书、精选资源指南、社区链接、用于微调的自学 Colab，以及问答环节。
