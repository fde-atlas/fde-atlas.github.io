Palo Alto, CA 前沿部署工程师职位 — Globality

原标题：Forward Deployed Engineer Job in Palo Alto, CA — Globality

Talentify · 2026-11-07 · 约 5 分钟读完

摘要

Globality 在加州 Palo Alto 招聘前沿部署工程师，年薪 10 万至 20 万美元。该公司打造自主采购平台 Glo，用 AI Agent 处理企业从需求到授标的采购流程。此岗位隶属产品组织，需驻场部署系统、编写生产代码并反馈产品改进。要求 3 年以上软件或解决方案工程师经验，熟悉 LLM 应用与 Python 或 TypeScript。每周 4 天到岗办公。

要点

  • Globality 招聘前沿部署工程师，年薪 10 万至 20 万美元。
  • 岗位负责在其采购平台 Glo 的企业客户现场部署与集成。
  • 需将客户需求转化为核心产品代码与平台改进。
  • 要求 3 年以上经验，熟悉 LLM、Agent 与企业系统集成。
  • 工作地点 Palo Alto，每周 4 天到岗办公。

全文

Globality 是一个自主寻源平台，用于管理从需求受理到授标的完整流程。

在 Globality，我们构建智能体技术，变革全球企业采购商品和服务的方式——自主化、规模化，并消除数十年来定义采购行业的低效问题。我们的平台能够解读采购意图、生成寻源材料、评估供应商，并在无需人工干预的情况下执行谈判策略。

职位介绍

作为 Globality 的前沿部署工程师，你将帮助企业的采购团队充分发挥 Glo 的价值，方法是在他们自己的系统内运行 Glo，并使其与他们的寻源政策保持一致。你将深入客户的采购、IT 和安全团队，配置 Glo，将其连接到客户的记录系统，并构建每次部署所需的内容——包括在配置和扩展无法满足需求时对 Glo 核心产品进行修改。你将隶属于产品组织，与产品团队和工程团队并肩工作，把你在一线学到的经验转化为平台改进。你的工作将决定客户能多快实现更短的周期和更低的成本。

你的职责

  • 构建自定义连接器、数据管道和原型，扩展平台以满足客户的特定需求。
  • 当客户需求无法通过配置或扩展满足时，修改和扩展 Glo 核心产品，并通过 Globality 标准的代码审查和发布流程交付生产代码。
  • 为企业客户主导 Glo 的技术部署，从项目启动到上线及推广采用。
  • 使用 API、Webhook 和 SSO，将 Glo 与客户的记录系统集成，包括 ERP、采购、合同管理和身份认证平台。
  • 配置需求受理流程、寻源工作流、审批规则和采购治理，以匹配每个客户的政策和支出类别。
  • 为每个客户调优自主模式和协作模式的行为，包括 Agent 防护机制、谈判参数，以及涵盖价格、质量、交付、服务和风险的评估标准。
  • 与客户的采购负责人、IT 和信息安全团队合作，确定需求范围、解决技术障碍并完成安全审查。
  • 监控生产环境中已部署的 Agent，诊断问题，并衡量周期时间、节省成本和受管支出等成果。
  • 捕捉一线洞察和可复用的模式，与产品团队和工程团队一起将其作为产品能力回馈到平台中。
  • 按照 Globality 的 SOC 2 Type 2 和 ISO 27001:2022 控制要求，记录可复用的部署模式。

你的背景

  • 3 年以上软件工程师、前沿部署工程师或解决方案工程师的经验，有交付生产代码的业绩记录，并具备直接面向客户的经验
  • 有在 AI 原生公司或 AI 原生平台上构建产品的经验，在生产环境中接触过基于 LLM 的应用、AI Agent 或工作流自动化
  • 具备设计、评估和监控 LLM 驱动系统的工作知识，包括提示词设计、工具使用、检索、防护栏和输出评估
  • 精通 Python 或 TypeScript，熟悉 REST API、webhook、JSON 和 SQL。有参与共享生产代码库的经验，包括代码评审、测试和 CI/CD
  • 有集成企业系统（如 ERP、CRM、采购或身份平台）的经验，熟悉 SSO、OAuth 和基于角色的访问控制
  • 有云基础设施（AWS、Azure 或 GCP）经验，理解企业安全与数据隐私方面的要求，包括 GDPR 和 CCPA
  • 具备清晰的书面和口头沟通能力，能够向采购高管和工程同事 alike 解释技术决策
  • 在模糊的客户场景中具备良好的判断力，强烈倾向于主动担当和结果导向，并能同时管理多个部署项目
  • 愿意根据需要前往客户现场

加分项

  • 有采购、寻源、供应链或金融科技背景
  • 有使用企业采购平台（如 SAP Ariba、Coupa 或 Jaggaer）的经验
  • 有使用 Agent 框架、评估工具或多 Agent 编排的经验
  • 有构建供其他工程师使用的开发者工具、SDK 或 API 的经验
  • 曾负责过面向客户的产品功能，从设计到上线的完整过程

为什么选择 Globality

机会巨大。 企业采购是最后一个尚未被 AI 变革的主要业务职能之一。我们不是在边缘优化——我们是在从根本上重新思考数万亿美元是如何被花费的。

团队世界一流。 我们的领导团队拥有来自全球领先企业数十年的经验，我们的文化是为那些追求真正担当而非头衔的人而打造的。

你将产生真正的影响。 这不是一个执行他人剧本的岗位。你将塑造战略、构建项目，并亲眼见证你的工作带来的直接业务影响。

我们协同工作——字面意义上的。 我们每周在帕洛阿尔托办公室工作 4 天，因为最好的想法——和最快的决策——都发生在面对面的交流中。其中一天你可以自由选择在最高效的地方工作。

该职位的预期年度基本工资范围为 100,000 - 200,000 美元。实际薪酬可能因经验、技能和地点等因素而有所不同。此信息依据《加州同工同酬法》提供。我们是机会均等的雇主，并参与 E-Verify（电子验证）计划。我们致力于建设多元化和包容性的工作场所，不因种族、肤色、性别、性取向、性别认同、宗教、国籍、年龄、残疾或任何其他受保护身份而歧视任何人。
