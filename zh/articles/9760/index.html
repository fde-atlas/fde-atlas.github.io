FDE 候选人筛选：分级部署案例

原标题：FDE candidate screening: graded deployment cases

摘要

A10X 推出面向 FDE 招聘的部署案例筛选服务：候选人完成 45–90 分钟限时真实客户场景，按七维度评分表打分并输出排名与逐人报告。文章引用 Indeed 数据称 FDE 职位一年增长 730%，认为 LeetCode 无法考察真实部署判断力。服务提供六个场景（医疗、财务、企业 IT、工程组织、公共部门、CRM 救援），含隐藏陷阱。首批五名候选人免费，之后每份 49 美元，48 小时内出报告。

《纽约时报》于 2026-08-30 报道了前沿部署工程师这一职位，援引 Indeed 的数据显示，相关职位发布量一年内增长了 730%。如今每个职位都会引来大量申请，而简历无法向你展示这份工作的核心：在客户真实约束条件下的判断力。

LeetCode 也测不出这种能力。部署案例可以。我们运行限时、贴近真实的客户场景，并按照该职位真正需要的评分标准对每个回答进行评分，这样你的团队只需面试前五名，而不用电话筛选五十人。

工作原理

  • 你向每位申请者发送一个私密案例链接：一个 45 到 90 分钟的限时部署场景，根据你的职位量身挑选。
  • 他们的书面回答将按照七维 FDE 评分标准进行评分，并明确指出他们发现或遗漏的每一个隐藏陷阱。
  • 你会得到一份排名表，以及一份可直接带入复盘会议的单人评分报告。

案例介绍

六个场景，每个都像真实的首次客户拜访一样构建，每个都带有能区分实践者与只读过 AI Agent 资料的隐藏陷阱：

  • 医疗行业的企业支持 Agent。 为一家拥有 14 家医院的医疗系统打造的 L1 Agent，绝不能编造临床建议。测试安全约束下的范围裁剪。
  • 应付账款发票自动化，财务运营。 一个处于付款流程中的 Agent，一旦付款出错便无法挽回。测试控制措施、评测和人机协同设计。
  • 全公司 AI 助手，企业 IT。 一个跨权限内部系统的工作助手。测试访问边界与事实依据纪律。
  • 编码 Agent 推广，工程组织。 将 Agent 推广到拥有 400 名工程师的组织。测试评测设计、灰度发布策略以及开发者工具的政治博弈。
  • 多机构数据智能，公共部门。 跨不共享数据模式或互不信任的机构的案件情报。测试最艰难情况下的需求发现与约束映射。
  • 失败的服务 Agent 拯救，CRM 平台。 一个合作伙伴构建的支持 Agent 在满意度上输给人工客服，没有任何测试，团队已准备放弃。测试截止期限压力下的诊断、评测设计与范围裁剪。

评分标准

每个回答在每个维度上按 1 到 5 分评分，每个分数附一行理由说明：

  • 需求发现与约束映射
  • 意图理解与范围裁剪
  • Agent 架构
  • 评测方案
  • 推广与干系人设计
  • 提问环节：他们在构建之前向你提出哪些要求
  • 产品反馈闭环：他们向你的产品反馈什么，而不是绕过问题硬编码

报告示例

医疗案例的示例报告。这位候选人在纸面上看起来不错；评分标准准确显示了他们在生产环境中会在哪些方面给你带来麻烦：

得分：3/5

发现与约束梳理：4/5。 在提出任何方案之前，先梳理了 PHI 暴露风险、Epic 只读限制以及临床拒答要求。遗漏了多家医院政策差异的问题：答案假设只有一个政策来源，而实际上十四家医院各有各的政策。

意图与范围裁剪：2/5。 正确地将临床建议从 v1 中剔除，并选择了密码重置和改期两类场景。但在容量测算时，直接把原始意图占比相加，声称 40% 的分流目标可以达成。在只读集成的情况下，写侧的改期仍需人工升级处理；诚实的可容纳数字大约只有声称的一半。这就是一个能挺过董事会评审的试点和一个挺不过去的试点之间的区别。

Agent 架构：4/5。 基于 Epic 和 Zendesk 的工具调用、带引用的政策检索、硬性升级规则。正确地将语音排除在试点之外。

评测计划：3/5。 提出了黄金数据集，并将幻觉临床建议列为 P0 失败类别。但没有注意到目前尚无意图分类体系，因此黄金数据集无从构建；该计划比现实允许的起点晚了一步。

上线与利益相关方设计：3/5。 金丝雀发布前先影子模式、有终止开关、指标设置合理。把市场团队已经公布的上线日期当作必须达成的截止期限，而不是需要摆上台面的冲突，并且从未询问决定节省成本是否真实的 BPO 合同条款。

需求提出：3/5。 索取了工单导出数据和 Epic 沙箱。但没有询问政策内容的负责人是谁，而这正是决定知识落地是否可行的关键问题。

产品反馈闭环：2/5。 提出了按医院定制拒答措辞和升级规则，但从未区分哪些属于产品本身、哪些只是 Meridian 的粘合代码。下一个医疗系统什么都继承不到，试点的失败也没有任何路径反馈回产品团队。

最大短板： 约束条件下的数字诚实。候选人把意图占比之和当作分流预测来呈现。在你的客户面前，这会变成一个你的部署无法兑现的承诺。

定价

试点：前五位候选人免费。 之后每位评分候选人 $49。批量及定制案例请洽谈。无需采用任何平台、无席位费、无合同；你提交候选人，你获得报告。
