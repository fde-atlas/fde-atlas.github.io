前沿部署团队的面孔：Shengyao Qian

原标题：The Faces of the Forward Deployed Team: Shengyao Qian

Cresta · 2026-11-18 · 约 6 分钟读完

摘要

Cresta 的访谈系列介绍了前沿部署工程师 Shengyao Qian。她曾在 Google Cloud 做时序数据库、在 Waymo 做车队管理软件，并联合创立过物流自动化公司 Joint AI。创业失败后，她希望直接面对付费客户，因此选择 FDE 岗位。在 Cresta，她主导了首个自助服务客户 Mercury Insurance 的落地，并为 Xanterra 构建 RAG 能力，其 AI Agent 在冰川和黄石国家公园的对话承接率分别达 84% 和 76%。她还参与合作伙伴渠道的培训与平台改进。

要点

  • Shengyao Qian 曾在 Google Cloud、Waymo 工作，并联合创立物流自动化公司 Joint AI。
  • 创业经历让她认识到付费客户才是真实需求信号，因而转向 FDE 岗位。
  • 她主导 Mercury Insurance 成为 Cresta AI Agent 首个自助服务客户。
  • 为 Xanterra 构建 RAG，两个公园的 AI Agent 对话承接率达 84% 和 76%。
  • 她还负责合作伙伴培训，并建议求职者选择灵活可适应的岗位。

欢迎阅读新一期《前沿部署团队风采》，本栏目聚焦与客户合作构建和部署 Cresta AI Agent 的团队成员。

本期我们将聚焦 Shengyao Qian，她是一位前沿部署工程师（FDE），工作地点在旧金山。

在加入 Cresta 之前，Shengyao 曾在 Google Cloud 构建时间序列基础设施，在 Waymo 开发车队运营软件，还与朋友们共同创办过一家初创公司。

我们聊了她从 Google 到 Waymo 的职业路径、她的创业者经历、作为 FDE 的一天是怎样的，以及更多内容。

你曾在一些非常了不起的公司工作过，包括 Google Cloud 和 Waymo。你在这些公司都做了什么？

我在 Google Cloud 团队时，参与构建了一个用于云端日志和监控的时间序列数据库。那是很底层的后端基础设施工作，技术含量很高，也是绝佳的学习机会。

后来有一天，Waymo 在我们大楼的顶层举办了一场派对，和招聘经理喝了一两杯之后，他问我想不想加入他们。

当时 Waymo 的车刚开始出现在旧金山街头，所以这个机会听起来非常有趣。我无法拒绝。

在 Waymo，我负责车队管理软件。我们在亚利桑那州凤凰城有一个大约 100 辆车的车场，我们的软件会给这些车分配不同的任务。有些车做训练，有些做地图测绘，有些则载着真实乘客进行试运行。

你还是一位联合创始人！跟我讲讲那段经历吧。

我和朋友们共同创办了一家名为 Joint AI 的初创公司，利用 AI Agent 来自动化物流运营。

我和最初的联合创始人都是技术背景，完全没有商业头脑。做产品对我们来说从来不难，但学会如何与人沟通、如何推销东西才是真正的挑战。

后来我们引入了一位专注于销售的联合创始人，他也是我们的朋友。我们的客户是仓库和货运代理公司，所以有一天他开车带我们在海沃德的一个物流中心转，挨家挨户敲门推销我们的平台。我们在洛杉矶也做了同样的事，那里聚集了很多物流公司。这段经历有点“创伤”，但也非常令人兴奋。

由于种种原因，这家初创公司最终没有成功，但我从中得出的结论是：我想更贴近客户。

你为什么想转向前沿部署工程岗位？

当你为另一个内部团队做工作时，很难验证需求是否真实。人们可能有不同的意见，有时更会表达的人赢了，即使那个想法并没有得到验证。

例如在 Google，我们的客户是内部基础设施团队，没有人为我们构建的东西付费。这就很难区分真实的需求和只是听起来有说服力的需求。

但当客户愿意为某样东西付费时，这是一个非常真实的信号。它证明我们正在满足市场上的某种需求。

这促使我去寻找能直接与客户交流、深入了解他们的业务需求并为他们构建产品的岗位。

以我的背景，没有人会雇我做销售，所以工程加上贴近客户是我理想的组合——而前沿部署工程正好满足这些要求。

你为什么选择 Cresta？

我喜欢每一位面试我的人。

我的第一个面试官给了我一道我从未听说过的算法题。他讲解得如此透彻，以至于我第一次听到就能实现它，这也说明了他对这道题理解得有多深。

之后的每一位面试官都以同样的方式讲解问题，包括一些对我来说全新的概念。因为每道题我都能完成，我甚至感觉自己在面试过程中就在成长。

我还希望自己的角色有灵活性。例如，我知道自己想参与售前工作，而不太想专注于产品开发。

在面试过程中，我清楚地看到领导层对我探索售前以及其他我感兴趣的领域持开放态度，现在依然如此。我觉得我很难找到像他们这样思想开放、支持我在其他领域发挥作用的领导。

谈谈你在 Cresta 做过的最引以为豪的一两个项目。

有两个项目立刻浮现在我的脑海中：

1. 帮助拿下 Mercury Insurance，使其成为我们 AI Agent 的首个自助服务客户。

我从一开始就负责与 Mercury 合作的各项工作。

我首先向 Mercury 的团队讲解我们的 AI Agent 是如何工作的。在此基础上，我和一位解决方案工程师一起分析 Mercury 的通话流程，以发掘最佳的自动化机会。我们最终确定了两个用例：理赔状态查询，以及针对来电取消服务的客户的优惠挽留方案。

接下来，我在一周的时间里每天与他们的团队通话，演示每个用例。我向他们讲解了我如何构建这些用例、如何阅读调用轨迹，以及他们自己构建时的步骤。我们每天收集他们的反馈，第二天带回改进后的版本，让他们总有新东西可以评估。

我还把他们在平台层面的更广泛反馈转化为对我们工程团队的请求。通过共同努力，我们最终改进了 Cresta CLI，这是开发人员用来构建和测试 AI Agent 的命令行工具。我们还构建了环境和部署功能，让团队可以为 Agent 设置独立的测试版本和生产版本，并在两者之间迁移变更。

可以说，Mercury 的反馈帮助我们的工程师专注于最重要的改进，确保未来每一位自助服务客户都能从一个更强大的平台起步。

2. 为 AI Agent 构建检索增强生成（RAG）功能。

我的工作重点是让 AI Agent 能够在客户的文档中找到正确的信息，并利用这些信息为每位用户撰写准确、完整且个性化的回答。

我们与 Xanterra 的合作实施是 AI Agent 使用 RAG 的一个绝佳真实案例。Xanterra 是美国国家公园中最大的小屋、餐厅和特许经营运营商。

他们的客人在四个联络中心咨询从住宿到野生动物游览的各种问题，因此 AI Agent 必须在高流量的情况下回答各种各样的问题。

借助 RAG，AI Agent 可以从 Xanterra 各个公园的自有内容中提取答案，为客人提供准确、最新且在各公园间保持一致的回答。

与 Xanterra 的合作成果有目共睹：冰川国家公园的 AI Agent“Skye”解决了 84% 的对话，而黄石公园的 AI Agent“Faith”解决了 76% 的对话。

在 Cresta 的一天通常是什么样的？

大多数 FDE 都从事部署工作，我也是如此。

我们为客户设计、开发和部署 Cresta AI Agent。但我们不仅仅是构建者。例如，当客户想要添加某项功能时，我们会提供技术建议，帮助他们权衡利弊。

此外，我还支持 Cresta 的合作伙伴渠道。

我们希望第三方经销商有能力销售和实施 AI Agent，因此我与合作伙伴公司合作，确定他们需要招聘什么样的人才。而在这些人加入后，我会对他们进行培训，讲解 AI Agent 的工作原理以及如何在 Cresta 平台上进行部署。

我还与我们的核心基础设施团队合作，让平台更便于合作伙伴的开发者使用，从界面到部署代码的规则都是如此。

对于在不同公司之间选择 FDE 职位的人，你有什么建议？

候选人经常问我 FDE 这个职位是否只是暂时的，因为如今的 AI Agent 解决方案高度定制化，最终可能会被自动化。我不知道这是否属实，也没有人能预测未来。

我所知道的是，无论未来如何，你都需要一个灵活且能够适应变化的职位。这对 FDE 职位和其他任何工作都适用。

在 Cresta，我有很大的探索和学习空间。我可以参与销售、合作伙伴关系以及客户合作，从事超越单纯构建 AI Agent 的项目，比如帮助他们设定收入目标。

这种灵活性意味着，无论 FDE 职位如何演变，我都能处于有利位置。
