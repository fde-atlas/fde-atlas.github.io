AWS 如何让前沿部署工程师与知识图谱对齐——以及为什么

原标题：How AWS is aligning Forward Deployed Engineers with knowledge graphs - and why

Diginomica · 2026-07-29 · 约 8 分钟读完

摘要

Diginomica 报道 AWS 将前沿部署工程师与知识图谱结合的战略。AWS 副总裁 Francessca Vasquez 介绍了 10 亿美元投入的 FDE 组织，配合新发布的 AWS Context 服务，帮助企业构建语义层和受治理的知识图谱，让 AI Agent 能基于企业数据推理。文章指出 FDE 概念已从 Palantir 特色变为行业默认，微软、Google Cloud、Salesforce 等纷纷跟进。AWS 强调模型中立，目标是让客户最终自给自足。

要点

  • AWS 投入 10 亿美元组建 FDE 组织，并推出 AWS Context 知识图谱服务。
  • FDE 模式一年内从 Palantir 特色变为行业默认，微软、Google Cloud、Salesforce 等纷纷跟进。
  • AWS 保持模型中立，可与 OpenAI、Anthropic 模型及 Bedrock 配合使用。
  • 目标是让客户自给自足，而非长期驻场运营。
  • 内部以 AI 45 方法论迭代：45 分钟构思、45 小时验证、45 天冲刺。

全文

  • 摘要：
  • AWS 前沿 AI 工程与服务副总裁 Francessca Vasquez 解析了 AWS 将以人为核心的前沿部署工程与新推出的 AWS Context 知识图谱服务对齐的计划，这一计划基于九年来对企业 AI 成功与停滞的观察。

早期将先进 AI 工具部署到企业中以实现现代化的愿景，正在遭遇日益被称为“上下文”的支撑作用以及人类专业知识方面的真实缺口。在 2026 年，“上下文”这个词值得加上引号，因为它被以各种不同的方式广泛使用，基本上用来概括所有与高质量数据相关的挑战，以及将 AI 用例映射到人类在为特定目的整理数据集时真正意图的问题。

AWS 希望通过名为 AWS Context 的服务，为厘清原始数据本来的含义以及如何将其合理应用于各种新用例的诸多流程带来一些秩序和理性。它基本上是一个服务、基础设施和受治理的智能体服务层，用于告知智能体在何时、为何以及如何将现有数据资产和服务重新用于新的工作流。

与此同时，AWS 最近宣布了一项 10 亿美元的前沿部署工程（FDE）组织计划，该组织融合了从帮助企业构建语义层的实践中提炼出的人类最佳实践，以支持新的 AI 和智能体用例。其核心论点是：这个新组织可以帮助企业团队将语义层连接到企业数据源、丰富元数据，并利用 AI 发布一个受治理、带版本管理的知识图谱。这有望为智能体的推理提供基础。而最关键的一点是——这个知识图谱将以某种方式编码存在于客户代码中的领域专业知识，而不是那些可能随人员流动而流失的机构知识。

我认为更广泛地澄清一点很重要：FDE 和知识图谱这些术语更多是愿景性的方向，而非严格的技术术语。我记得在 2021 年，曾读到一家专业服务公司宣称 2021 年是“知识图谱之年”，而其实际案例不过是一家公司用一个新的模式把两个数据库连接在一起。到了 2026 年，几乎所有有 AI 抱负的厂商都在寻求为一线专家构建一个更具可扩展性的框架，这一框架因 Palantir 对 FDE 的定位而广为人知，即将现有数据资产连接起来以支持新用例。

AWS 在这方面的努力，凭借其在整个云基础设施领域的巨大影响力，以及对负责将其扩展到新用例的人员的 10 亿美元投资，有望更广泛地推动知识图谱和 FDE 模式的前沿发展。

而这一切发生之际，各大超大规模云厂商和前沿实验室正趋同于 Palantir 二十年来在嵌入式工程模式上的深耕。微软七月初斥资 25 亿美元成立 Frontier Company，谷歌云五月的 FDE 招聘潮，埃森哲与微软、ServiceNow 和 SAP 合作的 FDE 实践，德勤在十二月跟进，IFS 的切身投入，以及Salesforce 承诺招募一千名 FDE。这个头衔在不到一年内从 Palantir 的独特做法变成了行业默认配置。

但这些新 FDE 们究竟在做什么真正新颖的事，彼此之间以及与 Palantir 又有何不同？AWS 前沿 AI 工程与服务副总裁 Francessca Vasquez 清晰地解读了 AWS 版本的故事：

我们在这条路上已经走了好几年，最初是从我们的解决方案架构师和机器学习解决方案实验室开始的，在 AI 和 ML 的早期，我们有团队在外帮助客户定义用例。三年前，我们成立了一个名为 Gen AI Innovation Center 的团队，专门致力于把这些用例转化为可运行的原型，再推向生产环境。

新的 FDE 组织是 AWS 自当前浪潮之前就一直在运行并不断改进的服务模式的第三个迭代，背后已有数千次客户合作。Vasquez 预测，下一波浪潮将需要聚焦于上下文和可组合性：

在当今世界，FDE 的很多价值将来自与客户共同构建以及他们的上下文智能，这一点很重要。正如你所说，很多价值在于他们会留下什么，技能如何，文化如何——其中很多是通过各种形式的知识图谱、语义层、本体论等（随你选哪种）来培养的。我们的 FDE 成果将高度侧重于直接与客户一起提供这种上下文智能。

关于上下文的上下文

到了 2026 年，“上下文”一词被以如此之多不同的方式广泛使用，以至于人们往往需要一两分钟才能弄清楚对方指的是什么。这个词原本基本上指背景信息，或在事物的周边环境中对其进行思考，如今却带上了更多技术色彩，即以某种方式为这些智能体（agentic）事物提供依据，从而减少凭空编造，并希望使其与人类的要求保持一致（前提是大家能就此达成共识）。

去年的上下文主要聚焦于通过更精准的检索增强生成（RAG）来收窄 LLM 处理的过滤范围。如今，焦点正扩展到由领域专家参与拓宽这一过滤范围。Vasquez 进一步阐述：

围绕上下文确实出现了一种新的方向。在我看来，以及从我们与客户的合作中所看到的，我们能够帮助客户获得更深层的语义上下文——而支撑这一点的前提是，我们还必须帮助客户将其数据整理到可用的状态。所以我认为这不仅仅是编写脚本和使用工具那么简单，而是要在客户的环境中做到高度贴合，因为我们的每位客户在数据主权管控方面都有不同的约束条件。我认为，正是在这里，我们能够为他们在各自的环境中、在我们所服务的客户中，提供一种不同的价值能力。

各家厂商的 FDE 很可能都被激励去推进与其销售模式相契合的特定最佳实践。而 AWS 尤其提供了大量模型，可以与前沿实验室的工作形成互补。Vasquez 解释道：

顺便说一句，Anthropic 和 OpenAI 都是我们很好的合作伙伴，因此我认为我们的一个天然优势在于，我们倾向于保持模型中立，能够根据客户的实际情况提供服务。所以在某些情况下，我们推动的 FDE 能力可能基于 Bedrock 上的 OpenAI 模型，也可能基于 Anthropic 的模型。这是一件好事——我们与他们有着很好的合作关系，并且我预见我们 FDE 的未来方向将与更多模型提供商保持紧密合作。

在其他场合，她对工具也表现出同样的开放态度，将 AWS 自家的规范驱动型 Kiro 与“第三方模型提供商的编码工具，如 Codex 和 Anthropic 的 Claude Code”并列提及。更广泛地说，这反映出人们日益认识到：关键不在于把客户锁定在某个特定模型上，而在于帮助企业培养自身内部能力，将新的 AI 模型应用于新的、经过更精心整理的数据模型。

与即使是最好的传统专业服务合作不同，AWS 这一模式的最终目标是让企业凭借成功的前进势头，逐步实现自给自足，如同一种“毕业”。Vasquez 说：

我们认为让客户长期嵌入 FDE 代为运营并不符合他们的利益。我们希望让客户实现自给自足。

当我问到十年后成功是什么样子时，她进一步说道：

我总是告诉我的团队，一个好的结果是：我们建立起一项业务来提供帮助，然后几年后，我们的客户会说我们做得太好了，或者产品和创新已经如此无缝、如此流畅、如此好用，以至于他们不再需要我们的帮助。对我来说，这将始终是一个持续运转的飞轮——我们会打造更好的产品和服务，我们的客户会获得价值，他们会在这个过程中提升技能，顺便说一句，这也可能降低成本结构，而这对客户来说也是一件好事。

值得注意的是，几乎所有新兴数据栈厂商都在为同一个目标提出自己的表述框架。Snowflake 发布了 Horizon Context 和 Cortex Sense，微软推出了 Fabric IQ 作为语义本体层，Pinecone 推出了 Nexus，Redis 则打造了一个上下文平台。而在所有这些方案中，都需要某种专业能力——无论是各厂商的 FDE，还是企业自身的内部专家——来帮助将这些新的上下文层引入企业，因为完全自动化的版本尚未成熟。

就 AWS 而言，他们在内部将这项工作称为 AI 45，即通过在不同规模上迭代式地积累小成功来促成更大的成功，形成一个良性循环，例如 45 分钟内快速构思、45 小时内完成验证、45 天内完成冲刺。Vasquez 认为，真正的价值在于通过团队协作完成这些越来越大的循环，从而带来文化变革的前景：

我们还看到了一个意想不到的好处——这不是技术本身，而是当你完成一次这样的冲刺之后会发生什么——我们的客户开始以前沿 AI 公司那样的方式来思考和运营，即使他们所在的行业可能已经存在了一百年或五十年。它开启了文化变革的循环，而在当今时代，这是非常难以做到的事情。

我的看法

这一切都很好，显然，新的咨询服务模式以及更加用心的配套数据模型的标准正在朝着正确的方向发展。但从更广泛的角度来看，AI 的长期普及可能还需要更多进展，以应对人们对失控的代币经济学成本的抵触，以及 AI 被强加于人所带来的挫败感。

Vasquez 表示，这些更具沉浸感的 FDE 模式的价值在于揭示那些没人会写下来的东西：

来自 AWS 等合作伙伴的 FDE 必须深入客户的业务流程之中，因此他们没有机会只从外部旁观；他们必须置身于业务流程之中。
