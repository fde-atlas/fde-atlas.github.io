选购指南6 个问题

什么是 MRP 软件？

MRP 指物料需求计划。该软件会计算出你需要采购或生产什么、数量多少以及何时完成。它从你的销售订单和预测出发，展开每个产品的物料清单，减去在库和在途的数量，然后显示短缺情况，接着生成采购订单和生产订单建议。在实践中，小型工厂用它来避免在任务本应开工的那天才发现缺少零件。本列表中有些产品以 MRP 为主，例如 MRPeasy 和 Fishbowl Advanced Manufacturing。另一些则起源于库存工具、后来加入生产功能，例如 Unleashed、Katana、Cin7 Core 和 inFlow。请每位供应商向你展示基于真实订单生成的短缺清单。

MRP 与完整的 ERP 有何不同？

完整的 ERP 涵盖整个业务：总账、工资、销售、采购、库存和生产都在同一个数据库中。MRP 覆盖物料和生产计划，以及它所依赖的库存和物料清单。大多数小型工厂用 QuickBooks 或 Xero 记账，并在旁边加上 MRP。MRPeasy、Katana、Fishbowl、Unleashed 和 Cin7 Core 的页面上都提到了 QuickBooks Online 或 Xero。Cetec ERP 和 ERPNext 将自己描述为围绕生产侧并包含财务和其他模块的更广泛的系统，而 Odoo 则在一系列应用套件中销售其制造应用。Unleashed 自己的页面说明它不是完整的 ERP。要问的问题是：你想用一个数据库管理一切，还是想要一个能与你的总账对话的计划工具。我们相邻的小型企业制造 ERP 列表涵盖了第一种情况。

机加工车间（job shop）与备货型生产车间有什么不同？

有区别，因为计划触发的机制不同。备货型车间根据预测和再订货点进行计划，按批次生产，关注货架上的成品。机加工车间根据客户订单进行计划，为每个工单报价，关注工艺路线、排程以及工单成本与报价的对比。Katana、Unleashed、Cin7 Core 和 Megaventory 偏向库存和销售渠道。JobBOSS² 针对按订单生产和定制金属加工车间，提供报价、拖拽式排程和工单成本核算。MRPeasy 在企业版中列出了销售预测和倒排排程，Odoo 列出了主生产计划和有限产能计划。请检查产品从哪一侧出发，因为另一侧通常功能较弱。

我需要 MRP，还是库存软件就足够了？

如果你根据较短的零件清单进行生产，并凭经验补货，那么带物料清单的库存软件可能就足够了。inFlow Manufacturing 和 Megaventory 在库存工具中增加了 BOM 和制造或工单，而且我们读到的两个页面都没有提到 MRP。当一个工单需要来自多个供应商、交货期各不相同的许多零件，或者当你针对同一批库存运行多个工单时，你就需要 MRP。这时缺料清单能省下真金白银，因为你不再过度采购，也不再停工等待。一个简单的测试方法是：问问上个月有多少次工单因为一个本可以提前预见的零件而延误。

为什么价格这么难比较？

它们使用不同的计价单位。MRPeasy 和 Cetec ERP 按用户收费。Unleashed、Cin7 Core、Fishbowl 和 inFlow 按套餐收费并限制用户数。Katana 的页面显示有免费套餐和定制合同。ERPNext 按托管收费，不按用户收费。Odoo 按用户收费，首个应用免费。JobBOSS² 仅提供报价。更大的陷阱在于 MRP 所处的位置。Unleashed 将 MRP 放在 Core 套餐每月 $149，Pro 套餐免费。Cetec ERP 的高级制造计划功能收费每月 $1,000。Fishbowl 较便宜的库存套餐完全不包含 MRP。请根据你的用户数，为包含你所需计划功能的套餐定价，再加上实施费用。

在做出决定之前我应该检查什么？

检查四件事。第一，在试用中跑一笔真实订单，看看缺料清单。第二，询问它如何对接你的会计系统，以及该对接是否额外收费。Cetec ERP 的 QuickBooks Online 集成标价为每月 300 美元。第三，询问与你规模相当的工厂上线花了多长时间。JobBOSS² 的 FAQ 显示大约 3 到 6 个月，而 Fishbowl 的页面则表示必须购买实施套餐。第四，弄清楚如果你离开，你的数据会怎样。签约前，要求完整导出物料、物料清单和未结订单。

如何选择

  • 1首先，决定你是按预测还是按客户订单来计划。备货型工厂需要再订货点、批次和成品管控。订单型工厂需要报价、工艺路线和可以灵活调整的排程。
  • 2其次，统计会使用系统的人数。MRPeasy 和 Cetec ERP 这类按用户收费的工具，随着操作员加入会变得更贵。Unleashed、Cin7 Core 和 inFlow 这类按套餐收费的工具，则对用户数和订单量设上限。Odoo 和 ERPNext 又是另一套算法。
  • 3第三，查明包含 MRP 的套餐价格。Unleashed 上是 Core 加附加组件或 Pro。Fishbowl 上是按报价提供的 Advanced Manufacturing。Cin7 Core 上是 Pro 和 Advanced，但请与供应商确认。要求以书面形式提供。
  • 4第四，决定账务放在哪里。如果你继续使用 QuickBooks 或 Xero，请查明确名的对接及其费用。如果你想要一个涵盖一切的单一数据库，可以看看 Odoo、ERPNext 或更广泛的 ERP 清单。
  • 5最后，规划好最初的 90 天。留出时间录入物料清单、库存盘点和未结订单。有试用和公开价格的工具可以让你低成本地测试这些。要求购买套餐且上线周期长的工具则是一笔更大的赌注。

常见问题6解答

小型制造商的 MRP 软件要花多少钱？

在我们打开的页面上，公开价格从每月 0 美元到 1,199 美元不等。MRPeasy 标价为每用户每月 49 至 149 美元。Unleashed 标价为每月 99、399 和 729 美元。Cin7 Core 标价为每月 349、599 和 1,199 美元。inFlow Manufacturing 标价为每年计费、每月 169 至 859 美元。Cetec ERP 标价为每用户每月 50 美元，最少 5 个用户。Odoo 标价为每用户 24.90 美元起，且首个应用免费。ERPNext 托管每月 5 美元起。Fishbowl Advanced Manufacturing 按报价每月 675 美元起。Katana 显示有免费套餐和定制合同，JobBOSS² 则未显示价格。

有免费的 MRP 软件吗？

部分有。Katana 列出价格为 0 美元的 Free 套餐，包含所有功能、不限用户数，但在最初 15 天后限制 30 个 SKU。Odoo 列出 One App Free，单个应用不限用户数。ERPNext 如果自行托管，是根据 GPL-3.0 的免费开源软件，Frappe Cloud 提供 14 天试用。MRPeasy、Unleashed 和 inFlow 提供试用但没有免费套餐。免费软件仍然需要花时间搭建，所以要为此预留预算。

MRPeasy 和 Unleashed 有什么区别？

MRPeasy 围绕生产构建：计划、BOM、采购以及 Enterprise 版的主生产计划，按用户定价。Unleashed 围绕库存和订单构建，Core 版的生产和 MRP 作为附加组件收费，Pro 版则已包含，按套餐定价。对于一家约 10 到 200 人、按订单或备货生产的工厂，MRPeasy 的页面更直接契合。对于通过多渠道销售、组装简单产品的企业，Unleashed 的页面紧随其后，是不错的选择。

我的库存应用能胜任这项工作吗？

对于简单的生产，有可能。inFlow Manufacturing 和 Megaventory 都列出了 BOM 以及制造订单或工单。我们阅读的两个页面都没有提到 MRP。如果你的工单使用少量零件且交货周期短，这可能就够了。如果一个工单需要从多个供应商调取大量零件，以 MRP 为核心的工具会更早发现短缺。

这些产品中哪些需要销售电话沟通？

JobBOSS² 未显示价格，并指向演示。Fishbowl 的 Advanced Manufacturing 需通过报价确认。Katana 的 Advantage 套餐为定制价格。Cin7 Core 的 Omni 套餐为定制价格。Megaventory 的 Enterprise 套餐为定制价格，Frappe 的 Enterprise 托管需报价。MRPeasy、Unleashed、Cetec ERP、inFlow 和 Odoo 公布了价格，不过 Odoo 的计费方式不明确。

这份清单多久更新一次？

我们每 90 天重新评分一次，下次评审日期为 2027-01-25。如果供应商在此之前更改价格或下架某个套餐，清单可能已过时，因此购买前请在供应商自己的页面上确认每一项数据。
