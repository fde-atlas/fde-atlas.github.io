摘要

这篇由 DeFactory 代表德满翔平撰写的指南面向日本自由职业工程师，系统介绍自由职业中介（Agent）的运作机制、选择标准与注册流程。中介在客户企业与自由职业者之间撮合业务委托合同，从月单价中抽取约10%至30%的佣金。文章比较了 PE-BANK、Midworks、Levtech Freelance、IT Pro Partners、TechStock 等主要平台，并引用数据称2025年日本 IT 自由职业市场规模达约1.18万亿日元，十年间增长约1.6倍。作者建议同时注册2至3家中介，并指出云架构、数据工程、生成式 AI 等技能可带来月单价100万日元以上的高薪案件。需注意文末带有对自家服务 BizDev Tech 的推广。

要点

  • 中介抽取10%至30%佣金，换取撮案、议价与法务支持。
  • 2025年日本 IT 自由职业市场约1.18万亿日元，十年增长约1.6倍。
  • 选中介应看案件匹配度、佣金透明度、直客比率与付款周期。
  • 建议同时注册2至3家中介，避免重复应募同一案件。
  • 云、数据工程与生成式 AI 技能可获月单价100万日元以上案件。

仅限拥有5年以上实务经验的工程师

高单价・直接承包案件信息

面向自由职业工程师的中介服务，是一种站在IT企业、初创公司等客户企业与自由职业工程师之间，为双方进行案件匹配的服务。与招聘中介不同，其特点是居中促成自由职业者与客户之间的“业务委托合同”。

基本的收益结构如下。

クライアント企業 → エージェント（マージン差引）→ フリーランスエンジニア

客户企业向中介支付月单价（例如：100万日元），中介从中扣除抽成（手续费）后，将剩余金额（例如：80万日元）支付给自由职业工程师。行业平均抽成率被认为在10%～30%左右，不同中介有公开与不公开之分。

自由职业者中介提供的主要功能

功能内容
案件匹配介绍符合技能和期望条件的案件，包括非公开案件
合同与谈判代理支持单价谈判、合同起草及法律确认
持续跟进处理项目进行中的问题、提前推荐下一个案件
请款与付款管理管理每月请款处理和付款周期
职业咨询提供技能提升和单价提升方面的职业建议

① 可以接触到非公开案件

中介所持有的案件大多是不对外公开的非公开案件。对工程师招聘较为谨慎的初创公司、大型SIer以及业务公司，为了降低招聘成本，往往倾向于通过中介进行案件的发包与接单。能够接触到靠自己无法遇到的高单价、好条件案件，是使用中介的最大优势。

② 可以代理单价谈判

自由职业者自己进行单价谈判的心理门槛较高，缺乏经验时可能会以低于合理价格的单价达成协议。中介熟悉市场行情，会基于工程师的技能和实绩与客户进行谈判，因此更容易获得合理的报酬。

③ 无需任何销售活动，案件可持续供给

独立初期最大的风险是“案件中断”。只要在中介注册，在当前案件结束之前就可以获得下一个案件的推荐，从而将收入的空白期（即所谓的“空窗期”）降到最低。

④ 可以规避合同与法律风险

自由职业者以个人身份直接与客户签订合同时，可能面临不利条款、付款延迟甚至赖账的风险。中介会对客户进行信用调查，万一发生纠纷也会居中处理。

⑤ 还支持确定申告与发票制度应对

部分中介还会就自由职业者特有的税务处理（确定申告、发票制度应对）提供建议，并提供与会计工具对接的支持。

优点虽多，但以下几点需要注意。

  • 因抽成导致实际到手收入减少：客户支付金额的10%～30%会成为中介的分成
  • 案件选择范围受限于中介持有的案件：选择在特定技术栈或行业有优势的中介非常重要
  • 有时需要同时注册多家中介：仅注册一家可能找不到满足期望条件的案件

如果想比较包括中介以外途径（众包、人脉介绍、社交媒体发声、直接销售）在内的接单方式，也请一并参阅自由职业工程师接单方式完全指南｜5种主流模式总结。

自由职业者中介有数十家以上，但“注册后发现没有适合自己的案件”“负责人态度差、用起来不方便”这样的经验之谈并不少见。以下面5个要点为轴进行选择，可以大幅降低失败的风险。

选择代理机构时，首先应确认的是自己的技能组合与案件领域是否匹配。例如，擅长 Python、机器学习类案件的代理机构，与擅长 Java 企业级案件的代理机构，虽然同样面向“IT 工程师”，但案件的质量和数量会有很大差异。

应确认的要点

  • 保有案件总数（不仅要看数字，还要询问与自己技能匹配的案件数量）
  • 支持的语言、框架（Python / Go / TypeScript / React / AWS / Azure 等）
  • 行业（SIer / 甲方企业 / 初创公司 / 金融 / 医疗等）

抽成率（手续费）因代理机构而异，部分代理机构不予公开。主要代理机构的抽成率参考如下（参考：sakufuri.jp 抽成率比较）。

代理机构抽成率参考
PE-BANK8〜15%（根据提款频率浮动）
Midworks实际约10〜15%（含福利待遇）
Levatech Freelance未公开（估计10〜20%）
IT Pro Partners未公开（直客案件比例90%，回报较高）
TechStock未公开（平均年收入935万日元，处于较高水平）

抽成率越低，到手收入越多，但相应地支持服务可能较为简单。重要的是不仅看“抽成率低”，还要综合考虑案件质量与支持内容之间的平衡。

在最大化自由职业者收入方面，容易被忽视的是多重转包结构的问题。如果代理机构中介的案件实际上是大型 SIer 的二次、三次转包，那么从客户支付的金额中，除了代理机构的抽成外，还会扣除多个中间环节的抽成，自由职业者的回报率会大幅下降。

选择直客案件比例高的代理机构可以避免这一问题。IT Pro Partners 公开表示“90%的案件是与甲方企业直接签约”，其结构不易产生中间抽成（参考：IT Pro Partners 官网）。

代理机构的好坏，很大程度上取决于负责的职业顾问的素质。在初次咨询时应确认以下几点。

  • 简历修改与案件推荐的具体性（是否有“某某案件月薪多少万日元”这类具体推荐）
  • 是否积极进行单价谈判
  • 响应速度（是否在下一个工作日内回复咨询）
  • 是否具备 IT、工程师领域的专业知识（能否进行技术性对话）

由于自由职业者的收入稳定性很重要，付款周期（账期）也应纳入选择标准。

  • 一般为月末结算、次月末付款（账期30天）
  • 也有部分代理机构为次月15日付款或隔月付款

此外，还有像 Midworks 这样提供补贴社会保险公司负担部分的福利待遇的代理机构。对于自付国民健康保险费负担较重的自由职业者来说，这类附加价值也可以纳入选择标准。

自由职业工程师市场正在迅速扩大。根据株式会社 INSTANTROOM（Freelance Start 运营方）的调查，2025年 IT 自由职业市场规模已达1兆1,849亿日元，较2015年（7,199亿日元）的10年间扩大了约1.6倍（参考：Freelance Start IT 自由职业市场白皮书 2025）。

此外，IT 自由职业者人数截至2024年已超过35万人，预计到2028年将扩大至45万人规模（参考：Levatech Freelance 自由职业者人口动向）。

市场扩大的背景包括企业推进 DX（数字化转型），以及云、AI、数据应用需求的激增。尤其是具备 Python、Go、TypeScript、云架构等技能的工程师需求旺盛，通过代理机构获得月薪80万日元以上的案件也并不罕见。

本文为首次使用自由职业者 Agent 的朋友，讲解从注册到实际参与案件的标准流程。

首先在 Agent 的官方网站进行免费注册。需要填写的内容主要有以下几项。

  • 姓名、联系方式、居住地
  • 当前的雇佣形态（公司职员 / 已是自由职业者）
  • 希望开始工作的时间
  • 掌握的技能、使用的语言、框架、工作年限
  • 期望月单价、工作方式（全职 / 每周 3～4 天 / 希望远程等）

要点：如果在这一阶段就准备好技能清单和职业经历书，之后的面谈会更加顺利。同时注册多个 Agent，可以比较更多的案件。

注册后，负责的职业顾问会通知你进行线上面谈。面谈主要围绕以下内容展开。

  • 梳理至今为止的职业经历与技能
  • 期望案件的条件（行业、技术栈、工作天数、是否可远程）
  • 独立的目的、职业发展方向
  • 当前状况（在职 / 已离职）与希望参与的时间

面谈时应传达的信息：

  • 期望月单价和最低底线（作为谈判空间）
  • 可通勤的区域、是否希望完全远程
  • 擅长的开发阶段（需求定义 / 设计 / 实现 / 测试）

面谈结束后，Agent 会推荐符合条件的案件。每个案件会提供以下信息。

  • 月单价、工作期间（一般为 3 个月～6 个月续约）
  • 业务内容、使用技术、开发环境
  • 工作地点（完全远程 / 部分到岗 / 常驻）
  • 客户企业的行业与规模

如果有感兴趣的案件，就进入选拔流程。选拔流程因 Agent 和客户而异，但一般为资料审核 → 线上面谈 1～2 次 → 录用结果通知的模式。

面谈往往一次就能定下来，因此请提前在自由职业工程师的面谈对策中确认常见问题和反向提问。

通过选拔后，将与 Agent 签订业务委托合同。合同的主要内容如下。

  • 业务委托合同书（准委托 or 承揽）
  • 月单价、工作时间的上下限（例如：140～180 小时）
  • 付款周期（月末结算、次月末支付等）
  • 保密协议（NDA）

对发票制度的应对（2023 年 10 月以后）：根据是否为合格请求书发行事业者（发票登记），向客户开票的方式会有所不同。部分 Agent 即使未登记发票也能应对，因此请提前确认。

开始工作后，优秀的 Agent 会持续提供跟进服务。

  • 开始工作后 1～2 周内的跟进联系（确认是否有困扰）
  • 合同续约时协助进行单价上调谈判
  • 提前推荐下一个案件（在合同到期前 1～2 个月开始）

工作中进行单价谈判的时机：合同续约（每 3～6 个月）的时机最为合适。很多自由职业者会在工作中积累业绩，通过 Agent 谈判将月单价上调 5～10 万日元。

如果“不知道哪个 Agent 适合自己”，最可靠的方法就是实际注册，确认其推荐案件的质量和数量。所有 Agent 的注册都是免费的，注册后也并非必须签订合同。

独立初期、正在考虑从公司职员转型的人 → 推荐 DeFactory（本公司运营的 BizDev Tech）。终端直签案件多，基本返还率也在 80% 以上，即使是第一次做自由职业者，也有完善的贴心支持体制。

重视高单价、现代技术案件的人 → 推荐 TechStock。Python、Go、TypeScript、云原生类的高单价案件丰富，平均年收入也是业界最高水平。

希望副业、每周工作 3～4 天的人 → 推荐 IT プロパートナーズ。每周工作 2～3 天的灵活案件中 90% 以上为直签案件，专为想作为副业、兼职利用的工程师提供支持。

希望将手续费降到最低的人 → 推荐 PE-BANK。抽成率为 8～15%，处于业界最低水平，结构上有利于有实力的工程师获得高返还。

业界普遍认为，同时注册 2～3 家自由职业者 Agent 效果最佳。理由如下。

  • 各 Agent 持有的案件不同，可以扩大选择范围
  • 从多个 Agent 获得案件推荐，更容易把握市场行情
  • 由于存在竞争关系，负责人往往会更积极地提供支持

但要注意，通过多个 Agent 申请同一个案件，可能导致选拔无效，因此申请前请务必向各 Agent 确认。
