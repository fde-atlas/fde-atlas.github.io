什么是 Dev？含义与定义

原标题：What is Dev? Meaning & Definition

FDE Pulse · 2026 · 约 1 分钟读完

摘要

本文解释 Palantir 对 Dev 的定义：Dev 是核心软件工程师，负责端到端拥有平台组件，为多个客户编写同一能力。与之相对，Delta（前沿部署工程师）为单一客户构建多种能力，Echo 则确保方案真正解决客户问题。文章认为 Dev 与 Delta 的对比是选择核心工程还是前沿部署路径的核心：前者重广度与产品所有权，后者重深度与客户影响。

要点

  • Dev 是 Palantir 核心软件工程师的内部称谓
  • Dev 端到端负责平台组件，服务多个客户
  • Delta 为单一客户构建多种能力，与 Dev 相反
  • Echo 负责确保方案真正解决客户问题
  • Dev 与 Delta 的取舍是职业路径选择的缩影

全文

FDE Pulse 术语表

另见：Palantir Dev、Software Engineer

Dev 是 Palantir 对其核心软件工程师的称呼。一名 Dev 端到端地负责一个平台组件，编写的代码会交付给许多不同的客户。其重点是为许多客户打造一项能力。

这正是 Delta（前沿部署工程师）的镜像：Delta 的重点是为一个客户打造多项能力。Palantir 自己对这一区别的表述是理解整个模式最清晰的方式：Dev 负责构建产品，Delta 负责将产品深度部署到一个地方，而 Echo 则确保产品在那里真正解决实际问题。

如果你在权衡核心软件工程路径与前沿部署路径，Dev 与 Delta 的区别就是这一决策的缩影：广度与产品所有权，还是深度与客户影响力。

常见问题

在 Palantir，Dev 和 Delta 有什么区别？

Dev 是核心软件工程师，为许多客户构建一项能力。Delta 是前沿部署工程师，为一位客户构建多项能力，并嵌入该客户的环境中工作。
