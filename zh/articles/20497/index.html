资深前沿部署工程师 | Databricks

原标题：Sr. Staff Forward Deployed Engineer | Databricks

Zero G Talent · 2026-07-09 · 约 3 分钟读完

摘要

Databricks 招聘资深前沿部署工程师（Sr. Staff FDE），要求驻场服务战略客户，负责架构设计并交付覆盖数据工程、AI 与应用开发的全栈生产级系统。职位强调端到端交付能力、与销售及产品团队协作，以及沉淀可复用资产以影响产品路线图。候选人需精通 Python、SQL、Java/Scala、TypeScript 等技术栈，并具备集成 OpenAI、Anthropic、Gemini 等 AI API 的经验。

要点

  • Databricks 招聘资深前沿部署工程师，驻场服务战略客户。
  • 职责包括主导架构、交付全栈生产级应用与 AI 集成方案。
  • 要求精通 Python、SQL、Java/Scala、TypeScript 等技术栈。
  • 需有集成 OpenAI、Anthropic、Gemini 等 AI API 的经验。
  • 还需沉淀可复用资产并与销售、产品团队协作。

任职要求

CSQ327R198

作为前沿部署工程师（FDE），你将直接深入我们最重要的战略客户，在 Databricks 数据智能平台及其他常见软件栈上设计和交付定制化的全栈应用与解决方案。你将负责架构设计、主导设计决策，并实现涵盖数据工程、AI 和应用开发的端到端系统。

这是一个需要亲自动手、直接面向客户的岗位，适合那些在技术与业务价值的交汇点上如鱼得水的软件工程师、开发者和构建者。理想的候选人兼具工程专业能力、适应力、好奇心，以及解决复杂问题、创造可衡量成果的热情。

你将产生的影响：

  • 负责架构：主导架构与设计决策，确保解决方案安全、可扩展，并兼顾客户需求与 Databricks 最佳实践。
  • 应用工程：设计并开发涵盖后端、前端和集成的应用程序，借助 Databricks 平台为 enterprise 用户实现数据与 AI 的价值。
  • 解决方案交付：交付生产级系统，从数据摄取与转换，到 ML/AI 模型集成，再到面向用户的应用与赋能。
  • 深入客户：与客户团队深度协作，与从技术一线人员到高管层的各利益相关方沟通，深入理解挑战并交付价值。
  • 跨职能协作：与销售、产品和现场工程团队紧密合作，确保客户从售前到部署后的全流程体验顺畅无阻。
  • 可复用资产与规模化：贡献加速器、框架和最佳实践，将影响力扩展到更多客户，并影响 Databricks 的产品路线图。

我们期待的人才：

  • 工程深度：扎实的软件工程背景，具备后端、前端和系统集成经验。精通 Python、SQL、Java/Scala、JavaScript/TypeScript 及现代框架。
  • 应用交付：具备设计、构建和部署生产级应用的能力，能够将数据管道、ML/AI 模型与面向用户的界面相结合。
  • AI/ML 经验：熟悉将 OpenAI、Anthropic、Gemini 等 AI API 集成到应用中，并善于利用 AI 代码生成工具提升工作效率。
  • 客户影响：在企业环境中交付技术解决方案并创造可衡量成果的成功记录。
  • 协作与沟通：能够与从工程师到 C 级高管的广泛利益相关方有效沟通，将复杂概念转化为可落地的解决方案。
  • 学习心态：充满好奇心、适应力强，乐于探索新技术、新领域和新客户挑战。
