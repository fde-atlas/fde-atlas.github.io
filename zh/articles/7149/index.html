Palantir FDE 简介

原标题：Palantir FDE Profile

Plank · 2026-07-18 · 约 1 分钟读完

摘要

本文介绍 Palantir 的前沿部署工程师岗位。作为 FDE 角色的开创者，Palantir 要求工程师长期驻场客户，将 Foundry 和 AIP 平台深度定制到客户的数据与工作流中。文章从公开职位描述中提炼出招聘信号：多数岗位要求或偏好安全审查，出差比例可达 25%，近期出现面向自主 AI Agent 的表述，并设有面向应届生的纽约培训计划。招聘覆盖美国、欧洲和亚太，以中级和早期职业阶段为主。

要点

  • Palantir 是 FDE 角色的开创者，工程师驻场数月甚至数年。
  • 主要平台为 Foundry 和 AIP，按客户需求定制。
  • 多数岗位要求或偏好安全审查，比例居各公司之首。
  • 出差最多 25%，近期 JD 出现自主 AI Agent 相关表述。
  • 设有纽约应届生培训计划，作为 FDE 人才通道。

全文

上市公司

发明 FDE 职位的公司。工程师与客户同处数月甚至数年，将软件直接融入客户的运营之中。Palantir Foundry 和 AIP 是主要平台；FDE 针对每位客户的数据模型和工作流对其进行定制和扩展。

从 Palantir 公开的 FDE 招聘信息中挖掘出的模式

  • 01在大多数公开的 FDE 职位中，安全许可为必需或优先条件。这是本报告所分析公司中的最高比例。
  • 02大多数职位的差旅比例标准为最高 25%，直接反映了 Palantir FDE 与客户嵌入合作的深度。
  • 03近期职位描述中出现了“智能体决策引擎”的表述，表明 AIP 正转向自主 AI Agent 部署。
  • 04一个位于纽约的应届生研究员项目是进入 FDE 职业通道的直接途径。对于一家通常招聘有经验工程师的公司来说，这很罕见。
