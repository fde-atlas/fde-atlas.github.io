原标题：SmolLM2 (2025) Explained for FDEs

FDE Interviews · 2026-10-18 · 约 4 分钟读完

摘要

本文解读 Hugging Face 的 SmolLM2 论文：一个 1.7B 参数模型在约 11 万亿 token 上训练，重点不在架构而在数据。作者用 Llama-3 系列模型按教育价值打分、训练小分类器过滤，构建了 FineMath、Stack-Edu 和 SmolTalk 数据集，并在一次约 25 万美元的训练中分四阶段手工调整数据配比。对 FDE 的启示是：这套过滤配方可直接迁移到客户自有数据（工单、代码、文档）的清洗与筛选。

要点

  • SmolLM2 为 1.7B 参数模型，训练约 11 万亿 token，远超算力最优规模。
  • 核心方法：用大模型按教育价值打分，训练小分类器大规模过滤数据。
  • 构建 FineMath、Stack-Edu、SmolTalk 三个新数据集并全部开源。
  • 训练分四阶段，每次根据评测结果手工调整数据配比。
  • 对 FDE：过滤配方可迁移到客户工单、代码、文档等数据的清洗。

一分钟读完这篇论文

SmolLM2 是一个 1.7B 参数的 Llama 风格模型（24 层，宽度 2,048，嵌入绑定），由 Hugging Face 在约 11 万亿 token 上训练，远超计算最优，目的是让小模型尽可能强大。这篇论文主要讲的是数据。

作者通过小型消融实验对比了现有数据集，并在其表现不佳之处用相同方法构建了新数据集：让 Llama-3-70B 或 Llama-3.1-70B 对文档样本的教育价值进行评分，用这些评分训练一个小型分类器，对整个语料库打分并保留高于阈值以上的文档。FineMath（多达 54B token）是展示逐步推理过程的数学网页文本；Stack-Edu（约 125B token）是来自 15 种语言的文档完善的代码；SmolTalk 是一个指令微调混合集，围绕一个新的合成对话集 MagPie-Ultra 构建，该对话集由 Llama-3.1-405B 生成。

训练分四个阶段进行，因为一次运行成本约 25 万美元。第 1 阶段为 90% 的英文网页（FineWeb-Edu 和 DCLM）加 10% 的代码。每个阶段结束后，作者查看分数并调整配比：增加代码，然后加入小型数学数据集，再用 Stack-Edu 替换原始代码，最后在学习率衰减期间加入最好的数学（FineMath4+）和代码数据。在最后这 1T token 中，数学分数从 7.27 提升到 22.07。

基座模型在多项知识和推理基准测试上领先 Qwen2.5-1.5B 和 Llama3.2-1B，但在数学和代码上落后于 Qwen2.5。经过指令微调和 DPO 之后，它在 IFEval 上领先，但在 MMLU-Pro 和 GSM8K 上落后于 Qwen2.5。所有数据集和模型均已发布。

研究笔记：问题、方法与结果

在最后 1T token 的衰减阶段（加入最好的数学数据）前后的平均数学分数

仅保留经 LLM 训练的分类器评为具有教育价值的 23% 代码后，MultiPL-E 在 C++ 上的提升

1.7B 训练运行（约 1e23 FLOPs）的大致 GPU 成本，这也是配比在单次运行中调整的原因

小模型容量有限，因此训练数据对它们的影响比对大模型更大。公开的数学、代码和指令数据集要么太小，要么噪声太多，而一次完整训练的成本太高，无法尝试多种数据配比。

通过让 LLM 对样本的教育价值评分、用这些评分训练廉价分类器并大规模过滤来构建新数据集（FineMath、Stack-Edu），外加一个合成指令集（SmolTalk）。用 11T token 分四个阶段训练，每个阶段结束后根据分数手动调整配比，并在最后的学习率衰减期间加入最好的数学和代码数据。

SmolLM2-1.7B 的基础模型在 MMLU-Pro（19.4 对 13.7）和 TriviaQA 上胜过 Qwen2.5-1.5B，但在 GSM8K（31.1 对 61.7）、MATH 和 HumanEval 上落后。按教育质量过滤代码，在仅保留 23% 的 token 的情况下，使 MultiPL-E 每种语言提升了 4 到 8 分。数学成绩在最后 1T 个 token 中翻了三倍。

这对 FDE 为什么重要

很少有客户会预训练模型，但许多客户会从自己的杂乱数据（支持工单、内部代码、文档）构建训练或微调数据集。这篇论文是关于如何整理此类数据并验证其效果的最清晰的公开记录。

过滤配方可以迁移。 让一个强大的 LLM 按照书面评分标准对几十万个样本打分，用这些分数训练一个廉价的分类器，用它处理全部数据，并通过小规模实验选择阈值。在代码方面，在 C++、JavaScript 和 Python 中保留被评为最具教育价值的 23% 到 43%，使 MultiPL-E 提升了 4 到 8 分。同样的配方也适用于工单质量、文档相关性或样本难度。

阈值在质量与重复之间权衡。 严格的过滤器留下的数据更少；如果训练需要的 token 超过这个量，就需要重复使用数据。作者的目标是每个数据集不超过 4-5 个 epoch，而一个经过重度过滤的数学数据集在大约 10 个 epoch 后就不再提升。

何时添加专门数据很重要。 小而高质量的数据集被留到最后，在那里它们对分数的提升最大。

基础模型的优势可能在调优后不复存在。 基础模型在 MMLU-Pro 上领先 Qwen2.5-1.5B 5.7 分；经过指令调优后反而落后 4.9 分。要评估客户实际会使用的那个模型。
