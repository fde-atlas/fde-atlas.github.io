AI 编程 Agent 与开发者工具

Cursor 构建 AI 编程工具，帮助开发者和软件团队规划、编写、测试和审查软件。其桌面环境和 CLI 支持交互式开发，而云端 Agent 则在各自的计算机上并行工作，构建并演示功能以供审查。Cursor 还可以在 Slack 中工作、审查 GitHub 拉取请求，并为维护任务提供定时或触发的自动化。开发者可以在 Cursor 自有模型和其他提供商的模型之间进行选择。

Michael Truell、Sualeh Asif、Arvid Lunnemark 和 Aman Sanger 于 2022 年创立了 Cursor 背后的公司 Anysphere；Truell 担任 CEO。其研究将模型训练直接与开发环境相连接。对于 Composer 2，Cursor 将 Kimi K2.5 的持续预训练与强化学习相结合，并使用与部署的 Agent 相同的工具和框架。其 CursorBench 评测基于工程师真实的编程会话，包括需要跨多个文件进行修改的模糊请求。

到 2026 年 8 月，该公司报告称企业客户贡献了近 80% 的收入，而 2025 年初超过 80% 的收入来自消费者。在合作的前几个月内，NVIDIA 的采用量超过了 30,000 名每周活跃用户。SpaceX 于 2026 年 8 月完成了对 Cursor 的收购，据报道这是一笔 600 亿美元的纯股票交易。
