摘要

Jones Lang LaSalle（JLL）发布前沿部署工程师职位，年薪 15 万至 30 万美元，工作地点为芝加哥、达拉斯或旧金山，需到岗办公。该职位要求 8 年以上软件工程经验，负责快速设计并部署 AI Agent 与全栈解决方案，需熟悉 AWS Agent Core、MCP、LangChain 等框架及 Python 与前端技术。职位不提供签证担保，招聘持续进行直至录用。

前沿部署工程师

关于 JLL

JLL 的员工通过为客户整合世界一流的服务、咨询与技术，塑造房地产行业的未来，共创更美好的世界。我们致力于招募最优秀、最有才华的人才，赋能他们蓬勃发展、成就有意义的职业生涯，并找到属于自己的归属。无论您在商业地产、技术工种还是技术领域拥有深厚经验，还是希望将相关经验应用于新行业，欢迎加入我们的团队，与我们携手开创更美好的前进之路。

职位概述

作为一名前沿部署工程师，您将站在创新的最前线——直接嵌入领域专家、产品和工程团队，快速设计、构建架构、制作原型并部署解决方案，以解决高优先级的业务问题。这不是一个交付周期漫长的传统工程岗位。您需要在数天而非数月内将概念转化为可运行的原型，同时保持企业级的质量、安全性和可扩展性标准。

您将具备卓越的综合能力：在 AI Agent 和全栈开发方面拥有深厚的动手工程经验，并具备赢得信任、推动共识以及在没有正式职权的情况下施加影响力的人际交往能力。您既能与高级利益相关者在白板上讨论系统架构，也能在同一天下午编写生产代码。您拥有在 AWS Agent Core 等平台上开发 Agent 的直接经验，并能在快速、充满不确定性的环境中茁壮成长，因为在这里创造性思维和执行速度至关重要。

主要职责

解决方案设计与架构

  • 主导复杂、跨职能的数据与 AI 问题的解决方案设计——从初步探索到技术蓝图
  • 向技术与非技术受众定义并传达架构决策、权衡取舍和交付方案
  • 设计可扩展的模块化系统，在速度需求与企业级的可靠性、安全性和可维护性标准之间取得平衡
  • 参与架构评审，确保与企业级架构模式和平台标准保持一致
  • 编写清晰的技术文档：架构图、数据流图、API 契约和解决方案简报

快速原型设计与解决方案交付

  • 在紧凑的时间周期内（通常为数天至数周），为复杂的数据与 AI 问题设计并交付可运行的原型
  • 在极少指导的情况下，将模糊的业务需求转化为具体的技术解决方案
  • 在交付速度与企业标准之间取得平衡——你的原型是可用于生产的，而非一次性产物
  • 根据产品经理、项目负责人和终端用户的直接反馈，持续迭代解决方案
  • 开发直观的前端界面和仪表盘，让业务用户能够直观地使用数据和 AI 输出
  • 运用出色的 UX 直觉简化复杂流程，使 AI Agent 的输出对非技术利益相关者而言易于理解且可操作

AI Agent 开发

  • 设计、构建并部署 AI Agent 和多 Agent 系统，实现复杂工作流的端到端自动化
  • 开发和维护 Agent 技能——离散、可复用的能力，可组合成更大的 Agent 流水线
  • 实现和扩展 Model Context Protocol（MCP）服务器与客户端，将 AI Agent 与企业工具、API 和数据源连接起来
  • 设计评测框架、防护机制和监控流水线，确保 Agent 在生产环境中的可靠性与安全性
  • 紧跟快速发展的 Agentic AI 领域，主动向团队引入新技术和工具
  • 将 LLM、RAG 系统和 ML 模型集成到生产工作流中

协作与利益相关者沟通

  • 直接融入产品、项目和工程团队，共同定义问题、共同交付解决方案
  • 在不依赖正式职权的情况下影响技术方向，并促成跨团队共识
  • 以清晰的方式向非技术业务利益相关者传达复杂的技术概念——包括书面沟通、会议和高管汇报
  • 指导并提升初级工程师的能力，分享 Agentic 开发、提示词设计和快速交付的模式与实践
  • 营造协作、低自我意识的团队文化，让速度与质量相辅相成

任职资格

关键技能

  • 8 年以上专业软件工程经验，包括解决方案设计和架构主导
  • 具备端到端系统架构设计能力——从需求到部署——并配有清晰的文档和利益相关者沟通
  • 具备构建 AI Agent 的实战经验，包括定义 Agent 技能、工具使用、记忆和多步推理
  • 具备 AI 增强工程（Harness Engineering）经验——日常积极使用 Claude Code、Codex 或同类助手等工具来加速编码、文档编写和问题解决
  • 具备 AWS Agent Core 或同类产品的直接经验——在生产环境中构建、部署和运维 Agent
  • 熟悉模型上下文协议（MCP）——包括构建或使用 MCP 服务器将 AI Agent 与外部系统连接
  • 具有使用 LangChain、LangGraph、AutoGen、CrewAI 或 Semantic Kernel 等 Agent 框架的经验
  • 精通 Python 以及至少一种前端框架（React、Vue.js 或 Angular）
  • 具有云平台（AWS、Azure 或 GCP）使用经验
  • 出色的沟通和人际交往能力——能够快速赢得信任，从容应对模糊性，并推动不同团队之间达成共识
  • 能够适应快节奏、优先级多变且高度强调主人翁意识的工作环境

加分技能

  • 具有 RAG 架构、向量数据库（Pinecone、Weaviate、pgvector）和语义搜索方面的经验
  • 熟悉提示词工程、微调和 LLM 评测技术
  • 具有 Agent 可观测性和追踪工具（LangSmith、Arize、Weights & Biases 或类似工具）的使用经验
  • 具有容器化和 CI/CD 实践经验（Docker、Kubernetes、GitHub Actions）
  • 具有房地产、金融服务或其他数据密集型企业领域的背景
  • 具有主持技术需求调研研讨会、设计冲刺或架构评审的经验
