Bella · AI Agent 的整合营销实地调研

原标题：Bella · An Agent’s integrated marketing fieldwork

AIelsen Agent Field Notes · 约 16 分钟读完

摘要

本文记录名为 Bella 的 AI Agent 参与一次完整产品发布营销的全过程：从关键词整理、竞品对比、FAB 提炼，到页面与 FAQ、TVC 脚本评审、创意概念图，再到上线后的运营答疑与版本维护。核心观点是各阶段判断相互衔接，前期建立的产品认知持续服务于后续真实用户反馈，而非一次性生成演示。

要点

  • Bella 作为 AI Agent 全程参与产品发布营销，而非单次生成演示。
  • 竞品对比曾因依赖搜索摘要被退回，改为按品类共同维度重建。
  • FAB 工作把功能转化为针对创作者、工作室、新手等不同人群的利益点。
  • 产出包括关键词分层、FAQ 框架、直播框架、评审要点与创意概念图。
  • 上线后继续根据用户评论组织答疑内容并维护视频版本。

从实地工作到持久的业务能力。前沿部署工程

现场智能体 · 实地笔记 01整合营销 / 持续协作 / 真实交付物

Bella——

帮助完成一次完整的产品发布。

从最初的简报开始，历经产品调研、FAB、营销策略、文案和电视广告，再到发布后的运营改进。

一份营销工作记录，超越了单次精修的生成演示，贯穿了真实反馈的持续迭代。

视觉对比只展示了工作的一部分。更大的故事是一个阶段做出的判断如何塑造下一个阶段的产出。

01 / 任务

购买理由必须清晰。

这个项目服务于创作者和小型工作室。产品结合了硬件、材料、软件和多种创作方式，因此营销挑战远不止写好文案。

创作者在意表达自由，小企业主在意订单和工作流程，初次使用者则在意如何上手。一张规格表无法回答所有人的问题。

产品信息、页面、常见问题、广告、直播和影片是相互关联的工作。功能名称、承诺的边界和核心卖点需要持续对齐。

持续整理产品和市场信息，把事实转化为营销判断，再把判断转化为可用的资产，然后利用团队反馈和发布后的问题来修订下一轮工作。

02 / 完整工作流程

一套持续推进的工作成果。

下面的工作流程根据项目记录重建，已去除客户和商业信息。展开每个阶段，查看其输入、关键判断、行动以及对下一步的影响。

把一份关键词表的需求转化为后续营销工作的起点。

  • 输入
  • 产品资料、阶段性目标和一项关键词任务。信息分散在培训材料、文档和对话中。
  • 判断
  • 如果一开始不明确产品边界、目标用户和相邻类别，关键词、FAB 和后续广告都可能偏离方向。
  • 行动
  • 区分规格、功能、使用场景、用户问题和待定事项。构建关键词矩阵，然后整理产品规格、用户画像和初步的 FAB 结构。
  • 交付物与交接
  • 关键词矩阵、产品信息表和初步卖点结构，成为后续调研、内容和广告建议的共同基础。

关键价值：把一个孤立的需求转化为后续任务可以持续使用的工作简报。

从搜索摘要和内部卖点转向完整规格和品类标准。

  • 收到的反馈
  • 第一版竞品对比覆盖的维度太少。问题不仅在于缺少条目：它过度依赖搜索摘要，并用本产品的卖点来选择对比标准。
  • 关键判断
  • 有利于我们的对比未必是客户需要的对比。应先建立通用的品类标准，再逐一审视各选项的优势与局限。
  • 行动
  • 阅读完整的官方规格和用户手册。在填写各竞品之前先定义覆盖全品类的维度，保留信息来源和未知项，并对相互矛盾的数据进行交叉核对。
  • 交付物与交接
  • 更完整的竞品矩阵和差异化证据，为定位、常见问题解答和创意评审提供了比单条搜索结果更坚实的基础。

核心价值：反馈不仅改变了这份文档，也改变了今后调研的标准。

说明功能对谁有益，以及为什么重要。

  • 所用材料
  • 经核实的功能与规格、竞品对比，以及不同用户的任务和关注点。
  • 关键判断
  • 同一项能力，对创作者可能意味着更多表达可能，对工作室可能意味着更广的接单范围，对新手则可能是学习挑战。只有明确受众，益处才有意义。
  • 行动
  • 将功能映射到优势和益处（FAB）。对卖点、品牌主张和证据需求排定优先级，将未经证实的技术和商业要点单独列出，而不是把它们变成承诺。
  • 交付物与交接
  • FAB 数据层、卖点优先级、信息结构和待确认事项清单，为页面叙事、广告角度和影片呈现提供了依据。

核心价值：把“我们的产品有什么”转化为“这类客户为什么在意”。

搜索捕捉意图，内容建立理解，演示解答疑问。

  • 所用材料
  • 关键词、目标受众、产品差异化，以及从上线前到发布各阶段的信息。
  • 关键判断
  • 不同购买阶段的人需要不同的材料。在订单开放之前，交易类关键词和转化信息也需要与直播销售阶段不同的处理方式。
  • 行动
  • 为品牌类、品类意图类、交易类和竞品相关关键词推荐分层策略。围绕演示、问答、品牌介绍和互动扩展直播结构，并整理已知局限，供上线前沟通评审使用。
  • 交付物与交接
  • 广告与 SEO 关键词分层、直播执行框架和评审简报要点，让每个渠道都有明确目的，而不只是再产出一份内容。

核心价值：将内容、客户旅程和渠道动作整合为一个可执行的计划。

每个触点共享相同的事实，同时回答不同的问题。

  • 输入
  • 品牌团队的基础页面文案、产品资料，以及上线前需要解答的用户问题。
  • 关键判断
  • 主页面负责建立价值；FAQ 负责解决决策障碍。速度、后处理时间、耗材成本和维护消耗需要比“易于使用”更多的解释。
  • 行动
  • 围绕核心能力、软件工作流、配件和销售政策组织问题。标记仍需产品团队提供的规格信息，然后利用页面卖点对齐后续广告、影片和 FAQ 的措辞。
  • 交付物与交接
  • 文案协作、FAQ 框架、缺失证据清单和一致的措辞。原始品牌文案保留其署名；Agent 专注于整理、填补空白和对齐素材。

核心价值：帮助客户理解产品，同时减少跨渠道的重复解释和相互矛盾的信息。

检查每个卖点是否出现在画面、屏幕文字和旁白中。

  • 输入
  • 现有影片脚本和页面卖点文档。原始脚本已包含有力的开场转变以及桌面、家庭和艺术叙事。
  • 关键判断
  • 仅靠视觉吸引力是不够的。有些功能虽然出现了，却被技术术语掩盖；另一些则隐含在画面中，观众不会自动理解。
  • 行动
  • 将脚本内容分类为表达清晰、表达不清、隐含或缺失。针对每个缺口，明确问题、建议修改和视觉处理方式，优先考虑产品理解和购买理由。
  • 交付物与交接
  • 结构化评审、按优先级排序的修改建议和概念参考，把“这里需要更好”变成制作团队可以讨论和执行的需求。

核心价值：保留原脚本的优势，同时帮助影片承担更多营销任务。

让场景、动作、镜头细节和情感变得具体。

  • 收到的反馈
  • 创意作品需要更强的故事性、情感和可信的日常氛围。“卡片活起来”的创意需要超越文字描述。
  • 关键判断
  • “高级感”“震撼”和“温暖”不是拍摄指令。要明确谁在做什么、观众首先看到什么，以及一个动作如何让产品能力变得可理解。
  • 行动
  • 迭代桌面游戏、家庭回忆和触感艺术方向。产出第二轮概念图和魔法卡片参考，将全彩模型、个人创作和凸起纹理转化为可供评审的视觉方案。
  • 交付物与交接
  • 概念图、分镜建议和修改记录为团队提供了共同的讨论对象。项目团队负责最终的拍摄、制作和发布。

核心价值：将抽象反馈转化为人们可以指向和修改的可见创意参考。

将工作从宣传内容延伸到解答问题和维护版本。

  • 输入
  • 里程碑视频发布后的评论、常见疑虑、阶段性传播需求以及修改反馈。
  • 关键判断
  • 当用户询问软件演示或兼容性、维护和运行成本等信息时，口号无法替代证据。内容需要回答与当前决策最相关的问题。
  • 行动
  • 归纳购买障碍并提出对应的常见问题解答、演示、更新和第三方评测。参与里程碑视频的迭代，并将版本回退转化为素材完整性检查。
  • 交付物与交接
  • 增长运营建议、问题与内容的映射、视频版本以及可复用的方法。此前确认的素材在下一轮视觉修改中予以保留。

核心价值：前期建立的产品理解持续服务于真实的用户反馈。

03 / 营销判断

判断贯穿各个阶段。

制作一张表格并不难。更难的问题在于它是否能塑造信息、渠道、页面和镜头，帮助团队决定先说什么、对谁说、用什么证据说。

策略链条

  • 界定品类边界哪些能力容易被混淆？哪些差异需要解释？
  • 选择具体受众对爱好者创作者、设计师和定制制作企业来说，什么最重要？
  • 识别购买理由与障碍它能做什么？我能学会使用吗？维护起来会不会很麻烦？
  • 设定信息顺序先确立价值，再展开技术和证据。
  • 将决策转化为渠道和素材任务页面负责解释，影片负责演示，常见问题负责解答，演示负责验证。

一次真实的修正

“竞品对比需要更多维度。”

根据项目反馈转述，并非聊天截图或逐字引用。

收到这条反馈后，Bella 的任务是重建对比方法，而不只是添加几项有利的规格参数。

  • 来源深度：搜索摘要 → 完整规格和用户手册。
  • 对比逻辑：我们的卖点 → 品类共有维度。
  • 事实管理：单一结论 → 条目级来源和待解问题。
  • 下游影响：定位、常见问题解答和创意建议共享了这份更可靠的工作简报。

这些匿名示例遵循项目的工作方法，并非客户原始表格的直接复制。在三种典型能力之间切换。

FFEATURE

图像辅助模型生成

BBENEFIT

首次创作的起点

为非专业人士提供一个易于理解的第一步，回应他们“自己能否建模”的顾虑。

FFEATURE

自动清洁与温控维护

原始草稿将多项维护技术归在一起，信息堆砌，不易理解。

AADVANTAGE

BBENEFIT

减少人工维护工作

工作室关心的是为下一项任务做准备和持续运营，而不只是单个功能的名称。

机制动画加上对实际收益的清晰说明。详细 FAQ 解释清洁模式、闲置期维护和耗材使用，但不承诺堵塞绝不会发生。

FFEATURE

多种材料与模块化工作流程

不同的基材、配件和生产规格服务于不同的定制生产任务。

AADVANTAGE

服务更广泛的生产需求

将零散的样品展示转化为展示客户作品、准备工作和批量生产的流程。

BBENEFIT

将创作能力转化为服务

帮助小型工作室看到他们可以提供的定制服务，而不只是一张精美样品的表格。

具体的订单场景、工作流程演示、材料条件和成本说明。能够满足需求并不等于保证盈利。

04 / 从概念到成片

在提案和成片中均可见。

项目负责人反馈，多条建议和创意想法进入了最终制作。以下四个示例使用原始素材，探讨场景、动作和产品卖点是如何被组织的，而不仅限于视觉上的相似。

01 桌面游戏：从打印几个模型到创造一个世界

产品能力：全彩模型 + 场景搭建 / 营销任务：让创意价值变得可感知

更强的场景感与情感

互动、奇幻角色、桌面故事和温馨的氛围。

模型成为完整桌面场景中互动体验的一部分。

单个样品只能证明打印是可行的，却无法解释用户为什么想要这个产品。模型需要与用户的兴趣和情感联结产生关联。

在原有的父子桌面游戏主题基础上，Bella 将关于故事、魔法和角色动作的反馈转化为第二轮概念图，供团队讨论。

桌面游戏世界和互动叙事得以保留，通过地形和成组的角色传达创作自由。最终成片并未逐帧复刻概念中的喷火特效场景。

从展示物品到展示其用途。技术能力通过这些模型所能创造的体验变得易于理解。人的互动和完整的世界将叙事串联起来。

02 家庭记忆：为软件能力赋予情感归宿

产品能力：图像转三维物体 / 营销任务：让流程更易理解、更易上手

同样的价值，不同的呈现方式

将日常照片、画作和个性化物品汇聚在一起。

一张家庭照片变成三维场景，让建模的结果清晰可见。

仅凭软件名称和“AI 建模”这样的说法，很难让人形成具体印象。新手需要明白从哪里开始、最终能得到什么。

评审发现软件术语堆叠过多，建议理清创作流程。概念方案随后将家庭照片、孩子的画作和日常物品置于使用场景之中。

成片展示了拍照、生成模型、制作一件三维家庭作品的过程。它延续了将个人记忆转化为实物的价值；其中的人物和产品形态并未完全复刻概念方案。

图像生成和家庭叙事在原剧本中已经存在。这一阶段的贡献在于更清晰的表达和更具体的场景设定。画面中的纯色色块遮盖了设备的小字信息。

03 触觉艺术：把一项技术规格变成走近细看的理由

产品能力：凸起的纹理与色彩 / 营销任务：让差异在视觉上易于理解

场景 + 细节证据

艺术品、观看者与近距离审视的动作共同营造出艺术鉴赏的体验。

放大镜与微距细节让“立体感”变得可见。

单凭纹理高度很难想象。规格需要转化为表面起伏、光线以及观看的动作。

沿用原作艺术与近距离审视的方向，Bella 补充了场景参考、纹理特写和比例建议，使触感成为具体可执行的视觉要求。

画廊为物品赋予艺术语境；放大镜强调纹理细节。场景与特写相结合，解释了它为何值得关注。

场景赋予意义；微距镜头提供证据。创意工作超越了“色彩丰富”，展示这些作品是如何被创作、陈列和欣赏的。

04 透明材质：让一个缺失的差异点变得可见

产品能力：透明与色彩的结合 / 营销任务：补全一项重要能力的说明

从评审缺口到视觉呈现

建议增加透明模型，以免遗漏一项重要能力。

透明外壳与彩色内部结构让这一组合能力一目了然。

评审发现，一项重要的透明材质能力没有被清晰展示。若只聚焦于全彩，就会遗漏另一个创意可能性。

增加透明模型和基于对比的视觉参考，将抽象的材质能力转化为观众看得见的实物。

发布的影片中包含一个结合透明与色彩的镜头。其物品与概念参考不同，但传达了同样需要更清晰说明的能力。

这些对比展示了环环相扣的协作过程：原始脚本、评审、讨论、概念与最终制作层层递进。建议落地执行体现了价值；整个营销活动的连贯性始终是核心故事。

05 / 文案要发挥作用

以及观众能理解什么。

TVC 评审将页面卖点与影片呈现进行了对比。下方的“原状”与“建议”描述为匿名摘要；相关观察已对照发布的影片和页面进行核实。最终的个别文案并非简单归功于某一个人的原创写作。

保留

已经清晰

保留有力的镜头和有效的叙事，不为改变而改变。

阐明

有呈现但不清晰

解开技术术语，并解释用户为何应该在意。

让其可见

隐含在画面中

添加必要的标注或动作，而不是让观众自行推断含义。

补充

尚未覆盖

按重要性顺序填补空白，同时不要把影片变成一份规格清单。

修改前

多个软件名称和“AI 建模”被挤在同一个屏幕文字元素中。

建议

展示从图像到模型再到成品的步骤，并说明这对入门者的价值。

发布观察：在 01:20–01:28 左右，影片展示了一张照片变成模型的过程，并说明初学者可以开始创作。页面则单独介绍了创意软件和多种输入方式。

修改前

自动清洁、温控和供墨机制同时出现，但缺乏足够的讲解。

建议

用机制动画展示维护流程，随后明确说明这能减少手动维护工作。

发布观察：在 02:24–02:32 左右，影片将清洁和加热与降低堵塞风险联系起来。页面标题也强调了维护工作量。

修改前

原始评审发现透明材料的展示缺失，导致差异化说明不完整。

建议

直接用透明物体展示；材料能力不应只停留在规格表中。

发布观察：在 00:26–00:30 左右，影片清晰地展示了透明与色彩的结合；页面也为这一能力单独设置了板块。最终制作团队选定了具体的展示物体。

修改前

虽然有纹理规格，但观众对厚度、表面和效果缺乏直观感受。

建议

增加特写和参照物，让浮雕清晰可见、纹理可以想象。

发布观察：在 03:21 左右，影片使用放大镜检查细节；页面用放大区块展示纹理。最终呈现并未完全复刻概念稿中的比例参照。

修改前

多种配件和材料隐含在样品中，但它们的各自用途未被说明。

建议

将模块、材料和任务关联起来，让工作室能够理解这些产品可以满足的定制生产需求。

发布观察：在 01:56–02:10 左右，影片按顺序串联了客户照片、定制物件、批量生产和模块扩展。

修改前

原始脚本有一个以形态变化为核心的强力开场，但需要更清晰的主旨信息和更有情感共鸣的结尾。

建议

用开场确立创作范围的广度，用结尾回归人们能够实现的成果，而不是重复罗列功能。

发布观察：影片以不同的创作形式开场，以让更多人能够进行创作的价值收尾。最终口号与提案版本不同，不能算作逐字采用。

推荐内容也可能出现在页面上，而不进入主片。例如，文生模型的生成内容在页面上有单独的板块。一个完整的营销活动要考虑信息如何到达合适的媒介，而不仅仅是它是否出现在某一部特定的影片中。

06 / 发布之后

持续把用户的问题转化为内容。

Bella 的工作在营销交付物移交之后仍在继续。发布后的问题、反馈和新的传播任务都汇入同一套产品理解与内容体系。

01 / 阅读问题

  • 这款软件究竟是怎么运作的？
  • 耗材和日常使用的成本是多少？
  • 配件、材料和模式是否适合我的任务？
  • 空闲期间和日常维护需要做些什么？

02 / 选择应对方式

  • 操作不清晰 → 持续性的演示
  • 信息不清晰 → FAQ 和适用范围说明
  • 信任不足 → 实测和第三方评测
  • 理解存在缺口 → 更新、图解和针对性问答

03 / 更新工作

  • 确定还需要补充哪些镜头和证据
  • 把反复出现的问题带回内容结构中
  • 统一团队的对外表述
  • 保留版本记录和下一次复盘事项

这些问题成为可复用的工作要求，而不是被隐藏起来。

调研质量

第一轮调研暴露了维度和信息来源上的缺口。改进方法是先定义品类标准，完整阅读材料，再解决冲突和未知项，而不只是增加更多搜索结果。

沟通质量

“让它感觉更有力量”需要转译成镜头、动作、道具、空间和情绪。视觉参考让项目负责人和制作团队有了具体可讨论的对象。

版本质量

里程碑视频的迭代中曾出现已确认素材的回退。这促使我们建立了内容完整性检查、版本标签和发布前的人工审核。

07 / 协作模式

团队共同交付。

一体化营销能力意味着理解并串联多个专业环节。Bella 负责调研、整理、建议和创意产出；人和团队负责关键决策并执行最终制作。

业务负责人

确定业务方向，提供并确认产品事实，判断优先级，给出创意反馈，决定取舍和对外承诺。

持续性营销工作

延续上下文，调研并核实信息，构建 FAB 和内容结构，提出策略建议，协作撰写文案，审阅脚本，产出概念，跟进反馈并沉淀可复用的方法。

制作与发布

提供现有的创意和内容；执行产品工作、拍摄、设计和后期制作；然后在项目约束内创建并发布最终素材。

Agent 的商业价值在于在各阶段之间传递信息、判断、素材和反馈，减少重复解释、信息传达断层和交接损耗。它并不意味着替所有人完成工作。

08 / 哪些内容可以复用

可以从一套成熟的工作方式入手。

客户的素材无法复制，但工作方法可以复用。将营销活动经验拆解为可交接、可审阅、可复用的模块，比仅凭几条好的提示词能保留更多价值。

可编辑的 Markdown 模板 · 不含客户原始素材

  • 需求简报与事实清单目标、受众、素材、产品边界、负责人和待解决问题。
  • 调研与竞品对比品类维度、官方来源、差异证据、相互矛盾的信息和未知事项。
  • FAB 与信息结构特征—优势—利益—证据—受众—渠道。
  • 营销素材清单页面、广告、FAQ、评测、直播和影片各自的职责。
  • 脚本与创意审阅卖点覆盖与清晰度、镜头如何提供证据，以及反馈如何转化为修改。
  • 上线反馈与版本更新用户障碍、下一步所需证据、内容更新、素材完整性和版本核对。
Agent 的实战工作不只是把一条提示词变成一个文件，而是推动一整套工作成果向前推进。

对于正在发布产品、解释复杂功能或跨渠道协调内容的团队，本案例展示了一种实用的分工方式：Agent 持续贡献，而专业判断和人工反馈仍然是流程的一部分。
