摘要

这是日本公司クラシル（Kurashiru）在招聘网站 OpenWork 上发布的 FDE 职位信息。该公司以食谱视频应用「クラシル」（累计下载约4,400万次）起家，正推出面向食品制造商、批发商和零售商的 AI Agent 平台「Kurashiru AI OS」。该 FDE 岗位需深入食品流通现场，针对仍依赖传真、纸质文件和 Excel 的手工作业流程，利用 AI Agent 推动业务自动化，负责从需求梳理、原型开发到上线运营的全流程。要求五年以上 Web 开发经验、熟悉 LLM API 及 Claude Code 等 AI 驱动开发。年薪1,000万至2,000万日元，弹性工作制，可远程办公。

要点

  • クラシル招聘食品流通行业 FDE，用 AI Agent 自动化传真、纸质与 Excel 手工作业。
  • 岗位覆盖从现场问题定位、原型到生产落地与持续改进的全流程。
  • 要求五年以上 Web 开发经验，熟悉 LLM API 与 AI 驱动开发工具。
  • 年薪1,000万至2,000万日元，弹性工作制，支持远程与副业。
  • 公司依托「クラシル」等 toC 产品的用户与数据基础切入 B2B AI 业务。

  • 职位名称
  • [开发] Forward Deployed Engineer（FDE） / 面向食品流通行业的 AI Agent（665803）
  • 工作内容
  • 在运营“Kurashiru”的本公司新项目中，招募 Forward Deployed Engineer（FDE），深入食品流通行业（制造商、批发、零售）中仍残留着大量依赖传真、纸质文件和 Excel 的手工作业的现场，推进利用 AI Agent 实现业务自动化。 随着 Coding Agent 的进化，软件实现本身已不再是瓶颈。对工程师所要求的附加价值，已转变为深入理解客户面临的本质性课题，并将其落实到从需求定义到具体解决方案的设计与实现。 在本职位中，你不仅要作为拥有全栈开发能力的 Builder 实现产品，还需要亲自深入客户现场，深入理解业务和课题。从课题的识别、原型制作、生产环境实现，到导入后的落地与改善，你将端到端地承担这一系列流程。 - 识别客户的现场课题 通过对客户的访谈和对现场的理解，对复杂的业务流程进行结构化梳理，在识别出本质性课题的基础上，提出具体的解决方案。 - 解决方案的设计 基于 PoC 中获得的验证结果，组合 AI-OCR、非结构化数据管道等技术，设计面向实际运营的系统。 - 全栈开发 最大限度地活用 Coding Agent，从前端、后端到 AI Agent Harness 的构建，端到端地实现所需功能。 - 运营、落地与持续改善 通过设计护栏（Guardrail）和微调等手段，运转实际运营中获得的反馈循环，最大化向客户提供的价值。
  • 期望的经验与技能
  • Web 应用开发经验（5 年以上） 使用 REST API 和数据库（RDB）进行后端设计与实现的经验 利用 LLM（OpenAI API、Claude API 等）开发应用的经验 实践过使用 Claude Code/Codex 等进行 AI 驱动开发的经验（个人或工作均可） 能够用日语顺畅地进行业务沟通的能力
