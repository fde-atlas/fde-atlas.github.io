AWS 为 Agentic AI 推出 FDE 认证

原标题：AWS lanceert FDE-certificeringen voor agentic AI

AWS lanceert FDE-certificeringen voor agentic AI · 2026-10-08 · 约 1 分钟读完

摘要

AWS 在 Partner Network 中推出面向 agentic AI 的 FDE 认证，提供 Ground、Orchestrate、Prove 三个免费学习路径，涵盖数据接入、工作流编排与评测安全。认证分 FDE Validated 与 FDE Advanced 两级，不采用选择题考试，而是要求候选人持有有效 AWS 认证并在 AWS 搭建的环境中完成实操任务。此举配合 AWS 此前宣布的十亿美元前沿部署工程组织投资，旨在提升合作伙伴可靠、规模化部署 AI Agent 的能力。

要点

  • AWS 推出 Partner-Led FDE 认证，聚焦 agentic AI 交付。
  • 三个免费学习路径：Ground、Orchestrate、Prove。
  • 认证分 FDE Validated 与 FDE Advanced 两级。
  • 考核为实操形式，需持有效 AWS 认证。
  • 配合 AWS 十亿美元前沿部署工程投资。

全文

Amazon Web Services 扩展其合作伙伴网络，为希望在生产环境中交付 Agentic AI 的开发者提供三个专项学习路径和认证。该举措与前沿部署工程组织的成立相呼应，AWS 此前已宣布为此投资十亿美元。

通过所谓的合作伙伴主导的 FDE 方法，AWS 希望提升合作伙伴组织的技术能力，以便可靠且大规模地部署 AI Agent。

通过 AWS Skill Builder 提供的免费内容聚焦三个核心领域。Ground 路径侧重于将 AI 系统与可靠的企业数据和上下文相连接。

Orchestrate 路径涵盖工作流的可靠协调、身份管理和故障恢复。

最后，Prove 路径聚焦于评测、安全、策略和人工监督，以确保生产环境中的安全性。

合作伙伴可以获得两个技能等级：FDE Validated 和 FDE Advanced。该认证并非基于选择题考试授予，而是通过在 AWS 搭建的环境中进行实操考核来颁发。候选开发者需持有有效的 AWS 认证，并完成实践任务，以证明其 AI 应用已达到企业可用的水平。
