摘要

Interview Kickstart 推出的 23 周前沿部署工程师（FDE）培训项目，面向有经验的工程师，结合 Agentic AI 技术与企业客户交付，并包含面试准备。课程由 MAANG 及顶级公司的在职 FDE 与 AI 工程师直播授课，分四个阶段：Agentic AI 基础（RAG、多智能体、评测、微调）、AI 辅助编程、FDE 交付技能（客户发现、SoW 定价、RBAC、合规交接）和六周面试训练。学员每周完成实战项目，共 8 个端到端项目加企业级毕业设计，主栈为 OpenAI Agent SDK 加 AWS Bedrock AgentCore，备选 Google ADK 加 Vertex AI 与 Claude Agents SDK 加 Azure。

要点

  • 23 周课程，分四大模块，可兼顾全职工作。
  • 覆盖 RAG、多智能体、评测、安全与成本控制。
  • FDE 模块教客户发现、定价、治理与交接。
  • 8 个实战项目加三云栈企业毕业设计。
  • 含六周针对 FDE 岗位的面试准备。

AI 工程主线

第 1 周：Agentic AI 基础与反射型 Agent

  • Agent 方程式：提示词、工具、记忆与 LLM
  • ReAct 循环与五种核心 Agentic 设计模式
  • Agentic 与自主决策的区别以及提示词工程

直播项目：CRM 线索资格判定 Agent 成果：判断一项任务何时需要 Agent——并搭建出第一个可运行的 Agent。

第 2–3 周：基于 RAG 的知识型 Agent

  • 使用 LangChain LCEL 的检索 → 增强 → 生成流水线
  • 带历史记录和幻觉防护的多轮 RAG
  • 检索与生成指标：Precision@K、groundedness

第 4 周：多 Agent 系统（规划器–执行器–评审器）

  • 基于角色的设计：编排器、规划器、合成器
  • 任务分解、路由与委派
  • LangGraph 的状态、节点、边与检查点持久化

第 5 周：对话式与多模态 Agent

  • 级联式 STT→LLM→TTS 与实时语音到语音的权衡
  • 可复用的 LangGraph 子图用于协调
  • 人在回路中的批准、审阅编辑与中断模式

第 6 周：Agent 通信协议（MCP、A2A、ACP）

  • 通过 MCP 与 FastMCP 服务器实现结构化工具访问
  • 借助有限状态机与经验证的转换实现可靠消息传递
  • 通过 Google ADK 基于 A2A 协议构建网络化 Agent

第 7 周：混合搜索与检索

  • 稀疏向量与稠密向量；k-NN、ANN 与 HNSW
  • 使用 SPLADE 实现学习型词汇匹配
  • 在 Qdrant 中使用倒数排名融合的混合搜索

第 8 周：Agent 可观测性、评测与安全

  • LangSmith 追踪以及基于精选追踪数据的评测数据集
  • LLM 评审、DeepEval 指标与 Guardrails AI
  • 使用 Presidio 进行 PII 脱敏；通过路由、缓存与批处理控制成本

第 9 周：微调与领域适配

  • 提示词 vs RAG vs 微调的升级框架
  • PEFT 全景：LoRA、QLoRA、前缀微调与适配器
  • 4 位量化、TRL SFTTrainer 以及部署到 HF Hub

实战项目：微调医疗问答 Agent 成果：掌握微调何时优于提示词工程——然后训练并发布一个适配器。

第 10–11 周：毕业项目——企业级多 Agent 系统

  • 从架构到构建，独立负责一个真实的企业问题
  • 集成检索、编排、评测、安全与成本监控
  • 像生产系统评审那样论证可靠性、延迟与成本

AI 辅助编程

第 12 周：与 Claude 结对编程

  • AI 时代真实的面试意图与问题解决思维
  • 结构化的五阶段 AI 辅助编程框架
  • Claude 生态系统：Skills、Projects、Artifacts 与 Claude Code

FDE 主线

第 13 周：客户探索与需求界定（FDE 毕业项目启动）

  • FDE 角色是什么，以及它与 SWE、SA 和 MLE 的区别
  • 90 分钟探索脚本与“展示你今天是如何做这件事的”
  • 利益相关者映射、RACI 与决策日志纪律

第 14 周：SoW、定价与解决方案架构

  • 带风险缓冲的四里程碑估算框架
  • 以评测为锚定验收标准及知识产权/数据条款的 SoW 撰写
  • 定价模型与可辩护的技术栈选择决策矩阵

第 15 周：构建生产级 Agent（OpenAI SDK + AWS Bedrock Agentcore）

  • Agent、交接、护栏、会话与沙箱执行
  • Foundry Agent Service vs 托管 Agent vs 容器应用
  • 生产加固、四种多 Agent 失败模式以及大规模 RAG

实战项目：毕业设计：将构建加固至生产级别 成果：在 AWS 上以真实负载运行经过加固的生产级 Agent。

第 16 周：API、MCP 服务器与 RBAC

  • 将 API 设计为 Agent 工具（FastAPI、OpenAPI 与幂等性）
  • 构建并加固 MCP 服务器，实现按租户隔离与审计日志
  • 认证模式：OAuth 2.0、Entra 服务主体与托管标识

第 17 周：评测、可观测性与交接（毕业设计完成）

  • 数据治理、数据驻留、租户隔离与自主性阶梯
  • 合规素养：SOC 2、HIPAA + BAA、FedRAMP、ISO 27001 与 GDPR
  • 将评测套件作为 CI 部署门禁、事故应急演练与清晰的交接

FDE 面试准备

第 18–21 周：Agentic AI 系统设计练习

  • 研究型 Agent：在面试条件下的规划、工具与防护机制
  • 在大型模式（schema）上构建可靠的文本转 SQL Agent
  • 多 Agent 协调、共享记忆与自我改进的验证循环

第 22 周：问题拆解与案例分析面试

  • 源自 Palantir 的 FDE 问题拆解/案例分析环节
  • 澄清模糊之处、进行拆解、提出 4 周的方案范围，并指出风险最大的假设
  • 10+ 场景题库、AI 辅助结对编程环节与架构追问

第 23 周：行为面试与采购–安全面试

  • STAR+ 框架与 16 道 FDE 专属行为面试题
  • 沟通权衡取舍，在不失信誉的情况下传达坏消息
  • 采购/安全模拟演练与 15 道安全题库

与讲师在直播课程中共同构建，逐步代码实操。

  • 你的第一个由 LLM 驱动的 Agent。学习 LLM 如何将函数调用作为其推理引擎、工具（领域查询、CRM 历史、线索评分）如何塑造行为，以及思考–行动–观察循环如何驱动真实决策。
  • 一个面向 IT 支持的生产级 RAG 系统，严格基于检索到的工单数据作答。涵盖 OpenAI 嵌入、分块、五种 LlamaIndex 索引方法、LangChain LCEL 管道、防幻觉保障机制、两层评估，以及带记忆的 Agentic RAG 扩展。
  • 一个 Orchestrator → 搜索 → 行程规划器 → 合成器的工作流，由专门的 Agent 搜索航班和酒店、生成行程并综合推荐。使用 LangGraph、LangChain、Tavily、SerpAPI 构建。
  • 一个基于 LangGraph StateGraph 的有状态语音助手，包含 RAG 产品发现、带 HITL 中断的订单跟踪、并行调度、MemorySaver 检查点，以及 Whisper + OpenAI TTS 流水线。
  • 一个买卖双方系统，Agent 通过类型化的 Pydantic 模式进行通信。从一个暴露十种失败模式的损坏构建开始，逐步演进为具备 FSM 终态、MCP 接地工具、LangGraph 路由以及通过 Google ADK 实现真正 A2A 传输的健壮架构。
  • 在 Amazon 的 ESCI 数据集上实现词汇精确性与语义理解的结合。使用 SPLADE 和 BGE-Large 生成双嵌入，以 HNSW 索引到 Qdrant，并通过倒数排名融合（Reciprocal Rank Fusion）进行合并。
  • 一个主管 + 专家系统，具备完整的生产级加固：LangSmith 追踪、DeepEval 指标、Guardrails AI 验证器、Presidio PII 脱敏，以及基于 tiktoken 的单次查询成本仪表盘。
  • 一个医疗问答 Agent：使用 QLoRA 微调 4 位量化的 Qwen2.5-1.5B-Instruct，将 LoRA 适配器部署到 HF Hub，并在 LangSmith 中与基础模型进行并排评估。

常见问题

1 什么是前沿部署 AI 工程师，为什么这个角色在快速增长？

前沿部署 AI 工程师这一角色将 AI 工程与面向客户的问题解决相结合。他们在企业环境中构建、部署和扩展 AI 解决方案，与客户紧密合作以确保真正的业务影响。随着 AI 在企业、GCC、产品公司和顶级初创公司中的加速普及，对能够连接技术与业务的工程师的需求正在迅速增长。

2 这个项目是为谁设计的？

两个群体，各自掌握 FDE 技能栈的一半。面向客户的工程师——客户工程师、解决方案架构师、解决方案工程师——希望获得 AI 工程的深度；以及编程或数据工程师——MLE、数据工程师、数据科学家、后端 SWE，以及编程方向的技术负责人、TPM 和 EM——希望掌握客户探索、范围界定和交付的技能。两者最终都将掌握完整的技能栈。

3 我需要具备 AI 或机器学习方面的经验吗？

不需要。本项目首先帮助学员打下坚实的现代 AI 工程基础，包括 Agent、RAG、多 Agent 系统、评测和企业 AI 概念。建议具备软件工程背景和 Python 的实际应用知识。

4 这个项目与其他 AI 项目有何不同？

大多数 AI 项目专注于构建 AI 应用。本项目更进一步，教你如何在企业环境中设计、部署、集成和扩展 AI 解决方案，同时培养前沿部署 AI 工程岗位所需的面向客户的技能。

5 实时指导项目与毕业设计有什么区别？

实时引导项目是在直播课程中与讲师一起逐步构建的。毕业项目是一个独立的 AI 项目，你将在导师指导下应用所学知识，类似于解决一个真实的客户项目。

6 该课程如何授课？

该课程包括讲师直播授课、每周引导项目、动手实践作业、面试准备，以及用于巩固关键概念的自学资源。

7 我每周需要安排多少时间？

预计每周需要投入约 10–12 小时，包括直播课程、作业、项目和自学练习。

8 我将学习哪些工具和技术？

你将使用 Python、LangChain、LangGraph、LlamaIndex、MCP、OpenAI、Anthropic、Gemini、FastAPI、Docker、AWS、Azure、GCP、向量数据库、评测框架以及企业 AI 部署工具。

9 什么是多技术栈毕业项目覆盖？

你将在多个领先的 AI 生态系统中构建毕业项目，帮助你获得 AWS、Azure 和 Google Cloud AI 平台的实践经验，从而为多样化的企业环境做好准备。

10 我可以选择自己的毕业项目吗？

可以。你可以从受行业启发的 AI 项目中选择，或提出自己的想法，并在导师的指导下确保项目在技术上可行且与行业相关。

11 我会学习何时不该使用 AI Agent 吗？

会。你将学习何时 Agentic AI 是正确的选择，何时传统软件、工作流或机器学习方法更有效，以及这些决策背后的推理逻辑。

12 我构建的系统将达到怎样的生产就绪程度？

你将构建以生产为导向的 AI 系统，融入真实组织中常用的评测、可观测性、安全、治理、部署和生产集成实践。

13 这能帮助我转型到前沿部署 AI 工程岗位吗？

可以。该课程通过 AI 系统设计、编程、案例分析讨论、行为面试准备以及符合领先科技公司、GCC 和 AI 创业公司招聘实践的模拟面试，帮助你准备前沿部署 AI 工程面试。

14 讲师的资质如何？

你将向来自 MAANG 及其他领先全球科技公司的现任和前任 AI 工程师、解决方案架构师和前沿部署工程从业者学习，他们都拥有构建企业 AI 解决方案的实战经验。

15 会有作业或考试吗？

该课程以项目为导向，而非以考试为导向。每个模块都包含旨在强化你的工程和系统设计技能的实践作业和动手构建任务。

16 如果我错过了一场直播课程怎么办？

所有直播课程均会录制，供您日后观看。您还可以获得讲师支持、讨论区和学习资源，帮助您保持学习进度。
