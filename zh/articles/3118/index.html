摘要

Plank 推出的免费 FDE 培训课程，面向会 TypeScript 和 Node.js 的全栈工程师。学员在 40 天内以 FDE 的方式构建并上线一个生产级 AI 产品 WorkBot，全程使用 Claude Code、Codex CLI、OpenCode 等 coding agent 开发，技术栈覆盖 Anthropic 与 OpenAI 双供应商、LangGraph.js、MCP 等。课程免费，验证和公开档案也免费，学员自付模型与云费用；完成后的已验证档案可作为求职 Plank FDE 职位的作品记录。

要点

  • Plank 提供免费 40 天 FDE 培训，8 周内完成
  • 学员全程用 coding agent 构建并上线 AI 产品 WorkBot
  • 技术栈不锁定供应商：Anthropic 与 OpenAI 并用，含 LangGraph.js 与 MCP
  • 内容涵盖聊天、语音、Agent、RAG、评测、集成、安全与部署
  • 每日通过 GitHub 仓库验证，完成后的公开档案可用于申请 Plank 的 FDE 职位

使用 AI 与构建 AI

使用 AI

你的工作方式。编码 Agent（Claude Code、Codex CLI、OpenCode）负责规划、编写、测试和审查代码。你负责明确需求、引导方向并做出决策。你从一个 Agent 和一个 pull request 循环开始。到第 5 周，你将通过积压任务运行一组 Agent，由评测和合并队列决定哪些可以合并

构建 AI

你交付的内容。产品中的模型：聊天与语音、带工具的 Agent、带引用来源的搜索问答、文档的读取与理解，以及能在其他系统中执行操作的集成。测试、评测、追踪和部署使其在生产环境中稳定可靠

使用 AI 是你每天的工作方式。构建 AI 是大多数日子里为 WorkBot 添加的内容。

你将学到什么

  • 与编码 Agent 协作
  • 把 Claude Code、Codex CLI 和 OpenCode 当作你的开发团队。Agent 编写规格说明、pull request 和代码审查。多个 Agent 在 git worktree 上并行工作，随后 50 个 Agent 同时处理积压任务
  • 聊天与语音助手
  • 在网页以及 Slack、WhatsApp、短信和 iMessage 上的流式聊天。能倾听、说话并处理打断的语音。由组件目录组合而成的界面
  • 会使用工具的 Agent
  • 能搜索、阅读、浏览并执行操作的 Agent，记住重要事项，并相互交接工作。同一个 Agent 用 3 种框架构建，供你选择其一
  • 公司知识搜索
  • 探索知识库、政策与手册的检索，并带引用来源回答问题。你将其与普通检索进行对比衡量
  • 文档、图像与电子表格
  • 从 PDF、扫描件、信函、发票和电子表格中提取结构化数据，并在关键环节由人工审核
  • 能执行操作的集成
  • 将 Agent 连接到 CRM、工单系统、日历和 GitHub。规则在模型之前生效，每个操作都有试运行，并且可以安全重试
  • 在两家供应商上运行
  • Anthropic 和 OpenAI 位于同一层之后，每个任务路由到其中之一，并在其中一个宕机时启用备用方案
  • 评测与生产环境
  • 每个拉取请求都进行测试和评测，按客户进行追踪和成本核算，角色与权限管理，以及针对提示词注入的防御
  • 架构与部署
  • 一种让新客户只需配置、无需改代码的设计。队列与事件。使用 Terraform 部署到托管平台和主流云平台。为受监管客户提供隔离，并按照操作手册交付到客户自己的云账户
  • 研究、增长与分析
  • 部署过程中的用户研究、一个可供答案引擎引用的网站、合规范围内的对外推广，以及一套带有可展示其 SQL 的 Agent 的分析技术栈

你要构建的东西

WorkBot 是一款面向公司运营、财务和支持团队的 AI 助手与工作流引擎。它同时也服务该公司自己的客户。员工通过网页应用、Slack 和语音与它交流。客户则通过 WhatsApp、短信和 iMessage 与它联系。

WorkBot 依据公司的知识库和政策回答问题，并注明来源。它接收来自电子邮件、文档和工单的工作，并应用公司的规则。它会让人员审批重要事项。它在公司已有的系统中执行操作：用于客户记录的 CRM、工单系统，以及用于财务和运营的 ERP。管理控制台让每个客户无需编写代码即可完成配置。在适当的时候，它会转交给人工处理。

你从第一天起就开始构建它，并且每天不断完善。

WorkBot

公司内部的运营、财务和支持团队，以及他们所服务的客户

在公司的各个系统中运行其工作。聊天和语音助手依据知识库和政策回答问题，并附引用来源。它接收电子邮件、文档和工单，应用固定规则，请求审批，并在 CRM、工单系统和 ERP 中执行操作。管理控制台对其进行配置，并在适当的时候转交给人工处理

教授内容：聊天和语音界面、何时应拒绝回答、图像和文档作为输入、记忆、多渠道、集成、角色与权限、隔离每个客户的数据、能在重启后继续运行的工作流、通过配置即可接入新客户、隐私规则下的个人数据，以及部署到客户自己的云环境

你在此过程中构建的功能，例如：

  • 一个聊天助手，依据公司政策和文档回答员工的问题，并展示答案的出处
  • 一条支持电话热线，能倾听、回应，并根据通话内容创建工单
  • 从 PDF 或照片中读取发票，提取其字段并路由以供审批
  • 一个调查工单的 Agent。它会搜索过往工单和知识库，查询 CRM 并起草回复
  • 等待人工审批的工作流，能在服务器重启后继续运行，并在完成后发送通知
  • 一场从网页开始、在 WhatsApp 或 Slack 上继续的对话
  • 一个管理控制台，客户在其中设置自己的规则，这样下一个客户只需通过配置即可完成设置
  • 由模型根据描述生成的仪表盘和表单
  • 整个系统通过脚本部署到一个全新的云账户中，并附带一份他人可以照着执行的运行手册
  • 一个能回答业务问题并展示其运行 SQL 的分析助手

检查点

每一天都以功能合并进 WorkBot 结束，并且每天在进入下一天之前都会从你的代码库进行验证。第 3 天是检查点：中期设计、交付到客户账户，以及最终发布。

  • 第 20 天架构设计与产品思维一份 2 到 3 页的架构文档、一份一页纸的功能提案，以及一场 5 分钟的带问答环节的路演。
  • 第 37 天用户研究，并交付到客户云环境由他人按照运行手册将 WorkBot 部署到一个全新账户并运行冒烟评测。访谈和可用性调研结果会连同证据一起写成文档，并归入配置和待办事项。
  • 第 40 天最终发布WorkBot 上线、一份架构文档、一段 10 分钟的演示录像，以及各项数据。

第 1 天之前

提前准备

第 1 天需要用到。

  • Claude Code：从第 1 天起、在项目每一天都会使用的智能体编程工具。
  • Ghostty：支持标签页、分屏和桌面通知的终端，用于并排运行多个智能体。
  • Cursor：这款 IDE，已为 AI 辅助的 TypeScript 开发配置好。
  • GitHub：代码仓库和拉取请求；从第 3 天起使用 GitHub MCP。
  • Vercel：每次推送都进行预览和生产环境部署。
  • Codex plugin for Claude Code：标准版和对抗版的 PR 审查。
  • Node.js LTS、pnpm 和 Git：基础工具链。

常见问题

  • 什么是 AI FDE 课程？
  • Plank 提供的免费前沿部署工程师（FDE）培训：40 天内，一名全栈工程师以前沿部署工程师的方式构建并交付一个生产级 AI 产品——WorkBot。这是 Plank AI 加速器的 2 个月项目，对所有人开放。
  • 这门课程适合谁？
  • 使用 TypeScript 和 Node.js 的全栈工程师，无论处于职业生涯哪个阶段，只要想转向 AI 工程或前沿部署工程师岗位。无需具备任何 AI 工程经验。
  • FDE 培训需要多长时间？
  • 40 个工作日，在 8 周内或更快完成。第 1 周搭建 AI 驱动的开发工作流；第 2 至 8 周通过聊天、Agent、检索、语音、评测、集成、安全、基础设施以及最终发布来构建 WorkBot。
  • 课程是免费的吗？
  • 是的。每天的验证和个人资料都是免费的。你只需自行支付模型和云服务的使用费用。
  • 每一天是如何验证的？
  • 使用 GitHub 登录并关联一个公开仓库。完成一天的任务后，推送并验证：系统会对照当天应交付的内容检查自上次验证日以来的提交，并将该天连同其提交记录一起记录下来。
  • 完成后我能获得什么？
  • 部署好的 WorkBot，以及在 joinplank.com 上以你的 GitHub 用户名命名的公开个人资料，其中列出每个已验证的日子、对应的提交以及涵盖的技能。Plank 招聘前沿部署工程师，一份经过验证的个人资料是你已交付工作的记录，可以在求职申请中附上链接。
  • 该课程与 Plank AI Accelerator 有什么关系？
  • 该课程是 Accelerator 的 2 个月项目，对所有人开放，可按自己的节奏完成。完整的 Accelerator 是一个选拔性的为期一年的线下项目，最终以在 Plank 担任前沿部署工程师的职位收尾。
