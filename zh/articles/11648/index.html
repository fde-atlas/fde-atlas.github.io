摘要

本文解读 NVIDIA 与 Caltech 等团队的 Voyager 论文：用 GPT-4 在 Minecraft 中自动探索的智能体，无需微调，靠自动课程、技能库和自我验证持续进步。160 次迭代发现 63 种物品，是基线的 3.3 倍，唯一造出钻石工具的方法。作者将三个机制映射到 FDE 场景：把成功经验存成可执行的代码、存储前必须验证、按前置条件排序任务，并提醒客户内部系统不在模型训练数据中，需要更多辅助。

要点

  • Voyager 由自动课程、技能库、迭代提示循环三部分组成。
  • 技能以可执行代码存储，可检索复用且不会遗忘。
  • 160 次迭代发现 63 种物品，为基线 3.3 倍。
  • 消融显示自我验证最关键，随机课程使发现减少 93%。
  • 对 FDE 的启示：建立经过验证、可复用的技能库。

一分钟速览论文

Minecraft 没有固定目标。玩家自由探索、收集资源，并沿着从木制工具到石制、铁制和钻石工具的科技树不断攀升。Guanzhi Wang、Linxi Fan、Anima Anandkumar 以及 NVIDIA、加州理工学院等机构的研究者们构建了 Voyager，一个使用 GPT-4 玩 Minecraft 的 agent，无需 fine-tuning，并通过不断积累技能持续进步。

它由三部分组成。自动课程让 GPT-4 在给定“尽可能发现更多样的事物”这一目标、agent 的物品栏和周围环境，以及已完成和已失败任务的情况下，提出下一个任务。技能库存储每个成功运行的程序，并按其描述的 embedding 建立索引，以便后续任务可以检索并调用它：

craftStoneShovel()

,

combatZombieWithSword()

。一个

iterative prompting

循环将每个新技能编写为基于高层 Mineflayer 控制函数的 JavaScript 代码，运行它，并反馈三类信号：来自游戏的消息（“我无法制作 stone_shovel，因为我还需要：2 根木棍”）、来自解释器的执行错误，以及由第二次 GPT-4 调用充当评审者的判定——它会检查 agent 的状态，判断任务是否完成，若未完成则说明如何完成。经过四轮失败后，课程会转向下一个任务。

以代码作为动作空间至关重要。程序可以循环、等待并调用其他程序，因此技能可以组合：铁镐技能会调用熔炉和熔炼技能，而后者又会调用更早的技能。由于技能是存储而非重新训练的，旧技能不会被遗忘。

在 160 次提示迭代中，Voyager 发现了 63 种独特物品，是从 ReAct、Reflexion 和 AutoGPT 改造的基线方法的 3.3 倍，行进距离是它们的 2.3 倍，解锁工具等级的速度也快得多。它是唯一能制作钻石工具的方法。面对一个新世界和四个未见过的任务，它凭借自己的技能库全部完成。

基于语言模型构建的 agent 一次只能处理一个任务，且任务之间不保留任何东西。在 Minecraft 这样的开放世界中，无法积累技能的 agent 会永远重复学习基础知识，永远无法触及科技树的高阶部分。

让 GPT-4 根据自身状态和进展提出下一个任务，将每个技能编写为可执行程序，根据环境反馈和错误进行改进，由第二次 GPT-4 调用验证成功与否，并将验证通过的程序存入库中，按描述进行检索。

经过 160 次提示迭代，Voyager 找到了 63 个独特物品，是基线的 3.3 倍，解锁工具层的速度比 AutoGPT 快 6.4 到 15.3 倍，并且是唯一在 3 次运行中的 1 次里达到钻石工具的方法。它的技能库还帮助另一个 Agent 在新世界中表现更好。

这对 FDE 意味着什么

Voyager 是一个游戏 Agent，但它的记忆设计直接适用于为客户执行重复工作的 Agent：一个由经过验证、可复用的流程组成的库，由 Agent 在工作中逐步构建。

把有效的东西以代码形式存储。 一个经过测试的函数形式的技能可以被审查、版本化和复用。关于“我上次是怎么做的”的文字笔记无法以同样的方式被执行或检验。

存储前先验证。 自我验证步骤是消融实验中最重要的反馈。在客户环境中，验证器应尽可能是一个真实的检查：一个查询结果、一个测试、一次状态比较。一个存储失败结果的库会毒害建立在它之上的一切。

安排好工作顺序。 随机课程使发现数量减少了 93%。学习新环境的 Agent，以及将 Agent 引入新环境的人，应该从前置条件已经具备的任务开始。

了解模型已经知道什么。 GPT-4 从互联网上了解了 Minecraft：配方、物品名称、策略。客户的内部系统并不在模型的训练数据中。预期课程和代码在那里需要多得多的帮助。
