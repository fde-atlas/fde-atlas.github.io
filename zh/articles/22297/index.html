旧金山（San Francisco, CA）前沿部署工程师职位 — Column

原标题：Forward Deployed Engineer Job in San Francisco, CA — Column

Talentify · 2026-10-06 · 约 5 分钟读完

摘要

Column 是一家同时具备银行牌照与软件能力的公司，旨在简化金融科技依赖的银行供应链。其旧金山 Presidio 办公室招聘首位前沿部署工程师，年薪 13 万至 25 万美元加股权。该岗位需深入客户现场，基于 Column 的 API 帮助客户构建产品，编写生产级代码，并将一线经验反馈给工程团队以改进平台。候选人需具备后端、API 或基础设施经验，擅长沟通与项目管理，有支付或银行基础设施经验者优先，最好掌握西班牙语、法语或俄语之一。该职位直接向 CEO William 汇报，需频繁赴美国及海外客户现场出差。

要点

全文

关于 Column

对于构建金融科技并推动金融服务变革的公司而言，其增长和创新的最大瓶颈往往在于它们所依赖的底层银行和基础设施体系。我们的职业生涯中曾创立并扩展过 Plaid、Square、Meta、Blend 和 Affirm 等公司，并亲眼目睹了这一问题——构建者和开发者不得不与传统的银行合作，在银行、其核心系统以及众多其他供应商拼凑而成的体系之上构建 API 和抽象层。这一切导致了一条复杂（且往往成本高昂）的银行供应链，其中涉及用户、金融科技公司、BaaS 中间件提供商、银行、核心系统以及美联储。

在 Column，我们的目标就是简化并解决这一问题。我们是一家从零开始打造的银行兼软件公司，为构建者和开发者提供技术领先的银行解决方案，省去数百家供应商、中间件提供商和抽象层。这意味着一条更安全、更透明、成本更低的银行供应链。快来与我们一同构建吧！

这个机会：我们是一支精干且经验丰富的工程团队，正在招聘我们的第一位前沿部署工程师。你将定义这个职位在 Column 的样子。

作为一名 FDE，你将与客户深入合作，理解他们的问题，并帮助他们基于 Column 的 API 构建新产品。你在一线学到的东西将直接反馈到我们工程团队对平台的改进中。

这是一个动手实践的工程职位。你将编写代码、调试支付流程并设计集成方案，并且会花大量时间驻场在客户现场。你将深入了解从我们的 API 到美联储的完整银行体系。

该职位位于我们旧金山 Presidio 办公室，需要频繁前往美国及海外的客户现场。你将直接向 CEO William 汇报。

在这里了解更多关于 Column 的团队生活（Life @ Column）和我们的招聘流程。🚀

你的工作内容：

  • 直接与合作伙伴的工程团队合作，基于 Column 顶尖的银行体系设计、构建并发布产品
  • 作为战略客户从入驻到上线的技术负责人，帮助他们在架构、记账、对账以及资金流转的边缘情况上扫清障碍
  • 编写生产级代码，加速集成进程，并逐步沉淀为可复用的产品
  • 将一线的模式转化为产品和平台改进，与工程团队紧密合作，共同塑造我们的 API、文档和开发者体验
  • 为客户提供咨询，帮助他们在受监管的环境中构建安全、合规且有韧性的金融产品
  • 在与客户高管和工程负责人的沟通中代表 Column，建立可信赖的长期关系

我们的期望：

  • 扎实的工程基础，最好具备后端系统、API 或基础设施方面的经验
  • 产品思维：你能透过眼前的需求看到背后的根本问题，并为客户和 Column 找到最佳解决方案
  • 出色的人际交往和沟通能力。你能向工程师或高管清晰地解释复杂系统
  • 具备高管风范和自信，能够主导高风险的客户对话
  • 较强的项目管理能力。你能同时推进多个客户项目，并让每个项目持续进展
  • 自驱型心态。你能从容应对模糊性，并在尚无流程的情况下建立流程
  • 有支付、银行或金融基础设施方面的经验者优先
  • 理想情况下，能流利使用西班牙语、法语或俄语中的一种。

我们将为你提供：

  • 🏥 全面的医疗、牙科和视力保险计划，包括由 Column 为你 100% 承保、且为你的家属 100% 承保的选项！
  • 🐣 通过与 Carrot 合作提供全面的家庭计划与生育福利，包括最高 20,000 美元的合格费用报销
  • 🏡 居住在 Column 办公室 2 英里范围内的员工，每月最高可获得 2,000 美元（税后）房租补贴
  • 💳 提供 FSA 和 HSA 账户选项，可使用税前资金支付医疗和子女照护费用
  • 📈 401k 计划，包括自主经纪账户选项
  • 🌴 灵活的休假政策——按自己的需要休假，放松身心、恢复活力
  • 🧳 公休假计划——工作满 5 年即可享受最长 8 周的全薪假期，用于休息、充电和追求个人兴趣，薪资和福利全额保留
  • 👶 100% 带薪育儿假，包括生育母亲 16 周、主要照护者 12 周、次要照护者 8 周
  • 😇 每年最高 4,500 美元的临时托育费用报销
  • 🍽️ 为旧金山员工提供工作餐（午餐和晚餐）
  • 🚆 通勤福利，包括报销往返办公室的交通费用
  • 🎉 定期团队建设活动，包括年度外出团建

薪酬透明：

Column 的薪酬方案包括基本工资、股权和福利。新员工录用报价基于候选人的经验、专业能力、地理位置以及相对于同职级同事的内部薪酬公平性。

该职位在美国的年度基本工资范围为 130,000–250,000 美元 + 股权。

我们期待收到你的消息

Column 致力于从最广泛的人才库中招揽最优秀、最聪明的人才。我们重视汇聚拥有不同视角、教育背景和生活经历的团队，并相信思想的多样性正是我们开发出最佳解决方案的关键。欢迎所有符合条件的候选人踊跃申请。

如果你在申请和招聘过程中需要协助或合理便利安排，请联系 accommodations@column.com。
