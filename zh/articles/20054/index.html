前沿部署工程师 | Vooma | 加州旧金山

原标题：Forward Deployed Engineer | Vooma | San Francisco, CA

Zero G Talent · 2026-03-24 · 约 4 分钟读完

摘要

Vooma 在旧金山招聘前沿部署工程师，加入创始团队。公司为美国超 8000 亿美元的卡车运输行业打造 AI 编排平台，其 AI Agent 通过语音、邮件和短信自动化货运全流程。该职位需直接对接货运经纪、承运商和 3PL 客户，负责需求调研、方案设计、集成开发（Python/TypeScript）、测试上线及上线后 90 天内的技术支持。要求具备全栈能力、REST/GraphQL 等集成经验、LLM 与 Agent 开发经验，并接受最多 25% 的出差。投资方包括 Index Ventures、Craft Ventures 和 Y-Combinator。

要点

  • Vooma 为美国卡车运输业构建 AI Agent 编排平台。
  • 前沿部署工程师需直接对接企业客户并交付定制集成。
  • 要求全栈开发、系统集成与 LLM/Agent 实战经验。
  • 需承担上线后 90 天的现场技术支持与迭代。
  • 最多 25% 时间出差，常驻旧金山或货运枢纽城市。

关于 Vooma

企业软件正在经历一场革命。世界正在从“记录系统”转向“自动化系统”——由 LLM 驱动的 AI Agent 和编排器，能够代表人类并与人类协作执行复杂的业务任务，自主性不断提升。

Vooma 的使命是为美国 8000 多亿美元的卡车运输行业打造 AI 编排平台。我们在物理世界中接触到的一切货物都由卡车运输——它是美国经济的支柱。然而，如今的物流仍然极度依赖人工，这使其成为最渴望向 AI Agent 转型的行业之一。

在 Vooma，你将构建的产品会帮助货运经纪人和卡车运输公司赢得更多业务并无缝执行货运。我们的 AI Agent 通过语音、电子邮件和短信运作，自动化整个货物生命周期中的关键工作流程。

Vooma 获得了顶级投资者的支持，包括 Index Ventures、Craft Ventures、Y-Combinator，以及来自物流行业的 CEO、创始人和高管。

关于该职位

如果你选择加入我们，你将成为我们创始团队中的一名前沿部署工程师。

这是真正落地实践的地方。你将成为我们尖端 AI Agent 技术与支撑美国货运行业的现实世界系统之间的桥梁。你将直接与企业客户合作，设计、构建和部署定制化集成方案，让我们的 AI Agent 融入他们的日常运营。

如果你是那种无论环境如何都被同行认为能移山填海、不断推进工作的人，那你非常适合这个职位。你热衷于与客户互动，喜欢解决复杂的技术难题，并且看到自己的代码立即对价值数十亿美元的企业产生影响时会充满干劲。

你的职责包括：

  • 与货运经纪人、承运商和第三方物流（3PL）IT 团队开展需求调研会议，明确痛点、数据来源和成功指标
  • 设计端到端解决方案——梳理数据流，选择合适的模型，并创建能够经受老旧 TMS/ERP 系统考验的集成架构
  • 快速构建与交付——编写整洁的代码（Python/TypeScript），搭建 API、Webhook 和 ETL 管道，将 Vooma Agent 与客户系统无缝连接
  • 快速迭代——小步发布，在生产环境中验证，收紧反馈循环，尽早淘汰无效功能
  • 负责测试与上线——构建全面的测试套件，与运营团队一起进行 UAT，消灭边缘情况下的 Bug，推动成功上线
  • 辅导客户——记录工作流程、培训用户、创建操作手册，确保解决方案在交接后持续落地
  • 项目管理——设定切实可行的时间表、尽早暴露风险、协调跨职能利益相关者，并让高管随时掌握进展
  • 担任技术第一响应人——在生产环境上线后的关键前 90 天内，对问题进行分类处理、修补集成，并基于真实流量优化模型

必备条件：

  • 全栈构建者思维——能够自如地在后端 API 和前端界面之间切换
  • 集成专长——精通 REST/GraphQL、webhook、消息队列和身份认证方案（OAuth2、SAML 等）
  • LLM/Agent 经验——在提示词工程、向量搜索和评测指标方面有实战经验；能够将业务逻辑转化为 AI Agent 工作流
  • 客户同理心与沟通能力——能够在高管层战略讨论与一线运营技术细节之间无缝切换
  • 快速原型习惯——行动导向，愿意在紧迫的期限内进行快速开发、测试和重构
  • 结构化问题解决——将复杂的物流流程拆解为模块化组件，尽早发现边缘情况，并做出数据驱动的决策
  • 主人翁意识——遇到阻碍时主动扫清障碍，没有“这不归我管”的心态
  • 在模糊性中茁壮成长——适应不断演变的规格说明、变化的需求以及快节奏的创业环境
  • 出差灵活性——愿意将最多 25% 的时间用于现场工作，以降低部署风险并建立客户关系

加分项：

  • 在物流、供应链或运输技术领域的经验
  • 熟悉电话 API（Twilio 等）
  • 具备数据科学背景，可进行模型微调与优化
  • 曾从事面向客户的技术岗位

为什么你会喜欢在这里工作

  • 加入一支实力强劲的团队、共同打造一家基业长青公司的难得机会
  • 直接影响力——你的代码将立即改变价值数十亿美元的物流公司的运营方式
  • 前沿技术——使用现代技术栈（Next.js、GraphQL、Node、OpenAI、Anthropic）从事最新的 Agentic AI 工作
  • 有竞争力的薪酬，以及可观的股权上涨潜力
  • 全面的福利，包括医疗、牙科和视力保险
  • 在旧金山与才华横溢、经验丰富的创始团队进行线下协作
  • 以客户为中心的文化——直接与企业客户合作，亲眼见证你的解决方案带来的即时影响

该职位需在加利福尼亚州旧金山现场办公。我们也欢迎位于美国战略货运枢纽（芝加哥、达拉斯、亚特兰大）的候选人。
