AWS 为合作伙伴推出前沿部署认证

原标题：AWS launches forward deployed credentials for partners

Kernavique · 2026-10-08 · 约 2 分钟读完

摘要

据 Dutch IT Channel 2026 年 10 月 8 日报道，AWS 面向合作伙伴推出两级前沿部署工程师认证，分为 Validated 与 Advanced 两级。课程通过 AWS Skill Builder 免费提供，包含 Ground、Orchestrate、Prove 三条学习路径。考核为实操形式，在 AWS 搭建的环境中进行，并非选择题。申请者须持有有效的 AWS 认证，但报道未说明具体是哪一项。该认证与 AWS 的合作伙伴主导的前沿部署工程战略及其 10 亿美元投资相关。Kernavique 认为，这可能影响合作伙伴的岗位要求，也让客户在采购团队时有据可依。

要点

  • AWS 推出 Validated 与 Advanced 两级前沿部署认证。
  • 三条学习路径经 AWS Skill Builder 免费提供。
  • 考核为实操形式，在 AWS 环境中进行。
  • 申请者须持有有效的 AWS 认证。
  • 认证与 AWS 10 亿美元投资及合作伙伴战略相关。

2026年10月8日，Dutch IT Channel报道称，AWS面向其合作伙伴推出了两个级别的前沿部署认证。这篇荷兰语报道说，三条学习路径——Ground、Orchestrate和Prove——通过AWS Skill Builder免费提供。考核是实践性的，在AWS搭建的环境中进行，并非选择题。本条目仅基于该报道。

已发生。由Kernavique于撰写。来源：Dutch IT Channel（报道）。

发生了什么

Dutch IT Channel提到了两个认证级别：Validated和Advanced，均带有前沿部署标签。报道称，申请者必须持有有效的AWS认证。报道未说明是哪种认证。

该报道将这些认证与AWS以合作伙伴为主导的前沿部署工程模式及其10亿美元投资联系起来。报道为荷兰语，未返回直接引语，因此此处不提供引语。

如果你是前沿部署工程师

如果你在AWS合作伙伴公司工作，这表明一项有正式名称、通过实践考核的认证可能开始出现在岗位要求中。报道称首先需要持有有效的AWS认证，但未说明是哪种。

如果你在招聘他们

该报道表明，AWS合作伙伴现在可以展示经AWS认证的两个级别的人员，而不是仅凭自己的说法称其为前沿部署。这为购买合作伙伴团队服务的买家增加了一项可以提出的要求。
