Leo Mehr - Ramp 的 440 亿美元服务豪赌

原标题：Leo Mehr - Ramp’s $44B Bet on Services

Forward Deployed · 2026-08-08 · 约 1 分钟读完

摘要

Ramp 工程总监 Leo Mehr 在访谈中分享其前沿部署工程团队的实践：企业级 AI Agent 的难点不在模型，而在打通分散的内部数据系统并沉淀未成文的组织知识。他认为 B2B 公司将两极分化为 Agent 友好型 API 或贴身服务，中间地带将消亡，并讨论服务业务能否达到风投规模、大客户为何不适合作为早期共建对象，以及 AI 实验室为何难以吞并初创公司。

要点

  • Ramp 估值 440 亿美元，Leo Mehr 领导前沿部署工程团队。
  • 企业 Agent 的最大瓶颈是数据接入，而非模型本身。
  • 未成文的组织知识是部署中最难捕获的部分。
  • B2B 公司将分化为 API 或贴身服务，中间将消亡。
  • AI 实验室难以取代初创公司，关键在激励机制而非模型。

全文

为什么这在实践中很重要

企业级 AI Agent 的难点往往在于数据访问和未成文的运营知识，这也是工程团队必须贴近实际工作流程的原因。

Ramp

交付一个 AI Agent 最难的部分往往不是 Agent 本身，而是让它能够访问散落在十几个内部系统中的数据，并捕捉那些支撑公司运转却从未被记录下来的经验知识。

我与 Ramp（一家估值 440 亿美元的公司）的工程总监 Leo Mehr 进行了一次对谈。他负责前沿部署工程团队，深入大型企业，用 Agent 替换真实而痛苦的工作流程。我们聊到了为什么模型通常是最简单的部分，以及为什么数据访问是“帐篷里最长的撑杆”。Leo 还提出了一个观点：如今没有人再想购买另一款软件了——每家 B2B 公司都将变成对 Agent 友好的 API，或者为所有人提供白手套式服务，而中间地带将会消亡。我们讨论了服务型业务是否真的能达到风投级别的规模、为什么他认为 AI 实验室不会吞掉所有创业公司（关键在于激励机制，而不是更好的模型）、为什么最大的客户往往是最不适合为其构建产品的客户，以及十年前造就一名优秀工程师的特质为何已不再是如今最重要的特质。

我们聊了这些以及更多话题。这期你绝对不容错过！
