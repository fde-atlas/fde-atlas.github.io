摘要

这篇指南面向准备前沿部署工程师（FDE）面试的读者，介绍一套循序渐进的备考方法：先用免费课程了解岗位职责，再通过约15分钟的就绪评估找出知识盲区。文章按背景给出不同路径，包括后端工程师、ML工程师、解决方案工程师、在职部署AI从业者、应届生和Agent开发者，各自推荐对应课程与练习。平台资源包括5门课程、658道面试题、200篇论文解读、111家公司面试流程资料及浏览器实验室等。核心学习法是先作答再看解析，限时复述决策，反复补短板。

要点

  • 先学免费基础课，再用15分钟评估找差距
  • 按六种背景给出不同备考路径
  • 资源含658道题、200篇论文解读、111家公司资料
  • 方法：先答题再看解析，限时演练并复盘
  • 强调不必学完全站，按需选点突破

就绪度评估帮助你审视自己的覆盖情况并选择要学习的内容。它是一个规划辅助工具，并非对面试结果的预测。

约 15 分钟 · 免费，无需注册账号

从你已有的知识出发。

打开与你的背景最接近的一项，按照其中的步骤进行。这些只是建议的起点；当其他差距变得更明显时，你可以随时改变方向。

后端或全栈工程师将你的工程技能对接到客户工作中。

  • Foundations of FDE → 从免费的开篇课程开始，然后按照大纲学习。
  • One module knows their system → 免费课程：弄清哪些内容是特定客户独有的。
  • Customer and behavioural questions → 练习阐述范围、权衡取舍和交付决策。

机器学习工程师或数据科学家将模型推进到集成、服务和评估阶段。

  • The weights are the easy part → 免费课程：在选择硬件之前先算好内存预算。
  • The FDE Engagement → 跟随一个客户问题走完集成与交接的全过程。
  • Serving and cost research → 比较推理性能背后的各种机制。摘要免费。

解决方案工程师或顾问在客户对话背后构建扎实的工程深度。

  • How FDE differs from adjacent roles → 在选择备考计划之前，先阅读角色对比。
  • Foundations of FDE → 免费开始；把更多时间花在集成和生产模块上。
  • Coding and DSA practice → 在查看答案之前先自己解题。访问权限已标注。

已从事部署 AI 工作研究更难的失败模式，并为你的设计选择辩护。

  • The first 48 hours of a rescue → 免费课程：在上下文不完整的情况下恢复一次部署。
  • Production AI Agents → 从关于工作流、工具和控制的免费课程开始。
  • The research starting path → 阅读检索、Agent、评测和服务背后的证据。

学生或应届毕业生打好基础，并做出一件你能讲清楚的作品。

  • What a forward deployed engineer does → 关于该角色及其职责的公开介绍。
  • Foundations of FDE → 从免费课程开始，一次学习一个模块。
  • Try a browser lab → 选择一个免费的入门任务。无需配置机器即可练习。

构建编码或领域 Agent为 Agent 的工作明确授权、证据和恢复规则。

  • 定义 Harness 边界 → 免费课程：将模型的提案与权限和验收分开。
  • 面向 FDE 的 Harness 工程 → 跟随 38 节课和九个项目。每节课都标注其访问权限。
  • Agent 研究 → 比较 Agent 规划、工具与评估背后的证据。

学习、尝试、讲解。然后重复。

你不需要读完整个网站。选择一项技能，练习它，并用结果决定下一步。

  • 01选择重点找到差距或选择目标职位。用它来决定接下来练习什么。
  • 02学习机制跟随一门课程。当某个概念需要深入理解时，使用概念、视频和研究。
  • 03亲自尝试在阅读解答之前先作答。然后在实验或工作样本中测试同一技能。
  • 04演练与回顾在限时内讲解你的决策。回到你无法自圆其说的部分。

为任务选择合适的资源。

课程提供顺序。概念解释想法。论文让你审视其证据。选择能帮助你完成眼前工作的形式。
