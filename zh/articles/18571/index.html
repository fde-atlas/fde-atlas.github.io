FDE课程大纲：33章·9篇与实验清单

深圳市真实智元科技有限公司 · 2026 · 约 8 分钟读完

摘要

真实智元发布了一套FDE实战培训课程大纲，共33章、9篇及配套实验清单。课程以OpenAI五步交付框架（发现→原型→验证→上线→规模化）为主轴，配合FCB三级能力基准考核，包含16道考核题与48小时挑战。内容覆盖认知、角色、方法论、技术、交付、职业、考核与案例，技术篇涉及RAG、Agent、MCP协议、评测体系等，并要求实验可在无GPU、无商业API条件下完成。另设毕业项目、客服质检仿真案例及ADP、扣子、百炼等低代码平台对比，提供5天训练营、12周系统课、企业内训等四种班型。

要点

  • 课程共33章9篇，以OpenAI五步交付框架为主轴。
  • 考核含16道题库与48小时挑战，采用FCB三级能力基准。
  • 技术篇覆盖RAG、Agent、MCP、评测等，实验不依赖GPU或商业API。
  • 案例篇含客服质检六阶段推演与低代码平台对比。
  • 提供训练营、12周系统课、企业内训等四种开课形式。

第一篇 · 认知篇（第 1–5 章）

目标：搞清 FDE 从哪来、边界在哪，避免把营销叙事当职业事实。

章 标题 可测量学习目标（摘要）
01 起源与定义：从 Palantir 说起 不看讲稿 3 分钟讲清军事词源、S-1 定义与 Delta/Echo 双角色分工，同伴判定无事实错误为通过
02 为什么是现在：部署鸿沟与四股推力 画出 deployment gap 示意图（≥3 个差距来源），串起 Software 3.0 / service-as-software / margin-for-moat 论证链
03 全球 FDE 地图：谁在养这个岗位 完成起源派 / 模型厂商 / 云与 SaaS 三列组织对照表，每列 ≥2 家公司并标注来源与截止日期
04 中国 FDE 地图：大厂与模型公司的本土打法 完成七厂商对照表；复述薪资与供需比时必须同时报出来源与截止日期
05 角色边界与争议：FDE 不是什么 完成 FDE vs 相邻角色判边界卡与五维评估实操（计费方式单列记录）

第三篇 · 方法论篇（第 9–13 章）

五步法逐章展开，每章作业即 48 小时挑战对应阶段的预演。

章 标题 可测量学习目标（摘要） 对应挑战阶段
09 Discover · 需求发现 提交前五天行动清单（≥5 项标准动作）、真痛点过滤练习与第一份数据权限请求草稿 需求澄清

12 Go live · 生产上线：灰度、人在环与合规 提交四级灰度上线表，每级写全晋级条件、回滚条件、负责人三列 评测→汇报

章 标题 可测量学习目标（摘要） 实验 / 产物

17 Agent 开发：workflow 优先，agent 按需 对 2 个场景完成 workflow/agent 选型决策单；完成三级对照实验（固定 Workflow → 单 Agent → 混合） 三级对照实验报告（成本/延迟/成功率/失败模式）

21 部署与可观测：让系统在现场活得下去 完成部署形态选型单（全托管/私有化/混合）与四类可观测信号配置 可观测配置方案
22 从 Demo 到产品：AI 生成代码如何变成稳定系统 对 1 个 demo 逐条排查五条鸿沟；执行分层审查并接上双轨回归 鸿沟排查单、加固清单、回归记录

MCP与低代码平台，分别学什么？

MCP（模型上下文协议，Model Context Protocol）用于规范AI应用与外部工具、资源和提示模板的连接。低代码平台则提供应用搭建与流程编排的工作环境。课程分别练习接口连接与平台选型，再用相同的输入、输出和评测样例检查结果。

课程形式与学习安排

  • 5 天训练营：认知 → 五步法 → Prototype 日 → Validate 日 → Demo Day，对标 Palantir AIP Bootcamp。
  • 12 周系统课：周节奏 6–8 小时，作业全部来自各章 practice，期末 Demo Day 收尾。
  • 企业内训：2 天集中研讨 + 4–8 周内部项目 Residency，结合企业产品、交付要求与现有作业流程准备练习材料。
  • 伙伴 / 渠道工作坊：1–3 天，限时场景考核，对齐需求分析、方案设计、应用搭建、交付实施、安全合规五域。
