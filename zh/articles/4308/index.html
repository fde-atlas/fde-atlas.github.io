Sierra AI 对企业级 AI Agent 的 150 亿美元豪赌

原标题：Sierra AI's $15B Bet on Enterprise AI Agents

150 亿美元押注：Agent 将成为永久性品类

Sierra AI 于 5 月 4 日融资 9.5 亿美元，投后估值超过 150 亿美元，距其 3.5 亿美元融资、估值定为 100 亿美元仅过去八个月。本轮 E 轮由 Tiger Global 和 GV 领投，Benchmark、Sequoia 和 Greenoaks 参投。公司报告的年度经常性收入为 1.5 亿美元，高于 2025 年 11 月下旬的 1 亿美元，在大约 10 周内 ARR 增长了 5000 万美元。

增长速度比数字本身更重要。Sierra 在八个季度内从零做到了这一 ARR 规模，公司称这种增长速度在传统软件领域前所未有。财富 50 强企业中超过 40% 是其客户。这些正是投资者按 100 倍 ARR 估值所依据的指标——只有当你相信企业级 AI Agent 正在成为一个永久性的软件品类，而不是一个会在两年内被吸收进现有 CRM 平台的功能时，这个倍数才说得通。

企业的支出模式也印证了这一押注。Uber CTO Praveen Neppalli Naga 在 TechCrunch StrictlyVC 活动上透露，在去年年底向 Agentic AI 工具敞开大门后，公司“花爆了预算”。在大约 8000 名工程师中，目前约 10% 的代码由 AI 自主生成。一个通常需要一年的酒店预订集成，借助 Agentic 工作流在六个月内就完成了。正是这种实证案例，能把试点项目转化为采购承诺。

Sierra 的招聘也反映出同样的紧迫性。Zero G Talent 的看板显示，仅过去 7 天公司就新增了 5 个职位，包括伦敦的一个 Forward Deployed Infrastructure Engineer 职位和一个欧洲区 People Partner 职位，这表明新资金正投向国际扩张和面向客户的技术人才，而不仅仅是模型研究。这些职位分布在旧金山、伦敦以及葡语市场。

与 Clay Bavor 共同创立 Sierra 并担任 OpenAI 董事会主席的 Bret Taylor，将本轮融资形容为一场他预计终将整合的市场中的圈地运动。“竞争确实很多。我们的规模是第二大对手的数倍，并且正在积极投入，以便继续扩大领先优势，”他说。他还预测两年内市场将出现一次调整，一场会淘汰没有真实收入和留存率的公司的洗牌。Sierra 正在把自己定位为企业在洗牌到来之前就锁定合作的平台。

当一家估值 150 亿美元的公司开始将资金投入前沿部署基础设施和区域人员运营时，它是在组建团队以支持生产级的企业合同，而不是做演示。对于关注 Agentic AI 就业市场的工程师来说，Sierra 的发展轨迹是资金和岗位正在向何处集中的领先指标。

Ghostwriter 将客户体验转化为 Agent 代码

Sierra 以昂贵的方式建立了自己的业务：前沿部署工程师与每一位新客户并肩工作，手工构建客户服务 AI Agent。Ghostwriter 于 2026 年 3 月发布，是该公司的一次押注——它认为今后不必再这样做了。

该平台让非技术员工用通俗的英语描述他们希望 Agent 做什么，然后生成一个可用于生产的 Agent，覆盖语音、聊天、电子邮件以及 30 多种语言。上传 SOP、支持通话记录、领域专家的音频录音或白板照片。Ghostwriter 会解析这些材料，识别关键行为和边缘情况，并输出一个已内置防护机制的 Agent。Sierra 联合创始人 Bret Taylor 在一次公开演示中展示了这一工作流程，仅使用自然语言提示就从零构建了一个 Agent。

Ghostwriter 与市面上已有的数十种 Agent 构建工具的不同之处，在于初始构建之后发生的事情。Sierra 在发布的同时发布的《Agents as a Service》博客文章明确指出了这一区别：Agent 开发的难点不在于从零到一，而在于持续改进。Ghostwriter 会在每次变更时自动生成测试模拟，诊断失败并实施修复，无需人工调试。一个名为 Explorer 的配套工具会分析真实的客户对话，提出改进建议，并将其反馈给 Ghostwriter。Sierra 将这一循环描述为“Agent 流水线”：分析、改进、测试、验证、发布，循环往复。

在底层，该平台要求 Sierra 将自身重构为无头基础设施。Ghostwriter 需要直接访问完整的工作区、一个沙盒测试环境以及一个连贯的操作空间，Sierra 将其称为“Agent 框架（agent harness）”。正是这次重构使系统能够自主构建和修改 Agent，而不是依赖人工点击菜单和表单字段。

商业逻辑很直接。Sierra 在 2025 年 11 月的融资轮后估值达到 100 亿美元，此前每一位客户的入驻都依赖重工程的流程。The Information 指出，此次发布正值大型企业从测试 Agentic AI 转向将其嵌入核心工作流程之际。

Ghostwriter 并不会消除对工程师的需求。它改变的是工程师被需要的位置——从构建单个 Agent 转向构建和维护那个用来构建 Agent 的平台。Sierra 自己的招聘信息也反映了这一转变：该公司正在招聘 Agent 开发产品经理和前沿部署基础设施工程师，这些岗位处于平台与客户之间，而不是在每个部署项目内部。

Sierra 的开放职位揭示了企业级 Agent 工程的什么

Sierra 的招聘页面上列出了超过 120 个开放职位。仅这个数字就足以说明其规模，但这些职位的构成则告诉你“企业级 Agent 工程”到底意味着什么——而这并不是大多数招聘网站会让你以为的那样。

最大的单一类别是 Agent Engineering（Agent 工程）。Sierra 在旧金山、纽约、伦敦、新加坡、东京、巴黎、马德里、慕尼黑、多伦多和悉尼的办公室发布了大约 20 个“Software Engineer, Agent”和“Agent Engineer, TLM”的职位变体。其中许多是针对特定语言的：阿拉伯语、粤语、荷兰语、法语、德语、意大利语、韩语、西班牙语和泰语。Sierra 不是在为某一个市场构建一个 Agent，而是在构建能够以数十种语言原生运行的 Agent 系统，因此它需要能用这些语言工作的工程师来训练、评测和部署它们。

然后是平台层。在 Platform Engineering（平台工程）之下，Sierra 正在招聘 Agent Architecture、Agent Builder、Agent Data Platform、Agent Intelligence 和 Agent SDK 等职位，全部位于旧金山。这些是基础设施岗位：负责构建工具、让 Agent 工程师能够交付产品的人。一个前沿部署基础设施工程师职位横跨旧金山、纽约和伦敦，这表明 Sierra 将平台人员嵌入到面向客户的团队中，而不是集中管理。

Product（产品）部门也体现了这种分工。Agent 开发产品经理分布在旧金山、纽约、伦敦和东京，同样有针对特定语言的职位变体。但 Sierra 还列出了 Ghostwriter、Agent Studio、Agent SDK、Agent Data Platform 和 Voice 的专门产品职位，每一个都是平台内一个独立的界面。每个方向都有专人负责路线图。

缺失的职位同样能说明问题。这里没有“提示词工程师”的头衔，也没有“AI whisperer”之类的角色。其职位架构将 Agent 开发视为一个带有专业分工的软件工程学科，而不是一种提示词编写练习。Agent Engineer, TLM 职位（TLM 意为“调优与语言模型”）最接近研究侧，而且它发布在纽约和伦敦，而不是旧金山，这表明 Sierra 将其模型调优工作与特定的人才库放在同一地点。

名为 APX 的早期职业计划直接对接这一组织架构。Sierra 的招聘页面称，APX 成员“直接与客户合作，为全球领先品牌构建 AI Agent”。这不是传统意义上的轮岗项目，而是一条通往 Agent 工程的快速通道。

同一追踪数据显示，过去一周新增了 18 个职位，旧金山产品类职位的公布薪资在 15 万美元至 39 万美元之间。伦敦的前沿部署基础设施工程师职位薪资为 17 万至 29 万英镑。这些并非入门级薪资，但反映出一家公司正在同时招聘不同资历层级的人才，这也表明该组织扩张的速度快于内部晋升的速度。

剥去部门标签，一个清晰的画像浮现出来：Sierra 需要能够在生产环境中构建并交付 Agent 系统的工程师，既懂模型层又懂企业客户的产品经理，以及能与客户并肩部署的基础设施人员。Agent 技术栈已经分化出不同的工程专业方向，而构建它的公司需要同时拥有所有这些人才。

旧金山：Agent 人才的聚集地

这股 Agentic AI 招聘热潮并非均匀分布，而是呈现聚集态势，而当前最重要的聚集地就在旧金山。

Sierra AI 过去一周新增的五个职位中，有三个位于旧金山：两个面向 Agent 开发的产品经理职位（一个负责旗舰部署，一个要求掌握巴西葡萄牙语）以及一个 RFP 战略与运营分析师。另外两个职位位于伦敦。对于这家估值达 150 亿美元、企业级 Agent 领域最受关注的公司之一来说，旧金山职位占比高达 60%。

Anthropic 近期发布的职位也呈现同样的倾向。同一追踪数据显示，过去 7 天新增了 18 个职位，其中四个将旧金山列为主要工作地点，包括 Claude Code 开发者效率团队的两个资深软件工程师职位和一个领域扩展方向的研究工程师职位。其中部分职位将纽约和西雅图列为备选地点，但旧金山始终是第一个被提及的城市。

这并非新现象，但聚集程度正在加深。至少从 2023 年起，旧金山就一直是 AI 初创公司的默认发源地，当时 OpenAI、Anthropic 以及一批规模较小的实验室纷纷在此设立总部。如今不同的是职位的类型。早期湾区 AI 招聘偏向研究科学家和机器学习基础设施工程师，而当前这波热潮则面向产品：懂得 Agent 编排的产品经理、深入企业客户一线的前沿部署工程师，以及为 Agent 部署搭建 RFP 流程的运营分析师。正是这些角色，才能把一个模型变成财富 500 强企业真正愿意购买的产品。

其他中心也在竞争，但没有一个能匹敌这种密度。纽约的势力正在增长——Anthropic 在多个职位中将纽约与旧金山并列，而且该市的金融服务业是 AI Agent 工具的天然买家。西雅图受益于其传统云基础设施人才储备。伦敦正在承接面向欧洲的职位，正如 Sierra 在伦敦发布的 People Partner 和前沿部署基础设施工程师职位所示。但这些城市只是在边缘增加 Agent 职位。旧金山才是核心团队组建之地。

薪资数据进一步印证了这种吸引力：

公司职位地点薪资范围
Sierra AI产品经理，Agent 开发旧金山$180,000–$390,000
Sierra AI前沿部署基础设施工程师伦敦£170,000–£290,000
Anthropic高级软件工程师（Claude Code）旧金山$405,000–$485,000
Anthropic研究工程师，领域扩展旧金山$350,000–$850,000

这些数字不仅具有竞争力，更是一个信号：企业愿意支付溢价，将 Agent 人才集中在一个大都市区，让招聘负责人、产品负责人和构建底层工具的工程师彼此近在咫尺。

这种集中的风险显而易见：一个关键人才管道过度集中于单一地理区域会造成脆弱性。但就目前而言，引力效应正在占上风。如果你是一名想在 2026 年从事企业级 Agent 工作的工程师或产品经理，招聘信息和薪资都在指向旧金山。

还有谁在招聘——以及 Sierra 如何竞争

Sierra 并非在真空中招聘。该公司进军企业级 Agent 工程领域，正迎面撞上一个市场：Salesforce、Anthropic 以及一批资金充足的初创公司都在争夺同一小批能够构建、部署和维护生产级 AI Agent 的工程师。

Salesforce 在 Dreamforce 2025 上明确了其意图。该公司发布了 Agentforce 360，作为 CEO Marc Benioff 所称的“Agentic Enterprise”的支柱，即 AI Agent 在所有业务职能中与人类员工协同工作的模式。已有超过 12,000 家客户使用该平台，包括 Reddit、OpenTable、Adecco 和 Williams-Sonoma。其卖点是信任与集成深度：Salesforce 将其 26 年的 CRM 基础设施与 OpenAI（GPT-5）和 Anthropic（Claude）的前沿模型相结合，后者专门面向金融和医疗等受监管行业。

这种双重合作战略对人才争夺战至关重要。Salesforce 不仅在构建 Agent 工具——它还将 Agentforce 360 定位为企业数据与多个模型提供商之间的连接纽带。懂得如何在这种多模型、高合规性环境中编排 Agent 的工程师，正是 Sierra 也试图招募的人才。

与此同时，Anthropic 自己也在大举招聘。Zero G Talent 的看板显示，过去一周新增了 18 个职位，其中包括一个领域扩展研究工程师（Research Engineer for Domain Scaling）岗位，标注的年薪范围为 35 万至 85 万美元，以及多个年薪在 40.5 万至 48.5 万美元区间的资深软件工程师（Staff Software Engineer）职位。该公司与 Salesforce 的合作为 Claude 提供了进入企业工作流的直接通道，但 Anthropic 也在构建自己的面向 Agent 的工具，而 Claude Code 相关职位表明，该公司希望掌控开发者体验层，而不仅仅是提供模型。

科技巨头仍然开出最大的支票，但更精简的初创公司则在使命和股权增值空间上展开竞争。这种态势正在旧金山全面上演——Sierra、Anthropic 和 Salesforce 都在此列出职位，这里也是 Agent 专属工程人才最密集的地方。对于在 Anthropic 40 万美元的资深职位和一家上市前 Agent 初创公司的职位之间做抉择的工程师来说，考量因素不仅仅是薪酬，还在于这家较小的公司能否在平台巨头吞并整个市场之前推出产品。

Sierra 的赌注是，企业会想要一个专门的 Agent 层，而不是 CRM 的附加组件。Salesforce 的赌注是，CRM 本身就已经是那个层。现在被招聘进来的工程师将决定哪种愿景胜出。

工程师应该学什么才能在 Agentic AI 领域找到工作

招聘启事告诉你公司想要什么。而在招聘要求与大多数工程师实际掌握的技能之间的差距，正是机会所在。

Sierra 自己的招聘页面将 Agent 工程师描述为“在软件工程、前沿 AI 部署和客户最紧迫挑战的交汇点上解决问题”的人。这不是一句空洞的使命宣言，而是一张技能图谱。把它拆开来看，会出现三个截然不同的能力集群。

经得起生产环境考验的软件工程。 Sierra 招聘板上 Software Engineer, Agent 的职位说明写道，你将“构建并交付每天处理数千次客户对话的 AI Agent”。这不是研究原型。它意味着编写可扩展、能优雅地失败、并能与真实企业系统集成的代码——CRM 平台、工单工具，以及那些从未被设计为让 LLM 接触的 API。如果你的经验仅限于 Jupyter notebook，那你还没有准备好应对这一层。

LLM 编排与工具使用。 GitHub 上的开源 agentic-ai-engineering 课程（agenticloops-ai/agentic-ai-engineering）将其教程围绕 LLM API、提示工程、工具调用和 Agent 循环展开——所谓 Agent 循环，就是模型决定使用某个工具、执行它、读取结果、再决定下一步做什么的循环。Coursera 的 agentic AI 工程课程则增加了工作流编排、记忆与状态管理，以及多 Agent 协调。这些不是选修内容，而是这份工作的核心。一篇发布在 arXiv 上、关于生产级 agentic 系统的论文用生命周期术语概括了这一点：工作流分解、多 Agent 设计模式、Model Context Protocol（MCP）、确定性编排，以及环境感知部署。能够从“模型输出文本”进阶到“Agent 可靠地使用五个工具完成多步骤工作流，并在置信度下降时转交给人类”的工程师，才是能拿到面试机会的人。

面向客户的部署技能。 这是大多数 AI 工程指南都忽略的部分。Sierra 的早期职业页面明确表示，你将与全球领先品牌合作，做的正是这类工作。Exponent 为 Sierra 的 Agent Engineer 职位编写的面试指南证实，其面试流程不仅考察技术深度，还考察你如何思考客户问题，并将其转化为 Agent 行为。这意味着你要充分理解一个业务工作流，能够将其分解为 Agent 步骤，并向非技术利益相关者解释你的设计选择。

薪资数据印证了这种需求。Sierra 位于旧金山的 Product Manager, Agent Development 职位年薪为 18 万至 39 万美元。Anthropic 的 Research Engineer, Domain Scaling 职位（与 agentic 工作相关）年薪在 35 万至 85 万美元之间。这些溢价并不是给做前沿研究的博士的，而是给能够真正交付产品的工程师的。

Zero G Talent 的职位板显示，仅过去一周 Sierra AI 就新增了 5 个职位，Anthropic 新增了 18 个。招聘速度就是信号，技能缺口就是机会。
