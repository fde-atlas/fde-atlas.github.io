AI 正在超越聊天机器人的范畴。企业如今构建能够理解指令、使用工具、检索信息、调用 API、运行多步骤工作流并与其他 Agent 协作的 AI Agent。这就是 Agentic AI（智能体 AI），它已被应用于银行、医疗、IT 支持、软件开发、客户服务和金融等领域。

无论是应届生还是有经验的工程师，证明 Agentic AI 能力的最佳方式就是动手做项目。提示词工程证书的含金量要低得多。本指南列出了从入门到专家级的 25 个项目。每个项目都包含技术栈、值得实现的功能、业务用例，以及（如果有的话）完整分步教程的链接。

这些项目使用 Python、LangChain、LangGraph、Amazon Bedrock、Microsoft Foundry、RAG、MCP、Docker、Kubernetes 和 Terraform。它们适合所有准备应聘 GenAI 工程师、Agentic AI 工程师、AI 应用开发工程师或前沿部署工程师职位的人。

什么是 Agentic AI？

Agentic AI 系统通过多步推理、工具使用、工作流执行以及与外部系统的交互来达成目标。基础聊天机器人主要生成文本，而 Agent 可以：

  • 理解请求并将其拆解为任务；
  • 选择合适的工具、检索信息并调用 API；
  • 跟踪工作流状态；
  • 执行已获批准的操作并检查结果；
  • 在需要审批时上报给人工处理。

示例：聊天机器人可以*解释*如何排查服务器故障。而一个 IT 运维 Agent 可以获取该服务器的运维手册，分析其有权读取的监控数据，找出可能的原因，创建事件工单并推荐修复方案。如果工作流允许，它还可以在适当的安全控制下执行已批准的低风险操作。

对这些概念还不熟悉？请先阅读什么是 Agentic AI？和 Agentic AI 设计模式。

入门项目（1–5）

1. AI 个人助理 Agent

  • 技术栈：Python、LLM API、LangChain、FastAPI。
  • 构建： 理解指令并回答问题；总结文档并搜索已批准的来源；管理任务列表；返回结构化输出；保留对话上下文。
  • 用例： 员工生产力助手。
  • 展示： LLM 集成、工具调用、API 开发。

2. AI PDF 研究代理

  • 技术： Python、LangChain、嵌入、Chroma。
  • 构建： 上传 PDF；提取并分块文本；嵌入并存储向量；检索相关段落；回答时附上来源引用。
  • 用例： 政策搜索、法律和研究文档。
  • 展示： RAG、嵌入、向量数据库。

3. AI 网络研究代理

  • 技术： Python、LangChain、搜索 API。
  • 构建： 将研究简报转化为搜索查询；收集并总结来源；比较研究结果；生成带链接的结构化报告。
  • 用例： 市场和竞争对手研究。
  • 展示： 工具调用、结构化输出、提示词设计。

4. AI 邮件管理代理

  • 技术： Python、Gmail API、LangGraph。
  • 构建： 对邮件分类并总结会话线程；标记优先消息；起草回复；提取待办事项和提醒。
  • 必备： 在发送邮件或在邮箱中执行任何敏感操作之前，必须经过人工批准。
  • 展示： API 集成、人在回路设计。

5. AI 面试准备代理

  • 技术： Python、LangGraph、Streamlit。
  • 构建： 生成针对特定职位的问题；评估答案并提出改进建议；设置编程练习；跟踪进度。
  • 展示： 代理编排、评测。

常见问题

哪种 Agentic AI 项目最适合应届生？ PDF 研究助手、带工具的个人助理，或 RAG 知识助手。这些项目能教你 Python、LLM、嵌入、API 和检索。

必须用 LangGraph 吗？ 不需要。LangGraph 只是构建有状态、多步骤 Agent 的框架之一。其他框架也可以，直接调用模型 API 同样可行。

LangChain 与 LangGraph 的区别？ LangChain 为 LLM 应用和 Agent 提供构建模块。LangGraph 则通过节点、边、条件路由和持久化来编排有状态的工作流。

什么是 MCP？ 模型上下文协议（Model Context Protocol）是一个开放标准，规定了 AI 应用如何通过 MCP 客户端和服务器连接外部工具与上下文。

GitHub 上应该放多少个项目？ 三到五个高质量项目，每个都要有可运行的代码、文档、测试、架构图，并清晰说明你构建了什么。

DevOps 工程师能转型 Agentic AI 吗？ 可以。在你现有的云、IaC、容器和 CI/CD 技能基础上，补充 Python、LLM、RAG 和 Agent 编排能力。参见 DevOps 工程师转型 FDE。

常见问题解答

哪种 Agentic AI 项目最适合应届生？ PDF 研究助手、带工具的个人助理，或 RAG 知识助手：它们涵盖 Python、LLM、嵌入、API 和检索。

哪些项目最适合 GenAI 工程师简历？ 多 Agent 客户支持、企业级 RAG、银行知识助手和 MCP 集成。

Agentic AI 必须用 LangGraph 吗？ 不需要。它只是构建有状态多步骤 Agent 的框架之一；其他框架或直接调用 API 也同样可行。

LangChain 和 LangGraph 有什么区别？ LangChain 为 LLM 应用和 Agent 提供构建模块；LangGraph 通过节点、边、条件路由和持久化来编排有状态的工作流。

我可以用 Amazon Bedrock 构建 Agentic AI 项目吗？ 可以。Bedrock 为企业级 GenAI 应用提供基础模型、知识库、Agent 和护栏（Guardrails）。

什么是 Agentic AI 中的 MCP？ 模型上下文协议（Model Context Protocol）是一个开放标准，用于通过 MCP 客户端和服务器将 AI 应用连接到外部工具和上下文。

我应该在 GitHub 上放多少个项目？ 三到五个高质量项目，包含可运行的代码、文档、测试、架构图，以及对你贡献内容的清晰描述。
