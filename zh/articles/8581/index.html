基础检索增强生成（RAG）RAG 通过在查询时检索相关段落并将其放入提示词中，使语言模型基于你自己的数据作答，从而让模型依据真实来源而非记忆回答问题。它几乎是所有企业级 FDE 部署的默认模式，这也是为什么几乎每个面试流程都会考察它。

基础向量数据库向量数据库将嵌入向量与元数据一起存储，并使用近似索引快速回答最近邻查询。真正的面试问题不是它们如何工作，而是你什么时候真正需要一个向量数据库，而不是一个库或带 pgvector 的普通 Postgres。

基础AI Agent 与工具使用Agent 是被包裹在循环中的语言模型，让它可以选择工具、执行操作、观察结果并决定下一步做什么。面试官考察的技能是判断力：知道这个循环何时值得它的不可预测性，何时固定流水线更便宜、更快、更安全。

OpenAI 的前沿部署工程师面试循环会考察 RAG 与 Agent 系统设计问题，例如“请端到端地讲解一个 RAG 流水线，并告诉我它通常在哪里出问题”、“关键词搜索 vs 向量搜索：在 RAG 系统中各自真正带来什么价值？”、“什么时候 Agent 是错误的答案？请论证为什么不该构建一个。”。检索流水线、分块、重排序、使用工具的 Agent、护栏、多租户和评测框架：这是 OpenAI、Anthropic、Sierra、Glean 和 Scale 最典型的 FDE 设计轮。完整题集按从易到难排序并附专家答案，见下方。
