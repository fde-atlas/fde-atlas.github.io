前沿部署工程师（正式员工）| Anthropic | 纽约州纽约市

原标题：Staff Forward Deployed Engineer | Anthropic | New York, NY

Zero G Talent · 2026-10-14 · 约 7 分钟读完

摘要

Anthropic 在纽约招聘 Staff 级前沿部署工程师，隶属市场推广团队。该职位需驻扎于战略客户现场，主导企业 AI 落地的技术方向：负责重点客户的技术策略、跨工作流的架构决策、独立的咨询与需求探索，并向 VP 及 C 级高管汇报。候选人需具备生产系统设计经验、LLM 与 Agent 实操能力、Python 等编程功底，以及资深客户-facing 技术背景（FDE、Tech Lead 或创业者）。要求约 25% 出差，支持签证担保。未要求已上线过 Agent 产品，但强调在模糊环境中决策与交付可运维生产系统的能力。

要点

  • Anthropic 纽约招聘 Staff 级前沿部署工程师，隶属市场推广团队。
  • 职责包括主导重点客户技术策略、架构决策与独立咨询。
  • 需向 VP 及 C 级高管汇报，并交付可运维的 Claude 生产应用。
  • 要求生产系统经验、LLM 与 Agent 实操能力及 Python 功底。
  • 出差约 25%，支持签证担保，不强制要求上线过 Agent。

关于 Anthropic

Anthropic 的使命是打造可靠、可解释、可操控的 AI 系统。我们希望 AI 对用户乃至整个社会都是安全且有益的。我们的团队由一群快速成长的研究人员、工程师、政策专家和业务负责人组成，大家携手构建有益的 AI 系统。

关于该职位

作为 Anthropic GTM 团队的一员，你将担任资深前沿部署工程师（FDE），直接深入我们最具战略意义的客户，并主导其 AI 落地的技术方向。客户邀请你是为了让你来主导，而不仅仅是实施：你要决定应该构建什么，并确保它被高质量地构建出来。你将与客户团队协作，交付能够解决现实业务问题的高级 AI 应用，并围绕这些构建工作，在整个客户账户范围内指导架构与咨询工作。

你将与我们的研究、产品和工程团队紧密合作，结合工程专业知识、对前沿 AI 应用的理解以及面向客户的技能，深入理解客户的工作流程，开发创新解决方案以应对复杂的业务挑战，同时保持我们在安全性和可靠性方面的高标准。

你将站在企业级 AI 部署的最前沿，并在其规模化过程中帮助塑造我们的前沿部署模式。我们期望资深 FDE 能够在模糊环境中确定方向，并在客户环境中以最高水准代表 Anthropic。在这一职位上，你将指导跨工作流的架构与构建计划，直接与高级技术和业务利益相关者合作，并对覆盖客户账户路线图的成果负责。

你不需要有将 Agent 投入生产环境的经验，但你需要具备构建和运维生产系统的深厚经验、使用 Agent 的实战经历，以及带领企业客户开展架构与咨询工作的判断力。

职责

  • 与客户团队和产品团队协作，负责重点客户或垂直领域的技术战略。
  • 指导多个并行工作流中的技术架构与设计决策。
  • 独立主导探索与咨询类项目，在开发启动前确定项目范围和技术战略。
  • 主导与合作伙伴共同交付的项目，为你并非亲自构建的工作设定架构和质量标准。
  • 审查设计方案，并在艰难的技术决策上为其他 FDE 排除障碍。
  • 代表 Anthropic 与高级技术和业务利益相关者（包括副总裁和 C 级高管）沟通，就战略达成一致并降低交付风险。
  • 端到端地负责你的项目：确定工作范围、安排优先顺序、排除障碍、预判安全与采购环节，并交付客户能够运营的生产系统。
  • 深入客户系统内部，使用 Claude 构建生产应用和 AI Agent 组件，并交付客户可以运行和维护的系统。
  • 识别并总结可复用的部署模式，将洞察反馈给我们的产品与工程团队。
  • 与客户建立长期关系，并在项目的整个生命周期中主动发现 AI 部署的新机会。
  • 频繁出差（25%）前往客户现场，与客户面对面协作开发。
  • 在一线成为 Anthropic 使命的倡导者。

如果你具备以下条件，你可能非常适合这个职位

  • 深厚的系统设计与问题分解能力：你可以仅凭一个业务问题开展探索性沟通，并最终为复杂企业环境中遗留系统、身份与访问管理以及合规要求下的安全、可投入生产的设计，制定出经得起推敲的技术战略。
  • 拥有高级技术类、面向客户的岗位经验，例如前沿部署工程师，或具备咨询或产品经验的技术负责人（Tech Lead）。也欢迎曾经的技术创业者申请。
  • 有这样的履历记录：当团队面临模糊不清的技术决策时，大家会向你求助——无论是通过架构评审、结对编程还是非正式的指导。
  • 有在复杂组织中直接影响高级技术和业务利益相关者（包括副总裁和 C 级高管）的履历记录。
  • 在构建和运营生产系统方面拥有丰富经验。具备 LLM 和 AI Agent 的实际操作经验是基本要求。个人项目和原型也算数。
  • 具备扎实的编程能力，精通 Python（最好还掌握 TypeScript、Java 等一门或多门其他语言），有交付生产应用的经验，日常使用 AI 编程工具，并具备审查和引导的判断力。
  • 有主导咨询和架构评审项目以及亲自参与构建的经验，并能端到端地推进这些工作。
  • 具备高度的主观能动性，能够应对复杂组织中存在的模糊性，并拥有快速学习新领域和新工具的能力。
  • 热衷于通过创造性的技术应用推动安全、有益的 AI 系统的发展。
  • 具有金融服务、医疗/生命科学或其他企业垂直行业的背景者优先。

最低工作年限要求：所需的工作年限将与该职位的内部职级要求相关联

基于办公地点的混合办公政策：目前，我们期望所有员工至少有 25% 的时间在我们的办公室办公。不过，某些职位可能需要更多时间在办公室。

签证担保：我们确实提供签证担保！但是，我们并非能为每个职位和每位候选人都成功办理签证担保。如果我们向你发出录用通知，我们将尽一切合理努力为你办理签证，并聘请了移民律师来协助此事。

即使你认为自己不完全符合所有任职条件，我们也鼓励你申请。并非所有优秀的候选人都能完全符合所列的每一项任职条件。研究表明，自认为属于弱势群体的人更容易产生“冒名顶替综合征”，怀疑自身竞争力，因此我们恳请你不要过早地自我否定，如果你对这份工作感兴趣，请提交申请。我们认为，像我们正在构建的这类 AI 系统具有巨大的社会和伦理影响。我们认为这使得团队中的多元代表性更加重要，因此我们努力在团队中纳入各种不同的视角。你的安全对我们至关重要。为保护你免受潜在诈骗，请记住：Anthropic 的招聘人员只会通过 @anthropic.com 邮箱地址与你联系。在某些情况下，我们可能会与经过审核的招聘机构合作，他们会表明自己是代表 Anthropic 开展工作。请警惕来自其他域名的邮件。正规的 Anthropic 招聘人员绝不会在你入职第一天之前要求你提供钱款、费用或银行信息。如果你对某条沟通信息存有疑虑，请不要点击任何链接——请直接访问 anthropic.com/careers 查看确认的职位空缺。

我们的不同之处

我们相信，最具影响力的 AI 研究将是“大科学”。在 Anthropic，我们作为一个紧密协作的团队，只专注于少数几个大规模研究项目。我们重视影响力——推进可操控、可信赖的 AI 这一长期目标——而不是研究更小、更具体的问题。我们将 AI 研究视为一门实证科学，它与物理学和生物学的共同之处不亚于与计算机科学传统研究的共同之处。我们是一个非常注重协作的团队，经常举办研究讨论，以确保我们在任何时候都在从事最具影响力的工作。因此，我们非常重视沟通能力。

了解我们研究方向的最简单方式是阅读我们近期的研究成果。这些研究延续了我们团队在 Anthropic 成立之前所从事的许多方向，包括：GPT-3、基于电路的可解释性、多模态神经元、缩放定律、AI 与算力、AI 安全的具体问题，以及从人类偏好中学习。
