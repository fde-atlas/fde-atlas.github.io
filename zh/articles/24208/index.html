前沿部署工程师 | Mind Robotics | Normal, IL

原标题：Forward Deployed Engineer | Mind Robotics | Normal, IL

Zero G Talent · 2026-06-10 · 约 3 分钟读完

摘要

Mind Robotics 在伊利诺伊州 Normal 招聘前沿部署工程师，驻场服务关键客户，负责机器人数据采集设备的维护、网络配置与软件部署，后续转向机器人部署支持。

要点

  • Mind Robotics 专注工厂场景的 Physical AI，招聘驻场前沿部署工程师。
  • 职责包括硬件诊断、Linux 配置、网络排障与车队监控。
  • 要求掌握 Bash、Python、Git 及 TCP/IP 等网络基础。
  • 需将现场问题反馈为可复现的 bug 报告并参与软件迭代。
  • 岗位初期管理数据采集设备，之后转向机器人部署支持。

关于 Mind：

Mind Robotics 正在打造面向真实工业部署的物理 AI，从工厂车间起步。我们相信，当研究人员和工程师每天亲身接触物理世界时，AI 中最难的问题才能被解决——我们正在寻找热爱机器人技术、重视主人翁精神并乐于攻克难题的人才。如果你想超越数字智能，让智能真正运转起来，欢迎加入我们。

关于该职位

我们正在招聘一名前沿部署工程师，作为我们的“手和眼”驻场于伊利诺伊州诺默尔的一位重要客户。你将负责我们的数据采集设备机群——诊断和维修设备、配置新硬件、排查网络问题，以及运行保持系统健康运行的诊断工作流。该职位将从关键的机器人数据采集设备起步，随后过渡到机器人部署支持工作。

这是一个前沿部署职位，总部将提供强力支持。你不会孤军奋战：我们的工程团队只需一条 Slack 消息即可联系，你将与他们紧密合作，上报复杂问题、将修复成果回馈到产品中，并把客户的声音带入我们的产品路线图。理想的候选人应具备技术好奇心、在压力下保持冷静，并因成为现场解决问题的人而充满干劲。

职责

  • 通过安装和配置 Linux、部署我们的软件栈，并在设备投入生产前验证其健康状况，完成新硬件的配置。
  • 运行诊断脚本、收集并解读系统日志，执行命令行工作流，以定位设备或网络问题的根本原因。
  • 配置并排查本地网络（IP、DHCP、DNS、VLAN、Wi-Fi/以太网），确保设备可靠地连接到我们的后端。
  • 作为客户现场的主要技术联系人，与总部工程和支持团队紧密协作，解决问题，并将现场经验反馈到产品中。
  • 为现场发现的问题开发代码修复，包括将问题根因定位到代码层面，并通过 Git 和代码评审提交变更。
  • 通过执行测试计划、记录结果和回归情况，在软件版本全机群推广前给出放行与否的判断，对现场设备上的软件试用进行测试和验证。
  • 参与软件迭代冲刺，包括参加规划会、站会和复盘会，认领与现场相关的工单，并根据客户影响协助确定待办事项的优先级。
  • 通过将现场观察转化为可复现的错误报告（日志、步骤、遥测数据），并将软件变更和新工作流程传达给现场团队，弥合软件团队与 FDE 之间的差距。
  • 构建脚本和小型工具，实现配置、诊断、日志收集和日常设备维护的自动化。
  • 使用仪表盘、指标和日志监控设备健康状况，及早发现问题，并验证已部署的修复是否解决了问题。
  • 支持跨设备分组的分阶段软件发布和回滚。
  • 维护操作手册、故障排除指南和已知问题文档。

任职资格

  • 具备硬件和软件故障排除的实操经验，最好有微型计算机、嵌入式设备、摄像头或类似单板计算机的经验。
  • 熟悉 Linux 系统管理：安装发行版、软件包管理、systemd 服务、文件权限以及基本的 shell 操作。
  • 具备 Bash（最好还有 Python）的工作知识，能够阅读和运行简单的诊断脚本并自动化日常任务。
  • 扎实的网络基础知识：TCP/IP、子网、DNS、DHCP、基本防火墙规则，并熟练使用 ping、traceroute、tcpdump 和 ssh 等工具。
  • 出色的面向客户的沟通能力，以及在现场独立工作的自主性，同时与远程总部团队保持紧密协作。
  • 具备软件开发经验，能够阅读、调试和编写生产代码（首选 Python）。
  • 具备基于 Git 的工作流程经验（分支管理、拉取请求、代码审查），并熟悉 Agile/冲刺环境下的工作方式。
  • 具备软件测试和验证经验：编写测试用例、复现错误并清晰地记录结果。
  • 有现场服务、前沿部署或解决方案工程相关岗位经验者优先。
  • 熟悉 DevOps 和软件基础设施工具（如 Docker、Ansible、Portainer 等）者优先。
  • 熟悉计算机视觉系统、IP 摄像头或工业物联网部署者优先。
  • 有 Git、Python 基础脚本编写或远程设备管理工具使用经验者优先。
