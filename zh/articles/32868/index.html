AI 前沿部署工程师技能：RAG、评测与提示词

原标题：AI Forward Deployed Engineer Skills: RAG, Evals & Prompts

FDE India · 2026-11-13 · 约 10 分钟读完

摘要

文章分析了 2026 年 11 月印度八个 FDE 职位列表，统计各职位对 AI 技能的要求。结果显示：全部八个职位要求 AI Agent 或工具调用能力，七个要求 RAG，六个要求提示词设计与 Python，五个要求评测；微调仅在两个职位中出现，属于加分项而非入门必备。文章为每项技能给出达标标准和周末可完成的小项目，并提供六周学习计划。经验要求从 1 年到 5 年以上不等，八个职位均未公布薪资。

要点

  • 八个印度 FDE 职位全部要求 AI Agent 或工具调用能力。
  • 七个职位要求 RAG，六个要求提示词设计与 Python。
  • 五个职位要求评测，被视为区分 FDE 与演示制作者的关键。
  • 微调仅在两个职位出现，属加分项，不必优先学习。
  • 经验要求为 1 至 5 年以上，所有职位均未公布薪资。

在印度，AI 前沿部署工程师需要为客户构建可运行的 LLM 系统，而不仅仅是调用 API。纵观 2026 年的八个印度 FDE 职位，每一个都要求 AI Agent 或工具调用能力，七个提到 RAG，六个要求提示词设计，五个要求你会运行评测。而很多人最先学习的微调技能，只在两个职位中出现。

本指南按照职位描述中的实际用法逐一讲解这些技能，说明面试中“足够好”的标准是什么，并为每项技能提供一个可以在一两个周末内完成的小项目。

我们阅读了哪些职位

我们于 2026 年 11 月阅读了八个位于印度、均以 LLM 工作为核心的前沿部署职位。其中四个已标记为关闭（Sarvam AI 的 FDE 职位、Nanonets、evnek 和 Google Cloud 的 GenAI FDE 职位），RevRag AI 的两个职位均显示即将开放申请。我们纳入已关闭的职位，是因为它们展示了知名 AI 雇主如何定义这份工作。只有职位明确提到的技能才计入统计。

Agent 和 RAG 几乎是普遍要求；微调只是小众要求。根据上述八个职位统计，阅读时间为 2026 年 11 月。

技能 1：构建能调用工具的 Agent

全部八个职位都以某种形式要求 Agent、Agentic 工作流或工具调用。Prodigal 希望前沿部署工程师构建由 LLM 驱动的 AI Agent，包括语音 Agent。Nanonets 要求具备 Agentic 工作流和 Agent 编排能力。RevRag AI 的 FDE 职位同时提到了工具调用、系统提示词和结构化输出。

大多数职位没有指明具体框架。指明了的如下：

  • Sarvam AI（FDE）： LangGraph、LlamaIndex、Google ADK 和 MCP 服务器。
  • Google Cloud（GenAI FDE）： LangGraph、CrewAI 和 MCP 服务器，以及使用外部工具编排模型调用。
  • RevRag AI（两个职位）： LiveKit Agents 和 Pipecat 作为加分技能，因为其 Agent 通过语音与客户交流。

LangChain 常被视为默认选择，但八个职位中没有一个提到它。启示是：先理解工具调用在底层的运作方式（模型返回一个结构化调用，你的代码执行它，结果再返回到上下文中），然后选择一个框架。雇主在意的是你能否调试这个循环，而不是你用了哪个库。

优秀标准： 你能解释 Agent 为什么调用了错误的工具，并通过更好的工具描述、修改 schema 或在代码中加防护来修复它。

迷你项目： 一个通过调用两个真实或模拟的 API（订单 API 和物流 API）来回答“我的订单在哪里？”的 Agent，返回结构化 JSON，并在缺少订单 ID 时礼貌地拒绝。将其中一个工具以 MCP 服务器的形式暴露出来，以契合 Sarvam AI 和 Google 的要求。

技能 2：能在杂乱的客户数据上正常工作的 RAG

八个职位中有七个提到了 RAG。Prodigal 和 Nanonets 都要求 RAG 流水线；evnek 的职位将 RAG 与 AI Agent 并列为该角色的核心；Google Cloud 的 GenAI 职位直接点名检索增强生成。Sarvam AI 的软件工程师职位是唯一没有提到“RAG”的，但它要求向量数据库和语义搜索，这其实是同一个构建模块。

对前沿部署工程师来说，RAG 很少是一个干净的演示。客户的文档是 PDF、扫描表单、维基和工单，而且常常不止一种语言。你的工作就是从中获得高质量的答案。

优秀标准： 你知道 RAG 通常在哪里失败（糟糕的分块、缺少元数据过滤、检索返回了错误的段落），并且能展示你如何将检索质量与答案质量分开衡量。

迷你项目： 一个基于 50–100 份真实公开文档（如 RBI 通知或你所在州的政府命令）的问答助手。将嵌入存储在任意向量库中，添加元数据过滤（按日期或部门），并在每个答案中返回来源段落。

技能 3：面向生产环境的提示词设计，而非聊天

六个职位要求提示词工程或提示词设计。RevRag AI 的要求最具体，要求为 LLM Agent 提供实用的提示词工程能力，涵盖系统提示词、工具使用和结构化输出，以及对话设计。Prodigal 要求 FDE 设计和优化提示词；Sarvam AI 的软件工程师职位要求你学习并应用提示词工程技术。Sarvam AI 的 FDE 职位用了另一个说法——“上下文工程”，表达的是同一个理念：精确决定模型看到的内容。

优秀实践的标准： 提示词纳入版本控制，每次修改前用固定的输入集进行测试，并将输出强制转换为代码可解析的 schema。

迷你项目： 拿你的 RAG 助手，为它的系统提示词写三个版本。用同样的 30 个问题运行这三个版本，并记录一张表格，标明哪个版本胜出以及原因。这张表格可以直接用于技能 4。

技能 4：评测——将 FDE 与演示搭建者区分开来的技能

八个职位中有五个要求评测能力。Google Cloud 的 GenAI FDE 职位要求你构建评测流水线。Sarvam AI 的 FDE 职位要求工程师搭建评测，并具备评测思维。Prodigal 要求评测框架。RevRag AI 的高级职位要求以评测驱动的迭代，并以可衡量的准确率、延迟和转化率提升来评判成功。

评测是说服客户开启一个 AI 系统的关键。一个能说“在我们 200 题测试集上，准确率从 71% 提升到 88%，以下是具体改动”的 FDE，远比一个只会说“现在看起来好多了”的 FDE 有用得多。我们在 AI 创业公司 FDE 的关键职责领域指南中介绍了评测如何作为一项工作职责出现。

优秀实践的标准： 一套固定的测试集、每个任务有明确的指标（精确匹配、由模型评分的评分标准，或对样本进行人工评分），以及每次发布前运行评测的习惯。

迷你项目： 为你的 RAG 助手编写 50 组问答对，其中包括 10 个它应该拒绝回答的问题。对每次提示词或检索改动进行评分，并绘制分数随时间变化的曲线。

技能 5：监控、防护栏与语音

五个职位要求生产监控、可观测性或防护栏。Google Cloud 的 GenAI 职位明确提到可观测性框架和细粒度追踪；evnek 要求模型可观测性；Prodigal 包含对已部署 Agent 的监控；RevRag AI 要求 FDE 配置工具和防护栏。这是上线之后才开始的工作部分。

语音 AI 也出现在五个职位中：RevRag AI 的两个职位、Prodigal，以及 Sarvam AI 的两个职位。如果你的目标是向银行、贷款机构或客服团队销售的印度 AI 创业公司，一个语音 Agent 项目是很有力的信号。更多招聘信息请阅读 Sarvam AI 的公司页面。

迷你项目： 为你的 Agent 添加日志记录（每次提示词、工具调用、延迟和成本）、一个简单的仪表盘，以及一条防护栏，例如屏蔽提及账号的回答。

微调与 Python：它们的适用位置

只有两条职位描述提到微调：Google Cloud 的 GenAI 职位，以及 RevRag AI 的高级职位，后者将 LoRA 或 QLoRA 微调列为加分项。大多数 FDE 工作是让现有模型在客户的数据上表现出色，所以请在掌握其他五项技能之后再学习微调，而不是之前。

Python 则是另一回事。八条职位描述中有六条明确提到它：Prodigal 要求扎实的 Python 和 SQL，Sarvam AI 在两个职位中都要求 Python，Google 要求三年使用 Python 及 ML 库的经验，RevRag AI 则要求扎实的 Python 基础。上述 LLM 技能都建立在常规软件工程之上。我们更全面的指南印度雇主对 FDE 的六大技能要求涵盖了非 AI 方面的内容。

这些职位期望多少经验

每条职位描述中注明的最低年限。Google 的数字指 Python 和 ML 库的使用年限。职位信息读取于 2026 年 11 月。

入门门槛比许多人想象的要低。Sarvam AI 的软件工程师职位要求 1–3 年经验，RevRag AI、Prodigal 和 Nanonets 都从约 2 年起步。RevRag AI 和 Sarvam AI 的高级职位从 4 年起步，evnek 则要求 5–10 年。

六周技能提升计划

  • 第 1 周 – 从零开始实现工具调用。 使用原始模型 API、不用任何框架构建订单状态 AI Agent，从而理解其中的循环机制。然后用 LangGraph 或职位描述中提到的其他框架重新实现它。
  • 第 2 周 – 针对真实文档的 RAG。 构建带元数据过滤器和来源引用的文档助手。
  • 第 3 周 – 评测。 编写 50 道题的测试集，加入拒答案例，并记录一个基准分数。
  • 第 4 周 – 提示词迭代。 针对你的评测运行三个提示词版本和两种分块策略。保留结果表格。
  • 第 5 周 – 生产环境基础。 添加日志、成本和延迟跟踪、一个防护栏，并将其部署到招聘人员可以试用的地方。
  • 第 6 周 – 讲好故事。 为每个项目写一页案例研究：客户问题、你构建了什么、指标及其变化。在面试中使用它；我们的 FDE 面试流程指南说明了它的用武之地。

如果你想了解这些技能中有哪些已被你现有的经验覆盖，可以试试 FDE Fit Check。

常见问题

在印度，前沿部署工程师需要哪些 AI 技能？

在 2026 年的八条印度 FDE 职位描述中，最常见的技能要求是：构建带工具调用的 AI Agent（八条全部提到）、RAG（七条）、提示词设计（六条）、Python（六条）和评测（五条）。生产监控或防护栏以及语音 AI 也各出现在五条职位描述中。

FDE 需要掌握微调吗？

很少。在我们审阅的八条职位描述中，只有两条提到它：Google Cloud 的 GenAI FDE 职位，以及 RevRag AI 的高级 FDE 职位，后者将 LoRA 或 QLoRA 微调列为加分项。RAG、提示词设计和评测出现得频繁得多。

印度 FDE 职位描述提到了哪些 Agent 框架？

大多数职位都没有列出具体名称。Sarvam AI 的 FDE 职位列出了 LangGraph、LlamaIndex、Google ADK 和 MCP 服务器；Google Cloud 的 GenAI FDE 职位列出了 LangGraph、CrewAI 和 MCP 服务器；RevRag AI 将 LiveKit Agents 和 Pipecat 列为语音 AI Agent 的加分技能。八份职位中没有任何一份提到 LangChain。

在没有 AI 工作经验的情况下，如何展示 FDE 职位所需的 LLM 技能？

构建一些与职位描述相符的小型已部署项目：一个基于真实文档、带有评测集的 RAG 助手，一个调用两三个真实 API 的 Agent，以及为它搭建的监控仪表盘。写下你选择的指标以及它如何变化。
