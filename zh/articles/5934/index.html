摘要

本文介绍 Deloitte 作为 Anthropic 渠道合作伙伴招聘前沿部署工程师的情况。该职位正式名称为 Anthropic Forward Deployed Engineer，隶属政府与公共服务部门，分标准、高级和主管三级，工作地点包括 Nashville、San Diego、Atlanta 等城市。岗位要求包括 Claude API、Claude for Enterprise、Claude Code 等实操经验、约 50% 出差以及获得美国政府安全审查资格。文章还列出面试考察方向（LLM 交付、检索与 Agent、AI 安全治理、客户沟通），但未提供经核实的薪酬数据，并提醒读者以官方招聘页面为准。

LLM 与生成式 AI 基础

基础Tokenization 与 Token语言模型读取的不是字符或单词，而是 token：由分词器产生的子词片段，每个 token 被映射为一个模型嵌入的整数。Token 是上下文窗口和计费的单位，文本如何切分成 token 解释了大量模型怪癖，这就是为什么几乎每个面试流程都从这里开始。

基础上下文窗口上下文窗口是语言模型一次能够关注的固定 token 数量，输入和输出共享同一预算。理解它，是能够合理设定提示词规模、控制成本与延迟、并判断何时该使用 RAG 的工程师，与只会把所有内容粘贴进去然后祈祷的工程师之间的分水岭。

基础Embeddings 与向量表示嵌入将一段文本转换为一组数字，其位置使得相似的含义在空间中彼此接近，从而让你可以按含义而非关键词进行搜索。嵌入是 RAG、语义搜索、聚类和去重背后的引擎，因此 FDE 面试流程期望你能解释余弦相似度，以及那些会悄悄破坏向量索引的陷阱。

检索与 Agent

基础检索增强生成（RAG）RAG 通过在查询时检索相关段落并将其放入提示词中，使语言模型基于你自己的数据作答，让模型依据真实来源而非记忆回答问题。它是几乎所有企业级 FDE 部署的默认模式，这就是为什么几乎每个面试流程都会考察它。

基础向量数据库向量数据库将嵌入与元数据一同存储，并使用近似索引快速回答最近邻查询。真正的面试问题不是它们如何工作，而是你何时真正需要一个向量数据库，而不是一个库或使用 pgvector 的普通 Postgres。

AI 安全、隐私与治理

面向客户的技艺

基础需求发现需求发现是找出隐藏在客户明确诉求背后的真实问题的工作。客户交给你的请求（“给我们做一个聊天机器人”）几乎从来不是真正的需求；能够弄清楚谁在使用它、成功是什么样子、实际存在哪些数据、以及为什么截止日期就是截止日期的 FDE，才能交付出人们真正使用的东西。

基础界定模糊问题界定一个开放式命题（“某城市想缩短 911 响应时间”）是一种结构化的操作，而不是灵光一现：澄清输入和约束，大声说出你的假设，切分出最小可用的 MVP，明确你正在选择的准确性/成本/延迟权衡，并规划失败时该怎么办。直接跳进模型或架构是候选人在模拟轮中被淘汰的最常见原因。

基础向非工程师解释权衡高管并不关心你选择了 RAG 还是微调；他们关心的是成本多少、何时交付、以及可能出什么错。翻译技术权衡意味着把准确性、成本和延迟转化为业务真正在做的决策，用他们的语言把每个选项框定为带有后果的选择，并回答他们最终都会问的问题：为什么 AI 每次给出的答案都不一样，以及为什么这不是一个 bug。

是的，而且不同寻常的是，职位名称直接标注了合作伙伴：Anthropic 前沿部署工程师，隶属于 Government and Public Services 部门。Deloitte 在美国多个城市以标准、高级和主管级别发布该职位。

职位要求具备 Anthropic 的实际动手经验，涵盖 Claude API、Claude for Enterprise、工具使用、extended thinking 或 Claude Code，此外还要求有领导客户项目工作流和编写可维护代码的经验。职位还列出了大约 50% 的差旅要求，以及获得并保持美国政府安全许可的能力。

你是在客户环境中部署合作伙伴的模型，而不是部署自己的产品，而且客户往往是政府机构。这使得安全许可、采购和利益相关者管理成为重点，所以请准备好谈论在这些约束条件下的交付，而不仅仅是构建。

Deloitte 尚未公布我们能够确认的 Anthropic 前沿部署工程师职位的薪酬数字。咨询公司的薪酬结构与产品公司不同：预期是基本工资加奖金，而非有实质意义的股权，并请注意该职位大约有 50% 的出差要求。
