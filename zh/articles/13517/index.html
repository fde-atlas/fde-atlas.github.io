AI 顾问在 DevDay 2026 之后：工作机会在哪里

原标题：AI Consultants After DevDay 2026: Where the Work Will Be

Szymon Paluch — AI Consulting · 2026-09-30 · 约 6 分钟读完

摘要

作者以 OpenAI Select 合作伙伴身份分析 DevDay 2026：官方回顾未提及咨询合作伙伴计划，但每次发布都给企业留下 OpenAI 不会代劳的工作。文章列出五类咨询机会：为自主运行的 dot 编写 Custom Rules、整理 GDPR 数据驻留地图、按任务成本选模型（如 GPT-6.1 Sol 输入输出价格约为 GPT-6 Astra 的五分之一）、在 Agents API 与 AWS Bedrock 等部署路线间做选择、以及开发插件与集成。作者认为这些工作核心是权限、数据、质量与成本，提示词只占小部分，建议顾问在一周内自建示例项目作为敲门砖。

要点

  • DevDay 官方回顾未提及 Partner Network 或认证顾问。
  • 五类工作：dot 规则、GDPR 数据地图、模型成本、部署路线、插件。
  • GPT-6.1 Sol 价格约为 GPT-6 Astra 的五分之一。
  • OpenAI 计划年底前培养 30 万认证顾问，投入 1.5 亿美元。
  • 建议顾问一周内自建示例项目，证明部署能力。

OpenAI 的 DevDay 2026 回顾中没有提到其合作伙伴计划。然而，几乎每一次发布都会给企业留下 OpenAI 不会替它们完成的工作：AI Agent 的规则、数据地图、模型成本和集成。这些正是 AI 顾问的客户工作。以下是我看得最清楚的五类工作，以及它们所需的技能。

我从两个角度来写这篇文章。我的公司自 9 月 24 日起持有 OpenAI Select Partner 资格。日常工作中，我为客户部署 AI Agent，并运营一个 AI 顾问集体。因此，我带着一个问题来解读 DevDay 的发布内容：客户能拿到哪些现成的东西，又有哪些需要有人替他们搭建？

DevDay 关于合作伙伴说了什么，又遗漏了什么

官方的 DevDay 回顾没有提到 OpenAI Partner Network。它对认证顾问或 Forward Deployed Experts 计划只字未提。合作伙伴出现在两个地方。其一是 OpenAI Marketplace 中的 32 家软件公司。其二是 16 个可以使用 ChatGPT 套餐额度的工具。

还有一句话谈到了谁在大型企业中部署 AI Agent。对于 dot，OpenAI 表示它从聚焦的试点开始。OpenAI 自己的工程师将与这些组织合作。他们将定义 AI Agent 的职责、其工具，以及人们如何审批它的工作。另一个被点名的合作伙伴是 Microsoft，凭借 Agent 365。咨询公司不在那句话之中。

那些与客户坐在一起、在其系统内部搭建这套配置的工程师，有一个专属的职位名称：前沿部署工程师。我曾在雇主自己的原话中描述过这类工作在 LLM 和 AI Agent 项目中涉及的内容。

该合作伙伴计划自 6 月起运行。OpenAI 为其投入了 1.5 亿美元。它还计划在 2026 年底前培训并赋能 30 万名认证顾问。该计划分为三个层级：Select、Advanced 和 Elite。我曾描述过我的公司如何达到第一层级，以及该资格并不保证什么。DevDay 对该计划没有任何宣布。但它确实改变了客户将带给顾问的问题清单。

DevDay 留给企业的五类工作

1. dot 的规则

dot 是一种在自己的云端计算机上全天候自主工作的 AI Agent。它可以访问你连接给它的应用。它遵循 Custom Rules，这些规则可以允许某个操作、要求审批，或将其阻止。在 AI Agent 获得电子邮件和 CRM 的访问权限之前，必须有人先写好这些规则。还必须有人知道，dot 的记忆无法逐条修正，只能整体清除。

2. 符合 GDPR 的数据地图

一家欧洲公司首先会问数据去向哪里。DevDay 之后，答案取决于具体功能。在 ChatGPT 中，只有 Enterprise 和 Edu 套餐能将数据保留在欧盟境内。Space、Pages、Meetings 和团队任务不在该数据承诺覆盖的清单之内。Agents API 仅支持美国数据驻留。客户需要一页纸，清楚展示哪些功能可以开启、哪些不可以。我单独核查了这一点，逐个功能进行了梳理，并就会议记录的参与者同意问题做了说明。

3. 模型成本

GPT-6.1 Sol 的输入和输出价格仅为 GPT-6 Astra 的五分之一。Ultrafast 的价格是标准费率的六倍。Luna 比 Sol 便宜二十倍。这些差距会改变每个 AI Agent 的账单。客户并不知道哪个模型对其任务来说已经足够好。能在客户数据上测量一次完整任务成本的顾问，就有一项现成的服务。

4. 自有账户上的 AI Agent

Agents API 将 Codex harness 作为服务提供。Bedrock Managed Agents 在 AWS 内部也提供同样的能力。对客户来说，这带来了三条路线：基于 OpenAI API 的 AI Agent、部署在 AWS 中的 AI Agent，或自建 harness。每条路线对数据、成本和供应商依赖的影响都不同。选择与迁移本身就是一项独立的项目。

5. 插件与集成

ChatGPT 插件现在可以拥有自己的面板、对话旁的视图以及文件查看器。MCP Events 可以在连接的应用发生变化时启动自动化流程。Sites 可以使用插件，并向每位访客展示其自己的数据。如果一家公司的系统没有现成的插件，就需要有人来开发一个。这是五项工作中技术含量最高的一项。

为客户设计或部署 AI Agent？在我们的 AI 顾问集体中，你可以为 AI 供应商合作伙伴认证做准备，并与其他顾问一起学习。当合适的客户需求到来时，我们可能会邀请你参与项目。

哪些技能和认证会有帮助

这五项工作都涉及权限、数据、质量测量和成本。提示词只是其中最小的一部分。这些是一个理解模型行为的系统架构师所需的技能。

目前 OpenAI 的认证范围还很窄。OpenAI Certified 确实存在，但文档中写明的访问权限仅面向受邀的 Enterprise 和 Edu 组织。自 9 月 21 日起，OpenAI Academy 推出了四条学习路径。通过课程评估后，你会获得课程徽章。OpenAI 并不将其称为认证。我对比了 Claude、AWS 和 Microsoft 的考试以及 OpenAI 的课程各自能证明什么，以及每条路径适合哪类工作。

OpenAI 的目标是在年底前认证 30 万名顾问。考试能证明知识水平。但客户仍会要求查看你实际构建过的部署案例。

如何在客户开口之前先行起步

从这五种工作中选一种，在一周内用自己的例子做出来：为一个 dot 制定规则手册、为一家公司绘制数据地图，或者为你熟悉的系统写一个简单插件。写下你做了什么、测量了什么。有了这样的项目，回答客户的需求就更容易了。我在这里介绍了 AI 顾问在哪里找到客户工作，以及如何确定首个试点的范围。

你也可以以小组形式进行。我运营着一个 AI 顾问社群，你可以在那里准备 AI 供应商合作伙伴认证，并在完成个人档案评估后，有机会受邀参与项目。目前我们正通过合作伙伴组织在那里准备 Claude 认证考试。

我在一篇指南中整理了 OpenAI 在 DevDay 2026 上发布的全部内容，包括主题演讲的时间线。先从影响你客户的内容入手，并写下你本周要问他们的一个问题。

常见问题

DevDay 2026 之后，AI 顾问还有工作机会吗？

有。DevDay 的发布给企业留下了 OpenAI 不会替他们完成的工作：为 Agent 制定规则、为 GDPR 绘制数据地图、按成本选择模型、在 Agents API 和自建 harness 之间做选择，以及构建插件。

OpenAI 在 DevDay 2026 上为合作伙伴宣布了什么吗？

没有针对咨询合作伙伴的内容。官方回顾中没有提到 OpenAI Partner Network 或认证顾问。DevDay 上的合作伙伴是 OpenAI Marketplace 中的软件公司，以及支持 Sign in with ChatGPT 的工具。

什么是 OpenAI Partner Network？

它是 OpenAI 于 2026 年 6 月宣布的合作伙伴计划，分为三个层级：Select、Advanced 和 Elite。OpenAI 为其投入了 1.5 亿美元，目标是在 2026 年底前培训并赋能 30 万名认证顾问。

OpenAI 有面向顾问的认证吗？

OpenAI Certified 确实存在，但据文档记载，其访问权限仅限受邀的 Enterprise 和 Edu 组织。OpenAI Academy 的课程结束时颁发的是课程徽章，OpenAI 并不称之为认证。

在大型企业中，谁来部署专业化的 dot？

据 OpenAI 称，在发布时，由其自己的工程师在与客户的试点中进行部署。与 Microsoft 合作时，OpenAI 将这些 dot 与 Agent 365 中的治理和安全控制相连接。
