全文

认识 Method

Method 打造了连接消费者金融账户的最现代化方式。通过将实时负债连接与即时支付执行相结合，Method 的 API 旨在让人们能够轻松地将自己的金融账户连接到想要使用的应用和服务。我们已帮助 4500 多万用户以免凭证方式连接了 3.5 亿多个负债账户，并处理了超过 25 亿美元的支付，帮助用户节省了数百万美元的利息。美国每三张信用卡中就有一张处于 Method 生态系统中，SoFi、Bilt、Cleo、Sezzle、Figure 和 Aven 等领先金融机构都依赖我们的 API 为数百万消费者打造出色的体验。我们是一支 50 多人的团队，分布在奥斯汀、旧金山、纽约市和华盛顿特区的办公室！我们期待与来自 Andreessen Horowitz、Emergence Capital、Y Combinator、Avra 和 Ardent 的投资者和顾问携手，继续保持这一发展势头。欲了解更多关于我们的信息，请查看我们的博客！

关于该职位

Method 的前沿部署工程师是直接与客户合作的工程师。你将加入工程团队，在客户签约时被分配给客户，并负责让每个客户成功上线 Method 的 API。这意味着与他们的工程师并肩工作，确切了解他们正在构建什么，并编写代码来弥合 Method 当前能力与他们上线需求之间的差距。

这是真正的工程工作。当客户需要某个端点尚不支持的配置能力时，你来构建它。当上线依赖于基于现有服务构建的新功能时，你来界定范围并交付。你还将负责每个集成客户都会接触到的各个界面：我们的 SDK、OpenAPI 规范、客户配置工具以及集成指南。对于 Method 最大的战略客户，你将长期跟进，与前沿部署 PM 搭档，构建定制扩展并推动向新产品拓展。

如果你想要一份既有工程岗位的深度，又能直接对接客户，并在构建、销售和产品方面获得广泛职责的职位，这个职位正是为此而设。

你的工作内容

  • 从入驻到上线再到扩展，全程负责客户集成，编写必要的代码使 Method 的 API 适配每个客户的使用场景
  • 直接从客户处收集需求，并将其转化为范围明确、可交付的工作
  • 交付扩展 Method 平台的功能，从现有端点的新参数和配置能力，到基于现有服务和模式构建的更大功能
  • 负责 SDK、OpenAPI 规范、客户配置工具，以及集成客户所依赖的集成指南和文档
  • 作为战略客户的工程负责人长期跟进，与前沿部署 PM 合作进行定制开发和业务拓展
  • 每天参加客户会议，包括与客户工程负责人的会议
  • 与产品工程师一起参与工程值班轮换和工程例会
  • 将反复出现的客户请求转化为反馈和提案，让平台对每一位客户都更好

你是谁

  • 3 年以上专业工作经验
  • 一名优秀的软件工程师，有交付生产代码的实绩
  • 精通 API：理解 API 设计模式以及集成在生产环境中的表现
  • 你真心希望与客户合作，并从了解他们想要构建的东西中获得动力
  • 你行动迅速，能在需求变化时快速调整
  • 你能自如地在大型现有代码库中工作并扩展其模式
  • 你对结果负责，而不仅仅是完成任务单
  • 你能在早期阶段的团队环境中如鱼得水，并定义工作的完成方式

加分项

  • 在 API 优先的公司担任过前沿部署工程师、解决方案工程师或集成工程师的经验
  • 在人才密度高、服务大型企业客户的公司工作的经验
  • 有面向客户的创始人或早期员工经历
  • 接触过金融科技、支付或金融数据 API

到岗办公政策

对于 Method 的大多数职位，我们期望员工定期到我们位于纽约、奥斯汀、旧金山或华盛顿特区的办公中心之一现场办公。我们允许灵活地偶尔远程办公一周，但总体期望是平均每周至少到岗办公 2-3 天。全职远程办公是不可行的。
