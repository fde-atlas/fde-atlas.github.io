前沿部署工程师（内部工具）| Trexo Robotics

原标题：Forward Deployed Engineer (Internal tools) | Trexo Robotics

Zero G Talent · 2026-11-02 · 约 4 分钟读完

摘要

Trexo Robotics 招聘一名前沿部署工程师，负责内部工具建设。该公司开发助力儿童脑瘫患者行走的可穿戴外骨骼机器人，产品已在北美数百个家庭和多家顶级医院使用。此为新设的混合岗位，每周需在密西沙加办公室到岗三天。职责包括与财务、市场、生产等内部团队合作，找出运营瓶颈，用 LLM、Python、JavaScript 及 Zapier、Airtable、Salesforce 等工具构建 AI Agent、自动化流程、数据管道和仪表盘，并端到端负责项目。要求三年以上软件或数据工程经验，有生产级 LLM 应用（Agent、RAG、工作流）开发经验，熟悉 SQL、REST API。作为该岗位第一人，还需建立内部工具建设的标准与规范。

要点

  • Trexo Robotics 招聘首位前沿部署工程师，专注内部 AI 工具建设。
  • 岗位为混合办公，每周三天在密西沙加现场工作。
  • 职责涵盖诊断运营瓶颈并端到端交付自动化方案。
  • 要求三年以上经验及生产级 LLM 应用开发能力。
  • 作为首任者需制定内部工具建设的标准与实践。

任职要求

  • 3 年以上软件工程、数据工程或技术运营经验
  • 具备生产级 LLM 应用经验，涉及 AI Agent、RAG 或工作流
  • 精通 Python 和/或 JavaScript，用于系统集成
  • 精通 SQL 和数据处理，熟练使用 Excel 或 Google Sheets
  • 熟悉 REST API、webhook 和 JSON

工作内容

  • 设计并构建 AI 驱动的内部工具、AI Agent 和工作流
  • 与内部团队合作，识别并优先处理自动化瓶颈
  • 构建数据管道、集成和仪表盘，提供运营洞察
  • 与团队合作定义并跟踪有意义的 KPI
  • 端到端负责项目，从设计到部署

关于我们

Trexo Robotics 通过打造动力外穿式机器人来帮助人们实现行动能力。我们的首款产品是一款面向患有脑瘫等运动障碍儿童的机器人，它让许多孩子有生以来第一次能够行走。目前，该设备已被北美数百家家庭和顶尖医院使用。

我们始终致力于为所有人打造行动能力解决方案。在 Trexo Robotics，你将加入一个扁平化组织，与高度乐观、低调务实且才华出众的同事共事，共同解决难题。

关于该职位

我们正在寻找一位前沿部署工程师，直接与我们的团队合作，发掘真实的运营瓶颈，并构建解决这些瓶颈的自动化方案、AI Agent、仪表盘和工具。你将端到端地负责问题，从判断哪些问题值得解决，到交付持久可靠的解决方案，并持续观察其长期表现。

这不是一个问题已被预先界定好的岗位——你需要诊断哪些瓶颈值得解决，决定如何解决，并将方案从想法推进到落地实施。你将编写同事日常依赖的真实代码，与被自动化工作流程的员工并肩工作，并端到端地负责项目。

这是一个新设立的混合办公职位（每周 3 天在密西沙加现场办公）。

工作内容

  • 使用 LLM、Python、JavaScript 以及 Zapier/Make、Airtable 和 Salesforce 等工具，设计并构建 AI 驱动的内部工具、AI Agent 和工作流。
  • 直接与内部团队（如财务、市场、业务运营、法规或生产部门）合作，了解工作的实际运作方式，识别影响最大的瓶颈，并确定自动化的优先级。
  • 构建并改进数据管道、集成和仪表盘，将零散的运营数据转化为可靠、可执行的洞察。
  • 与团队合作定义并跟踪有意义的 KPI，调查问题，并将分析转化为清晰的建议和决策。
  • 端到端地负责项目，从诊断问题、设计解决方案，到部署、监控、文档编写和持续改进。
  • 作为该职位的第一位成员，为 Trexo 内部工具的构建和扩展建立标准、实践和基础。

必备技能

  • 3 年以上软件工程、数据工程、技术运营或类似岗位经验，最好曾构建过供其他团队使用的工具或自动化流程。
  • 具有构建生产级 LLM 应用（Agent、工具调用/函数调用、RAG 或自动化工作流）的实战经验，而不仅仅是演示或课程作业。
  • 熟练使用 AI 开发工具和平台（例如 Claude Code、Curson、Codex 或类似的专业级 Agentic 编程工具）
  • 扎实的 Python 和/或 JavaScript 技能，能够构建集成并处理无代码工具无法应对的场景。
  • 扎实的 SQL 和数据处理能力，包括处理关系型数据、清洗杂乱数据集以及评估数据质量。熟练使用 Excel 或 Google Sheets。
  • 有构建仪表板、报表或数据管道以支持实际业务决策的经验，并对哪些指标真正重要有良好的判断力。
  • 熟悉 REST API、Webhook 和 JSON，有连接 CRM、电子邮件、日历、电子表格和内部数据库等实际系统的经验。
  • 出色的沟通与协作能力，能够与非技术团队紧密合作，并将技术或数据洞察转化为清晰的行动。
  • 能够适应模糊性和极少的流程规范，因为作为该职位的第一位成员，你将亲自定义这两者。

加分项

  • 有使用 MCP 服务器、Agent 框架（如 LangChain、LangGraph）或工作流编排工具（如 n8n）的经验。
  • 有使用 BI/仪表板工具（Tableau、Quicksight、Looker、Metabase 或类似工具）的经验。
  • 有在具备一定规模的公司使用 Airtable、Zapier 或 Salesforce 等 CRM（流程、字段、报表）的经验。
  • 有早期创业公司的工作经验，尤其是曾帮助搭建新的内部职能。
  • 对漏斗分析和营销归因有基本了解。
  • 有处理医疗健康、医疗器械或其他受监管/合规敏感数据的经验。
