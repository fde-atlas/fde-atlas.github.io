Snowflake SQL 与数据工程环节背后的概念

这些题目所假设的术语和思维模型。基础部分免费学习；更深层次的、决定面试成败的理念属于付费内容。

基础SQL 窗口函数窗口函数在与当前行相关的一组行上计算数值，而不会将这些行合并，因此你可以在保留每一行的同时进行排名、与相邻行比较或计算累计总和。这是分析师在纯 SQL 中回答“与什么相比？”这类问题的方式，大多数面试官会用它来区分“懂 SQL 的人”和“只懂 GROUP BY 的人”。

Snowflake 的前沿部署工程师面试环节会涉及 sql 与数据工程类问题，例如“RANK、DENSE_RANK 和 ROW_NUMBER 有什么区别？什么时候这个选择才真正重要？”、“编写 SQL：按区域、按月统计收入排名前 3 的产品。”、“用 SQL 对原始事件流进行会话切分：超过 30 分钟的间隔即开启新会话。”。窗口函数、间隙与孤岛、Spark 内部机制、湖仓设计、幂等管道和 CDC：这就是 Databricks/Snowflake/Palantir 的数据方向。完整题集按由易到难排序并附专家答案，见下文。

Snowflake 公布了一套通用的工程流程，包括技术面试和面试小组，并按级别提供可选的 Tech Talk。我们尚未验证解决方案架构师岗位的单一匹配流程。请准备数据架构以及技术权衡的沟通，并确认该岗位的具体练习环节。
