摘要

FDE-Gym 是一个测试 AI Agent 能否胜任前沿部署工程师工作的基准数据集，发布于 Hugging Face。它包含 20 个真实场景任务（另有 75 个变体留作榜单评测），覆盖银行、医院、物流、电网等行业。Agent 需进入模拟的客户环境、与利益相关者沟通并交付可上生产的系统。评分以标准化业务提升计算，0 为现状基线，1 为参考方案，并扣除询问相关方的接触成本。数据集公开但需接受许可条款，禁止将文件用于模型训练或公开评分标准。

要点

  • 基准测试 AI Agent 能否完成前沿部署工程师的实际工作。
  • 含 20 个原始场景与 75 个留出变体，共 95 个任务。
  • 场景覆盖银行、医院、物流、电网、制造业等行业。
  • 评分 = 标准化业务提升减去利益相关者接触成本。
  • 数据需接受许可条款访问，禁止用于训练或公开泄露。

FDE-Gym：AI 交付的最后一公里

FDE-Gym 测试 AI Agent 能否胜任前沿部署工程师的工作：进入客户的运行环境，弄清其中真正重要的东西，做出这项工作所需的决策，并交付一个能在生产环境中稳定运行的系统。

论文：arXiv:2610.22350 · 排行榜：https://fde-gym.com/paper

本仓库包含 20 个场景中每个场景的原始任务。

本仓库包含的内容

cases/<scenario>/
  engagement.json    title, what the scenario runs (model gateway, simulated services)
  briefs/L0..L3.md   the task instruction the agent receives, at four levels (L0 says most, L3 least)
  world/             the customer's environment: documents, data, the system as found
  npcs.json          the customer's stakeholders: what each knows, and the contact cost of asking
  build_world.py     builds the agent's workspace
  gen.py, ...        generators for the data and for the held-out production traffic
  services/          simulated customer services, where a scenario has them
  grader.py          replays production on the delivered system and scores it
  truth.json         reference facts used in scoring
  variants.json      scoring anchors (the system as found, the reference solution)
data/raw/review/     public data used by review_screening (SYNERGY and OpenAlex, both CC0)

charge_care_config电动车充电网络：在固定弱模型的低代码 Agent 平台上提供司机支持
estate_repair_cases住宅小区：连续数周运行基金出资的大型维修的 Agent
fund_recon基金运营：清理对账差异的 Agent
grid_interval_pipeline供电公司：每夜的电量区间结算任务
hiring_screen物流公司：跨两个司法辖区的求职者筛选

本仓库不包含的内容

该基准测试包含 95 个任务：即这 20 个原始任务及其 75 个变体，其中客户世界的事实有所不同。这些变体被保留不公开，仅在排行榜上评分。参考解决方案也不予发布。

运行一个案例

这些案例在 FDE-Gym 测试框架上运行，该框架根据场景构建工作区，提供其服务和人员，并对交付成果进行评分：https://github.com/deeplethe/fde-gym（这些文件已使用标签

harness-v1.1.0

）进行核对。将

cases/

和

data/

放在

harness/

旁边，或将

FDEGYM_ENGAGEMENTS

指向

cases/

。需要 Python 3.9 或更高版本，且仅使用标准库。

python3 harness/run.py new   --engagement campus_booking --level L3 --name campus-L3-1
python3 harness/run.py serve --name campus-L3-1
python3 harness/run.py grade --name campus-L3-1

分数以归一化业务提升值报告：0 为不作为的基线（即现有系统），1 为参考解决方案。FDE-Gym 分数为该提升值减去利益相关者沟通成本。
