免费 AI 构建者速成课程

原标题：The Free AI Builders Crash Course

Maven · 2026-08-26 · 约 3 分钟读完

摘要

Maven 推出的免费 AI Builders 直播系列课程，覆盖从零构建 LLM、Agent 模式、检索、评测、安全治理到生产落地的完整链路。课程面向工程师、数据科学家和技术负责人，包含多场专题：与 Workato 合讲的七要素生产级 AI Agent 框架、与 Atlan 合讲的企业上下文层架构、与 1Password 合讲的 Agent 安全实践，以及由 Google 的 FDE 讲师主持的前沿部署工程师面试备考专场。

要点

  • 免费直播系列，覆盖 LLM 构建到生产落地的全流程。
  • 七要素框架讲解如何安全地让 Agent 执行真实业务操作。
  • 企业上下文层专场解决 Agent 缺乏业务知识的问题。
  • 1Password 专场讲解 AI Agent 的密钥与权限安全。
  • FDE 面试备考专场由 Google 的前沿部署工程师讲授。

从零构建你自己的 LLM（真正理解 AI）

现在每家公司都在向 LLM 砸钱，但大多数团队仍然说不清模型为什么会有那样的表现。从零构建一个 LLM，情况就会改变。你不再把它当作黑盒，而是开始确切地知道该调整什么、为什么调整、何时调整，从而真正解决业务问题，而不是双手合十祈祷输出看起来没问题

生产级 AI Agent 的七要素框架

真正的 AI Agent 会采取行动。它转移资金、更新记录、取消订单、更改企业赖以运转的系统。这正是 Agent 强大之处，但几乎没有人教如何安全地做到这一点。本节课与 Workato——治理和扩展企业级 AI 的平台——合作，讲解一套建立在真实生产经验之上的工程方法论。课程结束后，你将能够判断任何 Agent 是否已准备好被托付真实的工作。

免费前沿部署工程师（FDE）面试准备

FDE 职位是当前最热门的 AI 工作之一——Anthropic、OpenAI、Google 提供百万美元以上的薪酬包，但也是最容易准备错误的职位。大多数候选人按照典型的 SWE 面试流程来准备：LeetCode、系统设计，诸如此类。FDE 面试考察的是不同的东西——你能否为真实世界构建 AI 系统、界定混乱的客户问题，并在模糊不清的情况下做出判断。如果忽略了这一点，即使是优秀的工程师也会失败。

保护 AI Agent 安全：1Password 实战手册

大多数团队并不知道自己组织里到底运行着多少 AI Agent。它们存在于浏览器、IDE 和开发者的笔记本电脑中，通常使用几个月前有人粘贴进去并早已遗忘的 API 密钥进行身份验证。一旦该密钥泄露，攻击者就能获得该 Agent 所能访问的一切。而当出现问题时，往往没有记录表明是哪个 Agent 所为，也不知道是谁授权的。让我们在本次与 1Password 的会议中深入探讨这个问题。
