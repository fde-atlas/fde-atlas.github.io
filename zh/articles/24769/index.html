这篇由 DeFactory 代表德满翔平撰写的文章面向初学者，解释软件开发的六个阶段中编程所处的位置，指出编程是在设计文档基础上实现功能的实质开发环节，并区分功能需求与非功能需求。文章随后介绍 JavaScript、Python、PHP、Ruby、Java、C++、C#、Kotlin、Go 等主流语言的特点与代表服务，并引用 Stack Overflow 2025 调查及该公司 BizDev Tech 平台 183 件案件数据，说明各语言的使用率与平均月单价（整体约 79.8 万日元），最后按手机应用、游戏、Web 系统、AI 等用途给出语言选择建议。

  • Stack Overflow 2025 调查：JavaScript 使用率 66%，Python 57.9%。

软件开发大致分为以下几个环节。

1. 需求定义・要求定义 2. 设计 3. 开发 4. 测试 5. 发布 6. 维护・运营

其中进行编程的是“3. 开发”阶段。

首先，在需求定义・要求定义阶段，需要明确要开发的软件需要哪些功能。然后，在设计阶段，编写实现这些功能的设计文档。

开发是根据设计阶段编写的UI等外观以及内部功能相关的基本设计文档・详细设计文档，实际进行编码的环节。也就是说，编程属于实现功能的工作，可以说是软件实质性的开发工作。

具体进行编程的部分包括以下几个方面。

・基本功能 ・数据的输入输出 ・业务流程图 ・操作界面的布局 ・服务器 ・与函数处理相关的批处理 ・数据库 ・维护 等众多方面

此外，编程的内容大致可分为功能性需求和非功能性需求。

功能性需求是指客户对软件所要求的“功能”。例如“能够高效处理〇〇数据的功能”，可以说是该项目中最低限度必须达成的部分。

而非功能性需求则是指功能性需求之外的、与软件质量相关的部分。具体包括“可用性”“性能・可扩展性”“可迁移性”“运营・可维护性”“安全性”“系统环境・生态”等方面。

通过在编程中考虑非功能性需求，例如如何让实现的功能尽可能高效且安全地运行、如何提高易用性等，可以提升软件整体的品质。

此外，作为基础设施的建设，服务器的搭建也非常重要。不仅包括硬件服务器，Web服务器、数据库服务器、文件服务器、邮件服务器等软件服务器也需要进行适当的搭建。

在编程语言中，它是最具代表性的语言。虽然处理速度本身并不算快，但编码简单，自由度也相对较高。

PHP 擅长 Web 系统的开发，例如根据用户改变网站上显示的信息等，尤其擅长创建动态页面。可以开发各种 Web 系统，例如创建咨询表单和搜索功能、构建电商网站等。

另一方面，PHP 不擅长高级的数值处理，因此不太适合开发计算量大的任务或图形表现类的任务。

Facebook、Wikipedia、ココナラ 等

JavaScript 与 PHP 一样，也是非常流行的编程语言之一。可以进行从简单处理到复杂处理的广泛编程，也被用于创建网站的动态页面以及游戏开发等。

更改文字的颜色和大小、切换图片等，可以只让网站画面的一部分动起来，因此也擅长开发在浏览器上具有高级动态效果的应用等。例如，Google 文档和 Google 表格就是由 JavaScript 驱动的应用之一。

Kindle Cloud Reader、Google 文档／Google 表格、カグサイズ検索 等

Python 是 1991 年开发的编程语言，其特点是在控制代码量的同时能够简洁地编写。由于其易写易读，程序员和工程师之间的熟练度差异不易显现，因此在多人共享的项目中也能发挥重要作用。

除了图像处理、视频处理和数值处理之外，与 Web 开发和数据库相关的库也十分丰富，因此可以应对各种开发需求。

虽然是一门历史悠久的语言，但近年来在发展尤为显著的 AI 和机器学习领域，Python 在深度学习处理方面具有优势。

不过，执行速度慢是其弱点，因此可能不太适合大型项目或游戏等需要快速处理速度的开发。

YouTube、Dropbox、Instagram 等

Ruby 是由日本人开发的编程语言。其特点是编码简洁、易于读写，即使采用自己的风格编写也没问题，因此许多开发公司都能使用它进行开发。

Ruby 与 Python 有很多共同点，基本上用 Ruby 能开发的东西用 Python 也可以开发。

但是，这两者之间存在以下差异。

・Ruby：适合构建电商网站、应用网站等利用框架的 Web 系统

・Python：适合开发运用 AI 进行解析、分析等的软件

クラウドワークス、价格.com、Hulu 等

Java 是在世界范围内广泛使用的编程语言，可以进行 Web 系统、应用等各个领域的开发。

Java 有一句宣传语：“Write Once, Run Anywhere”，意思是“一次编写，到处运行”。正如这句话所说，用 Java 可以编写出在 Mac、Windows 等不同操作系统上基本上都能在任意环境中流畅运行的程序。

Java 具有技术稳定性、顶级的处理速度、高安全性等诸多优势，甚至被用于 Android 应用开发和大规模系统开发，是一门值得信赖的语言。

另外，JavaScript 只是名字相似，两者完全没有关联，是完全不同的东西，请注意不要混淆。

Evernote、楽天、Twitter 等

这是一门被称为“C Plus”“C Plus Plus”等的编程语言，由用于快速驱动计算机的 C 语言派生而来。

通用性高，可以在 IoT、游戏、操作系统等各种领域进行开发。实际上，用 C++ 开发的例子包括 Google 的浏览器“Chrome”，以及开发游戏《堡垒之夜》的 Epic Games 的“Unreal-Engine”等。

由于 C++ 本来就是从重视计算机处理速度的 C 语言派生而来，因此适合对处理速度和复杂处理有要求的开发。

Google Chrome、Unreal-Engine、Cocos2d-x 等

这是一门 C 语言体系的编程语言，最初是为 Windows 专门开发的。现在支持的操作系统也在增加，包括 Mac 和 Linux 等。

其语法本身与 C 语言相似，但受 Java 影响较大，特点是融合了 C++ 和 Java 的优点。

由于它本来就是用于 Windows 的语言，许多 Windows 应用都是用 C# 开发的。此外，它还被用于许多 Web 应用、游戏和手机应用的开发等，可以说是一门灵活且高效的开发语言。

MSN、Bing、Unity 等

Kotlin 是 2011 年开发的比较新的编程语言，加上 Google 将其采用为 Android 的官方开发语言，如今在 Android 软件开发中被广泛使用。

它拥有独特的语法，与 Java 等有很多不同之处，但其一大特点是可以在开发时调用已经用 Java 编写的源代码，或复用用 Java 开发的资产。

Uber、Netflix、LINE 等

Go 是 Google 开发的编程语言，特点是“简洁且能进行高效的高速处理”。

由于它可以在 Windows、Mac 等不同操作系统环境中运行，因此适合构建 Web 系统、Web 服务器以及应用开发等。

实际上，YouTube 和 Mercari 等用户众多、需要处理海量数据的软件和应用的开发中就使用了 Go。

Mercari、グノシー、クックパッド 等

如上文所介绍，编程语言种类非常多。每种语言都有各自擅长和不擅长之处，根据想要开发的内容选择合适的语言，在软件开发中非常重要。

作为智能手机应用的开发用途，Java、Kotlin、Go语言等比较适合。

由于Java的通用性很高，许多用Java开发的应用已经在Google Play等平台上发布。此外，如前所述，Kotlin是在Android软件开发场景中经常使用的语言。

作为游戏的开发用途，C#和C++比较适合。C#被知名的游戏引擎采用，可信度很高；而C++凭借其处理速度的优势，对在线游戏的开发尤为有用。

作为Web系统的开发用途，PHP和JavaScript比较适合。

PHP可以应用于多种场景，能够顺畅地实现各种Web系统与数据库之间的联动。此外，JavaScript易于在浏览器上进行运行验证，这也是它适合Web系统开发的原因之一。

作为AI和机器学习领域的开发用途，Python和Java比较适合。尤其是Python，由于拥有丰富的库，在需要统计处理和高级计算的AI、机器学习领域的开发中不可或缺，因而备受关注。
