前沿部署工程师 | Applied Intuition

原标题：Forward Deployed Engineer | Applied Intuition

Zero G Talent · 2026-10-27 · 约 5 分钟读完

摘要

Applied Intuition 在伦敦招聘前沿部署工程师，面向国防与政府客户，负责将公司的车辆智能产品、Vehicle OS 与自动驾驶技术栈集成到军事平台。公司成立于 2017 年，估值 150 亿美元，全球前 20 大车企中有 18 家是其客户。该职位要求 C++ 与 Python 能力、系统部署与硬件集成经验，并须能取得英国安全审查许可。公司实行每周五天到岗办公，提供带薪假期、餐补、保险与学习津贴等福利。

要点

  • Applied Intuition 估值 150 亿美元，服务国防与汽车等行业。
  • 前沿部署工程师需将车辆智能产品集成到国防平台。
  • 要求精通 C++ 与 Python，并有系统部署经验。
  • 候选人须能持有英国安全审查许可。
  • 公司要求员工每周五天到办公室工作。

任职要求

  • 具备计算机科学或相关领域的扎实工程背景
  • 精通 C++ 和 Python 编程
  • 具有系统部署和硬件集成经验
  • 能在模糊的运营环境中出色地解决问题
  • 能够通过英国安全审查

工作内容

  • 为国防客户部署并落地车辆智能产品
  • 将工具和自动驾驶技术栈集成到国防平台中
  • 设计可扩展的客户合作与项目执行方案
  • 与工程、产品和客户团队协作
  • 在动态环境中推动技术项目完成

Applied Intuition, Inc. 正在驱动物理 AI 的未来。这家硅谷公司成立于 2017 年，目前估值达 150 亿美元，正在打造让地球上每一台移动的机器都具备智能所需的数字基础设施。Applied Intuition 在三大核心领域为汽车、国防、卡车运输、建筑、采矿和农业行业提供服务：工具与基础设施、操作系统以及自动驾驶。全球前 20 大汽车制造商中的 18 家，以及美国军方及其盟友，都信赖该公司的解决方案来实现物理智能。Applied Intuition 总部位于加利福尼亚州森尼韦尔，在华盛顿特区、圣地亚哥、佛罗里达州沃尔顿堡滩、密歇根州安娜堡、伦敦、斯图加特、慕尼黑、斯德哥尔摩、班加罗尔、首尔和东京设有办事处。了解更多信息，请访问 applied.co。

我们是一家实行办公室办公的公司，期望全职员工每周主要在 Applied Intuition 办公室工作 5 天。不过，我们也认识到灵活性的重要性，并信任员工能够合理安排自己的日程。这可能包括偶尔远程办公、先在家参加晨会再前往办公室，或在需要时提前下班以照顾家庭事务。此办公室办公要求不适用于承包商职位

关于该职位

作为一名前沿部署工程师，你将在小团队中工作，负责高风险项目的端到端执行。你将成为 Applied Intuition 的新型车辆智能平台与客户真实运营环境之间的技术桥梁。

该职位既要求深厚的技术功底，也要求卓越的运营能力。你将与国防和政府客户合作，在严苛的作战环境中将我们的工具、Vehicle OS 和自动驾驶技术栈与国防平台集成。独特优势在于：你可以利用我们成熟的商用技术和快速演进的产品套件，交付传统国防承包商需要数年才能开发出的能力。你将解决涵盖核心软件工程、系统部署、硬件集成以及其间各类环节的问题，确保任务成功。

在 Applied Intuition，你将：

  • 直接与国防和政府客户合作，在军事和政府环境中部署、集成并实际应用 Applied Intuition 的车辆智能产品——从国防承包商到前沿作战基地
  • 应对广泛的技术挑战，包括软件工程、操作系统配置、系统部署和硬件集成
  • 连接客户自建系统与 Applied 的解决方案，交付切实价值
  • 设计并实施可扩展、一致性的客户沟通与项目执行方法
  • 开发能够提升各项目一致性和可扩展性的架构解决方案
  • 与内部工程、产品和客户团队协作，确保取得成功成果
  • 对技术成果负责，推动项目完成，并适应不断变化的需求和优先级

我们寻找具备以下条件的人才：

  • 拥有扎实的工程背景，最好是计算机工程、计算机科学、航空航天工程等领域
  • 优秀的工程师，熟练掌握 C++、Python 等编程语言
  • 在软件工程、操作系统及部分硬件方面拥有广泛的技术经验
  • 具备支持复杂系统集成与部署的经验
  • 出色的问题解决能力，并能在高度模糊、快速演变的作战环境中独立发展并创新
  • 卓越的沟通能力，专注于解决客户问题
  • 具备推动客户合作并取得成功的经验
  • 推荐人会将你描述为低调谦逊、高度积极、有主见且深思熟虑、善于沟通、乐于倾听的人

差旅要求：

  • 愿意为公司业务在办公室之间以及前往客户现场出差

加分项：

  • 曾与政府客户、国防承包商合作，或在军事环境中工作的经验
  • 熟悉系统架构和可扩展解决方案的设计
  • 具备国防、汽车、机器人或相关行业的经验

安全要求：

  • 必须能够获得英国安全审查许可（现持有或曾持有者优先）

福利：

  • 每年 25 天带薪休假
  • 每日餐饮福利：£19 午餐预算和 £19 晚餐预算，办公室内还提供免费早餐、零食和饮品
  • 每月最高 £300 的私人医疗保险（PMI）报销（个人或家庭保单）；每月最高 £250 的人寿保险和重大疾病保险
  • 工作场所养老金计划，雇主匹配缴纳 5%
  • 每年 £795 的学习与发展预算和每年 £475 的健身预算
  • 骑行上班计划（Cycle to Work Scheme），以税收优惠方式购买通勤自行车及配件
  • 慷慨的育儿假：在法定育儿假基础上额外提供

未完全满足所有要求？如果你对这个职位充满热情，但过往经历与职位描述中的每项资格条件并非完全吻合，我们仍鼓励你申请。你或许正是这个职位或其他职位的合适人选。

Applied Intuition 是一家机会均等雇主，同时也是联邦承包商或分包商。因此，双方同意在适用范围内遵守 41 CFR 60-1.4(a)、41 CFR 60-300.5(a) 和 41 CFR 60-741.5(a) 的要求，且这些法规在此以引用方式纳入。这些法规禁止基于受保护退伍军人或残障人士身份对合格个人进行歧视，并禁止基于种族、肤色、宗教、性别、性取向、性别认同或国籍对所有个人进行歧视。这些法规要求适用的主承包商和分包商采取积极行动，在雇用和晋升方面不因种族、肤色、宗教、性别、性取向、性别认同、国籍、受保护退伍军人身份或残障而区别对待个人。双方还同意在适用范围内遵守第 13496 号行政命令（29 CFR 第 471 部分，A 分部附录 A）中关于联邦劳动法下员工权利通知的规定。
