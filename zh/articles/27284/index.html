前沿部署工程师，AI Gateway（APJ）| Kong

原标题：Forward-Deployed Engineer, AI Gateway (APJ) | Kong

Zero G Talent · 2026-11-20 · 约 3 分钟读完

摘要

Kong 在亚太区招聘 AI Gateway 方向的前沿部署工程师。该职位要求候选人深入企业客户现场，负责从技术调研、架构设计到试点落地的全过程，确保客户的 AI 应用在真实生产环境中安全运行，而非停留在演示阶段。候选人需具备 Go、Python 或 TypeScript 的生产级开发经验，熟悉 API 网关、Kubernetes、OAuth/OIDC、mTLS 等基础设施技术，并了解 LLM、Agent 模式、MCP 与评测。职责包括设计跨模型、API、身份与策略的运行时架构，解决试点和生产中的认证、可观测性、延迟与成本问题，并将现场经验沉淀为可复用模式反馈给产品团队。该岗位强调端到端拥有技术交付成果，从试点推进到付费转化，并需定期与 Kong 内部工程团队协作。

要点

  • Kong 在 APJ 招聘 AI Gateway 前沿部署工程师，面向企业客户现场交付。
  • 要求 Go、Python 或 TypeScript 生产级开发经验及客户侧技术岗位背景。
  • 需掌握 API 网关、Kubernetes、OAuth/OIDC、mTLS 及 LLM、MCP、评测等技术。
  • 职责覆盖从技术调研到试点付费转化的端到端技术路径。
  • 需将现场经验沉淀为可复用模式并反馈给产品与工程团队。

任职要求

  • 具备 Go、Python 或 TypeScript 的生产级软件开发经验
  • 拥有前沿部署或解决方案架构方向的面向客户技术岗位经验
  • 熟悉身份、网络、安全与可观测性方面的企业级架构
  • 了解 LLM 与 AI Agent 模式，包括 MCP 与评测
  • 熟悉 API 网关、Kubernetes、OAuth/OIDC、mTLS 与策略执行

工作内容

  • 与客户团队共同主导 AI、API 与 AI Agent 相关的技术调研
  • 设计涵盖模型、API、MCP、身份与策略的运行时架构
  • 为生产流量构建原型、集成方案与参考实现
  • 消除试点与生产环境中的阻碍，包括认证与可观测性问题
  • 负责从试点到付费的完整技术路径，直至工作负载上线运行

关于该职位：

  • 如果您认为自己不完全符合以下所有条件，但仍对该职位感兴趣，欢迎申请。没有人能满足所有要求——我们寻找的是在少数领域特别出色，同时对其他领域也有一定兴趣和能力的候选人。
  • 您将帮助客户在真实环境中、以生产级标准安全地落地他们的首个战略性 AI 用例。不是演示，也不是悄然夭折的概念验证，而是真实的流量、真实的身份、真实的策略。
  • 作为 APJ 地区的前沿部署工程师，您将与该地区一些最重要企业的平台、安全和工程团队并肩工作，负责从首次技术调研电话到工作负载真正上线运行的完整技术路径。您是一名具备企业架构直觉的建设者，能够赢得资深工程师和安全架构师的信任，并能从容应对 API、AI Gateway、AI Agent、MCP、身份与策略等方面的各种不确定性。
  • 这不是仅做演示的售前工程师岗位，也不是基于工单的实施咨询工作。您将端到端地负责战略性 AI 商机的技术成功，并将所学带回 Kong 的工程团队，让下一单成交得更快。

工作内容

  • 与客户的平台、安全和工程团队共同主导 AI、API 与 AI Agent 相关的技术调研。
  • 设计涵盖模型、API、MCP 与工具访问、身份与策略的运行时架构。
  • 构建原型、集成方案、评测流程和参考实现，证明 Kong 能够治理真实的生产流量。
  • 消除试点与生产环境中的阻碍：认证、网络、可观测性、延迟与成本。
  • 负责从试点到付费的完整技术路径，并坚持跟进直至工作负载上线运行。
  • 将你构建的成果转化为可复用的模式，让下一个 AI Gateway 项目的赢单速度更快、成本更低。
  • 定期深入 Kong 内部工程团队，与工程师结对开展 AI Gateway 和智能体路线图相关工作。
  • 在竞争对手定义话语权之前，将一线模式和路线图关键需求直接反馈给产品团队。
  • 与 APJ 地区的销售、解决方案工程和客户成功团队协作，共同推进战略性 AI 机会。

你将带来：

  • 扎实的工程实战背景，具备构建和交付生产级软件的经验（Go、Python、TypeScript 或类似语言）。
  • 具备面向客户的技术岗位经验，如前沿部署工程师、解决方案架构、资深或首席工程师，或技术咨询。
  • 企业架构直觉：能够在复杂环境中针对身份、网络、安全和可观测性约束进行设计。
  • 具备 LLM 和智能体模式的应用知识：模型 API、工具调用、MCP、评测以及成本与延迟的权衡。
  • 具备 API 网关或基础设施经验：Kubernetes、服务网格、OAuth/OIDC、mTLS、策略执行。
  • 在资深工程师和安全架构师中具备可信度。你能够主导一场技术讨论，从白板推演到可运行的代码。
  • 你对结果负责，而非只处理工单。你能从容应对模糊性，并推动工作直至完成。
  • 具备优秀的英语书面和口头沟通能力；掌握其他欧洲语言者优先。
  • 愿意根据需要前往 APJ 地区的客户现场出差。

加分项：

  • 曾在 AI 原生、开发者平台或基础设施公司工作。
  • 具备 Kong Gateway、Konnect 或其他 API 管理平台的使用经验。
  • 有开源贡献经历，或发布过参考架构或技术模式的良好记录。
