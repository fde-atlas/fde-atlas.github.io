前沿部署软件工程师 | Theseus

原标题：Forward Deployed Software Engineer | Theseus

Zero G Talent · 2026-04-01 · 约 2 分钟读完

摘要

Theseus 在旧金山招聘前沿部署软件工程师，负责将其 GPS 拒止环境下的无人机视觉定位系统部署到商用与政府无人机平台。工作涵盖基于 ArduPilot 的集成、Python 与 C++ 开发、软硬件联调、现场排障及操作员培训，并需频繁出差，包括前往乌克兰等前沿部署环境。公司强调小团队、高自主性与真实战场落地。

要点

  • Theseus 专注 GPS 拒止环境下的无人机视觉定位，产品已在实战环境使用。
  • 岗位负责端到端部署：集成、测试、现场排障到操作员交接。
  • 要求熟悉 ArduPilot、Python 或 C++，能独立解决真实环境问题。
  • 需频繁出差，包括乌克兰等前沿部署的作战环境。
  • 加分项包括 MAVLink、机载 Linux、PX4 及国防领域经验。

你需要具备

我们是谁

Theseus 是一家国防科技公司，致力于构建视觉定位技术，为未来 1000 万架无人机解决可靠性问题。我们专注于解决当今 GPS 受拒战场上的定位问题，因为我们认为这是无人机实现物理智能的最大障碍。

我们的产品目前已在真实的作战环境中投入使用。我们是一个规模虽小但高度负责、勇于担当的团队，我们正在寻找希望快速行动、在真实世界约束下构建产品、并有机会通过工作产生直接影响的工程师。

职位描述

我们正在寻找一位前沿部署软件工程师，负责将 Theseus 的产品部署到商用和政府无人机平台上。

这一职位处于软件、集成、测试和外场作业的交汇点。你将直接与自动驾驶系统、机载计算设备、传感器、操作员以及合作伙伴团队合作，让我们的产品完成集成、升空飞行，并在真实世界中创造价值。你应该能够在代码、硬件、外场调试和面向操作员的部署工作之间自如切换。

你将：

  • 负责 Theseus 系统在作战环境中的端到端部署，从初始集成到操作员交接以及持续的外场性能保障
  • 使用基于 ArduPilot 的系统将 Theseus 软件集成到无人机平台上
  • 编写和修改 Python 与 C++ 代码，以支持集成、工具开发、调试和部署工作流
  • 对自动驾驶系统、计算设备、传感器、网络、遥测和操作员界面等完整系统进行搭建、测试和故障排查
  • 直接与操作员和合作伙伴团队合作，了解任务需求，支持外场部署，并使系统适应真实的作战约束
  • 在外场对操作员和合作伙伴进行部署、故障排查和最佳实践方面的培训
  • 在真实条件下调试问题，并迅速将外场反馈转化为修复、产品改进以及更可复用的部署工作流
  • 根据需要出差，包括前往乌克兰及其他前沿部署的作战环境，以支持部署、测试和任务执行

你应具备以下条件

  • 拥有丰富的 ArduPilot 实操经验以及真实的无人机集成工作经验
  • 具备扎实的 Python 和/或 C++ 编程能力，能够构建工具、调试生产系统，并在软硬件混合技术栈中快速行动
  • 具备强烈的责任感和行动导向：你能够快速诊断问题、独立开展工作，并在真实世界约束下推动系统达成可用成果
  • 能够直接与操作人员或外部合作伙伴合作，并在快节奏的环境中清晰沟通
  • 愿意并能够经常出差，包括前往乌克兰及其他前沿部署的作业环境

加分项

  • 具有 MAVLink、伴飞计算机、机载 Linux 系统、遥测链路和现场网络方面的经验
  • 具有将软件集成到无人机、机器人或其他边缘硬件平台上的经验
  • 能够直接与操作人员合作，并根据任务特定的工作流程和约束条件调整系统
  • 具有 PX4、任务规划软件、遥测系统或面向操作人员的工具方面的经验
  • 具有国防、军民两用或其他高可靠性现场环境的工作经验
