前沿部署工程师 - 巴黎 | OpenAI | 法国巴黎

原标题：Forward Deployed Engineer - Paris | OpenAI | Paris, France

摘要

OpenAI 在巴黎招聘前沿部署工程师（FDE），负责与战略客户合作，将前沿模型落地为生产系统。职位要求五年以上工程或技术部署经验，需具备全栈编码能力（Python、JavaScript 等）和 LLM 系统部署经验。工作采用混合模式，每周三天到岗，出差比例最高可达 50%，公司提供搬迁支持。

要点

  • OpenAI 巴黎办公室招聘前沿部署工程师，岗位为混合办公，每周三天到岗。
  • FDE 负责从原型到稳定生产的端到端交付，直接嵌入客户团队工作。
  • 要求五年以上面向客户的工程经验，并能编写生产级全栈代码。
  • 需有 LLM 或生成式模型系统的构建或部署经验。
  • 出差比例最高 50%，公司提供搬迁协助。

任职要求

关于团队

OpenAI 的前沿部署工程团队与客户合作，将研究突破转化为生产系统。我们的工作处于客户交付与核心平台开发的交汇点。

关于职位

前沿部署工程师（FDE）与我们最重要的战略客户合作，负责前沿模型在生产环境中的复杂端到端部署。你将负责需求探索、技术范围界定、系统设计、构建和生产上线，并与客户的工程团队和领域团队直接协作。

你将通过生产环境的实际采用、可衡量的工作流影响，以及能够改变产品和模型路线图的评测驱动反馈来衡量成功。你将与我们的产品、研究、合作伙伴、GRC、安全和市场推广团队紧密合作。

该职位位于巴黎。我们采用每周 3 天到岗的混合办公模式，并提供搬迁协助。该职位需要出差，出差比例最高可达 50%。

在这个职位上，你将

  • 负责多个部署项目的技术交付，从首个原型到稳定的生产系统
  • 构建全栈系统，为客户创造价值，并提升我们的学习能力
  • 深度融入客户团队，理解他们的需求，并引导他们采用你构建的成果
  • 界定工作范围、安排交付顺序，并尽早清除障碍
  • 在范围、速度和质量之间做出权衡；调整计划以保障交付
  • 在进展或清晰度取决于代码时，直接参与编码
  • 将有效的工作模式沉淀为他人可用的工具、操作手册或构建模块
  • 分享一线反馈，帮助研究和产品团队了解模型在哪些方面表现出色、在哪些方面可以改进
  • 通过清晰的沟通和持续跟进推动团队前进

如果你具备以下条件，你可能非常适合这个职位

  • 拥有 5 年以上工程或技术部署经验，并包含面向客户的工作
  • 曾在快速变化或模糊的环境中界定并交付复杂系统
  • 使用 Python、JavaScript 或类似技术栈编写和评审覆盖前端与后端的生产级代码
  • 曾构建或部署由 LLM 或生成式模型驱动的系统，并理解模型行为如何影响产品体验
  • 善于化繁为简，能在压力下快速做出合理决策
  • 与工程师、产品团队和客户利益相关者清晰沟通
  • 及早发现风险并做出调整，同时不拖慢进度
  • 在高风险情况下展现冷静与判断力
