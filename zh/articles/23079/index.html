前沿部署工程师（售后）| Tennr

原标题：Forward Deployed Engineer (Post-Sales) | Tennr

Zero G Talent · 2026-03-30 · 约 3 分钟读完

摘要

Tennr 在纽约招聘售后方向的前沿部署工程师。Tennr 是一家医疗 AI 创业公司，用专有模型自动化保险报销等繁琐文书工作，减少患者转诊等待时间。该职位需端到端负责大型医疗系统客户的实施交付，从售前调研到上线及扩展，兼具技术顾问与项目负责人角色。要求 3 年以上 SaaS 交付经验，熟悉 API 与系统集成，最好有医疗行业背景。岗位每周四天到 Hudson Square 办公室工作，提供无限假期、全额医保等福利。

要点

  • Tennr 用 AI 自动化医疗后台文书，缩短患者转诊等待。
  • 前沿部署工程师需端到端负责企业级客户实施交付。
  • 要求 3 年以上 SaaS 交付经验，熟悉 API 与系统集成。
  • 医疗或复杂行业领域知识为重要加分项。
  • 职位位于纽约，每周四天到岗办公。

公司简介

如今，当您去看医生并被转诊给专科医生时，医生会发出转诊单并告诉您：“他们很快会联系您。”于是您开始等待。一直等。有时要等几天、几周，甚至几个月。为什么？因为医疗服务提供者常常被向保险公司收款所需的繁琐乏味的工作压得喘不过气来。Tennr 依托专有模型，处理复杂的文书工作，帮助患者顺利就诊、让医疗服务提供者获得报酬，帮助运营人员让患者在正确的时间、以正确的方式获得正确的诊疗。

职位描述

作为一名前沿部署工程师，您将主导 Tennr 最复杂客户——大型医疗系统、全国性医疗服务集团和企业合作伙伴——的自动化解决方案的设计、交付与持续优化。这是一个高度技术性、战略性且面向客户的职位，要求具备深厚的领域知识、高管层面的沟通能力以及出色的系统性思维。

您将端到端地负责实施工作：从售前调研和商业价值对齐，到上线及后续扩展。您既是值得信赖的技术顾问，也是项目负责人，将与客户高层利益相关者以及 Tennr 的跨职能团队紧密合作，确保长期成功。

该职位隶属于一个高绩效的实施小组，并直接影响 Tennr 的市场推广和产品战略。

职责

  • 主导从调研到上线后的端到端实施
  • 协调跨职能团队，管理项目交付、风险与变更
  • 开展运营审计，识别工作流缺口和自动化机会
  • 使用 Tennr 的平台和 API 设计可扩展、可配置的解决方案
  • 以自动化最佳实践重新构想流程，而非简单复制遗留系统
  • 与产品、工程和销售团队协作，共同确定解决方案和交付范围
  • 维护文档，促进知识转移，并改进内部交付工具
  • 支持销售战略，指导初级团队成员，并影响产品路线图

任职资格

  • 3 年以上 SaaS 交付或解决方案设计经验
  • 强烈优先考虑拥有计算机科学、工程或相关技术领域学位或辅修背景的候选人
  • 对 API、系统集成和技术架构有深入理解
  • 具备主导大型企业客户复杂技术项目的成功经验
  • 擅长向高管和技术受众传达技术概念
  • 具备在复杂组织架构中协调跨职能利益相关者的经验
  • 出色的问题解决能力，专注于战略性、可扩展的解决方案
  • 商业敏锐度和领域知识——最好具备医疗健康或类似复杂行业的经验
  • 能够从容应对模糊性和快节奏、非结构化的环境
  • 有指导他人并为团队最佳实践做出贡献的能力
  • 高度的主人翁意识和紧迫感——积极主动、善于应变、以影响力为导向

加分项

  • 熟悉工作流自动化、RPA 或企业集成平台（例如 MuleSoft、Workato）
  • 具有咨询、解决方案架构或技术客户成功方面的背景
  • 有初创公司环境或扩展交付职能的经验

为什么选择 Tennr？

  • 创造影响力：我们公司的价值观之一是“Cowboy（牛仔精神）”，意味着节奏由你来定。你不仅要谈论事情，还要把它们做成，并感受到自己的影响力。
  • 培养运营专长：深入了解扩展系统、工具和基础设施的内部运作
  • 有目的地创新：我们做这些不只是为了好玩（尽管我们确实玩得很开心）。在 Tennr，你将加入一支高水准的团队，专注于减少美国医疗系统中的患者延误。
  • 建立人际关系：每周 4 天在我们位于 Hudson Square 的办公室与志同道合、积极进取的伙伴协作交流
  • 免费午餐！还有满满一储藏室的零食。

福利

  • 位于 345 Hudson Street 的崭新漂亮办公室
  • 不限天数带薪休假
  • 100% 由公司支付的员工健康福利选项
  • 雇主资助的 401(k) 匹配
  • 有竞争力的育儿假
