如何在 2026 年成为 Palantir Foundry 开发者

原标题：How to Become a Palantir Foundry Developer in 2026

PAL4C LABS · 2026-10-27 · 约 10 分钟读完

摘要

文章介绍2026年起个人无需受雇于Palantir客户即可自学Foundry：Palantir Learn课程免费，AIP Developer Tier提供免费环境，且可通过Foundry Support申请认证考试码。作者给出按背景选择的学习顺序、三级认证体系（Specialist每次350美元）、六个月学习计划、作品集建议及雇主与薪资概况（美国基本工资约10万至20万美元）。

最后更新：2026 年 10 月 27 日

你现在无需就职于 Palantir 客户也能学习 Palantir Foundry。Palantir Learn 课程免费，AIP Developer Tier 提供免费环境，而且自 2026 年 8 月起，个人可以通过 Foundry Support 申请认证考试代码。先扎实掌握 SQL 和 PySpark，做一个真实项目，然后参加认证。我们在达拉斯地区的 Palantir 线下培训班正是基于这条路径构建的。

要成为 Palantir Foundry 开发者，请学习 SQL 和 PySpark，注册免费的 AIP Developer Tier 账户，学习 Palantir Learn 的免费课程，构建一个端到端项目，然后考取对应的 Associate 认证。

多年来，关于“如何学习 Foundry”这个问题的诚实答案是：先被一家拥有该平台的公司雇用。这个平台一直隐藏在企业合同背后。课程假设你拥有公司环境，而认证也基本只能通过客户和合作伙伴获得。

情况已经改变。

凭借免费的 Developer Tier 以及 Palantir 2026 年 8 月的认证更新，如今与 Palantir 毫无关联的工程师也可以自主学习、构建项目并考取认证。目前还没有任何针对这个主题排名的内容跟上这一变化。搜索一下，你得到的只是招聘信息。

我是 PAL4C Labs 的总监，这是一家位于德克萨斯州达拉斯地区的 Palantir 人才培养公司。我们为工程师提供 Foundry、Ontology 和 AIP 方面的培训，所以这正是我们每天都在思考的路径。本文涵盖不同背景所需的前置知识、免费访问渠道及其注意事项、学习顺序、2026 年认证阶梯、六个月计划、作品集项目，以及哪些公司在招聘。

Palantir Foundry 开发者到底做什么？

Palantir Foundry 开发者基于 Palantir 的运营数据平台进行开发。他们引入数据，在管道中清洗数据，将其建模为 Ontology 中的对象，并构建人们用来做决策的应用和 AI 工作流。

这个头衔涵盖的范围比听起来更广。有些 Foundry 开发者整天泡在 PySpark 管道里。另一些人则每周都在 Workshop 中为调度员和分析师构建应用，或者编写将 LLM 接入实时工作流的 AIP Logic 函数。我们的 Palantir Foundry 开发者招聘指南将这一职位拆分为六种不同的角色，在你选择方向之前，从雇主的角度读一读会很有价值。

先选定一个方向。你最终会接触到其他方向。

开始之前你应该了解什么？

SQL，人人必备。数据工程师需要 Python，应用开发者需要 TypeScript。还需要足够的数据建模知识，能够解释表和实体之间的区别，因为 Ontology 正是建立在这个概念之上的。

你的背景你已具备先学什么自然的第一个角色
数据工程师（Spark、dbt、Airflow）SQL、Python、管道Pipeline Builder、Code Repositories、Ontology 基础Foundry 数据工程师
软件开发者（React、Node）TypeScript、API、GitOntology、Functions、Workshop、OSDK应用开发者
数据或 BI 分析师（Power BI、Tableau）SQL、业务背景Pipeline Builder、Ontology、Workshop先做分析师型构建者，再成为应用开发者
转行者领域知识，可能懂一些 SQL在接触 Foundry 之前先打好 SQL 和 Python 基础给自己更多时间

对转行者说句直话。Foundry 比从零学 Spark 容易，但它不是绕过基础的捷径。头几个月先花在 SQL 和 Python 上。跳过这一步的人，第一次遇到 UI 无法解释原因的流水线故障时就会卡住。

没有雇主许可证也能学 Foundry 吗？

可以。Palantir Learn 的课程是免费的，AIP Developer Tier 通过 build.palantir.com 为个人提供免费的 Foundry 和 AIP 环境，但有使用限额和一些地域限制。

Palantir 的 Learn FAQ 指出所有学习课程均免费，而认证考试需要付费。Developer Tier 注册通过 build.palantir.com 进行，Palantir 员工指出存在一些限制，例如地域限制。根据关于免费层级限额的社区回答，Developer Tier 包含已正式发布的应用，Beta 应用需要提交支持请求，你的使用限额位于控制面板的 Your Plan 下。

我们见过人们踩过的几个坑。

  • 一位论坛用户发现，在 learn.palantir.com 上已使用过的手机号码会阻止在 build.palantir.com 上注册。从第一天起就在两个平台使用同一身份。
  • 一些 Palantir Learn 课程假设你拥有公司级的 Foundry 环境。筛选出你能在 Developer Tier 上完成的课程，否则你会在模块中途碰壁。
  • 在大型公开数据集上你会遇到计算限额。对数据进行抽样缩减。
  • 2026 年 8 月认证体系更新后，旧代金券已失效，所以不要购买二手代金券。

Palantir 还维护着一个开发者资源页面，将构建者引导至 build.palantir.com、Palantir Learn、开发者社区和 OSDK 教程。收藏它。

应该按什么顺序学习 Foundry？

存在两种流派。官方路径是先学流水线，再学 Ontology，然后是应用，最后是 AIP。很多自学的构建者先学 Ontology 和 Workshop，再学流水线。根据自身背景来选择。

Palantir Learn 将课程按角色路径组织，包括数据工程和应用开发。先学数据是合理的。底层数据不好，会毁掉其上的一切。

但一些学习者觉得数据管道很抽象，直到他们看到管道所处理的内容。在 Palantir 社区一个题为 New to Foundry, what helped you learn it quickly? 的帖子中，一位没有编程背景的构建者描述了自己从 Ontology Manager 和 Workshop 入手、之后再添加管道的经历，他写道：“一旦我有了一个可运行的模型，管道就变得容易理解多了。”同一个帖子还建议初学者把 Palantir 的 Speedrun 课程作为起点。

我们的建议，按背景划分。

如果你是从这里开始然后再然后
数据工程师管道和代码仓库OntologyWorkshop 和 AIP
软件开发者Ontology 和 FunctionsWorkshop 和 OSDK管道
分析师一个 Speedrun，从头到尾Ontology 和 Workshop管道

每个人最后都会走到 AIP。LLM 工作流的好坏取决于它们能触达的对象和操作。如果你想先了解概念，在用 Agent 构建任何东西之前，先阅读 Palantir AIP 到底做什么 和 Ontology 如何运作。

2026 年 Palantir 认证阶梯是如何运作的？

共三个级别。Foundry Aware 是免费的。Data Engineer、Application Developer 和 AI Engineer 的 Associate 考试是限时、开卷的选择题考试。Specialist 考试是实操的、有监考的构建考试，每次尝试费用为 350 美元。

Palantir 于 2026 年 7 月在其社区论坛上宣布了这次更新。Associate 考试于 8 月 3 日上线，有效期为两年。Specialist 考试随后于 9 月 30 日推出，每月举行一次，由 Ontologize 通过 Zoom 提供，分为三个阶段：先在无 AIP 的情况下规划 20 分钟，然后在有 AIP 的情况下构建 120 分钟，最后在关闭 AIP 的情况下修改 40 分钟。

级别方向形式费用谁可以参加
Foundry Aware一个基于 Foundry 和 AIP Aware 课程免费任何人
AssociateData Engineer、Application Developer、AI Engineer限时、开卷、选择题需要优惠码，价格未公布任何持有优惠码的人
Specialist同样三个方向3 小时有监考的实时构建每次尝试 350 美元持有对应 Associate 认证者

这是几乎没人写过的一点。根据 2026 年 8 月的一条 Palantir 员工回复，没有 Palantir 联系人的人可以通过 Developer Tier 账户向 Foundry Support 提交工单，团队可以生成一个优惠码让你免费参加考试。批准并不保证。不过，这是一扇两年前还不存在的门。

先考哪个？匹配你的方向。数据工程师考 Data Engineer Associate，应用开发者考 Application Developer，而 AI Engineer 则在其中一个之后。一次性培训十人以上的团队应改为阅读我们的 Foundry 企业团队培训与认证指南。

成为 Foundry 开发者的六个月计划

六个月的时间适合有一定 SQL 和 Python 基础、且在全职工作之余学习的人。数据工程师可以压缩这个周期。转行者应提前增加三个月的基础学习。

  • 第 1 个月：熟练掌握 SQL 和 Python，开通 Developer Tier 账户，并完成一个 Speedrun，这样你就完整接触过数据、Ontology 以及一个连通的应用。
  • 第 2 个月：学习 Palantir Learn 中与你角色匹配的学习路径，并在公开数据集上构建你的第一条数据管道，其中至少包含一个数据校验。
  • 第 3 个月：在 Ontology 中对该数据集建模，包含三到四个对象类型、链接类型，以及一个可编辑数据的操作类型。
  • 第 4 个月：在其上构建一个 Workshop 应用，添加一个 TypeScript 或 Python Function，并展示给一位非工程师看看。
  • 第 5 个月：添加一个 AIP Logic 函数并配上若干评测用例，然后撰写完整的项目文档并附上截图。
  • 第 6 个月：申请优惠码，参加对应的 Associate 认证考试，并开始求职，把这个项目作为你的核心展示作品。

为什么第 4 个月要找非工程师看？因为这正是这份工作的本质。如果你的应用让邻居看不懂，它也会让调度员看不懂。

Foundry 作品集里应该放什么？

一个端到端的项目胜过五个教程。招聘经理想看到的是：杂乱的数据变成一个能改变决策的可用应用，并且写下你的思考过程。

优秀的作品集项目通常是这样的。

  • 将城市 311 服务请求数据建模为包含 Requests、Neighborhoods 和 Crews 的 Ontology，并添加一个重新分配工作组的操作。公开数据，真实的运营逻辑。
  • 一个供应链玩具项目。包含 Shipment、Carrier、Dock，以及一个延迟交付警报。规模虽小，但能体现你以对象和操作进行思考的能力。
  • 领域是否与你想要工作的方向匹配？如果匹配就用它。面向医院系统的医疗排班，面向制造业的维护日志。
  • 一个 AIP Logic 函数，用于总结工单并提出下一步建议，同时配备能捕捉虚构零件编号的评测。

像写案例研究一样把它写出来。哪些数据很乱、你建模了什么、哪里出了问题、你会做哪些改进。截图很有帮助，因为 Developer Tier 之外没人能打开你的环境。

谁在招聘 Foundry 开发者，薪资如何？

三类雇主：Palantir 本身、Palantir 的合作伙伴和咨询公司，以及 Palantir 的客户。2026 年美国公布的基本薪资大多在约 10 万至 20 万美元之间。

雇主类型招聘示例公布薪资要求的 Foundry 经验
Palantir全栈软件工程师，应用开发，纽约基本薪资 $135,000 至 $200,000不要求
合作伙伴或咨询公司Guidehouse Palantir Foundry 开发者，2025$98,000 至 $163,0002 年以上实操经验
客户正在组建内部团队的银行、制造商、公用事业公司和政府机构因内部职级而异通常需要一定经验

作为背景，美国劳工统计局（BLS）2025 年 5 月软件开发人员的中位数薪资为 135,980 美元，而 Levels.fyi 显示 Palantir 软件工程师的总薪酬（含股票）平均约为 234,500 美元。

发现悖论了吗？Palantir 对该职位并不要求 Foundry 经验，但合作伙伴要求。他们把你的工时卖给客户，而客户期望你第一天就具备 Foundry 技能；与此同时，Palantir 招聘的是扎实的工程能力，然后自己教平台。所以现实的入行路径有两条：一是打好基础，瞄准 Palantir 或其前沿部署类职位，详见我们的前沿部署工程师指南；二是打造 Developer Tier 作品集并考取认证，瞄准客户和合作伙伴。

免费培训、付费课程，还是线下班？

先从免费的开始。只有当你需要学习框架、督促机制，或需要一位真正在生产环境中部署过 Foundry 的人提供反馈时，才付费。

选项费用最适合缺点
Palantir Learn 加 Developer Tier免费自驱型学习者没人审阅你的作业
Ontologize 培训与内容付费专家级考试备考、结构化自学仅限线上
线上班付费，有时需排队等候希望有固定学习计划的学员名额售罄
线下班，比如我们开设的付费喜欢在导师现场指导下动手学习的学员受地点限制，达拉斯地区或驻场

请保留一分怀疑，因为我们卖的就是第四行。我们的 Foundry 工程、Ontology 工程、AIP 工程和前沿部署工程方向仍在排期中，日期和定价会优先通知已注册的申请者。如果你足够自律，并且已经是在职数据工程师，免费路线完全可以带你走完全程。很多人并不需要我们。

你的下一步

Foundry 现已向个人开放。Learn 课程免费，Developer Tier 提供真实环境，Foundry Support 可向非合作伙伴发放考试代码。能被录用的工程师都具备扎实的 SQL 和 Python 能力、一个真实完整的端到端项目，以及对应的 Associate 认证。而 350 美元的 Specialist 认证，才是真正证明你具备构建能力的凭证。

PAL4C Labs 是一家位于达拉斯地区、由从业者创立的 Palantir 人才培养公司，为工程师提供培训，并帮助组织搭建 Palantir 团队。本周就开通你的 Developer Tier 账户；如果你更愿意在导师现场指导的课堂中学习，可以注册表达对 Foundry 工程班的兴趣。想了解哪个方向适合你？直接联系我们。

有志成为 Foundry 开发者的人常问的问题

不在客户公司工作，能学习 Palantir Foundry 吗？

从 2026 年起，完全可以。build.palantir.com 上的 AIP Developer Tier 免费，Palantir Learn 课程免费，Foundry Support 还能为 Developer Tier 用户生成考试优惠码。

Palantir Developer Tier 真的免费吗？

免费，但有使用限制。您不会被收费，但会遇到计算和存储的使用上限，且注册有地域限制。请在控制面板中查看“您的计划”以了解您的情况。

Palantir 认证费用是多少？

每次 Specialist 考试 350 美元。Foundry Aware 免费。Associate 考试需要促销码，非合作伙伴可以通过 Developer Tier 账户向 Foundry Support 申请，有时可免费获得。

需要学 TypeScript 吗，还是 Python 就够了？

取决于您的方向。数据工程师几乎可以完全使用 SQL 和 PySpark。应用开发人员在 Functions、OSDK 以及任何超出基础 Workshop 逻辑的场景中都需要 TypeScript，而 AI 工程师通常两者都会用到。

实际上需要多长时间？

对于有 SQL 基础和一定 Python 经验、利用业余时间学习的人来说，六个月是一个合理的计划。一名在职数据工程师可能只需一半时间就能达到就业水平。从零开始转行的人则应预留接近一年的时间，其中大部分时间花在基础学习上，之后才接触 Foundry，这完全没问题。

没有 Foundry 经验能找到 Foundry 工作吗？

在 Palantir 本身，可以，因为其部分工程职位并不要求有 Foundry 工作经验。合作伙伴通常要求两年以上经验，因此一个出色的 Developer Tier 项目加上认证就是您的替代方案。

应该学 Gotham 还是 Foundry？

Foundry。Gotham 面向国防和情报客户，不开放自学，而 Foundry 支撑商业业务，并提供免费的 Developer Tier。
