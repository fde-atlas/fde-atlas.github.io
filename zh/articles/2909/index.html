AWS成立FDE組織，派遣AI工程師進駐企業部署代理AI

全文

AWS

AWS周二（6/30）宣布成立專責前線部署工程（Forward Deployed Engineering，FDE）組織，並將以10億美元內部資源擴大AI部署服務，派遣數千名AI工程師進駐企業客戶，共同開發及部署代理AI系統，加入OpenAI與Anthropic布局FDE服務的行列。

FDE模式最早始於Palantir，指的是由供應商派遣工程師直接進駐客戶組織，與客戶團隊共同釐清需求、整合資料與調整系統，使技術能真正落地到既有流程與營運場景中。AWS FDE模式有3項特色，包括採用「代理人優先」（Agentic-First）模式、將AI部署時程由數月縮短至數天，以及讓客戶於專案完成後仍能獨立運作AI系統，而非持續依賴AWS。

AWS說明，大多數的FDE工程師原本就是AWS AI服務的開發者，將與客戶的業務、工程及資訊安全團隊合作，利用客戶自身的資料、治理架構及流程，共同建置並部署正式上線的AI系統。此外，有別於傳統顧問公司僅提供評估與建議，且將每次專案視為獨立案件，AWS FDE採取長期合作模式，以共同的商業目標及成果為導向，而非以工時計費。

AWS FDE採用代理人部署技術（Agentic Deployment Technology），並導入AI驅動開發生命周期（AI-Driven Development Lifecycle），讓AI代理人參與軟體開發各階段，並由人類工程師負責監督、驗證及引導。

AWS FDE的最終目標是培養客戶的自主能力，使客戶工程師逐步從旁觀者、共同開發者，最終成為可獨立運作AI系統的管理者；待專案完成，客戶將取得已部署完成的AI系統、知識圖譜（Knowledge Graph）、操作手冊、系統架構文件，以及已完成培訓的內部AI種子人才。

目前AWS FDE工程師已進駐多家企業，包括Allen Institute、Cox Automotive、美國職業籃球聯盟（NBA）、美國國家美式足球聯盟（NFL）、日本理光（Ricoh）與西南航空（Southwest Airlines）。
