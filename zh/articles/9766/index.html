核心课程与掌握的生产技能

支柱 1：LLM 系统架构与多模型网关

  • 重点： 构建弹性多供应商抽象层。
  • 技能： 供应商路由、回退逻辑、速率限制管理、LiteLLM/Bifrost 网关，以及亚毫秒级语义缓存，可将 API 支出降低 30%–70%。

支柱 2：提示词版本控制与防护栏

  • 重点： 将提示词视为有版本管理的软件组件。
  • 技能： GitFlow 提示词版本管理、结构化 JSON 输出强制执行（PydanticAI）、OWASP 输入净化，以及 NVIDIA NeMo 防护栏。

支柱 3：生产级 RAG 与混合向量搜索

  • 重点： 运营高吞吐量检索流水线。
  • 技能： Weaviate 和 Qdrant 托管向量存储、稠密检索加 BM25 混合搜索、上下文窗口优化，以及数据摄取流水线自动化。

支柱 4：实时 LLM 可观测性与遥测

  • 重点： 调试非确定性模型行为与幻觉追踪。
  • 技能： 全链路追踪回放、token 经济建模，以及使用 Arize Phoenix、Langfuse 和 LangSmith 构建评测仪表盘。

支柱 5：自动化评测与治理（LLM-as-a-Judge）

  • 重点： 用持续自动化评分取代人工响应测试。
  • 技能： 构建黄金数据集、自动化评分框架（Ragas、DeepEval、Promptfoo），以及生产上线前的回归测试。

支柱 6：云端、本地与 Kubernetes 部署

  • 重点： 将企业工作负载保护在私有基础设施之后。
  • 技能： 使用 Docker 的容器化微服务、自动化 Jenkins/GitLab CI/CD 流水线、Kubernetes（Minikube/Helm）编排，以及 CISO 合规审计日志。

本项目专为希望专注于 AI 平台运营与基础设施的技术专业人士设计：

  • LLMOps 与 MLOps 工程师，致力于标准化部署流水线、可观测性仪表盘和评测框架。
  • DevOps 与 SRE 专业人士，将 Docker 容器化、Kubernetes 编排和 CI/CD 流水线扩展到 AI 工作负载。
  • 后端与 AI 工程师，从本地 Jupyter notebook 和原始 API 调用转向可扩展的生产级架构。
  • 云与平台架构师，设计安全、私有且多云的企业 AI 系统。
  • 技术负责人与工程经理，希望降低 token 成本、通过安全审计，并加快 AI 项目投入生产的速度。
