前沿部署数据工程师 | TENEX.AI

原标题：Forward Deployed Data Engineer | TENEX.AI

Zero G Talent · 2026-06-01 · 约 3 分钟读完

摘要

TENEX.AI 在堪萨斯州 Overland Park 招聘前沿部署数据工程师（SIEM/SOAR 方向）。TENEX 是一家 AI 原生的托管检测与响应（MDR）初创公司，由 Crosspoint Capital Partners 领投，种子轮由 Andreessen Horowitz 领投。该职位负责编写检测规则、日志解析器、SOAR 剧本、仪表盘和 API 集成，覆盖 Google SecOps 与 Microsoft Sentinel，并需将 MITRE ATT&CK 战术融入检测逻辑，同时承担客户技术培训职责。要求三年以上检测工程或安全运营经验，熟悉 YARA-L、KQL、Python 等。

要点

  • TENEX.AI 招聘前沿部署数据工程师，聚焦 SIEM/SOAR 内容开发。
  • 工作涵盖检测规则、日志解析器、SOAR 剧本与 API 集成。
  • 需熟悉 Google SecOps 的 YARA-L 与 Sentinel 的 KQL。
  • 要求三年以上检测工程或安全运营经验，懂 MITRE ATT&CK。
  • 该岗位还负责对客户进行深度技术培训。

公司概况：

TENEX 是一家 AI 原生、自动化优先、为规模化而构建的托管检测与响应（MDR）提供商。我们是防御者的力量倍增器，通过先进的威胁检测、快速响应和持续保护，帮助组织增强其网络安全态势。我们的团队由在网络安全、自动化和 AI 驱动解决方案方面拥有深厚经验的行业专家组成。在领先投资者的支持下，我们正在快速增长，并寻求顶尖人才加入我们，共同实现革新 AI 原生 MDR 格局的使命。

我们是一家快速成长的初创公司，由行业专家和顶级投资者支持，主要投资方为 Crosspoint Capital Partners，同时获得 Shield Capital、DTCP（前身为 Deutsche Telekom Capital Partners）、Deepwork Capital 和 Florida Opportunity Fund 的支持。种子轮由 Andreessen Horowitz (a16z) 领投。作为早期员工，你将在定义和塑造我们的企业文化方面发挥重要作用。从零开始参与其中。我们是一支规模虽小但资金充足的团队，刚刚完成了一轮大规模融资——现在加入风险有限，回报无限。

企业文化是 TENEX.AI 最重视的事情之一——请访问 culture.tenex.ai 浏览我们的文化手册，了解我们如何践行这一文化，并优先重视线下工作中不可替代的协作与社区氛围。

关于该职位

作为前沿部署数据工程师——SIEM/SOAR，你将构建支撑 TENEX MDR 交付的内容。从检测规则和日志解析器，到 SOAR 剧本、仪表板和自定义 API 集成，你的工作是让平台变得智能。你同时也是一名技术培训师——帮助客户理解他们所运行的内容以及他们所操作的平台。

工作职责

  • 在 Google SecOps 和 Microsoft Sentinel 上编写、调优和维护检测规则、关联逻辑和威胁内容
  • 为集成到客户环境中的新数据源构建并验证日志解析器
  • 针对常见告警类型和运营用例，开发并维护 SOAR 剧本、自动化工作流和仪表板
  • 在没有原生连接器或内容的情况下，构建 Cloud Run 函数、脚本和 API 集成
  • 与部署工程师协作，确保内容为新客户上线做好准备
  • 监控检测覆盖范围的缺口，并主动开发内容加以弥补
  • 将威胁情报和对手 TTP（MITRE ATT&CK）融入检测逻辑
  • 作为客户的高级赋能资源——在更深入的技术层面为客户提供检测内容、仪表板和平台能力的培训
  • 用清晰的元数据、使用场景和调优说明记录所有内容
  • 支持以人工审核作为质量关卡的 AI 辅助内容生成工作流

必备技能与资格条件

技术与行业专长

  • 3 年以上检测工程、内容工程或安全运营经验
  • 精通 SIEM 检测规则开发——包括 Google SecOps 的 YARA-L、Sentinel 的 KQL 或类似语言
  • 具有构建和维护 SOAR 剧本及自动化工作流的经验
  • 熟练为多种数据源类型开发日志解析器
  • 了解 MITRE ATT&CK 框架及其在检测内容中的应用
  • 具有 Python、Cloud Run Functions 和 REST API 集成经验
  • 具有为运营场景构建安全仪表盘的经验
  • 理解威胁情报以及如何将 TTP 转化为可执行的检测逻辑

软技能

  • 出色的问题解决与故障排查能力，倾向于快速行动
  • 优秀的面向客户的沟通与协作能力
  • 能够在快节奏、高性能的创业环境中茁壮成长
  • 对网络安全、自动化和持续改进充满热情

教育与认证

  • 计算机科学、网络安全、工程或相关领域的学士学位（或同等实践经验）
  • 持有相关认证者优先，如 CISSP、CISM、GIAC 认证、Google Cloud Professional、Microsoft SC-200/AZ-500 或 AWS Certified Solutions Architect

为什么加入我们？

  • 有机会接触尖端的 AI 驱动网络安全技术和下一代安全平台
  • 与一支专注于持续改进安全运营的富有才华和创新精神的团队协作
  • 有竞争力的薪酬和福利待遇
  • 注重成长与发展的文化，提供在 AI、网络安全和工程领域拓展专长的机会
  • 参与从零开始打造新事物——TENEX 的前沿部署工程组织是一个全新机遇，让你定义企业级安全如何规模化交付
