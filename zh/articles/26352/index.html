Praxent 前沿部署工程师

原标题：Forward Deployed Engineer at Praxent

Torre · 2026-09-30 · 约 4 分钟读完

摘要

Praxent 发布的 FDE 职位（已关闭）：作为 Anthropic 合作伙伴，该公司为银行、贷款和支付机构部署 agentic AI。前沿部署工程师需驻场客户环境，负责从需求到上线的完整工作流，交付符合合规要求、可移交客户自主运维的 AI 系统。要求 3 年以上生产软件开发经验，熟悉 LLM、RAG、评测等技术，有金融行业合规经验者优先。美国基本薪资 156,000 至 186,000 美元，远程办公。

要点

  • Praxent 是 Anthropic 与 Microsoft 合作伙伴，深耕金融服务软件 26 年。
  • FDE 需驻场银行或支付客户，端到端负责一个工作流直至生产上线。
  • 核心挑战是在合规、遗留核心系统等约束下交付可运维的 AI 系统。
  • 要求 3 年以上生产经验，熟悉 LLM、RAG、评测，金融背景优先。
  • 薪资 156,000 至 186,000 美元，面向美国居民远程办公，职位已关闭。

全文

关于 PraxentPraxent 是 Anthropic 的合作伙伴，我们面前的机遇前所未有。每家金融机构都在同时问同一个问题：我们如何在如此关键的领域内部署 AI Agent？很少有团队既拥有构建答案的前沿模型访问权限，又具备让方案获得批准的监管深度。而我们两者兼备。这份深度源于 26 年的积累。Praxent 构建银行、信用合作社、贷款机构、保险公司和财富管理平台实际运行的软件，身处企业软件中最严苛的环境。大多数公司把这些约束视为障碍，而我们围绕它们锤炼出了自己的专业能力。使命作为一名前沿部署工程师，你将直接嵌入 Praxent 的客户（一家银行、贷款机构或支付公司），构建在其业务内部运行的 AI 系统。架构师或资深 FDE 会确定系统的整体形态，你则负责其中一个工作流并将其推向生产环境——编写大部分代码、做出日常决策，并让你的部分通过合规审查。不是在会议室里令人惊艳的原型，而是我们交付之后依然稳固可靠的系统。你将负责的内容在客户环境中上线、可靠的 AI。满足客户功能与合规要求的 AI Agent 和基于 LLM 的功能，并在交付后持续运行，而不仅仅在我们的测试环境中。一个端到端的工作流。你负责项目中的一个部分，从理解客户问题一直到交付有完整文档的解决方案。契合客户世界的 AI。与你实际接触的系统进行干净的集成，包括遗留核心系统、受治理的数据以及他们的身份和基础设施，而不是理想化的全新开发。客户无需你也能运行的系统。让客户团队能够运营并信任你所构建内容的评测、护栏、操作手册和交接文档。在一线赢得的信任。客户工程师希望你参与讨论，因为你的沟通清晰、执行可靠。我们的工作方式Praxent 以服务精神运转，客户从第一周就能感受到。我们秉持“是的，而且”的态度：从客户的目标出发，围绕他们的实际运作方式调整自己，而不是带着一套固定的方案上门。在金融服务领域，这意味着把合规、风险审查、遗留系统、审计与可解释性要求等约束不当作需要绕开的障碍，而是当作设计问题本身。最出色的前沿部署工作正是拥抱这些约束，并因此变得更好。你不会孤军奋战。你将与 Praxent 的资深前沿部署工程师、产品经理以及客户自己的团队并肩工作，从第一次提交到自信的交接，全程负责你那一部分的成果。你需具备的条件3 年以上交付他人依赖的生产级软件的经验。有 LLM 和 AI Agent 系统（RAG、Agent 框架、向量数据库、评测）的直接经验最为理想，不过近期深入钻研过 AI 的优秀产品工程师也完全在考虑范围内。精通 Python 和/或 TypeScript，熟悉全栈开发以及主流云平台（AWS、Azure 或 GCP）、容器和 CI/CD。有直接嵌入客户环境中、与混乱的真实世界系统和数据集成的经历，而不仅仅是从零构建。你是在他人已做出的决策框架内工作。能够与客户的工程师进行技术对话并直接与他们协作。有银行、贷款或支付行业经验者优先，包括直接与风险和合规伙伴合作，以及在受监管组织中推动 AI 通过模型风险或安全审查。你的工作方式：我们的 CAN/DO 价值观实践深切关怀。你把客户的用户、数据和约束当作自己的来对待。始终交付。你说到做到，人们可以信赖你的执行力。永不满足。即使“足够好”能通过审查，你仍不断提高质量标准。协作共赢。你与客户团队和 Praxent 同事建立信任，并寻求双赢。对结果负责。你为结果而非仅仅任务承担责任，并且第一个挺身而出解决问题。你将喜欢我们这里的原因身处重要行业的前沿席位。Praxent 是 Anthropic 和 Microsoft 的合作伙伴。这意味着合作伙伴级别的赋能以及进入两个生态系统的直接通道——应用于银行、贷款机构和保险公司，那里的工作艰难而利害攸关。26 年的积淀。在金融服务领域历经数十年赢得的声誉。在坚实的基础上做前沿工作。真实的休假。入职即享 15 天带薪休假且逐年增加，9 个美国法定假日，5 个健康日，带薪育儿假。把标准福利做对。医疗、牙科、视力、残障、意外保险，健康计划，以及最高 3% 匹配的 IRA。值得推荐的文化。获得 Texas Monthly、Clutch 和 Comparably 的认可。门是敞开的，想法可以向上传递，这里没有人说“这只是生意”。该全职职位美国基本薪资目标为 156,000-186,000 美元 + 福利。我们的薪资范围由职位、级别和地点决定。每个职位发布页面上显示的范围反映了该职位在美国所有地点新员工薪资的最低和最高目标。在范围内，个人薪酬由工作地点及其他因素决定，包括与工作相关的技能、经验以及相关教育或培训。
