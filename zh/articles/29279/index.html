AWS AI 总监谈前沿部署工程师以及合作伙伴共同前方的“清晰”道路

原标题：AWS AI Director On Forward Deployed Engineers And Partners’ ‘Clear’ Path Ahead Together

crn.com · 2026-08-25 · 约 3 分钟读完

摘要

AWS 前沿 AI 工程与服务董事总经理 Taimur Rashid 向 CRN 介绍，公司上月投入 10 亿美元组建前沿部署工程（FDE）团队，该团队由曾构建 AWS 生产服务的软件工程师和应用科学家组成，此前已通过 GenAI Innovation Center 积累三年实践经验。AWS 将与渠道伙伴采取联合销售与联合交付模式：AWS 提供前沿工程与科学能力，伙伴贡献客户关系、行业深度和运营覆盖。AWS 还在投入伙伴培训与工具。伙伴（如 BizCloud Experts）认为 FDE 是互补而非竞争，是业务的放大器。文中还提到 AWS 2026 年第二季度收入 422 亿美元，同比增长 37%，年化运行率达 1690 亿美元，以 28% 的份额居全球云市场第一。

要点

  • AWS 投入 10 亿美元组建前沿部署工程团队。
  • FDE 团队源自构建 AWS 生产服务的工程师，已有三年实践。
  • AWS 与伙伴采用联合销售、联合交付模式推进 AI 项目。
  • 伙伴提供客户关系与行业深度，AWS 提供工程与科学能力。
  • AWS 第二季度收入 422 亿美元，同比增长 37%。

全文

“合作伙伴应该与我们携手合作的原因很明确——我们带来前沿软件工程经验、应用科学专业知识，以及三年帮助客户利用 AI 推动业务成果的实战经验，”AWS 的 Taimur Rashid 告诉 CRN。

Amazon Web Services 的全新获得 10 亿美元支持的前沿部署工程团队将帮助渠道合作伙伴通过一种市场上独一无二的合作销售模式来推动 AI 交易和收入增长，AWS 的 Taimur Rashid 表示。

对于希望与 AWS 前沿部署工程（FDE）组织共同交付的合作伙伴来说，“机会是清晰的，”AWS 前沿 AI 工程与服务董事总经理 Rashid 告诉 CRN。

“合作伙伴应该与我们携手合作的原因很明确——我们带来前沿软件工程经验、应用科学专业知识，以及三年帮助客户利用 AI 推动业务成果的实战经验，”Rashid 说。“合作伙伴则带来客户所需的互补能力，例如现有客户关系、行业深度和运营覆盖范围。”

[相关阅读：随着 Amazon 2200 亿美元支出目标的推进，AWS 向美国数据中心投入 60 亿美元]

这家市值 1690 亿美元的云市场份额领导者将利用 AWS 合作伙伴在 AI 模型、行业知识和技能方面的专长，确保为客户提供合适的工程师。

总部位于西雅图的 AWS 还在投资合作伙伴培训、工具和资源，以加速 AWS FDE 项目的开展。

Rashid 表示，合作伙伴能力与 AWS FDE 工程和科学能力的结合，将使共同客户“能够更快地行动，并在规模化中持续取得成果”。

AWS 的 FDE 10 亿美元战略

Amazon 上个月投资 10 亿美元成立了 AWS 前沿部署工程组织。

“我们正在抽调构建 AWS 生产服务的软件工程师，将这种前沿工程专业知识与我们的科学能力相结合，帮助客户通过 AI 实现真正的业务成果，”Rashid 说。“过去三年，我们已通过 GenAI 创新中心开展这项工作。”

AWS 及其合作伙伴将直接与企业合作，尽快将 AI 从概念推向生产。

“合作伙伴融入这一模式的方式与他们在其他 AWS 能力领域的方式相同。首先，合作伙伴需要理解我们的 FDE 方法论和方法，”Rashid 说。“其次，就像我们其他的联合交付模式一样，AWS 和合作伙伴可以为共同客户进行联合交付。”

作为 AWS 顶级合作伙伴的 BizCloud Experts 期望通过与 AWS FDE 合作，赢得更多 AI 交易并推动净新增销售。

“AWS 正在引入既能理解 AI 的业务逻辑又能理解其技术逻辑的人才，帮助客户在更短的周期内解决各种问题，更快地获得答案，”BizCloud Experts 总裁兼首席增长官 Sepehr Noorizadeh 表示。

“AWS 为前沿部署工程师所做的是搭建一个让合作伙伴生态系统走向成功的环境，”Noorizadeh 说。“因为无论如何，总得有人去为客户进行大规模部署。这正是 AWS 看待合作伙伴生态系统的角度，并问：‘我们现在如何一起协作销售？’”

“所以每次 AWS 参与洽谈时，他们也会带着合作伙伴一起参与。这就是为什么在我看来，它不是我们的竞争对手。如果说有什么的话，它是对我们工作的补充，起到了力量倍增器的作用，”他说。

AWS 2026 年第二季度业绩与云市场份额

2026 年第二季度，AWS 报告总收入为 422 亿美元，使亚马逊的云业务年化运行率达到创纪录的 1690 亿美元。

422 亿美元的收入同比增长 37%，这是 AWS 18 个季度以来的最高增长率。

根据 Synergy Research Group 2026 年第二季度的数据，AWS 仍然是全球云市场份额的领导者。

AWS 目前占全球云基础设施服务市场 28% 的份额，其次是 Microsoft 占 20%，Google Cloud 占 15%。
