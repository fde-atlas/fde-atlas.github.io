前沿部署工程师 | Plexe | 远程，印度

原标题：Forward Deployed Engineer | Plexe | Remote, India

Zero G Talent · 2026-04-23 · 约 2 分钟读完

摘要

Plexe 招聘远程（印度）前沿部署工程师，负责客户现场集成其多 Agent ML 平台、搭建端到端 ML 管道，并反馈需求至产品路线图。要求 3 年以上生产级 ML 经验、熟悉 Python 与主流框架及 LLM 部署，差旅占 30%–50%。面试含技术作业与案例研究。

  • 要求 3 年以上生产级 ML 经验与 LLM 部署能力。
  • 差旅占 30%–50%，需赴客户现场工作。

你需要具备什么

职位介绍

我们正在寻找一位前沿部署工程师，直接与客户合作，帮助他们集成 Plexe 并使用我们的平台构建完整的机器学习流水线。你将身兼技术顾问、解决方案架构师和实施伙伴三重角色——前往客户现场，了解他们独特的挑战，确保他们在我们的机器学习工程平台上取得成功。如果你热爱在真实环境中解决复杂问题，并乐于与客户互动，这个职位就是为你准备的。

你的工作内容

  • 客户沟通： 拜访客户现场，了解他们的机器学习工作流程、痛点和业务目标。你将是 Plexe 的技术形象代表，与工程团队建立关系和信任。
  • 集成与实施： 帮助客户将 Plexe 集成到他们现有的基础设施中，并使用我们的多 Agent 平台构建端到端的机器学习流水线。你将亲自上手处理他们的数据、模型和系统。
  • 解决方案架构： 设计定制的机器学习流水线解决方案，充分发挥 Plexe 的能力，同时无缝融入客户环境。每一次实施都将根据客户的具体需求量身定制。
  • 技术支持与培训： 提供持续的技术支持，开展培训课程，并创建文档，确保客户能够有效使用和维护他们的 Plexe 实施方案。
  • 产品反馈闭环： 收集客户需求、痛点和功能请求，为我们的产品路线图提供参考。你将是工程团队中客户声音的传递者。

我们的要求

我们在寻找一位兼具扎实技术能力和出色客户沟通能力的人：

  • 3 年以上在生产环境中构建和部署机器学习系统的经验
  • 精通 Python，并有机器学习框架（PyTorch、TensorFlow、scikit-learn）的使用经验
  • 有 LLM 部署和 Agent 系统的经验
  • 有面向客户的经验，能够向不同受众讲解技术概念
  • 具备解决问题的思维，能够在陌生的环境中调试和排查问题

加分项：

  • 有咨询或客户成功岗位背景
  • 有数据工程和流水线编排工具的使用经验
  • 了解企业级安全和合规要求

为什么选择这个职位？

这不是一份普通的工程职位——你将在使用前沿 AI 技术的同时，对客户成功产生直接影响。你将亲眼见证自己的工作如何改变企业，与客户建立深厚的关系，并帮助塑造机器学习流水线开发的未来。

差旅： 该职位需要 30%-50% 的时间出差前往客户现场，有机会与不同行业和规模的公司合作。

准备好成为创新 AI 技术与客户实际成功之间的桥梁了吗？欢迎与我们聊聊。

  • 初步电话沟通
  • 技术轮（带回家的作业 + 后续跟进）
  • 案例研究
