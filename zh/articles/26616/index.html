创始前沿部署工程师（FDE） | Armature

原标题：Founding Forward Deployed Engineer (FDE) | Armature

Zero G Talent · 2026-11-04 · 约 3 分钟读完

摘要

Armature 在巴黎招聘创始前沿部署工程师，负责客户交付体系。公司产品自动化 AI Agent 工作流测试，通过 MCP、CLI 等接口持续测试并对比竞品。该职位需设计实验、维护客户关系，并用 AI Agent 逐步自动化交付流程，同时把一线反馈带回产品团队。

要点

  • Armature 产品用于自动化 AI Agent 工作流测试，覆盖 MCP、CLI 及多个 harness。
  • 岗位驻巴黎，需到访旧金山，英语即可，无需法语。
  • 核心职责：搭建客户运营体系、设计并运行实验、对承诺结果负责。
  • 最看重的技能是通过编码 Agent 拆分并完成实际工作。
  • 面试含创始人初谈、运营案例和一天带薪试用。

我们需要什么

  • 顶尖学校的工程师
  • 熟练使用编程 Agent 来拆分工作并指导 Agent
  • 愿意与客户交流并主导对话
  • 高度主动：无需等待指令即可推进工作
  • 交付承诺的成果

你将做什么

  • 构建客户运营职能：流程、标准、工具
  • 设计并运行客户实验，展示结果
  • 负责客户关系及承诺的成果
  • 使用 AI Agent 自动化交付任务
  • 将一线反馈带回产品，帮助确定构建优先级

工作地点：法国巴黎。我们重视线下办公，但也保持灵活。你可能还需要前往旧金山与我们的客户会面。

语言要求：必须会英语。无需会法语。

职位介绍

客户交付是 Armature 当前的核心，而这项工作由你负责。你要确保我们的客户每天都能获得真正的价值，在我们成长的过程中塑造价值交付的方式，并为产品做出贡献。

一切从你的客户开始。你要了解每家客户的业务、竞争对手和增长难题，设计实验来衡量编程 Agent 选用其产品的频率，并证明是什么改变了 Agent 的选择。你将从创始人身边起步，逐步接管客户账户，直到成为客户信赖的专家，并对我们承诺的成果负责。

目前这项工作很大程度上仍依赖我们手动提示的 Agent，但随着客户增加，这种方式难以为继。因此，你要定义我们的标准方法，搭建流程，并运用 Agent，让每新增一位客户所需的时间都比前一位更少。这类工作是全新的，所以你运行它的方式，将成为 Armature 运行它的方式。

你在这一过程中学到的东西，也将塑造我们的产品。你会与我们的产品工程师和应用研究工程师协作，把你在一线的所见所为转化为更好的产品。

你将做什么

  • 构建我们的客户运营职能：流程、标准和工具。
  • 深入了解每家客户的业务和增长难题。
  • 为每家客户设计并运行实验，并展示结果。
  • 负责与客户的客户关系以及我们向他们承诺的成果。
  • 使用 AI Agent 实现交付自动化，每次解决一个重复性任务。
  • 将一线反馈带回产品，并帮助确定构建优先级。

我们寻找什么样的人

  • 你是顶尖学校的工程师，如果你是应届毕业生，你的实习经历应能证明你具备构建产品的能力。
  • 你能通过编程 Agent 完成实际工作：拆分任务、指导 Agent 并理解它们的产出，这是我们最看重的能力。
  • 你乐于与客户交流，并准备好主导对话。
  • 当你承诺一个成果时，你就会交付它。
  • 你有很强的主观能动性：无需等待指示就能主动推进。

不适合的情况

  • 你想远离客户。
  • 你想把大部分时间花在构建产品上。
  • 你愿意永远手工重复交付同样的工作。
  • 你从未使用过 AI Agent 来自动化部分工作。

面试流程

  • 与创始人之一进行初识电话沟通。
  • 基于客户项目的运营案例。
  • 与团队一起进行一天的带薪试用。

关于 Armature

随着我们从用户体验转向 Agent 体验，我们设计、运营和评估产品的整个方式都必须重新思考。第一步是了解 Agent 如何通过 MCP 和 CLI 使用产品，就像我们过去了解用户如何与 UI 交互一样。Armature 自动化 Agent 工作流测试。连接你的 MCP、CLI 和 ChatGPT 应用，让 Armature 发现 Agent 实际运行的工作流。Armature 随后会在每个 harness（Claude Code、Codex、Openclaw 等）和前沿模型上持续测试它们，向你展示你的表现、你与竞争对手的对比情况，并在出现问题时提醒你。
