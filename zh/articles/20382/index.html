前沿部署工程师（FDE） | Peakflo | 远程，印度

原标题：Forward Deployed Engineer (FDE) | Peakflo | Remote, India

Zero G Talent · 2026-03-24 · 约 4 分钟读完

摘要

Peakflo（Y Combinator W22、Google AI 加速器校友）正在为印度远程岗位招聘前沿部署工程师。该职位聚焦财务领域的 Agentic AI：设计语音优化的提示词流程，构建协调子 Agent 的分层工作流，结合 RAG 与企业知识库减少幻觉，并用 Python 和 SQL 自动化财务流程。候选人需具备 0.5 至 2 年机器学习、NLP 与提示词工程经验，熟悉 Gemini、GPT、Claude 等模型及 LangChain 等框架。面试共四轮，包括提交编码 Agent 会话记录、实操技术面、与 CTO 的终面及背景调查。

要点

  • Peakflo 招聘印度远程前沿部署工程师，专注财务 Agentic AI。
  • 工作涵盖语音提示词设计、分层 Agent 架构与 RAG 集成。
  • 要求 0.5 至 2 年 ML、NLP 与提示词工程经验，精通 Python。
  • 面试四轮，需提交编码 Agent 会话记录作为实验环节。
  • 公司为 Y Combinator W22 与 Google AI 加速器校友。

任职要求

🚀 我们是谁 & 我们在构建什么

Peakflo 是一家快速成长的 Agentic AI 公司。我们正在用尖端的智能体工作流彻底改变全球财务团队的工作方式，并积极寻找跨领域的优秀人才来引领这场变革，汇聚多学科专业能力，推动我们的全球战略愿景。

  • 我们的成长故事：Peakflo 获得全球顶级加速器和投资者的支持。我们是著名的 Y-Combinator (W22) 和 Google AI Accelerator 的骄傲校友。我们的发展势头和影响力已获得顶级科技与财经媒体的全球认可：

我们的文化：我们致力于打造充满活力、高性能的文化，奖励好奇心、主人翁精神和创新。我们的团队遍布全球，我们乐于聚在一起解决难题并庆祝胜利。最重要的是，我们已经开始营造一个提供支持与指导的环境，帮助大家取得成功、学习和成长。❤️

💻 我们在寻找：

我们正在寻找一位积极进取、注重细节的前沿部署工程师（FDE）加入我们充满活力的团队。在这一职位上，你将弥合我们的核心 AI 技术与真实财务工作流之间的差距。你将在开发、调优和实施智能体机器学习解决方案方面发挥关键作用，以推动业务增长并优化我们的产品。

💪 你的工作内容

  • Voice AI & Prompt Engineering
    • 打造语音优化的提示词流程： 设计考虑自然语音模式（停顿、打断、语调）的对话流程，针对纯语音交互进行优化。确保提示词对 TTS 发音清晰明确，避免歧义。
    • 持续改进： 利用 LLM 反馈循环和“自我反思”来评估输出、检测幻觉并改进提示词。搭建针对财务用例的 A/B 测试、提示词版本管理和性能 QA 流水线。
    • 语音集成： 与工程团队协作，将提示词与语音识别、意图提取、LiveKit 语音基础设施和电话 API 集成。确保编排保持实时响应和低延迟。
  • Agentic Architecture, LLMs & RAG
    • 构建分层工作流： 开发能够协调子智能体（例如研究智能体、财务智能体和编辑智能体）的财务 AI Agent，以实现可扩展性和模块化。
    • 模型优化： 运用在主流 LLM（Gemini、GPT 系列、Claude）方面的专业知识，优化我们的 AI 财务员工的表现。确保所有应用都具备低延迟和高效率。
    • 接地与 RAG： 将检索增强生成（RAG）与企业知识库和财务 API 集成，以防止幻觉，并在业务领域周围保持严格的上下文控制。
    • 系统集成： 设计并将 LLM 系统与第三方工具、邮件交互和用户聊天界面集成。开发可定制的 OCR 模型等配套组件。
  • Data Analytics & Workflow Automation
    • 流程改进： 分析业务流程、数据质量和运营瓶颈，识别改进机会并提出可执行的建议。
    • 自动化与报告： 使用 Python 和 SQL 实现工作流、数据转换和报告的自动化。构建并维护仪表板和数据监控框架。
    • 协作与文档： 与产品、工程和运营团队紧密合作以明确需求。清晰地记录工作流逻辑、脚本和解决方案设计。

🕵️‍♀️ 我们在寻找什么样的人

  • 教育背景： 统计学、机器学习、数据科学、计算机科学或相关技术领域的学士或硕士学位。
  • 经验： 拥有 0.5 – 2 年机器学习、NLP、LLM 微调和提示词工程方面的行业经验。
  • 优秀的英语书面和口头沟通能力。
  • Technical Skills: Strong proficiency in Python programming (specifically back-end development).
    • 熟悉云平台（例如 Google Cloud）。
    • 拥有在生产环境中部署或使用 ML 模型的实际经验。
  • 软技能： 优秀的英语书面和口头沟通能力；对 AI 及其变革业务的潜力充满热情。

➕ 我们尤其青睐具备以下条件的人：

  • 有使用多个 LLM 平台和编排框架（例如 LangChain、LlamaIndex）的经验。
  • 熟悉高级自然语言处理（NLP）技术和相关库。
  • 精通软件工程最佳实践和版本控制系统（Git）。

🙂福利：

  • 有竞争力的薪酬方案
  • 福利待遇
  • 快速职业成长和技能发展的机会。
  • 协作且富有创新精神的工作环境。
  • 灵活的工作时间和远程办公选项。

面试流程

以下是我们前沿部署工程师职位的面试流程。我们重视透明度，并希望为您提供充分展示自身优势的机会，尤其是您对现代 AI 开发工具的熟练运用。

1. 初步筛选与技术理论 第一轮是了解您的背景、经验和基础技术知识的对话。特别说明：如果您进入此轮，我们会请您回复一份您特别引以为豪的编程 Agent 会话记录。我们设置这一实验性环节，是为了让候选人有机会展示使用 AI 编程工具的实战能力。许多编程 Agent（例如 Claude Code、Cursor）都有

/export

命令或提供导出会话记录的按钮。您可以以纯文本或 Markdown 格式提供给我们。

2. 动手技术面试 这是一场实践性的动手环节，你将解决与 FDE 日常工作中类似的实际工程问题。我们关注你的问题解决思路、编程能力，以及你如何将需求转化为可运行的解决方案。

3. 与 CTO 及联合创始人的最终技术面试 在这最后一轮技术面试中，你将直接与我们的 CTO 和联合创始人会面。这是一场更深入的动手环节，重点考察架构思维、复杂问题解决能力，以及评估你与我们高性能工程文化的契合度。

4. 背景调查 作为发放录用通知前的最后一步，我们会请你提供职业推荐人。我们会与他们进行简短交流，以进一步了解你过往的工作方式、你的优势，以及我们如何才能最好地支持你在团队中取得成功。
