AI 成本与单位经济模型

原标题：AI Cost and Unit Economics

FDE Interviews · 2026-06-14 · 约 1 分钟读完

摘要

本文讲解 AI 部署中的单位经济效益：以每次请求的 token 成本乘以用量，对比被替代的人工基线，判断部署是否值得推进。文章还讨论了调用 API 与自建 GPU 的盈亏平衡点——只有利用率达到一定阈值时自建才划算。页面属于 FDE 课程体系，附带相关课程、练习题（如容量与成本估算、批量管道设计）及评测等进阶内容。

要点

  • 单位经济效益决定 AI 部署能否落地
  • 成本由输入输出 token 乘以用量计算
  • 需对比被替代的人工基线成本
  • 自建 GPU 仅在高利用率时优于 API
  • 页面含课程、练习题与评测资源

单位经济效益是决定一个 AI 部署能否上线的粗略测算：由输入和输出 token 驱动的单次请求成本，乘以业务量，再与其所替代的人工或手动流程基线进行对比。它还决定了 API 与自托管之间的盈亏平衡点——只有当真实利用率超过某个阈值时，自建 GPU 才会更有优势。
