Sierra 的 FDE「Agent Engineer」是什么｜不称为 FDE 的理由与三种职种的分工及日本市场拓展

原标题：SierraのFDE「Agent Engineer」とは|FDEと呼ばない理由と3職種の分業・日本展開

FDE Talent編集部 · 2026-10-16 · 约 36 分钟读完

摘要

Sierra 不用 FDE 称呼其前沿部署型岗位，而称 Agent Engineer。负责人 Natalie Meurer 在 2026 年 7 月的演讲中说 FDE 一词含义过泛已失去定义，其共同核心是对客户负责，并把 FDE 工作按 2008 年起的四个年代（平台运维、数据整合、定制方案、客户赋能）拆解。截至 2026 年 10 月 16 日，Sierra 的 68 个 Agent 开发职位分为 Agent Engineer（26 件）、Strategist（27 件）、PM（12 件），美国 Agent Engineer 年薪 18 万至 39 万美元。职位集中在旧金山和伦敦，30 件在职位名中标注特定语言，但东京的 Agent 开发职位为零。Sierra 已收购 OPERA TECH 并与软银签订日本独家销售协议，软银 LINEMO 试点将解决率从 83% 提升至 97%。同行 Decagon 则把 FDE 视为与产品开发同一，通过自助化将每个 Agent 的定制工程量减少 80%。

要点

  • Sierra 以 Agent Engineer 取代 FDE 称呼，团队超 120 人，负责人为 Natalie Meurer。
  • Meurer 称 FDE 含义过泛，按四个年代拆解工作，共同点是对客户负责。
  • 68 个 Agent 开发职位分三职种，美国 Agent Engineer 年薪 18 万至 39 万美元。
  • 东京尚无 Agent 开发职位，Sierra 与软银签日本独家销售协议。
  • Decagon 将 FDE 视同产品开发，自助化使每 Agent 定制工程量减 80%。

顧客と対話するAIエージェントのプラットフォームを提供するSierra(シエラ)は、顧客と一緒にエージェントを作るエンジニアを、FDE(Forward Deployed Engineer/フォワードデプロイドエンジニア)ではなく「Agent Engineer(エージェントエンジニア)」と呼んでいます[3][2]。その責任者のNatalie Meurer氏は、2026年7月に公開された講演で、FDEの「汚い秘密」はFDEが存在しないことだと述べ、FDEの仕事を年代ごとに分解してみせました[1]。Sierraは2025年12月に東京オフィスの開設を発表し、2026年3月に東京のOPERA TECHを買収、7月にはソフトバンクと日本での独占販売の契約を結んでいます[26][15][16][17]。

本文将Meurer演讲的文字记录与采访报道、Sierra官方博客、编辑部于2026年10月16日获取的Sierra公开招聘186个（其中Agent开发类招聘68个）、软银与Sierra的发布进行对照。依次解读不叫FDE的理由、Agent Engineer·Strategist·PM三个职种的分工、薪酬与语言要求、与同为AI客服公司的Decagon的差异，以及在日本招聘的现状。关于FDE这一职种本身的说明，请参阅FDE（前沿部署工程师）是什么。

Sierra的FDE是怎样的职种？

SierraでFDEにあたるのは、顧客と一緒にAIエージェントを設計・構築・出荷するAgent Engineerです[3]。ジョブボード上の職種名は「Software Engineer, Agent」で、Engineering部門のAgent Engineeringチームに属します[6]。チームを率いるHead of Agent EngineeringのNatalie Meurer氏は、2026年7月時点で120人を超えるエンジニアの組織を率いています[2]。

  • Sierra的Agent开发4个团队的公开招聘（186个中）
  • 68个
  • 編集部が集計。Sierraの公開ジョブボード(Ashbyの公開API)で2026年10月16日取得。Agent Engineering 27件・Agent Strategist 27件・Agent Product Management 12件・Agent Engineering New Grad 2件[14]

Sierraは、企業の顧客対応を担うAIエージェントを作って動かすプラットフォームの会社です。共同創業者は、OpenAIの取締役会議長を務め、Salesforceの共同CEOだったBret Taylor氏と、Googleに18年在籍してGoogle Labsを率いたClay Bavor氏です[6]。求人票は顧客の例にGap、Rocket Mortgage、SoFi、Sutter Health、ソフトバンクを挙げており[6]、同社は2026年7月の発表で、世界の主要銀行の3行に1行、Fortune 50の40%に導入されていると説明しています[16]。

エージェント開発の求人は、技術で作り込むAgent Engineer、顧客の経営層と業務の成果を受け持つStrategist、製品とデモを受け持つProduct Managerの3職種に分かれています[6][7][8]。Sierraの中でFDEの仕事は、1つの職種ではなく、この3職種の組み合わせで担われていると読めます。

Sierra为何称“Agent Engineer”而非“FDE”？

Meurer氏の説明では、FDEという名前は意味が広すぎるうえ、職種名には顧客への執着という面だけでなく、技術的な仕事の形を表したかったからです。そこで「agent engineer」を選び、Agent EngineerをFDEの一部か、FDEに隣接する職種と位置づけています[2]。

“前沿部署工程的含义可能过于宽泛。我们认为职种名称应该体现技术工作的形态，而不仅仅是体现对客户执着的这一要素。” “Forward deployed engineering can mean so many things. We thought the title should capture the shape of the technical work, rather than only the customer-obsession element.”

Natalie Meurer（Sierra Head of Agent Engineering）— Latent Space 采访（2026年7月1日）

[2]

Meurer氏は2016年から2021年までPalantirに在籍し、プライバシーのチームに所属し、インフラエンジニアとして、また主に法執行機関と防衛の顧客を担当するFDEとして働きました[1]。2024年にSierraに入社したときのチーム名は「deployment team」で、本人は講演で「当時はその名前が嫌いだった」と振り返っています[1]。入社から約半年後の2024年7月に公式ブログで「Meet the AI agent engineer」を書き、Agent Engineerを、Sierraのプラットフォーム(Agent OS)を使って顧客と一緒にエージェントを設計・構築・出荷する人と定義しました[3][1]。

同じ記事は、Agent EngineerをAI Engineeringという分野の一部とし、エージェントのデモを1時間で作ることと、数百万件の会話で安定して動かすことの間には大きな差があると書いています[3]。AIエージェントは出力が決定的でなく、一般的なソフトウェアの技術スタックにはない道具の上に作られるため、ソフトウェアエンジニアとしての力に加えて、LLM・ベクトルデータベース・プロンプト設計・エージェントの設計を使いこなす必要がある、という説明です[3]。2026年の取材では、声で話すエージェントを設計するには、何が自然で人間らしく聞こえるかを判断する「taste(感覚)」も要ると述べています[2]。

负责人是如何拆解FDE工作的？

Meurer氏は講演で、FDEの「汚い秘密」はFDEが存在しないことだと述べました。言葉があまりに多くの仕事を指すため、何も意味しなくなっているという意味です。Palantirの歴史をたどると、FDEの仕事はプラットフォームの安定稼働、データ統合、個別ソリューション、顧客の自走支援と積み重なってきたので、職種名だけでは中身が分からない、という主張です[1]。

“FDE的肮脏秘密，我不卖关子，直接告诉你，就是它并不存在。这个词本意是要描述太多东西，以至于现在几乎什么意思都没有了。” “And so the dirty secret of forward-deployed engineering, I won't make you wait until the end, is it doesn't exist. It is a term that is, is meant to describe so many things that it sort of means nothing at this point.”

Natalie Meurer（Sierra）— AI Engineer World's Fair 2026 演讲《The Dirty Secret of Forward Deployed Engineering》（2:42起）

[1]

講演はAI Engineer World's Fair 2026で行われた16分49秒のもので、YouTubeでは2026年7月28日に公開され、10月16日時点で約2.2万回再生されています[1]。Meurer氏は、FDEの仕事を4つの「年代(vintage)」に分けて説明しました。

Meurer氏が示したFDEの4つの「年代(vintage)」
年代工作重心演讲中列举的内容
2008年〜 プラットフォームの安定稼働 顧客先のオンプレミス環境にソフトウェアを入れ、動かし続ける。DevOpsに近い仕事で、Meurer氏がPalantirに入って最初に与えられた課題も、AWSのEC2にソフトウェアを載せることだった[1]

[1]

4つの仕事は入れ替わったのではなく、上に積み重なりました[1]。Meurer氏は、すべてを1人に求める求人を「スタッフエンジニア8年、直販6年、ソリューションアーキテクト4年、できれば教職の経験も」と皮肉り、2年から2年半この種の職種を採用してきた実感だと述べています[1]。そのうえで、すべての年代に共通するのは顧客に対して責任を負うことだとし、採用面接では候補者に「あなたはどの年代のFDEか」を尋ねるよう勧めました[1]。

講演の後半は、FDEとプロダクト開発の境界の話です。Meurer氏によれば、FDEは顧客と話したり試作したりするだけでなく、コーディングエージェントを使ってエンドツーエンドの解決策まで作れるようになった一方、Sierraではプロダクトのエンジニアも顧客に近づいており、2つの職種は収束しつつあります[1]。Sierraは成果に応じて課金しており、市場の価格の大半は成果課金に移ると見ています。「成果をどう保証するのか。それこそがFDEだ」というのが講演の結論で、最後は「FDEは死んだ、FDE万歳」と締めくくりました[1]。成果課金の仕組みと各社の課金モデルはFDEの費用は誰がどう払うのかで詳しく扱っています。

Agent Engineer的招聘启事里写了什么？

Agent Engineerの求人票は、本番で動くAIエージェントを作り、最初のパイロットから運用と改善までを自分で持つことを業務の中心に置いています[6]。必須要件には「本番のシステムを作って拡張した経験」と「顧客と直接働くことに抵抗がないこと」が並び、LLMを本番で扱った経験は歓迎要件にとどまります[6]。

Agent 开发如何在 3 个职位间分工？

Sierraのエージェント開発は、Engineering部門のAgent Engineerと、Product部門のStrategist(Agent Strategist)とProduct Manager(Agent PM)の3職種で分担されています[14]。求人票では、Agent Engineerが作り込み、Strategistが顧客の経営層と業務の成果、PMがエンジニアと顧客の間の要件とデモを受け持つように書き分けられています[6][7][8]。

ただしAgent EngineerとStrategistはどちらもADLCを持つと書かれ、通信・メディア企業の解約防止エージェントなどの仕事の例も重なっています[6][7]。

Sierraの公式ブログは、Strategistを「GTM(市場開拓)、コンサルティング、構築を1つにした役割」と説明しています[4]。この役割が成り立つようになった変化として挙げるのが、エージェントを作るためのエージェント「Ghostwriter」のような道具です。AI以前はアイデアをソフトウェアにするのに多くの調整とエンジニアの工数が要ったが、いまは1人がアイデアを構想から本番まで持っていける、という説明です[4]。同じ記事は、Sierraは成果に応じて課金しており、エージェントが実際に成果を出したときだけ支払いを受けるとも書いています[4]。

这对日本的求职者和招聘企业意味着什么？

求職者にとっての要点は、FDEと書かれていない求人にもFDE型の仕事があることと、経験を職種名ではなく「どの年代の仕事を、どの成果に責任を持ってやったか」で語る必要があることです[1]。採用企業・導入企業にとっての要点は、エージェントを外部に作ってもらっても、会話の品質を評価して持ち続ける役割が社内に残りやすいことです。Sierraの開発の進め方(ADLC)は、会話の評価に業務のルールを知る専門家が要るとしています[5]。

对求职者而言

  • 職種名で探さない。Sierraは「Software Engineer, Agent」「Strategist, Agent Development」、Decagonは「Agent Deployment Engineer」「Agent Development Manager」と、FDEの名を使わずに同じ種類の仕事を募集しています[6][7][21][22]。日本で募集中の求人はFDE求人一覧にまとめていますが、職種名に頼らず業務欄で判断するのが確実です。
  • 英語と現地の言語の両方が条件になりやすい。韓国のAgent Engineerは英語と韓国語の両方を、東京の採用職は日本語と英語を求めています[11][12]。
  • AIの経験は必須でないことが多い。SierraのAgent Engineerは、LLMの本番経験を歓迎要件にとどめ、本番システムと顧客対応の経験を必須にしています[6]。
  • エンジニア以外の入口がある。ADMは導入支援・ソリューションコンサル・コンサルティング・プロダクト・プロジェクト管理の経験者を対象にし、SaaSの連携とAPIへの理解を求めています[22]。Strategistは、PM・エンジニア・コンサルタントなど多様な出身者がいるとされ、APIドキュメントやデータモデルを理解できることが必須です[4][7]。

对招聘企业和引入企业而言

  • SierraのADLCでは、会話の評価には業務のルールを知る人(カスタマーエクスペリエンスや営業の責任者など)が要るとされています[5]。ソフトバンク経由で導入する場合も、評価と改善の担当者を社内に置けるかを導入前に確かめる必要があります。
  • Decagonは、エージェントは顧客が持つものとし、プロンプトとパッチのブラックボックスにしないことを原則にしています[18]。外部に作ってもらうときは、引き渡しのあとに自社で直せる状態になるかを確かめるのが要点です。
  • 成果課金を前提にするなら、何を成果とみなし、誰が測るかを契約の前に決める必要があります。Rekhi氏も、案件の最初の会話で成功の指標を決め、できれば書面にすることを勧めています[18]。
  • 如果要自建FDE型团队，可以参考那两家将“构建者、定义成果者、连接产品者”分开并按行业设置负责人的做法。部门设置位置和评估指标在FDE组织的搭建方法中进行了比较。

总结

Sierra将FDE型工作分配给构建者、定义成果者、连接产品者三种职位，并在不使用FDE这一名称的情况下进行招聘。在日本，销售由软银承担，Agent的设计和导入由Sierra承担的体制正在形成。要点如下。

  • SierraはFDE型の職種を「Agent Engineer」と呼び、技術的な仕事の形が伝わる名前として選んだ。責任者のMeurer氏は2026年7月時点で120人超のチームを率いる[2]。
  • Meurer氏はFDEの仕事を、安定稼働・データ統合・個別ソリューション・自走支援の4つの年代の積み重ねとして説明し、共通点は顧客への責任、採用では「どの年代のFDEか」を聞くべきだとした[1]。
  • 2026年10月16日時点のエージェント開発の求人68件は、Strategist 27件、Agent Engineer 26件、PM 12件などで、30件が言語を、17件が業種などを職種名に掲げていた[14]。
  • 米国のAgent Engineerの報酬レンジは18万〜39万ドル(約2,844万〜6,162万円)で、必須要件にAIの経験は入っていない[6][25]。
  • Decagonは「FDEはプロダクト開発と同一」とし、個別対応のセルフサーブ化で1エージェントあたりの個別開発を80%減らしたと公表している[18][19]。
  • Sierraは2025年12月の東京オフィス開設の発表に続き、2026年にOPERA TECHの買収とソフトバンクとの独占販売の契約を進めたが、10月16日時点で東京のエージェント開発の求人はまだない[26][14][15][17]。

常见问题

问：Sierra 的 Agent Engineer 和 FDE 是同一个职位吗？

基本是同一类工作。Sierra 的负责人 Natalie Meurer 将 Agent Engineer 定位为 FDE 的一部分，或与 FDE 相邻的职位。与客户一起设计、构建并交付 AI Agent，并负责其在生产环境中的改进，这一点与 FDE 相同。区别在于名称的选择，Meurer 解释说，选择“Agent Engineer”这个名称，不仅是为了体现对客户的专注，也是为了体现技术工作的形态（构建 Agent）。

问：Sierra 在日本招聘 Agent Engineer 吗？

截至 2026 年 10 月 16 日尚未招聘。Sierra 公开的 186 个职位中，东京办公的职位有 4 个，分别是 3 个招聘职位和 1 个公关与市场营销职位。不过，东京招聘负责人的职位描述写明，该职位将领导包括工程和产品管理在内的整个日本招聘工作。此外，在与软银的合作中，Sierra 宣布将负责 Agent 的设计、部署与运营。

问：Sierra 的 Agent Engineer 年薪是多少？

旧金山等美国办公地点的职位描述中写明薪酬为 18 万至 39 万美元，外加股票授予（截至 2026 年 10 月 16 日）。按 1 美元 = 157.99 日元换算，约为 2,844 万至 6,162 万日元。伦敦办公地点为 15 万至 31.5 万英镑，应届生岗位（New Grad 2027）为 15 万至 18 万美元。职位描述中的区间只是报价范围，并非实际发放金额。

问：Agent Engineer 和 Agent Strategist 有什么区别？

Agent Engineer 是工程部门的职位，负责打造生产环境的 Agent，要求具备系统构建与扩展的经验。Strategist 是产品部门的职位，作为客户管理层的顾问，负责定义成功标准与部署决策。编写代码并非必备条件，但需要具备能够理解 API 文档和数据模型的技术素养。职位描述中写明，两者都要负责 Agent 开发生命周期（ADLC）。

问：Decagon 和 Sierra 的 FDE 有什么不同？

Decagon 将用技术进行深度开发的 Agent Deployment Engineer 与用平易英语组装 Agent 的 Agent Development Manager 分开设置，并将 FDE 定位为与产品开发是同一回事。Sierra 则由 Agent Engineer、Strategist、PM 三个职位分工承担。截至 2026 年 10 月 16 日，美国的薪酬区间为：Decagon 的 Agent Deployment Engineer 为 17.5 万至 23 万美元，Sierra 的 Agent Engineer 为 18 万至 39 万美元。
