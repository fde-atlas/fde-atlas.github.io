Anthropic 的 Claude 前沿部署工程师路径：11 门课程涵盖哪些内容，以及 FDE 面试仍在考察什么

原标题：Anthropic's Claude Forward Deployed Engineer Path: What the 11 Courses Cover, and What FDE Interviews Still Test

FDE Interviews · 2026-11-19 · 约 11 分钟读完

摘要

文章梳理了 Anthropic 在 Skilljar 上推出的 Claude 前沿部署工程师学习路径：共 11 门课程、约 9.5 小时，面向 Claude Partner Network 成员，最终产出是一份试点计划。作者逐课对照 FDE 面试环节，指出该路径是不错的平台与试点入门材料，但未覆盖评测、安全审查和限时案例轮。

要点

  • 路径共 11 门课约 9.5 小时，分核心、构建、试点交付三块。
  • 构建类课程占 52%，试点交付仅约 100 分钟。
  • 最终产出为含基线、成功指标、首切片和首批用户的试点计划。
  • 七门课程在公开 Academy 目录可见，其余仅限合作伙伴。
  • 路径未覆盖评测深度、安全对话与限时案例轮等面试环节。

Anthropic 在 Skilljar 上的 Claude FDE 学习路径包含 11 门课程，约 9.5 小时，以一份试点计划收尾。本文介绍每门课程教授的内容、谁能参加、它与 Frontier Academy 及认证的关系，以及它无法帮你准备的面试环节。

作者：EMILY CARTER · FDEINTERVIEWS 编辑部 · 更新于 2026 年 11 月 19 日 · 阅读时间 9 分钟

实战演练：检测你的 FDE 面试准备程度（免费） · Anthropic FDE 面试指南 · 实时定义试点成功指标 · 行为与客户问题 · 必知的 FDE 问题

Anthropic 的 Claude 前沿部署工程师路径是其合作伙伴 Skilljar 网站上的一套自学课程，共 11 门，总计约 9.5 小时，其宣称的目标是“在现场带领客户从第一个用例走到一个可运行的试点”。 四门核心课程介绍 Claude 能做什么、不能做什么以及如何选择模型。五门构建课程涵盖 Claude 平台、Claude Code、MCP 和 Agent 技能。两门交付课程涵盖试点设计与企业采用。学完后你能够撰写一份试点计划：基线、构建前商定的成功衡量标准、首个交付切片以及第一批用户。我们将每门课程与 FDE 面试流程逐一对照后的结论是：它是一份出色的平台与试点入门材料，但限时案例环节、评测深度和安全话题仍需你自己准备。

本周该学习路径在 LinkedIn 上以“Anthropic 推出了 Claude 前沿部署工程师学习路径”的形式流传。以下所有内容均已于 2026 年 11 月 19 日在 Anthropic 官方页面上核实。课程列表和时长会变动，因此请将这些数字视为特定日期的数据。

想知道在花 9.5 小时学习之前，评测、安全还是客户沟通是你的短板？ 我们的免费 FDE 准备度检测 会提出来自真实 FDE 面试环节的场景问题，覆盖 11 个领域，耗时约 15 分钟且无需注册账号，并会针对你尚未覆盖的领域返回一份学习计划。

学习路径包含什么

路径页面将课程分为三个模块，并给出每个模块的时长。下图按顺序展示这些课程，条形长度由分钟数决定。

模块课程分钟数占路径比例
核心1 至 417530%
构建5 至 930052%
试点交付10 和 1110017%
总计11575约 9.5 小时

这些算术是我们根据页面上的时长计算的，各部分占比因四舍五入加起来不正好是 100%。这个分配说明了 Anthropic 如何看待这份工作。超过一半的时间用于与 Claude 一起构建，面向客户的交付工作约占一百分钟。页面还提到该路径与 Claude Developer 路径共享九门课程，所以已完成该路径的人还剩两门课程和约 100 分钟，与两门交付课程的总时长相同。

按页面自己的表述，每个板块教授的内容如下：

  • 核心。“AI Capabilities and Limitations”讲的是“你在试点第一天就要向用户解释的那些限制”。“AI Fluency for Builders”将 Anthropic 的 4D 框架（委托、描述、辨别和勤勉）应用于构建。“Claude Platform and Model Foundations”涵盖“在编写提示词之前你要做的四个决定：入口点、能力特性、模型和上下文”。Claude Academy 上一个十分钟的模块讲解哪个 Claude 模型适合哪类任务，以及每个模型如何消耗你的速率限制。
  • 构建。“Claude Platform 101”从第一次 API 调用一直讲到 Agent 循环、工具、扩展思考、技能、MCP、上下文管理和托管 Agent。“Claude Code 101”被定位为“你在客户代码库中进行原型开发的工具”，“Claude Code in action”则涵盖通过权限模式、钩子和验证来控制的长时间无人值守会话。MCP 课程将 Claude 连接到客户的系统，Agent 技能课程则将“有效的做法打包起来，供客户团队复用”。
  • 交付试点。“Delivery Methodology”涵盖用例筛选、试点设计、基线采集以及采用与风险管理。“Driving enterprise adoption of Claude”跟随客户“从激活走向规模化”，包括赋能、上线和寻找下一个工作负载。

谁可以学习

路径页面上的注册面板显示该路径“面向 Claude Partner Network 成员开放”，且声明的先决条件是你从事软件开发并曾直接与客户团队合作。

如果你不在合作公司，大部分材料仍然可以访问。2026 年 11 月 19 日，Anthropic 的公开 Academy 目录列出了与十一门课程中七门同名的课程：AI Capabilities and Limitations、AI Fluency for Builders、Claude Platform 101、Claude Code 101、Claude Code in Action、Introduction to Model Context Protocol 和 Introduction to agent skills。Claude Platform and Model Foundations 和两门交付课程未出现在其中，模型选择模块位于 Claude Academy。标题相同并不代表内容完全一致，所以在假设某门公开课程能算数之前，请先核实。

路径、Academy 与认证：如何区分

三个不同的东西被混在一个名称之下，在面试中弄清对方指的是哪一个会很有帮助。

Claude FDE path Claude Frontier Academy Claude certifications
是什么自定进度的在线课程提名制的线下项目，外加 12 周的驻场配套备考课程的考试
时间约 9.5 小时多日课程，随后 12 周Foundations 备考约 13 小时
面向谁Claude Partner Network 成员由所在组织提名的工程师报名考试的考生
考核方式完成课程一次评分实操，随后对真实项目的评估考试本身
证书本身无证书Claude Resident Engineer 徽章，随后是 Claude Frontier Deployed Engineer 徽章Claude Certified Developer，Foundations 或 Professional

Frontier Academy 于 2026 年 10 月 2 日发布，投入 1 亿美元，目标是到 2027 年底培养 10,000 名前沿部署工程师。首批学员分布在旧金山、纽约和伦敦，包括来自 Accenture、Bain、Capgemini、澳大利亚联邦银行、Deloitte、McKinsey、Morgan Stanley 和 Novo Nordisk 的工程师。工程师们要完成一次模拟的企业部署——“从选择合适的用例，到安全审查，再到交付交接”，参加一次评分实操，然后在所在组织主导一个真实的 Claude 用例，为期 12 周。Anthropic 预计首批 Claude Frontier Deployed Engineer 徽章将于 2027 年初颁发。在线路径是通往同一知识体系的开放入口，只是没有考核环节。

完成该路径后，页面建议了三个方向：如果你的项目走向生产环境（Agent 架构、可靠性、可观测性、评测、成本与延迟、安全），可以参加 Developer Professional 考试；如果你负责解决方案设计，可以准备 Architect Professional；如果你为客户部署 Claude Code，可以考取 Claude Code 合作伙伴徽章，包含八门课程、约 12 小时、一个毕业项目和一次考核。

交付成果：一份符合该路径要求的试点计划

该路径的既定成果是一份文档，值得亲眼看一份样例。以下是一个假设用例的试点计划，按照页面指定的四个部分撰写。其中的数字是为示例虚构的。

用例。 某保险公司的理赔受理团队阅读通过邮件发来的首次损失通知，并手动录入理赔系统。Claude 起草结构化记录，由理赔员批准或修正。基线，在构建之前测量。 对 400 份通知的现有流程进行两周测量：每份通知的中位处理时间为 11 分钟，6% 的记录事后被第二位理赔员修正，从收到通知到获得理赔编号平均需要 2.1 天。成功指标，在构建之前商定。 在相同类型的通知组合下，中位处理时间低于 5 分钟。修正率不高于 6%。未经理赔员批准不得创建任何记录。每周在由客户团队标注的样本上测量，而不是在供应商的测试集上。第一个切片。 以单封邮件形式到达且无附件的车险和房屋险通知，约占业务量的 40%。带附件、多个索赔人或带有诉讼标记的通知在试点期间仍保持人工处理。第一波。 一个班次的六名理赔员，由团队主管挑选，前两周每天用十五分钟审查每一次修正。只有连续两周达到指标后，才扩展到下一个班次。

这份计划中的每一句话都是面试官可以追问的点。为什么是 400 份通知？每周样本由谁来标注，你如何防止他们打分过于宽松？你排除在外的 60% 怎么办？练习讲解计划固然好，但练习为每一句话辩护，才能真正转化为面试表现。我们的试点成功指标问题和试点验收标准概念正是围绕这一点展开的。

该学习路径涵盖的内容，对照面试流程

Anthropic 及其他公司的 FDE 面试通常包括构建或用例筛选、解决方案设计轮、案例或拆解轮、客户对话轮和编程轮。详情见 Anthropic FDE 面试指南。以下是我们对该路径在每一轮中能帮你走多远的解读。

最大的差距在于评测。该路径教你如何获取基线并商定指标，但如何从真实失败案例构建评测集、验证 LLM 评审与人类判断一致、以及通过多次重复运行来把关发布，这些内容属于 Professional 考试备考，而不在此路径中。我们的评测循环概念是攻克这一内容的最短路径。

第二个差距是时间压力。课程让你可以想思考多久就思考多久，而案例轮会给你一个模糊的业务问题和三十分钟时间。拆解轮指南和客户模拟指南正是为此而设计的。

在六周计划中我们会如何使用它

如果你正在准备 FDE 面试并且能够访问该路径：

  • 第 1 周。 学习四门核心课程。用你自己的话写一页纸，说明在你的目标行业中，Claude 有哪些方面不应被信任。你将在每一次客户对话中用到它。
  • 第 2 周和第 3 周。打开一个真实的代码仓库，学习五门构建课程。针对一个模拟的内部系统构建一个小型 MCP 服务器，再制作一个封装可重复任务的 skill。这些将成为你在面试中谈论的项目。
  • 第 4 周。学习两门交付课程，然后从我们的行为与客户问题中随机挑选用例，照上面的样子写三份试点计划。给自己计时。
  • 第 5 周和第 6 周。把时间花在学习路径未覆盖的内容上：评测、一次安全评审对话以及限时案例演练。我们的六周计划涵盖了其余内容。

如果你无法访问该学习路径，七门公开课程覆盖了第 1 至 3 周的大部分内容，而交付材料正是本站试点与推广类问题所对应的，包括那道关于九十天后推广停滞在 12% 的问题。

优缺点

优点缺点
自定进度，每门课程都标注了时长仅对合作伙伴成员开放；部分课程不公开

面试中如何谈论它

如果面试官问你如何准备，请说出你构建了什么，而不是你完成了什么。“我学完了 Claude FDE 学习路径”只是一句话。“我为一个理赔受理用例写了一份试点计划，包含一个我能在两周内衡量的基线，以及一个把附件排除在范围之外的首个切片，而且如果安全评审延迟了，我会这样裁剪范围”才是一个回答。学习路径给你词汇，面试检验你能否在压力下、在没见过的问题上运用它们。

常见问题

这是 Anthropic 合作伙伴 Skilljar 网站上的一条自定进度学习路径，描述为“带领客户从第一个用例走到现场可运行的试点”。它包含 11 门课程，约需 9.5 小时，最终培养撰写试点计划的技能：基线、构建前商定的成功衡量标准、首个交付切片，以及如何让首批用户上手。

路径页面显示它对 Claude Partner Network 成员开放。截至 2026 年 11 月 19 日，其 11 门课程中有 7 门也出现在 Anthropic 的公开 Academy 目录中，包括 Claude Platform 101、Claude Code in Action 和 Model Context Protocol 入门。我们核查时，两门试点交付课程和 Claude Platform and Model Foundations 尚未出现在公开目录中。

不是。该路径是自定进度的在线课程。Claude Frontier Academy 于 2026 年 10 月 2 日公布，是一个提名制项目：为期数天的线下课程，包含有评分的实践环节，随后是 12 周的驻场期，负责一个真实的 Claude 项目，通过考核后可获得 Claude Frontier Deployed Engineer 徽章。Anthropic 预计将于 2027 年初颁发首批徽章。

单靠它不行。路径页面将其列为 Claude Certified Developer - Foundations 考试的备考内容，另有约 13 小时的独立备考课程，并指出 Claude Certified Developer - Professional 是更高级别的认证。

它对 Claude 平台、Claude Code、MCP、技能和试点交付的覆盖不错。但 FDE 面试还会考察在限定时间内拆解模糊业务问题的能力、评测与故障诊断、安全话题的对话，以及现场应对客户压力。请将该路径的学习与这些环节的练习结合起来。

讨论 (4)

最终产出物才是有用的部分。一份在构建之前就完成基线测量的试点计划，正是大多数首次试点所欠缺的东西，也是在案例面试环节中面试官会要求你当场口头产出的成果。如果你只从这条路径中学一件事，那就练习在二十分钟内为一个你从未见过的用例写出那一页计划。

读者提问：该路径与开发者路径共享九门课程。这是否意味着它基本上就是一门开发者课程，只是加了个交付的外壳？

按分钟数来看，是的：九个半小时中约有五个小时是构建类课程，而交付只占大约一百分钟。这与 Anthropic 对该角色的描述相符——首先是工程师。这也告诉你，如果你的薄弱环节是与客户的沟通而非代码，应该把额外的自学时间花在哪里。

面试时值得把这些名称区分清楚。Anthropic 的 Academy 用的是 Frontier Deployed Engineer，Skilljar 路径用的是 Forward Deployed Engineer，而大多数职位发布写的是 forward deployed。如果咨询公司的面试官提到驻场期，他们指的是提名制的 Frontier Academy 项目，而不是在线路径。
