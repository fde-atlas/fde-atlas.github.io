Full Stack Open 怎么学：FDE 学习路线

FDE Times · 2026-10-09 · 约 4 分钟读完

摘要

文章介绍赫尔辛基大学的免费课程 Full Stack Open，并说明它为何适合想成为 FDE 的工程师：课程共 14 个部分，覆盖 React、Node/Express、TypeScript、CI/CD 与容器等客户现场常见的各层技术。作者建议按顺序学习并完成练习，把部署好的完整项目作为简历证据，并提醒商用教材需遵守 Creative Commons 许可。

要点

  • Full Stack Open 免费，共 14 部分，从 React 讲到 CI/CD 与容器。
  • 课程由 Matti Luukkainen 主笔，TypeScript、CI/CD、容器部分来自校外贡献者。
  • 纯文字加练习、无视频，不适合零基础者，需先有编程基础。
  • 对 FDE 的价值在于理解数据如何流经客户系统的每一层。
  • 建议把带测试、CI 和 Dockerfile 的已部署项目作为简历证据。

赫尔辛基大学 2019 年因“全栈”最常见于招聘广告而开课，如今 14 个部分从 React 讲到 CI/CD 与容器。

要点速览

  • Full Stack Open 免费，从 Part 0 到 Part 13。大部分内容由 Matti Luukkainen 编写，TypeScript、CI/CD 和容器部分由校外人士贡献。
  • 课程只有文字和练习，没有视频，不适合还不会编程的人。
  • 对 FDE 来说，它的价值在于覆盖了客户系统里会遇到的各层：前端、API、类型、流水线和容器。

2019 年 3 月课程上线时，赫尔辛基大学的 Matti Luukkainen 给出的理由非常务实：“full stack”是招聘广告里出现最多的词。他还说，学完这门课的人可以胜任初级开发者的工作。

七年过去，Full Stack Open 依然免费。课程现在有 14 个部分，从 Part 0 到 Part 13。

对前线部署工程师（FDE）来说，学这门课的理由和找初级岗位的人略有不同。在客户现场，你很少能自己挑技术。

你得能读懂他们的 React 前端，调用他们的 Node API，改一个 TypeScript 文件，还要弄明白他们的 CI 流水线为什么变红了。这门课把这些层都教了，而且是按它们层层叠加的顺序来教。

课程由谁打造，教些什么？

课程全称 Full Stack Open，副标题是“Deep Dive Into Modern Web Development”，官网是 fullstackopen.com。课程由赫尔辛基大学与 Houston Inc. 共同打造。2019 年 6 月，学校发布英文版，目标是把芬兰的大学教育免费带给国际学习者，由 Luukkainen 担任协调人。

Part 0 到 Part 8 以及 Part 13 由 Luukkainen 编写。其余部分由校外人士贡献：Part 9（TypeScript）来自 Terveystalo 的开发者，Part 11（CI/CD）来自 Smartly 的一位开发者，Part 12（容器）来自 Jami Kousa。

课程核心是用 React 构建单页应用，围绕它展开的有 Node/Express、测试、GraphQL、React Native 和关系型数据库。

据 About 页面介绍，课程免费，提供证书，还能获得赫尔辛基大学的欧洲学分（ECTS）。全部教材放在一个公开的 GitHub 仓库里，fork 数以千计。

它能培养哪些 FDE 技能？

设想你在客户现场的第一周。客户想要一个内部看板，从现有 API 拉数据，周五要给管理层演示。你需要搭一个 React 应用，写一层薄薄的 Node 服务来收集和清洗数据，加上 TypeScript 类型，保证 schema 变化时不出问题，最后打包成容器，让对方 IT 团队能运行起来。

清单上的每项任务都对应 Full Stack Open 的某个部分。真正练的不是某个框架，而是理解数据如何流经每一层，以及某一层出问题时错误会在哪里暴露。半夜调试别人的系统时，需要的也正是这个能力。

谁适合学，按什么顺序学？

这门课不面向初学者。About 页面要求学员编程能力扎实，并掌握 Web 和数据库基础。Scrimba 在 2026 年的全栈课程盘点中，把它推荐给想转全栈的前端开发者，但明确说还不会编程的人不要把它当作第一门课。

Scrimba 也指出了代价：课程以文字和练习为主，没有视频可以依靠。freeCodeCamp 论坛上一位在 2020 年学完大部分内容的学员给了很高评价，但仍建议先有一些 React 经验，因为文字相当冗长。

如果你是想转做 FDE 的后端工程师，先按顺序学前几个部分，也就是 React、Node/Express 和测试。不要跳过练习，正是练习逼你真正弄懂。然后直接进入 Part 9、11 和 12。

这三部分都来自校外贡献。只要代码得跑在别人的基础设施上，类型、流水线和容器就是绕不开的几层。GraphQL 和 React Native 可以等具体客户需要时再学。

三点值得记住

第一是课程的由来。上线时，Luukkainen 把它和招聘广告挂钩：full stack 是被提到最多的词。读 FDE 岗位描述时也可以这么做：列出提到的技术，标出自己已有证据的那些，再针对空缺去学。

第二，纯文字的形式听起来是缺点，其实很契合这份工作。FDE 天天要读文档、README 和别人的代码。花几周啃一套冗长枯燥的教材，正好锻炼这项能力。

最后是许可协议。教材采用 Creative Commons 许可，未经许可不得商用。如果打算在付费合同里用这些内容培训客户团队，先申请许可，或者自己写教材。

把练习变成简历

I-Programmer 2019 年的一篇文章提到，当时学分、练习提交和期末考试只对赫尔辛基大学学生开放，校外人员学的是无人监督的公开版本。无论证书如今分量如何，都应把代码仓库当作主要证据，因为招聘方可以打开自己核实。

在简历上放一个完整、已部署的应用，带测试、通过的 CI 流水线和 Dockerfile，再用一句话说明你如何让数据流经每一层。这几乎就是 FDE 一周工作的写照。

Luukkainen 说，学完这门课的人可以当初级开发者。对 FDE 而言，收获则是走进客户的代码库而不迷路。
