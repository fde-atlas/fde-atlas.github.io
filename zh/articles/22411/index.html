旧金山（San Francisco, CA）支持工程师职位 — Exa

原标题：Support Engineer Job in San Francisco, CA — Exa

Talentify · 2026-10-31 · 约 4 分钟读完

摘要

Exa 在旧金山招聘全职支持工程师，要求到岗办公。Exa 是一家面向 AI 的搜索引擎公司，刚完成由 a16z 领投的 2.5 亿美元 C 轮融资，估值 22 亿美元，团队约百人。该职位采用 AI 优先的支持模式：用 Pylon 等工具和 Agent 处理大部分工单，工程师负责 AI 无法解决的疑难问题，包括调试 API、SDK 和客户集成，直接提交修复代码，并作为客户联系人跟进到底。岗位要求多年编程经验、生产环境排障能力，并需参与 7x24 轮班。文中薪资数据为 Talentify 对加州同类岗位的统计，并非该职位实际薪资。

要点

  • Exa 完成 2.5 亿美元 C 轮融资，估值 22 亿美元，由 a16z 领投。
  • 支持工程师需处理 AI 与 Pylon 无法解决的疑难技术工单。
  • 职位要求直接提交代码修复，并跟进客户问题直至解决。
  • 需参与 7x24 轮班支持，岗位为旧金山现场办公。
  • 文中薪资为加州同类岗位统计，非该职位实际薪资。

职位提醒仅通过电子邮件发送。我们会先发送确认链接，在您点击之前不会有任何其他邮件。每封邮件都包含一键退订功能。隐私政策。

关于 Exa

我们完成了 2.5 亿美元的 C 轮融资，致力于为 AI 打造搜索引擎。本轮融资由 a16z 领投，现有投资者 Benchmark、Lightspeed 和 YC 追加投资，使 Exa 的估值达到 22 亿美元。

Exa 正在为 AI 时代打造搜索引擎。我们的 Search API 目前为 AI Agent、财富 500 强企业和 AI 实验室提供支持，正在变革一个自 90 年代以来从未被颠覆的行业。我们是一支约 100 人的团队，主要驻扎在旧金山，成员来自哈佛、MIT、Meta、Google Research，也有前创始人和辍学者。我们正在快速打造历史上最智能的搜索引擎。我们高度主动、低调务实，并因一个共同的信念而团结一致：这是少数值得做对的重要问题之一。

关于该职位

支持工程师确保每一位有承诺的 Exa 客户都能快速、全天候地解决其问题。我们以 AI 优先的方式运营支持工作：Pylon 等 AI 工具和 AI Agent 会对工单进行分类、回答并解决它们能处理的问题。您负责 AI 无法处理的部分：需要真正工程师来解决的困难、模糊的技术问题。

您将具备与我们前沿部署工程师同等的技术深度。您将深入研究 API、SDK 和客户的集成，重现 bug，并提交包含修复方案的 pull request 供我们的工程师审核。当问题确实需要工程团队处理时，您会带着他们采取行动所需的一切信息进行升级，并在问题解决之前始终作为客户的联系人。这不是一个照本宣科的岗位。您是一位对修复负责到底的工程师。

在此职位上，您将：

  • 构建支持系统：配置我们的 Pylon 实例，建立完善的工单跟踪、SLA 跟踪和自动化流程，使支持职能尽可能高效
  • 解决 AI 无法处理的工单，在 API、SDK 和客户集成之间进行故障排查
  • 重现 bug 并修复它们，直接提交 pull request 供工程团队审核
  • 在无法自行解决时向工程团队升级并提供完整背景信息：重现步骤、日志、客户影响以及您已排除的可能性
  • 对您工单上的每一次客户跟进负责，包括已升级的工单，直至问题得到解决
  • 让 AI 第一线表现更好：通过完善文档、知识库以及我们的 Pylon 和 AI Agent 工作流，让更多工单无需人工介入即可解决
  • 保持跨时区交接的紧密衔接：每班结束时通过自动化交接，让下一位支持工程师对未结工单拥有完整的上下文
  • 与客户团队协作（客户经理、前沿部署工程师），让他们及时了解其客户相关的工单，并尽早预警客户层面的风险
  • 负责升级管理：主要通过 AI 监控客户健康信号，将每一次收缩或流失风险连同建议措施和负责人上报给客户团队和领导层，并跟进直至解决
  • 发现工单中的共性模式，并将其转化为产品反馈和修复方案

任职要求

  • 多年实际编程经验。你能够阅读和调试陌生的代码，并且能自如地在生产代码库中提交 Pull Request
  • 有在生产环境中排查 API、SDK 或分布式系统问题的经验，最好涉及搜索、检索、LLM 或数据管道
  • 面对模糊问题有结构化的解决思路：你会提出正确的问题、建立假设并进行验证
  • 能清晰判断何时继续深挖、何时升级，并能向客户和工程师清楚地解释技术问题
  • 习惯以 AI 优先的方式工作，将 AI 工具和 AI Agent 融入日常工作流程
  • 能够接受轮班工作，作为 24/7 跨时区支持模式的一部分

如果你具备以下条件，可能会脱颖而出……

  • 曾在开发者工具、API 或 AI 公司担任软件工程师、支持工程师、解决方案工程师或站点可靠性工程师
  • 用 LLM、RAG 或 AI Agent 构建过产品，并能对检索和搜索质量进行推理分析
  • 构建过自动化或 AI 工作流，为团队减轻了重复性工作
  • 喜欢成为那个最终弄清楚问题真相的人
  • 深切关注如何组织世界上的知识并让机器能够访问这一问题

这是一个位于旧金山的现场办公职位。除了优质医疗福利（医疗、牙科、视力）外，我们还为所有员工提供生育福利和每月健康津贴。

Exa 是一家机会均等的雇主。所有符合条件的申请人都将获得平等的录用考虑，不因种族、信仰、肤色、宗教、性别、性取向、性别认同或表达、国籍、残障、年龄、退伍军人身份、婚姻状况、怀孕或相关状况、符合适用法律的犯罪记录，或任何其他受适用法律保护的特征而受歧视。
