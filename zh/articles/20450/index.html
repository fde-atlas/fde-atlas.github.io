高级前沿部署工程师 | Clutch | 远程，美国

原标题：Senior Forward Deployed Engineer | Clutch | Remote, US

Zero G Talent · 2026-10-02 · 约 8 分钟读完

摘要

Clutch 正在招聘资深前沿部署工程师，远程（美国），负责其面向信用社的 AI Agent 从签约到上线的全流程交付。其催收 Agent Emma 已在五家信用社上线，其中一家十二周内处理逾六万次会员对话。该岗位要求七年以上工程经验、TypeScript/Node.js 后端能力、集成与安全经验，需约 20% 出差，年薪 15.8 万至 21 万美元，公司获 Andreessen Horowitz 投资。

要点

  • Clutch 为信用社构建 AI Agent，催收 Agent Emma 已在五家信用社上线。
  • FDE 每周写生产代码，负责集成、Agent 调优、现场测试与上线。
  • 要求七年以上经验，强调 TypeScript/Node.js、集成与安全判断。
  • 平均约 20% 出差，团队分布于美国、巴西、阿根廷，异步协作。
  • 年薪 15.8 万至 21 万美元，公司由 Andreessen Horowitz 支持。

任职要求

  • 5 年以上软件工程经验，SaaS/金融科技背景，资深 TypeScript/Node.js 能力
  • 集成/API 工程：安全端点、第三方 API、遗留银行系统
  • 安全/认证判断力：OAuth、M2M、租户隔离、密钥管理、不涉及 PII
  • 客户现场能力：为副总裁级客户提供咨询，在现场做出并承担决策
  • 代码质量判断力：有意识地引入技术债务、明确标注、逐步偿还

工作内容

  • 端到端负责信用社的实施落地：集成、配置、上线
  • 独立运行 LLM Agent 的评测/调优循环
  • 开展现场走访，将反馈转化为产品决策
  • 为未来的 Agent 构建可复用的平台能力
  • 为 AI Ops 团队编写实施手册

关于该职位

Clutch 构建为信用社服务的 AI Agent。我们的催收 Agent Emma 已在五家信用社上线，并在其中一家的前十二周内处理了 60,000 多次会员对话。在她背后是一个不断壮大的产品组合：贷款发起、欺诈二次验证、会员（重新）互动与激活 Agent，全部构建在同一个 Agents Platform 之上（TypeScript、NestJS、我们自研的 agent SDK、MCP、Temporal、promptfoo）。

作为一名 FDE，你是某个 Agent 的两位工程师之一。你负责将其在特定信用社从“已售出”推进到“上线并高效运行”：你参与需求发现会议，构建与其核心银行系统和贷款系统的集成，编写并调优 Agent 的行为，与其员工一起进行线上测试，并陪伴它度过上线以及投产后的最初几周。当需要有人亲临现场时，你就是那个飞过去的人。

这是一个资深工程职位，而非解决方案或支持职位。你每周都会在我们的 monorepo 中编写生产代码：集成、模块以及 Agent 本身（提示词、工具、评测），与 pod 中的其他工程师协作。与传统工程师的区别在于，你更常驻现场，需要在客户面前做出判断决策，并对结果负责。你在一线学到的东西会直接回流到产品中：默认配置、实施手册，以及下一个 Agent 所需的平台能力。

你负责构建；我们的 AI 运营经理负责交付。Pod（pod 负责人加工程师）以高度贴身的方式与首批客户共同设计和构建每个 Agent。一旦 Agent 定义完成并上线，AI Ops 会协调后续信用社的实施、配置和持续成功运营。你交给他们的是一个能用的产品以及一份运行手册。

  • 该职位平均需要约 20% 的差旅，在项目启动和上线前后会有连续一到两周的出差。base 在美国，能够短通知内出差

关于团队

你将加入 Agents 团队——一个在 Clutch 内部以创业公司方式运作的小型资深团队：七名工程师、一个专门的 AI 产品小组以及 AI 销售专家，直接服务全国一些最大的信用合作社。每个 AI Agent 由两名工程师共同负责，一人偏重对话和 LLM 方面，一人偏重软件和集成方面，另有一位 pod 负责人掌管产品的日常运营。你与客户之间没有任何中间层，你与平台团队之间也没有任何中间层。

团队的工作风格是直接、书面化、以证据为驱动：采用 BLUF（结论先行）式更新，评测优先于观点，业务成果优先于工单数量。团队分布在巴西、阿根廷和美国，默认以异步方式协作。现场办公是我们在特定时刻（项目启动、现场测试、上线）使用的工具，而非长期驻派。

工作内容

在 1 个月内，你将：

  • 通过团队的评审流程，向一个线上运行的 AI Agent 交付你的首个生产变更，并能解释会员来电如何从端到端流经 Agents Platform
  • 深入学习一个 AI Agent：系统提示词、工具契约、编排触发器、合规关卡，以及从项目启动到上线的实施流程
  • 以第二工程师的身份参与至少一个信用合作社的实施项目，包括与其员工进行现场测试
  • 梳理当前实施流程中浪费时间的环节，以及哪些默认配置或工具本可以减少一轮往返沟通

在 3 个月内，你将：

  • 端到端负责一个信用合作社实施项目的技术部分：核心系统和 LOS 集成、AI Agent 配置、测试、上线以及上线后的最初几周
  • 负责你所负责 AI Agent 的评测与调优循环（黄金对话记录、评分标准评判、回归测试套件），并在无需第二工程师复核的情况下被信任修改其行为
  • 完成至少两次现场走访，并将你在现场听到的反馈与 pod 负责人和 PM 一起转化为产品决策
  • 向 Agents Platform 贡献至少一项可复用的能力，使下一次实施无需重新构建

在 6 个月内，你将：

  • 将一个全新的 AI Agent 从售出推进到在首家信用合作社上线，并拥有可以向合作伙伴展示的数据
  • 成为信用合作社员工在部署需要变更时点名求助的工程师
  • 编写好你所负责 AI Agent 的实施手册，使 AI Ops 团队能够在没有你的情况下完成第二和第三家信用合作社的实施
  • 参与塑造下一代 AI Agent 的形态，因为你已经亲眼见证了现有 AI Agent 在实际应用中的失效之处

我们期待你具备

按大致优先级排序。

  • 7 年以上快节奏环境中的软件工程经验，最好在 SaaS 和/或金融科技领域，具备在大型代码库中使用 TypeScript 和 Node.js 后端的高级经验（NestJS、CQRS、模式校验边界、依赖注入）。我们不计算 AI 经验的年限；这个领域太年轻，年限说明不了什么。我们看重的是你交付过什么，以及你如何对它进行推理
  • 集成与 API 工程：安全的服务间端点、第三方 API、Webhook，以及与那些并非为集成而设计的遗留银行系统打交道的耐心
  • 安全与认证判断力：OAuth 与机器对机器认证、租户级访问控制、密钥管理、日志中不留 PII。我们的 Agent 会接触敏感的会员数据，并受消费者联络相关法规的约束
  • 客户在场能力：你能与催收副总裁面对面而坐，听取需求，并说出“这是我的建议及其理由”，即使答案是“不行”也是如此。你能在现场果断做出决策，并在事后为之负责
  • 截止日期压力下的代码质量判断力：你有意地承担技术债务、明确标注它并逐步偿还，而不是过度打磨或留下隐性债务
  • 对 LLM Agent 的真正热情：对非确定性系统的评测纪律、像读代码一样阅读系统提示词、理解某些决策绝不能交给模型。好奇心加上已交付的成果就足够了；不要求研究深度
  • 加分项（明确非必需）：语音与电话系统（LiveKit、Twilio）、Temporal 或事件驱动编排、Python、核心银行或 LOS 集成经验、信用合作社或银行业务领域知识

你能获得什么？

  • 远程办公灵活性： 享受随时随地远程工作的自由，轻松平衡生活与事业。
  • 难忘的线下聚会： 每年两次，与同事在精彩的目的地相聚，增进团队协作，激发新想法。
  • 带薪休假： 每年享受灵活的带薪休假，放松身心、恢复活力。
  • 股票期权： 加入我们意味着分享我们的成功，因此你的薪酬方案中将包含股票期权。
  • 居家办公设备： 使用专属预算购置居家办公必需品，打造你的理想工作空间。
  • 差旅预算： 通过工作相关差旅和联合办公预算，实现个人与职业的双重成长。
  • 健康保障： 通过全面的健康和牙科保险计划，优先关注你的健康。

关于我们

Clutch 是一家革命性的垂直 SaaS 公司，由 Andreessen Horowitz (A16z) 惊喜投资，致力于彻底改变信用合作社与会员互动并改变他们生活的方式。作为财务健康的倡导者，在美国人均家庭债务超过 155,000 美元的时代，我们致力于满足人们对可负担贷款解决方案的迫切需求。与传统金融机构不同，Clutch 开发软件将信用合作社转变为金融科技（FinTech）贷款机构，并利用其资产负债表负责任地为超过 1.3 亿美国人提供贷款。我们的使命不仅限于金融交易本身；我们努力从根本上提升信用合作社与会员互动的方式。通过整合前沿技术和以用户为中心的设计，我们帮助信用合作社提供与领先科技公司比肩的无缝数字体验。这种方式不仅保留了信用合作社固有的社区化和以会员为中心服务的悠久传统，还使其焕发新的活力。

Clutch 是一家机会均等的雇主。所有申请人的录用考量均不涉及种族、肤色、宗教、性别、性取向、性别认同、国籍、退伍军人身份或残障状况。

薪资透明度 美国第一梯队（旧金山、纽约、洛杉矶、西雅图）：$176,000 - $210,000 美国第二梯队（其他所有地区）：$158,000 - $188,000 实际薪酬可能因资历、技能、经验和地点而有所不同。基本工资不包括奖金、股权或福利，如适用，这些将额外提供。招聘申请长期接受。

我们的组织参与 E-Verify（就业资格验证）。点击此处了解 E-Verify。关于 Clutch 使用 AI 的说明 我们热爱 AI。我们经常使用它，并鼓励团队在工作中创造性地、高效地利用 AI 工具。如果你加入 Clutch，我们希望你同样热衷于探索 AI 如何放大影响力、生产力和创新。不过，在面试过程中，我们想听到你自己的想法。请在面试中不要使用 AI 工具——我们的目标是了解你如何思考、解决问题和沟通。一旦你入职，就尽情使用提示词吧！

关于 Clutch

构建覆盖整套银行产品的互联端到端旅程。无论是开设新账户还是申请贷款，都提供一流的数字化获客体验。Clutch 的现代化平台为会员和员工消除摩擦——释放增长、提升运营效率并深化客户关系。我们解决的问题：• 存款增长：从直观的界面到最先进的安全功能。通过让开户流程快捷顺畅来吸引更多存款，提升您的钱包份额。• 贷款增长：促成更多新贷款发放，为更多现有贷款再融资，转化更多申请人，扩大您的市场份额。• 全渠道：无论在线上还是网点，都提供同样快捷顺畅的会员和存款开户体验。• 运营效率：通过我们的集成减少繁琐的后台任务，让您的员工更快审批贷款、更轻松地为存款账户放款。
