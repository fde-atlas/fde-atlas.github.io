Rocketlane 自动化：为真正重要的工作腾出时间

原标题：Rocketlane Automations: Making time for work that matters

Rocketlane · 2023-11-10 · 约 9 分钟读完

摘要

本文是 Rocketlane 的 RocketFuel 系列工作坊内容，由产品经理 Vedika 介绍 Rocketlane Automations 功能。文章引用 Formstack 与 Rocketlane 自身的调研数据，说明自动化可节省成本、标准化流程，并缓解客户引导团队在跟进审批上耗费大量时间的问题。文中介绍了模板、SmartFill 等既有功能，讲解全局与模板级自动化的设置方式，列举软件实施、企业客户监控等应用场景，并预告 webhooks、HTTP 请求和定时触发器等新特性，最后以问答形式回应常见用例。

要点

  • Formstack 调研：自动化每年最多可节省 46,000 美元，可标准化 76% 的日常运营。
  • Rocketlane 调研显示 62.1% 的引导人员最耗时的工作是催促客户审批，也最希望自动化。
  • Automations 支持跨项目、阶段、任务和表单设置触发器，可全局或按模板配置。
  • 路线图包括出站 webhooks、HTTP 请求和定时触发器等新功能。
  • 问答环节覆盖邮件审批、HubSpot 日志记录、表单驱动的模板自动导入等场景。

总结博客内容

这是 RocketFuel 的最新一期，这是一个互动式研讨会系列，我们邀请构建 Rocketlane 的专家来学习如何打造令人愉悦的客户上手体验的细微之处。

本期嘉宾是 Vedika，她是一位狂热的高尔夫爱好者，也是 Rocketlane 的产品经理。她是我们的一个颠覆性功能——Rocketlane Automations 背后的智囊。

面对严峻经济环境下“用更少资源做更多事情”的日益增长的压力，企业正将技术视为必需品，而非奢侈品。

于是，自动化应运而生，它是高效、高产地大规模管理运营的解决方案。

自动化不仅能提升绩效，还有助于员工的身心健康，让企业在不确定性中蓬勃发展。

根据 Formstack 的工作流自动化研究，采用自动化的企业可以获得多重收益。例如，通过将运营的某些环节自动化，它们每年最多可节省 46,000 美元。

此外，自动化使 76% 的日常运营得以标准化，并简化了 36% 的法规与合规工作。这些数字意义重大且可衡量，对利益相关者和企业领导者都极具吸引力。最终，这些切实的影响能够助力企业顺利实现规模化扩张。

Rocketlane 的 2024 年客户上手现状调查 显示，高达 62.1% 的上手专员认为工作中最大的时间消耗是跟进和催促客户及项目利益相关者进行审批。这也是他们最希望自动化的工作。流程的自动化和标准化也是他们 2024 年的首要目标之一。

在与客户交流时，我们经常遇到一个问题：自动化如何帮助员工以及那些将重复性任务自动化的人。首先，我们认为它能减轻压力，因为你不必不断重复做同样的事情。它还能让你腾出时间专注于能推动业务发展的高价值工作，并充满信心地实现规模化。

但自动化对我们来说并不新鲜！

这是我们在 Rocketlane 内自动化的首批创意之一。它最初专注于消除重复性任务，尤其是面向客户的团队中的任务。模板解决了简化周期性项目任务、文档和更新流程的需求，无论是每周、每季度还是每月。这包括将客户反馈模板化。其口号概括了精髓：“花时间创建一次，永久使用。”它强调了通过自动化这些重复性元素所获得的效率，为持续进行的项目节省时间和精力。

SmartFill 就像一个作弊码，可用于在项目或任务级别捕获动态信息。你还可以用它来个性化与客户的沟通，甚至通过我们强大的集成功能，将技术栈中的信息引入 Rocketlane。

其目标是消除重复手动输入的需要，例如在通知中用姓名称呼个人。借助 SmartFill，用户可以自动插入动态信息（如客户的名字），从而提高沟通效率。虽然它与 CRM 或客服系统中的占位符类似，但 Rocketlane 中的 SmartFill 将个性化提升到了更深的层次，可以在整个平台中动态引入项目或任务中已有的信息。

‍Rocketlane Automations 可以帮你免去从项目启动到交付过程中的繁琐任务，同时打造卓越的客户体验，并让所有人随时了解进展。它支持跨项目、阶段和团队进行自动化，助你掌控交付中的混乱，在不牺牲定制化的前提下简化运营。

Rocketlane Automations 重新定义了项目管理，让用户能够亲手构建符合自身业务需求的定制化工作流。该功能带来了一系列能力，使用户可以在项目、阶段、任务和表单之间无缝扩展自动化。

从标记逾期任务，到通过热情的欢迎邮件和满意度调查实现客户互动自动化，它培养了一种以客户为中心的工作方式。此外，它还帮助用户通过构建升级矩阵来减少项目交付中的不可预测性，并掌控时间线。跨团队协作的梦想也随着项目阶段之间的顺畅过渡而成为现实。Rocketlane Automations 还能确保整个组织的运营标准化，同时为独特的项目需求保留灵活性，实现高效而不重复、定制而不复杂。简而言之，它将项目管理转变为一种连贯、以客户为中心且精简流畅的体验。

在 Rocketlane，我们从两个层面考虑自动化：一个是全局层面，另一个是模板层面。

全局自动化 更适用于账户级别的使用场景，而 模板自动化 则可用于更具体的场景。

自动化的可能性是无穷的。你可以通过多种方式定制工作流，以适应你的业务和标准实践。你可以进行全局设置，也可以使用模板来设置。

以下是企业在 2024 年可以实现自动化的一些工作流：

假设您的公司专注于为不同领域和规模的用户提供软件实施服务。为了高效应对这种多样性，您可以设置不同的项目模板，分别面向中小企业、中型市场和大型企业客户。每次实施都遵循一套标准实践，例如在项目启动时发送个性化的电子邮件邀请，详细介绍项目信息和联系人。作为具有前瞻性的领导者，这意味着您会预先组建一个升级处理团队来应对潜在的陷阱，确保实施过程的每一步都顺利进行。无论是定制项目模板还是主动应对挑战，您的做法都将体现战略远见和适应能力，最终提升软件实施的成功率。

设想这样一个场景：您的公司受托服务关键的企业客户，您需要密切监控他们的实施过程。您的目标是确保流程顺畅，不仅满足他们的期望，还可能通过专门的反馈表获得好评。传统上，这一流程需要手动登录系统，识别偏离轨道的项目、未完成的任务和待发送的客户邮件——这是一份耗时且繁琐的日常维护清单。然而，借助自动化，这套繁琐的例行工作可以变得非常简单。工作重心随之从日常维护转向战略监督，让您能够更高效、更有影响力地管理关键客户的实施过程。

以下是我们正在为自动化功能开发的几项增强功能：。

1. 我们正在推出 webhooks 和 HTTP 请求，两者均为传出类型。这意味着您可以自由地从 Rocketlane 获取信息，并以您想要的格式使用，无论是我们提供的格式还是您自选的格式。在从我们的平台提取数据时，您还可以灵活自定义多个方面。

2. 第二种类型是“定时计划”触发器。例如，如果您想运行每周例会，或与团队负责人进行每月沟通，都可以进行设置。您还可以将其设置为监测是否有人在每周五晚上提交表单，并在有人未提交时收到通知。基本上，任何需要按特定时间间隔召开会议或进行跟进的例行任务，都可以使用定时计划触发器实现自动化。

1. 我可以设置每周在特定日期发送电子邮件，为公司内部用户分配私人任务吗？

可以，我们的“定时计划”触发器可以解决这个问题。它允许您按每周、每月甚至每季度的频率重复执行活动。

2. 可以利用自动化来推动产品采用吗？

是的，Rocketlane Automations 可以帮助您推动产品采用，并帮助您的客户获得产品的预期价值。例如，如果响应延迟导致客户流失，可以通过设置以客户为中心的触发器来缓解这一问题，通知内部团队加快回复速度，保持客户的参与度。Rocketlane Automations 提供多样化的解决方案，并可根据您的具体使用场景进行定制。

3. 对于包含审批步骤的项目，是否可以设置自动发送的电子邮件？我的想法是，在自动化触发后，项目经理（PM）在邮件发送前对其进行编辑。

可以。让我们把这个流程分解成几个步骤。这可以通过两个不同的自动化无缝实现。

步骤 1：触发发送给您的项目经理（PM）的电子邮件，供其编辑。

步骤 2：启动审批流程，由业务经理审核该邮件。

步骤 3：设置另一个自动化，当特定任务被标记为完成时，将邮件发送给客户。

4. 可以使用 Rocketlane Automations 记录来自 Hubspot 的电子邮件吗？

可以。您可以通过 Webhook 和 HTTP 请求从 Rocketlane 推送信息，实现向您选择的任何系统的无缝数据传输。在发送电子邮件方面，Rocketlane Automations 让操作更加便捷。例如，您可以使用 Automations 发送邮件，只需将电子邮件地址添加到密送（Bcc）字段，即可轻松地将这些邮件记录到 HubSpot 等系统中。此外，Rocketlane API 是即将推出的功能，将为您提供端到端的灵活性，高效地传输信息。

5. 如何让不属于 Rocketlane 项目的客户也能及时了解情况并获得项目状态通知？我们可以通过 Rocketlane 向他们发送每周状态报告和提醒吗？

可以，我们可以通过 Rocketlane 的“发送电子邮件”（Send Email）操作来实现。借助“发送电子邮件”操作，您可以轻松通知 Rocketlane 之外的人员，确保关键利益相关者及时了解情况。这不再是手动流程，无需再纠结是否应该发送邮件或是否值得占用某人的时间。通过将其与自动化触发器关联并定义条件，您可以将电子邮件通知无缝融入您的自动化中，让所有人同时获知信息，即使是那些不直接使用 Rocketlane 的人。我们的许多客户，尤其是喜欢通过收件箱了解动态的领导者，都对这一功能非常满意。

6. 我们希望避免为项目创建千篇一律的模板。相反，我们希望采用类似乐高积木的自组装方式：在发现或启动阶段向客户提出几个问题，并根据他们的回答为其构建定制化的计划。目前这一流程是手动完成的，能否借助 Rocketlane Automations 将其自动化？

可以！我们可以设置触发器和条件来处理表单回复。根据客户的回复，我们可以自动导入相关的模板。

例如，如果客户在表单中选择了 JIRA 和 Slack 集成，我们的自动化功能就会自动用我们创建的 JIRA 和 Slack 模板填充剩余阶段。这无需人工干预，也省去了查看客户答案的麻烦。
