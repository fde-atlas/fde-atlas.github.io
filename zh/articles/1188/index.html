AWS 斥资 10 亿美元投入前沿部署工程中心

原标题：AWS funnels $1B into forward deployed engineering hub

CIO Dive · 2026-06-30 · 约 2 分钟读完

摘要

AWS 宣布投入 10 亿美元组建专门的前沿部署工程组织，将软件工程师团队与 AI Agent 结合，在客户环境中构建和部署 AI 系统。该模式以 Agent 为先，采用 45 天冲刺压缩部署周期，并在客户 AWS 账户中部署语义层和知识图谱，使 AI Agent 长期驻留支持持续创新。Cox Automotive、NBA 和 NFL 已在使用该服务，NFL 在数周内推出了 NFL Fantasy AI 等功能。

要点

  • AWS 投入 10 亿美元组建前沿部署工程组织。
  • 模式以 Agent 为先，5-6 人小组与 AI Agent 协作。
  • 采用 45 天冲刺压缩部署周期。
  • 语义层与知识图谱让 AI Agent 长期驻留客户环境。
  • NFL、NBA、Cox Automotive 已在使用该服务。

全文

反馈。

简报要点：

  • 这家云计算巨头在周二的一份公告中表示，AWS 正在向一个专门的前沿部署工程组织投资 10 亿美元，该组织将其由软件工程师组成的前沿团队与 AI Agent 相结合，在客户环境中构建和部署 AI 系统。
  • AWS 前沿 AI 工程与服务副总裁 Francessca Vasquez 表示，AWS 的 FDE 模式设计为 Agent 优先，也就是说，虽然由五到六名人类工程师组成的小组最初会在客户组织内工作以压缩部署周期，但目标是让 AI Agent 在业务环境中长期运行，以支持持续创新。
  • Vasquez 告诉 CIO Dive，AWS 的方法针对端到端业务工作流，并且“正在重新构建我们部署的最后一公里”。她说：“我们认为这是客户希望通过 Agent 获得更多价值的下一个演进方向。”

深度分析：

随着企业在自身环境中规模化部署 AI，AWS、Google 和微软等公司正在大力投资 FDE 项目，帮助客户解决采用过程中的痛点。

Google Cloud 今年早些时候发布了59 个工程职位的招聘启事，以充实公司市场推广团队中一个专注于 AI 的部门。与此同时，埃森哲在 3 月与微软宣布了推出前沿部署工程业务的计划。

AWS FDE 的方法将人类工程技能与 AI Agent 相结合。FDE 团队将使用 Agent 化的部署技术，让 AI 在有人参与的情况下为项目提供动力。据 AWS 介绍，随着项目推进，客户工程师将与 AWS 团队共同创建工作流，以便在 FDE 组织离开后，他们能够借助留下的 AI Agent 自主继续推进。

Vasquez 告诉 CIO Dive：“我们确实认为，我们在 FDE 执行方面的差异化优势在于，能够在非常短、高度压缩的时间周期内——45 天的冲刺——将人类专业知识与 Agent 的力量结合起来，帮助客户加速实现价值。”

公告称，这项工作的一个核心组成部分是部署到客户 AWS 账户中的语义层，它将连接企业数据源，并利用 AI 发布一种称为知识图谱的结构化数据网络，AI Agent 将基于该知识图谱进行推理，从而在客户代码中沉淀长期存在的专业知识。

包括 Cox Automotive、NBA 和 NFL 在内的 AWS 客户已经在使用 AWS FDE 组织的资源。

NFL 首席信息官 Gary Brantley 在公告中表示，NFL 与 AWS FDE 合作，在数周内与其技术团队共同构建了包括 NFL Fantasy AI 和 NFL IQ 在内的新客户功能。
