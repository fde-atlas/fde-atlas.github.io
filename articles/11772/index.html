FDE Practice Charter

FDE Interviews · 2026-10-07 · 1 min read

Summary

This piece introduces the idea of an FDE practice charter: a document that specifies which work the team accepts, who funds it, and who has authority to change commitments. The author argues that admission gates should be set up before evaluating attractive-looking projects, so the practice only takes on work it can actually finish. The page also lists related course lessons and practice questions, covering scenarios such as defining pilot success metrics with a customer live and running a workshop to pick the first use case when a customer brings 30 AI ideas.

Key points

  • A practice charter defines what work the team accepts
  • It clarifies who funds work and who can change commitments
  • Set admission gates before comparing attractive projects
  • Core rule: admit only work the practice can finish
  • Related exercises cover pilot metrics and use-case selection
