Summary

Independent engineer Rohit Raj lists AI delivery services centered on an embedded forward deployed engineer who works inside a client's repo from workflow discovery to production. Offerings include MCP integration consulting for connecting AI agents to APIs and databases, Claude Code setup with skills, hooks and evals, a two-week AI engineering foundations program, fractional FDE engagements, and 6-8 week MVP sprints for pre-seed startups, plus mobile, fintech and healthcare app development for the Indian market.

Key points

  • Embedded forward deployed engineer covers workflow discovery through production rollout.
  • MCP consulting connects AI agents securely to APIs, databases and internal tools.
  • Claude Code consulting covers skills, hooks, subagents, CI pipelines and guardrails.
  • Fixed-scope 6-week MVP sprints let founders own the code from day one.
  • Services target Indian fintech, healthcare and WhatsApp bot use cases.

Choose the scope you need

For a defined feature such as document search or an AI product backlog, choose freelance AI engineering. If the work starts with operators and spans several internal systems, an embedded forward deployed engineer covers workflow discovery through rollout. If you already have an agent and need it to reach an approved API or database, start with MCP integration consulting.

  • 1Foundations →Train the team: specs, models, effort, context files.
  • 2Measure & roll out →Tool setup, guardrails and a productivity baseline.
  • 3Build →AI systems shipped inside your product.
