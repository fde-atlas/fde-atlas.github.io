Forward deployed engineer skills, what the 2026 postings ask for

Masai School Blog · 2026-10-30 · 8 min read

Summary

This article reviews the skills demanded of forward deployed engineers in 2026, based on Bloomberry's analysis of roughly 1,000 mostly US postings plus job listings from DevRev, Databricks, Cursor, Anthropic, OpenAI and Indian companies. Python appears in 66% of postings, AI agents in 35%, LLM experience in 31% and RAG in 12%; cloud demands centre on AWS (32%), GCP (22%) and Azure (18%). Postings also stress customer-facing work such as discovery, pilots and demos. Skill emphasis varies by employer type: data platform firms want Spark and multi-cloud, AI product firms want agents and evals, integration-heavy firms want TypeScript and SQL. Experience bars typically run 4-6+ years, certifications are rarely required, and employers value evidence that something has shipped and run in production.

Key points

  • Bloomberry's ~1,000-posting analysis: Python 66%, AI agents 35%, LLM experience 31%, RAG 12%.
  • Cloud skills: AWS 32%, GCP 22%, Azure 18%; TypeScript appears in 35% of postings.
  • Customer-facing skills are universal: discovery, onsite pilots, demos, embedding with client teams.
  • Employer type shapes asks: Databricks wants Spark and multi-cloud; Cursor and Anthropic want agents and evals.
  • Experience bars of 4-6+ years dominate; shipped production artefacts matter more than certifications.

Forward deployed engineer skills: Bloomberry's analysis of about 1,000 postings found Python in 66%, AI agents in 35% and LLM experience in 31% of roles.

The forward deployed engineer skills that postings ask for most are Python, cloud deployment and hands-on work with LLMs and agents. Bloomberry's analysis of about 1,000 postings (mostly United States), updated on 25 January 2026, found Python in 66%, TypeScript in 35%, AWS in 32%, AI agents in 35% and LLM experience in 31%. Customer-facing skills sit on top of that list.

Which engineering, cloud and data skills do forward deployed engineer postings name?

Python is the most named language. Beyond it, Bloomberry found TypeScript in 35% of postings, AWS in 32%, GCP in 22% and Azure in 18%. The data set is mostly United States postings from late 2025, and the shares overlap because one posting can name several languages and clouds, so they cannot be added together.

India's postings point the same way. DevRev's Delhi NCR FDE posting, updated on 9 October 2026, asks for work in TypeScript, JavaScript or Python and for SQL. Databricks' Senior FDE posting in Bengaluru, updated on 6 October 2026, asks for Python, Scala or JavaScript and TypeScript, two or more of AWS, Azure and GCP, Apache Spark and CI/CD. Cursor's India posting asks for strong Python and TypeScript or JavaScript.

Indeed's India report, relayed by IANS on 14 October 2026, lists the wider family of skills: Python or Java, data engineering, APIs, integrations and full-stack development, along with cloud technologies. Palantir's posting asks first for a strong engineering background, with computer science, mathematics, software engineering, physics and data science named as preferred fields.

The common thread is integration work. Observe.AI's posting, discussed below, describes a role that is not building foundational models. OpenAI's posting puts the job at leading end-to-end deployments in production. Production-grade code in Python or JavaScript is how OpenAI's San Francisco posting of 11 September 2026 puts it.

Which AI skills do forward deployed engineers need: agents, LLMs, RAG and evals?

The AI layer is the part that has changed most. Among AI skills in Bloomberry's data, AI agents appeared in 35% of postings, LLM experience in 31%, RAG in 12%, OpenAI in 8%, Anthropic or Claude in 7% and PyTorch in 6%. Product and model names matter less than the pattern: employers want applied work with language models, not research.

The postings add detail on what applied work means. Anthropic's London FDE posting, updated 14 September 2026, asks for production LLM experience covering prompt engineering, agent development and evaluation frameworks, and says FDEs deliver MCP servers, sub-agents and agent skills. OpenAI's posting asks for LLM-powered systems and for success to be measured through production adoption and eval-driven feedback. DevRev asks for prompt engineering and semantic search tuning.

Evals, meaning systematic tests of whether a model-based system behaves as intended, recur in the better-specified postings. Cursor's India posting says FDEs own production quality, listing tracing, evals, metrics and the trade-offs between latency and cost. The earlier explainers on retrieval-augmented generation and on the core elements of an AI agent cover the concepts underneath.

India's own job market shows the same direction in broader data. Naukri's AI at Work report, summarised on 16 July 2026, found AI mentions in technology job descriptions grew nearly 17-fold, from 0.9% in 2020 to 15% in 2026. In foundit's 2025 breakdown of AI postings, Generative AI and LLMs appeared in 22% with 58% year-on-year growth, and MLOps and model deployment in 10% with 42% growth.

Which customer-facing skills do the postings spell out?

DevRev describes its FDE role as 80% customer-facing. Cursor has FDEs lead discovery with customer engineers. OpenAI lists discovery and technical scoping as part of owning a deployment. Anthropic says FDEs embed with strategic customers, and HackerRank's Bengaluru posting asks for a customer-facing technical lead who works onsite, runs pilots and demos, and can explain web applications as well as debug them.

The postings name discovery (Cursor, OpenAI), embedding with customers (Anthropic), and onsite pilots and demos (HackerRank). Salesforce said on 18 March 2026 that its FDEs code, consult and translate agentic AI into working solutions, often sitting side by side with the customer.

HackerRank lists solutions or sales engineering experience as a plus; the other postings ask for engineering experience with customer-facing work. The postings tie communication to engineering judgement. Sarvam's Agent Engineer posting, for example, expects the engineer to sit with a customer's engineering team.

The pattern follows the employer. A data platform company such as Databricks leans toward data engineering, Spark and multi-cloud work. An AI product company such as Cursor or Anthropic leans toward Python plus agent and evaluation skills. An integration-heavy software company such as DevRev adds TypeScript, SQL and customer-system connections.

The experience bar changes with employer type as well. DevRev asks for 5+ years, Databricks 6+, Anthropic 4+ and OpenAI 5+, while Cursor states no minimum. A skills list that looks like a graduate syllabus can sit under a job that asks for several years of delivery.

What do the India postings add, and which skills or certifications genuinely help?

India's postings add two things. First, the customers are often large Indian institutions: Sarvam's Deployment Strategist role is aimed at India's large banks, insurers, digital natives and government departments. Second, delivery roles at Indian AI companies stress shipping. Observe.AI's AI Agent Engineer posting in Hyderabad, dated 23 September 2026, describes a client-facing, delivery-focused role that designs, integrates and deploys enterprise voice and chat AI agents and is explicitly not building foundational models.

On certifications, the postings are sparse. Databricks lists Databricks Certification among what it looks for in its Senior FDE role, but it is one line among many and sits beside 6+ years of experience. Anthropic's minimum education is a Bachelor's degree or an equivalent combination of education, training and experience, and DevRev asks for a Bachelor's or Master's degree in computer science, engineering or a related technical field.

Rubrik's Senior Applied AI Engineer posting in Bangalore, updated 21 October 2026, shows how the neighbouring titles read: 8+ years of software engineering with 1 to 2 years shipping AI-agent features into production, plus React or Next.js, REST APIs and distributed systems. That is a different bar from an FDE posting, and a reminder to read each description.

How can an engineer show evidence for each of these skills?

The postings repeat one idea: show that something ran. Sarvam's Agent Engineer posting of 20 August 2026 says that having shipped and run something real users depended on matters more than years. Cursor asks for experience owning AI-native workflows in production. Anthropic's names a deliverable, an MCP server. These point to evidence an engineer can produce without a job title.

Learning in the current AI era is easier to organise around artefacts than around topics. Backend work can be evidenced by an API that others call. Cloud work can be evidenced by a deployment that someone else can reach. The AI layer can be evidenced by a retrieval or agent system with an evaluation set. Customer skills can be evidenced by a written discovery brief for a real or realistic problem.

A repository with these pieces speaks to much of what the postings ask. It also speaks to the experience question indirectly, since Anthropic's posting accepts an equivalent combination of education, training and experience. The path through the experience bars is covered in the post on how to become a forward deployed engineer, and the market for these roles in India is in the post on forward deployed engineer jobs in India.

Where does a structured programme fit?

A taught route is the Forward Deployed Engineer (FDE) Cohort. It is a Leap by Masai programme for engineers with hands-on technical experience, run as an in-person start, an online build phase and an in-person hackathon for qualifying participants, covering production Python, APIs, cloud deployment, LLMs, retrieval, agents, security and client engagement. Its eligibility reads: engineers with at least 1 year of hands-on technical experience and comfort writing code.

Frequently asked questions

What skills does a forward deployed engineer need?

Strong Python, cloud deployment on AWS, Azure or GCP, APIs and integrations, and applied LLM work including agents, retrieval and evaluation. In Bloomberry's analysis of about 1,000 postings, Python appeared in 66% and AI agents in 35%. Customer-facing skills such as discovery and scoping are asked for as well.

Do forward deployed engineers need machine learning?

Usually applied AI, not model research. Indeed's India report, relayed by IANS on 14 October 2026, lists machine learning and generative AI, but Anthropic's and OpenAI's postings centre on production LLM systems, evaluation and deployment. Training models from scratch does not appear as a core ask in the postings cited here.

Which programming language is best for forward deployed engineer roles?

Python, by a clear margin. Bloomberry found it in 66% of postings, against TypeScript in 35%. DevRev, Cursor and Databricks all name Python alongside TypeScript, JavaScript or Scala, and HackerRank's Bengaluru posting names Python or Ruby for API scripts. SQL appears in DevRev's list.

Is a degree required to become a forward deployed engineer?

Postings usually ask for a degree but accept equivalents in some cases. Anthropic lists a Bachelor's degree or an equivalent combination of education, training and experience. DevRev's Delhi NCR posting asks for a Bachelor's or Master's degree in computer science, engineering or a related field. Experience bars usually matter more than the degree.

How long does it take to learn forward deployed engineer skills?

The postings state experience bars of 4+ years at Anthropic, 5+ at OpenAI and DevRev, and 6+ at Databricks, while Cursor states no minimum. The time is therefore measured in years of shipped work, and no posting gives a course length for these skills.
