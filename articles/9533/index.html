End-to-End Hands-On Project

Original title: 端到端实战项目｜FDE 从入门到精通

FDE 从入门到精通 · 2026-10-14 · 2 min read

Summary

This article presents an end-to-end hands-on project for learning forward deployed engineering: building and validating an enterprise after-sales ticket assistant as a reviewable demo. All companies, users, tickets, and metrics are synthetic; no real LLM or production RAG is claimed. The project spans six milestones—discovery, design, implementation, validation, launch readiness, and retrospective—each with defined deliverables and review evidence. A 100-point scoring rubric covers problem value, engineering integration, AI evals, security/reliability, and handoff; failing security-critical items blocks any production-readiness claim. A downloadable offline retrieval script and advanced tasks (real identity, recall evaluation, cost tracking) are included.

Key points

  • Synthetic after-sales ticket assistant case, from problem interviews to launch retrospective.
  • Six milestones, each with concrete review evidence like ADRs and permission matrices.
  • Implementation order: deterministic search first, then model integration.
  • Validation covers no-answer, unauthorized, and failure scenarios with fixed samples.
  • Security-critical failures prevent production-readiness claims regardless of total score.

Project Goals and Scope

Complete the project design and validation package for an enterprise after-sales ticket assistant. All enterprises, users, tickets, manuals, and metrics are synthetic materials. This case is for learning purposes only; it is not a delivered customer case, and it does not claim to run a real large model or production RAG.

The first phase supports reading tickets, searching authorized materials, generating drafts with citations, and human review; it excludes automatic sending, device control, cross-tenant queries, and automatic closure.

Review and Scoring

DimensionScoreEvidence Required to Pass
Problem and Value20Facts/hypotheses separated, metrics have denominators
Engineering and Integration25Contracts, duplicate requests, exception behavior
AI and Evals20Sample versions, error taxonomy, and human scoring
Security and Reliability25Isolation, revocation, degradation, and recovery
Handover and Review10Reproduction by others and follow-up ownership

This is a learning scoring suggestion, not a professional certification. If safety-critical items fail, the project cannot be claimed production-ready even with a high total score. Unimplemented capabilities are explicitly marked as designed or pending validation.

Advanced Tasks

After integrating real identity and persistence services, retest resource authorization; replace keyword retrieval and evaluate recall; after integrating a model, add factual support, citation accuracy, and cost tracking; before adding write tools, add approval, idempotency, and recovery. Use the project template throughout to save evidence.
