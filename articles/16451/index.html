Align your team's skills with Rocketlane Skills Matrix

Rocketlane · 2024-05-20 · 4 min read

Summary

Rocketlane announced Skills Matrix (May 2024), a feature for professional services teams that replaces spreadsheet-based skill matching with a centralized, searchable skills library. It maps team proficiencies to project requirements, converts requirements into resource plans, and integrates with Rocketlane's Resource AI to assemble project teams automatically. Managers can group skills by role, view ratings, spot skill shortages, and decide where to upskill or hire. The skill library can be updated in real time, and gap-reporting features were teased as upcoming.

Key points

  • Skills Matrix centralizes team skills, replacing spreadsheets and manual filtering.
  • Project requirements can be turned into resource plans in seconds.
  • Resource AI uses skills and proficiency data to build teams automatically.
  • Skills can be grouped by role to reveal gaps and guide upskilling or hiring.
  • The skill library updates in real time; gap reports are coming soon.
