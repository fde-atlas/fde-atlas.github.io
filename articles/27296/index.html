Over 9 weeks, you build one customer AI engagement, from problem discovery to a tested deployment, user acceptance and handover. Each week adds to the same engagement repository.

Phase 1, BuildEngineer intelligent AI systemsWeeks 1–4

Sessions 01–08

Week 01, sessions 01–02Models and agent harnesses

  • S01: Model, reasoning, context and gateway engineeringFast vs deliberative models, structured outputs, context budgeting and compaction, caching, model routing, cost and provider abstraction.
  • S02: Agent harness, skills and engineering velocityPi, AGENTS.md, SKILL.md, plugins, progressive disclosure, Superpowers, SDD/TDD, independent review and sandboxed execution.

Week 02, sessions 03–04Retrieval and knowledge engineering

  • S03: Advanced retrieval strategiesDocument AI, multimodal parsing, lexical, vector and hybrid search, reranking, hierarchical and vectorless retrieval, provenance, citations and abstention.
  • S04: Knowledge bases, knowledge graphs and GraphRAGEntities, relationships, ontologies, small-scale graph construction, multi-hop reasoning, temporal facts and graph-assisted retrieval.

Week 03, sessions 05–06Loop and graph engineering

  • S05: Loop engineeringReAct, plan-act-verify, bounded goal loops, heartbeat, schedule and event triggers, tool permission boundaries, budget limits, stuck detection, retry, pivot, escalation and termination.
  • S06: Graph engineering and adaptive agent topologiesLangGraph state, deterministic and validator nodes, conditional edges, checkpointing, human interrupts, parallel delegation, static vs adaptive graphs and A2A concepts.

Week 04, sessions 07–08Memory, evaluation and optimisation

  • S07: Memory and long-context engineeringWorking, episodic, semantic and procedural memory, consolidation, compaction, contradiction handling, revision, expiry, deletion and poisoning defence.
  • S08: Agent evaluation and neuro-symbolic verificationTask and trajectory evaluation, calibrated judges, tool-action correctness, property testing, deterministic invariants, Z3 constraints and evaluation-driven optimisation (GEPA).

Phase 2, ConnectIntegrate enterprise data and systemsWeeks 5–8

Sessions 09–16

Week 05, sessions 09–10Enterprise context and governed data access

  • S09: Enterprise data discovery and agent-ready accessData estates, metadata discovery, ownership, lineage, permissions, catalogues, APIs, databases, warehouse access and synthetic data environments.
  • S10: Enterprise context, semantics and ontology engineeringCanonical entities, cross-system identity mapping, business vocabularies, semantic metrics, entity relationships, source precedence and knowledge provenance, with an introduction to Apache Ossie and metadata-aware AI.

Week 06, sessions 11–12AI-native data engineering and storage

  • S11: Intelligent multimodal ingestion and data contractsLLM-powered extraction, classification and enrichment, deterministic transformations, schema validation, AI data contracts, exception handling, lineage, freshness and deletion propagation.
  • S12: AI storage architecture and knowledge lifecycleRelational, vector and graph stores, lakehouse and warehouse integration, indexing strategies, tenant-aware filtering, incremental updates, re-embedding, versioning, retention and safe migrations.

Week 07, sessions 13–14Enterprise SQL agents and AI analytics

  • S13: Semantic-layer-grounded SQL agentsMetadata-guided schema discovery, business metric definitions, text-to-SQL, query decomposition, SQL AST validation, schema and column authorisation, read-only execution, query budgets and execution-accuracy evaluation.
  • S14: Analytical intelligence across structured and unstructured dataMulti-step analytical planning, sandboxed Python computation, warehouse and lakehouse access, graph, SQL and vector reasoning, source attribution, numerical reconciliation and analytical evaluation.

Week 08, sessions 15–16Enterprise capability integration and proactive AI workflows

  • S15: Agent-ready enterprise APIs, MCP and connectorsConverting existing APIs into safe agent capabilities, OpenAPI-to-MCP adaptation, skills and plugins, typed tool contracts, scoped permissions, approval-bound actions, idempotency and connector governance, with an introduction to browser and computer-use fallback.
  • S16: Event-driven, proactive and recoverable agent workflowsWebhooks, schedules, CDC, event-triggered loops, asynchronous execution, knowledge freshness, duplicate events, retries, dead-letter handling and recovery.

Phase 3, ShipSecure, deploy, operate and demonstrate valueWeeks 9–12

Sessions 17–24

Week 09, sessions 17–18AI operations, controlled pilots and safe releases

  • S17: Observability, continuous quality and AI FinOpsOpenTelemetry and OpenObserve, model, agent and tool traces, task quality, drift, cost per successful task, tenant and feature attribution, budgets, SLOs and FOCUS-aligned cost reporting.
  • S18: Progressive autonomy, model migration and safe releasesShadow, human-approved and scoped autonomous execution, OpenFeature and flagd, evaluation-based canaries, prompt, model and skill versioning, rollback, release manifests, technical UAT and incident recovery.

Week 10, sessions 19–20Identity, trusted execution and security

  • S19: Enterprise identity and agent authorisationOIDC, SAML and SCIM, authentik, scoped and delegated credentials, user-to-tool attribution, MCP authorisation, enterprise-managed authorisation, RBAC and ReBAC, and gateway policy controls.
  • S20: Agentic security and AI supply chainOWASP LLM, agentic and MCP risks, malicious skills and plugins, memory poisoning, tool escalation, sandbox boundaries, PII, model provenance, approved capabilities and AI bills of materials.

Week 11, sessions 21–22Model serving and operational applications

  • S21: Model selection, optimisation and servingHosted vs self-hosted models, sovereign and Indian-language options, prompt optimisation, RAG vs fine-tuning, quantisation, KV caching, batching, vLLM and inference economics.
  • S22: Deployable AI applications and agent-to-user interfacesProduction service topology, durable execution, containers, AG-UI, MCP Apps, streaming progress, human approvals, exception handling and managed vs self-hosted runtimes.

Week 12, sessions 23–24Distributed AI systems and scaling

  • S23: Scaling and isolating agent workloadsStateless services vs durable state, workers, Kubernetes pods, queues, KEDA, safe code execution, sandbox isolation, resource limits and failure recovery.
  • S24: Distributed inference and capacity engineeringModel-aware routing, KV cache reuse and offloading, disaggregated inference, SGLang, llm-d, Dynamo, residency, availability and cost-capacity architecture.

Alongside the weekend sessions, industry leader talks and doubt-clarification sessions will be held on pre-informed weekdays.

The curriculum and schedule are subject to enhancements. A few modules, topics or their sequence may change as the programme is enriched, while retaining the core learning objectives.
