Prerequisites

AIelsen FDE Academy · 2026 · 1 min read

Summary

This page outlines prerequisites for the AIelsen FDE Academy, an engineering and delivery course for FDE practitioners. It states that a learner's background changes preparation priorities but not the final standard. Required technical baseline includes Python or TypeScript, SQL, HTTP/JSON, Git, and basic testing, with concrete checks like reading CSVs, writing SQL with correct denominators, calling functions with error handling, and explaining changes in Git. Documents do not replace code: learners must independently run, modify, and explain an adapter and business tool. Software engineers should strengthen discovery, metrics, stakeholder work, and attribution, while business specialists start with the business path and can join interviews and reviews, though the engineering path still requires code, tests, and delivery evidence.

Key points

  • Background changes preparation priorities, not the final standard for FDE practitioners.
  • Baseline skills: Python or TypeScript, SQL, HTTP/JSON, Git, and basic tests.
  • Concrete checks include reading CSVs, writing SQL, handling function errors, and running tests.
  • Documents do not replace code; learners must run and explain an adapter and business tool.
  • Business specialists use the business path first; engineering path still requires delivery evidence.

Full text

BACKGROUND & PREPARATION

Software engineering

Strengthen discovery, metrics, stakeholder work and attribution.

Preparation evidence

Turn a business incident into objects, definitions, ownership and acceptance.

From fieldwork to lasting business capability.FORWARD-DEPLOYED ENGINEERING

PREREQUISITES / FDE PRACTITIONERS

This is an engineering and delivery course for FDE practitioners. Your background changes preparation priorities, not the final standard.

Run and modify local programs, understand tables and APIs, track changes in Git and write basic tests. Python or TypeScript, SQL and HTTP/JSON are recommended.

  • Read a CSV; check nulls and duplicates.
  • Write SQL; explain denominators, windows and empty results.
  • Call a function, validate parameters and handle errors.
  • Run tests and explain a change in Git.

Strengthen action states, integration, operations and scope management.

Demonstrate replay, unknown outcomes, denial and recovery.

Strengthen Python, SQL, APIs, Git, tests and model tool use; documents do not replace code.

Independently run, change and explain an adapter and business tool.

If coding is new, begin with the Academy business path, then build programming foundations and complete the entry check. Business specialists can join interviews and reviews; the engineering path still requires code, tests and delivery evidence.
