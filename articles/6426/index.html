Why AI Infrastructure must evolve for Agent Experience — Akshat Bubna, Modal CTO

Latent Space · 2026-07-08 · 60 min read

Summary

In this Latent Space episode, Modal CTO Akshat Bubna argues that cloud infrastructure designed for human developers must evolve for agents, which need fast iteration loops, sandboxes, and programmatic control instead of docs and dashboards. Modal, fresh off a $355M Series C, rebuilt cloud primitives from scratch for AI workloads—elastic inference, GPU snapshotting, speculative decoding, and serverless multi-node training—claiming Kubernetes was never suited to bursty, compute-heavy jobs. The company has shifted its SDK focus from developer experience to agent experience, runs a capacity pool across 17 cloud providers, and says RL rollouts can demand 100,000 sandboxes. Observability, he argues, now matters more than reading code.

Key points

  • Modal raised a $355M Series C and positions itself as an AI-native cloud.
  • Kubernetes was built for web servers, not bursty AI workloads.
  • Modal shifted its SDK focus from developer experience to agent experience.
  • RL rollouts may require 100,000 sandboxes; production agents need hard guardrails.
  • Modal pools capacity across 17 cloud providers and prioritizes observability.

The cloud was built for developers. But agents are now changing that.

The old infra stack was designed for a human who could read docs, reason through YAML, and understand dashboards to figure out what they need when something broke. While this was painful for developers, it worked since they could fill in missing context in their heads.

However, agents don’t have that luxury. Now in this new era of agents, everything has to be tighter.

Agents need good developer experience too - Modal Blog

They need a place to write code, run it, inspect the output, change the environment, debug failures, and try again. Fast iteration and feedback loops with all the necessary context are crucial for agents to operate properly.
