Palantir Foundry Pipeline Builder: Concepts & Join Types (Theory)

FDE Times · 2026 · 1 min read

Summary

This FDE Times video article is a theory-focused tutorial on Palantir Foundry's Pipeline Builder. It explains the tool's core concepts and the various join types available when building data pipelines, aimed at helping forward deployed engineers and data practitioners understand how datasets are combined before moving to hands-on work. No step-by-step implementation is covered; it serves as a conceptual foundation for working with Foundry pipelines.

Key points

  • Theory tutorial on Palantir Foundry's Pipeline Builder.
