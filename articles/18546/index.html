Forward Deployed Engineer vs. Prompt Engineer: Unterschied

Spitzenbesetzung · 2026-11-02 · 5 min read

Summary

This German article contrasts the Forward Deployed Engineer with the Prompt Engineer. The FDE owns the whole system—data, integrations, permissions, and rollout to stable operation—while the prompt engineer only improves response quality. The author argues prompt engineering is usually a skill within other roles, not a standalone job, and offers symptom tables to diagnose whether the bottleneck lies in instructions or in data and integration. Salary benchmarks: FDEs at €90,000–120,000 or from €1,050/day; pure prompt roles typically below the GenAI median of €96,500. Recommendation: identify the bottleneck before posting a job.

Key points

  • FDEs own the solution through stable production; prompt engineers only optimize answers.
  • Prompt engineering is usually a skill embedded in other roles, rarely a standalone position.
  • Symptom tables help decide if the problem is instructions, data, or integration.
  • FDE salaries run €90,000–120,000; pure prompt roles sit below the €96,500 GenAI median.
  • Advice: diagnose the bottleneck first, then decide which role to hire.

Ein Prompt Engineer verbessert, wie ein Sprachmodell antwortet: Er schreibt und testet Prompts und baut Bewertungen dafür. Ein Forward Deployed Engineer verantwortet das ganze System bis zur stabilen Nutzung, also Daten, Anbindung, Rechte und Einführung. Hängt nur die Antwortqualität, reicht ein Prompt Engineer. Hängt die Einführung, brauchen Sie den Forward Deployed Engineer.

Warum Prompt Engineering oft keine eigene Stelle ist

Prompt Engineering ist eine Fähigkeit und in vielen Unternehmen keine eigene Stelle. Die Arbeit wandert oft in andere Rollen: Der Forward Deployed Engineer schreibt Prompts als Teil seiner Einführung, der AI Engineer als Teil seiner Anwendung. Eine eigene Prompt-Stelle kommt vor allem dort vor, wo Antwortqualität das Hauptproblem ist und ein Produkt bereits läuft.

Ein Beispiel: Ein Assistent für den Kundenservice antwortet zu unpräzise. Ein Prompt Engineer verbessert Anweisungen, Beispiele und Testfälle. Bekommt das Modell aber die falschen Dokumente, liegt das Problem im Abruf der Daten. Dann hilft ein besserer Prompt wenig. Die Suche und ihre Datenquelle müssen geändert werden, je nach Aufstellung durch einen AI Engineer oder einen Forward Deployed Engineer.

Wann ein Prompt Engineer sinnvoll ist

  • Eine KI-Anwendung läuft bereits im Betrieb.
  • Daten und Anbindung sind in Ordnung.
  • Fachbereiche brauchen Vorlagen und Schulung.
  • Sie brauchen für eine begrenzte Zeit Spezialwissen.

Hier passt oft ein zeitlich begrenzter Einsatz, siehe Prompt Engineer Freelancer.

Wann Sie einen Forward Deployed Engineer brauchen

  • Die Lösung läuft noch nicht im Betrieb.
  • Das Vorhaben berührt Daten, Rechte und mehrere Systeme.
  • Niemand verantwortet die Einführung.
  • Sie wollen eine Person, die den ganzen Weg geht.

Gehalt und Tagessatz

Für eine reine Prompt-Rolle führen wir keinen eigenen Indexwert. Näherungsweise dient der KI-Tagessatz- und Gehaltsindex DACH Q3/2026 für GenAI, LLM und RAG Engineers mit einem Median von 96.500 € Jahresvergütung und 1.060 € Tagessatz. Unsere Einschätzung: Reine Prompt-Profile liegen je nach Tiefe auch deutlich darunter. Der Forward Deployed Engineer liegt in unseren sechs Mandaten bei 90.000 bis 120.000 Euro oder ab 1.050 Euro Tagessatz, siehe Forward Deployed Engineer Gehalt.

Warum Sie auch ohne Stelle Prompt-Wissen brauchen

Wer mit Sprachmodellen arbeitet, muss gute Anweisungen und Tests schreiben können. Dieses Wissen gehört in jede KI-Rolle. Prüfen Sie es im Gespräch mit einer kleinen Aufgabe: Geben Sie eine schlechte Antwort vor und lassen Sie sich zeigen, wie die Person die Ursache sucht. Was sich am Berufsbild verändert hat

Die Modelle sind in den letzten Jahren deutlich besser darin geworden, auch aus einfachen Anweisungen etwas Brauchbares zu machen. Das verschiebt die Arbeit: Weniger Formulierungskunst, mehr Systemarbeit mit Kontext, Werkzeugen und Tests. Diese Entwicklung ist unsere Einschätzung des Marktes. Für Unternehmen heißt das: Prüfen Sie jede Prompt-Stelle kritisch darauf, ob sie in zwei Jahren noch dieselbe Aufgabe hat.

Die stabile Kernfähigkeit dahinter bleibt wichtig. Wer systematisch misst, ob eine Änderung Antworten verbessert, arbeitet professionell. Wer nur nach Gefühl umformuliert, liefert selten dauerhafte Verbesserungen. Lassen Sie sich im Gespräch zeigen, wie die Person eine Verbesserung nachweist.

Der Unterschied bei Fehlern

Ein Beispiel zeigt das Denken beider Rollen. Ein Assistent nennt eine veraltete Preisliste. Ein Prompt Engineer ergänzt die Anweisung, immer die neueste Fassung zu verwenden. Ein Forward Deployed Engineer prüft, warum die alte Fassung überhaupt gefunden wird, und ändert den Abruf oder die Datenquelle. Die erste Lösung wirkt schnell, nur die zweite verhindert, dass der Fehler wiederkommt.

Wenn Sie zwischen den Rollen schwanken, schauen Sie auf die letzten Fehlerfälle. Ging es um Formulierung oder um Daten und Systeme? Das zeigt am besten, was als Nächstes ansteht.

Empfehlung: Erst den Engpass finden, dann die Stelle ausschreiben

Suchen Sie zuerst den Engpass. Liegt er bei Daten, Anbindung oder Nutzung, sucht ein Prompt Engineer an der falschen Stelle. Bevor Sie Prompts optimieren, sollte die Lösung laufen. Dafür zeigt unser Leitfaden, wie Sie einen Forward Deployed Engineer finden.

Häufige Fragen

Was ist der Unterschied zwischen Forward Deployed Engineer und Prompt Engineer?

Der Prompt Engineer verbessert die Antwortqualität. Der Forward Deployed Engineer verantwortet die Lösung bis zur stabilen Nutzung im Betrieb.

Schreibt ein Forward Deployed Engineer auch Prompts?

Ja, das gehört meist dazu. Es ist aber nur ein Teil der Arbeit.

Lohnt sich eine eigene Stelle für Prompt Engineering?

Eher selten. Sinnvoll ist sie, wenn eine Anwendung läuft und die Antwortqualität der Engpass ist.

Muss ein Prompt Engineer programmieren?

Das schwankt je nach Stelle. Für Tests und Bewertungen hilft Programmieren deutlich.

Ist für den ersten KI-Anwendungsfall ein Prompt Engineer oder ein Forward Deployed Engineer besser?

Meist der Forward Deployed Engineer, weil zuerst Anbindung und Nutzung stehen müssen.
