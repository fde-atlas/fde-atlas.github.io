Summary

This channel from FDE中国 collects 12 tool profiles for forward deployed engineers delivering AI agents, updated through August 18, 2026. Each card gives a one-line positioning, when to use the tool on-site, and whether it is open source or commercial. Coverage spans evals (OpenAI Evals, promptfoo, Braintrust), observability (Langfuse, LangSmith, Arize Phoenix), agent frameworks (LangGraph, OpenAI Agents SDK, Claude Agent SDK), self-hosted inference with vLLM, elastic compute with Modal, and the MCP integration standard. Selection methods and deeper comparisons also live here.

Key points

  • 12 tool profiles covering the FDE and AI agent delivery toolchain.
  • Evals tools include OpenAI Evals, promptfoo, and Braintrust.
  • Observability options compared: Langfuse, LangSmith, Arize Phoenix.
  • Agent frameworks covered: LangGraph, OpenAI Agents SDK, Claude Agent SDK.
  • vLLM for private deployment, Modal for pilot compute, MCP as connection layer.
