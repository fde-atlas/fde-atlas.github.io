Forward deployed engineers trained by Plank

Plank · 2026-06-15 · 1 min read

Summary

This page from Plank describes its AI FDE Course, a 40-day program that trains full-stack TypeScript engineers as forward deployed engineers. It defines an FDE as a software engineer who embeds within a customer's organization, writes production code against real customer data and systems, and owns whether the product delivers results rather than merely ships. The curriculum covers an AI-powered development workflow plus building production AI systems: chat, agents, retrieval, voice, integrations, infrastructure, and enterprise deployment, with each day ending in a working build. The page lists 8 engineers, only 1 with completed days so far, and shows public profiles containing each engineer's name, GitHub account, a dated timeline of completed course days, and a skill set weighted by how many completed days cover each tool or technique. Profiles update as days are marked complete.

Key points

  • Plank runs a 40-day AI FDE Course for full-stack TypeScript engineers
  • FDEs embed with customers and own outcomes, not just shipping
  • Curriculum spans chat, agents, retrieval, voice, and enterprise deployment
  • Every course day ends in a working production build

Questions

  • What is a forward deployed engineer?
  • A forward-deployed engineer (FDE) is a software engineer who embeds inside a customer's organization to make a product actually work in their environment. They write production code against the customer's real data and systems, and they own whether it delivers a result, not just whether it ships.
  • How does Plank train forward deployed engineers?
  • Plank trains forward deployed engineers on the AI FDE Course: 40 days for full-stack TypeScript engineers: the AI-powered development workflow, then building and shipping production AI systems, from chat and agents to retrieval, voice, integrations, infrastructure and enterprise deployment. Every day ends in a working build.
  • What does a profile on this page show?
  • Each profile shows the engineer's name and GitHub account, a timeline of the AI FDE Course days they have completed with the date of each, and a skill set folded from those days: the tools and techniques each day teaches, weighted by how many completed days cover them. Profiles are public and update as days are marked complete.
