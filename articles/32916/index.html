Forward deployed engineer skills: what the job ads name

Kernavique · 2026-11-26 · 2 min read

Summary

Kernavique analyzed the text of 297 open US job ads titled with "forward deployed" from 65 employers on November 26, 2026, counting how often each of 37 predefined skills was named. Python leads with 204 mentions (43 employers), followed by AI agents (168) and APIs (134); TypeScript appears in 119 ads and Java in 63. The article cautions that a mention does not mean a skill is required, and that one employer posting many ads can inflate counts, so each figure includes the number of distinct employers. Advice: candidates should mirror ad wording and pair skills with customer problems solved; employers should check these counts before publishing ads to avoid narrowing their candidate pool unintentionally.

Key points

  • 297 US job ads from 65 employers were analyzed on November 26, 2026.
  • Python is named most often: 204 ads across 43 employers.
  • AI agents appear in 168 ads; APIs in 134; TypeScript in 119.
  • Mentions do not distinguish required skills from optional ones.
  • Candidates should pair named skills with customer problems on résumés.

What it means

The counts above come from employers’ own ads. What follows is Kernavique’s reading of them.

If you are a forward deployed engineer

Use the words the ads use. If you have shipped work with a skill on this page, name it on your résumé with the customer problem it solved, because that is the pairing these ads describe.

If you are hiring them

Compare your ad with these counts before you publish it. An ad that asks for a skill few others name narrows the field; decide whether you mean it as a requirement or as one option among several, and write it that way.

Questions people ask

  • How are the skills counted?
  • We read the full text of each ad from the employer’s own job feed and check it against a fixed list of 37 skills. An ad counts once for a skill however many times it names it. Skills not on the list are not counted.
  • Does a named skill mean it is required?
  • No. An ad may list a skill as required, preferred or as one of several options, such as “Python, Java or Scala”. We count the mention and do not judge the condition. Read the ad for that.
  • Why do some employers’ products appear?
  • An employer’s ads name its own product. Every Databricks ad names Databricks, for example. The employer figure beside each count shows when a skill is named mostly by one employer.
  • Which language do most ads name?
  • Python, on November 26, 2026: 204 of 297 ads name Python, at 43 employers. TypeScript is named in 119 and Java in 63.
