Razorpay, the Bengaluru payments company, hires Forward Deployed Engineers to ship AI agents inside its merchants’ businesses. It is one of the few Indian product companies using the FDE title for a role that looks like the original model: you sit with the customer’s engineers, own the integration end to end and stay on until it works in production.

Why Razorpay needs FDEs

At its FTX’26 event in March 2026, Razorpay launched Agent Studio, a marketplace for AI agents in payments and banking (Razorpay’s own blog lists the no-code agent builder as a beta), according to The Paypers. Launch agents included abandoned-cart conversion over voice or messaging, dispute response, subscription recovery (built with ElevenLabs) and cash-flow forecasting, with integrations into Shopify, WhatsApp, Shiprocket, Slack and QuickBooks. The press release says Agent Studio is built with Anthropic’s Claude Agent SDK.

Off-the-shelf agents only go so far for large merchants. The FDE is the engineer who makes them fit a specific merchant’s systems.

What the FDE owns

Razorpay’s Bengaluru listing describes the full loop:

  • Pre-sale discovery. Assess integration complexity and whether a workflow suits an agent, then co-author the deployment plan in the proposal.
  • Integration lifecycle. Work with merchant engineering teams from architecture to go-live.
  • Agent building. Tool bindings, MCP integrations, orchestration pipelines, evals and human-approval flows on Agent Studio.
  • Cross-system debugging. Across Razorpay’s systems, the merchant’s systems, external tools and model behaviour.
  • Hypercare. First responder for 15–30 days after each go-live.
  • Making it repeatable. Quarterly deployment blueprints for the shared knowledge base, and structured feedback to product managers.

The listing is explicit that this is embedded engineering, not pre-sales, support or solutions architecture. If you are a solutions engineer, that line matters: you will need to show you write and debug production code, not only design it.

How to prepare

  • Ship a payments-flavoured agent. For example, an agent that reads a webhook for a failed payment, checks order data through an API and sends a WhatsApp recovery message, with a human approval step before any refund.
  • Show debugging across boundaries. Have one story where the bug was in someone else’s system and you found it through logs, retries or a webhook signature mismatch.
  • Learn MCP and one agent framework properly. The listing names MCP, LangChain, LangGraph and AutoGen. Build tool bindings and an eval set, not just a chat demo.
  • Practise discovery. Given a merchant problem, can you say in 10 minutes whether it suits an agent, what it integrates with and what could go wrong? That is the pre-sale part of the job.
  • Bring a hypercare mindset. Talk about monitoring, rollback and what you did in the first two weeks after something you built went live.

Razorpay FDE interview: what is publicly known

  • Process for the FDE role: Razorpay's FDE listing does not describe the interview rounds.
  • What to expect from the job description: The role covers pre-sale technical discovery, merchant integration, agent building with evals and production debugging, so expect to be tested on reading unfamiliar code, API and webhook integration, an agent or LLM design discussion and how you work with external technical teams.

Frequently asked questions

What does a Forward Deployed Engineer do at Razorpay?

They work with merchants' engineering teams to scope, build and launch AI agents on Razorpay's Agent Studio: technical discovery, integration architecture, agent workflows with tool bindings and evals, debugging across systems, and support for 15–30 days after go-live.

How much experience does Razorpay want for FDE roles?

The Bengaluru FDE listing asks for 3–10 years of hands-on software engineering, including shipping and debugging production code in live customer environments.

Can freshers join Razorpay as Forward Deployed Engineers?

Not in the FDE listing we found. Freshers usually enter Razorpay as SDE-1 or interns, according to FACE Prep, and can move towards customer-facing engineering after building production experience.

What is Razorpay Agent Studio?

A marketplace for AI agents in payments and business banking, launched at FTX'26 in March 2026, with a no-code agent builder in beta. Agents include abandoned-cart conversion, dispute response, subscription recovery and cash-flow forecasting, and the press release says it is built with Anthropic's Claude Agent SDK.
