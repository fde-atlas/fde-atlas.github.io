AI Agent — AI Glossary

AI Codex · 2026-04-23 · 8 min read

Summary

This glossary entry from AI Codex defines an AI Agent as a system that takes a sequence of actions to complete a goal, rather than simply answering questions. Unlike a chatbot, an agent can search the web, read documents, write code, call other systems, and keep working until the task is done — the key distinction being that agents act, not just say. Using Claude as the example, the entry describes giving an agent a goal (such as monitoring an inbox and drafting urgent replies) and letting it run autonomously. It also links to 37 related articles covering agent operations, evals, cost control, multi-agent systems, Anthropic product releases like Claude Code and Managed Agents, and emerging roles such as forward deployed engineers with compensation reportedly ranging from $150K to $700K+.

Full text

Also: autonomous agent

An AI system set up to take a sequence of actions to complete a goal — not just answer a single question. Instead of just responding to your message, an agent can search the web, read documents, write code, send requests to other systems, and keep working through multiple steps until it finishes the task. Claude can act as an agent when given the right tools. The key difference from a regular chatbot: agents do, not just say.

In practice

Instead of asking Claude "what should I do next?" and acting on its answer yourself, an AI agent does the acting. You give it a goal — "monitor this inbox and draft replies to anything tagged urgent" — and it runs, takes actions, checks results, and keeps going until the job is done.
