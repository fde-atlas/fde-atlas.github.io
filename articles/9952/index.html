What is Dev? Meaning & Definition

Full text

FDE Pulse Glossary

Also: Palantir Dev, Software Engineer

Dev is Palantir's name for its central Software Engineers. A Dev owns a platform component end to end and writes code that ships to many different customers. The focus is one capability for many customers.

That is the mirror image of a Delta, the Forward Deployed Engineer, whose focus is many capabilities for one customer. Palantir's own framing of the difference is the clearest way to understand the whole model: Devs build the product, Deltas deploy it deeply into one place, and Echos make sure it solves a real problem there.

If you are weighing a core software engineering path against a forward deployed path, the Dev versus Delta distinction is the decision in miniature: breadth and product ownership versus depth and customer impact.

Frequently Asked Questions

What is the difference between a Dev and a Delta at Palantir?

A Dev is a core Software Engineer who builds one capability for many customers. A Delta is a Forward Deployed Engineer who builds many capabilities for one customer, embedded in that customer's environment.
