  • Requirements split into functional and non-functional categories (security, performance, maintainability, etc.).

  • BizDev Tech data: TypeScript led listings (53), average monthly rate 798,000 yen across all projects.
  • Language picks by use case: Python for AI, C++/C# for games, PHP/JavaScript for web systems.

Software development broadly consists of the following stages.

1. Requirements definition 2. Design 3. Development 4. Testing 5. Release 6. Maintenance and operation

Among these, programming takes place during stage 3, "Development."

First, in requirements definition, you determine what functionality the software to be developed needs. Then, in the design stage, design documents are created for developing that functionality.

Development is the stage where actual coding is done based on the basic and detailed design documents for the UI and other external appearance and internal functionality created during the design stage. In other words, programming is the work of implementing functionality, so it can be considered the substantive development work of software.

Specific examples of parts that involve programming include the following.

・Basic functionality ・Data input/output ・Business flowcharts ・Layout of operation interfaces ・Servers ・Batch processing related to function processing ・Databases ・Maintenance, and many more

Note that programming content broadly falls into functional requirements and non-functional requirements.

Functional requirements are the "functions" that the client demands of the software. They can be considered the minimum that must be achieved in a given project, such as "a function that efficiently processes XX data."

Non-functional requirements, on the other hand, refer to aspects of software quality other than functional requirements. Specifically, these include "availability," "performance and scalability," "portability," "operability and maintainability," "security," and "system environment and ecology."

By programming with non-functional requirements in mind—such as how efficiently and safely the implemented functions can operate, and how to improve usability—the overall quality of the software improves.

In addition, server construction as infrastructure development is also important. Not just hardware servers, but software servers such as web servers, database servers, file servers, and mail servers also need to be properly built.

Among programming languages, it is the most representative language. Although its processing speed is not particularly fast, coding is simple and its flexibility is relatively high.

PHP excels at web system development, and is particularly useful for creating dynamic pages, such as changing the information displayed on a website based on the user. It can be used to develop a wide variety of web systems, including contact forms, search functions, and e-commerce site construction.

On the other hand, it is not good at advanced numerical processing, so it is not well suited to development involving heavy calculations or graphical representation.

Examples of services

Facebook, Wikipedia, Coconala, and more

JavaScript, like PHP, is one of the most popular programming languages. It enables a wide range of programming, from simple to complex processing, and is used for creating dynamic web pages as well as game development.

It can move parts of a website's screen, such as changing text color or size and switching images, so it is also good at developing applications with advanced behavior in the browser. For example, Google Docs and Google Sheets are applications that run on JavaScript.

Kindle Cloud Reader, Google Docs/Google Sheets, Kagu Size Search, and more

Python is a programming language developed in 1991, characterized by its ability to write simple code with a reduced amount of code. Due to its ease of writing and readability, differences based on the skill level of programmers and engineers are less likely to appear, making it useful even in projects shared by multiple people.

In addition to image processing, video processing, and numerical processing, it has a rich set of libraries for web development and databases, so it can handle all kinds of development.

Although it is a language with a long history, in recent years it boasts advantages in deep learning processing, particularly in the rapidly advancing fields of AI and machine learning.

However, its weakness is slow execution speed, so it is probably not suitable for large-scale projects or development that requires fast processing speeds, such as games.

YouTube, Dropbox, Instagram, and more

Ruby is a programming language created by a Japanese developer. It features simple coding that is easy to read and write, and allows even unconventional coding styles, so many development companies support it.

It has much in common with Python, and in general anything that can be developed with Ruby can also be developed with Python.

However, there are the following differences between the two.

・Ruby: Well suited for building web systems using frameworks, such as e-commerce sites and application sites

・Python: Well suited for software development involving AI-driven analysis and analytics

CrowdWorks, Kakaku.com, Hulu, and more

A programming language used around the world, capable of development in a variety of fields, including web systems and applications.

Java has the slogan "Write Once, Run Anywhere," meaning "write once, and it runs anywhere." Just as this phrase suggests, with Java you can build programs that run smoothly in basically any environment, regardless of OS type such as Mac or Windows.

Java has many strengths, including technical stability, top-class processing speed, and high security, and it is a trusted language, adopted even for Android app development and large-scale system development.

Note that JavaScript only has a similar name and is an entirely unrelated, separate language, so be careful not to confuse the two.

Evernote, Rakuten, Twitter, and more

Often called "C-plus-plus," this is a programming language derived from the C language, which was designed to run computers quickly.

It is highly versatile and can be used for development in various fields, including IoT, games, and operating systems. Actual examples of software developed in C++ include Google's browser "Chrome" and the "Unreal Engine" from Epic Games, the developer of the game "Fortnite."

Since C++ is derived from the C language, which originally prioritized computer processing speed, it is well suited to development that demands processing speed and complex processing.

Google Chrome, Unreal Engine, Cocos2d-x, and more

While its syntax is similar to C, it is strongly influenced by Java, and is characterized by a mix of the strengths of C++ and Java.

Since it was originally a language used for Windows, many Windows applications are developed in C#. It is also used in the development of many web applications, games, and smartphone apps, making it a language that enables flexible and efficient development.

MSN, Bing, Unity, and more

Although it is a relatively new programming language developed in 2011, Google's adoption of it as the official development language for Android helped it become widely used in Android software development.

While it has its own syntax and differs from Java in many ways, a major feature is that development is possible by calling source code already written in Java or reusing assets created in Java.

Since it runs regardless of OS environment, such as Windows or Mac, it is well suited for building web systems and web servers, as well as app development.

The programming languages suited to each type of development are summarized below.

For smartphone app development, Java, Kotlin, Go, and other similar languages are suitable.

Due to Java's high versatility, many apps built with Java have already been released on Google Play and elsewhere. Kotlin, as mentioned earlier, is a language frequently used in Android software development.

For game development, C# and C++ are suitable. C# is highly trusted, to the point of being adopted by famous game engines, while C++ is particularly useful for online game development thanks to its fast processing speed.

For web system development, PHP and JavaScript are suitable.

PHP, which can be applied in many situations, enables smooth integration between various web systems and databases. One reason JavaScript is well suited to web system development is that it allows easy testing in a browser.

For AI and machine learning development, Python and Java are suitable. Python in particular, with its abundance of available libraries, is attracting attention as an indispensable language for AI and machine learning development, where statistical processing and advanced calculations are required.

Note that the examples of programming languages by development type shown here are for reference only. There are many languages, and the languages programmers and engineers have mastered vary from person to person.

Which language is actually used for development will depend on the development company and the skills of the staff doing the programming.

In software development, it is important to proceed with development using the appropriate programming language and development method according to the nature and scale of the project. Just like programming languages, development methods each have their own strengths and weaknesses depending on the type.
