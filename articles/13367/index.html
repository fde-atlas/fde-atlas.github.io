Summary

This is an archive page for Anil Pervaiz's blog on AI architecture, agents, RAG, evals, and forward-deployed delivery. Key posts cover how he prices FDE engagements across discovery, thin slice, hardening, and handoff; a pre-handoff agent evaluation playbook using smoke tests, golden sets, and a go-live scorecard; and a build log for webflow-agent-kit, an open-source TypeScript toolkit with Zod-validated tools for Webflow. Other essays address the undemoed 80% of FDE work (SSO, legacy data, security review), role comparisons between FDEs, Solutions Engineers, and freelancers, staffing options for AI work, and 2026 AI consulting pricing. The tone is practical and field-oriented rather than theoretical.

Key points

  • Blog indexes essays on AI agents, RAG, evals, and FDE delivery.
  • FDE pricing follows discovery, thin slice, harden, handoff phases.
  • Agent quality is checked via smoke tests, golden sets, and scorecards.
  • Most FDE work is SSO, legacy data, security review, and day-2 ops.
  • Posts compare FDE, Solutions Engineer, and freelance developer roles.
