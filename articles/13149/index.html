FDE Insights: Practice, Skills and Hiring

FDE Council · 2026-10-25 · 1 min read

Summary

FDE Council's Insights section offers articles on Forward Deployed Engineering practice, skills, and hiring. Topics include mapping learning paths to an open competency framework with 11 draft domains, measuring delivery success using four kinds of evidence (with demos and pilots explicitly not counting as results), skills analysis based on Lightcast and Bloomberry job posting data, a comparison of FDE, Solutions Engineer, and related roles using cited 2026 data, plus competency-based hiring and delivery guides. The Council notes the framework is open for comment and not yet validated through a formal job task analysis, and the resource is editorial, not a certification.

Key points

  • Open competency framework has 11 draft domains; learning path mapping guidance is provided.
  • Success measurement relies on four evidence types agreed before the build.
  • Skills analysis maps Lightcast and Bloomberry posting data to framework domains.
  • Role comparison covers ownership, skills, pay, demand, with a five-question posting test.
  • Framework is open for comment and not yet formally validated.
