FDE-Adoption-Growth

Original title: FDE-Adoption-Growth

FDE中国社区 · 2026-07-12 · 4 min read

Summary

This article documents FDE-Adoption-Growth, a skill package (v1.1) from the FDE China community addressing a common failure mode: AI projects pass technical acceptance but nobody uses them, blocking renewals and expansion. It proposes an adoption funnel (awareness, trial, regular use, dependence, advocacy) supported by training, champion programs, feedback loops, value broadcasts, and usage dashboards, measured via DAU/WAU, task completion, renewal intent, and NPS. It defines four stage gates, collaboration interfaces across FDE, AIBP, business owners, and IT/security, common pitfalls, and four scenarios (post-PoC rollout, low adoption, pre-renewal, multi-department scaling). An illustrative case shows weekly active users rising from under 5% to 32% before renewal. The package includes checklist, evaluation, prompt, README, and workflow files for use with Agent Skills tools.

Key points

  • Targets projects that pass technical acceptance but see no real usage.
  • Uses a five-stage adoption funnel with champions, training, and feedback loops.
  • Tracks DAU/WAU, task completion, renewal intent, and NPS.
  • Defines stage gates and role boundaries for FDE, AIBP, owners, and IT.
  • Illustrative case lifts WAU from under 5% to 32% before renewal.

Methodology Framework

FAQ

Q1: When executing [FDE-Adoption-Growth], how do you avoid "doing training without building champions"?

A: Follow the README methodology step by step and showcase interim deliverables in the weekly Demo; if PoC materials are incomplete, first produce a "pending validation list" before proceeding.

Q2: What additional constraints apply in private deployment/Xinchuang/MLPS environments?

A: Specify the deployment model explicitly in the prompt constraints section; when data cannot leave the domain, localized components, or audit logs are involved, reference Private-Deployment-Gateway and RBAC-Audit accordingly.

Q3: What if the division of responsibilities with AIBP is unclear?

A: Return to the AIBP-Collaboration-Playbook to update the RACI; AIBP owns Ground Truth and business acceptance, while the FDE owns deliverable technical assets.

Q4: After the PoC passes, how do you transition to Beta/production?

A: Mark the next-stage Skill in the deliverables (e.g., RAG-Evaluation→Private-Deployment-Gateway→FDE-Adoption-Growth), and trigger the launch gate via the checklist.
