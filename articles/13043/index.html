Three Types of FDEs | FDE Learning Center

Original title: FDE 的三种类型 | FDE 学习中心

luoboask.github.io · 1 min read

Summary

This article argues that "FDE" means different things at different companies and splits the role into three types. Type A focuses on inference infrastructure—vLLM/TensorRT-LLM tuning, GPU cluster operations, and latency optimization—at companies like ByteDance and Alibaba Cloud. Type B covers application deployment: RAG pipelines, agent frameworks, and evals, typical of AI startups. Type C is the Palantir-style customer delivery model, also seen at OpenAI and Databricks, combining on-site deployment with consulting. The author suggests identifying a target company's type via job description keywords and team placement (infra, AI application, or GTM), then preparing interviews accordingly. The site's own learning path focuses on Type A.

Key points

  • FDE roles fall into three types: inference infra, application deployment, customer delivery.
  • Type A involves vLLM/TensorRT-LLM tuning and GPU cluster management at ByteDance, Alibaba Cloud.
  • Type B covers RAG pipelines, agent frameworks, and evals, mostly at AI startups.
  • Type C is the Palantir model: on-site deployment plus consulting, also at OpenAI and Databricks.
  • Identify the type via JD keywords and team placement, then prepare accordingly.

Different companies define FDE differently; before the interview, confirm which type you're interviewing for

Type A: Inference Infrastructure​

Core: Inference engine optimization, GPU management, latency/throughput optimization

Typical work​

  • vLLM / TensorRT-LLM tuning
  • GPU cluster operations and scheduling
  • Inference platform development
  • Quantization and performance optimization

Tech stack​

CUDA, C++, Python, K8s, vLLM/TensorRT-LLM

Representative companies​

ByteDance (AI Infra), Alibaba Cloud, Tencent AI Infra

Type B: Application Deployment​

Core: RAG systems, agent architectures, prompt engineering, evals

Typical work​

  • AI application architecture design
  • Building RAG pipelines
  • Agent framework development
  • Model evaluation systems

Tech stack​

LangChain/LlamaIndex, vector databases, eval frameworks

Representative companies​

AI startups, ToB AI service providers

Type C: Customer Delivery (Palantir model)​

Core: Deploying AI on-site at customers, business process transformation, technology + consulting

Typical work​

  • On-site customer deployment
  • AI-driven business process transformation
  • Technical solutions + consulting services
  • Cross-team collaboration

Tech stack​

Full stack + communication skills + industry understanding

Representative companies​

OpenAI (Forward Alliance), Palantir, Databricks

How do you determine the target company's FDE type?​

看 JD 关键词：
  - "vLLM / TensorRT / GPU / CUDA" → Type A
  - "RAG / Agent / LangChain" → Type B
  - "Customer / Client / Delivery" → Type C

看团队归属：
  - 归属 Infra / Platform 团队 → Type A
  - 归属 AI 应用团队 → Type B
  - 归属 GTM / Enterprise 团队 → Type C

Interview strategy: Once you've confirmed the type, prepare accordingly. This learning path focuses mainly on Type A (inference infrastructure).
