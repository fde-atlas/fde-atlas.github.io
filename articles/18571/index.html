FDE Course Syllabus: 33 Chapters, 9 Parts, and Lab List

Original title: FDE课程大纲：33章·9篇与实验清单

深圳市真实智元科技有限公司 · 2026 · 8 min read

Summary

Shenzhen-based 真实智元 has published a detailed syllabus for an FDE training course: 33 chapters across 9 sections plus a lab list. The curriculum is built around a five-step delivery framework attributed to OpenAI practice (Discover, Prototype, Validate, Go live, Scale) and assessed via an FCB three-level competency benchmark, 16 exam questions, and a 48-hour challenge. Technical chapters cover LLM APIs, function calling, RAG, agents, MCP, fine-tuning, evals, and production engineering, with labs designed to run without GPUs or paid APIs. It also includes a capstone project, a simulated customer-service QA delivery case, a comparison of low-code platforms (Tencent ADP, Coze, Alibaba Bailian), and four delivery formats from a 5-day bootcamp to a 12-week course and corporate training.

Key points

  • 33 chapters, 9 sections, structured around OpenAI's five-step delivery framework.
  • Assessment: 16 exam questions, a 48-hour challenge, and FCB three-level benchmark.
  • Technical labs on RAG, agents, MCP, evals run without GPU or commercial APIs.
  • Includes a capstone project and a simulated customer-service QA case study.
  • Compares Tencent ADP, Coze, and Alibaba Bailian low-code platforms against code frameworks.

MCP and low-code platforms: what do you learn from each?

MCP (Model Context Protocol) standardizes how AI applications connect to external tools, resources, and prompt templates. Low-code platforms provide a working environment for building applications and orchestrating workflows. The course practices interface connections and platform selection separately, then checks results using the same inputs, outputs, and eval samples.

Course Formats and Learning Schedules

  • 5-Day Bootcamp: Cognition → five-step method → Prototype Day → Validate Day → Demo Day, benchmarked against the Palantir AIP Bootcamp.
  • 12-Week Systematic Course: Weekly pace of 6–8 hours, all assignments from each chapter's practice, capped by a final Demo Day.
  • Corporate Training: 2 days of intensive workshops + a 4–8 week internal project Residency, with practice materials prepared around the company's products, delivery requirements, and existing workflows.
  • Partner / Channel Workshop: 1–3 days, timed scenario assessments aligned with five domains: requirements analysis, solution design, application building, delivery implementation, and security compliance.

Tuition and fees are determined by class type at consultation: watch related hands-on clips or return to the FDE Practical Training and Competency Assessment homepage.
