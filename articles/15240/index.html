FDE for Data Engineers: Free Course

DataDank · 2026 · 1 min read

Summary

DataDank offers a free course teaching data engineers the basics of forward deployed engineering. It contains six lessons (about one hour of reading) organized from beginner to advanced, each with runnable Python code. Topics include running technical discovery with customers, scoping a proof of concept with a success metric and review date, API integration (authentication, pagination, rate limits, retries), and customer data integration with field mapping, cleaning, quarantining bad records, and count reconciliation. Related free courses on Python, ETL/ELT, and AI agents are also listed.

Key points

  • Free six-lesson course, roughly one hour of reading, with runnable Python code.
  • Covers technical discovery: questions to ask and profiling customer data in week one.
  • Teaches POC scoping with a success number, tight limits, and a review date.
  • API integration lessons cover auth, pagination, rate limits, retries, and error handling.
  • Data integration includes field mapping, normalization, quarantine, and reconciliation.
