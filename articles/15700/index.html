Golden set

FDE Interview Prep · 2026 · 1 min read

Summary

This article explains the golden set: a fixed, versioned collection of inputs with expert-agreed labels, used to score every version of a system consistently. It must stay out of prompts and training data, with a dev split for iteration and a held-out split for scoring only, otherwise improvements may just reflect fitting the test. In FDE interviews, notably Snowflake's Senior/Staff Applied AI role, candidates should show how they would create labels: write guidelines with customer domain experts, verify inter-rater agreement, stratify by segment and risk, and size the set for the decision. Statistically, at a 0.90 pass rate, n=100 gives a 95% confidence interval of about ±0.06 and n=400 about ±0.03, so 100 samples cannot distinguish a 0.90 from a 0.93 system. New production failures enter as a new set version, keeping comparisons valid.

Key points

  • A golden set is a versioned, expert-labeled test set for consistent scoring.
  • Keep a dev split and a held-out split to avoid fitting the test.
  • FDE interviews test how you build labels with customer domain experts.
  • Sample size matters: n=100 cannot distinguish 0.90 from 0.93 pass rates.
  • Add new failures as a new version; compare scores only within a version.

Full text

A golden set is a fixed, versioned collection of inputs with expert-agreed expected outputs or labels, sampled to cover the segments and failure cases that matter, and used to score every version of a system the same way. It stays out of prompt examples and training data, and you keep a dev split to iterate on and a held-out split you only score; tune against the whole set and a better score may mean you fitted the test, not that the system improved. New production failures go in as a new version of the set, so scores are only ever compared on the same version.

In FDE interviews

Snowflake’s Senior/Staff Applied AI posting makes the hire responsible for turning customer goals into quality metrics, evaluation frameworks and golden datasets.
